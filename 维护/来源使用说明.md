# 来源材料怎么使用

主学习入口是各专题的中文章节。来源材料用于补原文、图示、完整推导和实验设计；来源保全不代表其全部结论已复核，也不代表其中历史代码能在今天直接运行。

## 数据科学 Notebook 的实际入口

从[20 课练习地图](../数据科学基础/10-课程练习地图.md)进入，打开 Notebook 时将工作目录设为该 Notebook 所在目录。数据相对路径按这个前提修复。

- 第 04 课统计例子和第 09～12 课可视化解答，已有本地数据；仍需安装代码导入的依赖。
- 第 01 课词云访问网页，并带安装命令；第 07 课论文分析依赖在线数据。先检查来源与依赖，不能默认离线可用。
- 第 07 课 COVID 示例使用历史教学数据，不表示当前疫情数据；若改用本地副本，先查看代码中的本地数据路径。
- 第 08、14、15 课包含练习步骤和可选库。空白练习单元不是文件损坏，应按题意补全。
- 第 19 课属于历史 Azure 工程示例；`solution/notebook.ipynb` 在固定上游提交中就是 0 字节。本仓库保留这一事实，不能把它当作有效解答。
- Notebook 的内嵌表格、图片、执行序号是来源中的历史输出。本次的文件结构检查不等于从头运行通过。

先做主库第 05 章的自包含 pandas 小例子。它不需要下载数据、注册云平台或执行来源中的安装命令，适合检验自己的基础环境。

## 上游缺失的内容如何处理

有些原始链接指向未随固定提交提供的运行结果 JSON 或架构图。本次在对应位置注明“上游未提供文件”，保留原文件名用于追溯，没有补造结果，也没有据此声称实验已复现。

R 分支中的三个作业链接在上游缺失，本次改为同主题已有的通用作业；这是阅读入口修复，不意味着补齐了专用 R 实现。上游错误的相对目录层级也已修正。

遇到本文未覆盖的失效链接，先区分：迁移路径错误、上游文件缺失、网络暂时不可达、版本变更。仅有 403、429、超时等响应不足以判定知识或来源失效。

## 原始字节与迁移修订

修订前的文件可通过 Study 的 Git 历史恢复；上游版本可由登记的提交与 Blob SHA 定位。修改过相对链接、数据路径或缺失提示的保全文件已登记新校验值，不再声称与上游逐字节相同。原清单中的 Blob SHA 始终描述上游文件，不能拿它与修订后的本地文件混为一谈。
