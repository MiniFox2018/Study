# 06 · Object-Oriented Programming

## 类与对象
类定义状态和行为，对象是类的实例。成员包括数据成员和成员函数。访问控制：`private`、`protected`、`public`。

## 构造函数
负责建立有效对象状态。常见类型：默认构造、参数化构造、拷贝构造和移动构造。优先使用成员初始化列表。

## 析构函数
对象生命周期结束时自动执行，常负责释放资源。作为多态基类时通常应提供虚析构函数。

## 封装
封装的核心是维护不变量，并通过稳定、最小的接口管理内部状态，而不是简单地把字段设为 private。

## 继承
继承表达“is-a”关系。C++ 支持单继承、多继承和不同访问继承方式。设计时通常优先组合，只有真正存在替代关系时才使用继承。

## 多态
- 编译期多态：重载、模板等
- 运行时多态：虚函数配合基类引用/指针

## 虚函数
基类声明 `virtual`，派生类建议写 `override`，由对象动态类型决定最终实现。

## 抽象类
包含纯虚函数的类不能直接实例化，可用于定义接口。

```cpp
struct Shape {
    virtual double area() const = 0;
    virtual ~Shape() = default;
};
```

## 接口
C++ 没有 interface 关键字，通常用只有纯虚函数和虚析构函数的抽象类表达接口。

## friend
friend 函数或类可访问私有成员。适合极少数紧密协作场景，但会扩大封装边界，应谨慎。

## static 成员
静态数据成员属于类而不是单个对象；静态成员函数没有 `this` 指针。

## 设计原则
保持类职责清晰；资源类遵循 RAII；多态删除时使用虚析构；覆写时写 override；优先组合；避免公开可随意修改的数据成员。
