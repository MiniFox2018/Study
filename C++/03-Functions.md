# 03 · Functions

## 函数基础
函数由返回类型、函数名、参数列表和函数体组成，用于复用逻辑和拆分复杂问题。声明可放头文件，实现放源文件。

```cpp
int add(int a, int b) {
    return a + b;
}
```

## 参数
- 按值：复制实参，适合小型标量
- `T&`：可修改原对象
- `const T&`：避免复制且保持只读，适合较大对象
- 指针：可表达可空对象、数组或底层接口

## 返回值
可返回值、引用或指针。不要返回局部对象的引用或地址。现代编译器可通过返回值优化和移动语义高效返回对象。

## 重载
同名函数可通过不同参数列表重载；仅改变返回类型不能构成重载。要注意隐式转换导致的二义性。

## 默认参数
默认参数应从右向左连续设置，通常只在声明位置给出一次。

## 递归
递归必须有基线条件，并保证问题规模不断缩小。适用于树遍历、分治等场景，同时要考虑调用栈深度。

## inline
`inline` 不保证机器码一定内联，它更重要的现代语义是允许符合 ODR 要求的头文件定义。真正的内联优化由编译器决定。

## Lambda
Lambda 是匿名可调用对象，适合局部算法和回调。捕获方式包括不捕获、按值、按引用和指定捕获；引用捕获必须保证生命周期安全。

```cpp
int limit = 10;
auto greater = [limit](int x) { return x > limit; };
```

## 函数设计
函数应职责单一、命名清楚、参数尽量少、错误策略一致，并避免隐藏的全局状态依赖。
