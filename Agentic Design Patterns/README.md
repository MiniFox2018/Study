1. 以当前目录作为后续增删改查的固定基线。

先读[导读](./00-导读.md)，再做第 1、5、11、12、19 章的小例子：拆步骤、调用工具、判定完成、处理失败、评价结果。做完以后再按遇到的问题补路由、记忆、RAG、并行或协议。

2026-10-02 将 21 个核心章节及附录/术语等原占位页补为可学习内容，包含原理、例子、反例和核对答案；主干是本库综合教学整理，不等同于原网站逐字译本。来源保全用于查完整上下文；其代码和实验不能因已保存就视为已运行。
