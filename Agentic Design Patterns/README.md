## 维护原则

1. 以当前目录作为后续增删改查的固定基线。
2. 新内容优先归入已有章节；确需新增主题时再进入「专题扩展」。
3. 技术术语统一维护在「术语表／术语对照表」。
4. 主目录保持精简；只有仍有长期价值且许可合适的来源才做保全。
5. 对高时效资料先做时效性审计；过时模型、API、SDK、价格和操作步骤不记录。
6. 每个章节文件独立维护，便于后续精确修改。
