## 工具、MCP与Skills的具体学习顺序

先能读写JSON、解释参数类型和错误，掌握[05工具](01-核心章节/05-工具使用.md)与[工程13结构化输出](../LLM%20工程实践/13-结构化输出与对话状态.md)。不需要先学完全部模型训练。每一步以“解释一对输入/输出、改一个反例并定位拒绝边界”为完成证据。

| 次序 | 中文主入口 | 先学会什么，再进入下一步 |
|---|---|---|
| 工具合同 | 05工具、工程13 | ID配对、参数/单位/事实/来源校验；只读不等确定性，ready仍可取消 |
| MCP角色与传输 | [10 MCP](01-核心章节/10-模型上下文协议-MCP.md)、[通信06](06-专题扩展/06-MCP通信与状态工程.md)第1～4节 | 每请求metadata、JSON-RPC、字节帧、HTTP状态、镜像头/正文一致；legacy适配独立 |
| 内容与消费 | 通信06第5～6节 | tool/resource/prompt选型、输出schema、五类内容、private缓存、opaque分页与订阅 |
| 输入与持久工作 | 通信06第7～10节 | MRTR新ID重试、nonce/版本批准、Tasks租约、取消竞态、业务幂等与Apps桥接 |
| 授权与运行治理 | [授权07](06-专题扩展/07-工具授权与发布治理.md)、[18安全](01-核心章节/18-安全模式.md) | issuer/resource/PKCE、JWT/opaque新鲜度、gateway逐跳授权、完整pin和可用版本回退 |
| 证据与互操作 | 通信06第11～12节、[15 A2A](01-核心章节/15-智能体间通信-A2A.md)、[19观测](01-核心章节/19-评估和监控.md) | core/Apps/Tasks各自版本；wire/SDK/proxy分层，trace真正传播/导出需要接收侧证据 |
| 组合应用 | [工程10案例](../LLM%20工程实践/10-案例方法论.md) | 明确handle/owner、effect receipt、重启恢复与未完成边界；再考虑真实集成 |
