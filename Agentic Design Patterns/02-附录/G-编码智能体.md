# 附录 G：编码智能体的学习练习

编码 Agent 的主原理集中在[Coding Agent 与通用 Agent](../06-专题扩展/02-Coding-Agent与通用Agent.md)；本页给出可独立验收的小练习。

## 练习：修复空输入问题

选一个本地小函数，例如计算数字列表平均值。先写清楚空列表应报错还是返回特定值，再提供一个正常样例和一个空输入样例。让 Agent 读取函数及调用位置、复现问题、只做必要修改、运行相关验证并解释差异。

验收包含四件事：正常样例仍正确；空输入符合约定；修改没有扩展到无关文件；你能说明为何修复有效。再把输入改成含非数字值或单元素列表，观察边界是否清晰。如果只会点击运行，却不能解释修改和失败原因，仍属待掌握。

**自检**：测试全部通过为什么仍可能有问题？**核对**：测试可能遗漏真实需求、断言过弱、共享同一错误假设或运行了旧文件。检查测试与需求的对应关系，必要时增加一个能暴露原错误的反例。

没有代码或明确问题时，不需要凭空让 Agent 重构整个项目；先建立可观察的任务和反馈。更新：2026-10-02。
