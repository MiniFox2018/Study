# 附录 E：命令行中的 AI 智能体

终端 Agent 通常可读文件、检索文本、运行命令、编辑代码和观察退出状态。能力来自可执行工具及其权限，模型生成的一串命令只是待执行输入。主流程见[工具使用](../01-核心章节/05-工具使用.md)与[异常恢复](../01-核心章节/12-异常处理和恢复.md)。

## 最小工作循环

确认工作目录与规则 → 读取目标文件和相关上下文 → 选择最小修改 → 查看差异 → 运行相关验证 → 报告实际结果。每条命令应有明确目的；处理大量文件时使用脚本和结构化结果，减少手动拼接。

操作前区分只读、可逆写入与外部副作用。对路径、引号、通配符和命令替换要保持警惕，优先传参数数组或使用安全的字面量；不要把模型生成的文本未经检查拼进 shell。密钥不进入日志、提示或提交。

**练习**：命令退出码为 0，但目标文件为空，任务是否完成？**核对**：没有。退出码只反映命令的成功约定，还要检查交付物内容、大小或语义。反过来，测试命令找不到依赖说明验证未执行，不能写成“测试通过”。
