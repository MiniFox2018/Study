# 模型后训练

> 完整来源：[《深入理解 AI Agent》第 8 章](../05-来源保全/深入理解%20AI%20Agent/source/book/chapter8.md)

并非所有 Agent 问题都应该通过训练模型解决。只有当某种能力需要稳定地内化到参数层，才进入后训练。

## 常见训练阶段

预训练、继续预训练（有时称 Mid-training）、SFT 与偏好/RL 优化是可选阶段，不是每个模型必须走完的固定顺序。Mid-training 的使用语境并不统一，应看具体数据与目标，不能仅由名称判断训练方法。

- 缺领域知识或基础分布能力：考虑继续训练；
- 行为格式和流程不稳定：优先考虑 SFT；
- 任务可交互、结果可验证、需要优化策略：可以考虑 RL；
- 若上下文、工具或工作流即可解决，通常没必要先修改模型参数。

## RL 关键问题

环境、任务分布、动作表示、多轮信用分配、工具调用、奖励来源以及结果奖励/过程奖励的取舍。

## 蒸馏

可以把更强模型或成功轨迹转化为训练信号，提高样本效率；也包括在轨蒸馏和自蒸馏等形式。

## 从 Bad Case 出发

后训练应先有稳定评估集，再围绕可复现失败训练，最后回到同一评估体系验证是否真的改善。

## 把 Agent 失败映射到可检验改动

若工具参数经常漏字段，先检查 schema 与提示示例；若结果正确却总提前结束，先检查完成条件和执行循环；若面对充分上下文仍稳定产生错误行为，并有可靠训练样本，再比较 SFT 或偏好训练。任务可验证也不等于必须上 RL，数据量、探索成本、奖励漏洞和回归风险都需考虑。

**自检**：把成功轨迹全部蒸馏进模型，能否保证更可靠？**核对**：不能。轨迹可能成功于偶然条件、包含无用步骤或错误理由。要验证最终结果与关键动作，去除泄漏，按目标任务划分数据，再比较训练前后的独立任务表现。
