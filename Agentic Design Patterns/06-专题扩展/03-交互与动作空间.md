# 交互：观察与动作空间的扩展

> 完整来源：[《深入理解 AI Agent》第 6 章](../05-来源保全/深入理解%20AI%20Agent/source/book/chapter6.md)

Agent 不只处理文本；更完整的视角是持续扩大其观察空间与动作空间。

## 异步与事件驱动

定时器、Webhook、消息、文件变化和审批结果都可主动触发 Agent。系统需要处理事件重复、超时、乱序、中断和长任务恢复。

## 语音

可以从处理管线与交互方式两个维度理解，以下选项并非互斥：

- ASR → LLM → TTS 级联；
- 端到端全模态模型；
- 全双工实时交互。

还需要处理打断、流式输入输出，以及实时回应和深度思考之间的时序关系。

## Computer Use

核心问题包括动作空间、视觉定位、动态页面观察、世界状态理解，以及移动端权限与生态限制。

## 机器人

进一步引入长程规划、低层控制、VLA、世界模型与 Sim2Real，使 Agent 的动作空间进入物理世界。

## 一个观察—动作错位的例子

Agent 看到“保存”按钮，准备点击时页面出现弹窗，原坐标已对应“删除”。这说明动作选择基于某个观察时刻，执行前可能需要重新确认目标。优先用语义元素和当前状态，动作后回读确认；截图坐标适用于当时画面，不能永久复用。

异步事件同样需要时间与身份：同一个 Webhook 到达两次只应处理一次；旧的“处理中”通知不能覆盖新的“已完成”。语音打断则需取消尚未播出的内容，并检查是否也要取消关联工具动作。

**自检**：端到端语音模型是否自动具备全双工交互？**核对**：不是。前者描述模型处理方式，后者描述同时听说及打断能力，还依赖音频管线、时序和产品实现。机器人中的高层语言规划也不能替代低延迟控制与安全约束。
