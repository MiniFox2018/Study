# 交互：观察与动作空间的扩展

> 完整来源：[《深入理解 AI Agent》第 6 章](../05-来源保全/深入理解%20AI%20Agent/source/book/chapter6.md)

Agent 不只处理文本；更完整的视角是持续扩大其观察空间与动作空间。

## 异步与事件驱动

定时器、Webhook、消息、文件变化和审批结果都可主动触发 Agent。系统需要处理事件重复、超时、乱序、中断和长任务恢复。

## 语音

三类主要范式：

- ASR → LLM → TTS 级联；
- 端到端全模态模型；
- 全双工实时交互。

还需要处理打断、流式输入输出，以及实时回应和深度思考之间的时序关系。

## Computer Use

核心问题包括动作空间、视觉定位、动态页面观察、世界状态理解，以及移动端权限与生态限制。

## 机器人

进一步引入长程规划、低层控制、VLA、世界模型与 Sim2Real，使 Agent 的动作空间进入物理世界。
