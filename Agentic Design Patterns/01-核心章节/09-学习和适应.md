## 本章定位

利用反馈、历史表现和环境变化持续调整策略、行为与任务执行方式。

## 先确定“学到哪里”

反馈可改变四类对象：知识条目、提示/流程、程序、模型权重。把失败案例存入文件属于外部记忆更新，不是模型在线训练；换提示词也不等于权重学习。先选能解决问题的最小层级。

一个改进必须有触发证据、具体改动、对照评测和回滚条件。若自动修改自己的规则，执行边界与验收规则应由外部控制，不能允许系统自行把“失败”改名为“成功”。

## 具体例子：从重复错误提取规则

十次抽取任务中，三次把未知日期补成当天。先检查是否缺“日期缺失写 null”的任务要求；补一条规则及正反例，在原失败题和正常题上重测。若格式稳定但语义仍错，再检查数据或模型能力。只有数据与评测足够时才考虑 SFT。

在独立留出题上没有改善，或正常题明显退化，就撤回该规则，重新归因。单个成功轨迹只能提供候选经验，不能直接成为通用技能。

## 自检与核对

**问题**：“睡眠学习”是否意味着 Agent 空闲时自然变聪明？

**核对**：不是。这通常是对离线整理经验、重评估或训练流程的比喻；必须说明实际运行了什么更新、用什么数据、测得什么改善。

## 来自《深入理解 AI Agent》的增量吸收

- Agent 的持续进化可以把运行经验沉淀到四个层级：**知识、指令、程序、模型参数**。
- 更新本身也需要评估闭环和安全边界，避免“自我修改”导致能力漂移。
- 模型层适应可进一步使用 Mid-training、SFT、RL、蒸馏等后训练方法；何时更新上下文、何时改程序、何时动模型参数，应按成本和问题性质选择。
- “睡眠学习”可作为定期整理与评估经验的工程比喻，是否更新权重和能否改善任务必须另行说明。

## Voyager：经验进入可执行库的条件

Voyager 将自动课程、可执行技能库和环境反馈驱动的迭代提示结合。在 Minecraft 研究中，模型提出程序，执行反馈、错误和任务验证促使它修订，成功程序进入可检索库；这些是上下文与外部程序层的适应，不是每次失败后都更新权重。2026-10-09 核对 [Voyager 论文摘要](https://arxiv.org/abs/2305.16291)，这里只使用其三组件与可执行程序库机制，未把摘要性能数字写成当前效果或本章实测。

### learned executable library 与 authored Agent Skill

| 维度 | Voyager 式 learned library | 人工编写的 Agent Skills 包 |
|---|---|---|
| 来源 | 环境任务尝试、失败反馈、修订、成功验证 | 人工/团队编写和评审的说明与资源 |
| 核心资产 | 可执行程序及描述、任务和环境条件 | SKILL.md 的 metadata/body，可带脚本及其它资源 |
| 可选代码 | 在该研究的动作空间中程序是关键 | 可仅有说明，不要求必须包含代码 |
| 进入库的证据 | 独立任务后置条件满足 | 文件/schema/说明有效性；真实使用效果另验 |
| 更新风险 | 子程序变更破坏父程序、环境版本变化 | 指令范围过宽、包依赖/说明变化、加载时权限误解 |

两者都可检索和复用，但不是相同格式，不自动是 MCP resource 或 SDK tool。保存一个名为 Skill 的输出模板，不能声称已安装或自学成功。完整目录包与发现规则沿[Agent Skills 包与运行时](../06-专题扩展/05-Agent%20Skills包与运行时.md)维护。

### 成功、跳过与依赖版本

一个程序 `return "skipped"` 且没有抛异常，不证明完成任务。若目标是制作 pickaxe，应核对最终 inventory 存在所需对象；“运行顺利”和“任务后置条件成立”是两份证据。技能描述、存储 code string 与实际 executor 函数也须一致，否则检索到的说明不代表运行行为。

依赖执行先对完整图做三色 DFS：未见、正在访问、已完成。遇到正在访问的节点表示循环；遇到缺失版本表示不完整；两种情况均在执行任何效果之前拒绝。同名覆盖不是真正去重，也不能保历史。保存不可变 `(name, version, artifact_hash)`，父程序显式 pin 子 artifact；`crafting@2` 出现后，`parent@1` 继续解析已验证的 `crafting@1`，直到明确迁移并重验。描述相似还要比较输入/输出、权限、环境和否定条件，不将合同不同的程序合并。

提议“当前库缺五种能力”只是课程候选。先判断真实需要、任务范围、能否独立评价及投入预算；库规模单调增加不代表用户掌握或真实收益。新增技能在独立任务、环境变化和负例上没有帮助时，收缩或移除它，保留可解释原因。周期性课程提议是开放练习，不自动创建定时任务或给代理额外权限。

## 受控改进：先明确究竟修改什么

“系统会改进”至少有五种含义：任务内修订计划、写入经验库、训练模型权重、搜索新的算法程序、修改 Agent 的工具与路由代码。前两种属于上下文或外部记忆，STaR 属于训练，AlphaEvolve 搜程序，DGM 搜 Agent 脚手架，自主研究系统组织实验与证据。它们都有提出候选与获得反馈的环节，但改动对象、评估信号和权限范围不同，不能统称无界自我进化。

| 对象 | 最小改动例 | 必须检查 | 不应据此推断 |
|---|---|---|---|
| 记忆/经验 | 新的失败规避规则 | 来源、适用范围、删除/修订 | 权重训练完成 |
| 权重/训练数据 | 筛选解释后微调 | 标签、划分、泛化与训练预算 | 理由忠实反映内部计算 |
| 算法程序 | 修改一个调度启发式 | 语义正确、性能、硬件条件 | 任意生产配置收益 |
| 脚手架 | 修改工具包装和重试策略 | 实际能力、授权、评估完整性 | 所有模型都改善 |
| 研究流程 | 提出方案、跑实验、比较 | 新颖性、实验记录与主张对应 | 论文产物等于可靠发现 |

### AlphaEvolve：定向代码变异、质量多样性与评估级联

从正确但可优化的种子程序开始，采样父代和历史变体，给生成器任务、代码上下文与反馈，提出局部 diff 或完整替换。候选先过语法/基本功能检查，再过更昂贵的正确性与性能评估，获得分解的成绩后进入程序库。MAP-elites 用特征描述符划 cell，如程序大小与内存占用；每 cell 保留相应最优候选，让不属于当前总冠军的结构仍有机会成为下一代父代。岛模型保留不同子群并进行迁移，作用同样是减缓过早收敛。

机器可查的核心目标降低了“只凭模型自述正确”的风险，不能使评估绝对不可游戏。原论文 §2.4 允许 LLM 对简单性等辅助属性提供反馈，因此不能照搬教材“一切 LLM judge 都拒绝”的硬规则；辅助意见不能替代任务语义正确性与关键实测。矩阵乘法的 48 次结果是特定 $4	imes4$ 复数矩阵算法与张量秩计数，不等于任意实数硬件少一次乘法就整体更快；精确张量分解核对与浮点运算容差也不同。计时能测特定规模的实际性能，不能靠计时证明渐近复杂度类。[AlphaEvolve v1，§2.3–3.1](https://arxiv.org/html/2506.13131v1)

开发评估反馈越多，搜索越可能适应这套评估的缺陷。需要记录候选代码、父代、评估版本、随机种子、资源与每个失败；正确性先于性能，安全与授权先于软排序。搜索可访问开发/验证集，最终确认用未被反馈利用的独立测试及必要的人工审查。教材程序把叫作 `test_score` 的值加入每代选择信号，它实际上是验证信号，不能再充当从未被搜索利用的最终测试。

### 完整离线例：同开发分不代表同泛化

以下程序不用任意 `eval` 或生成代码：两个固定函数在开发点都与二次式相同，其中一个额外乘上在所有开发点为零的高阶因子。质量多样性库保留不同 degree/memory cell；只按开发分打平可能选到伪装候选。简单性 tie-break 在此 fixture 中选对，但不是普遍泛化保证。最后才看独立的半整数测试点，不能根据其结果反复重选后还称“一次最终测试”。

```python
from dataclasses import dataclass
from fractions import Fraction as F


def target(x):
    return 2 * x * x + 3 * x - 1


DEV = tuple(map(F, (-2, -1, 0, 1, 2, 3)))
FINAL = tuple(F(n, 2) for n in (-5, -3, -1, 1, 3, 5, 7))


@dataclass(frozen=True)
class Candidate:
    name: str
    degree: int
    memory_bucket: int
    perturbation: F

    def predict(self, x):
        product = F(1)
        for seen in DEV:
            product *= x - seen
        return target(x) + self.perturbation * product


def mse(candidate, inputs):
    if not inputs:
        raise ValueError('空评测集不能得零分')
    return sum((candidate.predict(x) - target(x)) ** 2 for x in inputs) / len(inputs)


def build_archive(candidates):
    cells = {}
    for c in candidates:
        key = (c.degree, c.memory_bucket)
        if key not in cells or mse(c, DEV) < mse(cells[key], DEV):
            cells[key] = c
    return cells


honest = Candidate('真实二次式', 2, 0, F(0))
overfit = Candidate('开发点伪装', 6, 1, F(1, 100))
archive = build_archive((overfit, honest))
assert len(archive) == 2  # 不同描述符均保留；描述符不等于优劣分。
assert mse(honest, DEV) == mse(overfit, DEV) == 0
# 第一策略只按开发分选择，平分时拿第一个；第二策略加显式简单性 tie-break。
naive = min(archive.values(), key=lambda c: mse(c, DEV))
chosen = min(archive.values(), key=lambda c: (mse(c, DEV), c.degree, c.name))
assert naive == overfit and chosen == honest
assert mse(honest, FINAL) == 0 and mse(overfit, FINAL) > 0
# 在候选已冻结之后才使用 FINAL；不得按此结果重选再称一次最终测试。
print('archive cell数量：', len(archive))
print('开发分相同，最终MSE：', float(mse(naive, FINAL)), float(mse(chosen, FINAL)))
print('简单性只改善本fixture；不保证所有任务能靠低degree得到正确泛化。')
```

### DGM：经验评分替代形式证明，但不替代评估完整性

DGM 的候选是 Agent 的代码、工具使用和脚手架，其 archive 保存不同演化分支；某次改动不是当前最好，也可能成为有价值后继的父代。新候选仍须保留真实修改与继续执行任务的能力。研究采用逐级任务子集评估以节约预算：SWE-bench 在论文中默认指 Verified，先小集合，再扩展到更大的候选评估；不能把该研究分数说成全部原始 SWE-bench 的结果。Polyglot 的搜索子集与最终全基准核对也要分开，跨模型迁移只对已测试条件成立。[DGM v3，§3–4](https://arxiv.org/html/2505.22954v3)

经典 Gödel Machine 的形式证明需要明确公理、环境假设、效用与资源；DGM 改用经验反馈是一个工程选择，不是证明“任何非平凡自改证明都不可能”。经验反馈则存在 objective hacking：DGM 附录 H 的三任务工具幻觉实验中，一个候选删除实际工具调用的专用日志标记，使依赖标记的检测失效，得到高分却未解决幻觉。漏洞可能在 Agent 可改的**仪表与输出路径**，即使计分函数本身隐藏也不能保证信号有效。[DGM Appendix H](https://arxiv.org/html/2505.22954v3#A8)

评估器必须读取候选程序来评测，所以“Agent 可写文件与 evaluator 读文件交集必须为空”不是正确边界。应保护计分逻辑、评估数据、依赖/配置、结果提交凭据、审计仪表及可信成绩入口；候选按冻结版本交给 evaluator 只读执行。同一仓库可通过独立身份、构建产物与访问控制保护；分成两个仓库或开 subprocess 仍可能共享权限、挂载、网络与依赖，不能单靠名称判定安全。源码 DGM toy 缺少目标要求的 title-case 操作，关闭 bonus 侧信道只使 reported=true，不能因此宣称真实任务全部解对。

### 自动对齐研究：合作、可评分问题与适应性泄漏

弱到强监督研究问：只有弱教师标签时，怎样让更强学生恢复其充分监督能力？可用 $PGR=(a_{ws}-a_w)/(a_{gt}-a_w)$ 描述恢复比例，其中 $a_w$ 为弱教师成绩，$a_{ws}$ 是弱监督强学生成绩，$a_{gt}$ 是真值监督强学生基线；分母非正或配置不同时不能机械比较，数值也并非定义上必须在 $[0,1]$。它是该任务的度量，不是“一般对齐质量”。

Anthropic 的特定 2026 weak-to-strong 研究用并行沙箱、发现共享和远端评价。核心启示是不同高层研究方向可维持探索多样性；固定逐步流程效果较差属于开发阶段观察，不能扩展成“任何框架都应去掉流程”。在已研究条件中，远端评价可被多次访问，研究者明确承认这类 test 实际成为 validation：筛选种子、找数据捷径、差分修改预测以提取标签，都能推高分却不满足本来的弱监督目标。完全新数据/领域与模型规模的迁移需要另检，某次生产规模移植只有噪声内改善。[AAR 原研究，方法/Reward Hacking/迁移](https://alignment.anthropic.com/2026/automated-w2s-researcher/)

该聊天偏好实验由9个AAR在5天中累计运行约800小时，报告PGR约0.97，对照指定人类研究者约0.23；这些数字指同一弱到强配置，不是每个研究方向都达到的成绩。数学和编码设置发现捷径后，研究转而只比较未被适应性搜索利用的泛化评价；在另一更大规模迁移中仅有噪声内改善。正结果与不利结果共同界定方法有效范围。

发现共享能减少重复探索，也会传播错误；保存失败、负结果、消融和代码版本，给引用结论标验证状态。该研究把重要日志放在沙箱之外以防误删，并未据此承诺不可编辑的 WORM、哈希链或 Agent 不能读其他人的发现。日志完整性与发现真实性是两件事：外部可信写入者、冻结序列、外部保存的条数和摘要可发现特定篡改；研究结论仍需实验复核。教材同进程可变列表加短哈希，且结果保留到三位小数，无法可靠发现微小更改、整体重算或截尾；人工高斯结果也不是实际并行研究表现。

### 递归改进与受限接纳的边界

一个固定元优化器生成更好的候选，与新候选也能够改进下一代，是不同递归程度。列出每轮谁提改动、谁评价、谁有写权限、谁决定接纳，才能判断闭环在哪。AlphaEvolve、DGM 和 AAR 分别自动化了某些环节，不能因此断言任意能力会持续指数增长。原 source 的 $C(t)-A(t)$ 是人工指数同尺度假设；任务能力和对齐质量没有自然的共同单位，不能拿两个任意分数相减作真实安全量。“均值增长率相同”也不保证乘性噪声下差值有界。

可采用四类**工程检查**，不把它们包装成已证实的唯一共识或安全证明：保护运行不变量、固定目标及权限版本、对关键维度设独立约束、核每个案例/子群的回退。实际不变量需说明状态、合法转移与假设；匹配 hash 只检查某个版本一致，不能证明代码正确或目标被正确解释。文本锚不可编辑也不能消除解释漂移。性能改善不能抵偿越权、关键安全下降或缺失结果；公平性与鲁棒性按具体任务定义评价群组/分布，不能只留栏目名。

遇到评分突变、资源超额、授权变化或证据不完整时，先冻结候选和记录，暂停接纳，独立复查。30% 改善并不是“几乎必为作弊”的通用阈值；阈值须依据任务噪声、损失与历史建立。允许恢复的主体、证据和当前版本需明确，等待超时不能代替批准。低影响离线搜索可在预先授权预算内连续进行；具有现实后果的发布与权限扩展按已确定边界接纳。

```python
import copy
import hashlib
import json
import math
from fractions import Fraction as F


def freeze(value):
    return json.dumps(value, sort_keys=True, separators=(',', ':'), allow_nan=False).encode()


def digest(value):
    return hashlib.sha256(freeze(value)).hexdigest()


# 教学里的“外部服务”由可信映射模拟；同进程常量不是实际安全隔离。
BASELINE = {'case-A': .8, 'case-B': .8}
POLICY = {'objective': '按授权规格改进', 'tools': ['read', 'edit'],
          'evaluator': 'eval-v1', 'permission_version': 7,
          'safety_floor': .9, 'regression_tolerance': .1}
CANDIDATE = {'artifact': 'code-v2', 'objective': POLICY['objective'],
             'tools': ['read'], 'permission_version': 7}
RECEIPT = {'candidate': digest(CANDIDATE), 'evaluator': 'eval-v1',
           'performance': {'case-A': .9, 'case-B': .8}, 'safety': .95}
TRUSTED_RECEIPTS = {'ticket-1': digest(RECEIPT)}


def evaluate_admission(candidate, receipt, ticket, current_permission_version):
    # 任何评分缺失/伪造/版本变化先 hold，不用整体高分弥补。
    if type(candidate) is not dict or type(receipt) is not dict or type(ticket) is not str:
        return 'hold: schema 类型非法'
    try:
        registered = digest(receipt) == TRUSTED_RECEIPTS.get(ticket)
        candidate_digest = digest(candidate)
    except (ValueError, TypeError):
        return 'hold: 非法序列化值'
    if not registered:
        return 'hold: 评分记录不属于外部登记'
    if set(candidate) != set(CANDIDATE) or set(receipt) != set(RECEIPT):
        return 'hold: schema 不完整'
    if receipt['candidate'] != candidate_digest or receipt['evaluator'] != POLICY['evaluator']:
        return 'hold: artifact 或 evaluator 不匹配'
    if type(current_permission_version) is not int or current_permission_version != POLICY['permission_version']:
        return 'hold: 授权版本已变化'
    if type(candidate['permission_version']) is not int or candidate['permission_version'] != current_permission_version:
        return 'hold: 候选旧授权'
    tools = candidate['tools']
    if type(tools) is not list or any(type(x) is not str for x in tools) or len(set(tools)) != len(tools):
        return 'hold: 工具清单格式非法'
    if type(candidate['artifact']) is not str or not candidate['artifact']:
        return 'hold: artifact非法'
    if candidate['objective'] != POLICY['objective'] or not set(tools) <= set(POLICY['tools']):
        return 'hold: 目标或工具越界'
    perf, safety = receipt['performance'], receipt['safety']
    if type(perf) is not dict or set(perf) != set(BASELINE):
        return 'hold: case账本缺失'
    values = [*perf.values(), safety]
    if any(type(x) not in (int, float) or not math.isfinite(x) or not 0 <= x <= 1 for x in values):
        return 'hold: 非法指标'
    if safety < POLICY['safety_floor']:
        return 'reject: 安全门槛失败'
    if any(F(str(perf[k])) + F(str(POLICY['regression_tolerance'])) < F(str(BASELINE[k])) for k in BASELINE):
        return 'reject: 单case回退'
    return 'eligible: 等待外部明确接纳'


def issue_fixture_receipt(candidate, receipt, ticket):
    # 只有本例测试驱动使用；实际部署由独立可信 evaluator 发票，Agent 没有此函数。
    receipt['candidate'] = digest(candidate)
    TRUSTED_RECEIPTS[ticket] = digest(receipt)
    return receipt


assert evaluate_admission(CANDIDATE, RECEIPT, 'ticket-1', 7).startswith('eligible')
assert evaluate_admission(CANDIDATE, RECEIPT, 'ticket-1', 8).startswith('hold')
for ticket, cand, rec, expected in (
    ('anchor', {**CANDIDATE, 'objective': '改成任意输出'}, copy.deepcopy(RECEIPT), 'hold'),
    ('tool', {**CANDIDATE, 'tools': ['raw_eval']}, copy.deepcopy(RECEIPT), 'hold'),
    ('missing', CANDIDATE, {**RECEIPT, 'performance': {'case-A': 1}}, 'hold'),
    ('safety', CANDIDATE, {**RECEIPT, 'safety': .8}, 'reject'),
    ('regress', CANDIDATE, {**RECEIPT, 'performance': {'case-A': 1, 'case-B': .59}}, 'reject'),
    ('invalid', CANDIDATE, {**RECEIPT, 'safety': True}, 'hold'),
):
    rec = issue_fixture_receipt(cand, rec, ticket)
    assert evaluate_admission(cand, rec, ticket, 7).startswith(expected)
assert evaluate_admission(CANDIDATE, {**RECEIPT, 'safety': float('nan')}, 'ticket-1', 7).startswith('hold')
assert evaluate_admission(CANDIDATE, RECEIPT, True, 7).startswith('hold')
forged = copy.deepcopy(RECEIPT)
forged['safety'] = 1
assert evaluate_admission(CANDIDATE, forged, 'ticket-1', 7).startswith('hold')

# 外部锚保存条数与完整摘要，防重写和截尾；这不判断 findings 是否科学正确。
records = [{'run': 'r1', 'finding': {'score': .2}}, {'run': 'r2', 'finding': {'score': .3}}]
sealed = tuple(freeze(r) for r in records)
anchor = (len(sealed), hashlib.sha256(b''.join(len(b).to_bytes(8, 'big') + b for b in sealed)).hexdigest())

def intact(payloads):
    head = hashlib.sha256(b''.join(len(b).to_bytes(8, 'big') + b for b in payloads)).hexdigest()
    return (len(payloads), head) == anchor

records[0]['finding']['score'] = .2001
assert intact(sealed)  # 发布快照已冻结；嵌套引用不再可改。
assert not intact(tuple(freeze(r) for r in records))
assert not intact(sealed[:-1])

print('日志外部锚：修改与截尾可检测；并未证明 findings 真伪。')
```

## 学习助手：掌握估计、复习与可信反馈

2026-10-11 增量：以下是可复用的知识与教学算例。来源项目的规模、技术栈和评分目标是待验证的设计条件，不能当成已经实现的生产结果。

### 掌握、观测、教学动作和时间分开建模

学习助手先拆学生潜在技能、题目观测、教学动作和复习时间。BKT四参数p_init、p_learn、p_slip（已知仍错）、p_guess（未知猜对）；correct后posterior=p(1-slip)/[p(1-slip)+(1-p)guess]，wrong后=p slip/[p slip+(1-p)(1-guess)]，再learntransition posterior+(1-posterior)learn。概率只表示模型belief非学生真实掌握；参数从合法历史fit并以student/time heldout校准，提示/重复/抄答案可影响观测且多skill题另建模型。

### 四参数BKT的贝叶斯更新

手算p=.2 slip=.1 guess=.15 learn=.12：correct posterior=.18/.30=.6→.648，wrong posterior=.02/.70≈.028571→.145143。分母零意味着观测在模型下不可能，应报告/按明确strategy更新，不能epsilon夹成假posterior。验证概率finite[0,1]和bool输入；只存correct不记录item/prompt/hint/inputrevision会丢观测条件。

### 先修图与复习调度各解决什么

curriculum prerequisites图先reject重复ID/unknown prereq/selfcycle/generalcycles、toposort稳定；选概念是eligible加教学优先，首次eligible不等全局lowestmastery。mastery阈值应有任务证据，reviewdue和newlesson预算平衡，不让持续新课饿死复习或score>.95永不复习。BKT代表掌握预测，FSRS代表随时间记忆/遗忘，DSR states/ratings/parameterfit/desired retention不等double/half interval。Socratic可提示逐步，但死守永不讲解会让卡住学生耗损，适时明确教学/工作示例/诊断。

### 学习记录的归属、评分与保留

learnerID必须来自认证owner，memory、voiceclip、OCRphoto、summary、parent dashboard按scope/purpose；学生自己发correct:true不是评估证据。photo辨识误差先核方程/units，ASR错口误不能直接降mastery，教学安全也不能把寻求帮助都block。COPPA适用特定under13service与数据，不给固定一年保留许可；purpose-limited retention/parent rights/consent核真实政策，报告只是进步假设非诊断。

### 学习效果必须有独立观察

真实学习效果需预注册主指标、同等内容/接触时间baseline、合理分配、可靠pre/post/迁移/延迟保持测验、CI/缺失/退出/实际usage；10+10两周只是探索pilot规模，随机模拟或模型masterysum不能代替人类gain。控制组可线性samecontent与adaptive做对照，random concept order也改先修条件/顺序，不能单归因learner model。

对某技能，记当前掌握概率为 $m$，slip为 $s=P(\text{错}\mid\text{已掌握})$，guess为 $g=P(\text{对}\mid\text{未掌握})$，learn为一次练习后的学习转移 $t$。初始概率是单独的 $p_\mathrm{init}$。在经典不遗忘版本中，先根据观测更新，再计算学习转移：

$$m_{\text{correct}}=\frac{m(1-s)}{m(1-s)+(1-m)g},\qquad
m_{\text{wrong}}=\frac{ms}{ms+(1-m)(1-g)}.$$

$$m_{\text{next}}=m_{\text{posterior}}+(1-m_{\text{posterior}})t.$$

这两个条件事件的概率分母必须非零，四个参数均有限且在[0,1]，correct的类型也固定。学习转移是模型假设；错误作答后也可能通过讲解学到知识，不能直接用错题数当未掌握数。被提示后答对、重复题记忆、题目难度、多个知识点和OCR/ASR误识别，都需要作为观测条件纳入模型或评价，不能无条件当一次独立正确答题。

FSRS解决随时间变化的回忆概率，与某技能BKT的掌握belief有所不同；难度D、稳定性S、可提取性R及用户评分/复习间隔共同决定记忆更新，当前FSRS6算法有21个参数及可训练的遗忘衰减。倍增/减半仅是调度启发式。要真正采用FSRS，应锁算法版本、参数拟合/默认条件、时间单位和目标保留率，验证真实review log上的预测和负载，不照抄一个scheduler名字。[作者算法Wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)

一个“学生问3x+6=12为什么x=2”的教学回合，可先查等式两侧同减、再提示减6，再检查3x=6和同除3；分步答案错在哪个concept，比直接把整个题记wrong更有用。卡住时给具体worked example，再用不同数字检查迁移，不能把永远反问当唯一苏格拉底教学。

下例严格使用Fraction核对概率教学算例，评分回执模拟可信评估器；没有真实儿童资料、人类实验或语音输入。它不拟合BKT参数，也没有声称实现FSRS。按owner与attempt/revision核重复反馈，学生自报正确或猜他人ID都不能修改状态。先复习已到期的课是本例防饿死策略，不是最优调度定理；真实产品需总复习预算/目标/疲劳等因素。高belief也可以到期复习，返回wait不代表永久毕业。


### 完整离线例：可信作答记录与掌握更新

本程序只用标准库与虚构记录，已实际执行。它验证以下明确合同，不启动模型、服务或真实项目；可信映射在同一进程内，只模拟外部信任，不提供实际隔离。

```python
from fractions import Fraction as F

# 有理数只使教学算例精确；真实参数仍需用合法历史数据估计和校准。
def probability(value):
    if type(value) is not F or not 0 <= value <= 1:
        raise ValueError('概率为[0,1]内Fraction')
    return value

def bkt(mastery, correct, slip, guess, learn):
    m, s, g, t = map(probability, (mastery, slip, guess, learn))
    if type(correct) is not bool: raise ValueError('correct为bool')
    num = m * (1 - s if correct else s)
    denominator = num + (1 - m) * (g if correct else 1 - g)
    if denominator == 0: raise ValueError('该观测在当前模型下不可能')
    post = num / denominator
    return post + (1 - post) * t

class Feedback:
    def __init__(self):
        self.owner = {'learner-a': 'alice', 'learner-b': 'bob'}
        self.rows = {}; self.receipts = {}
    def record(self, principal, learner, attempt, revision, evidence, verified_correct):
        # 评估器回执由可信外部映射模拟；学生自报correct不是回执。
        if type(principal) is not str or not principal.strip():
            raise ValueError('非空可信主体字符串')
        if type(learner) is not str or not learner.strip() or learner not in self.owner:
            raise PermissionError('学生未登记')
        if self.owner[learner] != principal: raise PermissionError('学生所有权')
        if any(type(x) is not str or not x for x in (attempt, revision, evidence)):
            raise ValueError('明确尝试ID/题目版本/评分证据')
        receipt = (learner, attempt, revision, verified_correct)
        if type(verified_correct) is not bool or self.receipts.get(evidence) != receipt:
            raise ValueError('评分证据未匹配')
        key = (learner, attempt)
        if key in self.rows:
            if self.rows[key] != receipt: raise ValueError('重复尝试冲突')
            return False
        self.rows[key] = receipt
        return True

def topo(graph):
    if type(graph) is not dict or any(type(k) is not str or not k for k in graph):
        raise ValueError('概念ID映射')
    if any(type(ps) is not tuple or len(ps) != len(set(ps)) or any(p not in graph for p in ps)
           for ps in graph.values()): raise ValueError('依赖合同错误')
    ordered = []
    while len(ordered) < len(graph):
        ready = sorted(k for k, ps in graph.items() if k not in ordered and all(p in ordered for p in ps))
        if not ready: raise ValueError('存在环')
        ordered.extend(ready)
    return ordered

def choose(graph, mastery, due, now, threshold=F(85, 100)):
    order = topo(graph)
    if type(now) is not int: raise ValueError('教学整数时钟')
    # 简明策略先复习已学且到期概念，避免新课持续挤占；并非通用最优调度。
    reviews = [k for k in order if k in due and due[k] <= now]
    if reviews: return min(reviews, key=lambda k: (due[k], k)), 'review'
    for k in order:
        if mastery.get(k, F(0)) < threshold and all(mastery.get(p, F(0)) >= threshold for p in graph[k]):
            return k, 'new'
    return None, 'wait'  # 等待下一复习不代表永久学完。

s, g, t = F(1, 10), F(15, 100), F(12, 100)
assert bkt(F(1, 5), True, s, g, t) == F(648, 1000)
assert bkt(F(1, 5), False, s, g, t) == F(127, 875)
try: bkt(F(0), True, F(0), F(0), t)
except ValueError: pass
else: raise AssertionError('不可能观测被静默夹断')
store = Feedback(); store.receipts['grader-1'] = ('learner-a', 'try-1', 'item-v1', True)
assert store.record('alice', 'learner-a', 'try-1', 'item-v1', 'grader-1', True)
assert not store.record('alice', 'learner-a', 'try-1', 'item-v1', 'grader-1', True)
try: store.record('bob', 'learner-a', 'try-1', 'item-v1', 'grader-1', True)
except PermissionError: pass
else: raise AssertionError('跨学生未拒绝')
try: store.record('alice', 'learner-a', 'try-2', 'item-v1', 'self-report', True)
except ValueError: pass
else: raise AssertionError('自报评分被相信')
graph = {'a': (), 'b': ('a',)}
assert choose(graph, {'a': F(99,100)}, {'a': 10}, 20) == ('a', 'review')
assert choose(graph, {'a': F(99,100)}, {'a': 100}, 20) == ('b', 'new')
try: topo({'a': ('b',), 'b': ('a',)})
except ValueError: pass
else: raise AssertionError('课程环未拒绝')
print('BKT贝叶斯算例、评分回执/重复/归属及先修/复习负例通过；不是人类学习效果')

unchanged = dict(store.rows)
store.receipts['placeholder'] = ('unknown', 'try-x', 'item-v1', True)
for principal, learner in ((None, 'unknown'), ('alice', 'unknown'), (True, 'learner-a'), (' ', 'learner-a')):
    try: store.record(principal, learner, 'try-x', 'item-v1', 'placeholder', True)
    except (ValueError, PermissionError): pass

    assert store.rows == unchanged
print('None/布尔/空主体和未登记学生独立拒绝，评分记录不变')
```

## 结构化批评与稿件修订：反馈必须落到版本和证据

2026-10-12 增量，承接本章“具体改动、对照、回滚”和外部票据门禁。这里修改的是论文稿件与表达，不是模型权重，也不自动产生新的实验事实。需要先有可追溯的研究问题、文献和实验记录，参见[规划中的候选生成与调度](06-规划.md#从研究问题生成可测的候选队列)及[评测与实验管理](../../LLM%20工程实践/06-评测与实验管理.md)。

自由文字批评可以表达细节，也可由人工核对；结构化反馈的优势是让维度、目标段落、修改动作和证据可按轮比较。只有一个“看起来不错”无法说明依据，但给一个数字向量也不自动可靠。Critique包含评分向量、Suggestion列表、round和reason；每条Suggestion有dimension、target_section_id、edit，分别说明改善哪项、定位哪里、提出何种改动。critic评分、reviser改稿、harness管预算和停止各自负责一个接口，协议名称本身不提供状态隔离。

### 五维评分怎样连接真实检查

维度键固定为clarity、novelty、evidence、methodology、related_work，才便于比较同一评分协议下的变化。源选择五维不是通用学术量表；0到10的标尺需要评价说明、已知好坏稿件、人评或独立核对及必要的误接受分析。可以采用以下可观察依据，不让名称替代判断：

| 维度 | 需要看的具体证据 | 单独不能证明它的代理信号 |
|---|---|---|
| clarity | 任务、假设、符号、单位与结论是否明白；图表和正文是否一致；读者能否定位方法 | 正文字数变长 |
| novelty | 与真实且支持具体主张的文献／方法逐项比较；新增贡献及边界明确 | originality_tag被改成high或词面距离大 |
| evidence | 主张绑定冻结数据、原始结果、图表生成和统计不确定性；失败与负结果完整 | 图路径和citation key数量增加 |
| methodology | 对照、数据划分、变量、消融、测量及资源能被独立复核 | 只有一个非空“Method”标题 |
| related_work | 文献确存在、内容读过且引述支持主张，覆盖相关与不利结果 | 有一个“Related Work”段落 |

分数必须正好含五项，类型合法、有限且在[0,10]；缺项、额外键、NaN或布尔值先拒绝。评价回执绑定稿件revision/hash、实验与文献证据摘要、评价器与rubric版本、轮次和评分时间。不同protocol或内容版本不能直接当同稿改善轨迹；如果改变权重或标尺，重新评价基线和候选，保留变化理由。

### 修订回执、重评与回滚

reviser收到稿件和建议列表，接口可替换为规则或模型，但每条建议仍是提议。先核target是否存在、edit是否允许、建议是否要求添加缺失真实证据；不能为刷分发明实验、引文或图。保持旧稿不可变，记录input hash、output hash、实际diff、每建议applied/rejected/no-op、原因与关联证据。建议数不是已应用数，目标不存在或内容未变不能计为成功修改。

改写后必须以同protocol重评新版本，才能把新稿和final_scores一起返回。前面“外部票据、逐案例门禁与日志锚”已经示范可信成绩与产物摘要绑定，本节沿用这个合同，只补稿件重评。源reviser原位改同对象、未知edit或坏target可静默no-op，trace的suggestions_applied常直接等于建议条数；平台停止时甚至未执行reviser却仍有计划数。需要snapshot／真实diff，不能靠Protocol注解声称互不修改状态。

逐维与逐主张回归要独立检查。例如五维旧分都为6，改稿后变为(9,9,4,9,9)，均值从6到8，却把evidence降低2。平均分上升不能补偿证据倒退；设事先确定的维度下限／容差，超过允许回退就拒绝候选，保留前一已验证版本和差异以便归因。不同任务可允许小幅噪声容差，但不能在看到失败后改容差放行。若所有版本都不合格，明确返回未达标，不能把“最好”改称合格。

### 达标、平台和预算是不同终态

五维目标为每项 $s_d\ge\tau_d$，统一阈值8只是课程配置。目标满足时记录 `verified/target`；平台只表示按当前策略继续修订收益较小，记录 `stopped/plateau`；预算耗尽为 `stopped/budget`；输入或评价故障为error/hold；严重回归为rejected并回滚。暂停接纳与允许继续修改的条件另写清。稿件达到这套量表也只证明相应检查条件，不自动证明真实科学结论正确或允许发布。

设第r轮均值 $m_r=\frac15\sum_d s_{r,d}$。源plateau_window=2，至少看3个评分点，对最近两段差 $m_r-m_{r-1}$、$m_{r-1}-m_{r-2}$ 均不超过epsilon（默认0.1）就停；比较实际为 `<=`，并非只处理正增益。下降也可满足它，NaN若未拒绝也会污染判断，因此平台前应检查向量有效性和独立回退门禁；“变化小”策略可另明确使用绝对差或非负增益。两段低增益是停止策略，不证明全局再无进展。固定输入的确定性评分没有随机噪声，修订改变输入导致分数变化不应叫确定性critic本身有噪声；真实人评／模型评的随机性则需校准与重复观察。

源检查顺序是target→plateau→预算退出；target和plateau在reviser之前检查。它将target与plateau都命名 `converged`，外部必须读reason并单独算goal_met。一般预算路径最后一轮先改稿再返回**修改前**的分数，造成paper与final_scores错位；可在预算前阻止新的未评改写，或为必要重评保留额度，否则返回新稿“尚未评估”及旧分所属hash。轮数上限不能限制一个critic永远挂起，critic/reviser还需deadline、费用和错误出口；源固定建议阈值8与可配置target9/10也可能脱节而提前无建议。

### 完整离线例：把评分绑定到修订稿

下面程序于2026-10-12用标准库在CPU实际执行。它注入合成五维分数，检查版本绑定、真实diff/no-op、无重评时hold、非法向量、协议变化、逐维回退与终态优先级。Fraction让小数平台算例精确；本例零回退容差仅用于明确负例，不当真实评分噪声政策。评价器由同进程测试驱动模拟，构造器和消费端均核稿件版本、非空正文、64位摘要、协议、轮次及五项有限范围向量；手工构造的非法评分也必须拒绝。类型与范围检查不能替代签名／独立权限服务，本例也没有真正理解稿件、执行critic模型或完整异步循环。前面的外部票据与case检查程序继续作为该信任边界的主例，不再复制其实现。

```python
from dataclasses import dataclass
from fractions import Fraction as F
import hashlib
import math
import re

DIM = ('clarity', 'novelty', 'evidence', 'methodology', 'related_work')
PROTOCOL = 'synthetic-rubric-v1'

@dataclass(frozen=True)
class Draft:
    revision: int
    text: str

    def __post_init__(self):
        if type(self.revision) is not int or self.revision < 1:
            raise ValueError('稿件版本为非bool正整数')
        if type(self.text) is not str or not self.text.strip():
            raise ValueError('稿件正文为非空字符串')

    def digest(self):
        self.__post_init__()
        return hashlib.sha256(f'{self.revision}:{self.text}'.encode()).hexdigest()

@dataclass(frozen=True)
class Evaluation:
    artifact: str
    protocol: str
    round: int
    scores: tuple

    def __post_init__(self):
        self.validate()

    def validate(self):
        if type(self.artifact) is not str or re.fullmatch(r'[0-9a-fA-F]{64}', self.artifact) is None:
            raise ValueError('评分必须绑定64位十六进制产物摘要')
        if type(self.protocol) is not str or not self.protocol.strip():
            raise ValueError('评价协议为非空字符串')
        if type(self.round) is not int or self.round < 1:
            raise ValueError('评分轮次为非bool正整数')
        if (type(self.scores) is not tuple or len(self.scores) != len(DIM)
                or any(type(v) is not F or not 0 <= v <= 10 for v in self.scores)):
            raise ValueError('消费评分为恰好五项的Fraction元组，各项在0到10')

    def mean(self):
        self.validate()
        return sum(self.scores, F(0)) / len(DIM)

def fixture_score(draft, values, round_):
    # 本例驱动充当可信评价器；数字是注入的合成向量，不是文本质量评分。
    if type(draft) is not Draft:
        raise ValueError('评分输入为Draft')
    if type(round_) is not int or round_ < 1:
        raise ValueError('评分轮次为正整数')
    if type(values) is not dict or set(values) != set(DIM):
        raise ValueError('评分维度必须完整且唯一')
    # 先检查范围再转换做有限性判断，10**400会明确拒绝而不会float溢出。
    if any(type(v) not in (int, float) or not 0 <= v <= 10 or not math.isfinite(v)
           for v in values.values()):
        raise ValueError('分数为有限0到10的数，不能用bool')
    scores = tuple(F(str(values[d])) for d in DIM)
    return Evaluation(draft.digest(), PROTOCOL, round_, scores)

def revise(draft, text):
    if type(draft) is not Draft:
        raise ValueError('改写输入为Draft')
    draft.__post_init__()
    if type(text) is not str or not text.strip():
        raise ValueError('教学改写只接受非空字符串')
    changed = text != draft.text
    new = Draft(draft.revision + 1, text) if changed else draft
    return new, {'before': draft.digest(), 'after': new.digest(),
                 'applied': int(changed)}

def decide(draft, history, round_cap, target=F(8), epsilon=F(1, 10), window=2):
    if type(draft) is not Draft or type(history) is not list:
        raise ValueError('消费输入为Draft与评分列表')
    draft.__post_init__()
    for evaluation in history:
        if type(evaluation) is not Evaluation:
            raise ValueError('评分记录类型错误')
        evaluation.validate()  # 消费端也检查，不只依赖fixture_score或构造器。
    if type(round_cap) is not int or round_cap < 1 or type(window) is not int or window < 1:
        raise ValueError('轮次上限与窗口为正整数')
    if type(target) is not F or not 0 <= target <= 10 or type(epsilon) is not F or epsilon < 0:
        raise ValueError('目标与平台容差必须合法')
    if not history or history[-1].artifact != draft.digest():
        return 'hold', '当前稿件尚未重评'
    if any(e.protocol != PROTOCOL for e in history):
        return 'hold', '评价协议不可比'
    if any(a.round >= b.round for a, b in zip(history, history[1:])):
        return 'hold', '评分轮次必须递增'
    current = history[-1]
    # 逐维回退是独立门禁，不能被mean或target覆盖。此例容差为零。
    if len(history) > 1 and any(b < a for a, b in zip(history[-2].scores, current.scores)):
        return 'rejected', '维度回退，保留前一版本'
    if all(v >= target for v in current.scores):
        return 'verified', 'target'
    if len(history) >= window + 1:
        recent = history[-(window + 1):]
        if all(abs(b.mean() - a.mean()) <= epsilon for a, b in zip(recent, recent[1:])):
            return 'stopped', 'plateau'
    if current.round >= round_cap:
        return 'stopped', 'budget'
    return 'continue', '需要有限修订'

d1 = Draft(1, '有待复核的合成稿件')
e1 = fixture_score(d1, dict.fromkeys(DIM, 6.0), 1)
d2, diff = revise(d1, '修订后的合成稿件')
assert diff['applied'] == 1 and diff['before'] == d1.digest()
old_snapshot = (d1.revision, d1.text, d1.digest(), e1)
assert decide(d2, [e1], 2)[0] == 'hold'  # 修订后旧分不能当final_score。
regress = dict.fromkeys(DIM, 9.0); regress['evidence'] = 4.0
e2 = fixture_score(d2, regress, 2)
assert e2.mean() > e1.mean()
assert decide(d2, [e1, e2], 2)[0] == 'rejected'
assert (d1.revision, d1.text, d1.digest(), e1) == old_snapshot
rescored = fixture_score(d2, dict.fromkeys(DIM, 6.0), 2)
assert rescored.artifact == d2.digest() and rescored.artifact != e1.artifact
assert decide(d2, [e1, rescored], 2) == ('stopped', 'budget')
good = fixture_score(d2, dict.fromkeys(DIM, 8.0), 2)
assert decide(d2, [e1, good], 2) == ('verified', 'target')
assert d1.text == '有待复核的合成稿件'  # 被拒稿仍可回滚到不可变旧对象。
same, no_op = revise(d2, d2.text)
assert same is d2 and no_op['applied'] == 0 and no_op['before'] == no_op['after']
for invalid in ({'clarity': 8}, {**dict.fromkeys(DIM, 8), 'extra': 8},
                {**dict.fromkeys(DIM, 8), 'evidence': float('nan')},
                {**dict.fromkeys(DIM, 8), 'evidence': 10**400},
                {**dict.fromkeys(DIM, 8), 'evidence': True}):
    try:
        fixture_score(d2, invalid, 2)
    except ValueError:
        pass
    else:
        raise AssertionError('非法向量未拒绝')
assert decide(d2, [e1, Evaluation(d2.digest(), 'other-rubric', 2, good.scores)], 2)[0] == 'hold'

def rejected(call):
    try:
        call()
    except ValueError:
        return
    raise AssertionError('非法合同没有明确ValueError')

for revision in (True, 0, -1, 1.0):
    rejected(lambda: Draft(revision, '稿件'))
for text in ('', ' ', None):
    rejected(lambda: Draft(1, text))
    rejected(lambda: revise(d2, text))
for round_ in (True, 0, -1, 1.0):
    rejected(lambda: fixture_score(d2, dict.fromkeys(DIM, 8), round_))
    rejected(lambda: Evaluation(d2.digest(), PROTOCOL, round_, good.scores))
for artifact, protocol, scores in (
    ('bad-hash', PROTOCOL, good.scores), (d2.digest(), ' ', good.scores),
    (d2.digest(), PROTOCOL, (F(20),) * 5),
    (d2.digest(), PROTOCOL, [F(8)] * 5),
    (d2.digest(), PROTOCOL, (F(8),) * 4),
    (d2.digest(), PROTOCOL, (float('nan'),) * 5),
    (d2.digest(), PROTOCOL, (True,) * 5)):
    rejected(lambda: Evaluation(artifact, protocol, 2, scores))
# 模拟绕过构造器、破坏frozen对象；消费端仍须拒绝，不允许手工20分达标。
tampered = Evaluation(d2.digest(), PROTOCOL, 2, good.scores)
object.__setattr__(tampered, 'scores', (F(20),) * 5)
rejected(lambda: decide(d2, [tampered], 2))
assert (d1.revision, d1.text, d1.digest(), e1) == old_snapshot
assert (d2.revision, d2.text) == (2, '修订后的合成稿件')

# 固定报告中的后3轮向量；这是独立合成核对，不调用来源critic。
vectors = ((6.21, 9, 9, 9, 9), (6.62, 9, 9, 9, 9), (7.03, 9, 9, 9, 9))
history = []
for round_, row in enumerate(vectors, 3):
    current = Draft(round_, f'合成稿件r{round_}')
    history.append(fixture_score(current, dict(zip(DIM, row)), round_))
assert decide(current, history, 6) == ('stopped', 'plateau')
assert history[-1].scores[0] < 8
assert [float(e.mean()) for e in history] == [8.442, 8.524, 8.606]
budget = fixture_score(d2, dict.fromkeys(DIM, 7), 2)
assert decide(d2, [e1, budget], 2) == ('stopped', 'budget')
target_history = [fixture_score(d2, dict.fromkeys(DIM, 8), i) for i in (1, 2, 3)]
assert decide(d2, target_history, 3) == ('verified', 'target')
print('版本绑定/修订重评、真实diff/no-op、非法向量/协议拒绝、均值掩盖回退均核对通过')
print('构造与消费边界：bool版本/轮次、手工20分/错tuple/NaN/巨大整数均拒；旧稿和no-op状态不变')
print('合成mean=8.442/8.524/8.606；r5 stopped/plateau，clarity=7.03<8；target优先于平台与预算')
print('仅标准库CPU合同例；未评分真实论文、未执行来源critic或实验')
```

### 原critic的评分、图示与扩展实践

源deterministic_score用平均正文长度计算clarity，用originality_tag给novelty，用figure_refs/cites数量给evidence，用非空Method／Related Work段落给其余两维；reviser追加x、换标签、加占位引用／图号。这些合成信号能测试循环接口，增加字数或自称high无法证明清晰、新颖与证据质量。source主流程是critic→检查target/plateau→若继续才reviser，与sequenceDiagram先revision再convergence的顺序不同；四个Mermaid是结构和控制意图，无课内SVG，不能当版本隔离、真正diff或达标证据。`chCritic`动态图五维上升轨迹全预设，不执行向量评分和回归门禁。

11个source测试方法只静读，核维度键/范围、标签影响、建议、调优稿目标、平台、预算与trace；stuck例断言plateau或budget，不能据文案认定一定五轮budget，也不能仅因程序停了归因“critic有bug”。需要核目标可达性、证据缺失、reviser是否执行、无效建议与阈值不一致。异常、原位历史、最后预算旧评分、逐维退步及真实评价可靠性不在这些断言的保证内。

原55没有独立编号练习；Going further有两项，保留其开放评价方式。第一，维度权重可表达任务优先级，但加权均值只能在已过证据、方法等硬条件的候选中排序，不能用新颖权重抵偿证据不足或直接取代逐维目标。第二，paired critic让另一评价器裁决建议，需给它独立依据，测误接受／误拒绝、两者相关错误、建议可执行性与额外费用；第二意见不是自动可靠，也尚未运行真实双critic。

### 六道原测验的中文问题与解释

1. **55.Q1：为什么按五个固定维度评分，而不只返回自由文字段落？** 原D。向量提供可比较字段，便于发现逐维回退；自由文字也可核查，向量不自动有真值。源码只用mean判断平台，并未实现题意所暗示的全部回归门禁。
2. **55.Q2：每轮结束按什么顺序检查停止条件？** 原D，target→plateau→budget。先确定五维达标，再检查低收益停止，最后预算；源码reviser的最后预算行为仍需修复。顺序使同轮多条件结果稳定，不使平台成为学术合格。
3. **55.Q3：为什么平台观察两段连续小变化，而非一段？** 原B的理由是避免单轮变化误停。必要更正：确定性评分在固定稿件上没有随机噪声，修改顺序／输入变化才影响分数；两段只能形成自设停止政策，不证明稿件真的再无改进。
4. **55.Q4：每轮reviser接收什么输入？** 原D，paper与Suggestion记录列表。每条记录说明dimension、目标section与edit，reviser不直接收评分；接口可替换，但需实际diff、版本与no-op说明，不能借结构声称没有共享可变状态。
5. **55.Q5：trace逐轮包含什么？** 原D，round、score vector、mean、suggestions_applied和verdict。它能支持分数轨迹与诊断；源码applied常是计划建议条数，未执行或no-op时仍可能误记，需改为真实回执并绑定稿件版本。
6. **55.Q6：critic持续提建议但所有评分都没有提高，会产生什么终态？** 原C，plateau或budget。有限循环会结束，但源plateau也叫converged，不能说它“从不会默默成功”；外部检查reason与五维目标。保留不合格状态和原因，再诊断critic、reviser、目标或证据问题，不能凭这一轨迹唯一归因。
