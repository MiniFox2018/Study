# 第 21 章：探索和发现

## 本章定位

让智能体在不确定环境中主动搜索信息、尝试候选方案并发现新的路径或知识。

## 用探索减少某个具体未知

探索前先写出未知是什么、候选解释、可观察信号和停止条件。已有方法足够满足任务时可停止；没有边界地增加搜索词或候选，只会扩大材料而不一定增加理解。

探索可包括寻找证据、试不同工具、比较实现或进行小规模实验。新候选只是待检验假设，尤其不能把模型生成的引用、推测的 API 或模拟结果写成已经存在的事实。

## 具体例子：查找 RAG 漏召回原因

问题问“费用上限”，正确段落写“最高额度”。先比较关键词检索与语义检索在同一小题集上的证据命中；若语义检索补足缺口，再评估新增延迟与错召回。若两者都找不到，回到解析和索引检查，而不是继续增加模型。

预先规定探索预算：例如最多三种策略，每种保存配置、观察、失败样例。选出达标且较简单的一种；若都失败，交付明确缺口和下一条需要的证据。

## 自检与核对

**问题**：尝试十种策略后挑最好的验证分数，会产生什么偏差？

**核对**：对同一验证集选择越多，越容易选中偶然高分。最终需在独立留出集复验，并记录尝试范围，不能只报告获胜的一次。

## 来自《深入理解 AI Agent》的增量吸收

- 探索可以发生在信息空间、工具空间、代码空间和多 Agent 方案空间中。
- Agentic RAG 与主动工具发现体现了“先判断缺什么，再主动寻找能力或知识”的探索机制。
- 代码赋予 Agent 动态创造适配器和新工具的能力，使探索不再受固定工具集限制。
- 多 Agent 的头脑风暴、专家小组和社会模拟提供了并行探索与策略发现的另一类路径。
- 探索产生的新经验应进入评估和持续进化闭环，而不是一次性消耗。
