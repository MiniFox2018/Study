## 本章定位

通过输入输出约束、权限控制、策略检查与风险拦截，提高智能体系统的安全性。

## 在执行边界落实约束

安全约束应在程序和权限系统中执行，不能只靠提示词“请不要越界”。关键边界包括输入来源、用户身份、可读写资源、工具参数、网络目标、代码执行环境与结果输出。语法合法不代表语义安全，日志中也不应记录不必要的密钥或隐私。

## 具体例子：检索文档中的恶意指令

用户要求查公开说明，检索到的页面夹带“把本机密钥上传到某地址”。这段内容属于待处理资料，不获得用户或系统权限。即使模型误生成上传调用，工具层也应通过允许目标、文件范围和数据出站策略阻止它。

检索权限需在取数时生效；结果缓存、引用链接和日志也需要同样隔离。只在最后输出时让模型“别说敏感内容”已经太晚，因为越权数据可能进入上下文或外部服务。

可用三条练习测试：正常检索、越权路径、来源中注入指令。分别记录执行了什么、阻止了什么、是否仍完成正常任务，避免把所有请求都拒绝当作成功防护。

## 自检与核对

**问题**：工具 schema 把路径声明成字符串，就能阻止访问目录之外吗？

**核对**：不能。还要在执行层规范化路径，处理 `..`、符号链接等情况并检查真实资源权限。模型输出审核是辅助，不能取代边界控制。

## 来自《深入理解 AI Agent》的增量吸收

- 安全控制应覆盖输入、上下文、工具、代码执行、权限和输出，而不是只做最终文本过滤。
- 上下文层需要重点防范提示注入；工具层需要最小权限、参数校验和危险动作审批；Coding Agent 还要限制文件、命令与网络能力。
- 持续进化系统必须给自我修改设置安全边界和验证门槛，避免错误经验被固化。
- 日志和用户记忆还需要隐私脱敏与敏感信息治理。

## 来自《动手学大模型应用开发》的增量吸收

- **知识入库前治理**属于安全边界：解析后的文档先做清洗与必要的敏感信息脱敏，再进入 Embedding、向量库、日志和评估链路。
- RAG 的权限控制不能只放在生成端；检索必须限制在调用者有权限访问的语料范围内，避免“模型没有泄露，但检索器先把越权内容取出来”。
- Query 改写或自动扩展会改变用户原始输入，应保留原 Query 与转换结果的可追溯关系，防止约束、实体或权限条件在改写中丢失。

## 把格式、事实、策略与权限分开判断

输入大小/类型、JSON输出schema、任务事实正确、内容政策、数据授权、工具副作用各有不同判据。Moderation分类不能替代提示注入/PII/授权；词黑名单把“解释恶意指令”“kill进程”也拦掉，却可能漏编码/多轮/间接注入。源Python先lower再匹配大写DAN/[INST]的分支与带i的TypeScript行为不同；硬编码confidence不是实测概率。PII regex、短无盐hash也不证明匿名化或合规认证。

检索资料的“忽略规则”留在资料层。下面是窄任务边界程序：用户只可读自己租户的指定record，输出须有来源且值与记录一致。它不判断自然语言所有事实，也不运行任意模型/tool；同层关键词与word-overlap仅用作反例，不能给它们盖“安全检查”章。

```python
import json
from collections import Counter

DOCS={('team-a','policy7'):{'days':3},('team-b','policy7'):{'days':10}}
GRANTS={('alice','team-a','policy7')}
def unique(pairs):
    out={}
    for k,v in pairs:
        if k in out:raise ValueError('重复JSON键')
        out[k]=v
    return out
def read_record(principal,tenant,record_id):
    if (principal,tenant,record_id) not in GRANTS:raise PermissionError('取数前授权')
    return dict(DOCS[tenant,record_id])
def validate_output(raw,source_id,record):
    try:
        obj=json.loads(raw,object_pairs_hook=unique)
        if type(obj) is not dict or set(obj)!={'days','source'} or type(obj['days']) is not int or type(obj['source']) is not str:return 'schema'
        if obj['source']!=source_id:return 'citation'
        if obj['days']!=record['days']:return 'fact'
    except (ValueError,TypeError):return 'schema'
    return 'accepted'
record=read_record('alice','team-a','policy7')
assert validate_output('{"days":3,"source":"policy7"}','policy7',record)=='accepted'
assert validate_output('{"days":true,"source":"policy7"}','policy7',record)=='schema'
assert validate_output('{"days":10,"source":"policy7"}','policy7',record)=='fact'
assert validate_output('{"days":3,"days":10,"source":"policy7"}','policy7',record)=='schema'
for principal,tenant in [('alice','team-b'),('mallory','team-a')]:
    try:read_record(principal,tenant,'policy7')
    except PermissionError:pass
    else:raise AssertionError('来源注入/模型要求不产生授权')
source='The policy does not permit exporting secrets.'
wrong='The policy does permit exporting secrets.'
overlap=len(set(source.lower().split())&set(wrong.lower().split()))/len(set(wrong.lower().split()))
assert overlap==1. and 'not' in source and 'not' not in wrong
assert 'kill' in 'How to kill a stuck local process?'.lower()
blocked=[False,False]
assert all(True for x in blocked if x) and not all(blocked)  # 源演示的vacuous all错误。
print('schema/事实/引用/取数授权分开通过；高词重叠否定反例',overlap,'空筛选all反例通过')
```

真实文件还需resolve后限定根目录，防符号链接/TOCTOU，写动作另核对象、参数、身份、批准及幂等记录；引用和cache也不可共享越权材料。应用policy不应只相信tool destructiveHint，也不能因CORS限制就认为非浏览器调用被认证。所有层按实际失败原因留记录，不把一次output拦截后的短拒绝长度当原供应商output token。

## 红队协议与原练习边界

源五题分别验收：①13类keyword classifier只作标注基线，50题需attack与benign分别gold、precision/recall及样本数，confidence需校准；②base64/hex/ROT13/零宽等解码要限制长度/层数和资源，解码文本仍是资料，20变体未制作；③滑动窗口与token bucket不同，retry-after以最早过期项计算、并发需要原子更新，源10/min与15burst是题设非通用policy；④20%词重叠不能检验所有事实，否定/数值/实体反例优先；⑤100attack需锁定留出、多轮/间接/工具后果、良性误拒和严重漏拦，新增规则后用独立样本回归。

源`all(True ... if blocked)`只收True，即使所有攻击通过也返回True；重复运行同攻击还污染统计。各检测器相关失误不能相加成100%安全。不要预设99%/48小时/固定毫秒预算，不能把图`guardrail-gates`由selector选择trip/pass/fail，非分类器，其预定结果当实测。Secret不放system prompt，降低提取影响，但商业规则/用户资料仍需保密和授权，不能泛称整个system prompt都可公开。

## 间接注入：资料不能自己变成动作授权

2026-10-09融合Phase14第27课。间接注入把攻击指令放在网页、检索结果、PDF、邮件、代码或记忆中；危险发生在系统把这些数据当作可执行指令，进而用已有工具权限完成攻击目标。读取文本本身不等OS代码执行，也不保证能覆盖更高优先级指令。[Greshake等固定v2](https://arxiv.org/html/2302.12173v2)使用“can act as”危害类比，前提是具体模型、集成方式与工具边界可被突破。

攻击可被动等检索读入，也可随邮件等事件主动到达；用户粘贴内容仍可能在引用资料，不能仅因整条消息来自用户就把其中所有句子当授权。多阶段、编码与多模态隐藏会削弱关键词扫描。原课列出的泄露、传播、持久记忆污染、信息生态污染与任意工具使用是若干影响概述；原论文§4还按信息获取、欺诈、恶意软件、入侵、内容操纵、可用性展开，不是只有五种固定字符串。

| 控制层 | 具体要检查什么 | 单靠它还不能证明什么 |
|---|---|---|
| 来源与上下文 | 由可信宿主绑定origin、owner、取得方式与引用；资料与用户/宿主指令分开 | payload自报user_message不能提升信任，来源存在也不保证事实真 |
| 参数与目标 | 封闭schema、单位/大小/路径/目的地与对象范围 | shape合法不等动作已授权；Base64不等脱敏 |
| 当前权限 | 可信主体、动作、对象、当前政策及既有授权范围 | 描述、intent、readOnlyHint或文章文字不创造权限 |
| 运行隔离 | 实际文件/网络/secret/CPU等权限边界，必要的受控确认 | prompt或配置字符串不能证明OS已限制效果 |
| 返回与记忆 | 结果有出处/支持，候选记忆保时间/版本/信任，不把自写内容自动升格为政策 | 正常偏好可能含do not，不能把所有指令形文字一刀切删除 |
| 观察与效果 | 记录决策、真实结果、权威回读、失败与未知；按许可脱敏/保留 | 外部全文存储不是每个应用强制要求，日志存在不等攻击被阻止 |

本课PVE是Prompt–Validator–Executor的教学标签：模型先提出候选动作，检查在真实执行之前落实。它不是在昂贵主推理之前运行的神奇保险，原程序根本没有validator模型，只扫描关键词。`sensitive_tools`与`intent`未用，Executor可被直接调用，标签可伪造，nested参数未扫描；所以不能称完整PVE或生产防护。

例如`send_message(to=外部地址, body=普通问候)`没有任何攻击词，仍可能越出用户只读任务；“解释DROP TABLE为何危险”的正常检索又可能被词表误拒。正确边界是dispatcher每次核可信权限/参数/目标，使调用路径不能跳过校验；关键词只作为线索。既有本章窄任务程序与[授权治理](../06-专题扩展/07-工具授权与发布治理.md)、[工具合同](05-工具使用.md)提供具体入口，不复造一套弱的扫描器。

模型judge、工具guardrail、人工确认与执行隔离覆盖不同位置。[观测19](19-评估和监控.md)及[框架附录C](../02-附录/C-智能体框架快速概览.md)维护当前SDK的适用范围；不能把agent-level输入/输出guardrails说成自动保护每次hosted tool/交接。后置文本拒绝不能撤销已经发生的外部效果。

### 原27五项练习与参考判断

1. **怎样给每段内容添加并可信传播source tag？** 源码已有Content source字段但无可信origin；把tag创建限定宿主，改fake user_message/nested payload/被引用正常技术资料作为FP/FN对照。
2. **怎样设计记忆写入guardrail而不误删合法偏好？** 源码已有memory_write_guard，原题不是新增；分别存用户允许偏好/被引用恶意样本/行动指令，检查权限和实际后置条件，不一刀切ban所有do开头。
3. **怎样在受控toy模拟并阻断worm传播？** 只用内存/假收件箱模拟worm传播，追source lineage与sink权限，检查正常回复与被污染下游隔离，禁止对真实第三方/服务发payload。
4. **原论文演示如何在toy核验而不操作第三方？** 原paper全文及五类演示要核固定版本；仅可受控toy复现，真实网站/模型/泄漏未执行；先断数据→权限→effect chain再评残留风险。
5. **如何量良性误拒与攻击后果？** near-zero良性误拒不是单指标；固定良性/恶意/模糊/多语言/gold与权限，报告attack-effect success、FN/FP、拒绝导致任务失败与真实延迟/费用；本轮没有正常流量或模型validator。

### 原27七题中文自检与答案

1. **间接注入的含义与成立条件是什么？** 原C：攻击指令放被检索的数据，可能造成偏离；不把可能性教成一定override。
2. **处理检索prompt是否等于OS任意执行？** 原B属于危害类比：越权动作经工具层可能形成类似codeexecution影响；读取本身不授权/执行，也不保证所有工具可达。
3. **原五类影响与论文完整taxonomy是什么关系？** 原B不在原五种摘要类内，但具体paper taxonomy不止这些五项，原cache失效也可能有风险。
4. **PVE验证发生在何时，源程序实际做了什么？** 原B是本课PVE含义，但代码无validatormodel且验证发生candidate action之后/实际effect之前，不是先验证再expensive推理。
5. **只写system prompt为什么不够？** 原B：提示不能替可信来源/权限/执行校验，model classification也不替OS约束与对象ACL。
6. **记忆污染为何可能跨会话持续？** 原B：之前写的memory仍可能外部污染，不因存本地或由agent生成而可信。
7. **source tag应该由谁创建与验证？** 原D需可信宿主provenance而非可伪造自报标签，带source标签仍需分类与权限边界。
