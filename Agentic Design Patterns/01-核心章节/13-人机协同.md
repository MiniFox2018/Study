## 本章定位

在关键节点引入人工确认、反馈、审批或干预，实现可控的人机共同决策。

## 把人工节点放在真正的决策点

人工协同可以解决缺失信息、偏好选择、超出已授权范围的操作和结果验收。只读且范围明确的常规步骤可按既有授权执行；不要把每个中间动作都变成确认请求，导致用户无法分辨重要决定。

审批应绑定具体对象、动作和参数。用户批准版本 A 的计划后，若收件人、金额或内容变为版本 B，就不能沿用含糊的旧批准。等待输入期间保存状态，并继续可独立完成的工作。

## 具体例子：准备一封邮件

助手先读取用户提供的材料、整理草稿、显示收件人/主题/正文。用户只要求“写草稿”时，完成到草稿即可；用户明确授权发送具体邮件后，执行发送并核对结果。草稿润色权限不等于发送权限，发送授权也不等于可任意增加收件人。

人工看见的应是可判断的成品和重要差异，而不是“是否继续”四个字。最终验收记录用户决定与实际执行结果，避免只保留模型的解释。

## 自检与核对

**问题**：用户已经批准一次同一范围的批处理，每条记录是否都要重新确认？

**核对**：通常不需要，除非范围变化、出现新风险或明确规则要求逐项批准。应复用已有授权，并只把异常项交给用户。

## 来自《深入理解 AI Agent》的增量吸收

- 人工介入应被设计成明确的系统节点，而不是发生问题后临时接管：高风险动作审批、歧义澄清、失败升级和结果验收都可触发人工。
- 交互形态从文本扩展到语音、GUI、异步消息和现实世界操作后，人机协同需要同时管理**控制权、时序和反馈渠道**。
- 人类评估与自动评估应互补：人工用于价值判断、边界案例和高风险样本，自动评估用于规模化回归。

## 状态机中的人工输入、断点与恢复

StateGraph的node读state并返回update，edge决定去向；conditional edge不是一个node，源“agent/tools/条件边/回边共四node”计数错误。Reducer定义同key怎样合并，默认替换、operator.add追加与add_messages按message ID追加/更新不同。TypedDict主要是静态约定，运行时仍需校验；并行写未声明可合并字段可触发InvalidUpdateError，不是默默last writer wins。[官方Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api)、[并发更新错误](https://docs.langchain.com/oss/python/langgraph/errors/INVALID_CONCURRENT_GRAPH_UPDATE)于2026-10-07核对。

静态`interrupt_before/after`是node边界的debug断点，按官方以`None`输入继续。动态`interrupt(value)`在node中请求输入，用`Command(resume=...)`在同thread恢复，node从头重新执行，interrupt前代码可能重跑；二者不能混用。[官方interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts)支持的typed response_schema与普通JSON Schema dict有不同校验行为，不能只见schema字段就断言运行时已验。

[Checkpointer](https://docs.langchain.com/oss/python/langgraph/checkpointers)在super-step边界保存完整snapshot，并保存完成task的pending writes用于同step失败恢复；不是任意语句后checkpoint。InMemory保存不跨进程，thread_id需区分租户/用户/会话，访问历史也鉴权；checkpointer短期thread状态与Store跨thread记忆不同。保存checkpoint不等所有外部写已精确一次，time-travel恢复计算状态也不撤销已发邮件或数据库写。

### 可独立运行的暂停、持久恢复与冲突小例

以下是SQLite支持的**自写有限状态机**，不是LangGraph替身或SDK实跑。草稿→等待批准→完成，批准绑定run与草稿版本；本地effect receipt与状态同一数据库事务提交，所以本fixture重试不会重复“发送”。真实邮件无法与本地SQLite共享原子事务，需outbox/供应商幂等与查询回执，不能照此宣称网络exactly-once。

```python
import sqlite3,tempfile,json,hashlib
from pathlib import Path

def fingerprint(text):return hashlib.sha256(text.encode()).hexdigest()
class Flow:
    def __init__(self,path):
        self.db=sqlite3.connect(path)
        self.db.executescript('CREATE TABLE IF NOT EXISTS state(run TEXT PRIMARY KEY,body TEXT);CREATE TABLE IF NOT EXISTS effects(key TEXT PRIMARY KEY,body TEXT);')
    def start(self,run,draft):
        state={'status':'awaiting','draft':draft,'sha':fingerprint(draft),'approved':False}
        with self.db:self.db.execute('INSERT INTO state VALUES (?,?)',(run,json.dumps(state)))
        return state
    def load(self,run):
        row=self.db.execute('SELECT body FROM state WHERE run=?',(run,)).fetchone()
        if row is None:raise ValueError('未知run')
        return json.loads(row[0])
    def resume(self,run,sha,decision):
        if type(decision) is not bool:raise ValueError('明确bool决定')
        with self.db:
            s=self.load(run)
            if s['sha']!=sha:raise ValueError('旧稿批准不可复用')
            if s['status']=='done':return s
            if s['status']!='awaiting':raise ValueError('状态不允许恢复')
            if not decision:s['status']='rejected'
            else:
                key=run+':'+sha
                self.db.execute('INSERT OR IGNORE INTO effects VALUES (?,?)',(key,s['draft']))
                s.update(status='done',approved=True)
            self.db.execute('UPDATE state SET body=? WHERE run=?',(json.dumps(s),run))
        return s
    def close(self):self.db.close()
def merge_by_id(old,new):
    result={m['id']:dict(m) for m in old};order=[m['id'] for m in old]
    for m in new:
        if m['id'] not in result:order.append(m['id'])
        result[m['id']]=dict(m)
    return [result[i] for i in order]
def merge_parallel(updates):
    result={}
    for update in updates:
        for key,value in update.items():
            if key in result:raise ValueError('未声明reducer的并行同key写入')
            result[key]=value
    return result
with tempfile.TemporaryDirectory() as d:
    p=Path(d)/'state.sqlite';f=Flow(p);s=f.start('tenant-a/session-1','草稿A');f.close()
    f=Flow(p);assert f.load('tenant-a/session-1')['status']=='awaiting'
    try:f.resume('tenant-a/session-1',fingerprint('草稿B'),True)
    except ValueError:pass
    else:raise AssertionError('版本变化必须重新确认')
    assert f.resume('tenant-a/session-1',s['sha'],True)['status']=='done'
    assert f.resume('tenant-a/session-1',s['sha'],True)['status']=='done'
    assert f.db.execute('SELECT count(*) FROM effects').fetchone()[0]==1
    s2=f.start('tenant-a/session-2','另一草稿');assert f.resume('tenant-a/session-2',s2['sha'],False)['status']=='rejected';f.close()
msgs=merge_by_id([{'id':'m1','text':'旧'}],[{'id':'m1','text':'新'},{'id':'m2','text':'追加'}]);assert [m['text'] for m in msgs]==['新','追加']
try:merge_parallel([{'plan':['A']},{'plan':['B']}])
except ValueError:pass
else:raise AssertionError('并行冲突不能静默覆盖')
print('SQLite重开恢复/批准版本/本地原子receipt/拒绝分支/message ID更新/并行冲突通过；无LangGraph或真实发送')
```

批准变更tool_call时保留其关联ID与对应ToolMessage，拒绝需合法停止/替换流程；不能追加一句“blocked”后仍路由执行pending旧调用。审阅节点前只做可重放纯计算，把外部副作用置后或以持久task/幂等key保护；循环、Send fanout、subgraph自己的state/namespace与reducer另行定义。保留checkpoint code/config/schema版本，恢复前核迁移，不对任意code顺序变化保证可继续。
