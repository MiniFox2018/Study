# 第 2 章：路由

> 来源：<https://adp.xindoo.xyz/chapters/>  
> 整理语言：中文  
> 整理更新：2026-10-02；含原理、教学例子与自检。示例不是生产部署验收。

## 本章定位

根据输入特征、任务类型或上下文，将请求分配给合适的模型、工具、智能体或工作流。

## 路由器需要决定什么

路由器接收请求，输出一个可执行分支或“无法判断”。可以按确定规则路由，例如文件扩展名；也可让模型分类。规则清晰时用规则，语义含糊时才引入分类模型，并为低置信情况保留澄清或通用处理路径。

路由标签应来自有限集合，记录“选了什么、依据是什么、后续是否成功”。模型自己说“90% 确信”不是经过校准的概率，不应直接拿它决定高风险动作。

## 具体例子：知识库助手

设三条路径：`查文档`、`算数`、`需要澄清`。问题“报销标准是什么”进入检索；“3 份各 28 元共多少”进入计算器；“那个怎么弄”缺指代，应先澄清。请求可能同时需要检索和计算，此时应拆分步骤，而不是硬塞进单一类别。

用一张 12 题小表测试路由：每类 3 道正常题，另放 3 道模糊/混合题。分别数错分、漏分和不必要升级，检查最终任务成功率。换一个更贵的模型若只减少错分却大幅增加成本，仍要看任务预算。

## 自检与核对

**问题**：关键词“删除”出现，是否一定路由到删除工具？

**核对**：不一定，用户可能在问“怎样恢复已删除文件”。应识别意图，并在调用层另外验证授权和参数；路由结果不等于执行许可。

## 来自《深入理解 AI Agent》的增量吸收

- 路由既可发生在**工作流层**（根据任务类型选择固定分支），也可发生在**能力层**（模型、工具、Skill、子 Agent 的动态选择）。
- 工具数量增加后，应采用层次化组织、按需加载和主动工具发现，避免把所有工具定义一次性塞入上下文。
- 路由决策应同时考虑任务适配度、成本、时延、上下文长度和失败回退路径。

## 模型网关：先决定能发送到哪里

工作流路由决定“查文档还是计算”，模型网关决定“这次推理可由哪个具体后端执行”。两者可以组合，不能互相替代。网关输入除了 messages，还包括已认证主体、租户、数据等级、允许地域、所需媒体/工具/schema 能力、输出上限、deadline 与总预算；输出不只是答案，还应有具体 backend/revision、每次 attempt、实际 usage、unknown 状态和选择理由。先修是前文有限标签分类、[工具合同](05-工具使用.md)与[资源感知优化](16-资源感知优化.md)中的预算。

### 硬条件先筛，软目标后排

设候选集合为 B。先求满足条件的 `B_allowed`：能力足够、请求上下文/输出长度可接受、该主体有访问权、处理/日志/子处理方数据位置允许、数据等级可处理。只有在 `B_allowed` 内，才按任务质量、成本、时延、负载或实验桶排序。若集合为空，返回明确的不可服务或澄清结果。地区、隐私与授权不能作为低权重项放入一个加权平均，让低价抵消越界。

例如题设需要 EU 内处理、结构化 JSON 输出和工具调用。后端 A 便宜但仅 US，B 在 EU 却不支持工具，C 在 EU 且具备所有能力。只选 C；C 不可用时，可以停止，不能把 A 称为“备用”然后跨地域发送。日志、网关本身和失败诊断也在数据流向内，不是只检查最后一个模型 URL。

质量是同任务集上的实证条件。分类模型说“复杂”不证明昂贵模型会成功；候选以固定 prompt/data/schema 与 holdout task 比较任务成功、严重错误、时延/费用分布。先识别哪些任务可用便宜候选，再评价错分后果。原图中的“最便宜且足够好”是优化目标，不是该 stub 的实测能力。

alias 如 `smart` 是应用逻辑名。配置还应固定 route revision、具体 model revision、translation/schema 与模板版本；变更 alias 指向也属于系统变更，应回归与回滚，不能用“应用代码没变”免除验收。OpenAI-compatible 说明一部分请求/响应外形，不保证全部角色、工具、媒体、流事件、错误、usage 与行为等价；adapter 要定义支持子集，对不能保真的字段显式拒绝。

### Fallback 的每一跳重新准入

回退链是在当前合法集合中依次尝试，每次重新核能力、当次授权、数据位置与输出合同。前一次允许不代表下一供应商允许；撤权、租户状态、路线配置也可能在等待过程中变化。对于模型已输出的片段，不把换模型的新片段随意拼接成同一次成功；选择缓冲重启、明确的部分结果或失败，取决于产品合同。

| 失败类别 | 原请求是否可原样重试/回退 | 必须记录或先做的判断 |
| --- | --- | --- |
| schema、空输入、未知 alias、能力不支持 | 通常不可原样重试 | 修输入或选择已验证兼容的候选；不把任意 model 字符串当隐式放行 |
| 身份无效、权限不足、地域/隐私不允许 | 不能靠回退绕过 | 保留拒绝；身份刷新/授权变化由独立边界处理 |
| 瞬态网络/5xx、限流 | 满足剩余预算时才可 | 错误分类、Retry-After/backoff、单候选与总 attempts 上限 |
| timeout、取消 | 先区分未 dispatch / in-flight / 远端已完成 | deadline 关闭本地等待不证明远端停止；保留未知计费 |
| 输出格式/证据不合格 | 是否重试由业务策略决定 | 原 usage 照记；不能把拒绝短文本的 token 当原账单 |
| 工具写入效果未知 | 先查 receipt / 幂等状态 | 不重复有副作用调用；转 reconcile_required |
| 全候选失败或无候选 | 明確失败出口 | 返回有界错误与尝试摘要，不无限循环 |

总 deadline 涵盖队列、重试等待与所有尝试。每次发送前看剩余时间，不给每个 backend 都重新获得完整期限。速率限制控制每窗口请求或 token；月度预算控制累计费用；并发限制控制在途请求。三者的单位与资源不同，不能把“每 API key 一个速率阈值”当作可靠的团队账期总账。

### 成本账本要包括失败和未结费用

在价格按每百万 token 计费的简单题设中，第 i 次尝试费用为 `C_i=(input_i×p_in_i + output_i×p_out_i)/1,000,000`。token 是计量数量，p 是货币/百万token，C 才是货币；实际供应商可能另有 cached/reasoning/media/tool/request 计费，不能用此简式覆盖全部合同。

同请求 `C_total=Σ known_C_i`，同时单列 unknown attempts 与未释放预留。例：第一次500输入/0输出，题设价格2/百万，仍产生0.001；第二次500输入/100输出、价格2/4，产生0.0014，已知总计0.0024。若第一次超时且没有 usage，不能写成0；先占住有依据的上界预留，待账单/receipt 对账。源 `PRICES.get(model,(0,0))` 会把未知价格误算免费，应返回 unknown 或拒绝无法计量的路线。

发送前在团队/项目/账期原子预留最大预期费用，实际已知后结算差额；unknown 时保留预留。若无法得到可靠的最大收费边界，就不能保证绝不超支，只能说明软预算/风险缓冲策略。并发多 worker 的 sum+check 再加费存在竞争，需要同一个原子账本。使用 Decimal 或整数最小货币单位避免边界漂移，账期与时区也要固定。

### 精确缓存与语义缓存是两种判断

SHA256 完整请求用于精确缓存，回答的是“请求身份相同吗”；embedding 近邻用于语义候选，回答的是“表示相近吗”。“今天/昨天”“允许/禁止”“100/1000”以及两个租户同名制度都可能相近而答案不同，语义命中需要额外的实体、时间、数值、否定、证据与权限检查，并用任务集测误命中损失。原练习“SHA256 prompt 的 semantic cache”应正名精确缓存。

缓存 key 在路由与证据确定后建立，至少绑定主体/租户与授权版本、route/model revision、模板/实验、完整 messages/采样参数、工具/输出schema、数据和证据身份。hit 当次仍核权限、TTL、候选可用范围和结果合同；不能先按问题命中再考虑授权。完整可运行 LRU/TTL 程序由[推理与服务化](../../LLM%20工程实践/03-推理与服务化.md#15-请求结果缓存相同问题还不够)统一维护，本章下面只用小 cache 验证路由与账本的组合。

### 一个可运行的约束、回退与账本实验

输入是已认证的 tenant/actor、EU/private/JSON 请求与固定候选/结果；费用单位为教学 units，时间为虚拟整数，不是供应商价格或延迟。最大费用 reserve 是本例后端保证的题设上界。输出保留尝试账本、过滤/停止原因、已知费用和未结预留。故障是预设，程序未调用模型、测质量、实现网络取消、分布式账本或通用 adapter。

```python
import copy, hashlib, json
from dataclasses import dataclass
from decimal import Decimal as D

@dataclass(frozen=True)
class Backend:
    name: str; region: str; capabilities: frozenset; privacy: str
    reserve: D = D('.20')
    rates: tuple | None = (D('1'),D('2'))  # units / 1000 tokens，非真实价格

BACKENDS = [Backend('us-cheap','US',frozenset({'json','tools'}),'private'),
            Backend('eu-primary','EU',frozenset({'json','tools'}),'private'),
            Backend('eu-backup','EU',frozenset({'json','tools'}),'private')]
allowed = {'us-cheap','eu-primary','eu-backup'}  # 来自外部当前政策，非用户正文
cache = {}
def eligible(b, req):
    return (b.name in allowed and b.region == req['region'] and
            req['needs'] <= b.capabilities and b.privacy == req['privacy'])
def identity(req):
    data = dict(req, needs=sorted(req['needs']))
    return hashlib.sha256(json.dumps(data,sort_keys=True,separators=(',',':'),allow_nan=False).encode()).hexdigest()
def route(req, outcomes, budget=D('.50'), deadline=10, revoke_after=None):
    if budget < 0 or type(deadline) is not int or deadline <= 0: raise ValueError('预算')
    key = identity(req)
    if key in cache:
        old = copy.deepcopy(cache[key])
        backend = next(b for b in BACKENDS if b.name == old['chosen'])
        if not eligible(backend,req): raise PermissionError('cache hit 当次仍核政策')
        return dict(old,cache_hit=True,ledger=[],known=D(0),held=D(0))
    known=held=D(0); elapsed=0; ledger=[]; rejected=[]; status='all_providers_failed'
    for b in BACKENDS:
        if not eligible(b,req):
            rejected.append((b.name,'constraint')); continue
        # outcome 的 duration 是 fixture 预先可知的虚拟时间，非现实网络预测
        outcome=outcomes[b.name]; duration=outcome['duration']
        if type(duration) is not int or duration <= 0: raise ValueError('时长')
        if elapsed+duration > deadline: status='deadline'; break
        if known+held+b.reserve > budget: status='budget'; break
        elapsed += duration
        usage=outcome.get('usage'); cost=None
        if usage is not None and b.rates is not None:
            if any(type(t) is not int or t < 0 for t in usage) or len(usage)!=2: raise ValueError('usage')
            cost=(D(usage[0])*b.rates[0]+D(usage[1])*b.rates[1])/1000
            if cost > b.reserve: raise ValueError('违反题设最大收费边界')
            known += cost
        else: held += b.reserve
        ledger.append({'backend':b.name,'status':outcome['status'],'cost':cost,
                       'unsettled_reserve':b.reserve if cost is None else D(0)})
        if revoke_after: allowed.difference_update(revoke_after.get(b.name,set()))
        if outcome['status']=='ok':
            if outcome.get('answer') != {'answer':'申请表','evidence':['policy:7']}:
                status='output_rejected'; break
            result={'status':'accepted','chosen':b.name,'answer':copy.deepcopy(outcome['answer']),
                    'known':known,'held':held,'ledger':ledger,'elapsed':elapsed,
                    'rejected':rejected,'cache_hit':False}
            if held==0: cache[key]=copy.deepcopy(result)  # 未结结果不缓存于本例
            return result
        if outcome['status'] not in {'transient','timeout','rate_limited'}:
            status=outcome['status']; break
    return {'status':status,'known':known,'held':held,'ledger':ledger,
            'elapsed':elapsed,'rejected':rejected,'cache_hit':False}

req={'tenant':'t1','actor':'alice','auth_revision':'a1','route_revision':'r1',
     'model_revision':'pool1','template_revision':'p1','data_revision':'d1',
     'tool_revision':'tool1','schema_revision':'s1','evidence':['policy:7'],
     'region':'EU','privacy':'private','needs':frozenset({'json','tools'}),
     'messages':[{'role':'user','content':'请假材料？'}],'temperature':0}
answer={'answer':'申请表','evidence':['policy:7']}
outcomes={'eu-primary':{'status':'transient','duration':2,'usage':(100,0)},
          'eu-backup':{'status':'ok','duration':3,'usage':(100,20),'answer':answer}}
first=route(req,outcomes)
assert first['status']=='accepted' and first['known']==D('.24') and first['held']==0
assert [r['backend'] for r in first['ledger']]==['eu-primary','eu-backup']
assert ('us-cheap','constraint') in first['rejected']
hit=route(req,outcomes); assert hit['cache_hit'] and hit['known']==0
changed=dict(req,auth_revision='a2'); assert identity(changed)!=identity(req)
allowed.remove('eu-backup')
try: route(req,outcomes)
except PermissionError: pass
else: raise AssertionError('hit 不得绕过当前撤权')
allowed.add('eu-backup');cache.clear()
unknown=copy.deepcopy(outcomes); unknown['eu-primary'].pop('usage')
pending=route(req,unknown,budget=D('.35'))
assert pending['status']=='budget' and pending['held']==D('.20') and pending['known']==0
cache.clear(); rev=route(req,outcomes,revoke_after={'eu-primary':{'eu-backup'}})
assert rev['status']=='all_providers_failed' and len(rev['ledger'])==1
allowed.add('eu-backup')
down=copy.deepcopy(outcomes);down['eu-backup']['status']='transient'
assert route(req,down)['status']=='all_providers_failed'
assert route(req,outcomes,deadline=4)['status']=='deadline'
denied=copy.deepcopy(outcomes);denied['eu-primary']['status']='permission_denied'
assert len(route(req,denied)['ledger'])==1
print('硬条件先筛、每hop撤权重核、精确hit、总费',first['known'],
      'unknown保留',pending['held'],'预算/deadline/全失败/权限错误停止通过')
```

本例调用权限以固定 backend 集合表示，实际系统必须由可信身份/政策服务给出 per-tenant、per-actor、per-tool 的决定，不能把 allowed 写死就称 RBAC 完成。缓存全量身份仅用于假设封闭的小请求；生产读取时还核TTL/结果合同，更多字段与并发/持久行为沿用缓存主入口。预知 duration 是为了验证事件模型，现实 in-flight timeout 还需要保留其可能收费与停止状态。

### 网关部署与失败域的选择

自托管可控制政策、数据位置和代理日志，代价是升级、凭据、值班、容量、证书与可用性；托管转移运营责任，同时把数据/元数据/账单边界交给服务方。比较时逐项查所用版本的能力、保留/出站政策、连接方式、可观测性、费用和故障域，不能以“production”宣传词推断合规。备用供应商若仍走同一网关、网络出口或账户，未消除该共同失败域。

一个候选也可以是合法设计：必须满足私有部署或只许可某模型时，应明确停止和恢复，而非强加一个不许可的备用。原 outputs 的“用户指定单模型必须拒绝”“所有链必须多个 provider”是课程模板政策，不是普遍工程规则，更不能改变当前任务选定模型。MCP sampling 的旧整合建议属于旧版本功能路径，当前2026-07-28协议以[MCP主章](10-模型上下文协议-MCP.md)核验，不在新设计中默认启用。

## 原课五项练习的参考答案

1. **主后端故障回退**：原 source 在 OUTAGE 触发 RuntimeError 后尝试第二候选，成本只算最终成功。正确验收同时核允许集合、错误类型、每attempt usage与总账；本例EU主失败仍计0.10，加备用0.14得到0.24 units。它不是实际供应商费用。
2. **SHA256 缓存**：题目应正名精确缓存。重复完整身份命中可省下一次模型请求，hit仍核当前权限；变授权/模型/模板/证据/参数应miss或拒绝。节省以同一任务窗口中原本会发出的真实 attempts计量，不能从本例字典命中推导30%–60%实际节省。
3. **code / summarize 分类**：关键词路由可作为有限任务集基线，补否定/引述/混合任务与低置信出口；固定同case比较错分、任务成功与费用。分类选择后仍过能力与权限过滤，不能把“code”当调用高权限工具许可。本批未运行分类模型。
4. **团队账期预算**：定义账期/货币/粒度，发送前原子reserve，成功和失败按实际usage结算，unknown留hold，重试消耗同一总预算。多worker竞争和账单对账需单独证据；源没有实现真实团队预算，本例只验证单进程总请求预算。
5. **三产品“独有功能”**：不存在无需日期/版本即可确定的唯一答案。可评判提交应给三方官方版本与同一功能定义、配置/限制的证据；未找到不能写“不支持”。本章保留部署/信任/故障域比较方法，未核当前产品排他特性，也未安装或选购网关。
