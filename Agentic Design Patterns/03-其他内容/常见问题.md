# 常见问题

**Agent 与普通模型调用有什么区别？** 普通调用可以只产生一次回答；Agent 系统通常根据观察连续选择动作，并由程序维护状态、权限和停止条件。并非必须有多 Agent 或复杂框架。

**需要先读完 21 个模式吗？** 不需要。先按[导读](../00-导读.md)完成一个小闭环，再带着真实失败学习对应模式。

**RAG 能消除幻觉吗？** 不能。解析、检索、版本、引用和生成任一环节都可能出错，见[RAG](../01-核心章节/14-知识检索-RAG.md)。

**多 Agent 一定更好？** 不一定。独立分工可增加覆盖，但会增加协调成本，且错误可能相关。先有单 Agent 基线再比较。

**一段提示能永久教会模型吗？** 普通上下文不会改变权重；持久记忆、程序更新和训练是不同机制，见[学习和适应](../01-核心章节/09-学习和适应.md)。

**正文例子是已运行成果吗？** 标为教学例子的场景用于解释和自检，不能作为本仓库已有部署或个人能力证明。只有有环境、命令、输入、输出与日期的记录才可标为实际验证。

**读完怎样知道学会了？** 能解释输入输出、手做一个例子、识别反例，并在改变条件后说明方法是否还成立。学习完成状态由自己的练习证据填写。
