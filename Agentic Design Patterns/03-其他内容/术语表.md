# 术语表

本页维护定义；[术语索引](./术语索引.md)负责跳转，[术语对照表](../04-项目信息/术语对照表.md)维护中英文写法。

| 术语 | 本库采用的含义 | 常见误解 |
|---|---|---|
| Agent | 在环境反馈下选择动作的系统，通常由模型、状态与工具编排组成 | 一定是多模型或具有自主意识 |
| Workflow | 明确约定步骤和分支的工作流 | 固定工作流就不能使用 LLM |
| Harness | 承载模型的执行、状态、权限和评测程序 | 只是一个系统提示 |
| Context | 本轮模型实际可见的输入工作集 | 等于全部历史或全部知识 |
| Token | Tokenizer 定义的编码单位 | 永远等于一个汉字或一个词 |
| Tool | 有输入输出契约的可执行能力 | 模型提到工具名即已执行 |
| Memory | 被选择、保存并可检索的历史信息 | 自动改变模型参数 |
| RAG | 先检索相关证据再辅助生成 | 向量库或正确性保证 |
| MCP | 应用连接外部工具与上下文的协议 | 工具安全性认证 |
| A2A | 远端 Agent 能力发现与任务协作协议 | 所有多 Agent 通信的统称 |
| SFT | 在监督样本上继续训练 | 必然比提示或检索更合适 |
| DPO | 用偏好对优化相对参考策略的偏好差值 | 不需要高质量标签 |
| Verifier | 按明确条件验证结果的程序/机制 | 测试过即覆盖全部现实情况 |
| LLM 裁判 | 用语言模型按标准评价输出 | 独立、客观、永不出错 |
| 幂等性 | 重复相同操作具有与一次相同的约定效果 | 任何失败都可以无限重试 |
| 回归集 | 用于检查已有行为是否被新修改破坏的样本 | 永远不受调参影响的测试集 |

更新：2026-10-02；定义是工程语境下的简化入口，边界以各主章节为准。
