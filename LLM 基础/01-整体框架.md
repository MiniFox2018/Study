# 01｜整体框架

## 1. LLM 的基本任务

自回归大语言模型的核心训练目标很简单：

> 给定前面的 Token，预测下一个 Token。

训练时，输入序列与目标序列通常只错开一个位置。例如：

```text
输入：  t1  t2  t3  t4
目标：  t2  t3  t4  t5
```

模型不断学习条件概率：

```text
P(t_next | t_1, t_2, ..., t_current)
```

复杂的语言能力、知识表达和生成行为，建立在这个基本目标之上。

## 2. 从文本到输出的完整数据流

一个 GPT 类模型可以理解为以下流水线：

1. 原始文本被 Tokenizer 切分为 Token；
2. Token 映射为整数 ID；
3. Token ID 映射为连续向量；
4. 加入位置信息；
5. 经过多层 Transformer Block；
6. 每一层进行注意力和前馈变换；
7. 最终输出每个词表位置的 logits；
8. 将 logits 转为下一个 Token 的概率分布；
9. 根据解码策略选出下一个 Token；
10. 将新 Token 加回上下文，重复生成。

## 3. 训练生命周期

从模型能力演进角度，可分为三个主要阶段：

### 3.1 预训练

目标：让模型学习语言结构、模式与一般知识。

数据主要是大规模无标注文本，使用 next-token prediction 训练。

### 3.2 监督微调

目标：把通用模型调整到具体任务或行为。

例如：

- 分类；
- 指令跟随；
- 特定领域表达；
- 特定输出格式。

### 3.3 对齐与偏好优化

目标：使输出更符合人类偏好、规范和任务要求。

可使用偏好数据和 DPO 等方法进一步优化。

## 4. 参数与上下文是两类不同能力来源

需要区分：

- **参数中的知识**：训练后固化在模型权重中；
- **上下文中的信息**：推理时临时提供给模型。

很多工程问题不需要重新训练模型，通过 Prompt、RAG、工具或 Agent 就能解决。

只有当能力需要稳定、反复地写入参数时，才考虑进一步训练。

## 5. 从“从零实现”能学到什么

从零实现小型 GPT 的价值不在于训练出一个生产级模型，而在于理解：

- Tokenizer 为什么影响上下文和成本；
- Attention 为什么能利用上下文；
- 为什么要做 causal mask；
- 为什么 Transformer 要有残差、归一化与 FFN；
- cross-entropy 在训练什么；
- 生成时 temperature、top-k 在改变什么；
- 微调为什么可以只更新部分参数；
- KV cache 为什么能加速生成。

这些概念对理解更大的现代模型仍然成立。

## 6. 不应误解的地方

- 小模型的教学代码不代表生产级训练系统；
- “从零实现”强调可理解性，不代表最佳性能实现；
- 当前主流模型会使用更复杂的注意力、归一化、激活函数、MoE、长上下文等结构；
- 但基础的数据流和训练目标仍然具有长期解释价值。
