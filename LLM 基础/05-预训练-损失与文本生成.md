# 05｜预训练、损失与文本生成

## 1. 预训练目标

自回归 LLM 通过 next-token prediction 学习：

```text
输入上下文 → 下一个 Token
```

模型不是直接学习“答案”，而是在大量文本中不断学习条件概率分布。

## 2. Logits 与概率

模型最后输出 logits。

对 logits 使用 softmax：

```text
logits → probability distribution
```

训练时关心目标 Token 的概率是否足够高。

## 3. Cross-Entropy Loss

交叉熵用于衡量预测分布与真实 Token 之间的差异。

直观上：

- 正确 Token 概率越高 → loss 越低；
- 正确 Token 概率越低 → loss 越高。

训练目标就是最小化平均 loss。

## 4. Perplexity

Perplexity 常由平均交叉熵指数化得到：

```text
PPL = exp(loss)
```

它可理解为模型在每一步面对的“有效不确定候选数”。

越低通常表示语言建模越好，但不能用 PPL 单独代表所有下游能力。

## 5. Train / Validation

训练集 loss 下降并不等于模型真的泛化。

必须同时看 validation loss。

典型过拟合现象：

```text
train loss ↓
val loss ↑
```

小数据教学实验尤其容易出现记忆训练文本。

## 6. 训练循环

基础训练循环包括：

1. 前向传播；
2. 计算 loss；
3. 清空梯度；
4. 反向传播；
5. 参数更新；
6. 定期在验证集评估；
7. 保存模型状态。

## 7. 解码不是训练

训练完成后，生成阶段需要从概率分布里选 Token。

这属于 decoding，而不是重新训练模型。

## 8. Greedy Decoding

每次选择概率最大的 Token。

优点：

- 确定；
- 简单。

缺点：

- 容易重复；
- 多样性低；
- 局部最优不一定带来整体最好序列。

## 9. Temperature

Temperature 对 logits 进行缩放。

直观规律：

- 较低温度 → 分布更尖锐、更确定；
- 较高温度 → 分布更平、更随机。

Temperature 控制的是采样随机性，不是模型知识量。

## 10. Top-k

Top-k 只在概率最高的 k 个 Token 中采样。

作用：

- 剔除低概率长尾 Token；
- 降低异常输出；
- 同时保留一定多样性。

## 11. 模型权重

训练后要保存：

- 模型参数；
- 必要时保存优化器状态；
- 配置与 Tokenizer 信息。

只保存一个权重文件而缺少配置，往往无法可靠复现模型。

## 12. 长期结论

评估一个预训练模型时，应分开看：

- 训练是否稳定；
- 验证 loss；
- 生成行为；
- 下游任务表现；
- 推理成本。

不能用一段“看起来很顺”的生成文本代替系统评估。
