# 05｜预训练、损失与文本生成

## 1. 预训练目标

自回归 LLM 通过 next-token prediction 学习：

```text
输入上下文 → 下一个 Token
```

模型不是直接学习“答案”，而是在大量文本中不断学习条件概率分布。

## 2. Logits 与概率

模型最后输出 logits。

对 logits 使用 softmax：

```text
logits → probability distribution
```

训练时关心目标 Token 的概率是否足够高。

## 3. Cross-Entropy Loss

交叉熵用于衡量预测分布与真实 Token 之间的差异。

直观上：

- 正确 Token 概率越高 → loss 越低；
- 正确 Token 概率越低 → loss 越高。

训练目标就是最小化平均 loss。

## 4. Perplexity

Perplexity 常由平均交叉熵指数化得到：

```text
PPL = exp(按有效目标 Token 平均的负对数似然)  # 使用自然对数时
```

它可理解为模型在每一步面对的“有效不确定候选数”。

在相同测试文本、Tokenizer、预处理、上下文和计分方式下，越低通常表示预测更好。不同 Tokenizer 下的每 Token PPL 不能直接横比；PPL 也不能代表所有下游能力。

## 5. Train / Validation

训练集 loss 下降并不等于模型真的泛化。

必须同时看 validation loss。

典型过拟合现象：

```text
train loss ↓
val loss ↑
```

小数据教学实验尤其容易出现记忆训练文本。

## 6. 训练循环

基础训练循环包括：

1. 前向传播；
2. 计算 loss；
3. 清空梯度；
4. 反向传播；
5. 参数更新；
6. 定期在验证集评估；
7. 保存模型状态。

## 7. 解码不是训练

训练完成后，生成阶段需要从概率分布里选 Token。

这属于 decoding，而不是重新训练模型。

## 8. Greedy Decoding

每次选择概率最大的 Token。

优点：

- 在 logits 相同、并列值处理一致时确定；
- 简单。

缺点：

- 容易重复；
- 多样性低；
- 局部最优不一定带来整体最好序列。

## 9. Temperature

Temperature 对 logits 进行缩放。

直观规律：

- 较低温度 → 分布更尖锐、更确定；
- 较高温度 → 分布更平、更随机。

Temperature 控制的是采样随机性，不是模型知识量。

## 10. Top-k

Top-k 只在概率最高的 k 个 Token 中采样。

作用：

- 剔除低概率长尾 Token；
- 可能减少低概率输出，但不保证事实正确；
- 同时保留一定多样性。

## 11. 模型权重

训练后要保存：

- 模型参数；
- 必要时保存优化器状态；
- 配置与 Tokenizer 信息。

只保存一个权重文件而缺少配置，往往无法可靠复现模型。

## 12. 长期结论

评估一个预训练模型时，应分开看：

- 训练是否稳定；
- 验证 loss；
- 生成行为；
- 下游任务表现；
- 推理成本。

不能用一段“看起来很顺”的生成文本代替系统评估。

## 13. 算得出的损失与采样

两个目标 Token 获得概率 `0.5` 和 `0.25`，平均负对数似然为 `−(ln 0.5 + ln 0.25)/2 ≈ 1.0397`，困惑度为 `exp(1.0397) ≈ 2.828`。Padding 不应进入分母；若框架接收 logits，通常使用数值稳定的 log-softmax/交叉熵实现，避免先 softmax 再取对数造成下溢。

温度采样为 `p_i = softmax(z_i/T)`，其中 `T>0`；`T=0` 通常是接口约定的贪心模式，不应真的除以零。给分布 `[0.6, 0.3, 0.1]`，top-k=2 会去掉最后一项，并重新归一化为 `[2/3, 1/3]`。采样参数改变选择规则，不会验证事实。

**自检**：把所有 logits 加 100，softmax 是否改变？生成时温度为 0，是否保证整个部署重复运行完全一致？

**核对**：加同一常数不改变分布；但后端非确定性、浮点误差和版本变化仍可能改变 logits，因此“贪心”不等于跨环境可复现。

## 14. 温度、预训练与能力的区别

温度改变给定logits的选择分布，不增加权重知识；下一token训练也不等于网页逐句读取或全部事实验证。可核对例子与证据边界见[常见误解](../AI%20算法基础/19-AI常见误解与证据边界.md)。
