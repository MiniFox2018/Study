# 06｜微调、指令跟随与偏好优化

## 1. 微调的本质

这里讨论的自回归语言模型通过预训练学习下一Token条件预测。

微调是在已有权重上用目标更明确的数据继续优化，可以改变行为、任务能力及知识关联。能否准确写入、泛化并保留已有能力，取决于数据和训练过程，不能简单说“只改变风格”或“可靠加入所有事实”。

## 2. 两类典型微调

### 2.1 任务微调

例如分类：

```text
文本 → 模型表示 → 分类头 → 标签
```

可选择：

- 冻结大部分模型；
- 只训练分类头；
- 解冻后几层；
- 全量微调。

可训练参数更多提供更大的优化自由度，但实际表现仍取决于数据、正则化和优化过程，不保证更强；成本和过拟合风险也需评测。

### 2.2 指令微调

训练数据一般组织为：

```text
Instruction
+ Optional Input
→ Desired Response
```

目标是让模型学习“按照指令完成任务”的行为模式。

## 3. 数据格式一致性

指令微调对数据模板非常敏感。

训练和推理的 Prompt 格式应尽量一致，包括：

- 指令边界；
- 输入字段；
- 回答起始位置；
- 特殊 Token；
- 对话角色。

## 4. Padding 与 Loss Mask

不同样本长度不一致时，需要 Padding。

但 Padding Token 不应参与训练损失。

因此通常使用 loss mask 或 ignore index，把无意义位置从 loss 中排除。

进一步还可以只对 Response 部分计算 loss，而忽略 Instruction 部分。

## 5. 数据质量比单纯数据量更重要

指令数据要关注：

- 正确性；
- 覆盖范围；
- 去重；
- 格式稳定；
- 难度分布；
- 是否存在互相矛盾的示例。

低质量合成数据可能把错误稳定写入模型。

## 6. 评估指令模型

不能只看训练 loss。

还要评估：

- 是否遵循指令；
- 是否回答正确；
- 是否遵守格式；
- 是否拒绝不该完成的任务；
- 是否在未见过的任务上泛化。

可使用：

- 规则验证器；
- 标准答案；
- 人工评估；
- LLM-as-a-Judge；
- 任务型 benchmark。

## 7. Preference Tuning

监督微调告诉模型“理想答案是什么”。

偏好优化则提供：

```text
Prompt + preferred answer + rejected answer
```

模型学习哪一种回答更符合目标偏好。

## 8. DPO

Direct Preference Optimization（DPO）绕过显式奖励模型，直接利用偏好对优化策略。

核心思想不是“背一个公式”，而是：

> 提高“相对于参考模型的偏好回答对数概率增益”与“非偏好回答增益”之间的差值。

这是由带 KL 正则的奖励最大化目标推导出的偏好损失，不是硬性的距离约束，也不保证 chosen 的绝对概率必然上升。

它是偏好对齐的一种方法，不代表所有对齐问题都应该使用 DPO。

## 9. 什么时候不该微调

如果目标只是：

- 给模型最新知识；
- 查询私有文档；
- 调用外部系统；
- 动态改变规则；

优先考虑：

- RAG；
- Prompt；
- 工具；
- Agent Workflow。

微调更适合需要稳定改变模型行为或内部能力的场景。

## 10. SFT 与 DPO 的可核对例子

SFT 样本为“把姓名提取成 JSON”，正确回答 `{"姓名":"小林"}`。若只训练回答，用户问题和系统指令仍参与前向计算，但它们对应的目标位置不计入 loss；attention mask 控制能看见哪些位置，loss mask 控制在哪些位置计分，两者不是一回事。

对一个 DPO 偏好对，设策略与参考模型在 chosen 上的对数概率差为 `+0.2`，在 rejected 上为 `−0.1`，则偏好差值为 `0.3`。标准 DPO 损失为 `−log sigmoid(β×0.3)`；取 β=1，约为 `0.5544`。这里用的是整个回答序列条件概率的对数和，参考模型通常固定。增大这个差值会降低该样本损失，但仍需检查其他任务是否退化。

**自检**：chosen 事实错误、只是措辞好看，会怎样？模型没有显式奖励网络，是否意味着 DPO 不需要质量标签？

**核对**：错误偏好会推动错误行为；DPO 仍依赖可靠偏好数据。减少一个训练组件不等于免除评测。

核验依据（2026-10-02）：[DPO 原论文](https://arxiv.org/abs/2305.18290)。这里只讨论标准 DPO，不将后续变体混为同一损失。

## 11. 知识更新与微调的条件

变化频繁、需要权限和出处的知识常先考虑检索；稳定行为和领域能力可按评测考虑微调，两者可以结合。“微调永远不能学新知识”不是原理定律；完整辨析与模型编辑/指令训练证据见[AI误解与边界](../AI%20算法基础/19-AI常见误解与证据边界.md)。
