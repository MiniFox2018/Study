# 01｜电脑、文件与显示基础

## 1. 先建立一张“电脑在做什么”的图

一台个人电脑可以先粗略理解成：

输入设备 → CPU / GPU 计算 → RAM 临时承载 → SSD/HDD 长期存储 → 显示器/扬声器等输出

操作系统位于应用和硬件之间，负责进程、文件、设备、权限和界面。应用一般不直接操纵硬件，而是调用操作系统提供的接口。

这张图很重要，因为以后排障时，“慢”“卡”“打不开”“没空间”“画面掉帧”分别可能来自不同层。

## 2. bit、Byte 与容量单位

最小的二进制信息单位是 bit，取值 0 或 1。8 bit 通常组成 1 Byte（字节）。

需要区分两套容量前缀：

- 十进制：1 kB = 1000 B，1 MB = 1000² B，1 GB = 1000³ B；
- 二进制：1 KiB = 1024 B，1 MiB = 1024² B，1 GiB = 1024³ B。

硬盘厂商通常按十进制标称容量；有些操作系统界面历史上按 1024 换算却仍显示 GB 标签，所以“1 TB 硬盘为什么系统里看起来更小”首先是单位口径问题，不代表容量凭空丢失。

网络带宽常用 bit/s，而文件大小常用 Byte；100 Mb/s 理论上不是 100 MB/s，而约为 12.5 MB/s，实际还要扣协议开销。

## 3. 重启为什么不总等于“关机再开机”

在启用 Fast Startup 等机制的 Windows 上，关机可能保存部分系统会话状态，而“重启”通常会更完整地重新加载系统内核与驱动。

因此排查驱动、更新、系统状态问题时，明确选择“重启”比“关机后再按电源键”更可靠。

“睡眠”“休眠”“关机”“重启”是不同的电源状态，不应混为一谈。

## 4. F1～F12 与 Fn 键

笔记本常把 F1～F12 与音量、亮度、飞行模式等硬件功能复用。到底直接按 F5 得到“F5”还是亮度键，取决于厂商设置和 Fn Lock。

遇到快捷键无效时，应先检查：

- 是否需要同时按 Fn；
- 是否启用了 Fn Lock；
- BIOS/厂商控制软件是否改变了功能键模式。

## 5. Settings 与 Control Panel

Windows 的现代设置正在逐步集中到 Settings，但部分传统管理项仍可能通过 Control Panel、MMC 或专用系统工具呈现。

长期原则：优先使用系统公开的现代设置入口；只有在功能尚未迁移或需要高级管理时，再进入传统工具。不要把某一版本的菜单路径当成永久知识。

## 6. CPU：执行指令，不等于“核越多就一定越快”

CPU 的核心职责是取指令、译码、执行并读写数据。

看 CPU 时至少区分：

- 架构与指令集，例如 x86-64、Arm；
- 核心数与线程数，影响可并行工作量；
- 单核性能，很多交互和串行任务仍受它影响；
- 频率、缓存、功耗与散热，共同决定持续性能；
- 工作负载，不同软件对核心数、缓存、向量指令的利用完全不同。

因此“i7 一定比 i5 快”“八核一定比四核快”都不是可脱离代际、功耗和任务成立的结论。

## 7. RAM：工作台，不是长期仓库

RAM 用来保存正在运行程序所需的代码与数据。它速度快、容量相对有限、断电后内容消失。

内存不足时，操作系统会频繁回收、换页或压缩内存，体感可能表现为切应用变慢、大量磁盘活动、浏览器标签重载、大型程序卡顿甚至退出。

容量是否够用取决于任务集合，不应把 PDF 中 2024 年的 8/16/32 GB 建议当作永久购买标准。

## 8. SSD/HDD：长期存储

长期文件、应用、系统本身都存储在非易失介质上。

- SSD 随机访问延迟低，日常启动程序和系统响应通常明显更快；
- HDD 机械结构导致随机访问慢，但大容量冷数据场景仍可能有成本优势；
- 二者都不是永久档案介质，都需要备份；
- “盘符”不是物理硬盘本身，一个物理盘可以有多个分区。

## 9. GPU：并行处理器

GPU 最初围绕图形流水线发展，但大量并行计算单元也适合矩阵、向量和张量运算，因此广泛用于科学计算与 AI。

需要区分集成 GPU、独立 GPU、显存容量和实际算力。显存大不等于 GPU 一定快，GPU 快也不等于任何应用都会受益。

## 10. 文件、文件名与扩展名

文件是持久化数据的基本组织形式。Windows 常用扩展名帮助判断类型和默认打开方式，例如 .txt、.pdf、.jpg、.zip、.exe。

扩展名只是文件名的一部分，不是可靠的安全认证。恶意文件可以伪装名称，因此应让系统显示扩展名，并结合来源、数字签名和安全扫描判断。

把 image.jpg 手工改名为 image.png 并不会把 JPEG 数据真正转换成 PNG。

## 11. 文件夹、路径和当前位置

路径回答“文件在哪里”。

例如 C:\Users\Alice\Documents\report.pdf 包含盘符、层级目录和文件名。

需要理解：

- 绝对路径从根位置完整描述；
- 相对路径相对于当前工作目录；
- 路径中的空格和特殊字符有时需要引号；
- 同名文件可以存在于不同目录；
- “桌面上的文件”实际也有磁盘路径。

这与之后的命令行、编程、Git、Python 环境和 Docker 路径直接相关。

## 12. 可执行文件、快捷方式和文件关联

.exe 等可执行文件包含可由操作系统装载的程序代码与相关数据。

Windows 的 .lnk 快捷方式只是“指向目标”的元数据。删除快捷方式通常不会删除程序本体。

文件关联决定双击某种扩展名时用哪个应用打开。改变默认应用不改变文件内容。

因此：

- 删除桌面图标 ≠ 卸载软件；
- 改默认打开方式 ≠ 转换文件格式；
- 快捷方式损坏 ≠ 原文件一定丢失。

## 13. 压缩文件的基本观念

压缩包通常同时解决两件事：将很多文件封装为一个归档，以及利用压缩算法减少冗余。

要区分无损压缩和有损压缩，也要知道归档格式与压缩算法并不总是一回事。

不要在压缩包内部直接长期编辑重要文件；先解压到明确目录，再工作，再决定是否重新打包。

## 14. 文件组织：重点不是“分几个盘”，而是可找到、可备份

一个实用文件系统应满足：

- 路径有意义；
- 临时下载与长期资料分开；
- 项目资料按项目归档；
- 大文件知道放在哪里；
- 备份范围清晰；
- 不把唯一副本放在 Downloads 或聊天缓存目录；
- 不依赖“桌面越乱越方便”。

可以按“领域 / 项目 / 年月 / 状态”组合分类，但不要创建过深层级。

建议至少定期清理 Downloads、聊天软件接收目录、桌面、临时导出文件、安装包和大体积重复文件。

## 15. 常用快捷键应该按“动作”记

不必死背全部快捷键，优先掌握复制、剪切、粘贴、撤销、全选、查找、切换窗口、关闭窗口、系统搜索、截图、锁屏和浏览器标签操作。

快捷键的价值不是炫技，而是把高频动作变成稳定肌肉记忆。

## 16. 显示器：五个经常被混淆的指标

### 分辨率与 PPI

分辨率是横向像素数 × 纵向像素数。PPI 是每英寸像素数：

PPI = sqrt(W² + H²) / D

W、H 是像素宽高，D 是屏幕对角线英寸数。

例如 27 英寸 2560×1440 屏幕的 PPI 约为 109。

### 色域

色域描述设备能覆盖的颜色范围，常见参考包括 sRGB、Display P3、Adobe RGB。“100% sRGB”不能与“100% P3”当成同一个指标。

### 色准

色准描述显示出来的颜色离目标颜色有多远。常用 Delta E 表示误差，但评价仍取决于测量标准、亮度和校准条件。

### 色深

色深决定每个颜色通道可表示的级数。更高色深有助于减少渐变断层，但内容、系统、接口、GPU 和面板链路都要支持才有意义。

### 刷新率

刷新率单位 Hz，表示屏幕每秒可更新多少次。高刷新率可以改善运动流畅度和交互延迟，但应用帧率、接口带宽和系统设置也必须跟上。

## 17. 面板类型：不要只用“好/坏”排序

常见面板路线各有取舍：

- IPS/LCD：可视角度与色彩表现通常均衡，应用广泛；黑位和对比度通常不如 OLED；
- VA/LCD：常见优势是对比度较高，但不同产品响应速度差异明显；
- TN/LCD：传统优势是响应快、成本低，但色彩和可视角度通常较弱，如今更多见于特定低成本或电竞场景；
- OLED：像素自发光，可实现极高对比度和快速响应，但要考虑烧屏风险、亮度策略、子像素结构和价格；
- Mini-LED 不是独立面板材料，而是一种 LCD 背光方案，通过大量局部调光区改善 HDR 和对比度，但可能出现 blooming。

真正选屏应把分辨率/PPI、色域、色准、色深、刷新率、响应、亮度、HDR、调光方式和使用场景一起看。

## 18. 最小练习

1. 找出自己电脑 CPU、RAM、磁盘和 GPU 的型号/容量，并用一句话解释各自职责。
2. 选一个文件，写出完整路径、主文件名和扩展名。
3. 创建一个快捷方式，删除快捷方式，确认原文件仍存在。
4. 计算当前显示器 PPI，并解释它为什么不能单独决定画质。
5. 把 Downloads 中一批文件按“临时/长期”分类，长期文件移动到明确目录。
