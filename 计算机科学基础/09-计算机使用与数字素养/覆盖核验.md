## 1. 处理原则

这次的“完整吸收”不是把 PDF 逐页复制，而是逐章建立知识去向：

- 长期有效知识进入主知识库；
- 已有更完整主干的内容优先补强或交叉引用；
- 旧 Windows UI、旧软件版本、价格、排行榜、具体注册表 tweak 等高时效内容不固化；
- 原 PDF 不提交仓库，只保留官方重新获取入口与精确版本信息；
- 原作要求衍生作品使用 CC BY-NC-SA 4.0，因此本专题明确继承该许可并保留署名。

## 4. 主动淘汰/降级的内容

以下不是遗漏，而是按 Study 规则主动过滤：

- 2024 年电脑硬件价格；
- 当时内存/硬盘容量的具体购买门槛；
- Office 版本历史的细枝末节；
- IE 和浏览器市场历史；
- 当时软件推荐榜单及具体下载按钮；
- Windows 10/11 某一版本菜单位置；
- Windows 11 恢复旧右键菜单/资源管理器的注册表技巧；
- 旧 OOBE 的断网跳过手段；
- 特定厂商、平台的短期产品描述。

保留这些内容会让主知识库迅速过时，且不会提升核心能力。

## 5. 吸收后的独立学习能力

不打开原 PDF，本专题已经可以用于学习：

电脑构成 → 文件 → 软件 → 办公与网络 → 安全 → 故障排查 → 显示 → 用户与存储 → 编码 → 密码学 → AI → 云与 IoT → 新电脑初始化。
