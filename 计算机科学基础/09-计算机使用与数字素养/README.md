# 计算机使用与数字素养

> 目标：把“会点电脑”提升为“理解电脑在做什么、能自己管理文件和软件、能安全使用网络、遇到问题能排查、知道什么时候该查证”。

## 学完后应该能做什么

你至少应能解释并实际完成这些任务：

- 区分 CPU、RAM、SSD、GPU 的职责，判断“电脑慢”大致可能卡在哪一层；
- 看懂路径、扩展名、可执行文件、快捷方式、压缩包和文件关联；
- 从可信来源安装/卸载软件，不把“删除快捷方式”误当卸载；
- 知道 UAC、管理员权限、更新、恶意软件和钓鱼的基本安全边界；
- 把一个模糊故障整理成可复现的问题，并使用错误信息、日志、搜索、官方文档和 AI 逐步缩小范围；
- 理解 PPI、色域、色准、色深、刷新率分别描述什么；
- 管理用户、权限、C 盘空间，理解符号链接、硬链接和目录联接的差别；
- 解释 UTF-8、Unicode、乱码产生的原因，并知道怎样避免；
- 解释 AES、公钥密码、哈希、数字签名、证书和 HTTPS 各解决什么问题；
- 区分训练与推理、IaaS/PaaS/SaaS，以及物联网设备为什么同时涉及便利、隐私和安全；
- 新电脑到手后按“先确认退换条件 → 外观与规格 → 系统与硬件检查 → 再配置账号和软件”的顺序完成初始化。

## 阅读原则

这套笔记不是 Windows 某个版本的点击教程。按钮位置会改，长期能力不会改。

遇到具体 UI、产品套餐、软件下载地址、云服务功能和当前 Windows 行为时，应查对应厂商的当前官方文档；本专题负责告诉你“要检查什么、为什么检查、结果意味着什么”。
