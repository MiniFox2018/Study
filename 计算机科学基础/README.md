## 定位

这个目录补齐 Study 里此前缺少、又无法自然塞进 C++ 或 AI 算法基础的通用计算机科学底座：

```text
离散数学 / 计算理论
→ 计算机体系结构
→ 操作系统
→ 并发与并行
→ 数据结构与算法
→ 生产级软件工程
→ SIMD / GPU / 异构计算
```

与其他目录分工：

- **C++**：语言本身、标准库、语法与 C++ 工程；
- **计算机科学基础**：跨语言的计算机系统、算法与软件工程原理；
- **AI 算法基础**：数学、机器学习与深度学习；
- **LLM 工程实践**：模型推理、部署和 ML Systems。
