# 计算机科学基础

> 维护原则：跨语言、长期有效、面向实际工程；具体来源见 [来源审计](./来源审计.md)。

## 定位

这个目录补齐 Study 中通用计算机科学与系统工程底座：

```text
离散数学 / 计算理论
→ 计算机体系结构 / 操作系统
→ 并发与并行
→ 数据结构与算法
→ 生产级软件工程
→ SIMD / GPU / 异构计算
→ 容器化 / Docker / Kubernetes
```

与其他目录分工：

- **C++**：语言本身、标准库、语法与 C++ 工程；
- **计算机科学基础**：跨语言的计算机系统、算法、软件工程与基础设施原理；
- **AI 算法基础**：数学、机器学习与深度学习；
- **LLM 工程实践**：模型推理、部署和 ML Systems。

## 使用原则

这里不把某个 IDE、云控制台、安装 UI 或短期工具版本当作永久知识。长期需要掌握的是：抽象、复杂度、内存、并发、接口、测试、构建、部署、隔离、可观测性、安全与性能模型。
