# 01｜离散数学与计算理论

## 1. 为什么它是计算机科学的语言

连续数学描述“量如何变化”，离散数学描述“状态、结构和关系如何组合”。程序、图、逻辑电路、数据库、类型系统和算法都建立在离散对象上。

## 2. 命题逻辑与谓词逻辑

需要掌握：

- 命题、真值、否定、合取、析取、蕴含、等价；
- De Morgan 定律；
- 量词 `∀`、`∃`；
- 否定量词时的转换；
- 逻辑等价与可满足性。

程序中的条件判断、断言、规格说明和形式验证都依赖这套语言。

## 3. 证明方法

核心不是“会写数学证明”，而是建立严谨推理习惯：

- direct proof；
- proof by contradiction；
- contrapositive；
- mathematical induction；
- construction / counterexample。

递归程序与递推式尤其适合用归纳法理解。

## 4. 集合、关系与函数

集合运算：并、交、差、补、笛卡尔积。

关系要区分：

- reflexive；
- symmetric；
- antisymmetric；
- transitive。

等价关系会把集合划分为等价类；偏序关系构成 DAG、依赖图和调度问题的重要基础。

函数需要理解 injection、surjection、bijection，以及复合和逆。

## 5. 组合计数

常用工具：

- permutation；
- combination；
- multinomial；
- pigeonhole principle；
- inclusion-exclusion。

算法复杂度、概率和哈希冲突分析经常需要计数。

## 6. 图论

图 `G=(V,E)` 可以表示网络、依赖、状态空间和关系。

基本对象：

- directed / undirected；
- weighted / unweighted；
- path / cycle；
- connected component；
- tree；
- DAG；
- degree；
- adjacency matrix / list。

图论与 Study 的 GNN 章节衔接，但这里关注算法和结构，不关注神经网络。

## 7. 递推关系

递归算法的成本通常写成 recurrence：

```text
T(n) = aT(n/b) + f(n)
```

需要能够通过展开、递归树或 Master Theorem 判断增长阶。

## 8. 可计算性

计算机并不是“给足时间就能算一切”。

核心概念：

- finite automata；
- Turing machine；
- decidable / undecidable；
- halting problem；
- reduction。

Reduction 的价值是把“新问题难不难”转化为“它至少和某个已知问题一样难”。

## 9. 复杂度类

需要形成边界意识：

- P：多项式时间可解；
- NP：给定答案后可在多项式时间验证；
- NP-hard：至少和所有 NP 问题一样难；
- NP-complete：既在 NP 中又 NP-hard。

工程意义不是背定义，而是识别：

> 什么时候应该寻找精确算法，什么时候应接受近似、启发式或限制问题规模。

## 10. 与后续章节的连接

```text
逻辑 / 集合
→ 数据结构与类型

组合 / 递推
→ 算法复杂度

图论
→ 图算法 / GNN / 分布式系统

可计算性 / 复杂度
→ 认识问题的理论边界
```
