# 程序分析与逆向工程

本专题把程序文件、机器指令、控制流、类型、动态观察和重建验证连成一条学习路线。先修是[体系结构与操作系统](../02-计算机体系结构与操作系统.md)、[数据结构与算法](../04-数据结构与算法.md)中的图，以及基本C/Python阅读能力。

目前按顺序阅读：

1. [二进制布局与装载地址](01-二进制布局与装载地址.md)：通过字段、范围和重定位算例，理解函数字节的位置。
2. [指令、ABI与编译惯用法](02-指令ABI与编译惯用法.md)：手解指令，比较三类调用约定，再推导乘移除法、取余及循环/调用变形。
3. [控制流与中间表示](03-控制流与中间表示.md)：区分扫描与静态可达，学习支配、自然循环、IR、SSA与内存别名。
4. [数据布局与类型恢复](04-数据布局与类型恢复.md)：从访问事实推候选布局，核数组步长、DWARF索引与重定位、C++虚表及工具对照。
5. [静态与动态证据](05-静态与动态证据.md)：绑定目标、问题与环境，学习调试计划/命令映射、三态覆盖、core/trace边界及缓存与摘要的限制。
6. [差分重建与等价边界](06-差分重建与符号执行.md)：用反例设计网格，结合依赖/匹配/重定位，手解符号路径、模型、反例及截断输入集合。
7. [链接装载与无符号分析](07-链接装载与无符号分析.md)：追踪PLT/IAT/stub与修复槽，比较剥离前后元数据，处理函数起点和签名碰撞。
8. [字节码与托管容器](08-字节码与托管容器.md)：识别pyc/class/Wasm/CLI的版本与元数据，手解表引用、分支坐标和变长整数。

9. [AI协作与重建报告评估](09-AI协作与重建报告评估.md)：分开评价候选代码与解释，学习六栏范围、反例、命名预测、工具权限与可比较的成本记录。

10. [实现可审计的二进制检查器](10-实现可审计的二进制检查器.md)：沿六阶段实现格式、区域、符号、链接、起点与报告，区分可检查事实和启发式。

当前十篇的已写部分可独立阅读；三份新增手册知识已分别验收，逆向专题整体与其余项目尚未完成最终验收。

学习时只使用明确允许分析的材料，区分原作者工具输出、本库静态核对和你亲自完成的实践。记住三条判断：能解码不等可达，伪代码可读不等行为正确，有限样例一致不等全输入等价。
