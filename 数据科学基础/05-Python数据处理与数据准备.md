# 05 Python 数据处理与数据准备

## 1. 工具角色

典型 Python 数据栈：

- NumPy：数组与数值计算；
- pandas：表格数据处理；
- Matplotlib：基础可视化；
- Jupyter：交互式分析与实验记录。

工具会变化，但核心操作长期稳定：**加载、检查、变换、聚合、连接、验证、输出。**

## 2. DataFrame 思维

DataFrame 可以理解为带字段名和索引的二维数据表。

常见操作：

```python
df.head()
df.info()
df.describe()
df["col"]
df[["a", "b"]]
df.loc[...]
df.iloc[...]
df.query(...)
df.groupby(...)
df.merge(...)
df.sort_values(...)
```

不要只会“把代码跑通”，要知道每一步对行数、字段、粒度和语义做了什么。

## 3. 数据加载

加载后第一时间检查：

- shape；
- dtypes；
- 前后几行；
- 主键/唯一键；
- 缺失；
- 重复；
- 单位；
- 时间字段；
- 类别值。

这比直接画图更重要。

## 4. 清洗

### 重复
先确定“重复”的业务定义。完全相同行不一定是重复，重复订单号通常更值得关注。

### 类型
常见问题：

- 数字被读成字符串；
- 日期未解析；
- 布尔值有多种表示；
- 类别拼写不一致；
- 单位混用。

### 缺失
先量化缺失模式，再决定删除或插补。

### 异常
先判断是否真实，再决定截断、变换、保留或分组分析。

## 5. 数据变换

常见操作：

- 新字段计算；
- 字符串处理；
- 时间拆分；
- 分桶；
- 标准化；
- 对数变换；
- 类别编码；
- 宽表/长表转换。

变换应写成可重复执行的代码，而不是手工修改表格。

## 6. 聚合与分组

```python
df.groupby("category")["value"].agg(["count", "mean", "median"])
```

分组时始终确认：

- 分组键；
- 每组样本数；
- 是否存在极小组；
- 加权与非加权平均是否不同。

## 7. 合并

合并前检查：

```text
左表粒度
右表粒度
连接键
键唯一性
预期行数变化
```

合并后检查：

- 行数是否符合预期；
- 未匹配比例；
- 是否出现重复扩张。

## 8. 数据准备与建模边界

用于建模时，还要处理：

- 训练/验证/测试集；
- 数据泄漏；
- 时间切分；
- 类别编码；
- 特征缩放；
- 不平衡；
- 标签质量。

所有从数据“学习”出来的处理参数（均值、标准差、编码映射等），原则上只应在训练数据上拟合。

## 9. Notebook 的正确使用

Notebook 适合：

- EDA；
- 原型；
-教学；
- 实验记录。

当流程稳定后，应把关键处理提取为函数/模块，并固定输入输出和测试。

## 10. 数据处理检查清单

```text
读取 → 类型 → 唯一键 → 缺失 → 重复 → 异常
→ 单位/时间 → 变换 → 合并 → 聚合
→ 结果校验 → 输出
```

每一步都记录行数和关键质量指标，可显著减少静默错误。
