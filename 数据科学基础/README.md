## 核心原则

- 数据科学的目标不是“画图”或“训练模型”，而是从数据中形成**可验证、可解释、可行动的洞察**。
- 分析质量上限通常由**问题定义、数据质量与因果/统计假设**决定，而不只是工具熟练度。
- EDA、统计检验、可视化、建模不是线性流水线，而是围绕问题不断迭代。
- 任何结论都应能回答：数据从哪里来、经过什么处理、哪些假设成立、误差和偏差在哪里。
- 对供应商控制台、旧版 Azure UI、过期 API 等高时效内容不固化；只保留仍长期成立的云端与工程原则。
