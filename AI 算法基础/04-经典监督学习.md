# 04｜经典监督学习

## 1. 统一视角

训练集：

\[
D=\{(x_i,y_i)\}_{i=1}^N
\]

经验风险：

\[
R_{emp}(\theta)=\frac1N\sum_i L(f_\theta(x_i),y_i)
\]

带正则：

\[
\min_\theta R_{emp}(\theta)+\lambda\Omega(\theta)
\]

机器学习三要素：模型、学习准则、优化算法。

## 2. Linear Regression

\[
\hat y=w^Tx+b
\]

最小二乘：

\[
\min_w\|Xw-y\|_2^2
\]

闭式解在条件满足时：

\[
\hat w=(X^TX)^{-1}X^Ty
\]

## 3. Ridge 与 Lasso

Ridge：

\[
\min_w \|Xw-y\|_2^2+\lambda\|w\|_2^2
\]

Lasso：

\[
\min_w \|Xw-y\|_2^2+\lambda\|w\|_1
\]

L2 更偏向整体缩小，L1 更容易得到稀疏解。

## 4. Logistic Regression

\[
P(y=1|x)=\sigma(w^Tx+b)
\]

\[
\sigma(z)=\frac1{1+e^{-z}}
\]

它是概率分类器，不是普通回归。

## 5. Perceptron

误分类样本更新：

\[
w\leftarrow w+\eta yx
\]

它是理解线性分类与 margin 的重要前置模型。

## 6. SVM

硬间隔：

\[
\min_{w,b}\frac12\|w\|^2
\]

subject to：

\[
y_i(w^Tx_i+b)\ge1
\]

软间隔通过 slack variable 和 C 允许部分违约。

Kernel：

\[
K(x,z)=\phi(x)^T\phi(z)
\]

允许隐式进入非线性高维空间。

## 7. Naive Bayes

\[
P(y|x)\propto P(y)P(x|y)
\]

朴素条件独立：

\[
P(x|y)=\prod_jP(x_j|y)
\]

即使假设很强，在文本等问题中仍是非常好的 baseline。

## 8. Decision Tree

分类常用 entropy 或 Gini：

\[
H=-\sum_kp_k\log p_k
\]

\[
Gini=1-\sum_kp_k^2
\]

通过划分让子节点更纯。

树过深会过拟合，需要 pre/post pruning。

## 9. KNN

关键因素：

- k；
- 距离；
- scaling；
- neighbor search。

高维下会受到维度灾难影响。

## 10. Ensemble

两个要求：

- 单个学习器有一定准确率；
- 学习器之间有差异。

### Bagging

多个学习器并行训练，Random Forest 是典型。

### Boosting

学习器串行训练，后续模型修正前序错误。

代表：

- AdaBoost；
- Gradient Boosting；
- XGBoost；
- LightGBM。

## 11. Gradient Boosting

\[
F_M(x)=\sum_{m=1}^M\eta h_m(x)
\]

每一步拟合当前损失的负梯度方向，因此可推广到多种 loss。

## 12. 经典模型今天仍重要的场景

结构化表格数据中，尤其在：

- 数据中等；
- 特征有业务含义；
- 需要快速迭代；
- 解释性重要；

树模型通常仍是强基线。

具体 XGBoost/LightGBM API 会更新，本笔记只保留长期原理。
