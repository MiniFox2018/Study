# 10｜概率分布与贝叶斯推断

> 学习目标：能够给数据选择合理分布、计算条件概率，理解模型概率输出，并亲手完成一个文本分类器和一次贝叶斯更新。先修：分数、求和、指数与对数；矩阵仅在多元高斯部分使用。先读 1～7 节，再完成代码和练习。统计检验接[下一章](11-统计估计检验与实验判断.md)。

## 1. 概率描述什么：从事件到随机变量

样本空间是一次实验的全部可能结果；事件是其中的一部分。掷骰子的空间为 `{1,2,3,4,5,6}`，偶数事件为 `{2,4,6}`。非负性、总概率为 1、互斥事件概率可相加，是概率计算的起点。一般事件要扣除交集：

$$
P(A\cup B)=P(A)+P(B)-P(A\cap B).
$$

随机变量给结果赋数值，例如骰子点数 $X$、是否点击 $Y\in\{0,1\}$。它的分布描述这些数值如何出现。分类模型可输出类别的条件分布；回归模型也可只输出一个点估计。并非所有模型输出或损失函数都天然是概率分布。

若 $P(B)>0$，条件概率为 $P(A\mid B)=P(A\cap B)/P(B)$。在 12 张 J/Q/K 人头牌中有 4 张 K，因此 $P(K\mid\text{人头牌})=1/3$。条件把样本空间缩到已知证据所在的范围。

独立满足 $P(A\cap B)=P(A)P(B)$。互斥与独立不同：非零概率的互斥事件不能同时发生，因而不独立。放回抽牌可独立；不放回会改变下次抽牌概率。**条件独立**还要注明“给定什么”：两个症状即使总体相关，也可能在给定疾病类型后近似独立，反过来也可能不成立。

## 2. 概率质量、概率密度和累积分布

离散 PMF 为 $p(k)=P(X=k)$，所有质量相加为 1。连续 PDF 为 $f(x)$，区间面积才是概率：

$$
P(a\le X\le b)=\int_a^b f(x)\,dx,\qquad \int_{-\infty}^{\infty}f(x)\,dx=1.
$$

例如 $X\sim U(0,0.1)$ 的密度为 10，$P(0.02<X<0.05)=10\times0.03=0.3$。密度超过 1 完全合法，连续单点概率仍为 0。累积分布 $F(x)=P(X\le x)$ 则既适用于离散也适用于连续变量，并总在 $[0,1]$ 中。

联合分布同时描述多个变量；边缘分布通过求和或积分消掉其他变量。以下表中的 $X$ 表示天气，$Y$ 表示是否带伞：

| 联合概率 | 不带伞 | 带伞 | 天气边缘概率 |
|---|---:|---:|---:|
| 晴 | 0.40 | 0.10 | 0.50 |
| 雨 | 0.05 | 0.45 | 0.50 |
| 带伞边缘概率 | 0.45 | 0.55 | 1.00 |

$P(\text{带伞}\mid\text{雨})=0.45/0.50=0.9$，而 $P(\text{雨}\mid\text{带伞})=0.45/0.55\approx0.8182$。若独立，雨且带伞应为 $0.5\times0.55=0.275$，实际为 0.45，故不独立。这是通过联合表核验独立性的办法，不能只看两个变量名字不同。

## 3. 期望和波动：为什么平均值还不够

离散期望为 $E[X]=\sum_x xp(x)$，连续版改为积分。期望有线性性 $E[aX+bY]=aE[X]+bE[Y]$，不要求独立。方差和协方差为：

$$
\operatorname{Var}(X)=E[(X-E[X])^2],\qquad
\operatorname{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])].
$$

因此 $\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)$。不能在依赖数据上直接把方差相加。骰子 $E[X]=3.5$、$E[X^2]=91/6$，方差 $35/12\approx2.9167$，标准差约 1.7078。

训练的总体目标常写为 $E[\ell(X,Y)]$，有限数据平均损失是它的估计。样本多能降低随机波动，却不能消掉分布偏差。独立同分布且有有限绝对一阶矩时，大数定律给出样本平均的收敛；若还有有限非零方差，则：

$$
\frac{\sqrt n(\bar X-\mu)}{\sigma}\ \xrightarrow{d}\ \mathcal N(0,1).
$$

这是中心极限定理的常用版本。近似正态的是**标准化样本平均的分布**，不是原始数据变正态；Cauchy 无限方差、强依赖序列不能直接套用。也没有统一的“超过 30 个样本必然有效”。

```python
import numpy as np
rng=np.random.default_rng(42)
for n in [1,2,5,30]:
    means=rng.random((10000,n)).mean(axis=1)
    print(n,"均值",round(means.mean(),5),"标准差",round(means.std(),5),
          "理论标准差",round(np.sqrt(1/(12*n)),5))
```

均匀[0,1)平均值趋近0.5，平均的标准差随n约按 $1/\sqrt n$ 减小。要检验正态形状，可画标准化均值的直方图与标准正态比较；均值与方差匹配本身不证明正态。

## 4. 常见分布：先看变量和生成机制

### 4.1 单次选择、重复选择与次数

- **Bernoulli**：一次是否成功，$p(1)=p$、$p(0)=1-p$，均值 $p$、方差 $p(1-p)$。二分类点击概率用它描述。
- **Binomial**：$n$ 次独立、同一成功率试验的成功总数，$P(K=k)=\binom nk p^k(1-p)^{n-k}$。均值 $np$、方差 $np(1-p)$。10 次试验中 7 次成功，与一次成功的建模对象不同。
- **Categorical**：一次从 $K$ 个互斥类别中选择，参数 $(p_1,\ldots,p_K)$ 总和为 1。Softmax 适用于单标签多分类；可同时属于多个标签的任务通常用多个 Bernoulli，而不是强迫概率和为 1。
- **Multinomial**：$n$ 次类别选择的计数向量，$P(c_1,\ldots,c_K)=n!\prod_i p_i^{c_i}/\prod_i c_i!$，其中 $\sum_i c_i=n$。文本词频模型可用它近似词袋。
- **Poisson**：单位观察窗口的事件次数，$P(K=k)=e^{-\lambda}\lambda^k/k!$，均值与方差都为 $\lambda$。独立增量、近似稳定到达率的机制支持此模型；“稀有”并非定义。均值 3 时，零次事件概率 $e^{-3}\approx0.0498$。

组合数 $\binom nk$ 忽略顺序；排列数 $n!/(n-k)!$ 保留顺序。二项分布中的组合因子枚举成功所在位置。重复选择、放回与顺序是否重要，要在计数之前确定。

### 4.2 等待时间、正数、比例和重尾

**Exponential** 以速率 $\lambda>0$ 描述等待时间，$f(x)=\lambda e^{-\lambda x}$、$F(x)=1-e^{-\lambda x}$（$x\ge0$），均值 $1/\lambda$，方差 $1/\lambda^2$。它具有无记忆性：$P(X>s+t\mid X>s)=P(X>t)$。老化风险变化的寿命不应硬套它。

**Uniform** 对指定区间等密度：$f(x)=1/(b-a)$；均值 $(a+b)/2$、方差 $(b-a)^2/12$。均匀只是对当前坐标而言，均匀的 $x$ 经非线性变换后通常不再均匀。

**Normal** 的参数写成均值和方差 $\mathcal N(\mu,\sigma^2)$：

$$
f(x)=\frac{1}{\sigma\sqrt{2\pi}}\exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right],\quad\sigma>0.
$$

它适合近似对称误差，但会给所有负值区间非零概率。价格、距离、等待时间有硬下界时，要考虑 log-normal、Gamma 等。给定有限均值与方差，在实数上满足这些约束的连续分布中，高斯具有最大微分熵；这不是“所有数据都该用高斯”的理由。

读高斯图时：改变 $\mu$ 会平移曲线；增大 $\sigma$ 会变宽变矮，总面积仍为 1。$\mu\pm\sigma$ 约覆盖 68.27%，$\mu\pm2\sigma$ 约覆盖 95.45%，这些比例针对高斯，不是任意数据的规则。

**Beta** 描述 $p\in(0,1)$ 的未知比例，密度正比于 $p^{a-1}(1-p)^{b-1}$（$a,b>0$）：

$$
E[p]=\frac a{a+b},\qquad \operatorname{Var}(p)=\frac{ab}{(a+b)^2(a+b+1)}.
$$

同一均值下，$a+b$ 越大通常越集中。Beta(1,1) 在该参数坐标上均匀；它仍是一个先验选择，不能称为“完全没有假设”。边界恰为 0 或 1 的数据质量，需要额外点质量模型。

**Gamma** 使用形状 $a$、速率 $b$ 时，$f(x)=b^a x^{a-1}e^{-bx}/\Gamma(a)$，均值 $a/b$、方差 $a/b^2$；很多库用尺度 $1/b$，混淆两者会使结果完全错误。它也可描述多个指数等待时间之和。

**Dirichlet** 用于总和为 1 的类别概率向量，密度正比于 $\prod_i p_i^{\alpha_i-1}$，$E[p_i]=\alpha_i/\alpha_0$，$\alpha_0=\sum_i\alpha_i$。各分量不是独立的，因为总和固定。

需要更灵活机制时：几何分布 $P(K=k)=(1-p)^{k-1}p$（$k\ge1$）描述第一次成功的试验次数；负二项可描述等到 $r$ 次成功前失败次数，也常用于过度离散计数；log-normal 是 $\log X$ 正态的正数；Weibull 用形状控制随时间上升或下降的风险。重尾误差可考虑 Student-t；自由度 $\nu>1$ 才有均值、$\nu>2$ 才有有限方差，Cauchy 为 $\nu=1$。这些分布应由机制与数据检查支持，而不凭“变量像什么”直接断定。

### 4.3 多元高斯与白化

若 $x\in\mathbb R^d$、$\Sigma$ 正定，多元高斯密度中的距离为 $(x-\mu)^T\Sigma^{-1}(x-\mu)$。它同时考虑各特征尺度和相关方向。若 $y=Ax+b+\epsilon$，独立 $\epsilon\sim\mathcal N(0,R)$，则：

$$
y\sim\mathcal N(A\mu+b,A\Sigma A^T+R).
$$

标准化仅按各维标准差缩放；白化 $z=\Sigma^{-1/2}(x-\mu)$ 还去掉线性相关。退化 $\Sigma$ 需要降维或正则化，不能直接求逆；训练统计量只由训练集拟合，避免信息泄漏。

## 5. 模型为何使用 logits 和对数概率

Logits 是未归一化实数分数。Softmax：

$$
q_i=\frac{e^{z_i}}{\sum_j e^{z_j}},\qquad
\log q_i=(z_i-m)-\log\sum_j e^{z_j-m},\quad m=\max_j z_j.
$$

全体减去 $m$ 不改变比值，却使最大指数为 1。`exp(100)` 在 float64 中是可表示的；float32 更早溢出，float64 到约 710 附近也会溢出。稳定写法应始终使用，不依赖某个示例数值“刚好没问题”。

序列概率在条件分解下为 $\prod_t q(y_t\mid y_{<t})$，对数则为逐项相加。50 个概率 0.01 的项相乘为 $10^{-100}$，float64 尚能表示；更多项才会下溢。对数质量总不大于 0，但**对数密度**可为正，似然函数也不是参数空间上的归一化概率。

下面是完整 CPU/NumPy 示例：

```python
import math
import numpy as np

def log_softmax(z):
    z = np.asarray(z, dtype=float)
    if z.ndim != 1 or z.size == 0 or not np.isfinite(z).all():
        raise ValueError("需要非空、有限的一维 logits")
    shifted = z - z.max()
    return shifted - np.log(np.exp(shifted).sum())

def poisson_pmf(k, rate):
    if rate < 0 or not float(k).is_integer() or k < 0:
        raise ValueError("计数需要非负整数，速率需要非负")
    if rate == 0:
        return float(k == 0)
    return math.exp(k * math.log(rate) - rate - math.lgamma(k + 1))

z = np.array([2.0, 0.5, -1.0, 3.0, 0.1])
lp = log_softmax(z)
print("类别概率", np.exp(lp).round(6))
print("目标类别3的损失", round(-lp[3], 6))
print("平移不改变概率", np.allclose(lp, log_softmax(z + 10000)))
print("Poisson零次事件", round(poisson_pmf(0, 3), 6))
print("50项序列对数概率", round(50 * math.log(0.01), 6))
```

损失约 `0.420881`；平移检查为 `True`；零次概率 `0.049787`；序列对数概率约 `-230.258509`。Softmax 应沿类别维归一化，不能把不同样本混到一个分母。交叉熵与信息量的关系接[信息论章](12-采样蒙特卡洛与信息论.md)。

## 6. 贝叶斯：证据怎样改变判断

对未知参数 $\theta$ 和数据 $D$：

$$
p(\theta\mid D)=\frac{p(D\mid\theta)p(\theta)}{p(D)},\qquad
p(D)=\int p(D\mid\theta)p(\theta)\,d\theta.
$$

先验描述数据之前的假设；似然固定观测、比较参数对观测的支持；后验组合二者；证据保证后验归一化。离散假设用求和替代积分。

用一个合成“故障检测”例子避免基础率误解：设备故障率为 0.0001，故障时告警概率 0.99，正常时误报概率 0.01。它们是两个条件概率，不能仅称检测“99%准确”。

$$
P(\text{故障}\mid\text{告警})=
\frac{0.99\times0.0001}{0.99\times0.0001+0.01\times0.9999}
\approx0.009804.
$$

在一百万台设备中，约有 99 个真实告警、9999 个误报，所以告警设备中故障比例不到 1%。真实应用要核对这些输入是否适用于当前人群、设备或时间。

若两个检测在**给定真实状态后条件独立**，两次告警可将似然分别平方，后验为 0.495。若两次重复的是同一偏差、同一传感器错误或同一数据，不能重复相乘。顺序更新只是代数重排，需要为新证据使用正确条件似然。

## 7. MLE、MAP 与完整后验

MLE 最大化 $\sum_i\log p(x_i\mid\theta)$；MAP 额外加 $\log p(\theta)$。MAP 给后验众数，仍是点估计；完整贝叶斯后验给出参数范围和不确定性。频率学派也能给区间，不能简化成“频率只有一个数字，贝叶斯自动更可靠”。

高斯噪声线性回归和零均值高斯权重先验给出：

$$
-\log p(y\mid X,w)-\log p(w)
=\frac{\|y-Xw\|^2}{2\sigma^2}+\frac{\|w\|^2}{2\tau^2}+C.
$$

因此平方误差加 L2 是该模型下的 MAP；惩罚强度取决于噪声、先验尺度和损失是求和还是求平均。Laplace 权重先验对应 L1。MAP 对参数重参数化敏感，也不能代表整个后验。

对于 Bernoulli 试验，先验 Beta($a,b$)、成功 $s$ 次失败 $f$ 次给后验 Beta($a+s,b+f$)。其均值为 $(a+s)/(a+b+s+f)$；两个后验参数都大于 1 时，众数为：

$$
\hat p_{MAP}=\frac{a+s-1}{a+b+s+f-2}.
$$

观察 7 成功 3 失败，Beta(2,2) 给后验 Beta(9,5)：MLE=0.7，MAP=$8/12=0.6667$，后验均值=$9/14=0.6429$。三者不一样；参数小于或等于 1 时要检查边界众数，不能盲用公式。

顺序例子：Beta(1,1) → 7 成功 3 失败 → Beta(8,4) → 5 成功 5 失败 → Beta(13,9)，最终均值约 0.5909，与一次性输入所有数据相同。此处假设成功率固定；若机制漂移，长期累计会掩盖变化，要另建动态模型。

其他共轭关系：Poisson 次数与 Gamma 速率先验给 Gamma($a+\sum k_i,b+\sum t_i$)，$t_i$ 为曝光时长；类别计数与 Dirichlet 给 $\alpha_i+c_i$；已知观测方差的高斯均值，后验精度等于先验精度加数据精度。共轭不成立时也可数值积分、近似推断或 MCMC，并非必须有解析答案。

## 8. 手写词袋朴素贝叶斯

本节是从概率到文本分类的第一个标准库实现。学完后接[朴素贝叶斯与概率分类](../机器学习专题/05-朴素贝叶斯与概率分类.md)：那里维护三种事件模型、NumPy/库对照、完整中文管线和校准，避免在数学入口重复维护全部工程细节。

多项式朴素贝叶斯把文档表示为词次数 $c_w$，分数为：

$$
S(k)=\log P(k)+\sum_{w\in V}c_w\log\frac{N_{kw}+\alpha}{N_k+\alpha|V|}.
$$

$N_{kw}$ 为类别 $k$ 中词 $w$ 的总次数，$N_k$ 是全部词次数，$V$ 是训练词表。$\alpha=1$ 为加一平滑；正数平滑避免已知词在某一类未见导致零概率。若使用“词出现过没有”的 Bernoulli 模型，分母应来自文档数，还要计入未出现特征，不能与词频公式混用。[scikit-learn 官方说明](https://scikit-learn.org/stable/modules/naive_bayes.html)明确区分这些事件模型。

$S(k)$ 是省略共同归一化项的对数联合分数，**不等于**对数后验；变成类别概率须做下方的归一化。多项式模型可理解为给定类别/长度后独立抽词token，词次数因总和固定不彼此独立。$\alpha$计数平滑对应对称Dirichlet先验下的后验预测/均值，不应与MAP众数公式混用。

以下完整实现忽略词表外词；正式系统也可设置 `<UNK>` 类别，但须在训练和推断保持一致。中文实际文本需要约定分词；示例故意使用空格分隔，便于检查计数。

```python
import math
from collections import Counter, defaultdict

class WordCountNB:
    def fit(self, documents, labels, alpha=1.0):
        if len(documents) != len(labels) or not documents or alpha <= 0:
            raise ValueError("训练输入非空且等长，平滑系数应为正")
        self.alpha = alpha
        self.class_n = Counter(labels)
        self.word_n = defaultdict(Counter)
        self.vocab = set()
        for text, label in zip(documents, labels):
            words = text.lower().split()
            self.word_n[label].update(words)
            self.vocab.update(words)
        if not self.vocab:
            raise ValueError("训练词表不能为空")
        self.total = {k: sum(c.values()) for k, c in self.word_n.items()}
        return self

    def probabilities(self, text):
        words = Counter(w for w in text.lower().split() if w in self.vocab)
        scores = {}
        for k, count in self.class_n.items():
            score = math.log(count / sum(self.class_n.values()))
            denominator = self.total.get(k, 0) + self.alpha * len(self.vocab)
            for w, repeats in words.items():
                probability = (self.word_n[k][w] + self.alpha) / denominator
                score += repeats * math.log(probability)
            scores[k] = score
        largest = max(scores.values())
        weights = {k: math.exp(v - largest) for k, v in scores.items()}
        return {k: v / sum(weights.values()) for k, v in weights.items()}

docs = ["免费 奖品 免费", "中奖 奖品", "会议 项目", "项目 报告"]
labels = ["垃圾", "垃圾", "正常", "正常"]
model = WordCountNB().fit(docs, labels)
for text in ["免费 奖品", "项目 报告", "未知词"]:
    p = model.probabilities(text)
    print(text, {k: round(v, 4) for k, v in p.items()}, max(p, key=p.get))
```

第一条偏向垃圾类，第二条偏向正常类；完全未知词返回类别先验，此处各 0.5。`probabilities` 是**模型假设下**归一化分数，不保证真实校准。词序丢失、“北京 大学”相关或模板重复造成依赖会影响模型；一个词出现多次本身属于词频模型的正常输入，并不单凭重复次数就证明违背假设。相关证据误差未必在各类别抵消，可能连排序都错，仍需保留数据评估。

工程使用时：先划分数据，再在训练集拟合词表和概率；验证集选择平滑与特征；最终测试集只验收。检查类别不平衡、分词、词表外比例和模型校准。追加消息长度特征会与词计数相关，不能假装天然条件独立。

## 9. 贝叶斯 A/B：从“哪个均值大”到“值得切换吗”

假设随机分组、用户结果独立、每组固定点击率。A 为 1000 次中 50 点击，B 为 65 点击，均使用 Beta(1,1)，后验分别为 Beta(51,951)、Beta(66,936)。用后验采样估计 $P(p_B>p_A\mid D)$，也检查最小有用提升 $\delta$：

```python
import numpy as np
rng = np.random.default_rng(42)
a = rng.beta(51, 951, 100000)
b = rng.beta(66, 936, 100000)
diff = b - a
print("B更好概率", round((diff > 0).mean(), 4))
print("提升超过0.5个百分点概率", round((diff > 0.005).mean(), 4))
print("绝对提升90%可信区间", np.quantile(diff, [0.05, 0.95]).round(5))
```

该区间的后验概率解释与频率置信区间不同。相对提升 $(p_B-p_A)/p_A$ 在 A 接近 0 时会很不稳定，应同时报告绝对百分点、成本和护栏指标。

此环境的固定种子运行得到 B 更好概率约0.9241，超过0.5个百分点概率约0.8306，绝对提升90%可信区间约 `[-0.00211,0.03230]`。这些是所用先验和合成计数下的计算，既不是已有用户实验，也不足以单凭一个后验均值宣布上线。

后验可顺序更新，**不等于任意反复查看、到某一阈值就停止，便自动保持 5% 的长期误报率**。先验、停止策略、模型适配和决策目标都影响保证；参见[可选停止原论文](https://arxiv.org/abs/1807.09077)。预先说明最小收益、误判损失和停止规则，用模拟检查决策表现，再把后验概率用于实际判断。

## 10. 自查与实践参考答案

1. 两枚偏骰的边缘都是 $(0.2,0.3,0.5)$。如何构造独立联合表？**答案：**$J_{ij}=p_i p_j$。只给两组边缘不能证明独立；例如将质量放在对角线上也能有同样边缘，却完全相关。
2. 为什么 PDF=10 合法、PMF=10 不合法？**答案：**PDF 的面积归一化；PMF 单个值就是事件概率，必须不大于 1。
3. 把朴素贝叶斯 $\alpha$ 从 0.01、0.1、1 调到 10，词概率如何变化？**答案：**逐类趋向 $1/|V|$，数据差异变弱；$\alpha=0$ 时某类未见已知词给零概率、对数为负无穷。比较验证集效果，不能断言越大越好。
4. 怎样加入“短/长”特征？**答案：**训练时按预先固定阈值计文档数，估计 $P(\text{短}\mid k)=(n_{k,短}+\eta)/(n_k+2\eta)$，推断再加对应对数似然。必须承认它与词计数相关，并比较新增前后的保留集表现。
5. 如何挑选最可能的序列？**答案：**分别累加各序列条件对数概率，选择最大值；不能把不同候选序列所有词一起累加。不同长度有额外比较偏好，应按任务设置结束符及长度处理。
6. 10 次试验 7 成功，Beta(2,2) 的 MAP 为何不是 0.7？**答案：**最大化 $p^8(1-p)^4$，令对数导数为零，得 $8/(8+4)=2/3$。完整后验仍包含不确定性。
7. 两次告警何时不能把似然平方？**答案：**给定真实状态仍有关联时。改用 $P(E_2\mid E_1,H)$，不能重复把同一证据当成新信息。
