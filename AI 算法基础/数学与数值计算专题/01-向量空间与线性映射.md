## 1. 向量表示的是什么

向量 $x=(x_1,\ldots,x_d)^T$ 是一个向量空间的元素。在选定坐标系后，它可以写成一列数。二维时可以画成从原点指向 $(x_1,x_2)$ 的箭头，也可以把它作为一个数据点的坐标。点的位置与位移向量要区分：换原点会改变点的坐标，两个点之间的位移不受共同平移影响。

在 AI 中，一个样本的特征、一个词的 embedding、一个模型的参数都能用向量表示。但是“把对象变成数字”不会自动产生语义：只有表示方法和训练目标让相关对象在某种比较方法下接近，向量距离才具有任务意义。随机生成的数字可以测试检索程序，不能证明真的理解了文本。

例如传感器样本 $(20,0.7)$ 可以分别表示温度与湿度。第一维与第二维的单位不同；未经处理就比较欧氏距离，相当于人为认为“温度变化 1 与湿度变化 1 等价”。坐标含义、单位和顺序必须先说明。

向量加法逐分量相加，标量乘法逐分量缩放。$(3,4)+(1,2)=(4,6)$，$2(3,4)=(6,8)$。向量空间要求这些运算对集合封闭，并满足结合、分配、零元等规则。整数坐标集合对实数乘法不封闭，因此不是实数向量空间。

## 2. 点积、夹角与归一化

对 $a,b\in\mathbb R^d$，标准点积是

$$
a^Tb=\sum_{i=1}^d a_i b_i=\|a\|_2\|b\|_2\cos\theta,
\qquad \|a\|_2=\sqrt{\sum_i a_i^2}.
$$

点积同时受长度和方向影响。点积正、零、负分别表示夹角小于、等于、大于 $90^\circ$；“点积正”并不等于“两个文本语义相似”，那需要模型和阈值的实测支持。对于非零向量：

$$
\widehat a=\frac{a}{\|a\|_2},\qquad
\operatorname{cos}(a,b)=\widehat a^T\widehat b.
$$

$a=(1,2,3)$、$b=(4,5,6)$ 时，点积 $32$，两者长度为 $\sqrt{14}$ 与 $\sqrt{77}$，余弦约 $0.974632$。这说明方向接近，不能从这个数字推出它们长度接近。

下面是可直接运行的纯 Python 实现。它保留手写代码的计算思路，并显式检查两个常见陷阱：`zip` 会静默截断不同长度的输入；零向量没有定义良好的方向。

```python
import math

def dot(a, b):
    if len(a) != len(b):
        raise ValueError("点积要求两个向量长度相同")
    return sum(x * y for x, y in zip(a, b))

def norm(a):
    return math.sqrt(dot(a, a))

def normalize(a):
    length = norm(a)
    if length == 0:
        raise ValueError("零向量不能归一化为单位方向")
    return [x / length for x in a]

def angle_degrees(a, b):
    c = dot(normalize(a), normalize(b))
    # 浮点舍入可能得到 1.0000000000000002，先限制反余弦的输入范围。
    return math.degrees(math.acos(max(-1.0, min(1.0, c))))

a, b = [1, 2, 3], [4, 5, 6]
print(dot(a, b))                       # 32
print(round(dot(normalize(a), normalize(b)), 6))  # 0.974632
print(angle_degrees([1, 0], [0, 1]))    # 90.0
```

生产计算通常用 NumPy：`a @ b` 或 `np.dot(a, b)` 计算一维点积，`np.linalg.norm(a)` 计算长度。不要把多维 `np.dot` 的轴规则当作批量矩阵乘法，后者见[张量专题](04-张量形状广播与批量计算.md)。

## 3. 张成空间、线性独立、基与秩

一组向量的所有线性组合称为它们的张成空间（span）：

$$
\operatorname{span}(v_1,\ldots,v_k)
=\left\{\sum_{i=1}^k c_i v_i:c_i\in\mathbb R\right\}.
$$

若 $\sum_i c_i v_i=0$ 只能由所有 $c_i=0$ 得到，就称向量组线性独立。否则至少有一个向量可由其余向量组合出来。

取 $v_1=(1,0,0)$、$v_2=(0,1,0)$、$v_3=(2,1,0)$。因为 $v_3=2v_1+v_2$，这组三个向量只有两个独立方向，张成的是 $xy$ 平面，不能表示 $(0,0,1)$。不是“有三个向量就有三维信息”，也不是“元素不同就独立”。

**基**是既独立又能张成整个目标空间的一组向量。标准基 $e_1,e_2,e_3$ 是一种选择，其他三个独立的三维向量也可以成为基。同一个几何向量换一组基以后，坐标可能完全不同。

把向量作为矩阵 $A\in\mathbb R^{m\times n}$ 的列，**秩**等于独立列的数量，也等于独立行的数量。列空间的维度就是秩，零空间的维度满足

$$
\operatorname{rank}(A)+\dim\ker(A)=n.
$$

满秩是 $\operatorname{rank}(A)=\min(m,n)$。务必再看矩阵的形状：

| 情形 | 能推出什么 | 不能推出什么 |
|---|---|---|
| 方阵满秩 | 对任何 $b$，$Ax=b$ 有唯一解 | 不保证数值稳定 |
| 高矩阵 $m\ge n$ 满列秩 | 最小二乘参数解唯一 | 不保证存在精确解 |
| 宽矩阵 $m<n$ 满行秩 | 对任何 $b$ 存在精确解，零空间非平凡 | 不保证参数唯一 |
| 秩亏 | 存在冗余方向 | 不表示所有右端项都无解 |

`np.linalg.matrix_rank` 采用与奇异值有关的容差判断数值秩。若某一列几乎是另一列的倍数，数学上仍可能满秩，但对噪声非常敏感；检查奇异值和条件数比只看一个整数更有用。

在线性回归中，若第三列等于前两列的某个线性组合，多个参数向量会给出同样预测。问题主要是系数无法唯一识别；不能笼统说所有预测必然剧烈变化。删除重复特征、使用岭回归或选择最小范数解的作用，见[线性系统](02-矩阵变换与线性系统.md)。

## 4. 矩阵为什么是线性映射

映射 $T$ 满足 $T(ax+by)=aT(x)+bT(y)$ 时称为线性。它必须把零映射到零。给定输入与输出坐标系，任何有限维线性映射都可以写成 $T(x)=Ax$。

矩阵的第 $j$ 列就是 $Ae_j$，即第 $j$ 个输入基向量的输出。因此

$$
Ax=x_1A_{:,1}+\cdots+x_nA_{:,n}.
$$

例如 $A=\begin{bmatrix}1&2\\0&1\end{bmatrix}$，它把 $(1,0)$ 送到 $(1,0)$，把 $(0,1)$ 送到 $(2,1)$，所以把 $(3,4)$ 送到 $3(1,0)+4(2,1)=(11,4)$。从两列就能推算整个变换。

神经网络线性层中的一个输出是输入特征的加权和。若

$$
W=\begin{bmatrix}1&0&0\\0&1&0\\0.5&0.5&0\end{bmatrix},\quad
x=(0.8,0.6,0.1)^T,
$$

则 $Wx=(0.8,0.6,0.7)^T$。第一行复制第一个特征，第二行复制第二个特征，第三行取前两个特征的平均。加偏置以后 $Wx+b$ 是仿射映射；再加 ReLU 才得到非线性层。

## 5. 正交投影：保留沿某个方向的部分

把 $a$ 分成平行于非零向量 $b$ 的部分 $\alpha b$ 和正交残差 $r$：$a=\alpha b+r$，并要求 $b^Tr=0$。代入得到

$$
\alpha=\frac{b^Ta}{b^Tb},\qquad
\operatorname{proj}_b(a)=\frac{b^Ta}{b^Tb}b.
$$

这不只是记公式，而是在直线上寻找距 $a$ 最近的点。投影箭头是“影子”，$a$ 与影子末端之间的连线垂直于 $b$。夹角为 $90^\circ$ 时影子为零；超过 $90^\circ$ 时投影系数为负，影子指向 $b$ 的反方向。

$a=(3,4)$、$b=(1,0)$ 时，投影 $(3,0)$、残差 $(0,4)$。$a=(1,2,3)$、$b=(1,1,1)$ 时，系数为 $6/3=2$，投影 $(2,2,2)$、残差 $(-1,0,1)$，残差与 $b$ 的点积为零。

若 $Q\in\mathbb R^{d\times k}$ 的列是目标子空间的正交单位基，则投影矩阵是 $P=QQ^T$。它满足 $P^T=P$、$P^2=P$。对于不正交但满列秩的基矩阵 $B$，$P=B(B^TB)^{-1}B^T$ 是数学表达；工程上通过 QR 求 $Q$ 更合适。

这里必须区分两种“投影”：PCA 或最小二乘里的**正交投影**有上述条件；Transformer 的 `Q=XW_q` 常被称为 query projection，但 $W_q$ 通常是任意学习得到的线性映射，不满足 $P^2=P$。Attention 分数也是兼容性点积，不是逐一把 query 正交投影到 key 上。

## 6. Gram–Schmidt 与 QR：逐步去掉已有方向

要把独立向量变成正交单位向量，按顺序：从新向量中减去它在已有单位方向上的投影，再归一化。令 $w=v_j$，对所有已有 $q_i$ 更新 $w\leftarrow w-(q_i^Tw)q_i$；最后 $q_j=w/\|w\|_2$。

例如 $v_1=(1,1)$、$v_2=(1,0)$：

1. $q_1=(1,1)/\sqrt2$。
2. $q_1^Tv_2=1/\sqrt2$，减去投影后 $w=(1/2,-1/2)$。
3. $q_2=(1,-1)/\sqrt2$。两者长度为 1、点积为 0，张成空间没有改变。

下面展示修改版 Gram–Schmidt，逐次对残差做投影。相对于一次性用原向量计算所有系数，它通常更能控制舍入误差，但病态输入仍需要成熟的 Householder QR 或再正交化。

```python
import numpy as np

def orthonormal_columns(A):
    A = np.asarray(A, dtype=float)
    if A.ndim != 2:
        raise ValueError("输入必须是二维矩阵")
    qs = []
    tol = np.finfo(float).eps * max(A.shape) * np.linalg.norm(A)
    for column in A.T:
        w = column.copy()
        for q in qs:
            w -= (q @ w) * q
        length = np.linalg.norm(w)
        if length <= tol:
            continue  # 跳过零向量或数值冗余方向，返回张成空间的基。
        qs.append(w / length)
    return np.column_stack(qs) if qs else np.empty((A.shape[0], 0))

A = np.array([[1., 1.], [1., 0.]])
Q = orthonormal_columns(A)
print(np.round(Q, 6))
print(np.allclose(Q.T @ Q, np.eye(2)))  # True
print(np.allclose(Q @ (Q.T @ A), A))    # True
```

这里的 `Q` 约为 `[[0.707107,0.707107],[0.707107,-0.707107]]`。设 $R=Q^TA$ 就得到 $A=QR$；对独立列按原顺序处理时 $R$ 上三角。$Q$ 存方向，$R$ 存原列在这些方向上的系数。实际调用 `np.linalg.qr(A, mode="reduced")`，验证 $Q^TQ=I$、$QR=A$；高矩阵不能把 $QQ^T=I_m$ 当成验证条件。

## 7. 在线性层、检索和 LoRA 中使用这些知识

线性层要先决定数据布局。列向量写作 $y=Wx+b$，$W$ 为 `输出维×输入维`；样本放在行上的批量计算写作 $Y=XW^T+b$。这两种约定没有矛盾，转换时权重也要转置。详见[张量专题](04-张量形状广播与批量计算.md)。

检索中，可以先对所有非零向量逐行归一化，再计算 `scores = E_normalized @ q_normalized`，按分数降序取候选。需要明确处理零向量，排除查询自身，并在真实相关性标注上检查排序。向量相似不能替代事实核对。

LoRA 用 $\Delta W=BA$ 表示权重更新，其中 $B\in\mathbb R^{d_{out}\times r}$、$A\in\mathbb R^{r\times d_{in}}$。更新矩阵秩最多为 $r$，可训练参数从 $d_{out}d_{in}$ 减到 $r(d_{out}+d_{in})$。例如 $4096\times4096$ 与 $r=16$ 时，分别为 $16,777,216$ 和 $131,072$ 个参数。低秩约束针对更新 $\Delta W$，不表示整个原模型本来只有 16 维，也不保证任何任务都能保持同样效果。

点积求导也能手算：$f(x)=x^Ty$、$y$ 固定时，$\partial f/\partial x_i=y_i$，因此梯度就是 $y$。自动微分只是把这样的局部导数沿计算图组合起来。正文推导与反向传播见[主章节](../01-线性代数与矩阵微积分.md)。

## 8. 练习与判断标准

1. 给定 $a=(3,4)$，归一化后是什么？**答案：**$(0.6,0.8)$，长度为 1。若输入 $(0,0)$，应拒绝计算单位方向，而不是输出一个“正常”余弦值。
2. 矩阵 $\begin{bmatrix}1&0&2\\0&1&1\\0&0&0\end{bmatrix}$ 的秩和零空间维度？**答案：**秩 2，零空间维度 1；列空间为 $xy$ 平面。$(-2,-1,1)^T$ 在零空间。
3. 用缩放矩阵将 $(1,1)$ 的横坐标变成 2、纵坐标变成 3。**答案：**`np.diag([2.,3.]) @ [1.,1.]` 得 $(2,3)$。
4. 对 5 个固定随机的 50 维非零向量，找最相似的一对。**方法：**逐行归一化，算 $EE^T$，把对角线设为负无穷；只查上三角，避免同一对重复。没有普适的指定索引，结果取决于种子；应核对向量维数、分数范围和是否排除了自身。
5. Gram–Schmidt 输出是否必定与输入个数一样多？**答案：**只有独立、非零且数值处理可靠时如此。含重复向量应减少基的数量，不能归一化已经变为零的残差。
6. 对 $(1,2,3)$ 沿 $(1,1,1)$ 的投影，检查“投影+残差=原向量”和“残差点积为零”。**答案：**投影 $(2,2,2)$、残差 $(-1,0,1)$，两项成立。
