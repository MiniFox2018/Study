# 12｜采样、蒙特卡洛与信息论

> 先修：[概率分布](10-概率分布与贝叶斯推断.md)。前半章回答“怎样生成随机值、估计积分”；后半章回答“怎样衡量不确定性与预测损失”。MCMC 的动态结构接[图论与随机过程](13-图论与随机过程.md)，优化方法接[数值优化主入口](../03-数值优化-蒙特卡洛与采样.md)。

## 1. 先区分三种目的

生成输出，需要一个目标分布的样本；估计积分，需要一个低误差的估计量；训练随机模型，有时还需要估计量对参数可微。三者不应只用“采样”一个词混过去。

例如语言模型从类别分布选 token；mini-batch 从数据中抽样估梯度；重要性采样可估期望而不生成目标分布的独立样本；Gumbel-Softmax 返回连续松弛向量，不能当成精确离散样本。

伪随机数生成器从种子得到可复现实验序列；同种子不等于跨库、版本或设备输出完全一样。下面使用局部 `np.random.default_rng`，避免修改全局随机状态。概率向量应非负且总和为 1；随机算法也要检查空输入、非法参数和支持集。

## 2. 从 Uniform 产生其他分布

### 2.1 逆 CDF

先取 $U\sim U(0,1)$，再令 $X=F^{-1}(U)$。连续严格递增情形：$P(X\le x)=P(U\le F(x))=F(x)$；一般 CDF 使用广义逆 $\inf\{x:F(x)\ge u\}$。

离散分布 $(0.2,0.5,0.3)$ 的累计概率为 $(0.2,0.7,1)$：$u<0.2$ 返回 0，$0.2\le u<0.7$ 返回 1，其余返回 2。它把随机区间的长度转成类别概率。

指数分布 $F(x)=1-e^{-\lambda x}$ 给 $X=-\log(1-U)/\lambda$，使用 `log1p(-u)` 对小 $u$ 更稳。若采用 $-\log U$，需防 $U=0$。Cauchy 的逆为 $X=\tan[\pi(U-1/2)]$，接近端点会出现极大值；样本均值不稳定是重尾性质，不是程序必然写错。

### 2.2 Box–Muller 高斯生成

独立 $U_1,U_2\in(0,1)$ 给：

$$
Z_1=\sqrt{-2\log U_1}\cos(2\pi U_2),\quad
Z_2=\sqrt{-2\log U_1}\sin(2\pi U_2).
$$

它们是独立标准正态，$X=\mu+\sigma Z_1$ 有目标均值和方差。实用时使用标准库生成器；手写用于理解变换，不能遗漏零端点保护。

```python
import numpy as np
rng = np.random.default_rng(42)
n = 10000
u = rng.random(n)
expo = -np.log1p(-u) / 0.5
u1 = np.maximum(rng.random(n), np.finfo(float).tiny)
u2 = rng.random(n)
normal = np.sqrt(-2*np.log(u1)) * np.cos(2*np.pi*u2)
category = np.searchsorted(np.cumsum([0.2, 0.5, 0.3]), rng.random(n), side="right")
print("指数均值/目标", expo.mean(), 2.0)
print("高斯均值、方差", normal.mean(), normal.var())
print("类别频率", np.bincount(category, minlength=3) / n)
```

均值/方差只是初步检查，还要看区间频率和直方图；两个不同分布也可能有相同均值方差。

## 3. 拒绝采样：包络必须真能盖住目标

能从提议 $q$ 采样，且知道非负目标函数 $\tilde p$，选择 $M$ 使所有支持点满足 $\tilde p(x)\le Mq(x)$：采 $x\sim q$、$u\sim U(0,1)$，若 $u<\tilde p(x)/(Mq(x))$ 则接受，否则重来。

接受后密度正比于 $q(x)\tilde p(x)/(Mq(x))=\tilde p(x)/M$。若 $\tilde p$ 已归一化，接受率 $1/M$；否则为 $Z/M$，$Z=\int\tilde p(x)dx$。不能把未归一化截断正态的接受率也说成 $1/M$。

Beta(2,5) 密度为 $30x(1-x)^4$，提议 Uniform(0,1)，最大值在 $x=1/5$，因此 $M=2.4576$，理论接受率约 0.4069。低估 M 后将接受率截成 1 会扭曲目标分布，不能补救非法包络。有限网格上找到的最大值一般不是全域上界证明。

```python
import numpy as np
rng = np.random.default_rng(42)
M = 30 * 0.2 * 0.8**4
x = rng.random(50000)
accept = rng.random(len(x)) < (30*x*(1-x)**4)/M
samples = x[accept]
print("接受率/理论", accept.mean(), 1/M)
print("Beta均值/理论", samples.mean(), 2/7)
```

截断 $N(0,1)$ 于 $[a,b]$、用区间均匀提议时，可对区间内未归一化高斯密度拒绝采样；包络是 $(b-a)\max_{[a,b]}\phi(x)$，最终目标须按 $\Phi(b)-\Phi(a)$ 归一化。高维差的包络常导致接受率极低，但“维数增加必然指数下降”不是所有提议的通则：若 $q=p$，任何维数都接受。

## 4. Monte Carlo：积分变平均，误差也要估计

若 $X_i\sim p$ 独立，$\hat\mu=N^{-1}\sum_i f(X_i)$ 估 $E_p[f(X)]$。有限一阶矩支持大数定律；有限方差下标准误估计为样本标准差除以 $\sqrt N$。$O(N^{-1/2})$ 是典型随机误差尺度，不表示每次样本扩大后误差都单调缩小，也不表示高维问题没有代价：方差常数、生成成本和稀有事件都可能随维数变差。

区间 $[a,b]$ 上的积分为 $(b-a)E[f(U)]$，$U\sim U(a,b)$。估 $\int_0^\pi\sin x\,dx=2$：

```python
import numpy as np
rng = np.random.default_rng(42)
for n in [1000, 10000, 100000]:
    values = np.pi * np.sin(rng.uniform(0, np.pi, n))
    estimate = values.mean()
    se = values.std(ddof=1) / np.sqrt(n)
    print(n, "积分", round(estimate, 6), "标准误", round(se, 6))

points = rng.random((100000, 2))
inside = np.sum(points**2, axis=1) <= 1
print("圆周率估计", 4*inside.mean())
```

圆周率例子的含义是：单位正方形里四分之一圆面积为 $\pi/4$，内部点比例估这个面积。要检查平方和而非距离线性和，面积乘 4 而非 2。来源交互图用确定性低差异点来稳定展示，这不等同于独立随机 MC，不能凭图上一次误差轨迹“证明”$N^{-1/2}$。

### 4.1 减少方差

在 $[0,1]$ 均匀积分、等长 $N$ 层、每层独立采一点 $(i+U_i)/N$ 并平均时，分层估计方差不大于相同点数的普通独立 MC。若函数在每层内为常量，才会精确；不能把“任意分段常量”都说成精确。其他分层、样本分配和错误权重不自动保证降低方差。

下面通过多次独立重复比较估计量方差，而不是比较两次偶然结果的绝对误差：

```python
import numpy as np
rng = np.random.default_rng(42)
n, trials = 50, 500
ordinary = np.sin(np.pi*rng.random((trials,n))).mean(axis=1)
strata = (np.arange(n)+rng.random((trials,n)))/n
stratified = np.sin(np.pi*strata).mean(axis=1)
print("普通/分层估计方差", ordinary.var(ddof=1), stratified.var(ddof=1))
print("两种平均/目标", ordinary.mean(), stratified.mean(), 2/np.pi)
```

反变量用 $U$ 与 $1-U$；单调函数时负相关可降低方差。控制变量 $g$ 有已知期望，估 $f-c(g-E[g])$，最优 $c=\operatorname{Cov}(f,g)/\operatorname{Var}(g)$（存在时），相关越强通常越有效。Latin hypercube 在各坐标分别分层；不等于覆盖全部高维小格。确定性低差异法是准蒙特卡洛，其误差分析与普通随机 MC 不同。

## 5. 重要性采样：换提议、保留目标

$$
E_p[f(X)]=E_q\left[f(X)\frac{p(X)}{q(X)}\right],\quad
\hat\mu=\frac1N\sum_i w_i f(x_i),\quad x_i\sim q.
$$

关键条件是 $q$ 在 $pf$ 的非零贡献处必须为正，且估计量需有相应可积性；想用有限方差标准误，还需 $E_q[(wf)^2]<\infty$。用 Uniform(-3,7) 去估整个 $N(2,1)$ 的二阶矩，会完全漏掉区间外尾部，即使答案接近 5 也不是严格无偏全域估计。应扩大并明示截断误差，或选覆盖全实数的提议。

若只知未归一化 $\tilde p$，用自归一化 $\sum_iw_if_i/\sum_iw_i$，其中 $w_i=\tilde p(x_i)/q(x_i)$。通常有限样本有偏但在条件下相合，不能保证“总比普通 IS 更稳”。权重 ESS=$ (\sum_iw_i)^2/\sum_iw_i^2$ 提示是否被少数样本支配；它与 MCMC 自相关 ESS 是不同定义。

```python
import numpy as np
rng = np.random.default_rng(42)
x = rng.normal(0, 2, 100000)  # q覆盖全实数，尺度比目标宽
logp = -0.5*x**2 - 0.5*np.log(2*np.pi)
logq = -0.5*(x/2)**2 - np.log(2) - 0.5*np.log(2*np.pi)
w = np.exp(logp-logq)
print("E标准正态X²：IS/SNIS", np.mean(w*x*x), np.sum(w*x*x)/w.sum())
print("权重ESS", w.sum()**2 / np.sum(w*w))
```

策略比 $\pi_{new}(a\mid s)/\pi_{old}(a\mid s)$ 用于在旧策略样本上评估新策略的局部目标。完整轨迹和状态分布变化还需额外处理；PPO 裁剪是优化代理目标，不是“裁剪后仍无偏”的通用重要性估计。

## 6. MCMC：不需要算归一化常数

Metropolis–Hastings 从当前 $x$ 提议 $x'\sim q(\cdot\mid x)$，以概率：

$$
\alpha=\min\left(1,\frac{\tilde p(x')q(x\mid x')}{\tilde p(x)q(x'\mid x)}\right)
$$

接受新状态，否则保留原状态。对称高斯随机游走提议可消掉 q，计算对数比即可。**拒绝时重复保留当前状态**是算法的一部分；只记录接受点会改变分布。

该规则提供详细平衡，从而保证目标为不变分布；还需可达性、非周期等条件才能讨论收敛。固定丢弃 1000 次或前 10% 不是收敛证明。多初值链、轨迹、模式切换、$\hat R$、有效样本数与估计标准误共同检查；[Stan 官方诊断](https://mc-stan.org/docs/reference-manual/analysis.html)强调有限运行的诊断和自相关。

```python
import numpy as np

def mh(log_target, x0, n=20000, warmup=2000, scale=1.0, seed=42):
    if n < 1 or warmup < 0 or scale <= 0:
        raise ValueError("样本数、预热和步长参数不合法")
    rng = np.random.default_rng(seed)
    x = np.atleast_1d(np.array(x0, dtype=float))
    logp = float(log_target(x))
    if not np.isfinite(logp):
        raise ValueError("初值必须位于有限目标密度处")
    output, accepted = [], 0
    for t in range(n+warmup):
        proposal = x + rng.normal(0, scale, x.shape)
        proposed_logp = float(log_target(proposal))
        u = max(rng.random(), np.finfo(float).tiny)
        if np.log(u) < min(0.0, proposed_logp-logp):
            x, logp = proposal, proposed_logp
            accepted += t >= warmup
        if t >= warmup:
            output.append(x.copy())
    return np.array(output), accepted/n

samples, rate = mh(lambda x: -0.5*np.dot(x,x), [4.])
print("标准正态MH均值/方差/接受率", samples.mean(), samples.var(), rate)

def target2(x):
    a, b = x
    return -(a*a*b*b+a*a+b*b-8*a-8*b)/2
points, rate2 = mh(target2, [1., 1.], scale=0.5)
print("二维目标样本形状和接受率", points.shape, rate2)
```

小步长接受率很高，却探索慢；大步长常被拒绝。0.234 是某些高维随机游走极限下的效率结论，不是所有分布、维数和采样器的目标。Thinning 可节省存储，但在固定生成次数下丢掉样本通常不能增加信息；不要把“每隔 10 点”当成消除依赖的验收。

Gibbs 轮流从 $p(x_i\mid x_{-i})$ 采样。相关标准二元高斯满足 $x\mid y\sim N(\rho y,1-\rho^2)$，随后 $y\mid x\sim N(\rho x,1-\rho^2)$，用更新后的 x。需 $|\rho|<1$；$\rho$ 接近 1 时坐标更新沿窄斜谷慢。精确条件更新不需要拒绝，但“接受率 100%”不代表独立或混合快。

```python
import numpy as np
rng = np.random.default_rng(42)
rho = 0.8
x=y=0.; samples=[]
for t in range(22000):
    x = rng.normal(rho*y,np.sqrt(1-rho*rho))
    y = rng.normal(rho*x,np.sqrt(1-rho*rho))
    if t>=2000:
        samples.append([x,y])
samples=np.array(samples)
print("均值/协方差", samples.mean(axis=0), np.cov(samples,rowvar=False))
```

目标均值为0，协方差对角为1、非对角为0.8；有限链有误差，不能把“精确条件抽样”误读成整体有限链没有误差。

连续平滑高维目标可考虑梯度型 HMC/NUTS；条件容易采时可用 Gibbs；简单目标可用 MH。判断由目标几何、梯度成本和诊断决定，不用“超过固定维数就必须换”的硬阈值。

## 7. 文本生成：温度、top-k、top-p

温度 $T>0$ 时 $q_i\propto\exp(z_i/T)$。减小 T 放大 logit 差；增加 T 使分布更平。$T=0$ 要在实现中单独走 greedy，不能直接除零；最大 logit 并列时，$T\to0$ 的分布仍可在并列项上有质量，greedy 如何打破并列需另定。

Top-k 保留 k 个最高项；top-p 保留按概率排序后累计至少达阈值 p 的最小前缀，都要重新归一化。例 $(0.60,0.25,0.10,0.05)$：top-2 给 $(0.7059,0.2941,0,0)$；top-p=0.9 保留前三项，必须保留**跨过阈值的那一项**。

```python
import numpy as np

def token_distribution(logits, temperature=1., k=None, nucleus=1.):
    z = np.asarray(logits, dtype=float)
    if z.ndim != 1 or z.size == 0 or not np.isfinite(z).all():
        raise ValueError("logits需要非空有限向量")
    if temperature < 0 or not 0 < nucleus <= 1:
        raise ValueError("温度非负、top-p在(0,1]内")
    if k is not None and not 1 <= k <= z.size:
        raise ValueError("top-k超出词表范围")
    if temperature == 0:
        out = np.zeros_like(z); out[np.argmax(z)] = 1
        return out
    shifted = (z-z.max()) / temperature
    p = np.exp(shifted); p /= p.sum()
    order = np.argsort(-p, kind="stable")
    if k is not None:
        order = order[:k]
    retained = p[order] / p[order].sum()
    cutoff = min(len(order), np.searchsorted(np.cumsum(retained), nucleus, side="left")+1)
    chosen = order[:cutoff]
    result = np.zeros_like(p)
    result[chosen] = p[chosen]/p[chosen].sum()
    return result

rng = np.random.default_rng(42)
vocab = np.array(["the","cat","sat","on","mat","a","dog","ran","big","red"])
logits = [3.,2.5,2.,1.8,1.5,1.,0.5,0.,-0.5,-1.]
for options in [{"temperature":0.}, {"temperature":0.7}, {"k":3}, {"nucleus":0.9}]:
    p = token_distribution(logits, **options)
    print(options, "非零候选", (p>0).sum())
    for _ in range(5):
        print(" ".join(rng.choice(vocab, 20, p=p)))
```

这里每一步 logits 固定，是观察分布与多样性的玩具；真实语言模型会随上下文重算。组合过滤的顺序会影响结果，本实现先温度、后 top-k、再在剩余集做 top-p；具体服务实现需查文档。没有普遍最佳温度区间；greedy 可重复不代表事实可靠，top-p 也不保证连贯或正确。按任务评测质量、失败率和多样性。

## 8. 可微采样：重参数化与离散松弛

高斯重参数化把参数移进确定性变换：$\epsilon\sim N(0,1)$，$z=\mu+\sigma\epsilon$。固定噪声后，$\partial z/\partial\mu=1$、$\partial z/\partial\sigma=\epsilon$。若网络输出 $v=\log\sigma^2$，则 $\sigma=e^{v/2}$、$\partial z/\partial v=\epsilon\sigma/2$。

这提供路径导数；在交换求导与期望的条件下，可估 $\nabla E[f(z)]$。随机性本身不代表永远无法求梯度：还可用 score-function 等估计器，但方差和适用条件不同。离散 argmax 通常不可直接路径求导。

```python
import numpy as np
mu, logvar, epsilon = 2., 0.5, -0.3
def draw(m,v):
    return m+np.exp(v/2)*epsilon
h=1e-5
numeric_mu=(draw(mu+h,logvar)-draw(mu-h,logvar))/(2*h)
numeric_v=(draw(mu,logvar+h)-draw(mu,logvar-h))/(2*h)
print("均值导数/解析", numeric_mu, 1.)
print("log方差导数/解析", numeric_v, 0.5*np.exp(logvar/2)*epsilon)
```

固定同一个 epsilon 才是在检查路径导数；每次差分重采不同噪声会把随机变化混进梯度。

Gumbel-Max 使用独立 $g_i=-\log(-\log U_i)$，返回 $\arg\max_i(\log p_i+g_i)$，得到精确类别样本。已有 logits 时也可直接加 $g_i$，因为归一化常数不影响 argmax；不能把可能为负的 logits 当作概率再求 log。

Gumbel-Softmax 用 $y_i=\operatorname{softmax}((z_i+g_i)/\tau)$ 代替硬 argmax。有限 $\tau$ 返回可微连续向量，低温近似 one-hot，却有松弛偏差与梯度方差取舍。Straight-through 让前向硬、反向软，是有偏估计；在自动微分框架中可用 `hard - soft.detach() + soft` 表达计算图，普通 NumPy 同时返回 hard/soft 并没有自动建立梯度。

```python
import numpy as np
rng = np.random.default_rng(42)
p = np.array([0.5, 0.3, 0.15, 0.05])
u = np.clip(rng.random((20000, len(p))), np.finfo(float).tiny, 1-np.finfo(float).eps)
g = -np.log(-np.log(u))
noisy = np.log(p) + g
chosen = noisy.argmax(axis=1)
print("Gumbel-Max频率", np.bincount(chosen, minlength=4)/len(chosen))
for tau in [0.1, 0.5, 1., 5.]:
    scores = (noisy[0]-noisy[0].max())/tau
    soft = np.exp(scores); soft /= soft.sum()
    print("温度", tau, "软样本", soft.round(5))
```

连续重参数化支撑 VAE 的训练，离散松弛用于离散潜变量、操作选择等；不能保证任意离散决策都用同一松弛能成功。[Gumbel-Softmax 原论文](https://arxiv.org/abs/1611.01144)区分精确离散采样与可微近似。

## 9. 信息量、熵与编码直觉

一个离散事件的自信息 $I(x)=-\log p(x)$；越罕见越意外。以 2 为底，公平硬币一个结果为 1 bit，公平骰子指定点为 $\log_2 6\approx2.585$ bit，概率 0.001 为约 9.966 bit。

离散熵是平均意外 $H(P)=-\sum_i p_i\log p_i$。约定 $0\log0=0$；有限 K 类最大为 $\log K$，均匀时取得。确定结果熵 0，0.99/0.01 硬币约 0.08079 bit。编码下界是特定理想编码与长序列平均意义，并非说单个符号可使用任意小数 bit 的文件。

自然对数单位 nat，1 nat=$1/\ln2$ bit；1 bit=$\ln2$ nat。连续微分熵 $h(X)=-\int f\log f$ 可为负，并随坐标尺度变化，例如 Uniform(0,0.1) 的 $h=\ln0.1$。离散非负与有限类别上界不能原样套到连续变量。

## 10. 交叉熵、KL 和最大似然是一条线

真实分布 P、模型 Q 给：

$$
H(P,Q)=-\sum_i p_i\log q_i,\quad
D_{KL}(P\|Q)=\sum_i p_i\log\frac{p_i}{q_i},\quad
H(P,Q)=H(P)+D_{KL}(P\|Q).
$$

P 固定且量有定义时，最小化交叉熵等价于最小化这个方向的 KL。$p_i>0,q_i=0$ 时损失无穷；不能跳过此项。KL 非负但不对称、不满足距离所需全部性质。离散 $P=(0.9,0.1)$、$Q=(0.5,0.5)$ 两方向 KL 分别约 0.5310 与 0.7370 bit。

单样本 one-hot 目标时，CE=$-\log q_y$。多个条件独立观测的对数似然是逐样本 $\log q_{y_i}$ 之和，所以最小化平均 CE 等于最大化相应似然。Softmax 与 CE 合并的 logit 梯度为 $q_i-p_i$（单样本自然对数），因此真实类概率越低，改正信号越大。

Label smoothing 使用 $p'=(1-\epsilon)\operatorname{onehot}(y)+\epsilon/K$；4 类 $\epsilon=0.1$、真类为 2，目标为 `(0.025,0.025,0.925,0.025)`。损失为 $(1-\epsilon)CE(onehot,q)+\epsilon CE(uniform,q)$，后项是均匀目标的**交叉熵**，不是模型自身熵。它可限制极端置信，但是否改善校准要实测，不能当成保证。

蒸馏常把老师输出作为软目标；VAE 的 KL、RL 中熵奖励也使用这些量，但目标和 KL 方向不同。JS=$\tfrac12 KL(P\|M)+\tfrac12 KL(Q\|M)$，$M=(P+Q)/2$，对称且 base-2 时在 $[0,1]$，JS 本身与 $\sqrt{JS}$ 的距离性质要区分。Wasserstein 更关心支持位置和搬运几何，详见主入口，不与 KL 互换。

## 11. 联合熵、条件熵和互信息

对于离散变量：

$$
H(X,Y)=H(X)+H(Y\mid X),\quad
I(X;Y)=H(X)+H(Y)-H(X,Y)=D_{KL}(p(x,y)\|p(x)p(y)).
$$

两变量各 1 bit、联合表 `[[0.45,0.05],[0.05,0.45]]` 时，知道 X 后，Y 有 90% 同值概率，因此条件熵为二元熵 $h_2(0.1)\approx0.4690$，互信息约 0.5310 bit，联合熵约 1.4690 bit。相互独立的 0.25 表则联合熵 2、条件熵 1、互信息 0。这样即可理解来源的“信息重叠”图，不需依赖图的摆放记公式。

MI 能描述非线性依赖，但有限样本估计要选离散化、近邻等方法，会有偏差、参数敏感和成本，不能说“MI 检测一切且准确无条件”。单独排名还会漏掉特征交互：独立公平 $X_1,X_2$、目标 $Y=X_1\operatorname{XOR}X_2$ 时，各单特征 MI 为 0，却联合完全决定 Y。特征筛选必须只在训练数据上拟合，避免泄漏。

```python
import numpy as np

def distribution(p):
    p = np.asarray(p, dtype=float)
    if p.size == 0 or not np.isfinite(p).all() or (p < 0).any() or not np.isclose(p.sum(), 1):
        raise ValueError("概率必须非负、有限且和为1")
    return p

def entropy(p, base=2.):
    if base <= 0 or base == 1:
        raise ValueError("对数底需为正且不能等于1")
    p = distribution(p)
    positive = p > 0
    return -(p[positive]*np.log(p[positive])).sum()/np.log(base)

def cross_entropy(p, q, base=2.):
    if base <= 0 or base == 1:
        raise ValueError("对数底需为正且不能等于1")
    p, q = distribution(p), distribution(q)
    if p.shape != q.shape:
        raise ValueError("两分布形状必须一致")
    mask = p > 0
    if (q[mask] == 0).any():
        return np.inf
    return -(p[mask]*np.log(q[mask])).sum()/np.log(base)

def mutual_information(joint):
    joint = distribution(joint)
    if joint.ndim != 2:
        raise ValueError("需要二维联合表")
    return entropy(joint.sum(axis=1)) + entropy(joint.sum(axis=0)) - entropy(joint)

p, q = [0.9,0.1], [0.5,0.5]
print("KL两个方向", cross_entropy(p,q)-entropy(p), cross_entropy(q,p)-entropy(q))
print("相关表互信息", mutual_information([[0.45,0.05],[0.05,0.45]]))
print("支持集缺失CE", cross_entropy([0.5,0.5], [1.,0.]))
```

## 12. Perplexity：平均损失的指数

序列长度 N，按实际 token 计平均负对数似然：

$$
\operatorname{PPL}=\exp\left[-\frac1N\sum_t\log q(y_t\mid y_{<t})\right].
$$

相当于真实 token 条件概率几何平均值的倒数；若每步均匀在 K 类中选，则 PPL=K。它不是每一步实际保留 K 个候选，也不是每句错误数。每步平均 CE 为 $\ln50$ 的模型，PPL 为 50。

不同 tokenizer、评估语料、上下文窗口、掩码和损失加权方式，会使 PPL 不可直接比较；没有普遍“PPL 低于 10 就最先进”的标准。合并不同长度序列时按有效 token 数加权，不能直接平均各句 PPL。极差预测也可使 PPL 大于词表大小。

完整函数可把[分布章](10-概率分布与贝叶斯推断.md)的 `log_softmax` 加入同一脚本后计算：

```python
import numpy as np

def sequence_perplexity(labels, logits):
    if len(labels) != len(logits) or len(labels) == 0:
        raise ValueError("需要非空等长标签与预测")
    losses = []
    for target, z in zip(labels, logits):
        z = np.asarray(z, float)
        if z.ndim != 1 or z.size == 0 or not np.isfinite(z).all():
            raise ValueError("每步logits需为非空有限向量")
        if not isinstance(target, (int, np.integer)) or not 0 <= target < len(z):
            raise ValueError("真实标签索引越界")
        shifted = z-z.max()
        log_probs = shifted-np.log(np.exp(shifted).sum())
        losses.append(-log_probs[target])
    return float(np.exp(np.mean(losses)))

print(sequence_perplexity([0,1], [[0.,0.],[0.,0.]]))  # 2.0
```

## 13. 自查与原任务练习的判断标准

1. 采 Cauchy 后平均值没有稳定下来，要不要删极端值？**答案：**不能为了“验证均值”删。该分布无有限均值/方差，改看中位数、分位数和密度；删尾部会改目标。
2. Beta(2,5) 拒绝采样的理论接受率为何不是 0.5？**答案：**$1/M=1/2.4576\approx0.4069$，由目标最大密度决定。
3. 如何验证 MC 的误差尺度？**答案：**对每个 N 做多次独立重复，计算 RMSE或平均标准误，再比较 N 增 4 倍后的尺度；不能要求一次实现误差严格减半。
4. 二维 MH 提议步长调大，接受率变低是否一定更差？**答案：**需结合自相关、模式访问、ESS/时间判断。仅接受率不能排名；从不同初值比较 `target2` 的分布和轨迹。
5. 10 词 20 token 的生成例子为何没有语义连贯性？**答案：**固定 logits 只展示抽样，未用上下文模型。比较五次运行的候选支持、重复比例与序列差异，不编造“生成质量”。
6. 26 个等概率字母的熵是多少？**答案：**$\log_2 26\approx4.70044$ bit。不均匀真实频率的单字母熵不大于此值；真实语言依赖还可进一步降低每字母条件熵。
7. Logits `[5,2,0.5]`、真类 1 的 CE？**答案：**$\log(e^5+e^2+e^{0.5})-2\approx3.059114$ nat。有限 logits 的 Softmax 每类仍有正质量，one-hot 真类损失只能趋近 0；软目标匹配时最小 CE 等于目标熵，不是 0。
8. KL 能否对称化后直接叫欧氏距离？**答案：**不能。JS/平方根JS与 Wasserstein 有各自性质和几何含义。
9. 信息量函数接受 p=-0.1 应返回无穷吗？**答案：**这是非法概率，应拒绝输入；合法 p=0 对实际发生事件自信息无穷，熵里的零质量项按极限为0。
