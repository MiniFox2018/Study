# 09｜复数、傅里叶与频域理解

> 先修：向量点积、正弦余弦、Python/NumPy。按“复数旋转 → DFT → 频谱读数 → 卷积 → 窗口与 STFT”学习。最后把旋转连到位置编码。音频、图像纹理和周期时间序列都能用这些工具，但频谱有峰不直接证明真实因果周期。

## 1. 复数把平面向量与旋转写成一种运算

复数 $z=a+bi$，$i^2=-1$，几何上对应点 $(a,b)$ 或从原点指向它的向量；实数是虚部为零的特例。加法是向量相加，乘法同时旋转和缩放。

$$
(a+bi)+(c+di)=(a+c)+(b+d)i,
$$

$$
(a+bi)(c+di)=(ac-bd)+(ad+bc)i.
$$

共轭 $\bar z=a-bi$ 是沿实轴反射，$z\bar z=a^2+b^2=|z|^2$；除法通过乘分母共轭得到

$$
\frac{a+bi}{c+di}
=\frac{ac+bd}{c^2+d^2}+\frac{bc-ad}{c^2+d^2}i,
\qquad c+di\ne0.
$$

例如 $(3+2i)(1+4i)=-5+14i$；$(5+2i)/(1-3i)=-0.1+1.7i$。下面用数对从头实现，再以 Python 内建复数核对：

```python
import math

def add(z, w):
    return z[0]+w[0], z[1]+w[1]

def multiply(z, w):
    a, b = z
    c, d = w
    return a*c-b*d, a*d+b*c

def divide(z, w):
    a, b = z
    c, d = w
    denominator = c*c+d*d
    if denominator == 0:
        raise ZeroDivisionError("复数分母为零")
    return (a*c+b*d)/denominator, (b*c-a*d)/denominator

assert multiply((3, 2), (1, 4)) == (-5, 14)
r, im = divide((5, 2), (1, -3))
assert abs(complex(r, im)-(5+2j)/(1-3j)) < 1e-12
print("复数算术核对通过")
```

此简式只适合普通量级；巨大分母的平方会溢出，极小量级会下溢，实际程序优先使用内建 `complex` 和成熟库。模用 `abs(z)`、共轭用 `z.conjugate()`；`cmath.phase(z)` 给弧度相位，`cmath.polar(z)` 给极坐标。数组用 `np.abs/angle/conj/real/imag`，区分复数元素和仅保存实部的数组类型。

## 2. 极坐标、Euler 公式与相量

非零复数可以写成 $z=re^{i\theta}$，$r=\sqrt{a^2+b^2}$，$\theta=\operatorname{atan2}(b,a)$。不要用 `atan(b/a)` 替代 `atan2`：前者在 $a=0$ 出问题且不能区分象限。零的相位没有唯一数学含义；相位还具有 $2\pi$ 周期。

$$
e^{i\theta}=\cos\theta+i\sin\theta,
\quad (r_1e^{i\theta_1})(r_2e^{i\theta_2})=r_1r_2e^{i(\theta_1+\theta_2)}.
$$

乘 $e^{i\theta}$ 就是纯旋转：

$$
(x+iy)e^{i\theta}
=(x\cos\theta-y\sin\theta)+i(x\sin\theta+y\cos\theta).
$$

这与实矩阵 $R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$ 完全对应。乘 $i$ 是逆时针 90°，乘两次是 180°，所以 $i^2=-1$。$e^{i\pi}+1=0$ 是数学恒等式，浮点代码可能残留约 $10^{-16}$ 虚部，要用容差。

相量 $Ae^{i(\omega t+\phi)}$ 表示匀速转动的箭头：模为振幅、角度为相位、角速度为 $\omega=2\pi f$；实部是余弦信号，虚部是正弦信号。相同频率的正弦波相加可通过相量相加来简化；不同频率要保留不同的时间指数，不能把时间依赖丢掉。

```python
import cmath
import math
import numpy as np

z = 3+4j
rotated = z*cmath.exp(1j*math.pi/4)
matrix = np.array([[math.cos(math.pi/4), -math.sin(math.pi/4)],
                   [math.sin(math.pi/4), math.cos(math.pi/4)]])
assert np.allclose([rotated.real, rotated.imag], matrix @ [3, 4])
assert math.isclose(abs(rotated), 5)
point = 1+0j
for _ in range(12):
    point *= cmath.exp(1j*math.pi/6)
assert abs(point-1) < 1e-12
print("旋转后的点：", rotated, "十二次旋转后：", point)
```

## 3. 单位根为什么构成傅里叶的基础

$N$ 次单位根 $\omega_k=e^{2\pi ik/N},k=0,\ldots,N-1$ 是单位圆上等角间隔的 $N$ 个点，间隔 $2\pi/N$，满足 $\omega_k^N=1$。$N=4$ 时是 $1,i,-1,-i$。乘原始单位根 $e^{2\pi i/N}$，每个点走到下一个。

对 $N>1$，全部根之和为零；$N=1$ 唯一根为 1，和不是零。更关键的是

$$
\sum_{n=0}^{N-1}e^{2\pi i(k-\ell)n/N}
=\begin{cases}N&k\equiv\ell\pmod N,\\0&\text{否则。}\end{cases}
$$

这是有限几何级数：比率不为 1 时，分子 $1-r^N=0$，分母 $1-r\ne0$。不同频率的**长度为 $N$ 的复正弦向量**因此正交，而不只是“圆上的 N 个标量点互相正交”。正交性支撑 DFT 的逆公式。

## 4. 从时间/空间表示到 DFT 频率坐标

对 $N$ 个离散样本，采用与 NumPy 默认相同的约定：

$$
X[k]=\sum_{n=0}^{N-1}x[n]e^{-2\pi ikn/N},
\qquad x[n]=\frac1N\sum_{k=0}^{N-1}X[k]e^{2\pi ikn/N}.
$$

DFT 把信号投影到不同复正弦方向。对应频率存在时，随时间旋转的乘积倾向同向累积；无此频率时，绕一圈相互抵消。负号是前向约定，逆向反号并除 $N$；不同书或库的归一化可能不同，不能混用。

在数学精确算术中完整 DFT/IDFT 可逆，信息没有丢失；浮点程序只能近似重建。只留幅度、删掉频率或量化才会丢信息。相位决定信号的排列和时移，不能一律说“不重要”。

连续时间傅里叶变换可写为 $X(f)=\int x(t)e^{-2\pi ift}dt$，它不是直接对数组调用的 DFT；FFT 则是计算 DFT 的算法。傅里叶级数用于周期函数的整数谐波展开，三者共享基函数思想但对象不同。满足相应条件的方波可写

$$
\operatorname{square}(t)=\frac4\pi\left[\sin(2\pi t)+\tfrac13\sin(6\pi t)+\tfrac15\sin(10\pi t)+\cdots\right].
$$

前几个奇数谐波叠加会逐渐形成平顶和陡边，跳跃附近有 Gibbs 过冲；不能宣称有限项处处重建方波。源图中要读出“各灰色谐波合成蓝色总波形”，正确奇数系数是 $1,1/3,1/5,1/7$，而不是只改图中默认某个滑杆就得精确方波。

### 频谱每个位置是什么意思

采样率 $f_s$、采样间隔 $\Delta t=1/f_s$、观测时长 $T=N/f_s$。频率格间隔 $\Delta f=f_s/N=1/T$。

- $X[0]=\sum_nx[n]$ 是 DC，均值为 $X[0]/N$。
- 正频率索引 $k$ 的频率为 $kf_s/N$；超过正频率范围后解释为 $(k-N)f_s/N$。
- 偶数 $N$ 有一个 Nyquist bin $k=N/2$，对应 $f_s/2$；奇数 $N$ 没有恰好在 Nyquist 的 bin。
- 实输入满足 $X[N-k]=\overline{X[k]}$，正负频率重复，`rfft` 只保存非负部分。复输入通常没有这项共轭对称，不能只留半谱。

建议用 `np.fft.fftfreq(N,d=1/fs)` 或 `rfftfreq` 生成频率坐标，用 `fftshift` 同时平移频谱与坐标后画双边谱。不要把输出索引直接叫 Hz。

### 振幅、相位、能量和功率谱不能混称

对恰好落在格点的实余弦 $A\cos(2\pi kn/N+\phi)$，非 DC、非 Nyquist 系数 $|X[k]|=NA/2$，单边振幅为 $2|X[k]|/N$；DC/Nyquist 不乘 2。正弦系数相位会比同初始相位余弦少 $\pi/2$。

原始 $|X[k]|^2$ 常称功率谱读数，但其大小依归一化、长度和窗口。默认 DFT 下 Parseval 为 $\sum_n|x[n]|^2=(1/N)\sum_k|X[k]|^2$；平均功率还需再除 $N$。功率谱密度还要按采样率和窗能量标定，不能把未归一化平方系数直接当作带单位的 PSD。

## 5. 从头 DFT 与 radix-2 FFT

直接 DFT 每个输出加 $N$ 项，一共有 $N$ 个输出，成本 $O(N^2)$。Cooley–Tukey 的基 2 版本把样本分成偶数和奇数索引两半，递归变换得到 $E,O$：

$$
X[k]=E[k]+e^{-2\pi ik/N}O[k],\qquad
X[k+N/2]=E[k]-e^{-2\pi ik/N}O[k].
$$

每层合并为 $O(N)$，层数 $\log_2N$，所以总成本 $O(N\log N)$。$N\log N$ 是增长量级，不是逐条计数的复乘次数，更不等于实际加速倍数。

下面是完整标准库实现，并对照 NumPy。**仅此教学 radix-2 实现要求长度为 2 的幂**；实际 FFT 库支持其他长度，混合基数、Bluestein 等算法可以处理非 2 的幂，不必一律补到下一个 2 的幂。

```python
import cmath
import math
import numpy as np

def dft(values, inverse=False):
    values = [complex(v) for v in values]
    n = len(values)
    if n == 0:
        raise ValueError("变换长度需大于零")
    sign = 1 if inverse else -1
    result = [sum(values[j]*cmath.exp(sign*2j*math.pi*k*j/n)
                  for j in range(n)) for k in range(n)]
    return [v/n for v in result] if inverse else result

def fft2(values):
    n = len(values)
    if n == 0 or n & (n-1):
        raise ValueError("教学 radix-2 FFT 要求正的二次幂长度")
    if n == 1:
        return [complex(values[0])]
    even, odd = fft2(values[::2]), fft2(values[1::2])
    twiddled = [cmath.exp(-2j*math.pi*k/n)*odd[k] for k in range(n//2)]
    return [even[k]+twiddled[k] for k in range(n//2)] + [
            even[k]-twiddled[k] for k in range(n//2)]

def ifft2(values):
    conjugated = [complex(v).conjugate() for v in values]
    n = len(values)
    return [v.conjugate()/n for v in fft2(conjugated)]

rng = np.random.default_rng(11)
x = rng.normal(size=64)
slow, fast = dft(x), fft2(x)
assert np.allclose(slow, fast, atol=1e-10)
assert np.allclose(fast, np.fft.fft(x), atol=1e-10)
assert np.allclose(ifft2(fast), x, atol=1e-10)
assert np.allclose(dft(dft([1, 2, 3]), inverse=True), [1, 2, 3], atol=1e-12)
assert np.isclose(np.sum(x*x), np.sum(np.abs(fast)**2)/len(x))
print("DFT、FFT、逆变换与能量核对通过")
```

频率识别可独立运行：

```python
import numpy as np

fs, n = 32.0, 32
t = np.arange(n)/fs  # 不用 linspace 默认包含末端的写法
x = np.sin(2*np.pi*3*t)+0.5*np.sin(2*np.pi*7*t)
X = np.fft.rfft(x)
frequencies = np.fft.rfftfreq(n, d=1/fs)
amplitudes = np.abs(X)/n
amplitudes[1:-1] *= 2  # 此例 n 为偶数，最后一项是 Nyquist
assert np.allclose(amplitudes[[3, 7]], [1, 0.5], atol=1e-12)
assert np.allclose(np.fft.irfft(X, n=n), x)
print("两峰频率：", frequencies[[3, 7]], "振幅：", amplitudes[[3, 7]])
```

奇数长度单边谱的最后一个点也是普通正频率，需要乘 2；`irfft` 最好显式给原始长度，避免奇偶长度解释混淆。重要程序可对多个非 2 次幂长度与噪声信号重复核对。

## 6. 卷积定理：先分清循环与线性卷积

长度 $N$ 的循环卷积 $y[n]=\sum_mx[m]h[(n-m)\bmod N]$，自然对应 $\operatorname{IFFT}(\operatorname{FFT}(x)\operatorname{FFT}(h))$。它在边界绕回；普通线性卷积长度为 $N+M-1$，需把两输入都补到至少此长度才不混叠。

例如 $x=[1,2,3,4]$、$h=[1,1,1]$，线性结果为 $[1,3,6,9,7,4]$；若都变成长度 4，循环结果为 $[8,7,6,9]$，尾部回到头部，二者并不相同。

```python
import numpy as np

def linear_fft_convolution(x, h):
    x, h = np.asarray(x, dtype=float), np.asarray(h, dtype=float)
    if x.ndim != 1 or h.ndim != 1 or x.size == 0 or h.size == 0:
        raise ValueError("输入需为非空一维实信号")
    length = len(x)+len(h)-1
    X, H = np.fft.rfft(x, n=length), np.fft.rfft(h, n=length)
    return np.fft.irfft(X*H, n=length)

x, h = [1, 2, 3, 4], [1, 1, 1]
linear = linear_fft_convolution(x, h)
circular = np.fft.ifft(np.fft.fft(x, 4)*np.fft.fft(h, 4)).real
assert np.allclose(linear, [1, 3, 6, 9, 7, 4])
assert np.allclose(linear, np.convolve(x, h))
assert np.allclose(circular, [8, 7, 6, 9])
print("线性卷积：", linear, "循环卷积：", circular)
```

真实工作可用 `scipy.signal.fftconvolve` 并明确 `full/same/valid` 输出规则；性能上用 `scipy.fft.next_fast_len` 选择较快填充长度，不必严格取 2 次幂。长核时 FFT 法常有优势，小 3×3 核可能直接法、Winograd 等更快，不能由复杂度直接断言 CNN 都用 FFT。

CNN 层多数实现的是**互相关**，不翻转核；数学卷积需翻转或匹配约定。频域相关也涉及共轭与索引约定，不应把两者写成完全同一运算。二维图像 FFT 是空间频率变换，频谱方向和强度反映纹理、边缘等结构，可理解滤波而非只限音频。

## 7. DFT 性质是实际调试工具

在上面的默认归一化下：

| 性质 | 公式与用途 |
|---|---|
| 线性 | $\mathcal F(ax+by)=aX+bY$；叠加信号的频谱也叠加 |
| 循环时间移位 | $x[(n-r)\bmod N]\leftrightarrow X[k]e^{-2\pi ikr/N}$；幅度不变、相位改变 |
| 频率移位 | $x[n]e^{2\pi iqn/N}\leftrightarrow X[(k-q)\bmod N]$；整数 $q$ 的格移位 |
| 循环卷积 | $x\circledast h\leftrightarrow XH$ |
| 逐点乘法 | $xh\leftrightarrow (X\circledast H)/N$；窗口会在频域卷积频谱 |
| 实输入共轭对称 | $X[N-k]=\overline{X[k]}$ |
| Parseval | $\sum|x|^2=\sum|X|^2/N$；检查归一化和能量 |

只看幅度无法区分某些时移；重建、对齐、相干信号、滤波和图像处理都需要相位。相位在幅度接近零处往往受噪声主导，不应解释那里的角度为稳定结构。

## 8. 泄漏、窗口、零填充与混叠

### 8.1 泄漏与窗口的代价

有限截取可视为原信号乘矩形窗；DFT 使用该片段的周期延拓。非整数周期的片段边界通常不连续，单频能量散到多个格点，这叫谱泄漏。不是额外真实频率突然出现，也不能只看两个端点值判断所有泄漏。

Hann 对称窗 $w[n]=\tfrac12[1-\cos(2\pi n/(N-1))]$，Hamming 为 $0.54-0.46\cos(2\pi n/(N-1))$。频谱分析也常用周期窗，将分母改成 $N$；二者适用任务与端点不同。

| 窗 | 主瓣/旁瓣的取舍 | 选择方式 |
|---|---|---|
| 矩形 | 主瓣窄、旁瓣高 | 整周期格点信号或更重视近峰分离时可用 |
| Hann | 更宽主瓣、较低旁瓣 | 常见通用折中 |
| Hamming | 改变近旁瓣抑制 | 部分语音/谱分析，依目标选 |
| Blackman | 通常更宽主瓣、更低旁瓣 | 强弱频率并存、抑制旁瓣重要时考虑 |

窗不是“把信号两端必都变成零”：Hamming 端点并非零。窗口抑制旁瓣却使主峰变宽，也改变振幅和能量。对落在频率格点、远离 DC/Nyquist 的正弦，单边振幅可用 $2|X_w[k]|/\sum_nw[n]$ 校正 coherent gain；靠近特殊频率、离格点或多峰重叠还需更细分析。

### 8.2 零填充不增加原始观测的信息

观测 $T=N/f_s$ 秒，用 $L>N$ 点 FFT 会把格间隔变为 $f_s/L$，但只在同一有限记录的频谱上取更密的读数；原始能分开多近的频率仍受 $T$、窗主瓣、信噪比和估计方法影响。$1/T$ 是传统谱格尺度，不是所有参数化估计都不可突破的绝对定理。

```python
import numpy as np

fs, n = 128, 128
t = np.arange(n)/fs
x = np.sin(2*np.pi*10.3*t)+0.2*np.sin(2*np.pi*12.7*t)
window = 0.5-0.5*np.cos(2*np.pi*np.arange(n)/n)  # 周期 Hann
for length in (128, 1024):
    spectrum = np.fft.rfft(x*window, n=length)
    frequency = np.fft.rfftfreq(length, d=1/fs)
    peak = frequency[np.argmax(np.abs(spectrum))]
    print("FFT 长度、格间隔、最大峰位置：", length, fs/length, peak)
```

这里零填充让峰的位置读数更细，不能据此说已获得八倍真实分辨率。若想更稳定区分两个近频率，应延长真实记录或采用经过验证的模型。对 1 秒、128 Hz、恰为 10 Hz 与 12 Hz 的整周期两音，矩形窗本来可在各自格点分离，Hann 不一定更好；不能把源练习设成永远“Hann 胜出”的选择题。

### 8.3 混叠在采样前已经发生

采样率 $f_s$ 使 $f$ 与 $f+kf_s$ 的离散复指数相同，实信号还可在正负频率之间折叠。对带限连续信号，可靠重建需采样率超过最高频率两倍并满足相应条件；正好在 Nyquist 的正弦可能采成全零，不能保证恢复振幅和相位。

90 Hz 余弦以 100 Hz 采样，与 10 Hz 余弦相同；90 Hz **正弦**的样本是 10 Hz 正弦的负值，即相位相差 $\pi$，不能笼统说两者逐样本完全相同。只观察采样数组不能确定原信号是高频还是低频，需要采样前的低通/带限知识。

抗混叠应发生在降采样之前：ADC 的模拟低通，或数字降采样前低通滤波。图像/特征图下采样也会混叠；采样后再 FFT 不能追回已经折叠的信息。

## 9. STFT 和谱图：频率何时出现

整段 FFT 说明整段有哪些频率，不能直接指出各频率出现的时间。STFT 先把信号切成重叠短窗，每窗乘窗口并 FFT，得到复矩阵 $Z[k,m]$；$k$ 为频率，$m$ 为时间帧。$|Z|^2$ 的展示通常称谱图，复 STFT 本身还含相位。

窗长决定局部观察时间和频率尺度，hop 决定帧间距；hop 小不等于提高真实时间事件分辨力。长窗容易分近频率但混合时间变化，短窗追踪变化快却频率主瓣宽。常见 1024 窗、256 hop 只是一组示例，需结合采样率换算为秒。

下面完整 NumPy 教学程序构造前半 8 Hz、后半 24 Hz 的信号，检查时间帧上的主频变化；无补边，仅保留完整帧：

```python
import numpy as np

fs = 128
t = np.arange(256)/fs
x = np.where(t < 1, np.sin(2*np.pi*8*t), np.sin(2*np.pi*24*t))
window_size, hop = 64, 16
window = 0.5-0.5*np.cos(2*np.pi*np.arange(window_size)/window_size)
starts = np.arange(0, len(x)-window_size+1, hop)
frames = np.stack([x[start:start+window_size]*window for start in starts])
Z = np.fft.rfft(frames, axis=1).T  # 频率 × 时间帧
frequencies = np.fft.rfftfreq(window_size, d=1/fs)
times = (starts+(window_size-1)/2)/fs
dominant = frequencies[np.argmax(np.abs(Z), axis=0)]
assert dominant[0] == 8 and dominant[-1] == 24
print("STFT 形状：", Z.shape, "首尾主频：", dominant[0], dominant[-1])
```

跨越切换点的窗口会混合两频率，这是窗口观测范围，不是算法错误。实际用 `scipy.signal` 或音频框架时还需明确窗定义、补边、帧对齐、归一化及逆变换条件；保留复系数并满足重叠重建条件时才可讨论恢复波形，单幅度谱图不直接保证重建。

mel 特征把功率谱加权到不同间隔的滤波频带，再做 log 等处理，强调感知相关的频率尺度；不是简单“把 FFT 横坐标改名”。音频模型的输入特征还涉及采样率、帧长、mel 带数、log/归一化约定，换模型必须按其规范。FNet 用傅里叶变换混合 token 是仍有启发的架构思路，但历史实验数字不作为当前最优模型结论。

## 10. 位置编码：频率指纹与 RoPE 的相对角度

对偶数模型维度 $d$，原始 Transformer 的正弦位置编码为

$$
\operatorname{PE}(p,2j)=\sin(p\omega_j),\quad
\operatorname{PE}(p,2j+1)=\cos(p\omega_j),\quad
\omega_j=10000^{-2j/d}.
$$

成对的正弦、余弦可视为同一个单位复指数的两个坐标（顺序是 sin、cos，而不是直接等同 real、imag 的 cos、sin 顺序）。高频变化快，低频变化慢，给位置提供多个尺度。它借用了频率基函数思想，但不是把位置序列做 DFT 后得到的频谱。

每对完整编码的点积为 $\sin(p\omega)\sin(q\omega)+\cos(p\omega)\cos(q\omega)=\cos((p-q)\omega)$，所以整体

$$
\operatorname{PE}(p)^{\mathsf T}\operatorname{PE}(q)=\sum_j\cos((p-q)\omega_j)
$$

仅依赖位移，且是偶函数；它随距离可能振荡，不保证单调下降，也不保证有限精度中无限多位置完全可区分。固定偏移的 PE 可以由每对二维线性旋转得到，供模型学习相对关系；加入 token 内容、投影和其他计算后，完整注意力并不自动仅依赖位置差。

RoPE 把 query/key 的成对坐标直接旋转：$q'_m=R(m\omega)q_m$，$k'_n=R(n\omega)k_n$，则

$$
(q'_m)^{\mathsf T}k'_n=q_m^{\mathsf T}R((n-m)\omega)k_n.
$$

相对位置出现在旋转角，内容向量仍参与点积。多对坐标用不同频率，二维复乘只是实现方式，也可用纯实矩阵；不要求整个模型变成复值模型。RoPE 数学延展到长位置不保证训练外长上下文成绩，频率缩放与外推能力需另行验证。

```python
import numpy as np

def pe(position, d=16):
    omega = 10000.0**(-2*np.arange(d//2)/d)
    encoding = np.empty(d)
    encoding[0::2], encoding[1::2] = np.sin(position*omega), np.cos(position*omega)
    return encoding

assert np.isclose(pe(2) @ pe(7), pe(20) @ pe(25))
def rotate(vector, angle):
    c, s = np.cos(angle), np.sin(angle)
    return np.array([c*vector[0]-s*vector[1], s*vector[0]+c*vector[1]])

q, k, m, n, omega = np.array([1., 2.]), np.array([3., -1.]), 2, 7, 0.3
assert np.isclose(rotate(q,m*omega) @ rotate(k,n*omega),
                  q @ rotate(k,(n-m)*omega))
print("PE 等位移点积与 RoPE 相对旋转核对通过")
```

1. $(2+3i)(4-i)$ 与 $(5+2i)/(1-3i)$？**答案：**$11+10i$、$-0.1+1.7i$；可用数对与内建复数交叉核对。

4. 在 256、512、1024 等长度测直接 DFT 与 FFT 时间。**验收：**结果在容差内相等，并报告设备、实现、长度和测量次数；复杂度比例不是实测秒数。
5. 为什么 $X[0]$ 不能直接叫平均值？**答案：**当前正变换无归一化，它是 $N$ 倍平均值。
6. 对长度 4 的循环卷积算例按嵌套循环核对 $y[0]$。**答案：**$1+4+3=8$，并对照不绕回的线性卷积首项 1。
