## 1. 矩阵运算：相同数字，不同乘法

矩阵 $A\in\mathbb R^{m\times n}$ 有 $m$ 行、$n$ 列。加减法逐位置进行；标量乘法把每个元素都乘同一个数。矩阵乘法则组合线性映射：

$$
(AB)_{ij}=\sum_{k=1}^n A_{ik}B_{kj},\qquad
(m\times n)(n\times p)=(m\times p).
$$

设 $A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$B=\begin{bmatrix}5&6\\7&8\end{bmatrix}$。逐元素乘法 $A\circ B=\begin{bmatrix}5&12\\21&32\end{bmatrix}$，矩阵乘法 $AB=\begin{bmatrix}19&22\\43&50\end{bmatrix}$。左上角的 $19=1\cdot5+2\cdot7$ 是第一行与第一列的点积。NumPy 中两者分别为 `A * B` 和 `A @ B`。

下面可以脱离 NumPy 理解内部计算，不把矩阵乘法当黑箱：

```python
def shape(A):
    if not A or not A[0] or any(len(row) != len(A[0]) for row in A):
        raise ValueError("矩阵必须是非空、等长的二维行列表")
    return len(A), len(A[0])

def matmul(A, B):
    m, n = shape(A)
    n2, p = shape(B)
    if n != n2:
        raise ValueError("矩阵乘法的内维不匹配")
    return [[sum(A[i][k] * B[k][j] for k in range(n))
             for j in range(p)] for i in range(m)]

A, B = [[1, 2], [3, 4]], [[5, 6], [7, 8]]
print(matmul(A, B))  # [[19, 22], [43, 50]]
```

转置满足 $(A^T)_{ij}=A_{ji}$，把行列交换。$(AB)^T=B^TA^T$；逆矩阵也按相反顺序 $(AB)^{-1}=B^{-1}A^{-1}$。单位矩阵 $I$ 对角为 1、其他为 0，满足 $AI=A$、$IA=A$，但左右单位矩阵的尺寸可能不同。

手写三层循环解释原理；实际计算使用优化后的 BLAS/LAPACK。不要把“固定快 100 倍”当保证，速度还取决于规模、内存布局、线程和设备。

## 2. 几何变换与组合顺序

二维矩阵的列说明两个标准基向量被送到哪里。单位正方形的四个角 $(0,0),(1,0),(1,1),(0,1)$ 经线性变换后成为平行四边形或退化图形。这提供一个比查看所有元素更直接的理解方式。

令 $c=\cos\theta,s=\sin\theta$：

| 操作 | 矩阵 | 作用与条件 |
|---|---|---|
| 逆时针旋转 | $\begin{bmatrix}c&-s\\s&c\end{bmatrix}$ | 保持长度和夹角，$R^TR=I,\det R=1$ |
| 轴向缩放 | $\operatorname{diag}(s_x,s_y)$ | $(x,y)\mapsto(s_xx,s_yy)$，零尺度会丢失方向 |
| 横向剪切 | $\begin{bmatrix}1&k\\0&1\end{bmatrix}$ | $(x,y)\mapsto(x+ky,y)$，面积保持 |
| 纵向剪切 | $\begin{bmatrix}1&0\\k&1\end{bmatrix}$ | $(x,y)\mapsto(x,y+kx)$，面积保持 |
| 关于 $y$ 轴反射 | $\operatorname{diag}(-1,1)$ | 翻转横坐标，保持长度、翻转方向 |
| 关于 $x$ 轴反射 | $\operatorname{diag}(1,-1)$ | 翻转纵坐标 |

`[[1,kx],[ky,1]]` 同时含两个非零剪切参数时，行列式为 $1-k_xk_y$，不再是行列式为 1 的单次标准剪切，也不同于把两个标准剪切直接相乘。不能从“有剪切形状”推断面积一定保持。

先旋转后缩放是 $SRx$；从右向左读作用顺序。例如 $R$ 旋转 $90^\circ$、$S=\operatorname{diag}(2,0.5)$，对 $(1,0)$：$SRx=(0,0.5)$，$RSx=(0,2)$。矩阵乘法通常不交换。多个变换合成一个矩阵后可重复作用于很多点。

```python
import numpy as np

def rotation(theta):
    c, s = np.cos(theta), np.sin(theta)
    return np.array([[c, -s], [s, c]])

square = np.array([[0., 0.], [1., 0.], [1., 1.], [0., 1.]])
R = rotation(np.pi / 2)
S = np.diag([2., 0.5])
print(np.round(square @ R.T, 6))
print(np.round(S @ R @ [1., 0.], 6))  # [0.  0.5]
print(np.round(R @ S @ [1., 0.], 6))  # [0.  2. ]
assert np.allclose(np.linalg.norm(square[1:] - square[0], axis=1),
                   np.linalg.norm((square @ R.T)[1:] - (square @ R.T)[0], axis=1))
```

正方形旋转结果为 `[[0,0],[0,1],[-1,1],[-1,0]]`。点放在行里，所以批量写 `square @ R.T`，与列向量公式保持一致。

三维绕坐标轴的右手旋转为

$$
R_x=\begin{bmatrix}1&0&0\\0&c&-s\\0&s&c\end{bmatrix},\quad
R_y=\begin{bmatrix}c&0&s\\0&1&0\\-s&0&c\end{bmatrix},\quad
R_z=\begin{bmatrix}c&-s&0\\s&c&0\\0&0&1\end{bmatrix}.
$$

对 $(1,0,0)$，绕 $z$ 轴 $90^\circ$ 得 $(0,1,0)$，绕 $y$ 轴得 $(0,0,-1)$，绕 $x$ 轴不变。图片坐标的纵轴常朝下，视觉上的旋转方向可能与数学坐标不同，先声明约定。

平移 $y=Ax+b$ 是仿射变换；齐次坐标把它写成 $\begin{bmatrix}A&b\\0&1\end{bmatrix}\begin{bmatrix}x\\1\end{bmatrix}$。非线性激活后的网络不能仅靠这一个矩阵描述整个映射。

## 3. 行列式与逆：可逆性不等于稳定性

二维行列式 $\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$。绝对值是面积缩放比，符号表示定向是否翻转。一般方阵的行列式描述体积缩放，满足 $\det(AB)=\det(A)\det(B)$。

| 数值 | 解释 |
|---|---|
| $\det A=0$ | 至少一个方向被压扁，方阵不可逆 |
| $|\det A|=1$ | 体积保持，可能有剪切或各方向反向伸缩 |
| $\det A<0$ | 定向翻转，不表示一定是纯反射 |
| $\det A\ne0$ | 数学上可逆，不保证舍入误差小 |

例如 $\operatorname{diag}(10^8,10^{-8})$ 行列式为 1，但不同方向放大差异极大。不要用行列式大小替代条件数。

二维逆矩阵：

$$
A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}.
$$

例如 $A=\begin{bmatrix}4&7\\2&6\end{bmatrix}$，$\det A=10$，$A^{-1}=\begin{bmatrix}0.6&-0.7\\-0.2&0.4\end{bmatrix}$，乘回得到 $I$。

三阶手算可用代数余子式 $C_{ij}=(-1)^{i+j}\det(A\text{ 删除第 }i\text{ 行、第 }j\text{ 列})$，然后 $A^{-1}=C^T/\det A$。例如上三角矩阵 $\begin{bmatrix}1&1&0\\0&1&1\\0&0&1\end{bmatrix}$ 的逆为 $\begin{bmatrix}1&-1&1\\0&1&-1\\0&0&1\end{bmatrix}$。这是理解逆矩阵的练习方法；递归展开大矩阵行列式代价很高，工程求解不要照此实现。

## 4. 特征值：不变直线与对角化的条件

非零向量 $v$ 满足 $Av=\lambda v$ 时为特征向量。正特征值保持箭头方向，负特征值反向，零特征值把它映射到零。稳定不变的是它张成的直线；不能无条件说“方向完全不变”。

二维特征方程：

$$
\det(A-\lambda I)=\lambda^2-\operatorname{tr}(A)\lambda+\det A=0.
$$

对 $\begin{bmatrix}2&1\\1&2\end{bmatrix}$，特征值为 3 与 1，对应方向 $(1,1)$、$(1,-1)$。沿对角线伸长 3 倍，反对角线保持。对 $\begin{bmatrix}4&2\\1&3\end{bmatrix}$，方程 $\lambda^2-7\lambda+10=0$，特征值 5、2，对应方向 $(2,1)$、$(1,-1)$。

若 $n\times n$ 方阵有 $n$ 个独立特征向量，可写 $A=V\Lambda V^{-1}$。$V^{-1}$ 先换到特征基坐标，$\Lambda$ 缩放，$V$ 再换回来。一般 $V$ 不正交，这个换基不是普通旋转。实对称矩阵可以选正交特征基，使用 `np.linalg.eigh`；一般方阵用 `np.linalg.eig`。

不是所有矩阵都可对角化。$\begin{bmatrix}1&1\\0&1\end{bmatrix}$ 只有一条独立特征方向。二维 $90^\circ$ 旋转没有实特征向量，复特征值为 $\pm i$。一般矩阵出现复特征值表示存在旋转式动力学，但不能直接把 `atan2(虚部,实部)` 当作原欧氏坐标中每个向量的实际旋转角度。

在线性递推 $x_t=Ax_{t-1}$ 中，谱半径 $\rho(A)<1$ 保证 $A^t\to0$；$\rho(A)>1$ 表示存在增长方向，特定初值若完全没有该方向分量仍可能不增长。非正规矩阵还可能短期放大。非线性 RNN 的梯度取决于激活导数和各步 Jacobian 的乘积，不能只检查一个权重矩阵的特征值。

协方差特征向量用于 PCA；图 Laplacian 的特征向量用于谱聚类。二者都需要相应的对称性、图构造或数据条件，不把所有图神经网络都概括成邻接矩阵特征值算法。

## 5. $Ax=b$：先判断是否有解、是否唯一

行视角：每一行给一个约束。例如 $2x+y=5,x-y=1$ 的两条线相交于 $(2,1)$。列视角：寻找列向量的线性组合，$2(2,1)+(1,-1)=(5,1)$。

对于任意矩形 $A$：

- $b\in\operatorname{col}(A)$ 当且仅当存在精确解；等价地，增广矩阵 $[A\mid b]$ 与 $A$ 的秩相同。
- 已存在一个解 $x_0$ 时，全部精确解是 $x_0+z$，其中 $z\in\ker(A)$。
- 存在且 $\ker(A)=\{0\}$ 才是唯一精确解。

高矩阵可能有精确解，例如 $A=\begin{bmatrix}1\\2\end{bmatrix},b=(3,6)^T$；宽矩阵也可能无解，例如零矩阵与非零 $b$。未知数和方程的数量只是第一步，秩与一致性才决定结论。

## 6. 高斯消元、选主元与三角回代

消元用等价行操作把方程变成上三角。每列选当前行以下绝对值最大的元素作为主元，交换行，再用倍数相减把主元下方清零。部分选主元限制乘子大小，通常改善稳定性；不能保证任意矩阵都没有误差放大。

例子

$$
\begin{bmatrix}2&1&1\\4&3&3\\2&3&1\end{bmatrix}x
=\begin{bmatrix}8\\20\\12\end{bmatrix}.
$$

为方便手算，先不交换行：第二行减两倍第一行得 $(0,1,1\mid4)$；第三行减第一行得 $(0,2,0\mid4)$；第三行再减两倍第二行得 $(0,0,-2\mid-4)$。逆序回代：$x_3=2,x_2=2,x_1=2$。代码做部分选主元后中间矩阵可能不同，解应相同。

```python
import numpy as np

def gaussian_solve(A, b):
    A = np.asarray(A, dtype=float)
    b = np.asarray(b, dtype=float)
    n = A.shape[0]
    if A.shape != (n, n) or b.shape != (n,):
        raise ValueError("本示例只处理方阵与一维右端项")
    Ab = np.column_stack([A, b])
    tol = np.finfo(float).eps * n * np.linalg.norm(A, ord=np.inf)
    for k in range(n):
        pivot = k + np.argmax(np.abs(Ab[k:, k]))
        Ab[[k, pivot]] = Ab[[pivot, k]]
        if abs(Ab[k, k]) <= tol:
            raise ValueError("主元过小，改用秩分析或最小二乘求解")
        for i in range(k + 1, n):
            multiplier = Ab[i, k] / Ab[k, k]
            Ab[i, k:] -= multiplier * Ab[k, k:]
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (Ab[i, -1] - Ab[i, i + 1:n] @ x[i + 1:]) / Ab[i, i]
    return x

A = np.array([[2., 1., 1.], [4., 3., 3.], [2., 3., 1.]])
b = np.array([8., 20., 12.])
x = gaussian_solve(A, b)
print(x)  # [2. 2. 2.]
assert np.allclose(A @ x, b)
assert np.allclose(x, np.linalg.solve(A, b))
```

上三角回代每次使用已经算出的后续未知数；下三角前代每次使用之前的未知数，都是 $O(n^2)$。完整稠密消元是 $O(n^3)$。给出的容差是教学用数值保护，不是问题真实误差的完整模型。

## 7. LU：一次分解，多次求解

带行置换写为 $PA=LU$，$L$ 是单位下三角、记录消元乘子，$U$ 是消元结果，$P$ 记录行交换。解方程时依次解 $Ly=Pb$、$Ux=y$。

同一个 $A$、多个 $b$ 时，只分解一次。稠密方阵分解约 $2n^3/3$ 浮点操作，每个新右端项再用两次三角求解。不能每次重新计算逆矩阵。

```python
import numpy as np

def lu_factor_scratch(A):
    U = np.array(A, dtype=float, copy=True)
    n = U.shape[0]
    if U.shape != (n, n):
        raise ValueError("本示例只处理方阵")
    P, L = np.eye(n), np.eye(n)
    tol = np.finfo(float).eps * n * np.linalg.norm(U, np.inf)
    for k in range(n):
        p = k + np.argmax(np.abs(U[k:, k]))
        U[[k, p]], P[[k, p]] = U[[p, k]], P[[p, k]]
        L[[k, p], :k] = L[[p, k], :k]  # 之前存的乘子也必须交换。
        if abs(U[k, k]) <= tol:
            raise ValueError("主元过小")
        for i in range(k + 1, n):
            L[i, k] = U[i, k] / U[k, k]
            U[i, k:] -= L[i, k] * U[k, k:]
    return P, L, U

A = np.array([[0., 1.], [2., 3.]])
P, L, U = lu_factor_scratch(A)
assert np.allclose(P @ A, L @ U)
b = np.array([1., 5.])
# 这里用成熟 solve 展示两段求解；三角前代、回代可按上一节自行替换。
x = np.linalg.solve(U, np.linalg.solve(L, P @ b))
print(x)  # [1. 1.]
```

实际可使用 SciPy 的 `lu_factor`、`lu_solve` 复用分解。不要将库返回的 pivot 索引当成这里的显式 $P$，两者存储方式不同。

## 8. QR 与最小二乘：把残差正交分解

最小二乘求 $\min_x\|Ax-b\|_2^2$，适用于不一致、秩亏和普通一致系统，不局限于“方程多于未知数”。残差 $r=Ax-b$ 在最优点满足

$$
A^Tr=0\quad\Longleftrightarrow\quad A^TAx=A^Tb.
$$

这是正规方程，由梯度 $2A^T(Ax-b)$ 为零得到。拟合值 $Ax$ 是 $b$ 向列空间的正交投影；参数是否唯一取决于是否满列秩。

满列秩、$m\ge n$ 时，约化 QR 为 $A=QR$，$Q$ 为 $m\times n$、$Q^TQ=I_n$，$R$ 为可逆上三角。解 $Rx=Q^Tb$，无需形成 $A^TA$。

```python
import numpy as np
A = np.column_stack([np.ones(4), np.arange(1., 5.)])
b = np.array([3., 5., 6., 8.])
Q, R = np.linalg.qr(A, mode="reduced")
x = np.linalg.solve(R, Q.T @ b)
residual = A @ x - b
print(np.round(x, 6))         # [1.5 1.6]
print(np.round(residual, 6))  # [ 0.1 -0.3  0.3 -0.1]
print(np.round(residual @ residual, 6))  # 0.2
assert np.allclose(A.T @ residual, 0.)
assert np.allclose(x, np.linalg.lstsq(A, b, rcond=None)[0])
```

这里 $A^Tb=(22,63)^T$、$A^TA=\begin{bmatrix}4&10\\10&30\end{bmatrix}$，解的斜率是 **1.6**，不是来源某处误写的 1.7。正规方程可以教学推导，实际优先 `lstsq` 或 QR。若秩亏，$R$ 可能不可逆，改用 SVD / 最小范数解。`lstsq` 返回的 residuals 数组为空也不表示残差为零；宽矩阵或秩亏时应自己计算 `A @ x - b`。

## 9. Cholesky、正定性与岭回归

实对称正定矩阵满足 $x^TAx>0$ 对所有非零 $x$ 成立，可分解 $A=LL^T$，$L$ 下三角且对角为正。递推公式为

$$
L_{ii}=\sqrt{A_{ii}-\sum_{k<i}L_{ik}^2},\qquad
L_{ij}=\frac{A_{ij}-\sum_{k<j}L_{ik}L_{jk}}{L_{jj}}quad(i>j).
$$

例子 $A=\begin{bmatrix}4&2\\2&5\end{bmatrix}$，$L=\begin{bmatrix}2&0\\1&2\end{bmatrix}$。求解时先 $Ly=b$，再 $L^Tx=y$。分解成本约 $n^3/3$，约为一般 LU 的一半；墙钟耗时还依赖实现、规模和硬件，不能用 Python 循环计时保证“恰好两倍快”。

协方差矩阵和 $X^TX$ 是半正定，秩不足时不能直接 Cholesky。凸函数的 Hessian 在光滑、内点等条件下半正定，但不一定正定，例如 $f(x)=x^4$ 在零点二阶导数为零。有效核的 Gram 矩阵通常半正定，重复数据点可能使它奇异；加入正的对角噪声后才得到常用的严格正定系统。

岭回归最小化 $\|Xw-y\|_2^2+\lambda\|w\|_2^2$，$\lambda>0$ 时

$$
(X^TX+\lambda I)w=X^Ty.
$$

因为 $v^T(X^TX+\lambda I)v=\|Xv\|_2^2+\lambda\|v\|_2^2>0$，可以用 Cholesky。若 $X$ 的最大/最小奇异值为 $\sigma_{max},\sigma_{min}$，包含零方向时也按零计，则

$$
\kappa_2(X^TX+\lambda I)
=\frac{\sigma_{max}^2+\lambda}{\sigma_{min}^2+\lambda}.
$$

平方不可漏掉；正则化改了估计目标，也不保证任意很小的 $\lambda$ 都足以使系统良态。常规回归一般不惩罚截距；应先中心化数据，把截距单独恢复，或把截距对应惩罚设为零。

```python
import numpy as np
X = np.array([[1., 1.], [2., 2.], [3., 3.]])  # 特征重复。
y = np.array([2., 4., 6.])
lam = 1.0
G = X.T @ X + lam * np.eye(2)
L = np.linalg.cholesky(G)
w = np.linalg.solve(L.T, np.linalg.solve(L, X.T @ y))
print(np.round(w, 6))  # [0.965517 0.965517]
print(np.linalg.cond(G))  # 约 29
assert np.allclose(L @ L.T, G)
print(round(2 * np.log(np.diag(L)).sum(), 6))  # log(det(G))，约 3.367296。
```

高斯过程常用这样的分解计算 $K\alpha=y$，以及 $\log\det K=2\sum_i\log L_{ii}$。数值上不要先算可能上溢/下溢的行列式再取对数。

## 10. 伪逆、条件数与求解验证

SVD 伪逆 $A^+=V\Sigma^+U^T$ 给出所有最小二乘解中欧氏范数最小的解；完整构造见[降维专题](03-SVD-PCA与降维.md)。对于欠定系统 $x_1+x_2=2$，最小范数解是 $(1,1)$，而 $(2,0)$ 也是精确解但长度更大。

非奇异方阵的二范数条件数 $\kappa_2(A)=\sigma_{max}/\sigma_{min}$。仅扰动右端项时有上界

$$
\frac{\|\Delta x\|_2}{\|x\|_2}
\le\kappa_2(A)\frac{\|\Delta b\|_2}{\|b\|_2}.
$$

这是最坏方向的相对误差上界，不是每次误差必定放大该倍数。粗略估计可能损失 $\log_{10}\kappa$ 位精度，实际取决于噪声、方向、算法和浮点格式；“条件数小于 100 一定安全”没有普遍成立的精度标准。

真实可复算的敏感性例子：

```python
import numpy as np
eps = 1e-8
A = np.array([[1., 1.], [1., 1. + eps]])
b = np.array([2., 2. + eps])
x = np.linalg.solve(A, b)
x_perturbed = np.linalg.solve(A, b + np.array([0., eps]))
print(np.round(x, 6))            # [1. 1.]
print(np.round(x_perturbed, 6))  # 约 [0. 2.]
print(np.linalg.cond(A))         # 约 4e8，矩阵仍然可逆。
```

几何上两条约束线几乎平行，右端项微小变化让交点大幅移动。满列秩时 $\kappa_2(A^TA)=\kappa_2(A)^2$，因此正规方程可能进一步丢失精度。QR/SVD 改善计算途径，却不能消除数据本身的不确定性。

求解后同时检查：残差 $\|Ax-b\|$、归一化后向误差 $\|Ax-b\|/(\|A\|\|x\|+\|b\|)$、条件数，以及最小二乘的 $A^T(Ax-b)$。残差小而条件数大时，参数仍可能离真值很远。没有真值时不能把“各库算出同样答案”称为估计真实正确。

## 11. 共轭梯度：稀疏大系统迭代求解

CG 要求实对称正定；只需要乘法 $Ap$，不必显式存稠密矩阵。残差 $r=b-Ax$，搜索方向 $p$。每步用

$$
\alpha=\frac{r^Tr}{p^TAp},\quad x\leftarrow x+\alpha p,
\quad r_{new}=r-\alpha Ap,\quad
\beta=\frac{r_{new}^Tr_{new}}{r^Tr},\quad
p\leftarrow r_{new}+\beta p.
$$

“共轭”指不同搜索方向在 $A$ 内积下正交，可以避免不断破坏前面的最优进展。精确算术最多 $n$ 步收敛，浮点数中不保证如此，可能需更多迭代、预条件和真实残差检查。

```python
import numpy as np

def cg(A, b, rtol=1e-10, max_iter=None):
    A, b = np.asarray(A, float), np.asarray(b, float)
    n = len(b)
    if A.shape != (n, n) or not np.allclose(A, A.T):
        raise ValueError("CG 要求对称方阵；正定性还需要另外确认")
    x = np.zeros(n)
    r = b.copy()
    p = r.copy()
    rr = r @ r
    threshold = rtol * np.linalg.norm(b)
    if np.sqrt(rr) <= threshold:
        return x, 0, True  # b=0 时先退出，避免 0/0。
    for step in range(max_iter or 10 * n):
        Ap = A @ p
        denominator = p @ Ap
        if denominator <= 0:
            raise ValueError("遇到非正曲率，CG 条件不成立或发生数值失效")
        alpha = rr / denominator
        x += alpha * p
        r -= alpha * Ap
        new_rr = r @ r
        if np.sqrt(new_rr) <= threshold:
            return x, step + 1, True
        p = r + (new_rr / rr) * p
        rr = new_rr
    return x, step + 1, False

A = np.array([[4., 1.], [1., 3.]])
b = np.array([1., 2.])
x, steps, converged = cg(A, b)
print(np.round(x, 6), steps, converged)  # [0.090909 0.636364] 2 True
assert np.linalg.norm(A @ x - b) < 1e-9
```

稀疏矩阵每步约 $O(\mathrm{nnz}(A)+n)$，$k$ 步约 $O(k(\mathrm{nnz}+n))$；不能再额外乘一个 $n$。预条件矩阵 $M\approx A$ 应便于求 $Mz=r$ 并保持相应正定性，例如对角预条件或不完全 Cholesky。一般不完全 LU 未必适合标准 CG，非对称系统可考虑 GMRES/BiCGSTAB。

## 12. 选择方法与实践验收

| 输入条件 | 通常的起点 | 需核查的边界 |
|---|---|---|
| 非零对角矩阵 | 逐项相除，$O(n)$ | 零或很小的对角 |
| 非奇异三角矩阵 | 前代/回代，$O(n^2)$ | 稀疏结构还能减成本 |
| 一般稠密非奇异方阵 | 带主元 LU / `solve` | 条件数、重复右端项 |
| 对称正定 | Cholesky | 对称但不定应考虑带主元 LDL 分解 |
| 高矩阵、满列秩最小二乘 | QR / `lstsq` | 正规方程平方条件数 |
| 秩亏或需最小范数 | SVD / `lstsq` | 奇异值阈值决定保留方向 |
| 大型稀疏正定 | CG + 合适预条件 | 收敛状态、真实残差 |
| 一般稀疏 | 稀疏 LU、GMRES 等 | 直接法填充可能使内存增加 |
| 带状矩阵 | 带状专用求解 | 带宽 $w$ 的复杂度通常约 $O(nw^2)$ |

一般稠密 $m\times n$ 完整 SVD 成本约 $O(mn\min(m,n))$；高矩阵 QR 约 $O(mn^2)$。不要用矩阵维数的固定阈值代替实际内存和结构判断。`100000×100000` 稠密 float64 系数存储本身约 80 GB，稀疏矩阵的求解也不保证“几秒完成”。

动手练习：

1. 解 `[[1,2,3],[4,5,6],[7,8,10]] x = [6,15,27]`。**答案：**$(3,-3,3)$，三行分别得到 6、15、27；用消元、LU、`solve` 验证，不以整数四舍五入隐藏误差。
2. 对一个固定随机 `50×5` 满列秩矩阵，用正规方程、QR、SVD 和 `lstsq` 求解同一带噪目标。**判断标准：**解接近且最优残差一致；再把两列改得几乎相同，观察正规方程偏差与条件数平方，不预先假设一定发生某个固定误差。
3. 用 9～10 节例子比较岭回归：增加 $\lambda$ 后参数范数一般缩小、训练残差可能增大。**答案要点：**稳定性与拟合目标发生权衡，正则不是无损修复。
4. 生成 $A=M^TM+\lambda I$ 验证 CG，对比 $I+0.1M^TM/n$ 的迭代数。**判断标准：**记录种子、实际残差、收敛标志和条件数；不要把最多 $n$ 步的精确算术定理强加给浮点输出。
5. 对比 LU/Cholesky 耗时。**判断标准：**使用相同精度和成熟库、分别计分解与复用求解、重复测量；理论操作量的一半不等于设备上必定一半耗时。
