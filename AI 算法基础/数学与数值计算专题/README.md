## 怎样使用代码和答案

每个小例子先预测shape、结果或走势，再运行和修改一个条件。答案只核对当前例子的假设；没有看过原站也应能解释为什么成立。遇到失败先记录输入、库版本和错误，不通过无目标地升级所有依赖“修好”。

正文区分标准库/NumPy例子、需要第三方库的例子、依赖硬件的模板。只在验收记录标为实际执行的部分算本次运行验证；第三方包、CUDA、长期训练未运行的内容另列边界。
