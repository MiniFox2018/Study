# 11｜统计估计、检验与实验判断

> 目标：知道一个模型“提高了 2 个百分点”能说明多少，以及还需要什么证据。先修：[概率分布](10-概率分布与贝叶斯推断.md)的期望、方差、独立性和中心极限定理。顺序：先描述数据和确认抽样单位，再估计区间、选择检验，最后讨论收益与实验风险。

## 1. 描述数据：先看位置、波动和尾部

数据 `[1,2,3,4,1000]` 的均值为 202、中位数为 3。两者没有谁普遍“更正确”：均值适合总成本、总量与平均损失；中位数更贴近典型个体，且对极端值稳健。众数适合类别中最常见取值；多个并列众数应说明，不能任意选一个而当成唯一答案。

若这些值是完整目标总体，方差使用 $\sum_i(x_i-\mu)^2/N$；若为独立同分布样本、要估计总体方差，则：

$$
s^2=\frac{\sum_i(x_i-\bar x)^2}{n-1},\quad n\ge2.
$$

原因是样本均值也由这 $n$ 个数估出来，中心化残差只有 $n-1$ 个自由度。有限方差条件下 $s^2$ 无偏；标准差 $s$ 不因此自动无偏。一个观测不能估样本方差。不同软件中的 `ddof` 要明确。

分位数用来描述尾部：P50 是中位数，P95/P99 可检查慢请求。IQR=$Q_{0.75}-Q_{0.25}$ 描述中间 50% 的跨度，比最大值减最小值稳定。小样本分位数有多种插值定义，应记录方法；5 个样本计算 P99 几乎就是最大值附近的插值，不能假装精确尾延迟。

完整描述至少包括样本量、缺失比例、单位、均值/中位数、波动和重要尾分位。错误率、延迟和费用常有偏态，图形和分组统计比单个均值更能暴露问题。箱线图的异常点是检查线索，不是自动删数据的理由。

## 2. 相关、协方差与特征结构

Pearson 系数为：

$$
r=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum_i(x_i-\bar x)^2\sum_i(y_i-\bar y)^2}}.
$$

它衡量线性共同变化，范围 $[-1,1]$，有一个变量恒定时分母为零、相关未定义，不能说“相关为 0”。计算系数本身不要求正态；某些精确 p 值和区间推导才需要分布假设。[SciPy 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html)区分了描述系数与检验。

Spearman 先把数值换成秩，再对秩计算 Pearson。并列值取平均秩。例如 $x=(1,2,3,4)$、$y=x^3$ 单调但非线性，Spearman=1，Pearson 小于 1。$X$ 关于 0 对称、$Y=X^2$ 则可以 Pearson=0 却完全依赖。相关不推出因果：季节同时影响销量和溺水；数据筛选或共同驱动因素也能制造关联。

若数据矩阵 $X\in\mathbb R^{n\times d}$ 每行一个样本，中心化后协方差矩阵为 $C=X_c^TX_c/(n-1)$。对角项是方差、非对角项是协方差；$C$ 对称半正定。PCA 找它的特征向量以表示最大方差方向；标准化后协方差对应相关矩阵。请明确行列约定，原来源代码使用“每行一个特征”，与常见表格约定相反。

```python
import numpy as np
from scipy import stats
x = np.array([1., 2., 3., 4.])
y = x ** 3
xc, yc = x - x.mean(), y - y.mean()
r = (xc @ yc) / np.sqrt((xc @ xc) * (yc @ yc))
print("Pearson", round(r, 6))
print("Spearman", stats.spearmanr(x, y).statistic)
print("协方差", np.cov(np.column_stack([x, y]), rowvar=False))
```

## 3. 抽样决定推断能否代表目标

先问“希望结论适用于谁”，再问“这些人怎样进入数据”。随机抽样让每个总体单位有已知机会；分层抽样在各群体内抽样、汇总时按总体权重；系统抽样每隔固定间隔取一个，需防止与周期重合；整群抽样抽学校、家庭或用户群，再抽群内记录，必须考虑群内依赖。

100 万条来自 1000 个用户的记录，不等于 100 万个独立用户。评估用户层面效果应按用户聚合或用户级重采样。时间序列需要时间切分，不能把未来信息放进训练。单个医院数据也不直接代表所有医院。增加样本量通常缩小随机误差，无法自动纠正选择偏差、缺失群体和标签系统误差。

## 4. 点估计、标准误与区间

标准差描述**个体波动**；标准误描述**估计量的抽样波动**。独立、有限方差下，均值标准误估计为 $s/\sqrt n$。同一标准差下，样本增为 4 倍，均值标准误约减半。

若观测近似正态、总体方差未知，均值的 95% t 区间为：

$$
\bar x\pm t_{n-1,0.975}\frac{s}{\sqrt n}.
$$

总体标准差已知可用正态分位数；大样本时有时用 1.96 近似。小样本不应直接把估计的 $s$ 塞进正态区间而声称精确。对于 5 个观测 `[8,9,10,11,12]`，均值 10、$s^2=2.5$、SE=$\sqrt{0.5}$，$t_{4,0.975}\approx2.776$，区间约 `[8.037,11.963]`。

频率置信区间的 95% 是重复抽样程序的覆盖率，不能把未知固定参数解释成在此次固定区间内随机游走。贝叶斯可信区间则在所用模型与先验下有后验概率含义。区间很窄也可能因抽样偏差而整体错位；还应报告抽样机制和模型。

## 5. 检验：把反事实假设变成可核验问题

步骤是：预先定义总体、指标和零假设 $H_0$；选择备择方向、统计量和显著性水平 $\alpha$；在 $H_0$ 与其他模型条件下求“至少一样极端”的概率；再解释拒绝或不拒绝的含义。

$p=0.03$ 表示：若零假设及检验条件成立，这样或更极端的统计量出现概率为 3%。它不表示 $H_0$ 有 3% 概率为真、结果有 97% 概率可重复，也不证明效应真实。$p\ge\alpha$ 是证据不足，不是“证明没有差别”。若要支持“差别小于实际可接受范围”，应设计等效性检验并预先定义范围。

第一类错误是 $H_0$ 真实却拒绝；第二类错误是效应存在却未拒绝。功效是**在指定效应、样本量、方差和设计下**拒绝错误零假设的概率，不能脱离效应大小只谈“这个实验功效高”。

## 6. 选择检验：根据数据单位与目标

| 问题 | 常用方法 | 需要检查 |
|---|---|---|
| 一个总体均值与参考值比较 | 单样本 t | 独立观测、差异尺度与重尾 |
| 两个独立群体均值比较 | Welch t | 独立、有限方差；无需相等方差 |
| 同一对象两次连续测量 | 配对 t | **差值**的独立性与正态近似 |
| 多个独立组均值 | ANOVA / Welch ANOVA | 经典 ANOVA 的方差齐性、残差与事后比较 |
| 独立组有序/连续分布 | Mann–Whitney / Kruskal–Wallis | 测试分布/排序差异；非自动“中位数检验” |
| 配对差值的秩检验 | Wilcoxon signed-rank | 差值分布对称、并列及零差值处理 |
| 配对二分类结果 | McNemar / 精确二项 | 同一案例两模型的**不一致对** |
| 类别频数与指定分布 | 卡方拟合优度 | 独立次数、期望频数、估计参数耗用自由度 |
| 类别列联表关联 | 卡方独立性 / Fisher 精确 | 群体单位与稀疏格子 |
| 连续分布比较 | KS | 独立观测；参考分布是否由本数据估计 |
| 复杂指标区间 | Bootstrap | 抽样单位、依赖、退化重采样及偏差 |

“非参数”表示不指定某个有限参数分布族，**不表示没有假设**。Wilcoxon 有对称性条件，秩检验也不能纠正依赖。[官方 Wilcoxon 说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html)给出差值检验的条件。检验选择不应只按“$n<30$ 就换一个”，也不应在多种方法中挑最小 p 值。

### 6.1 t 统计量怎样计算

单样本 $t=(\bar x-\mu_0)/(s/\sqrt n)$，自由度 $n-1$。两个独立组 Welch 为：

$$
t=\frac{\bar x_1-\bar x_2}{\sqrt{s_1^2/n_1+s_2^2/n_2}},\quad
\nu=\frac{(s_1^2/n_1+s_2^2/n_2)^2}{(s_1^2/n_1)^2/(n_1-1)+(s_2^2/n_2)^2/(n_2-1)}.
$$

配对情况先形成 $d_i=b_i-a_i$，再对差值做单样本检验。两组任意独立重排会丢掉配对。零标准误时统计量退化，不能强行返回 t=0 代表没有差异。

真实检验使用可靠库求尾概率，不把来源中的自写不完全 Beta/Gamma 数值近似当成正式统计计算。手算的价值是理解“效应除以不确定性”。

### 6.2 卡方小算例

观察 `[120,80]`，参考期望 `[100,100]`，$\chi^2=20^2/100+(-20)^2/100=8$。若参考二类比例事先指定，自由度 1，p 约 0.004678。若期望中的参数由本数据估计，自由度还需调整；期望为 0 的格子不能静默忽略。卡方显著说明分布与参考不一致，不自动说明模型更好。

```python
import numpy as np
from scipy import stats
data = np.array([8., 9., 10., 11., 12.])
se = data.std(ddof=1) / np.sqrt(data.size)
ci = data.mean() + np.array([-1., 1.]) * stats.t.ppf(0.975, data.size-1) * se
print("均值95%区间", ci.round(6))
print("单样本检验", stats.ttest_1samp(data, popmean=9))
print("卡方", stats.chisquare([120, 80], f_exp=[100, 100]))
print("Welch", stats.ttest_ind([8, 9, 10, 11, 12], [9, 11, 12, 13, 15], equal_var=False))
```

此例只是不同设计的计算展示，不能把任意数列看成真实独立实验。必须知道观测怎样得到。

## 7. 同一测试集比较两模型：完整配对 Bootstrap

设 1000 个案例来自独立目标个体，记录每个案例真实标签和 A/B 预测。每次**用同一组索引**同时重采样三列，计算 B 指标减 A 指标，保存差值。分位区间是容易理解的教学方法；正式场景还可考虑 basic、BCa 及覆盖率检查。[SciPy Bootstrap 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)给出配对重采样和区间选项。

```python
import numpy as np
rng = np.random.default_rng(42)
y = rng.integers(0, 2, 1000)
pred_a, pred_b = y.copy(), y.copy()
pred_a[rng.random(1000) < 0.15] ^= 1
pred_b[rng.random(1000) < 0.12] ^= 1

def accuracy_diff(indices):
    a = (pred_a[indices] == y[indices]).mean()
    b = (pred_b[indices] == y[indices]).mean()
    return b - a

draws = np.empty(3000)
for i in range(draws.size):
    draws[i] = accuracy_diff(rng.integers(0, len(y), len(y)))
print("观测提升", accuracy_diff(np.arange(len(y))))
print("差值95%分位区间", np.quantile(draws, [0.025, 0.975]))
print("Bootstrap标准误", draws.std(ddof=1))
```

换成 F1/AUC 时，每次要重新计算整个指标，不能先算每个案例的“F1”再平均。某些重采样若只含一类，AUC 未定义，要预先设计分层方案并说明其目标。按患者/用户/文档聚类的案例，应重采样整个群；时间序列考虑块采样。Bootstrap 不能生成样本中从没出现的群体，也不能补救测试泄漏。

本例固定种子输出的点提升为0.037（3.7个百分点），分位区间约 `[0.007,0.068]`，标准误约0.01523。该区间仅对应合成个体样本和固定模型的测试变化，不能推广到真实生产提升。

固定已训练模型的案例 Bootstrap 估计的是测试案例变化带来的不确定性；它**不涵盖训练集、随机初始化和超参数搜索的波动**。如目标包括这些因素，应在独立划分或重复实验中重新训练，报告它们的变化。

来源统计课代码的 `bootstrap_compare` 两组独立重采样适合独立群体；不能直接用于同一测试集两模型。正文这里已经明确改成配对逻辑。

## 8. 多次比较、反复窥看和数据泄漏

20 个独立真零假设、每个 $\alpha=0.05$ 时，至少一次误报概率为 $1-0.95^{20}\approx0.6415$。此乘积依赖独立；依赖时不能直接套。Bonferroni 每次用 $\alpha/m$，由并集上界控制整组错误，**不要求检验彼此独立**；Holm 顺序校正通常更有力。大量探索也可按目标控制假发现率，但不能把不同保证混为一谈。

在模型选择中，尝试很多设置后拿最好结果在同一测试集宣称提升，会产生选择偏差。先分训练、验证、最终测试；标准化、分词、特征选择都只拟合训练数据。把同一患者的切片分到不同集合，会使“未见测试”名存实亡。

交叉验证各折训练集重叠，因此折得分并不是独立实验。把 5 个折分数直接当作独立样本做 t/Wilcoxon，改检验名字仍不能修复依赖。可使用独立最终测试集上的配对预测，或设计与目标匹配的重复数据集实验及修正方法。报告“这是描述性折间波动”优于伪造精确显著性。

固定样本量普通检验反复查看、到显著时停止，会改变误报控制。需预先固定停止点或用适当顺序设计。贝叶斯后验更新同样要区分后验解释与频率误判保证，详见[贝叶斯 A/B](10-概率分布与贝叶斯推断.md)。

## 9. 效应量、功效和真正值得改变的结果

同时报告原单位变化和区间。例如准确率 0.9234→0.9237 是 **0.03 个百分点**，相对提升约 0.0325%。有些业务它很重要，有些不足以覆盖部署成本；不能靠一个固定 Cohen 阈值替业务做决定。

独立组 Cohen's $d=(\bar x_2-\bar x_1)/s_{pooled}$，
$s_{pooled}^2=[(n_1-1)s_1^2+(n_2-1)s_2^2]/(n_1+n_2-2)$。配对数据可用 $d_z=\bar d/s_d$，与独立组定义不能混用。0.2/0.5/0.8 只是常见粗参考，基线风险、指标尺度和任务成本更关键。小样本可考虑偏差修正效应量。

功效模拟可以真正检验“需要多少数据”：设真实均值差 3、标准差 10，分别用每组 50 与 200 个独立观测，重复生成、Welch 检验、计拒绝比例。零效应情形估第一类错误；指定非零效应情形估功效。模拟次数也有误差，拒绝率 $\hat p$ 的 MCSE 约为 $\sqrt{\hat p(1-\hat p)/R}$。

```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(2026)
for n in [50, 200]:
    for effect in [0., 3.]:
        rejects = 0
        repeats = 500
        for _ in range(repeats):
            a = rng.normal(50, 10, n)
            b = rng.normal(50 + effect, 10, n)
            rejects += stats.ttest_ind(a, b, equal_var=False).pvalue < 0.05
        rate = rejects / repeats
        print(n, effect, round(rate, 3), "MCSE", round(np.sqrt(rate*(1-rate)/repeats), 3))
```

更大样本能提高指定效应的功效；不能保证每次都显著。要用实验设计中的最小有用效应和可能方差规划，而非实验结束后用观察效应给“事后功效”包装结论。

## 10. 可直接使用的实验复盘顺序

1. 写明目标总体、独立单位、抽样或随机化方式，以及分组是否可比。
2. 固定主要指标、最小有用效应、护栏指标、比较集合和停止规则。
3. 检查缺失、类别不平衡、分组依赖、时间漂移与泄漏。
4. 报告两模型点估计、配对差值、区间、适当检验、样本量与重采样单位。
5. 分清统计证据、业务收益、工程成本；对负面结果与护栏同样报告。
6. 保存代码、数据版本、随机种子和未覆盖因素。显著性不能代替复现。

## 11. 自查参考答案

- 100 万条记录的 p 很小，能证明提升值得上线吗？**答案：**不能。检查是否独立、效应与区间、风险和最小收益；p 不证明真实性或实用性。
- 两模型预测同一批案例，重采样时为何要共用索引？**答案：**保留每个案例的配对难度与相关性；分别抽样会改变估计目标。
- 10 折分数改用 Wilcoxon 是否消掉共享训练集依赖？**答案：**不会。检验仍需要设计与依赖假设；换分布假设不能改数据生成机制。
- 20 次比较的 Bonferroni 阈值多少？**答案：**0.0025。它控制家族误报率的上界，不要求独立；64% 的具体误报计算才要求独立。
- 常量与另一变量的 Pearson=0 吗？**答案：**未定义，应显示 NaN/错误并查数据；“无波动”不等于“证实无依赖”。
- Bootstrap 3000 次就是 3000 个新独立样本吗？**答案：**不是。原始信息量仍由原始样本决定，增加重采样只减数值模拟误差。
