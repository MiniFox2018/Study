# 05｜范数、距离与相似性

> 先修：[点积与投影](01-向量空间与线性映射.md)。先掌握 1～5 节的尺度与比较方式，再读分布比较、正则化与检索。选择相似性之前，明确什么变化应当被忽略、什么差异应当被惩罚；“文本用 cosine、图片用 L2”只能是某些情境的起点。

## 1. 范数与距离度量的基本条件

范数 $\|x\|$ 衡量向量大小，要求非负且仅零向量为零、绝对齐次 $\|ax\|=|a|\|x\|$、三角不等式 $\|x+y\|\le\|x\|+\|y\|$。范数诱导的距离 $d(x,y)=\|x-y\|$ 满足非负、同一性、对称性和三角不等式。

不是所有距离都能写成某个向量差的范数，例如字符串编辑距离、集合 Jaccard 距离。相似性分数通常越大越近；距离通常越小越近；KL 等 divergence 又不满足全部度量条件。命名中出现 “distance” 也不表示有严格数学度量性质。

对于 $p\ge1$：

$$
\|x\|_p=\left(\sum_i|x_i|^p\right)^{1/p},\qquad
\|x\|_\infty=\max_i|x_i|.
$$

$0<p<1$ 时此表达式不是范数，三角不等式可能失败；所谓 L0 常指非零元素个数，也不是范数。$\|x\|_\infty\le\|x\|_2\le\|x\|_1$：最大分量平方不超过平方和，所以第一项成立；绝对值之和的平方包含平方和以及非负交叉项，所以第二项成立。

二维单位球有不同形状：L1 边界 $|x|+|y|=1$ 是顶点在坐标轴上的菱形；L2 边界 $x^2+y^2=1$ 是圆；无穷范数边界 $\max(|x|,|y|)=1$ 是正方形。不同形状就是不同“代价相同”的定义，并不是画图风格的区别。

## 2. L1、L2、无穷范数与尺度

对 $a=(1,2,3)$、$b=(4,0,6)$，差为 $(-3,2,-3)$：

- L1 距离 $3+2+3=8$，像网格道路累加每轴路程。
- L2 距离 $\sqrt{9+4+9}=\sqrt{22}\approx4.690416$，是直线长度。
- 无穷范数距离 $3$，关心最大的单项偏差。

```python
import math

def difference(a, b):
    if len(a) != len(b):
        raise ValueError("向量维数必须一致")
    return [x - y for x, y in zip(a, b)]

def lp_distance(a, b, p=2):
    v = difference(a, b)
    if p == math.inf:
        return max((abs(x) for x in v), default=0.)
    if p < 1:
        raise ValueError("Lp 范数要求 p>=1")
    return sum(abs(x) ** p for x in v) ** (1 / p)

a, b = [1, 2, 3], [4, 0, 6]
print(lp_distance(a, b, 1))         # 8.0
print(round(lp_distance(a, b), 6)) # 4.690416
print(lp_distance(a, b, math.inf))  # 3
```

L1 对单个极大残差只线性惩罚，L2 **平方**惩罚对异常残差更敏感。但不能由此说任何使用 L1 的系统自动鲁棒，也不能说稀疏/高维必然只用 L1。比较要看尺度、异常模式、特征表示和任务指标。

平方欧氏距离适合快速排序，因为平方根单调，但它不满足三角不等式，例如一维点 0、1、2 的距离平方 $4>1+1$。需要三角不等式的剪枝算法不能不加条件使用平方距离。

身高厘米与收入元放在一个向量里，L2 可能被收入维支配。标准化可以除训练集标准差；领域加权可以令 $d^2=\sum_i w_i(x_i-y_i)^2$，$w_i>0$ 才是该空间的严格加权欧氏度量。测量容差不同的质量控制可用 $\max_i |x_i-y_i|/t_i$，各维都应满足各自容差，而不是以原始单位直接取最大。

## 3. 余弦、点积、欧氏距离：什么时候排序一致

对非零向量：

$$
\operatorname{cos}(a,b)=\frac{a^Tb}{\|a\|_2\|b\|_2}.
$$

余弦比较方向，正数倍缩放不变；点积同时包含两侧长度。若 embedding 训练目标让长度承载信心、频次等信息，归一化会丢掉它。长度是否有价值要依据模型、训练和实测，而不能将所有 embedding 都预设为“只看方向”。

$a=(1,0),b=(100,0)$ 余弦为 1、L2 距离 99；方向完全一致但长度相差很大。$a=(0.1,0),b=(0,0.1)$ 余弦为 0、L2 距离约0.141421；小向量可以方向不同但绝对距离很小。

非零向量归一化为 $\widehat a,\widehat b$ 后：

$$
\|\widehat a-\widehat b\|_2^2=2-2\widehat a^T\widehat b
=2(1-\operatorname{cos}(a,b)).
$$

因此对同一组单位向量，点积降序、余弦降序、L2 升序有相同精确排序（并列与浮点误差另算）。这并不保证不同 ANN 索引的近似候选也完全一致。

`1-cos` 常称余弦距离，但对一般非零向量，同方向但不同长度仍为零，不满足同一性；即使限制到单位球也可能违反三角不等式。例如方向 $0^\circ,60^\circ,120^\circ$ 的三对余弦距离是 $0.5,0.5,1.5$。单位球上的弦长 $\sqrt{2(1-cos)}$ 和角距离 $\arccos(cos)$ 有相应度量性质。

零向量的余弦未定义。某些库约定返回 0 或用 epsilon，属于工程约定，不能当数学结论。以下检索明确拒绝零向量，排除查询自身使用 ID，不用简单跳过排序第一名：

```python
import numpy as np

def normalized_rows(X):
    X = np.asarray(X, float)
    norm = np.linalg.norm(X, axis=1, keepdims=True)
    if np.any(norm == 0) or not np.isfinite(X).all():
        raise ValueError("检索输入存在零向量或非有限数")
    return X / norm

E = np.array([[1., 0.], [2., 0.], [0., 1.], [-1., 0.]])
En = normalized_rows(E)
query_id = 0
scores = En @ En[query_id]
scores[query_id] = -np.inf
order = np.argsort(-scores, kind="stable")[:2]
print(order.tolist())  # [1, 2]；同方向另一个对象不应被当成自身删除。
print(scores[order])   # [1. 0.]
```

这里只用二维数值演示排序规则，不声称这些人工向量代表真实文本语义。真实检索需检查数据归一化、训练指标、过滤条件、召回与误匹配。

## 4. Mahalanobis 距离：按协方差校正尺度与相关性

对称正定协方差 $S$ 下：

$$
d_M(x,y)=\sqrt{(x-y)^TS^{-1}(x-y)}.
$$

若 $S=LL^T$，先解 $Lz=x-y$，再取 $\|z\|_2$，相当于白化后计算欧氏距离。不要每次显式求 $S^{-1}$。

以 $S=\begin{bmatrix}1&0.9\\0.9&1\end{bmatrix}$ 为例，数据沿 $(1,1)$ 波动较多，沿 $(1,-1)$ 波动较少。两个点 $a=(1,1)$、$b=(1,-1)$ 到零点的 L2 距离同为 $\sqrt2$，Mahalanobis 分别为 $\sqrt{2/1.9}\approx1.025978$ 与 $\sqrt{2/0.1}\approx4.472136$，后者更偏离常见变化方向。

```python
import numpy as np
S = np.array([[1., 0.9], [0.9, 1.]])
L = np.linalg.cholesky(S)
for point in ([1., 1.], [1., -1.]):
    z = np.linalg.solve(L, point)
    print(round(np.linalg.norm(z), 6))  # 1.025978；4.472136。
```

协方差由训练或正常参考数据估计。有限样本、异常污染、重复特征、$d\ge n$ 可能导致奇异或不可靠的估计；可以使用收缩协方差、正对角加载、降维或稳健估计。没有“样本大于特征十倍就一定可靠”的通用保证。伪逆协方差忽略零空间方向，可能成为伪度量而非严格距离。

用于异常检测时，从均值的 Mahalanobis 距离是否“异常”还需要分布假设与阈值校准。高斯条件下平方距离与卡方关系有相应条件，实际估计均值/协方差时也有影响；不要看到一个大数字就自动下异常结论。

## 5. 集合重叠、Jaccard 与 MinHash

Jaccard 相似度 $J(A,B)=|A\cap B|/|A\cup B|$，距离 $1-J$。$A=\{猫,狗,鱼\}$，$B=\{猫,鸟,鱼,蛇\}$，交集 2、并集 5，相似度 0.4、距离 0.6。两个空集合通常约定相似度为 1；一个空另一个非空时为 0。

它关注出现与否，忽略重复次数及共同缺失。分割模型的 IoU 就是前景集合的 Jaccard，边界和类别定义要一致。TF-IDF 频次向量用余弦与标签集合用 Jaccard 的目标不同；集合当然也能转二值向量，问题是选择哪种比较语义，而不是“集合禁止向量化”。

近重复文档可转为 token/shingle 集合再比较。MinHash 对同一随机排列取集合中最小秩；两个集合的最小元素一致概率恰为 Jaccard。使用 $h$ 个独立排列，把一致次数除 $h$ 作估计，标准误差约 $\sqrt{J(1-J)/h}$。更多哈希降低波动，不能消除分词、集合定义或哈希碰撞的偏差。

下面用小宇宙的真实随机排列示范，不依赖 Python 每次进程可能不同的 `hash`：

```python
import random

def minhash_sets(sets, repetitions=200, seed=7):
    universe = sorted(set().union(*sets))
    rng = random.Random(seed)
    signatures = [[] for _ in sets]
    for _ in range(repetitions):
        order = universe.copy()
        rng.shuffle(order)
        rank = {value: i for i, value in enumerate(order)}
        for sig, values in zip(signatures, sets):
            sig.append(min((rank[x] for x in values), default=-1))
    return signatures

A, B = {"猫", "狗", "鱼"}, {"猫", "鸟", "鱼", "蛇"}
sigA, sigB = minhash_sets([A, B])
estimate = sum(a == b for a, b in zip(sigA, sigB)) / len(sigA)
print(len(A & B) / len(A | B), estimate)  # 真值 0.4，估计围绕真值波动。
assert 0 <= estimate <= 1
```

大型集合使用哈希函数近似排列，持久化签名须固定哈希方法、种子、分词和版本。LSH 可以把签名分 bands、同 band 一致者成为候选，再用精确 Jaccard 复核。候选策略会出现漏召回/误候选，评测时检查真实近重复对，而不只看平均数值误差。

## 6. 编辑距离：从最优子问题得到字符串匹配

Levenshtein 距离是把一个字符串变成另一个所需最少的插入、删除、替换次数，各操作成本为 1，不含相邻换位操作。`kitten→sitting`：`k→s`、`e→i`、末尾插入 `g`，共 3 步。

令 $D_{ij}$ 为前 $i$ 个字符和前 $j$ 个字符的距离，初始化 $D_{i0}=i,D_{0j}=j$，递推：

$$
D_{ij}=\min\{D_{i-1,j}+1,\ D_{i,j-1}+1,
\ D_{i-1,j-1}+\mathbf1[a_i\ne b_j]\}.
$$

三项分别对应删除、插入、相同/替换。只求最后距离不需要存整个表，保留两行即可：

```python
def edit_distance(a, b):
    if len(a) < len(b):
        a, b = b, a  # 让滚动行对应较短字符串。
    previous = list(range(len(b) + 1))
    for i, ca in enumerate(a, 1):
        current = [i]
        for j, cb in enumerate(b, 1):
            current.append(min(previous[j] + 1, current[-1] + 1,
                               previous[j - 1] + (ca != cb)))
        previous = current
    return previous[-1]

print(edit_distance("kitten", "sitting"))  # 3
print(edit_distance("", "abc"))           # 3
print(edit_distance("学习", "学会"))      # 1
```

时间 $O(mn)$、额外空间 $O(\min(m,n))$；需要恢复编辑步骤时要保留表或其他回溯结构。DNA 比对常用替换矩阵、缺口权重，已经超出简单单位代价 Levenshtein 的假设。

大小写、空格、Unicode 正规化、中文分词要先决定。Python 字符串遍历 Unicode 码点，不等于用户感知的字形；组合字符与 emoji 可能占多个码点。短姓名可考虑偏重共同前缀的 Jaro–Winkler；读音匹配可另做 Soundex/Metaphone，但这类英文语音编码不自动适合中文名字。拼写接近也不代表事实或身份相同。

## 7. 分布差异：KL、Jensen–Shannon 与 Wasserstein

### KL 是方向性 divergence

对同一离散支持上的概率分布，

$$
D_{KL}(P\|Q)=\sum_{i:p_i>0}p_i\log\frac{p_i}{q_i}.
$$

$p_i=0$ 项按零处理；若 $p_i>0,q_i=0$ 则为无穷大。自然对数单位是 nat，以 2 为底是 bit。输入必须非负、和为 1、支持对应；不能把任意两个特征数组直接塞进去。

它非负、一般不对称、无三角不等式。$P=(0.9,0.1)$、$Q=(0.5,0.5)$ 时，两个方向约为 0.368064 和 0.510826 nat。若固定目标 P、用受限模型 Q 拟合，最小化正向 KL 往往鼓励覆盖 P 的多个模态，反向 KL 可能更偏向少数模态；这是模型受限与多模态情境下的倾向，不是任何分布对都具备的独立性质。

交叉熵 $H(P,Q)=H(P)+D_{KL}(P\|Q)$。目标 P 固定时，最小化交叉熵与 KL 等价；交叉熵本身不是严格距离。VAE 的后验—先验项、知识蒸馏、策略更新的 KL 惩罚都要写明比较方向和分布。

Jensen–Shannon divergence 令 $M=(P+Q)/2$，$JS(P,Q)=\frac12 KL(P\|M)+\frac12 KL(Q\|M)$。它对称、可用于离散或连续分布，JS 本身不是通常所说的距离度量；$\sqrt{JS}$ 有度量性质。对数为自然底时范围 $[0,\log2]$。

### Wasserstein 要知道概率质量的位置

$W_1(P,Q)$ 是所有运输计划中最小的“质量×移动距离”总成本。它不只比较每个 bin 的概率差，还知道 bin 之间相距多远。同样大小的差异，移动一个位置和移动十个位置代价不同。

一维 $W_1=\int |F_P(t)-F_Q(t)|dt$。在共同有序支持 $x_0<\cdots<x_{n-1}$ 上：

$$
W_1=\sum_{i=0}^{n-2}|F_P(x_i)-F_Q(x_i)|(x_{i+1}-x_i).
$$

单位等距 bins 才能直接把 CDF 差相加。若输入只是“猫、狗、鱼”的标签概率，却没有定义类别间的运输成本，则不能用索引间距冒充距离。

```python
import math

def checked_probabilities(p, q):
    if len(p) != len(q) or not p:
        raise ValueError("分布必须有相同非空支持")
    if any(x < 0 or not math.isfinite(x) for x in p + q):
        raise ValueError("概率必须有限非负")
    if not math.isclose(sum(p), 1.) or not math.isclose(sum(q), 1.):
        raise ValueError("概率总和必须为一")

def kl(p, q):
    checked_probabilities(p, q)
    if any(a > 0 and b == 0 for a, b in zip(p, q)):
        return math.inf
    return sum(a * math.log(a / b) for a, b in zip(p, q) if a > 0)

def wasserstein_bins(p, q, positions):
    checked_probabilities(p, q)
    if len(positions) != len(p) or any(b <= a for a, b in zip(positions, positions[1:])):
        raise ValueError("支持位置须严格递增")
    balance, cost = 0., 0.
    for i in range(len(p) - 1):
        balance += p[i] - q[i]
        cost += abs(balance) * (positions[i + 1] - positions[i])
    return cost

p, q = [0.5, 0.5, 0., 0.], [0., 0., 0.5, 0.5]
print(wasserstein_bins(p, q, [0., 1., 2., 3.]))  # 2.0
print(kl(p, q))  # inf
p2 = [0.25, 0.25, 0.25, 0.25]
print(wasserstein_bins(p2, q, [0., 1., 2., 3.]))  # 1.0
```

第一对 CDF 差在三个区间为 0.5、1、0.5，总工作量 2；第二对为 0.25、0.5、0.25，总量 1。点质量 $\delta_0$ 与 $\delta_\theta$ 的 $W_1=|\theta|$，可在支持不重叠时仍表达移动趋势，但不意味着所有 Wasserstein 优化处处可微。

WGAN 使用 Kantorovich–Rubinstein 对偶中的 1-Lipschitz critic 近似 Wasserstein 目标；原始权重裁剪与后来的梯度惩罚是不同的约束近似。该思想改善某些训练问题，不保证“解决所有 GAN 不稳定”。多维运输的计算成本、Lipschitz 约束和模型优化都需要单独验证。

## 8. 距离、损失和正则化之间的关系

损失可以由距离构造，却不必是严格距离：分类交叉熵、margin hinge 等都有自己的目标。MSE 是按元素平均的平方误差，MAE 是平均绝对误差。

Huber loss 对误差 $e$：

$$
L_\delta(e)=\begin{cases}\frac12e^2,&|e|\le\delta,\\
\delta(|e|-\frac12\delta),&|e|>\delta.
\end{cases}
$$

小误差二次、较大误差线性，导数在接点连续。hinge 对标签 $y\in\{-1,1\}$ 和分数 $f$ 是 $\max(0,1-yf)$，不是某个任意“距离低于阈值”的统一定义。triplet 常写 $\max(0,d(a,p)-d(a,n)+m)$，距离可以是欧氏或经过训练的相似表示，应按任务选择。

正则化惩罚的是**参数**而非预测误差：Lasso 加 $\lambda\|w\|_1$，Ridge 加 $\lambda\|w\|_2^2$，Elastic Net 加两者。不要把“采用 L1 距离”与“采用 L1 权重惩罚”混为一谈。

L1 单位球有轴向尖角，因此优化的等高线较容易在某些系数为零的位置首次触碰约束。更精确的一个坐标例子：

$$
\min_w\frac12(w-z)^2+\lambda|w|
\quad\Rightarrow\quad
w^*=\operatorname{sign}(z)\max(|z|-\lambda,0).
$$

这就是 soft-threshold，不是简单“对小权重硬裁剪”。平方 L2 的同类问题解是 $w=z/(1+2\lambda)$，连续缩小，不会一般地制造精确零，但 $z=0$ 等特殊情形仍然可以为零。

```python
import numpy as np
z = np.array([2., -0.3, 0.1, 0.])
lam = 0.5
l1 = np.sign(z) * np.maximum(np.abs(z) - lam, 0.)
l2 = z / (1 + 2 * lam)
print(l1)  # [1.5 -0. 0. 0.]
print(l2)  # [1. -0.15 0.05 0.]
```

一般 Lasso 用近端梯度等方法，每步先对数据损失梯度更新 $z=w-\eta\nabla f(w)$，再以 $\eta\lambda$ 作 soft-threshold。来源的“只优化惩罚、循环50步并裁小值”是演示收缩，不能作为完整 Lasso 训练或 feature selection 实验。

相关特征下 Ridge/Elastic Net 常更稳定，Elastic Net 可以产生组效应，但不会保证任意相关特征组总一起保留/删除。标准化、截距处理、正则强度及验证集指标都影响解释。

## 9. 同一数据，不同最近邻

以 query $(1,0)$，候选 $A=(2,0)$、$B=(1,0.2)$、$C=(0,0)$ 为例：余弦把 A 视为完全同方向，L2 把 B 视为最近；C 无法参与余弦。选择不同度量是在定义不同目标，不能说其中一个排序天然正确。

另一例 query 为零点，候选 $(2,0)$ 与 $(1.2,1.2)$：L1 分别为 2、2.4，优先第一个；L2 分别为 2、约1.697056，优先第二个。度量选择能改变 KNN 的邻居与投票，但不保证每个数据集的分类结果一定改变。

KNN 应按训练集变换尺度，计算距离，选 $k$ 个邻居，再多数/距离加权投票。并列要定义稳定规则；距离为零时优先处理完全匹配，不能盲目使用 $1/d$。评测不同度量时使用相同划分、相同数据处理和实际指标。

选择参考：

| 对象/目的 | 比较方式 | 为什么、什么时候改用别的 |
|---|---|---|
| 相同量纲的空间坐标 | L2 | 真正直线距离；道路约束则需图路径 |
| 各坐标有容差 | 加权无穷范数 | 关注每项最坏偏差 |
| 方向承载任务意义的表示 | cosine / 单位点积 | 丢长度；长度有意义时核对未归一化分数 |
| 模型按内积训练的因子 | 点积 | 与训练目标一致，检查长度偏置 |
| 标签或出现集合 | Jaccard | 忽略频次与共同缺失 |
| 有相关性的正常样本偏离 | Mahalanobis | 需可靠参考协方差与校准 |
| 拼写或有限编辑 | Levenshtein | 不等于语义、身份或读音 |
| 有方向的分布拟合 | KL / 交叉熵 | 支持与方向明确，可能无穷 |
| 分布在有距离的空间上移动 | Wasserstein | 必须明确支持位置或运输成本 |

图片像素 L1/L2 都可用于误差衡量，但对平移、光照很敏感，不等同人的感知；学到的图像表示也要按训练指标选比较方法。对齐的同长度时间序列可用逐位置 L2；若时间节奏偏移可考虑 DTW。

DTW 的局部代价 $c(i,j)=|x_i-y_j|$ 或平方差，累积 $D(i,j)=c(i,j)+\min(D(i-1,j),D(i,j-1),D(i-1,j-1))$，用单调路径对齐时间。窗口约束防止过度扭曲，复杂度通常 $O(mn)$，它一般也不是严格度量。余弦并非“忽略所有时间顺序”，它会比较对应位置，但不会自动消除时间错位。

图对象先决定比较的是节点距离还是整个结构。节点可用最短路径距离；两个小图可用图编辑距离（插删改顶点/边的最小成本，常很昂贵）；图核以共有子结构表示相似性，例如 WL 迭代用邻居标签多重集合细化节点标签并统计特征，再取内积。这些比较对象不同，不能拿节点 embedding 与整个图编辑成本互换。

## 10. 精确检索与近似检索：先定义分数，再加速

一个 $d$ 维 query 对 $n$ 个向量逐一扫描约 $O(nd)$。只需 top-k 时可部分选择或维护堆，没必要构造 $n\times n$ 全相似矩阵。全矩阵的存储是 $O(n^2)$，单查询只需要 $O(n)$ 分数。

ANN 以遗漏部分真近邻换取速度/内存，主要方法：

- **KD tree**：按坐标轴切分空间，用区域距离下界剪枝。低维常有效，高维很多区域无法剪掉；不适合所有任意 similarity。
- **Ball tree**：用球包围子区域，以球的距离界剪枝。效能同样依赖维度、分布和所用度量。
- **LSH**：让相似对象更可能落入相同桶，多表扩大候选；不同度量要用匹配的哈希家族，MinHash 与 Jaccard 是一例。
- **HNSW**：建多层近邻图，顶层稀疏长跳，逐层下降扩大候选；底层在候选集中搜索近邻。连接数量、构图探索和查询探索控制内存、构图成本、速度/召回。它不是所有规模/任务的无条件最优选择。
- **IVF**：先在代表性训练数据上聚类，query 找附近粗簇，只扫描所探测列表。探测更多簇通常提高召回并增加工作量；分布变化可能让粗聚类不再适合。
- **Product Quantization**：把向量拆成子块，各子块量化成码本索引，用距离查表近似计算。节省存储，却引入量化误差；候选可再用原向量精排。

选择索引要同时看度量支持、维数、规模、内存、构图/更新成本与过滤需求。采样若不代表真实数据，IVF/PQ 的训练可能失效；高更新频率、删除、标签过滤也可能改变适用选择。

最小验收流程：先精确扫描得到真 top-k，再测近似候选命中的比例 `recall@k`、查询延迟分位数、内存与构图成本；再测最终检索的真实相关性。高 ANN recall 只说明接近所定义分数的精确结果，不表示分数本身适合任务。调整参数后保留中文说明：改了什么、召回与延迟怎么变、是否需要重新建索引。

## 11. 自查与动手题

1. 对 $(1,2,3)$、$(4,0,6)$ 检查范数顺序。**答案：**$3\le\sqrt{22}\le8$；证明见第1节，不靠随机样例代替证明。
2. 找高余弦、大 L2，与低余弦、小 L2 的两组向量。**答案：**第3节的 $(1,0),(100,0)$ 与 $(0.1,0),(0,0.1)$。
3. 为什么余弦距离不是严格度量？**答案：**一般非零向量有同方向不同长度零距离；单位向量也可能违反三角不等式，例如 $0,60,120$ 度例子。
4. 给定等距支持 0、1、2、3，比较两组分布的 Wasserstein。**答案：**第7节分别为 2 和 1；支持间距翻倍，距离也翻倍。
5. 用 100 个随机集合比较 50、100、200 个 MinHash 的误差。**判断标准：**记录集合生成方法和多个种子，报告误差分布；独立次数增加的平均波动通常减少，但单个样本未必严格单调。
6. 找让 L1、L2、cosine、Mahalanobis 最近邻各不相同的数据。**方法：**先固定非零 query、正定协方差和几类候选，按四种分数穷举；检查真实算出不同索引，不能把“代码标题说不同”当结果。并列需明确处理。
7. 构造近邻搜索基线，再加 ANN。**判断标准：**排序方向、零向量、查询自身、重复对象、top-k 边界、过滤与精确结果对照都需检查。
