## 1. 怎样把问题建成图

图 $G=(V,E)$ 包含节点与边。用户与友谊、分子原子与化学键、文档与引用都可建图，但建图决定“关系代表什么”，不能把数据里的任何共现当成因果连接。

无向边表示对称关系；有向边 $u\to v$ 不推出 $v\to u$。无权边只表示是否连接；加权边还表示距离、概率或强度，三种语义不能互用。例如距离越小越相似，但相似性权重通常越大连接越强。节点/边还可有属性，动态关系需要时间。

**邻接矩阵** $A_{ij}=w_{ij}$（无边为0）便于矩阵运算，稠密存储要 $O(n^2)$；**邻接表**仅存每个节点的邻居，稀疏图常为 $O(|V|+|E|)$。大图优先稀疏表示，不能因演示使用 NumPy 稠密矩阵就照搬百万节点。

三角形节点 0、1、2 的矩阵为：

$$
A=\begin{bmatrix}0&1&1\\1&0&1\\1&1&0\end{bmatrix},\quad D=\operatorname{diag}(2,2,2).
$$

无权度是邻居数，加权度是权重之和；有向图分入度和出度。构造加权拉普拉斯时必须用**加权度**，不能用邻居数减加权 A。自环和多重边要另定计数约定，本章默认简单图、无自环。

无向简单图的握手定理 $\sum_v d_v=2|E|$：每条边被两个端点各数一次，因此奇度节点数为偶数。来源图示改变节点和边数展示的就是这个不变量，而非证明某种真实网络一定是幂律。真实度分布需估计和检验；稀疏 Erdős–Rényi 图在适当极限下近似 Poisson，不是全部“随机图”的通则。

## 2. 遍历和路径：先选对算法

BFS 使用先进先出队列，先访问距离 1 的节点，再访问距离 2 的节点。节点在**入队**时标记，避免同一节点被多次加入。无权图或等正权图的首次发现层数给最小跳数。

DFS 用栈或递归，沿一条路径尽量深入后回退，适用于连通分量、环检测和 DAG 的拓扑顺序。无向图检测环时排除父边；有向图要跟踪递归活动栈或颜色。仅记录访问顺序不是完整环检测，也不是拓扑排序。

加权最短路：非负权可 Dijkstra，每次从优先队列取当前最小距离，跳过过时队列项；存在负权则不能直接用它，可考虑 Bellman–Ford 并检查负环。最小跳数不一定最小成本。例如 0→2 的成本 10，0→1→2 的成本 2，BFS 会选直接边，Dijkstra 选两边路径。

下面是完整标准库教学例子：

```python
from collections import deque
import heapq

def bfs(adj, start):
    distances = {start: 0}
    parent = {start: None}
    queue = deque([start])
    while queue:
        u = queue.popleft()
        for v in adj[u]:
            if v not in distances:
                distances[v] = distances[u]+1
                parent[v] = u
                queue.append(v)
    return distances, parent

def dfs(adj, start):
    visited, order, stack = set(), [], [start]
    while stack:
        u = stack.pop()
        if u in visited:
            continue
        visited.add(u); order.append(u)
        stack.extend(v for v in reversed(list(adj[u])) if v not in visited)
    return order

def components(adj):
    remaining = set(adj)
    result = []
    while remaining:
        group = set(bfs(adj, min(remaining))[0])
        result.append(sorted(group)); remaining -= group
    return result  # 仅适用于本章无向图的连通分量

def dijkstra(adj, start):
    if any(weight < 0 for edges in adj.values() for weight in edges.values()):
        raise ValueError("Dijkstra要求非负权重")
    distance, queue = {start: 0.}, [(0., start)]
    while queue:
        current, u = heapq.heappop(queue)
        if current > distance[u]:
            continue
        for v, weight in adj[u].items():
            candidate = current+weight
            if candidate < distance.get(v, float("inf")):
                distance[v] = candidate
                heapq.heappush(queue, (candidate, v))
    return distance

adj = {0:{1:1.,2:10.},1:{0:1.,2:1.},2:{0:10.,1:1.},3:{}}
print("BFS", bfs(adj,0)[0])
print("DFS", dfs(adj,0))
print("连通分量", components(adj))
print("成本最短路", dijkstra(adj,0))
```

输出到节点2的 BFS 跳数为1，Dijkstra成本为2；节点3独立成分。遍历仅覆盖起点可达部分，两者使用邻接表通常 $O(V+E)$；优先队列 Dijkstra 常为 $O((V+E)\log V)$。有向图的强/弱连通不同，不能直接拿无向分量函数分析它。

常见结构指标也应定义清楚：连通图的**直径**是最短路径长度的最大值，平均路径长度是指定节点对范围内的最短路平均。无权小图可从每个节点做BFS；不连通图要按成分报告或说明忽略不可达对，不能把缺失距离算0。无向简单图节点v的局部聚类系数为 $2t_v/[d_v(d_v-1)]$，其中 $t_v$ 为邻居之间的边数；$d_v<2$ 的值按软件约定通常记0或排除。它度量“朋友之间也相连”，不等于机器学习聚类标签。无向简单树满足连通且 $|E|=|V|-1$；这个判据不能不加条件套有向、多重或有自环图。

## 3. 拉普拉斯与谱聚类：平滑的含义

对于无向、非负权、对称 A，$L=D-A$；任意向量 $x$ 满足：

$$
x^TLx=\frac12\sum_{i,j}A_{ij}(x_i-x_j)^2\ge0.
$$

这证明半正定，也说明 L 衡量**相邻节点取值差异**。L 的每行和为0，常数向量属于零空间。每个连通分量可独立取一个常数，因此零特征值重数等于连通分量数。对有向或负权的任意 $D-A$，这些结论不能原样使用。

将特征值含零按升序写 $\lambda_1\le\lambda_2\le\cdots$，**Fiedler 值是第二小的 $\lambda_2$**。连通图中它为正；不连通时为0，不能跳过所有0改称“最小正特征值”。对应特征向量是满足与常数正交的平滑非平凡方向，紧密节点倾向相似数值，弱桥两侧可能取不同符号。

符号切分给一个容易理解的二分启发式，不保证最优离散割。特征向量整体换符号不会改变分组；特征值重复时向量基可能改变，零附近符号也不稳定。图权重整体缩放会缩放未归一化特征值，跨图比较“越大越连通”要控制尺度。

```python
import numpy as np
n = 6
A = np.zeros((n,n))
for group in [range(3), range(3,6)]:
    for u in group:
        for v in group:
            if u != v:
                A[u,v] = 1.
A[2,3] = A[3,2] = 0.1  # 两个三角形之间的弱桥
D = np.diag(A.sum(axis=1))
L = D-A
values, vectors = np.linalg.eigh(L)
fiedler = vectors[:,1]
print("度", A.sum(axis=1))
print("特征值", values.round(6))
print("符号组", np.flatnonzero(fiedler<0), np.flatnonzero(fiedler>=0))
print("半正定/常数零向量", values.min()>-1e-10, np.allclose(L@np.ones(n),0))
```

两个组应分别是 `{0,1,2}` 与 `{3,4,5}`，顺序可交换。删除桥后有两个零特征值；增加跨组权通常削弱分离，但具体切分还受图结构影响。

多类谱聚类需明确所用变体：[von Luxburg 教程](https://arxiv.org/abs/0711.0189)中的未归一化方法选 k 个最小特征向量（包含平凡向量），按行作为嵌入再聚类。常见归一化方法使用 $L_{sym}=I-D^{-1/2}AD^{-1/2}$ 或随机游走版；某些方法还逐行归一化。不要把“跳过第一列，取 k 列”套成所有变体唯一公式。孤立节点要先处理，避免度为0求逆。

社区检测若不知道分组数，可考虑模块度方法；它也有分辨率和算法随机性，不是“自动得到唯一真实社区”。传统算法适合连通性、最短路等精确任务；GNN适合根据结构和属性学习预测，不取决于节点数超过某个硬门槛。

模块度比较“组内边数”与保持节点度分布的随机基线，常见优化算法包括Louvain；高模块度不自动证明群体有现实意义。重叠社区允许节点属于多个组，可对图嵌入做软聚类作为近似方案，但嵌入质量、簇数和阈值都需评价，不能靠算法名字保证找出重叠关系。

## 4. 消息传递：把邻居信息写成矩阵运算

特征矩阵 $H\in\mathbb R^{n\times d}$，邻居均值 $D^{-1}AH$，再乘 $W\in\mathbb R^{d\times d'}$，最后激活。一个节点的一轮更新来自一跳邻居，两轮可接收两跳以内的信息；没有自环时自身信息可能被丢掉，孤立节点的邻居均值也需规定。

三角形特征 $H=[[1,0],[0,1],[1,1]]$，一轮无自环平均为 `[[0.5,1],[1,0.5],[0.5,0.5]]`。这是来源消息流图表达的计算，不是“节点学会交流”的拟人说法。

GCN 常先加自环 $\tilde A=A+I$，再使用对称归一化：

$$
H'=\sigma(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}HW).
$$

此矩阵通常**不满足每行和为1**，与随机游走均值不是同一归一化。GAT 用学习注意力加权，GraphSAGE 可采样邻居并设计不同聚合；详见已有 GNN 主章节，避免再建一套模型介绍。

```python
import numpy as np
A = np.ones((3,3))-np.eye(3)
H = np.array([[1.,0.],[0.,1.],[1.,1.]])
mean = A/A.sum(axis=1,keepdims=True)
print("一轮邻居均值", mean@H)
print("二轮邻居均值", mean@(mean@H))
with_self = A+np.eye(3)
degree = with_self.sum(axis=1)
normalized = with_self / np.sqrt(degree[:,None]*degree[None,:])
print("含自身传播", normalized@H)
```

图上反复平滑会让不同节点表示越来越相似，这是 over-smoothing；传播深度也可能把大量远处信息挤进有限向量。更多层不自动更好，且训练/测试邻边与时间泄漏需要检查。

## 5. 图随机游走与 PageRank

非孤立节点的随机游走转移为 $P_{ij}=A_{ij}/d_i$。无向连通图的不变分布为 $\pi_i=d_i/\sum_jd_j$，因为 $\pi_iP_{ij}=A_{ij}/\sum d=\pi_jP_{ji}$。二分图可能周期振荡；增加停留概率形成 lazy walk 可去周期。度大更常访问不等于任何任务中更重要。

PageRank 以概率 $\gamma$ 沿出边走，其余跳到指定分布（本例均匀）；没有出边的 dangling 节点把质量重新分配。按照“每行来源、每列去向”约定，行向量更新 $r'=\gamma rP+(1-\gamma)v$。跳转与 dangling 处理避免概率丢失，并在本例保证可收敛。

```python
import numpy as np
A = np.array([[0.,1.,1.],[0.,0.,1.],[0.,0.,0.]])
n = len(A); degree = A.sum(axis=1)
P = np.divide(A, degree[:,None], out=np.zeros_like(A), where=degree[:,None]>0)
P[degree==0] = 1/n
r = np.full(n,1/n)
for _ in range(1000):
    new = 0.85*(r@P)+0.15/n
    if np.abs(new-r).sum()<1e-12:
        r=new; break
    r=new
print("PageRank", r.round(6), "总质量", r.sum())
```

权重代表链接强度时可按权重归一化；不能把节点 PageRank 分数当成原始边权定义。节点重要性还可用介数（经过节点的最短路比例）、特征向量中心性等，要按问题选择。NetworkX 便于小中型图实验，但不是保证任意大小都由优化 C 后端处理的万能方案。

## 6. 随机游走：位置平均为0，距离却增长

公平独立增量 $X_i=\pm1$，位置 $S_n=\sum_iX_i$，有 $E[S_n]=0$、$\operatorname{Var}(S_n)=n$、均方根位移 $\sqrt{E[S_n^2]}=\sqrt n$。**平均绝对位移不等于标准差**；大 n 时 $E|S_n|\approx\sqrt{2n/\pi}$。比如 n=10000 的标准差100，平均绝对距离约79.8。

二维每步四方向等概率，$E\|S_n\|^2=n$，均方根距离仍为 $\sqrt n$。单条轨迹最后恰好接近原点不推翻规律；需要重复实验比较终点分布。

```python
import numpy as np
rng = np.random.default_rng(42)
steps = rng.choice([-1,1], size=(1000,10000))
endpoints = steps.sum(axis=1)
print("一维终点均值/std/平均绝对值", endpoints.mean(), endpoints.std(), np.abs(endpoints).mean())
directions = rng.integers(0,4, size=(1000,1000))
x = (directions==0).sum(axis=1)-(directions==1).sum(axis=1)
y = (directions==2).sum(axis=1)-(directions==3).sum(axis=1)
print("二维均方根/目标", np.sqrt(np.mean(x*x+y*y)), np.sqrt(1000))
```

赌徒破产例：公平游走从 k 出发，0 与 N 为吸收边界，先达到 N 的概率为 $k/N$。令 h(k) 满足 $h(k)=\tfrac12h(k-1)+\tfrac12h(k+1)$、h(0)=0、h(N)=1，可得到线性解。公平游走也是鞅 $E[S_{t+1}\mid S_0,\ldots,S_t]=S_t$；停时结论仍有适用条件，不能据此设计必胜赌博策略。

## 7. Markov 链：不变分布不等于已收敛

给定当前状态，未来下一步与更早历史条件独立：$P(X_{t+1}\mid X_t,X_{t-1},\ldots)=P(X_{t+1}\mid X_t)$。有限齐次链的转移矩阵每行非负、总和1；初始行分布 $v_{t+1}=v_tP$。

不变分布满足 $\pi P=\pi$、$\sum_i\pi_i=1$。有限不可约链有唯一不变分布；再有非周期性，任意初分布才收敛到它。$P=[[0,1],[1,0]]$ 的不变分布为 `(0.5,0.5)`，却从节点0永远在 `(1,0)` 与 `(0,1)` 间振荡。多个吸收态可有多个不变分布，结果依赖起点。

下面同时用线性方程、幂迭代与模拟核验天气玩具：

```python
import numpy as np
P = np.array([[0.7,0.1,0.2],[0.3,0.4,0.3],[0.4,0.2,0.4]])
assert (P>=0).all() and np.allclose(P.sum(axis=1),1)
system = np.vstack([P.T-np.eye(len(P)), np.ones(len(P))])
rhs = np.r_[np.zeros(len(P)),1.]
pi = np.linalg.lstsq(system,rhs,rcond=None)[0]
v = np.array([1.,0.,0.])
for _ in range(100):
    v=v@P
rng = np.random.default_rng(42)
counts = np.zeros(3); state=0
for _ in range(100000):
    state=rng.choice(3,p=P[state]); counts[state]+=1
print("理论稳态", pi.round(6))
print("幂迭代", v.round(6))
print("模拟频率", (counts/counts.sum()).round(6))
print("残差", np.max(np.abs(pi@P-pi)))
```

理论值为约 `(0.545455,0.181818,0.272727)`；来源正文 `(0.55,0.18,0.27)` 是两位小数近似。用特征法时求 P 转置的特征值1向量；任意取绝对值可能隐藏负项或错误，需检查质量与残差。

混合时间是达到指定总变差误差阈值所需步数；它还取决于起点和目标概率。可逆等条件下谱信息帮助界定混合；若链有负特征值，要考虑绝对值或 lazy 版本。$1/(1-|\lambda_2|)$ 只是松弛时间尺度，不能直接称“精确几步混合完”。

自回归语言模型若把**完整上下文**作为状态，可以表示状态转移；若状态只写“前一个 token”，一般不满足一阶 Markov，因为模型还看更早 token。词级一阶 Markov 文本生成器只是教学近似：统计相邻词计数、按每个来源词归一化、采下一词，使用 EOS 终止或最大长度；句末必须处理，不能产生零行。

```python
from collections import Counter, defaultdict
import random
corpus = ["猫 坐在 垫子 上", "狗 坐在 地板 上", "猫 吃 鱼", "狗 吃 饭"]
transitions = defaultdict(Counter)
for sentence in corpus:
    words = ["<BOS>"]+sentence.split()+["<EOS>"]
    for a,b in zip(words,words[1:]):
        transitions[a][b]+=1
rng=random.Random(42)
for _ in range(5):
    current="<BOS>"; output=[]
    for _ in range(20):
        next_counts=transitions.get(current)
        if not next_counts:
            break
        current=rng.choices(list(next_counts),weights=list(next_counts.values()))[0]
        if current=="<EOS>":
            break
        output.append(current)
    print(" ".join(output))
```

可能得到“狗吃鱼”等训练中没出现的组合，因为模型只有局部转移记忆；能重新组合不代表具备真实语言理解。

## 8. Brownian 与 Langevin：连续时间的噪声

标准 Brownian $B(0)=0$，不重叠时间增量独立，$B(t)-B(s)\sim N(0,t-s)$，路径连续且几乎处处不可微。离散采样按 $\sqrt{\Delta t}\,\epsilon$ 加增量，因此每个时长区间方差正比于时长，不能用 $\Delta t\epsilon$ 代替。

随机游走步长缩为 $1/\sqrt n$、每单位时间走 n 步，可在适当函数空间意义下趋于 Brownian。它提供扩散直觉，但有限步 DDPM 是噪声调度的离散链，并不是简单“纯 Brownian 从头到尾”。

能量 U 的过阻尼 Langevin 连续过程为 $dX_t=-\nabla U(X_t)dt+\sqrt{2T}\,dB_t$；在适当边界、可积性与正则条件下，其不变密度正比于 $e^{-U/T}$。Euler 离散：

$$
x_{k+1}=x_k-\eta\nabla U(x_k)+\sqrt{2T\eta}\,\epsilon_k.
$$

固定非零步长一般带离散化偏差。以 $U(x)=x^2/2$ 为例，变成 AR(1) $x'=(1-\eta)x+\sqrt{2T\eta}\epsilon$，$0<\eta<2$ 时离散不变方差为 $T/(1-\eta/2)$，**不是恰好 T**。大步长可能不稳定；减步长会减偏差，却需要更多步探索。

```python
import numpy as np
rng = np.random.default_rng(42)
eta,T = 0.1,1.
x=4.; values=[]
for i in range(50000):
    x=x-eta*x+np.sqrt(2*T*eta)*rng.normal()
    if i>=5000:
        values.append(x)
print("Langevin均值/方差", np.mean(values), np.var(values))
print("连续目标/离散理论方差", T, T/(1-eta/2))
```

T=0 时变为梯度下降，仍需稳定步长；T 增大使连续目标更分散，不代表一切任务越随机越好。双井 $U(x)=(x^2-1)^2$ 在小 T 下跨井可能极慢，但有限系统没有通用唯一“临界温度”，用模式切换次数、轨迹和多链比较探索速度。

SGLD 用适当缩放的 mini-batch 梯度与噪声近似后验动力学；渐减步长及其他条件支持渐近理论，固定步长与有限数据通常仍近似，不能称“免费得到精确后验”。若需要减少固定步长偏差可用 Metropolis 校正（如 MALA），需正确提议比。

## 9. 模拟退火：目标在变化的优化过程

用 MH 在温度 T 下的目标 $p_T(x)\propto e^{-U(x)/T}$ 采样，接受较高能量差 $\Delta U$ 的概率为 $\min(1,e^{-\Delta U/T})$（对称提议）。先高温允许跨障碍，再降低温度并记录最好的能量值，这是模拟退火。

温度不断变化的链并不在采一个固定目标。过快降温会卡局部极小值；一般日常冷却计划不保证全局最优。实践可对多个种子报告最佳值与失败率，与确定性基线比较。温度作用于目标能量，这与生成时缩放 logits 有相同指数族直觉，但不是同一个实验目的。

```python
import numpy as np
rng=np.random.default_rng(42)
def energy(x):
    return (x*x-1)**2+0.2*x
x=2.; best=x
for t in range(10000):
    temperature=max(0.01,2*(0.9995**t))
    proposal=x+rng.normal(0,0.5)
    difference=energy(proposal)-energy(x)
    if np.log(max(rng.random(),np.finfo(float).tiny))<min(0.,-difference/temperature):
        x=proposal
    if energy(x)<energy(best):
        best=x
print("最好位置/能量", best, energy(best))
print("最后位置/能量", x, energy(x))
```

最好位置应靠近偏低的负侧井；单次成功不证明算法全局收敛，实际应与网格或已知导数极值比较。

## 10. 扩散前向与反向：不能仅“减掉随机噪声”

DDPM 前向链定义 $\alpha_t=1-\beta_t$，
$x_t=\sqrt{\alpha_t}x_{t-1}+\sqrt{\beta_t}\epsilon_t$，$\epsilon_t\sim N(0,I)$。累计 $\bar\alpha_t=\prod_{s=1}^t\alpha_s$ 后：

$$
q(x_t\mid x_0)=\mathcal N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I).
$$

这允许一次直接采任意时刻，而不用真走完前 t 步。只有 $\bar\alpha_T$ 很小时，原始信号项才很弱、$x_T$ 才近似标准高斯。100 步配很小 beta 可能仍保留大量信号，必须看累计乘积，不能仅按步数声称“纯噪声”。

```python
import numpy as np
rng = np.random.default_rng(42)
signal = np.sin(np.linspace(0,2*np.pi,200))
for steps in [100,1000]:
    beta = np.linspace(0.0001,0.02,steps)
    abar = np.cumprod(1-beta)
    x = np.sqrt(abar[-1])*signal + np.sqrt(1-abar[-1])*rng.normal(size=len(signal))
    print("步数/累计alpha/剩余振幅", steps, abar[-1], np.sqrt(abar[-1]))
    print("与原信号相关", np.corrcoef(signal,x)[0,1])
```

100 步该调度的 $\bar\alpha_T$ 约0.364，信号振幅仍约0.603；1000步约 $4.0\times10^{-5}$，振幅约0.00635。短示例不能根据一条信号的相关系数证明全部目标分布已高斯。

反向近似条件转移可写 $p_\theta(x_{t-1}\mid x_t)=N(\mu_\theta(x_t,t),\sigma_t^2I)$。常见噪声预测参数化中：

$$
\mu_\theta=\frac1{\sqrt{\alpha_t}}\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right).
$$

训练从 x0、时刻 t 与独立噪声生成 xt，用网络估噪声；采样从新噪声开始并按反向链逐步生成。保存训练时真正加入的噪声然后相减，只是代数恢复原样本，不是学习了生成模型。使用“天真的减噪器”可验证计算，却不能冒充真实反向扩散。推导与条件参见[DDPM 原论文](https://arxiv.org/abs/2006.11239)，完整模型接仓库深度生成章节。

## 11. 练习与参考判断

1. 两三角形连通图去掉唯一桥后，零特征值个数？**答案：**2；有孤立节点时还会增加。浮点特征值用容差识别，不直接比较 `==0`。
2. BFS 与 Dijkstra 什么时候结果一致？**答案：**所有边成本相同且为正时，跳数与总成本成比例。负权不能套 Dijkstra。
3. 如何从 PageRank 例子验证正确？**答案：**总和1、非负、更新残差足够小；dangling 行也和为1。换起点收敛到相同结果只能验证这个具备条件的例子。
4. 如何复现两层消息传递？**答案：**对邻接均值做两次矩阵乘法，可对链图给节点0单独非零特征，检查两轮后节点2收到而更远节点尚未收到；是否包含自身看自环。
5. 在 Karate Club 小图上怎样核验？**答案：**用 `networkx.karate_club_graph()`；按本练习先转 `nx.to_numpy_array(G, weight=None)` 得无权度和 L，再算特征值/符号切分；节点 `club` 属性作为历史分组参照。标签0/1允许互换，用最佳标签匹配率或 ARI，不能断言谱聚类必等于真实分裂。该图34节点78边，度和156；加权分析需另行注明权重。
6. 如何做词级 Markov 文本生成？**答案：**对每句加 BOS/EOS，计连续词对，按来源词归一化，在 EOS 或最大步数结束。零行用终止/回退规则；若要保留长历史需把 n-gram 或完整上下文放进状态。
7. 随机游走10000步的预期位置、标准差和平均绝对距离？**答案：**0、100、约79.8，不能把三者混用；单条轨迹不足以核验分布。
8. 为什么找到不变分布还不够？**答案：**周期链可一直振荡，可约链可依初始成分停在不同分布。先检查动态条件。
9. 双井低温采样只在一个井，是目标只剩一个峰吗？**答案：**不一定，可能是未混合。用多初值、温度/步长、跨井统计复查，不能只加 burn-in 百分比。
10. 能否将100步扩散的每步真实噪声存下来，再倒着减，称为“训练了生成器”？**答案：**不能。它使用了生成时未知的信息，未学到条件噪声预测或目标分布。
