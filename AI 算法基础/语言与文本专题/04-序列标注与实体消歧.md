# 04｜序列标注、句法与实体消歧

> 先修：token与字符位置、条件概率、[序列模型](../深度学习专题/03-序列模型与机器翻译.md)。先做BIO/offset与指标，再读HMM/CRF、树结构、共指和实体链接。模型输出与知识库ID、身份簇是不同层次；不要把标签名相同视为同一实体。

## 1. 明确跨度、标签与身份

POS给每token词性，NER给带类型的跨度，共指把同文档/跨文档指向同实体的mentions成簇，实体链接再映射到指定KB revision的ID。比如“苹果”可以是公司或水果；NER=ORG只给类型，不能直接得出哪家公司的KB ID。“这家公司”不一定是命名实体，但可共指已提公司。

必须记录文本版本、tokenizer revision、token与原文 `[start,end)`映射、标签集、是否允许嵌套/不连续跨度、大小写/规范化和缺失标注。Python字符串下标一般是Unicode码点，UTF-8字节或浏览器UTF-16下标不同；规范化、清理和分词后不能继续把旧offset当原文位置。重复同名mention不能用`str.find`总取第一次。

一个句子可同时有多个实体；只选中其中一段演示BIO的交互图，不表示其余未选中的名字在完整标注中都应为O。BIO：B-X起实体，I-X延续同类型，O外部。B-X跟另一个B-X可表示两个相邻同类型实体。BILOU加入U单token、L结束，方便显式边界，但并非无条件更好。单层平坦BIO不能同时表示嵌套/重叠/不连续实体；采用多层/span模型也需对应标注与评价。

### 1.1 完整BIO往返与字符映射

此例以字符为token，检验平坦实体。选择严格拒绝非法I序列、重叠和越界；需要自动修复时，应另记录修复规则，不能像原助手函数默默吞掉非法标签。

```python
from collections import Counter
text="张三在北京大学读书"
tokens=list(text); offsets=[(i,i+1) for i in range(len(text))]

def spans_to_bio(n,spans):
    labels=["O"]*n;used=set()
    for start,end,kind in sorted(spans):
        if type(start) is not int or type(end) is not int or not 0<=start<end<=n or not kind:
            raise ValueError("合法半开token跨度/类型")
        positions=set(range(start,end))
        if positions & used: raise ValueError("平坦BIO无法表示重叠")
        used|=positions;labels[start]=f"B-{kind}"
        for i in range(start+1,end):labels[i]=f"I-{kind}"
    return labels

def bio_to_spans(labels):
    out=[];current=None
    def close():
        nonlocal current
        if current:out.append(tuple(current));current=None
    for i,label in enumerate(labels):
        if label=="O":close();continue
        if label.startswith("B-") and label[2:]:
            close();current=[i,i+1,label[2:]]
        elif label.startswith("I-") and label[2:]:
            if current is None or current[2]!=label[2:]:raise ValueError("非法I开始或跨类型")
            current[1]=i+1
        else:raise ValueError("不属于本BIO标签集")
    close();return out

gold=[(0,2,"PER"),(3,7,"ORG")]
labels=spans_to_bio(len(tokens),gold);recovered=bio_to_spans(labels)
assert recovered==gold
entities=[(offsets[s][0],offsets[e-1][1],kind) for s,e,kind in recovered]
print("BIO",labels,"原文实体",[(text[s:e],kind) for s,e,kind in entities])
for bad in [["I-PER"],["B-ORG","I-PER"]]:
    try:bio_to_spans(bad)
    except ValueError:pass
    else:raise AssertionError("非法BIO应被识别")
# exact span+type micro：重复预测仍会增加FP，不用set偷偷去重。
def entity_f1(pred,truth):
    p,g=Counter(pred),Counter(truth);tp=sum((p&g).values())
    precision=tp/sum(p.values()) if p else 0.;recall=tp/sum(g.values()) if g else 0.
    f1=2*precision*recall/(precision+recall) if precision+recall else 0.
    return precision,recall,f1
print("实体精确P/R/F1",entity_f1(entities+[entities[0]],entities))
assert entity_f1(entities+[entities[0]],entities)[0]==2/3
print("emoji码点/UTF16单位",len("😀"),len("😀".encode("utf-16-le"))//2)
```

输出张三=PER、北京大学=ORG；第三个重复预测使Precision=2/3，不能忽略它。实际指标还含document ID，分开报边界错误、类型错误、每类支持数与嵌套策略。token Accuracy高不代表实体边界F1好；允许partial overlap是另一协议，不能混报exact F1。

子词NER常把词拆成多块：可只监督首块、其他置-100，也可把后续块改I-X；special token/padding不作普通实体。两种监督有不同权重，要保word_id/offset，后处理不能把所有相邻同类B都无条件合并。标签集PRODUCT、MISC、LOC/GPE不等价，源不同checkpoint输出差异不只“模型小”造成。

## 2. 特征、词典与HMM的概率假设

词典/regex能作为可解释基线，也可通过模式覆盖新输入，不是新词覆盖必为0。大小写、词形、前后词、词缀与领域词典是候选特征；英语capitalization不直接迁移中文。歧义“Apple”、未知实体、复合名称与域变化需独立验证，不能因为同名在词典就确定类型/身份。

最常见词性基线MFT按训练词的多数标签预测，未知词按训练总体多数；保留case与否是一项明确选择。HMM则建模联合：

$$
P(y,x)=P(y_1\mid BOS)\prod_tP(x_t\mid y_t)\prod_{t>1}P(y_t\mid y_{t-1})P(EOS\mid y_T).
$$

观测条件独立/一阶转移是模型假设，不是语言事实。Viterbi在log空间找最高联合路径，$O(TK^2)$；终点要加EOS转移。未知词必须映射到有限UNK桶，否则对无限不同未见词各给同一概率不构成规范分布。源代码估了EOS却解码没用，而且tag set转list顺序不稳；以下把两点补齐。

### 2.1 完整估计、平滑、Viterbi及穷举检查

```python
import math,itertools
from collections import Counter,defaultdict
examples=[(["我","爱","猫"],["PRON","VERB","NOUN"]),
          (["你","爱","狗"],["PRON","VERB","NOUN"]),
          (["猫","跑"],["NOUN","VERB"])]
alpha=.1;transition=defaultdict(Counter);emission=defaultdict(Counter)
tags=sorted({t for words,ys in examples for t in ys});vocab=sorted({w for words,ys in examples for w in words})+["<UNK>"]
for words,ys in examples:
    if len(words)!=len(ys):raise ValueError("词/标签长度不同")
    previous="<BOS>"
    for word,tag in zip(words,ys):
        transition[previous][tag]+=1;emission[tag][word]+=1;previous=tag
    transition[previous]["<EOS>"]+=1

def tr(previous,following):
    possible=tags+["<EOS>"]
    return (transition[previous][following]+alpha)/(sum(transition[previous].values())+alpha*len(possible))
def em(tag,word):
    token=word if word in vocab else "<UNK>"
    return (emission[tag][token]+alpha)/(sum(emission[tag].values())+alpha*len(vocab))
def path_score(words,path):
    previous="<BOS>";score=0.
    for word,tag in zip(words,path):
        score+=math.log(tr(previous,tag))+math.log(em(tag,word));previous=tag
    return score+math.log(tr(previous,"<EOS>"))
def decode(words):
    if not words:return [],math.log(tr("<BOS>","<EOS>"))
    scores=[math.log(tr("<BOS>",tag))+math.log(em(tag,words[0])) for tag in tags];backs=[]
    for word in words[1:]:
        nxt=[];back=[]
        for tag in tags:
            candidates=[s+math.log(tr(prev,tag)) for s,prev in zip(scores,tags)]
            best=max(range(len(tags)),key=lambda j:candidates[j])
            nxt.append(candidates[best]+math.log(em(tag,word)));back.append(best)
        scores=nxt;backs.append(back)
    final=[s+math.log(tr(tag,"<EOS>")) for s,tag in zip(scores,tags)]
    last=max(range(len(tags)),key=lambda j:final[j]);path=[last]
    for back in reversed(backs):path.append(back[path[-1]])
    return [tags[j] for j in reversed(path)],max(final)
for tag in tags:
    assert math.isclose(sum(em(tag,w) for w in vocab),1.)
for previous in ["<BOS>"]+tags:
    assert math.isclose(sum(tr(previous,t) for t in tags+["<EOS>"]),1.)
words=["我","爱","小猫"]
path,score=decode(words)
exact=max(itertools.product(tags,repeat=len(words)),key=lambda p:path_score(words,p))
assert tuple(path)==exact and math.isclose(score,path_score(words,exact))
print("未知词HMM路径/log概率",path,round(score,6),"穷举一致",True)
print("空句解码",decode([])[0])
```

平滑会给训练没见的转移非零质量，不能拿这个小概率例宣称真实93%准确率。HMM也能借邻接转移处理部分`saw`上下文，不是任何词义歧义都无法解决；长距离/任意特征是限制。准确率需同语料、标签、切分和未知词率比较，超过某次人类一致率不自动证明测试过拟合。

## 3. 线性链CRF：归一化整条标签路径

CRF建模 $P(y\mid x)$，给定输入可用任意可用特征。令emission $e_t(k)$、转移 $A_{jk}$、开始/结束分数 $b_k,z_k$：

$$
s(x,y)=b_{y_1}+\sum_t e_t(y_t)+\sum_{t>1}A_{y_{t-1},y_t}+z_{y_T},\quad
\log P(y\mid x)=s(x,y)-\log\sum_{y'}e^{s(x,y')}.
$$

logZ用forward的logsumexp，Viterbi把同一递推中的sum改max并保存回指。CRF不是HMM的条件概率表，不要求每行transition softmax。学习转移倾向并不等于硬BIO约束：`all_possible_transitions=True`只增加可学特征，非法路径仍可能获高分；需要明确禁止非法开始/转移或在解码/训练使用一致约束。

### 3.1 完整受约束CRF与BiLSTM emissions

本例K=3（O/B-ORG/I-ORG），训练emission网络和transition，START/END教学固定0。可把边界分数也设参数。两个不同长度输入通过pack避免反向LSTM读取padding；对每条有效序列计算CRF，而不把padding转移混进logZ。

```python
import itertools
import torch
from torch import nn
from torch.nn.utils.rnn import pack_padded_sequence,pad_packed_sequence
torch.set_num_threads(1);torch.manual_seed(42)
labels=["O","B-ORG","I-ORG"]
allowed=torch.tensor([[1,1,0],[1,1,1],[1,1,1]],dtype=torch.bool)
start_allowed=torch.tensor([1,1,0],dtype=torch.bool)

def effective(A):return A.masked_fill(~allowed,-torch.inf)
def score_path(E,A,path):
    if not path or not start_allowed[path[0]]:raise ValueError("非法开始/空路径")
    if any(not allowed[a,b] for a,b in zip(path,path[1:])):raise ValueError("非法BIO转移")
    return sum(E[t,k] for t,k in enumerate(path))+sum(A[a,b] for a,b in zip(path,path[1:]))
def log_partition(E,A):
    if E.ndim!=2 or E.shape[1]!=3 or not len(E):raise ValueError("有效[T,3]emission")
    trans=effective(A);alpha=E[0].masked_fill(~start_allowed,-torch.inf)
    for row in E[1:]:alpha=torch.logsumexp(alpha[:,None]+trans,dim=0)+row
    return torch.logsumexp(alpha,dim=0)
def viterbi(E,A):
    trans=effective(A);value=E[0].masked_fill(~start_allowed,-torch.inf);backs=[]
    for row in E[1:]:
        value,back=(value[:,None]+trans).max(0);value=value+row;backs.append(back)
    last=int(value.argmax());path=[last]
    for back in reversed(backs):path.append(int(back[path[-1]]))
    return list(reversed(path)),value.max()

E=torch.tensor([[.1,2.,5.],[0.,.5,2.1],[2.2,.4,.1]])
A=torch.zeros(3,3)
legal=[]
for path in itertools.product(range(3),repeat=3):
    try:legal.append((path,score_path(E,A,path)))
    except ValueError:pass
path,score=viterbi(E,A)
assert path==[1,2,0] and torch.isclose(score,max(s for _,s in legal))
assert torch.isclose(log_partition(E,A),torch.logsumexp(torch.stack([s for _,s in legal]),0))
print("独立argmax/约束路径",E.argmax(1).tolist(),[labels[k] for k in path])

class Tagger(nn.Module):
    def __init__(self):
        super().__init__();self.embedding=nn.Embedding(10,4,padding_idx=0)
        self.lstm=nn.LSTM(4,3,batch_first=True,bidirectional=True)
        self.projection=nn.Linear(6,3);self.transition=nn.Parameter(torch.zeros(3,3))
    def forward(self,ids,lengths):
        packed=pack_padded_sequence(self.embedding(ids),lengths.cpu(),batch_first=True,enforce_sorted=False)
        states,_=self.lstm(packed);states,_=pad_packed_sequence(states,batch_first=True,total_length=ids.shape[1])
        return self.projection(states)
model=Tagger();ids=torch.tensor([[3,4,5],[6,7,0]]);lengths=torch.tensor([3,2])
emissions=model(ids,lengths);gold=[[1,2,0],[0,1]]
loss=sum(log_partition(emissions[b,:n],model.transition)-score_path(emissions[b,:n],model.transition,gold[b])
         for b,n in enumerate(lengths.tolist()))/len(ids)
loss.backward()
assert torch.isfinite(loss) and all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
print("BiLSTM/CRF shape与NLL",tuple(emissions.shape),round(loss.item(),6))
```

首步greedy选I非法，约束解为B/I/O；logZ与小穷举相同，训练图有有限梯度。仅合成ID/分数验证算法，不是CoNLL训练或NER性能。平坦BIO约束仍不支持嵌套实体，Transformer+token head也没有自动解决它。CRF参数/正则/目标尺度由训练数据选择，不按500/1000/几万句硬设模型禁用门槛。

## 4. POS标签、依存树与解析操作

UD的UPOS有17类；Penn的词性细分、标点/特殊标签计数和旧工具输出要分别说明，不能把“36”当所有PTB字段总数。`token.pos_`可为粗粒度词性，`tag_`/`dep_`取决于模型的细分/依存体系；spaCy英语`prep/pobj`等不自动等于UD的`case/obl`。不同语言的标注和树规范也非完全无关。固定标签依次落下的动画只是呈现顺序，不能证明真实POS模型必须从左往右解码；固定依存弧也没有执行解析搜索。

成分树表示NP/VP等嵌套短语；依存树表示head→dependent加关系，每个词通常一个head、一个人工ROOT。构造逐词最高分head可能形成环，不能当合法解析；图方法还需最大生成树或projective Eisner等全局约束。transition方法用stack/buffer和弧操作，arc-standard基本版处理projective树，非投射结构需额外动作或其他算法。

### 4.1 完整arc-standard状态机与树核查

下例动作是教学给定的正确轨迹，**不是从语料学出的自动parser**。它完整实现SHIFT/LEFT_ARC/RIGHT_ARC的结构效果和最终树检查，方便下一步把动作选择器换成可训练分类器。

```python
def parse_actions(tokens,actions):
    n=len(tokens);stack=[0];buffer=list(range(1,n+1));heads={}
    for action,relation in actions:
        if action=="SHIFT":
            if not buffer:raise ValueError("空buffer不可SHIFT")
            stack.append(buffer.pop(0));continue
        if len(stack)<2:raise ValueError("弧操作需要两个stack元素")
        if action=="LEFT":head,dependent=stack[-1],stack[-2];position=-2
        elif action=="RIGHT":head,dependent=stack[-2],stack[-1];position=-1
        else:raise ValueError("未知操作")
        if dependent==0 or dependent in heads:raise ValueError("不能给ROOT/已定head词再定head")
        heads[dependent]=(head,relation);stack.pop(position)
    if buffer or stack!=[0] or set(heads)!=set(range(1,n+1)):raise ValueError("未完成解析")
    if n and sum(head==0 for head,rel in heads.values())!=1:raise ValueError("本协议单ROOT")
    for dependent in heads:
        visited=set();node=dependent
        while node:
            if node in visited or node not in heads:raise ValueError("环或断开")
            visited.add(node);node=heads[node][0]
    return heads
words=["我","爱","北京"]
actions=[("SHIFT",None),("SHIFT",None),("LEFT","nsubj"),("SHIFT",None),
         ("RIGHT","obj"),("RIGHT","root")]
heads=parse_actions(words,actions)
print("依存弧",[("ROOT" if h==0 else words[h-1],words[d-1],rel) for d,(h,rel) in sorted(heads.items())])
assert heads=={1:(2,"nsubj"),3:(2,"obj"),2:(0,"root")}
try:parse_actions(words,[("RIGHT","root")])
except ValueError:print("非法动作已拒绝",True)
else:raise AssertionError("不能接受非法操作")
```

UAS衡量head正确率，LAS还要求relation正确；标点是否排除、分词是否金标准要固定。成分评价通常比较带标签constituent跨度而非词Accuracy。句法树可帮助抽取，但不是每个JSON/信息抽取系统必需，也不能凭语法正确证明事实正确。源依存SVG虽写“head→dependent”，若干箭头实际从从属词指向核心词；学习时按明确的 `(head,dependent,relation)` 三元组核对，而不照搬箭头方向。SVO规则须处理被动、并列、省略、否定与介词附着：`nsubj:pass`不是普通主动施事，缺省主语不能编造。

## 5. 共指：mention检出、候选排名与成簇

共指是同指，不是一般关联：汽车与“车轮”是bridging部分关系，不应直接合并为同实体。命名、人称/指示代词、普通名词描述、同位语都可能为mention；先行/后行照应、中文零代词与跨文档需要不同候选范围，纯“只看最近K个前词”不能覆盖全部。来源图中的“公司展示一台笔记本。它将在六月发货”也不能仅凭图中颜色就把“它”定为公司；产品更合理还是公司取决于具体上下文，应保留歧义并标注。

mention-pair模型预测是否同指后成簇，一条误连经传递闭包会把大簇过度合并；mention-ranking为每mention比较候选antecedent与dummy“无先行词”，防止强选最接近人名。span模型先枚举限长跨度、mention得分与候选剪枝，再算antecedent分数和成簇；2017 Lee模型并非Transformer原生，现代可替换表示。人名不必带性别，代词也不总能唯一解析，不用硬编码gender当身份事实。原规则程序实际将 `Her → AI`，说明名字/大小写/最近距离规则也会误连，而不是运行无异常就理解了文档。

令候选跨度表示 $g_i$ 拼接起止上下文、跨度内 attention 加权词向量和宽度特征，mention 网络得到 $s_m(i)$，pair 网络得到 $s_a(i,j)$；真实候选分数 $s(i,j)=s_m(i)+s_m(j)+s_a(i,j)$，dummy 分数固定 0。对保留下来的先行词集合归一化 $P(y_i=j)=\mathrm{softmax}_j s(i,j)$。一个mention可有多个正确先行词，训练用 $-\log\sum_{j\in G_i}P(y_i=j)$，而不是随意只选一个 gold；没有可用先行词时 gold 可为 dummy。剪枝会影响 gold 召回和端到端效果，需要单独统计。2017 span 方法从字符/词 embedding 和 BiLSTM 得上下文，不是 Transformer 原架构。[原论文](https://aclanthology.org/D17-1018/)解释了这一边缘似然训练。

### 5.1 完整排名到簇的小fixture

```python
text="张三到了。张三说，他想休息。李四点头。"
spans=[(0,2),(5,7),(9,10),(14,16)]
assert [text[s:e] for s,e in spans]==["张三","张三","他","李四"]
# 预造候选分数，只检验ranking与聚类，不声称自动理解此段。
candidate_scores=[{}, {0:2.}, {0:.5,1:.8}, {0:-.4,1:-.4,2:-.4}]
parents=list(range(len(spans)))
def find(i):
    while parents[i]!=i:parents[i]=parents[parents[i]];i=parents[i]
    return i
for i,scores in enumerate(candidate_scores):
    eligible=[(score,j) for j,score in scores.items() if j<i]
    best,j=max(eligible,default=(0.,-1))
    if best>0.:parents[find(i)]=find(j) # dummy无先行词分数0
clusters={}
for i,span in enumerate(spans):clusters.setdefault(find(i),[]).append(span)
print("mention簇",[[text[s:e] for s,e in group] for group in clusters.values()])
assert len(clusters)==2
ambiguous="阿明告诉阿强：他获奖了。"
print("歧义必须保留",ambiguous,"候选阿明/阿强，仅凭最近距离不能证明正确")
```

保留每次mention offset、antecedent候选/分数、dummy和簇ID。模型或LLM给“张三”字符串无法区分两次出现，不允许把无offset输出硬塞原文。滑窗会断跨窗口引用，应保持重叠、mention原位置与可追溯的跨窗合并；没有固定2000-token安全边界。NER不是检出全部nominal/pronoun的前提，先NER再coref只是可选流水线，不是唯一顺序。

### 5.2 完整共同mention全集的MUC/B³/CEAF-e例

不同指标关注连通关系、每mention簇纯度和全局实体对齐。MUC 对金簇 $G$ 的 recall 为 $\sum_G(|G|-\mathrm{parts}_{P}(G))/\sum_G(|G|-1)$，precision 交换 gold/pred；B³ 对每个mention平均交集/预测簇大小和交集/金簇大小；CEAF-e 用 $\phi_4(G,P)=2|G\cap P|/(|G|+|P|)$ 后通过一对一最优匹配最大化总相似度，以两侧簇数归一化。CoNLL F1常为MUC、B³、CEAF-φ4三个F1的算术平均，不能先平均P/R再算F1。以下限同一mention全集、无遗漏、无重叠分簇，不冒充含缺失跨度/单例规则的完整CoNLL官方实现。

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def f1(p,r):return 2*p*r/(p+r) if p+r else 0.
def cluster_scores(gold,pred):
    gold,pred=[set(c) for c in gold],[set(c) for c in pred]
    def validate(clusters):
        if any(not c for c in clusters):raise ValueError("空簇")
        joined=set().union(*clusters)
        if sum(map(len,clusters))!=len(joined):raise ValueError("一个mention不能在两个身份簇")
        return joined
    universe=validate(gold)
    if universe!=validate(pred) or not universe:raise ValueError("本例要求非空相同mention全集")
    def muc(source,other):
        denominator=sum(len(c)-1 for c in source)
        numerator=sum(len(c)-sum(bool(c&d) for d in other) for c in source)
        return numerator/denominator if denominator else 0. # 本例退化约定
    mp,mr=muc(pred,gold),muc(gold,pred)
    gp={m:c for c in gold for m in c};pp={m:c for c in pred for m in c}
    bp=np.mean([len(gp[m]&pp[m])/len(pp[m]) for m in universe])
    br=np.mean([len(gp[m]&pp[m])/len(gp[m]) for m in universe])
    similarity=np.array([[2*len(g&p)/(len(g)+len(p)) for p in pred] for g in gold])
    rows,cols=linear_sum_assignment(-similarity)
    aligned=similarity[rows,cols].sum();cp=aligned/len(pred);cr=aligned/len(gold)
    values={"MUC":f1(mp,mr),"B3":f1(bp,br),"CEAF_e":f1(cp,cr)}
    values["CoNLL教学均值"]=float(np.mean(list(values.values())))
    return values

gold=[[0,1,2],[3,4]];pred=[[0,1],[2,3,4]]
print("混合分簇",cluster_scores(gold,pred))
values=cluster_scores(gold,pred)
assert np.isclose(values["MUC"],2/3) and np.isclose(values["CEAF_e"],.8)
print("全部单例",cluster_scores(gold,[[i] for i in range(5)]))
```

要分开mention检出P/R、同指簇质量与下游效果；仅coref已给gold mentions的分数不能当端到端效果。BLANC 把所有mention对分成同指正链接和非同指负链接，分别计算 P/R，再按其规定合成指标，避免全部单例凭大量非同指对刷总体Accuracy。LEA 为每个实体赋重要性（常为簇大小），用恢复正确的簇内链接数/全部簇内链接数计算 resolution，再按重要性加权；precision 交换两侧。单例的链接数为0、遗漏mention如何处理都有专门约定，不能私设0后冒充官方值。本章只实作上面明确的共同mention三指标。完整协议核验见[官方评分一致性研究](https://www.cs.cmu.edu/~hovy/papers/14ACL-coref-scoring-standard.pdf)和[LEA原论文](https://aclanthology.org/P16-1060/)。实际按对应基准官方scorer处理跨度缺失、重复、singleton与跨文档边界，源码只给简化链接准确率不是CoNLL。

## 6. 实体链接：候选上界、语境和NIL

给mention表面形式与context，先由别名/稀疏/稠密检索找候选，再用先验+语境或cross-encoder重排。BLINK双塔与rerank、ELQ联合检出、GENRE生成检索并不是全都“一次forward自带NER”。预训练通用句向量加`[MENTION]`字符串可作baseline，但不等于学会BLINK标记/目标。

生成式检索通常生成token化title/ID序列，用候选trie约束合法输出；不是必逐字符，合法KB ID也不证明指代正确。JSON格式约束不能替代实体白名单/语境判断。KB更新时保revision、描述和别名索引版本，ID重定向与废弃项需可查。

候选Recall@K以正确实体是否在列表计算，ranking准确率须注明条件在gold实体已出现时；NER mention召回又是另一个上游指标。若候选召回0.8、条件top1准确0.99，已给正确mention的成功率为0.792，最高不超过0.8；不是“候选有80%就全管道80%”。端到端评价要求正确文档/跨度和KB ID。

NIL表示真实实体不在目标KB，检索没候选或低分只是不确定，不能自动证明KB不存在。需要区分no_candidate、ambiguous、link、经标注/策略确认的NIL；多个未知实体也不能全部合并为同一个“NIL”身份。

### 6.1 完整先验+语境、小候选集与拒识

```python
import math
KB={"company":{"name":"苹果公司","words":{"手机","电脑","科技"}},
    "fruit":{"name":"苹果水果","words":{"水果","甜","树"}}}
alias={"苹果":[("company",.7),("fruit",.3)]}
def link(surface,context_words,margin=.1):
    candidates=alias.get(surface,[])
    if not candidates:return {"status":"no_candidate","id":None,"KB_revision":"fixture-v1"}
    context=set(context_words);ranked=[]
    for eid,prior in candidates:
        words=KB[eid]["words"];similarity=len(context&words)/max(len(context|words),1)
        score=similarity+.05*math.log(prior)
        ranked.append((score,eid))
    ranked.sort(reverse=True)
    gap=ranked[0][0]-ranked[1][0] if len(ranked)>1 else float("inf")
    status="link" if gap>=margin and ranked[0][0]>0 else "ambiguous"
    return {"status":status,"id":ranked[0][1] if status=="link" else None,
            "candidates":ranked,"KB_revision":"fixture-v1"}
assert link("苹果",["手机","电脑"])['id']=="company"
assert link("苹果",["水果","甜"])['id']=="fruit"
assert link("苹果",["报道","出现"])['status']=="ambiguous"
assert link("新名字",["手机"])['status']=="no_candidate"
for context in [["手机","电脑"],["水果","甜"],["报道","出现"]]:print(context,link("苹果",context))
# 这里语境已经是词集合，真实tokenizer/offset在前一层，分数不是概率。
```

此margin与先验系数是fixture配置，不是生产NIL阈值。测试低频同名实体、未知KB、跨语言别名、候选漏掉、边界切半和多个mention同指一致性。context过短/歧义时保留候选而非“选最热门”，严格候选限定也可能把真实对象排除，需要单独测candidate recall。

## 7. 练习与参考判据

1. 十句BIO往返应验证什么？**参考：**同一tokenization和半开跨度、相邻实体、越界/重叠、非法I、空输入和类型；字符映射不因清理/Unicode编码改变而错位。
2. CRF是否天然保证BIO合法？**答案：**不，软转移特征只学倾向。硬约束需训练和decode一致，且必须证明legal gold仍可达。
3. HMM未知词与EOS怎样检查？**答案：**所有未见词映到同UNK桶，概率表行和为1，解码加入EOS；小穷举与Viterbi相同。85/93/97不是固定验收分数。
4. BiLSTM-CRF/Transformer比较什么？**参考：**同数据/标注/划分、有效长度、内存/时间与exact实体F1；不从几百句硬决定不可训练某模型，不能忽略nested类型。
5. SVO抽取怎样评估？**参考：**人工GT三元组+跨度/语义角色、否定/被动/并列/省略子集；parse树正确也不保证抽取关系正确。非法动作/环/多ROOT应被识别。
6. 共指“车轮”应加入车簇吗？**答案：**不是同指，是部分/bridging关系；跨任务不要直接union。性别、最近距离和同名都是候选线索，不是身份事实。
7. 模型只报字符串mentions可以评价吗？**答案：**需要能定位唯一原文offset/版本；相同字符串多次出现要分别记录，不默认第一次。mention与簇指标分开。
8. CoNLL均值怎么算？**答案：**三个F1平均；共同mention小例不是含漏检的官方端到端score，不能把MUC/B3/CEAF不同目标混成token Accuracy。
9. 候选召回80%、条件ranking99%整管道多少？**答案：**约79.2%（还假设mention已正确）；上游NER漏掉会更低。空候选不能直接确认NIL。
10. 50歧义mention句向量/100文章coref/1000实体KB练习怎样验收？**参考：**预定义KB revision、span/类/identity和真实标注，分候选召回、conditional ranking、NIL与端到端；本批未下载模型/数据或伪造这些实验。
