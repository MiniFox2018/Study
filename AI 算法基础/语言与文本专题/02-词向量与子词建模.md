# 02｜词向量与子词建模

[上一章](01-文本预处理与稀疏表示.md)的稀疏列表示“出现了哪个词”，本章学习如何让不同词共享统计信息，以及如何把未见词拆成可表示的片段。向量空间、梯度与稳定损失分别接[向量空间](../数学与数值计算专题/01-向量空间与线性映射.md)、[微积分与自动微分](../数学与数值计算专题/06-微积分梯度与自动微分.md)、[前向反向与损失实现](../深度学习专题/16-前向反向与损失实现.md)。各程序独立运行；小语料只能验证算法，不承担自然语言语义质量证明。

## 1. 静态向量、上下文向量与分词不是一件事

Embedding 表 $E\in\mathbb R^{|V|\times d}$ 给每个词/Token ID 一行向量；它等价于 one-hot 乘矩阵，实际查表更省内存。静态词向量的 `bank` 在不同句子中初始向量相同；上下文编码器可结合其他 Token 得到不同表示。使用静态输入的下游 RNN等也能结合上下文，不能推成“只要静态词向量就永远无法区分词义”。句向量还需要池化或句级目标，不是随便取某个 Token 行。

分布假设是“相似上下文提供意义相似的证据”。同义词、反义词都可能共享上下文，因此近邻不是词典等义关系。二维图中的 king/man/woman/queen 常是手工布点，线性类比是可以检验的统计现象，不是训练强制得到的几何公理；降维投影还会扭曲距离。用领域近邻、检索/分类任务和错误样本联合评价，类比成绩不能单独证明模型好。

## 2. Word2Vec：预测任务学习两张表

Skip-gram 用中心词预测窗口中的上下文；CBOW 把上下文向量求和/平均后预测中心。`The cat sat on the mat` 中以 cat 为中心、半径 2，实际上下文是 The、sat、on，句首边界使窗口少于四词。固定/随机窗口、频繁词下采样、是否跨句都会改变训练对。

用输入表 $V$ 和输出表 $U$，全 softmax 为：

$$P(o\mid c)=\frac{\exp(u_o^T v_c)}{\sum_{w\in Vocab}\exp(u_w^Tv_c)}.$$

每对枚举全词表的代价为 $O(|Vocab|d)$。分层 softmax 用树路径；负采样把训练改成区分语料正对与噪声对，成本约 $O((K+1)d)$。它们不是完全相同的概率模型。

### 2.1 SGNS 损失、噪声与梯度

对正对 $(c,o)$、噪声词 $n_{1:K}$，最小化：

$$L=\operatorname{softplus}(-u_o^Tv_c)+\sum_{k=1}^{K}\operatorname{softplus}(u_{n_k}^Tv_c).$$

$softplus(x)=\log(1+e^x)$ 用 `logaddexp` 稳定计算。将正/负输出 ID 合并成 $i_j$，标签为 $y_0=1,y_{j>0}=0$，$s_j=u_{i_j}^Tv_c$，$g_j=\sigma(s_j)-y_j$，则：

$$\frac{\partial L}{\partial v_c}=\sum_j g_j u_{i_j},\quad
\frac{\partial L}{\partial u_{i_j}}\mathrel{+}=g_j v_c.$$

同一个负词可能采样多次，要累计而不是用高级索引覆盖。算本次梯度时使用更新前的两张表；原地更新输出表再算中心梯度会变成另一个算法。

经典噪声分布常设 $q(w)\propto f(w)^{3/4}$，它是频率分布的经验平滑，不是定理要求。噪声词可以是实际共现词，甚至可能抽到当前正词；其标签指“来自噪声采样过程”，不是“这个词绝不会共现”。若实现排除某些词，应说明条件分布已变且补采样保证数量，不要把均匀、排除中心和正词的简化例子称原论文完整设置。SGNS的 $\sigma(s)$ 是对训练二分类任务的分数，不是词表归一化的 $P(o\mid c)$。

频繁词下采样旨在减少功能词主导和训练量。论文简化弃置率 $1-\sqrt{t/f(w)}$ 对高频词适用，需截到合法区间；常见工程保留率为 $\min[1,(\sqrt{f/t}+1)t/f]$。$f$ 是相对词频，阈值 $t$ 与语料有关。两式不是完全同一规则；删除词会改变相邻关系，应在形成窗口前应用并记录。

### 2.2 完整训练与重复索引梯度核对

```python
import numpy as np
from collections import Counter
from scipy.special import expit

rng = np.random.default_rng(7)
docs = [s.split() for s in ['cat drinks milk', 'dog drinks water',
        'cat eats fish', 'dog eats meat', 'kitten drinks milk', 'puppy drinks water']]*8
vocab = sorted({w for s in docs for w in s})
ids = {w:i for i,w in enumerate(vocab)}
freq = Counter(w for s in docs for w in s)
q = np.array([freq[w]**.75 for w in vocab], dtype=float)
q /= q.sum()
size, dim = len(vocab), 8
V = rng.normal(0,.1,(size,dim))
U = rng.normal(0,.1,(size,dim))

def loss_grad(V,U,c,out,y):
    v = V[c].copy()
    u = U[out].copy()
    score = u @ v
    loss = np.sum(np.logaddexp(0,score)-y*score)
    g = expit(score)-y
    gv = np.zeros_like(V)
    gu = np.zeros_like(U)
    gv[c] = g @ u
    np.add.at(gu,out,g[:,None]*v)
    return loss,gv,gu

# 重复负词，并检查两张表各一项；其余数学方法见梯度专题。
out, y = np.array([1,2,2]), np.array([1.,0.,0.])
_,gv,gu = loss_grad(V,U,0,out,y)
for table,grad,row,col in [(V,gv,0,1),(U,gu,2,1)]:
    old,eps = table[row,col],1e-6
    table[row,col]=old+eps
    a=loss_grad(V,U,0,out,y)[0]
    table[row,col]=old-eps
    b=loss_grad(V,U,0,out,y)[0]
    table[row,col]=old
    assert abs((a-b)/(2*eps)-grad[row,col])<1e-7

pairs = []
for s in docs:
    seq=[ids[w] for w in s]
    for i,c in enumerate(seq):
        for j in range(max(0,i-2),min(len(seq),i+3)):
            if j!=i:
                pairs.append((c,seq[j]))
# 固定探针对用于比较同一个目标，避免每轮换负样本造成不可比。
probe=[(c,np.r_[o,rng.choice(size,3,p=q)],np.r_[1.,np.zeros(3)])
       for c,o in pairs[:30]]
def probe_loss():
    return np.mean([loss_grad(V,U,c,out,y)[0] for c,out,y in probe])
before=probe_loss()
for epoch in range(45):
    rng.shuffle(pairs)
    for c,o in pairs:
        out=np.r_[o,rng.choice(size,3,p=q)]
        y=np.r_[1.,np.zeros(3)]
        _,gv,gu=loss_grad(V,U,c,out,y)
        V-=.025*gv
        U-=.025*gu
print('固定探针平均损失',round(before,4),'→',round(probe_loss(),4))
assert np.isfinite(V).all() and np.isfinite(U).all()
norm=np.linalg.norm(V,axis=1)
if (norm==0).any():
    raise ValueError('零向量不能计算余弦')
unit=V/norm[:,None]
sim=unit @ unit[ids['cat']]
sim[ids['cat']]=-np.inf
print('cat 近邻',[(vocab[i],round(float(sim[i]),3)) for i in np.argsort(-sim)[:3]])
print('重复负样本梯度检查通过')
```

使用中心表作为词向量是常见选择，输出表或两表组合也可测试。只看范数低于 .01或大于100不能判定训练 bug：尺度取决于初始化、维度、目标和正则；先查非有限值、零向量、相对异常、梯度和实际任务。训练语料越小，近邻和类比越不稳定；不要不断调 seed/epoch只为演出预期答案。

## 3. GloVe：拟合全局共现的对数

构建 $X_{ij}$ 表示词 $j$ 出现在中心词 $i$ 窗口的计数，可按距离 $1/r$ 加权。保留正计数的稀疏项，不必生成全 $|V|^2$ 矩阵。用两张向量表和两个偏置拟合：

$$J=\frac12\sum_{X_{ij}>0}f(X_{ij})[v_i^Tu_j+b_i+\tilde b_j-\log X_{ij}]^2,$$
$$f(x)=\begin{cases}(x/x_{max})^\alpha&0<x<x_{max}\\1&x\ge x_{max}.\end{cases}$$

采用 $1/2$ 后梯度是 $f(x)\delta$；若损失不含 $1/2$，梯度需乘 2。这个函数降低小计数不可靠项的权重，高计数封顶为 1；相对直接以计数为权重，它也避免高频对无界增长，**不是函数值对高频对递减**。GloVe不只是对原始计数矩阵做普通 SVD，也不是训练一次闭式求解。

### 3.1 完整共现构造、训练与有限差分

```python
import numpy as np
from collections import defaultdict

rng=np.random.default_rng(3)
docs=[s.split() for s in ['cat drinks milk','dog drinks water',
                         'cat eats fish','dog eats meat']]*5
words=sorted({w for s in docs for w in s})
ids={w:i for i,w in enumerate(words)}
co=defaultdict(float)
for s in docs:
    seq=[ids[w] for w in s]
    for i,a in enumerate(seq):
        for j in range(max(0,i-2),min(len(seq),i+3)):
            if i!=j:
                co[a,seq[j]]+=1/abs(i-j)
I=np.array([i for i,j in co]);J=np.array([j for i,j in co])
x=np.array(list(co.values()))
f=np.minimum((x/10)**.75,1)
V=rng.normal(0,.1,(len(words),5));U=rng.normal(0,.1,V.shape)
b=np.zeros(len(words));d=np.zeros_like(b)
def objective():
    delta=np.sum(V[I]*U[J],axis=1)+b[I]+d[J]-np.log(x)
    g=f*delta/len(x)
    gv=np.zeros_like(V);gu=np.zeros_like(U)
    gb=np.zeros_like(b);gd=np.zeros_like(d)
    np.add.at(gv,I,g[:,None]*U[J]);np.add.at(gu,J,g[:,None]*V[I])
    np.add.at(gb,I,g);np.add.at(gd,J,g)
    return np.mean(.5*f*delta**2),(gv,gu,gb,gd)
before,grads=objective()
old,eps=V[0,0],1e-6
V[0,0]=old+eps;a=objective()[0]
V[0,0]=old-eps;c=objective()[0]
V[0,0]=old
assert abs((a-c)/(2*eps)-grads[0][0,0])<1e-8
for _ in range(1200):
    _,grads=objective()
    for table,g in zip((V,U,b,d),grads):
        table-=.15*g
print('正共现项',len(co),'GloVe 平均损失',round(before,4),'→',round(objective()[0],4))
assert objective()[0]<before
E=V+U
print('最终词表与向量形状',words,E.shape)
```

最终可用 $V+U$，但必须按实际任务验证；不是“相加保证更好”。窗口、距离权重、对称化、最小词频、$x_{max}$、$\alpha$ 都是可复现设置。零计数没有 $\log0$，本目标忽略它们，而 SGNS 通过噪声构造负例，两者监督形式不同。

## 4. FastText：共享字符片段，而非仅列出片段

给 `where` 加边界成 `<where>`，3-gram含 `<wh,whe,her,ere,re>`；更长 n-gram与全词项也可参与。`whereupon` 共用一些片段，于是稀有/未见词可以利用训练过的片段向量。边界使词首、词尾和词内部片段不同。词形相似不保证语义相似，拼写错误或新词可能组合出不准确向量。

原方法将 whole-word 与字符 n-gram表的向量求和，用于 skip-gram等目标；实际实现用哈希桶节省词表，可能碰撞。把未训练的随机 n-gram向量相加只是结构演示，不是已获得语义。下面使用显式片段词表、集合去重和**平均**组合以控制尺度，是标明的教学变体。原实现whole-word词项与同字面字符片段可以使用不同参数，重复片段也可按出现次数计入；这里合成一个片段键集合，不复刻 fastText 的哈希/优化全部细节。

### 4.1 可运行的子词共享训练和 OOV 组合

```python
import numpy as np
from collections import Counter
from scipy.special import expit

def grams(w):
    s='<'+w+'>'
    return sorted({s}|{s[i:i+n] for n in range(3,7)
                             for i in range(len(s)-n+1)})
rng=np.random.default_rng(9)
docs=[s.split() for s in ['playing football','played football','player team',
                         'walking outside','walked outside','walker outside']]*8
words=sorted({w for s in docs for w in s});wid={w:i for i,w in enumerate(words)}
pieces=sorted({g for w in words for g in grams(w)})
pid={g:i for i,g in enumerate(pieces)}
comp={w:np.array([pid[g] for g in grams(w)]) for w in words}
Z=rng.normal(0,.1,(len(pieces),8));U=rng.normal(0,.1,(len(words),8))
f=Counter(w for s in docs for w in s);q=np.array([f[w]**.75 for w in words]);q/=q.sum()
pairs=[(a,wid[b]) for s in docs for a,b in (s,s[::-1])]
for epoch in range(80):
    rng.shuffle(pairs)
    for word,o in pairs:
        ix=comp[word];v=Z[ix].mean(axis=0)
        out=np.r_[o,rng.choice(len(words),3,p=q)]
        u=U[out].copy();score=u@v;y=np.r_[1.,np.zeros(3)]
        g=expit(score)-y
        gz=(g@u)/len(ix)
        np.add.at(Z,ix,-.025*np.broadcast_to(gz,(len(ix),8)))
        np.add.at(U,out,-.025*g[:,None]*v)

def compose(w):
    ix=[pid[g] for g in grams(w) if g in pid]
    if not ix:
        raise ValueError('该 OOV 没有任何已训练片段，不能声称有可靠向量')
    return Z[ix].mean(axis=0),len(ix)
for w in ['playing','players','walkers']:
    v,n=compose(w)
    print(w,'已训练片段',n,'向量范数',round(float(np.linalg.norm(v)),4))
a,b=set(grams('playing')),set(grams('played'))
print('playing/played 片段 Jaccard',round(len(a&b)/len(a|b),4))
assert np.isfinite(Z).all()
```

Morphology丰富、领域新词多时可将 FastText作为基线；它仍是静态词表示，不能自动处理多义、反讽或跨语言对齐。GloVe通常需要已有词项；子词共享帮助覆盖但不会凭空提供未训练语言能力。词向量文件下载、授权和大小需在真实使用时确认，本次没有下载预训练向量。

## 5. BPE：学习规则与编码新输入分开

字符 BPE先把每个训练词写成字符与词尾标记，按词频累积相邻对次数，每次合并频率最高的一对，再重新统计。固定并列决策才可复现。推理时使用已学合并**次序/排名**，不是在新输入上重新找最高频对。`(l,o)、(e,r)、(lo,w)、(low,er)` 能把 `l o w e r` 合成 `lower`，但这是指定规则示意；是否先选这组对取决于训练计数。

普通字符 BPE 对未见字符仍可能 OOV。保留所有 256 个字节的 byte BPE对有效 UTF-8输入可回退到字节，不需要 UNK；只训练出现过的字节就没有该保证。字符、字节、完整词不是同一个单位。字节 BPE编码是无损字符串覆盖，不是语义覆盖；一个 emoji可能含多个码点及字节，用多 Token也不表示它被误识别。

### 5.1 完整词内 BPE，保留初始与中间词表

原程序只统计最终训练分段里的片段当“词表大小”，会遗漏编码新词仍需要的原始字符和中间片段。下面从初始字符开始保留所有已引入符号，词频质量用 `+=` 合并，未知字符明确拒绝，训练规则不在推理时改变。

```python
from collections import Counter

END='</w>'
def merge(seq,pair):
    out=[];i=0
    while i<len(seq):
        if i+1<len(seq) and tuple(seq[i:i+2])==pair:
            out.append(seq[i]+seq[i+1]);i+=2
        else:
            out.append(seq[i]);i+=1
    return tuple(out)
class WordBPE:
    def fit(self,counts,steps):
        if not counts or any(not w or c<=0 or END in w for w,c in counts.items()):
            raise ValueError('非空普通词与正词频')
        vocab=Counter({tuple(w)+(END,):c for w,c in counts.items()})
        self.base={s for seq in vocab for s in seq}
        self.tokens=set(self.base);self.merges=[]
        for _ in range(steps):
            pairs=Counter()
            for seq,c in vocab.items():
                for pair in zip(seq,seq[1:]):
                    pairs[pair]+=c
            if not pairs:
                break
            pair=min(pairs,key=lambda p:(-pairs[p],p))
            self.merges.append(pair);self.tokens.add(''.join(pair))
            new=Counter()
            for seq,c in vocab.items():
                new[merge(seq,pair)]+=c
            assert sum(new.values())==sum(vocab.values())
            vocab=new
        self.ids={t:i for i,t in enumerate(sorted(self.tokens))}
        return self
    def encode(self,w):
        if END in w or any(c not in self.base for c in w):
            raise ValueError('字符 OOV 或保留标记冲突')
        seq=tuple(w)+(END,)
        for pair in self.merges:
            seq=merge(seq,pair)
        assert all(t in self.ids for t in seq)
        return seq
    def decode(self,seq):
        text=''.join(seq)
        if not text.endswith(END):
            raise ValueError('缺词尾标记')
        return text[:-len(END)]

m=WordBPE().fit({'low':5,'lower':2,'newest':6,'widest':3,'lowest':4,'newer':2},10)
print('前五个合并',m.merges[:5],'完整词表大小',len(m.ids))
for w in ['lowest','lower','slowest','newish']:
    try:
        seq=m.encode(w);assert m.decode(seq)==w
        print(w,seq,[m.ids[t] for t in seq])
    except ValueError as e:
        print(w,'明确边界',str(e))
assert m.decode(m.encode('lowest'))=='lowest'
# 频率加权压缩曲线，词尾标记不计原始字符，报告真实完成轮数。
counts={'low':5,'lower':2,'newest':6,'widest':3,'lowest':4,'newer':2}
chars=sum(len(w)*c for w,c in counts.items())
for steps in [0,2,5,10,30]:
    model=WordBPE().fit(counts,steps)
    nt=sum(len(model.encode(w))*c for w,c in counts.items())
    print('完成合并',len(model.merges),'词表',len(model.ids),'Token/原始字符',round(nt/chars,4))
```

记录压缩曲线时按词频加权，而且说明是否把词尾符号计入Token数；不能把未加权的不同词分段数当整个语料压缩率。上例直接输出曲线的数字，重跑即可作图；没有承诺渐近到某个字符数。

原 TypeScript 的 `Map<Word,...>` 数组键按对象身份比较，不是按片段内容比较；本例每个词路径可运行，但通用聚合同内容序列应使用安全序列键并累加。若用固定分隔符拼接两个片段作为键，输入含同一分隔符可碰撞；本教学Python直接用tuple键，TS通用实现应转义或用结构化键。朴素 ranked encoder每次扫描所有相邻对，最坏 $O(L^2)$，不能因“有排名表”就说近线性；生产实现可用链表/堆维护邻接候选。顺序重写与逐次最低 rank在常见合法学得规则上对应，但字符串拼接可产生不同构造同名片段；本程序定义的推理契约是训练规则顺序，不冒充具体生产 Tokenizer。

### 5.2 完整 byte BPE 的无未知字节与往返检查

此程序无预切分和标准化，直接对完整 UTF-8序列学习；可跨空格合并，与某个预训练模型的 byte BPE配置不同，不能替代其 Tokenizer。

```python
from collections import Counter

def combine(seq,pair):
    out=[];i=0
    while i<len(seq):
        if i+1<len(seq) and (seq[i],seq[i+1])==pair:
            out.append(seq[i]+seq[i+1]);i+=2
        else:
            out.append(seq[i]);i+=1
    return out
class ByteBPE:
    def fit(self,texts,steps=20):
        seqs=[[bytes([b]) for b in t.encode('utf-8')] for t in texts]
        self.tokens=[bytes([b]) for b in range(256)]
        self.merges=[]
        for _ in range(steps):
            c=Counter(pair for seq in seqs for pair in zip(seq,seq[1:]))
            if not c:
                break
            p=min(c,key=lambda p:(-c[p],p))
            self.merges.append(p)
            if p[0]+p[1] not in self.tokens:
                self.tokens.append(p[0]+p[1])
            seqs=[combine(seq,p) for seq in seqs]
        self.ids={t:i for i,t in enumerate(self.tokens)}
        return self
    def encode(self,text):
        seq=[bytes([b]) for b in text.encode('utf-8')]
        for p in self.merges:
            seq=combine(seq,p)
        return [self.ids[t] for t in seq]
    def decode(self,ids):
        ids=list(ids)
        if any(isinstance(i,bool) or not isinstance(i,int) or not 0<=i<len(self.tokens) for i in ids):
            raise ValueError('ID必须是词表范围内整数')
        # 不随便以 errors='replace' 掩盖无效字节序列。
        return b''.join(self.tokens[i] for i in ids).decode('utf-8')

m=ByteBPE().fit(['lower lower lowest','你好，世界','hello world']*3)
for text in ['你好，新词','👩🏽‍💻','', 'lower', '<EOS>']:
    ids=m.encode(text)
    assert m.decode(ids)==text
    print(repr(text),'码点',len(text),'字节',len(text.encode('utf-8')),'Token',len(ids))
print('字节覆盖与往返通过')
```

普通字符串 `<EOS>` 在这里就是文本字节，不自动变结构标记。真实库的特殊 Token策略可能允许/禁止解释这些字符串，需显式设置。特殊符号与普通输入的注入边界和模型协议一起检查，不能仅检查“decode能还原”。

## 6. WordPiece、Unigram 与 SentencePiece

WordPiece 与 BPE都可从子词学习，但经典解释把 WordPiece选择与语料似然提升相联系，常用 $freq(ab)/(freq(a)freq(b))$ 是教学评分代理，不代表每种实现都精确执行完整最大似然训练。常见推理是每个词从左向右最长匹配，后续片段用 `##` 区分；不能完成整个词时回到 UNK，除非该实现另设回退。

Unigram给每个片段概率 $p(s)$，一个分段的概率为 $\prod p(s_i)$。同一词可以有多个分段，训练目标是对所有可能分段概率求和后最大化语料似然。通常从较大候选集合起步，通过 EM估计概率，按删除候选造成的似然损失裁剪，保持基础字符或回退覆盖。常规确定性编码用 Viterbi找 $\max\sum\log p(s_i)$；训练时可采样多个分段作为子词正则化，不能说“Unigram 推理必然随机”。

SentencePiece是训练/编码工具，支持 BPE、Unigram等，不是与二者并列的唯一算法。它可直接接受原始文本，把空白用 `▁` 表示，并有规范化配置；`character_coverage` 通常按字符出现频率覆盖率选择基础字符，不是覆盖所有不同字符类型的比例。`byte_fallback` 保证特定未知字符可变为字节片段，但通常可能产生更多 Token，不能保证降低低资源语言 fertility。

SentencePiece官方流程是 `SentencePieceTrainer.train(input=语料路径, model_prefix=输出前缀, vocab_size=目标大小)` 训练，再用 `SentencePieceProcessor(model_file=模型路径)` 载入，`encode(text, out_type=str/int)` 输出片段/ID，`decode` 反解。训练配置另选 `model_type`、`character_coverage`、`byte_fallback`与特殊符号。本次未运行这个外部库接口；本章手写算法负责原理复现。默认规范化可能改变原字面形式，round-trip应说明比较原文还是规范化文本，不能对任意配置承诺原始字节无损。

### 6.1 两个完整编码器与可核对的差别

```python
import math

def wordpiece(word,vocab):
    pieces=[];start=0
    while start<len(word):
        hit=None
        for end in range(len(word),start,-1):
            candidate=('##' if start else '')+word[start:end]
            if candidate in vocab:
                hit=(candidate,end);break
        if hit is None:
            return ['[UNK]']
        pieces.append(hit[0]);start=hit[1]
    return pieces

def unigram_viterbi(text,probs):
    if any(not s or not 0<p<=1 for s,p in probs.items()):
        raise ValueError('非空片段与合法概率')
    if abs(sum(probs.values())-1)>1e-10:
        raise ValueError('片段概率需归一')
    dp=[-math.inf]*(len(text)+1);back=[None]*len(dp);dp[0]=0
    for end in range(1,len(text)+1):
        for s,p in probs.items():
            begin=end-len(s)
            if begin>=0 and text[begin:end]==s and dp[begin]!=-math.inf:
                score=dp[begin]+math.log(p)
                if score>dp[end]:
                    dp[end]=score;back[end]=(begin,s)
    if dp[-1]==-math.inf:
        raise ValueError('未覆盖字符，没有合法分段')
    out=[];i=len(text)
    while i:
        i,s=back[i];out.append(s)
    return list(reversed(out)),dp[-1]

wp={'low','lower','##er','##s','[UNK]'}
print('WordPiece',wordpiece('lowers',wp),wordpiece('lowest',wp))
p={'l':.05,'o':.05,'w':.05,'e':.05,'r':.05,
   'lo':.1,'wer':.1,'low':.3,'er':.25}
seg,score=unigram_viterbi('lower',p)
assert seg==['low','er']
assert abs(math.exp(score)-.075)<1e-12
print('Unigram',seg,'分段概率',round(math.exp(score),4))
assert wordpiece('lowest',wp)==['[UNK]']
```

### 6.2 Unigram 训练怎样遍历所有分段

Viterbi只找最优路径，EM训练需所有路径的和。令 $F_0=1$，$F_j=\sum_{s:text[j-|s|:j]=s}F_{j-|s|}p(s)$；后向 $B_j$ 同理从结尾回推。某个片段占据位置 $i:j$ 的后验质量为 $F_i p(s)B_j/F_T$。对所有文本和位置累积期望片段次数，再归一更新 $p(s)$。删除候选后重算似然损失，可按损失最小的候选裁剪；真实实现还会批量裁剪、平滑和处理大语料。本段给出完整小规模 EM程序，固定词表用于展示训练，不声称实现 SentencePiece全部剪枝工程。

```python
import numpy as np
from collections import defaultdict

def em_step(texts,probs):
    expected=defaultdict(float);ll=0.
    for text in texts:
        n=len(text);F=np.zeros(n+1);B=np.zeros(n+1);F[0]=1;B[n]=1
        for end in range(1,n+1):
            for s,p in probs.items():
                begin=end-len(s)
                if begin>=0 and text[begin:end]==s:
                    F[end]+=F[begin]*p
        if F[n]<=0:
            raise ValueError('未覆盖或数值下溢；长文本应改对数空间')
        for begin in range(n-1,-1,-1):
            for s,p in probs.items():
                end=begin+len(s)
                if end<=n and text[begin:end]==s:
                    B[begin]+=p*B[end]
        assert np.allclose(F[n],B[0])
        ll+=np.log(F[n])
        for begin in range(n):
            for s,p in probs.items():
                end=begin+len(s)
                if end<=n and text[begin:end]==s:
                    expected[s]+=F[begin]*p*B[end]/F[n]
    total=sum(expected.values())
    return {s:expected[s]/total for s in probs},ll

texts=['lower','lower','low','lower','low']
candidates=['l','o','w','e','r','lo','low','er','lower']
p={s:1/len(candidates) for s in candidates}
previous=-np.inf
for i in range(20):
    new,ll=em_step(texts,p)
    assert ll>=previous-1e-10
    previous=ll;p=new
print('EM 语料 log likelihood',round(float(ll),4))
print('片段概率',[(s,round(p[s],4)) for s in p])
assert abs(sum(p.values())-1)<1e-12
# 极小概率基础字符仍需保留/加覆盖约束；不可只据当前语料删尽。
```

实际长文本应用对数域或缩放的前向后向避免下溢。固定训练语料似然上升不是泛化证明；候选剪枝、验证集压缩率、覆盖率和下游指标共同选词表。BPE加 merge不必每次新增不同字符串符号，Tiny语料也可能提前无相邻对，不能承诺一定训练到指定次数。

## 7. 词表设计、适用场景与维护

新模型从头训练时，词表大小影响 Embedding和输出头参数量 $|V|d$、softmax成本、序列长度、跨语言/数字/代码切分。大词表压短序列但有更多低频词项；小词表利于共享但增加序列长度。不存在按模型参数量固定分段的正确词表门槛，单语词表小于16k也不自动不合格。

评估需在独立文本上记录 OOV、空输入、tokens/码点或字节、tokens/词（注明词边界协议）、压缩率、round-trip和下游效果。子词可以有多种合法分段，不代表 Token ID可跨模型共用。Tokenizer的词表、合并排名、规范化、预切分、特殊符号及 ID映射都与模型绑定。普通微调用原配；若有意扩词/改分词，必须同步修改 Embedding/输出头并重新训练适配，不能把它当普通配置互换。

库接口按需求选：Hugging Face Tokenizers支持多个算法和预切分器；SentencePiece可对原始多语言语料训练；tiktoken的常用 `get_encoding` 接口加载预置编码，不是生产语料训练接口；其官方 `_educational` 另有 `train_simple_encoding` 教学训练，不能把“常用预置编码”写成整个项目完全没有训练示例。本次没有加载需要获取编码资产的现成词表；`encoding_for_model`的模型名映射也需使用时核验，不能用库名称推测所有模型使用相同词表。`Ġ` 可能是 byte-to-Unicode的空白字节呈现，`▁` 是某些 SentencePiece空白标记，`##` 是续接标记；都不是全行业通用的“词首字符”。不要硬编码某模型词表大小、Token ID或预切分参数当永久事实。

## 8. 自检与练习参考答案

1. Skip-gram与CBOW方向？中心→上下文、上下文汇总→中心；两者训练形式与负采样/softmax选择是两个维度。
2. SGNS sigmoid为何不能拿来算正规 LM PPL？没有对所有上下文词归一，它区分数据对与噪声对；需要真正归一化的序列概率模型。
3. 两个负词 ID相同时为何用 `add.at`？两次训练项都贡献梯度，普通重复索引原地赋值可能覆盖而非累加。
4. GloVe的小计数项权重小、高计数项封顶1；不要写成对高频递减。$\log X$ 只算正计数。
5. 将 playing/played的片段Jaccard与向量余弦对照，能证明语义质量吗？不能；一者拼写集合、一者训练空间，真实任务和错误样本才能评价。
6. 子词是否消灭一切 OOV？字符字母表没覆盖新字仍可能UNK；全字节/适当回退提供编码覆盖，但不提供语言理解。
7. BPE训练500/1000轮的练习怎样公平做？同一训练语料、同一并列策略、保持基础符号，用未参与训练的文本比较实际完成轮数、序列长度和覆盖；不能凭固定次数预设压缩到2–3片段。
8. WordPiece最长匹配与Unigram Viterbi差别？局部最长不等于最高整体概率；后者要动态规划。Unigram训练还要所有路径的质量，不只是最优路径。
9. 向量 bias检查如何做？语言群体、语料分布和下游错误要有独立证据；`doctor−nurse` 等单轴混合职业/性别/频率关系，投影减轴不保证公平，也可能删除任务信息。
10. 原 Shakespeare、维基百科、现成 tokenizer/fastText下载练习本次未运行。真实扩展须先确定语料与许可，报告类比/近邻加下游结果，按语言分别测切分，不能把小程序输出改写为预训练模型成绩。
