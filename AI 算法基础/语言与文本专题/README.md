# 语言与文本专题

本专题从文本单位、训练数据与预测目标入手，把经典NLP和现代语言系统接到同一知识体系。词袋、词向量、序列标注、检索和生成解决的问题不同，先定义输入输出和评价，再选择方法。

## 怎样开始

先会Python字符串、数组形状、条件概率、分类损失及训练/验证切分。不熟悉这些时，回到[Python](../../Python/README.md)、[数学专题](../数学与数值计算专题/README.md)和[机器学习专题](../机器学习专题/README.md)。词、字符、字节、子词和模型token不是同一种单位，代码中的长度、offset和指标必须声明单位。

| 学习问题 | 主要维护入口 | 可核对的结果 |
|---|---|---|
| 文本如何变成稀疏特征 | [01 文本预处理与稀疏表示](01-文本预处理与稀疏表示.md) | 解释处理为何保留或改变含义；手算词频、文档频率、TF-IDF；只在训练集拟合词表与统计 |
| 词向量和子词怎样学习 | [02 词向量与子词建模](02-词向量与子词建模.md) | 核对训练对、负样本、目标和向量；运行小词表切分，说明未知词、合并顺序与特殊符号边界 |
| 分类、主题与跨语言怎样比较 | [03 文本分类、主题与跨语言学习](03-文本分类主题与跨语言学习.md) | 先做基线、否定/域差异失败例，再比较指标；主题模型输出不冒充真实标签，跨语言测试分语言报告 |

## 从算法走向工程

完成基础表示后，可按目标进入[文本检索与RAG文档工程](../../LLM%20工程实践/12-文本检索与RAG文档工程.md)；需要schema、纠正、对话状态或关系图时，进入[结构化输出与对话状态](../../LLM%20工程实践/13-结构化输出与对话状态.md)。语言模型、检索、长上下文和实际任务评价由[评测与实验管理](../../LLM%20工程实践/06-评测与实验管理.md)统一维护。

通过标准是能解释一个预测、修改小输入并预判结果、定位一个失败例，而不是背方法名称。小语料、手工向量、规则或mock只验证相应机制；预训练模型、真实泛化与服务效果需另有运行证据。
