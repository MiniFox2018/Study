# 05｜摘要推断与文本评价

> 先修：[文本表示与检索](01-文本预处理与稀疏表示.md)中的词频/向量概念，以及[序列模型](../深度学习专题/03-序列模型与机器翻译.md)。本章解决“保留哪些信息、文字是否支持结论、怎样比较输出”。先做 TextRank 与 NLI 反例，再学习指标。评价分数不等于事实真值。

## 1. 摘要任务与信息取舍

摘要把一份或多份材料压缩成满足读者需求的短文本。抽取式选择原有句子；生成式重新组织和表达。二者都需要确定长度、主题、受众、时间范围和信息优先级。原文的完整照抄不等于好的摘要，语言流畅也不保证保留了关键限制。

- **抽取式**优点是易追溯、无需生成每个词；限制是冗余、衔接差、指代不清，跨句信息可能被遗漏。原句被脱离引用、否定或条件上下文后仍能造成误导，不能承诺“抽取绝不幻觉”。
- **生成式**能压缩与改写，可用 encoder–decoder/条件语言模型最大似然学习参考摘要。限制是可能添加未经源文支持的关系、数字和结论；摘要模型不天然知道作者真实意图。
- **多文档**先按事件、主体、时间对齐，再区分冲突和互补证据。重复转载不等于独立证据数量。不同日期的说法不能直接拼成同一时刻事实。
- **长文档**需要覆盖分段、重叠上下文、章节层级和跨段整合。只截取开头虽能降低计算，却会遗漏尾部限制；分段摘要再汇总会放大前一阶段遗漏，须保留句段定位。

BART 用破坏/掩盖/打乱后的文本学习重建，encoder读取损坏输入、decoder恢复原文；摘要任务再以正文→参考摘要训练。PEGASUS 的 gap-sentence 预训练把选出的重要句子作为生成目标，其训练形式更接近摘要，但领域与数据匹配仍需验证，不保证一个 PubMed checkpoint 在所有论文上优于其他模型。现代指令模型可以按目的与格式生成，也需要来源支持和任务评估，不能靠提示词自动消除遗漏。

可先建表：每项候选事实记录主体、关系、客体、数值单位、时间、条件、来源句段、是否必须保留。摘要输出附可追溯证据 ID，检查否定、比较基线、统计不确定性和限制是否被删。实体不遗漏并不证明关系正确；“甲收购乙”改成“乙收购甲”仍含相同实体。

## 2. TextRank：句子图上的中心性

将句子作为节点、词汇相似度作为非负边权。相似词多的句子互相推荐，PageRank 迭代得到中心性。权重矩阵 $W$ 的每行归一化为转移矩阵 $P$，没有出边的节点称 dangling node，把其质量按初始分布 $v$ 重新分配：

$$
r^{(t+1)}=(1-d)v+d\left(P^\top r^{(t)}+v\sum_{i\in D}r_i^{(t)}\right),\qquad\sum_i r_i=1.
$$

$d\in[0,1)$ 是沿图推荐的概率，$v$ 通常均匀。每轮传播必须保留质量；简单把无出边分母设成很小但不分配其质量，会使分数总和缩水。用 L1 差小于容差或到最大迭代数停止，报告是否收敛。相似度可用词频 cosine、TF-IDF cosine 或合适语义向量，中心性仍不等于事实重要程度：重复宣传可能比唯一关键限制更中心。

### 2.1 完整小实现：PageRank、冗余惩罚与长度预算

为避免假定英文正则能正确切中文句子，例子显式提供分句与分词。实际应把它们与原字符区间一起保存。MMR 用 $\lambda\cdot\mathrm{salience}-(1-\lambda)\max\mathrm{similarity}$ 平衡重要性与冗余，选择后按原文顺序输出。预算使用实际 token 数，不能以句数冒充长度。

```python
import numpy as np
from collections import Counter

sentences = ["系统采用动态批处理以提高吞吐。", "动态批处理可减少重复调用。",
             "队列等待会增加尾部延迟。", "含个人信息的请求需要脱敏。"]
tokens = [["系统", "动态", "批处理", "吞吐"], ["动态", "批处理", "减少", "调用"],
          ["队列", "等待", "尾部", "延迟"], ["个人", "信息", "请求", "脱敏"]]

def graph(tokenized):
    n = len(tokenized)
    vocab = sorted({t for s in tokenized for t in s})
    counts = [Counter(s) for s in tokenized]
    x = np.array([[c[t] for t in vocab] for c in counts], dtype=float).reshape(n, len(vocab))
    norms = np.linalg.norm(x, axis=1)
    denom = norms[:, None] * norms[None, :]
    sim = np.divide(x @ x.T, denom, out=np.zeros((n, n)), where=denom > 0)
    np.fill_diagonal(sim, 0.)
    return sim

def pagerank(w, damping=.85, tol=1e-12, limit=1000):
    w = np.asarray(w, dtype=float)
    if w.ndim != 2 or w.shape[0] != w.shape[1] or not np.isfinite(w).all() or (w < 0).any():
        raise ValueError("要求有限非负方阵")
    if not 0 <= damping < 1 or tol <= 0 or limit <= 0:
        raise ValueError("迭代参数非法")
    n = len(w)
    if n == 0:
        return np.zeros(0), 0, True
    v = np.full(n, 1 / n)
    rows = w.sum(1)
    dangling = rows == 0
    transition = np.divide(w, rows[:, None], out=np.zeros_like(w), where=rows[:, None] > 0)
    rank = v.copy()
    for iteration in range(1, limit + 1):
        nxt = (1 - damping) * v + damping * (transition.T @ rank + rank[dangling].sum() * v)
        assert np.isclose(nxt.sum(), 1.)
        delta = np.abs(nxt - rank).sum()
        rank = nxt
        if delta < tol:
            return rank, iteration, True
    return rank, limit, False

def select(tokenized, w, rank, budget, weight=.65):
    if budget < 0 or not 0 <= weight <= 1:
        raise ValueError("预算或MMR权重非法")
    salience = rank / rank.max() if len(rank) and rank.max() > 0 else rank
    chosen, remaining = [], set(range(len(tokenized)))
    used = 0
    while remaining:
        eligible = [i for i in remaining if tokenized[i] and used + len(tokenized[i]) <= budget]
        if not eligible:
            break
        def score(i):
            redundancy = max((w[i, j] for j in chosen), default=0.)
            return weight * salience[i] - (1 - weight) * redundancy
        i = max(eligible, key=lambda i: (score(i), -i))
        chosen.append(i)
        remaining.remove(i)
        used += len(tokenized[i])
    return sorted(chosen), used

w = graph(tokens)
r, iterations, converged = pagerank(w)
assert converged and np.isclose(r.sum(), 1.)
assert np.allclose(pagerank(np.zeros((3, 3)))[0], np.ones(3) / 3)
assert pagerank(np.zeros((0, 0)))[0].size == 0
ids, used = select(tokens, w, r, budget=8)
assert used <= 8
print("中心性", np.round(r, 4), "收敛", converged)
print("摘要句ID", ids, "使用token", used)
for i in ids:
    print(i, sentences[i])
```

本例总质量为 1，孤立图得到均匀分数，预算最多保留两句。即使算法运行正确，摘要可能漏掉脱敏要求；这显示图中心性之外仍需任务约束，例如强制保留风险条款、人工复核或定义业务相关性。MMR 是启发式贪心，不保证组合预算下全局最优。

## 3. NLI：文本支持与世界真值的边界

自然语言推断输入为有方向的 `(premise, hypothesis)`：

- **entailment（蕴含）**：按约定的语义与背景，前提支持假设；“甲买了三本书”支持“甲买了书”。
- **contradiction（矛盾）**：二者在同一主体、关系、时间、范围下不能同时成立；“甲没有买书”与“甲买了书”矛盾。
- **neutral（中立）**：信息不足以支持或排除假设；“甲买了书”对“甲住在合肥”中立。中立不只指完全无关，也包括相关但缺少限定信息。

RTE 是文本蕴含识别的任务系列；例如 GLUE 的 RTE 是蕴含/非蕴含二类，而某些 RTE 挑战也采用三类。不能把所有 RTE 数据的标签合同都写成与三类 NLI 相同，需查对应基准。[NIST RTE 指南](https://tac.nist.gov/2008/rte/rte.08.guidelines.html)给出了当年两类/三类协议。

方向不能交换：“三本”→“书”可蕴含，“书”→“三本”信息不足。来源本身可能有误；即使前提蕴含假设，也不证明真实世界中为真。neutral 不能自动标成错误、造假或幻觉；它首先意味着当前证据不足。事实核验还需来源质量、独立证据、时间与范围。

### 3.1 关系与否定反例，而不是词重叠冒充推断

下面实现一个明确受限的命题检查器：输入已经人工结构化，只有显式同一命题/显式否定可判蕴含/矛盾，其他情况中立。它不是通用自然语言解析器或神经 NLI。保持开放世界：没有列出的事实不视为假。

```python
from dataclasses import dataclass
from collections import Counter
import numpy as np

@dataclass(frozen=True)
class Proposition:
    subject: str
    relation: str
    object: str
    positive: bool = True
    time: str = "同一时刻"
    def opposite(self):
        return Proposition(self.subject, self.relation, self.object, not self.positive, self.time)

def infer(premise, hypothesis):
    facts = set(premise)
    if any(p.opposite() in facts for p in facts):
        raise ValueError("前提含显式冲突，需要处理证据而非强行输出")
    if hypothesis in facts:
        return "entailment"
    if hypothesis.opposite() in facts:
        return "contradiction"
    return "neutral"

p = Proposition("甲", "收购", "乙")
cases = [(p, "entailment"), (p.opposite(), "contradiction"),
         (Proposition("乙", "收购", "甲"), "neutral"),
         (Proposition("甲", "收购", "乙", time="去年"), "neutral")]
confusion = Counter()
for h, gold in cases:
    pred = infer([p], h)
    confusion[(gold, pred)] += 1
    assert pred == gold
assert infer([], p) == "neutral"
# 相同实体集合不能识别关系方向。
assert {"甲", "收购", "乙"} == {"乙", "收购", "甲"}
print("受限命题测试", dict(confusion))

# zero-shot NLI 的两类常见归一化，数字仅演示机制。
# 每候选三类logits按[C,N,E]排序；实际顺序必须读model.config.id2label。
logits = np.array([[0., 1., 3.], [0., 2., 2.]])
def softmax(x, axis=-1):
    z = np.exp(x - x.max(axis=axis, keepdims=True))
    return z / z.sum(axis=axis, keepdims=True)
single_label = softmax(logits[:, 2], axis=0)
independent = softmax(logits[:, [0, 2]], axis=1)[:, 1]
assert np.isclose(single_label.sum(), 1.) and independent.sum() > 1
print("候选间单标签", np.round(single_label, 3))
print("逐候选E/C多标签", np.round(independent, 3))
```

单标签概率在候选之间归一化，新增候选会改变分数；多标签常对每候选的 entailment/contradiction 做二分类归一化，排除了 neutral，不等于完整三类模型的 entailment 概率。上例分别约 `[0.731,0.269]` 与 `[0.953,0.881]`。模板措辞、候选描述、模型标签配置与阈值都影响结果，不能把这些分数当校准后的事实概率。

### 3.2 神经 NLI、偏差与文档支持判断

cross-encoder 共同编码 `[前提,分隔符,假设]`，输出三类 logits，以交叉熵训练。联合读取能够建模词对齐、否定与关系，但训练集可能含 hypothesis-only 捷径，例如某些词与标签共现。用仅假设基线、去掉前提、角色交换、数字/时间/否定最小改动测试发现问题；随机测试集高准确率不足以证明迁移到法律、医学或中文领域。

文档核验先把答案拆成原子声明，检索相关句段，再对各声明给支持/矛盾/不足及证据定位。不要把整个答案拼成一长句送 NLI：截断可能删掉真正证据；多个相反来源不能用最高分支持段掩盖。模型概率要在目标领域有标注的验证集上调阈值、观察混淆矩阵/各类 precision-recall/校准和拒答覆盖率。测试集不能参与选阈值。NLI 也无法仅凭文本理解保证所有量词、反事实、时间、常识和多步组合推理。

RAG 的 faithfulness 可用不同 NLI、LLM 评审或规则实现，必须说明具体判定方法。文本支持比例不能替代检索覆盖率和世界事实正确率。把“原文没说”判为暂未支持后，可补检索或人工核验；未经依据不要强行判定假。

## 4. 翻译与摘要的文本指标

指标必须记录参考数量、分词、大小写、聚合、平滑、版本、空输出处理、是否按文档/语料统计。下面所有 token 指标输入显式 token 列表，避免把语言分词问题藏进公式。

### 4.1 BLEU：裁剪 precision 与长度惩罚

BLEU 统计候选的 $n$-gram precision，匹配次数以参考最大次数裁剪，防止重复一个常见词刷分。多参考逐 n-gram 取最大计数，候选长度对应最接近的参考长度（平局取短者）。语料 BLEU 先汇总匹配/总数与长度，再计算：

$$
\mathrm{BLEU}=\mathrm{BP}\exp\left(\sum_{n=1}^N w_n\log p_n\right),\qquad
\mathrm{BP}=\begin{cases}1,&c\ge r,\\\exp(1-r/c),&0<c<r,\\0,&c=0.\end{cases}
$$

通常等权 $w_n=1/N$。无平滑时任何有效阶 precision 为 0，整体为 0；句子很短且强制四阶时，即使完全匹配也可能为 0。effective order 仅用有候选 n-gram 的阶数；平滑是在稀疏小样本中另一种约定，不是随意抬分。句子 BLEU 的均值不是语料 BLEU。不同 tokenizer、大小写、平滑和 reference 数量不能直接排名。

### 4.2 chrF、ROUGE-N 与 ROUGE-L

chrF 用字符 n-gram 的平均 precision $P$ 与 recall $R$ 形成 $F_\beta=(1+\beta^2)PR/(\beta^2P+R)$，常用字符 1～6 阶、$\beta=2$；这对形态变化和部分词匹配更柔和。是否去空白、区分大小写、有效阶以及多参考策略必须固定。chrF++ 再加入词 n-gram；不能将只算字符的实现命名为 chrF++。

ROUGE-N 按 n-gram 重合报告 precision、recall、F1，分别衡量候选支持程度和参考覆盖；仅报 recall 会鼓励长输出。ROUGE-L 用最长公共子序列 LCS 的长度作为匹配数，保留顺序但允许不连续；`rougeLsum` 对摘要句边界采用不同的 union-LCS 处理，不等于把所有词拼成一串。默认英文字符清洗/英文词干化不适用于所有中文文本；应使用匹配语言的 tokenizer 并说明口径。

```python
import math
from collections import Counter

def grams(tokens, n):
    return Counter(tuple(tokens[i:i+n]) for i in range(max(0, len(tokens)-n+1)))

def corpus_bleu(hypotheses, reference_sets, max_n=4, effective_order=False):
    if len(hypotheses) != len(reference_sets) or not hypotheses or max_n < 1:
        raise ValueError("语料数量与阶数非法")
    matched, totals = [0]*max_n, [0]*max_n
    c = r = 0
    for hyp, refs in zip(hypotheses, reference_sets):
        if not refs:
            raise ValueError("每项至少一个参考")
        c += len(hyp)
        r += min((len(ref) for ref in refs), key=lambda length: (abs(length-len(hyp)), length))
        for n in range(1, max_n+1):
            candidate = grams(hyp, n)
            maximum = Counter()
            for ref in refs:
                maximum |= grams(ref, n)  # 逐项最大，不是加起来
            matched[n-1] += sum((candidate & maximum).values())
            totals[n-1] += sum(candidate.values())
    if c == 0:
        return 0.
    orders = [i for i, total in enumerate(totals) if total > 0] if effective_order else list(range(max_n))
    if not orders or any(totals[i] == 0 or matched[i] == 0 for i in orders):
        return 0.
    bp = 1. if c >= r else math.exp(1-r/c)
    return 100 * bp * math.exp(sum(math.log(matched[i]/totals[i]) for i in orders)/len(orders))

def prf(match, hyp_count, ref_count, beta=1.):
    p = match/hyp_count if hyp_count else 0.
    r = match/ref_count if ref_count else 0.
    f = (1+beta*beta)*p*r/(beta*beta*p+r) if p+r else 0.
    return p, r, f

def chrf(hyp, ref, order=6, beta=2., remove_space=True):
    if order < 1 or beta <= 0:
        raise ValueError("阶数和beta必须正")
    if remove_space:
        hyp, ref = "".join(hyp.split()), "".join(ref.split())
    precisions, recalls = [], []
    for n in range(1, order+1):
        h, r = grams(list(hyp), n), grams(list(ref), n)
        if not h or not r:
            continue
        p, recall, _ = prf(sum((h&r).values()), sum(h.values()), sum(r.values()))
        precisions.append(p)
        recalls.append(recall)
    if not precisions:
        return 0.
    p, r = sum(precisions)/len(precisions), sum(recalls)/len(recalls)
    return 100 * ((1+beta*beta)*p*r/(beta*beta*p+r) if p+r else 0.)

def rouge_n(hyp, ref, n=1):
    h, r = grams(hyp, n), grams(ref, n)
    return prf(sum((h&r).values()), sum(h.values()), sum(r.values()))

def rouge_l(hyp, ref):
    previous = [0]*(len(ref)+1)
    for word in hyp:
        current = [0]
        for j, other in enumerate(ref, 1):
            current.append(previous[j-1]+1 if word == other else max(previous[j], current[-1]))
        previous = current
    return prf(previous[-1], len(hyp), len(ref))

short = ["甲", "到"]
assert corpus_bleu([short], [[short]]) == 0.
assert corpus_bleu([short], [[short]], effective_order=True) == 100.
assert corpus_bleu([[]], [[short]]) == 0.
assert rouge_n(["甲", "甲", "甲"], ["甲"], 1) == (1/3, 1., .5)
assert rouge_l(["甲", "买", "书"], ["甲", "书", "买"]) == (2/3, 2/3, 2/3)
assert abs(chrf("北京 大学", "北京大学")-100) < 1e-10
assert chrf("", "北京") == 0.
print("短句固定四阶BLEU", corpus_bleu([short], [[short]]))
print("短句有效阶BLEU", corpus_bleu([short], [[short]], effective_order=True))
print("重复词ROUGE(P,R,F)", rouge_n(["甲"]*3, ["甲"]))
print("顺序变化ROUGE-L", rouge_l(["甲", "买", "书"], ["甲", "书", "买"]))
print("字符chrF", round(chrf("系统延迟降低", "系统延迟减少"), 3))
```

这是单参考 chrF、可多参考 corpus BLEU 和简单序列 ROUGE-L 的教学实现；不等于完整 SacreBLEU/ROUGE-Lsum 库。只在所声明的口径内测试。空候选得 0，即使空参考也按本例返回 0；不同库可能有其他约定，不应默认为统一正确答案。SacreBLEU 的 signature 可记录 `nrefs/case/eff/tok/smooth/version`；一份分数需要连同 signature 和测试集一起保存。

### 4.3 语义指标、人工评价与不确定性

BERTScore 用上下文 embedding 的余弦相似度软匹配 token：候选每个 token 在参考中找最大相似度，平均得到 precision；参考向候选反向得到 recall，再算 F1。可加 IDF 权重或 baseline rescaling。它能接受部分同义改写，但角色交换、数字变化、否定和高相似但错误的句子仍可能得高分；backbone、层、语言和参数需固定。它不因使用 BERT 就自动“训练过人类评分”。

BLEURT、COMET 等学习型指标在各自数据与目标上训练；是否需要参考、是否使用源文、是否是质量估计版本取决于具体 checkpoint。reference-free QE 可发现风险，但没有参考不意味着没有偏差。LLM 评审要记录 rubric、模型版本、提示、盲评顺序、重复一致性，并用人工标注校验；评审模型可能偏向长文本、流畅语气或同家族输出。不能以“某年最佳”“与人类 80% 一致”当跨任务普遍结论。

人工把充分性、流畅度和忠实性分开：逐项标遗漏、添加、错误实体/数字、关系反转、否定/时间/条件错误；允许多个等价译法。摘要的忠实性指源材料支持，世界正确性另需外部核验。实体 precision/recall 仅是辅助；别名或压缩可降低字面 recall，关系反转可保持实体 F1=1。

比较模型用相同测试项的配对评价，并报告按来源/文档的统计单位。不能宣称“BLEU 小于 1 分都是噪声”：方差取决于样本量、难度、相关性和协议。下面只演示已得到的逐文档标量差的 bootstrap；若报告 corpus BLEU 的区间，必须每次重采样原假设/参考并重算整个 corpus BLEU，不能对句 BLEU 均值冒充。

```python
import numpy as np
rng = np.random.default_rng(17)
# 六个独立文档的同口径人工评分或其他可逐文档聚合分数。
old = np.array([.70, .62, .81, .56, .76, .64])
new = np.array([.72, .60, .83, .57, .77, .65])
delta = new-old
samples = delta[rng.integers(0, len(delta), size=(3000, len(delta)))].mean(axis=1)
interval = np.quantile(samples, [.025, .975])
print("平均差", round(float(delta.mean()), 4), "配对bootstrap区间", np.round(interval, 4))
assert interval[0] <= interval[1]
```

测试集只有六项，区间本身也不稳定，这不是模型提升的真实证据。重复同一文档的句子不能按独立文档重采样；若按任务/来源分层，重采样需尊重分层或簇结构。统计判断更多见[统计估计检验与实验判断](../数学与数值计算专题/11-统计估计检验与实验判断.md)。

## 5. 从训练到可靠使用

源摘要动画先指定第2/5/8条高亮，再把三个矩形缩为原宽的55%；这不是执行TextRank或证明存在通用55%压缩率。NLI路由动画也把固定例子的脉冲送向蕴含框，三类框闪烁没有改变输入或运行分类器。算法/模型质量仍要按前述明确输入和真实输出评价。

生成摘要复用条件序列训练：目标错位一位、包含 EOS、PAD 排除、总体有效 token mean；见[Seq2Seq 完整实现](../深度学习专题/03-序列模型与机器翻译.md#5-seq2seq从训练错位到结束状态)。对重复文档、模板或同事件报道要按来源分组拆分，避免验证集只是训练集改写。设置关键词/术语约束应核验是否让语法或事实失真。

一个可审查的管道保存原文版本→句段位置→候选信息→输出→每条声明证据→指标和人工错误记录。上线按领域测试超长文档、空文、矛盾来源、引号、表格数值、混合语言与 prompt injection 内容。源文是数据，不是修改系统规则的授权。没有足够证据时注明不足或交给人工；重试不能自动变成事实核验。

模型接口示例依赖任务、模型语言、transformers 版本、tokenizer 和输出结构。正式使用先锁定版本、查官方文档和检查小样本实际结构；本章未下载 BART/PEGASUS/NLI 权重、未调用评审 API，没有声称复现原来源品牌模型的准确率。

## 6. 练习与核对答案

1. TextRank 把孤立节点质量丢弃会怎样？**答**：rank 总和下降、中心性失真；用 dangling mass 重新分配。
2. 重复出现的句子一定重要吗？**答**：不一定，可能是重复宣传；需冗余惩罚和任务/风险约束。
3. 摘要逐字抽取就不会误导吗？**答**：仍可能切掉条件、否定、引用或指代上下文。
4. 前提“甲收购乙”与假设“乙收购甲”共享所有词，是什么标签？**答**：仅凭此为中立，不可用词重叠判蕴含；明确有排他条件时才可能进一步判断矛盾。
5. NLI 蕴含能证明世界事实吗？**答**：不能，前提本身需核验；NLI是在给定文本上的语义支持。
6. neutral 等于 hallucination 吗？**答**：不是；首先是证据不足，也可能真实但没被当前材料覆盖。
7. 两词短句完全匹配而固定四阶无平滑 BLEU 为 0，是实现错误吗？**答**：是定义的稀疏边界；要报告有效阶/平滑约定。
8. 同一个词重复三次，参考只一次，ROUGE-1 recall=1 能说明摘要好吗？**答**：不能，本例precision=1/3、F1=.5，且语义冗余未由指标完整描述。
9. 翻译中实体完全一致却把买方卖方调换，如何发现？**答**：关系/角色错误审核或对照命题；实体覆盖不足以判断忠实。
10. 为什么不能给全部中文评价自动加英文 stemming？**答**：分词、清洗和词干规则不适配，可能删除有效中文或制造虚假分数。
11. 为何不能平均逐句 BLEU 当语料 BLEU？**答**：语料先累加计数和长度，再非线性取几何均值/BP，顺序不同。
12. 对两个系统差 0.7 BLEU，能否直接说无意义？**答**：需配对数据、统计区间与错误类别/实际影响，不能采用固定 1 分门槛。
