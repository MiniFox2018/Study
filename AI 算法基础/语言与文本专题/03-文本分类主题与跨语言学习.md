# 03｜文本分类、主题与跨语言学习

分类需要标签，主题模型探索未标注语料，跨语言迁移研究训练语言与应用语言不同的情况。三者共用[预处理与表示](01-文本预处理与稀疏表示.md)、[词向量与子词](02-词向量与子词建模.md)，但目标、分数与验收协议不能混用。这里给出完整小规模 CPU管线；人工语料、人工向量和模拟 logits均明确标记，不作为真实模型准确率。

## 1. 情感分类：先定义标签和信息单位

情感可以是整句正/负/中性，也可以是“屏幕很好、续航很差”的方面级结果。标注粒度、主观判断规则、讽刺和混合情感决定可达到的结果。把所有任务简化为正/负会强迫中性和混合样本进入错误类别。

经典流程是文本→计数/TF-IDF→分类器。多项式 NB的分数为 $\log\pi_c+\sum_t x_t\log P(t\mid c)$，平滑词概率分母是类别总词数加 $\alpha |V|$；这是条件独立近似，不是断言词真的独立。NB也能使用 n-gram特征，不能说它原则上无法学习 bigram。概率校准通常比类别排序困难，推导与完整 NumPy实现见[朴素贝叶斯主要入口](../机器学习专题/05-朴素贝叶斯与概率分类.md)。

逻辑回归直接学习 $z=w^Tx+b$、$p=\sigma(z)$。一个词的贡献是 $w_tx_t$，不是裸 $w_t$；系数解释还受相关特征影响。L2目标可写：

$$J=\frac1N\sum_i[\operatorname{softplus}(z_i)-y_i z_i]+\frac\lambda2\|w\|^2,$$
$$\nabla_w J=X^T(p-y)/N+\lambda w,\qquad \partial_b J=\operatorname{mean}(p-y).$$

常数偏置一般不正则化。这里用平均损失的 $\lambda$ 不可不加说明等同每个库的 `1/C`，库的缩放/样本权重有约定。高维稀疏特征容易过拟合，验证集选择正则强度，完整手写训练、稳定 sigmoid及阈值关系接[逻辑回归主要入口](../机器学习专题/02-逻辑回归与支持向量机.md)。

图中把若干词权重相加再过 sigmoid展示线性决策；默认权重之和为 $1.6-.4-1.8+.2=-.4$，$\sigma(-.4)≈.4013$，这些是人为设定的示意权重，不是训练结果。概率跨 .5会改变该默认阈值的分类，实际业务阈值可以不同。

## 2. 否定、局部次序与真实失败模式

`good` 与 `not good` 不同，但普通 unigram只看到独立计数。选择包括词 bigram、字符 n-gram、局部否定作用域、语法特征和上下文编码器。词 bigram能学某些组合，却不会自动推理所有句法；逻辑回归“没有 NB的条件独立假设”也不等于它有语言结构理解。

一种教学作用域规则：遇到 not/no/never之后，后续内容加 `NOT_`，遇句号/逗号等结束。原正则保留 `don't` 整词却期待独立 `n't`，会漏触发，需明确拆缩写。作用域规则不能完整处理 `not only`、双重否定、转折、跨标点关系，也不能把每一个 `no` 机械理解为负情感。让 `NOT_good` 与 `good` 分成两列，只是给模型学习不同权重的机会，结果依然取决于标签与数据。

### 2.1 完整 NB/LR比较管线

所有向量器仅训练集 fit，测试只 transform；标签是人为指定的教学事实。预处理属于整个管线契约，语料规模小所以 `min_df=1`，不能照搬大型语料的阈值。

```python
import re
import numpy as np
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, classification_report, f1_score

NEG={'not','no','never','nor','neither'}
TERM={'.','!','?',',',';'}
CONTRACTIONS={"can't":'can not',"won't":'will not',"don't":'do not',
              "isn't":'is not',"didn't":'did not',"wasn't":'was not'}
def tokens(text):
    text=text.lower()
    for a,b in CONTRACTIONS.items():
        text=re.sub(r'\b'+re.escape(a)+r'\b',b,text)
    return re.findall(r"[a-z]+(?:'[a-z]+)?|[.!?,;]",text)
def scoped(text):
    out=[];negative=False
    for t in tokens(text):
        if t in TERM:
            negative=False
        elif t in NEG:
            negative=True;out.append(t)
        else:
            out.append('NOT_'+t if negative else t)
    return out
assert scoped("isn't good, great acting") == ['is','not','NOT_good','great','acting']
assert scoped('not only good') == ['not','NOT_only','NOT_good']  # 明确演示规则局限
train=['good movie','great acting','loved the film','beautiful story',
       'good story and acting','funny film','excellent movie','worth the time',
       'bad movie','terrible acting','boring film','awful story',
       'not good movie','not worth the time','never enjoyed film','bad story and acting']
y=np.array([1]*8+[0]*8)
test=['good acting','terrible movie','not good story','beautiful film','boring story']
truth=np.array([1,0,0,1,0])
models={
 'NB':Pipeline([('features',CountVectorizer(tokenizer=scoped,token_pattern=None,
                      lowercase=False,ngram_range=(1,2))),('model',MultinomialNB(alpha=1))]),
 'LR':Pipeline([('features',TfidfVectorizer(tokenizer=scoped,token_pattern=None,
                      lowercase=False,ngram_range=(1,2),sublinear_tf=True)),
                ('model',LogisticRegression(C=2,max_iter=400,random_state=0))])}
for name,model in models.items():
    model.fit(train,y);pred=model.predict(test)
    print(name,'预测',pred.tolist(),'混淆矩阵行真列预测\n',confusion_matrix(truth,pred,labels=[0,1]))
    print(classification_report(truth,pred,labels=[0,1],digits=3,zero_division=0))
# 极端失衡：全预测多数类，accuracy=.9但少数类 recall=0。
imbalanced=np.r_[np.zeros(90,dtype=int),np.ones(10,dtype=int)]
pred=np.zeros(100,dtype=int)
assert np.mean(pred==imbalanced)==.9
print('全预测多数类的 macro-F1',round(f1_score(imbalanced,pred,average='macro'),4))
```

训练缺少否定例时规则也不会凭空学到其标签。可比较“保留词”“bigram”“作用域”三套配置，但测试集不能用于反复选最好版本。源课只有 10条手写评论，不是公开真实数据集；源码五条测试的指标只能说明该演示的运行结果。

## 3. 评测、成本与升级条件

混淆矩阵固定行=真实类别、列=预测类别，二分类明确哪个是正类。Precision=$TP/(TP+FP)$、Recall=$TP/(TP+FN)$、F1为二者调和平均。宏平均对每类等权，weighted按支持数加权；单标签全部类别的 micro-F1等于 accuracy，容易遮住少数类。缺分母时约定值并报告支持数，不用 `zip` 静默截断标签长度。

类别失衡时同时看每类 precision/recall、混淆矩阵、macro-F1及业务代价。AUROC衡量正负样本的排序；PR曲线/average precision对罕见正类更有针对性，但依赖正类比例。“失衡就只能报 AUPRC”或“macro-F1永远是主指标”都过强。阈值按验证集目标选择，概率如用于风险或排序再检查校准；新数据基础率改变时再核验。

训练/验证/测试按真实部署方式划分：同一用户、重复评论、模板文本或同一事件不能跨集制造泄漏；时序任务用时间外推。class_weight可调整 LR目标的重要性，重采样只在训练折内进行。90/10数据的加权、阈值与不加权基线都需对照，不能把训练“平衡”误当测试分布也改变。

反讽、方面级、长文情绪转变、跨语言是比较上下文模型的理由，不是宣布所有经典模型一定失败。标注质量、领域表达和成本可能比架构更重要。升级时看真实错误类别和预算；每批/事件触发抽样审查与漂移监控，频率由业务变化决定。若为“讽刺导致的错误”另建残差分类器，训练残差应由折外预测产生，否则会学到训练集过拟合；必须有可信讽刺标签，机会水平也不总是50%。

### 3.1 类别加权的可运行消融

加权目标可写 $\sum_i a_i L_i/A+\lambda\|w\|^2/2$，$A=\sum_i a_i$，梯度为 $X^T[a\odot(p-y)]/A+\lambda w$。`balanced`的类权重为 $N/(K N_c)$；它改变训练重要性，不改测试集真实比例，校准/阈值需再核验。下面直接运行两种库设置，不预设加权一定提升macro-F1。

```python
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, f1_score
x,y=make_classification(n_samples=700,n_features=5,n_informative=3,n_redundant=0,
                       weights=[.9,.1],class_sep=.9,flip_y=0,random_state=7)
a,b,c,d=train_test_split(x,y,test_size=.35,stratify=y,random_state=3)
for weight in [None,'balanced']:
    m=make_pipeline(StandardScaler(),LogisticRegression(class_weight=weight,max_iter=400))
    m.fit(a,c);pred=m.predict(b)
    print('权重',weight,'macro-F1',round(f1_score(d,pred,average='macro'),4),
          '混淆矩阵',confusion_matrix(d,pred).tolist())
```

这里是数值合成消融，不是实际文本失衡效果；否定作用域的消融可在本章文本管线中替换 tokenizer为原 `tokens`、`scoped`并比较，真实数据另做同折对照。

## 4. LDA：文档是主题混合，主题是词分布

这里的 LDA是 Latent Dirichlet Allocation，不是线性判别分析。设文档 $d$ 的主题比例 $\theta_d\sim Dir(\alpha)$，主题 $k$ 的词概率 $\phi_k\sim Dir(\beta)$。每个位置先选 $z_{di}\sim Cat(\theta_d)$，再选 $w_{di}\sim Cat(\phi_{z_{di}})$。同一文档可以同时谈 finance和technology，模型不要求一个文档只属于一个主题。

$\theta$ 每行主题概率和为1，$\phi$ 每行词概率和为1；主题编号可任意置换，不自带真实名称。“topwords看起来像金融”是人的命名解释，不是监督分类准确率。Dirichlet先验小可鼓励更稀疏的混合，但不能简单保证更好。模型用词袋计数，输入 TF-IDF会偏离生成故事，库接受浮点不代表其概率解释不受影响。

### 4.1 折叠 Gibbs条件与可手算核对

积分掉 $\theta,\phi$ 后，临时移除当前 Token，按下式重采样它的主题：

$$P(z_{di}=k\mid z_{-di},w)\propto
(n_{dk}^{-di}+\alpha)\frac{n_{kw}^{-di}+\beta}{n_k^{-di}+|V|\beta}.$$

第一项表示这篇文档已有多少该主题，第二项表示该主题多偏好当前词。共同的文档分母与 $k$ 无关可以在归一化时省去，主题分母不能省。若两主题的文档计数都是1、当前词在主题中的计数为3与0、主题总词数为6与6、$|V|=5,\alpha=.1,\beta=.1$，权重比就是3.1:.1，所以概率为 .96875与 .03125。

```python
import numpy as np

def gibbs_lda(docs,K=2,iters=240,burn=80,seed=2,alpha=.2,beta=.1):
    if isinstance(K,bool) or not isinstance(K,int) or K<=0:
        raise ValueError('K为正整数')
    if not docs or alpha<=0 or beta<=0 or not 0<=burn<iters:
        raise ValueError('非空语料、正先验、有效迭代')
    words=sorted({w for d in docs for w in d})
    if not words:
        raise ValueError('全空词表')
    W=len(words);D=len(docs);ids={w:i for i,w in enumerate(words)}
    x=[np.array([ids[w] for w in d],dtype=int) for d in docs]
    rng=np.random.default_rng(seed)
    z=[rng.integers(K,size=len(d)) for d in x]
    nd=np.zeros((D,K),dtype=int);nw=np.zeros((K,W),dtype=int);nt=np.zeros(K,dtype=int)
    for d,seq in enumerate(x):
        for w,k in zip(seq,z[d]):
            nd[d,k]+=1;nw[k,w]+=1;nt[k]+=1
    theta=np.zeros((D,K));phi=np.zeros((K,W));samples=0
    for step in range(iters):
        for d,seq in enumerate(x):
            for i,w in enumerate(seq):
                k=z[d][i];nd[d,k]-=1;nw[k,w]-=1;nt[k]-=1
                p=(nd[d]+alpha)*(nw[:,w]+beta)/(nt+W*beta)
                p/=p.sum();k=rng.choice(K,p=p)
                z[d][i]=k;nd[d,k]+=1;nw[k,w]+=1;nt[k]+=1
        assert nt.sum()==sum(map(len,x)) and (nd>=0).all() and (nw>=0).all()
        if step>=burn and step%10==0:
            theta+=(nd+alpha)/(nd.sum(axis=1,keepdims=True)+K*alpha)
            phi+=(nw+beta)/(nt[:,None]+W*beta);samples+=1
    theta/=samples;phi/=samples
    assert np.allclose(theta.sum(axis=1),1) and np.allclose(phi.sum(axis=1),1)
    return words,theta,phi

raw=['cat dog pet cat','kitten pet cat','dog puppy pet',
     'stock bond market stock','bond rate market','stock rate market']
words,theta,phi=gibbs_lda([s.split() for s in raw])
for k,p in enumerate(phi):
    print('主题',k,[(words[i],round(float(p[i]),3)) for i in np.argsort(-p)[:5]])
print('文档混合\n',np.round(theta,3))
hand=np.array([1.1*3.1/6.5,1.1*.1/6.5]);hand/=hand.sum()
assert np.allclose(hand,[.96875,.03125])
print('手算后验',hand,'计数与归一检查通过')
```

样本间若主题标签频繁交换，直接按编号平均会混淆，需要先对齐主题；该小例在固定链内演示后验平均，真实推断须查混合、稳定性、多个 seed及留出集。空文档的比例来自先验，不应当作内容证据。

### 4.2 变分库实现与概率读取

```python
import numpy as np
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.decomposition import LatentDirichletAllocation

docs=['cat dog pet cat','kitten pet cat','dog puppy pet',
      'stock bond market stock','bond rate market','stock rate market']
v=CountVectorizer(tokenizer=str.split,token_pattern=None)
x=v.fit_transform(docs)
m=LatentDirichletAllocation(n_components=2,max_iter=30,learning_method='batch',random_state=0)
theta=m.fit_transform(x)
# components_是变分参数/平滑计数形态，需要行归一化后才作为词分布。
phi=m.components_/m.components_.sum(axis=1,keepdims=True)
assert np.allclose(theta.sum(axis=1),1) and np.allclose(phi.sum(axis=1),1)
print('库 LDA文档混合',np.round(theta,3))
print('主题词表',v.get_feature_names_out().tolist())
```

`n_components` 是主题数；batch重复处理全部训练数据，online用小批近似更新，二者不是分类标签数量的同义词。`min_df/max_df`、停用词可减轻纯功能词主题，但也可能删领域词；不能只按词长删去 ai/ml等短术语。原课用人工短词 allowlist 是教学选择，不是普适语言规则。

## 5. 聚类主题与 c-TF-IDF

BERTopic常见管线是句向量→降维（常见UMAP）→密度聚类（常见HDBSCAN）→每簇 c-TF-IDF提取代表词。这些组件可替换，不必固定384维、5维或某个 BERT模型。`-1` 常表示离群/未分配文档，应检查它的比例和内容，不能强行称为有意义的主题。通常的簇标签是一文一簇，但可扩展概率或多主题模式，不等于 LDA生成后验。

c-TF-IDF把簇内文档合成一个“类文档”。默认定义的 $TF_{ct}$ 是类词次数占该类总词数比例；$f_t=\sum_c C_{ct}$ 是词在所有类中的**总次数**，不是普通文档 DF；$A$ 为平均类文档词数，$idf_t=\log(1+A/f_t)$，代表权重为 $TF_{ct}idf_t$。实现可选其他加权，不能把常规 TF-IDF公式直接套名字。

### 5.1 完整替代管线与代表词计算

为避免下载句向量模型，下面采用 TF-IDF→SVD→KMeans，验证聚类后解释的逻辑；它是**稀疏表示替代实验**，不是已运行 BERTopic/HDBSCAN，也不能据结果证明上下文句向量优于 LDA。

```python
import numpy as np
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.decomposition import TruncatedSVD
from sklearn.cluster import KMeans

docs=['cat dog pet cat','kitten pet cat','dog puppy pet',
      'stock bond market stock','bond rate market','stock rate market']
tf=TfidfVectorizer(tokenizer=str.split,token_pattern=None)
x=tf.fit_transform(docs)
z=TruncatedSVD(n_components=2,random_state=0).fit_transform(x)
labels=KMeans(n_clusters=2,n_init=10,random_state=0).fit_predict(z)
cv=CountVectorizer(tokenizer=str.split,token_pattern=None)
c=cv.fit_transform(docs).toarray()
classes=sorted(set(labels));aggregated=np.array([c[labels==k].sum(axis=0) for k in classes],dtype=float)
length=aggregated.sum(axis=1,keepdims=True)
A=float(length.mean());frequency=aggregated.sum(axis=0)
idf=np.log1p(A/frequency)
weights=aggregated/length*idf
names=cv.get_feature_names_out()
print('替代聚类标签',labels.tolist())
for k,row in zip(classes,weights):
    print('簇',k,'代表词',[names[i] for i in np.argsort(-row)[:4]])
assert np.isfinite(weights).all()
print('类词次数汇总守恒',int(aggregated.sum())==int(c.sum()))
```

SVD压缩的是词项统计结构，不等于句向量语义编码。UMAP的随机种子、距离、邻居数和维度会改变簇；HDBSCAN密度阈值会改变离群率和主题粒度，使用时应保存输入/模型配置并回看原文。长文超过编码器限制需分段/池化设计，不能默默截掉后文。

## 6. 主题怎样评价，怎样跟踪变化

主题没有标签时不能凭“词聚在一起”的动画判断正确。检查 topwords是否可命名、文档例子是否符合、同主题是否重复、离群内容是否被漏掉，以及不同seed/采样是否稳定。topic diversity是不同 topword数/所有 topword位置数，高不必然好；全是噪声也可非常多样。K小可能混合，K大可能碎裂，没有 $\sqrt{N}$、至少5主题或最多200主题的普适定律。

共现 PMI为 $\log[P(w_i,w_j)/(P(w_i)P(w_j))]$，NPMI再除 $-\log P(w_i,w_j)$，估计时要固定文档或滑窗、平滑和支持数。常用 $c_v$包含滑窗共现、NPMI与间接向量余弦聚合，**不是单纯平均 PMI/NPMI**。若手写平均NPMI只能称代理指标，不能冒充 gensim的 c_v。自动 coherence也会偏好常见词/主题数，须结合人工文档核对；LDA留出PPL与主题可解释性可能不一致。

跨时间比较时，先以主题词分布/向量相似度对齐主题，编号0→0未必同主题。监测主题频率、词分布漂移、离群率及原文例子；允许新增/消失主题，而不是强制一对一。NMF是另一个可解释基线：对非负文本矩阵 $X$寻找非负 $W,H$使 $\|X-WH\|_F^2$较小，可用TF-IDF；行和不是天然概率，需与LDA的生成概率解释分开。其他聚类/神经主题工具应按训练目标与具体组件核验，不因名字里含“Topic”认定都与LDA等价。

短文本计数稀疏是比较语义聚类的动机，长文主题混合是 LDA的优势场景；两者都要按具体数据验证，不接受“某法通常必胜”的排名结论。

## 7. 跨语言：共享参数不等于自然对齐

零样本跨语言迁移指在源语言标签上训练，在无目标语言标签监督的条件下评测目标语言；不等于训练数据为零，也不等于“给分类标签写文本”的 NLI零样本分类。多语言预训练可共享词表/编码器，桥梁来自训练数据、目标、相关性和容量，而非共享 ID自动建立等义关系。

静态向量可借助双语词典线性对齐；句向量可通过平行句/翻译对比学习等目标训练；多语言 MLM编码器的任意池化结果不自动是优秀跨语言检索向量。作为历史研究例子，mBERT在多语言Wikipedia上用掩码目标预训练；XLM-R扩大多语言CommonCrawl训练规模，可做跨语言编码基线；NLLB研究多语言机器翻译。它们说明数据规模、训练目标和任务不同，不是当前通用排名或指定模型推荐。翻译模型、生成模型、分类编码器任务不同，不能只因都多语言就互换。

### 7.1 正交 Procrustes的完整合成核对

设双语锚点矩阵 $X,Y\in\mathbb R^{m\times d}$，求 $\min_{R^TR=I}\|XR-Y\|_F^2$。对 $X^TY=U\Sigma V^T$，解 $R=UV^T$；正交变换保留源空间距离。锚点必须对应、维度相同，训练/评测锚点分开；真实两语言空间未必仅差一个旋转，领域和频率会影响映射。

```python
import numpy as np
rng=np.random.default_rng(4)
X=rng.normal(size=(12,4))
Q,_=np.linalg.qr(rng.normal(size=(4,4)))
Y=X@Q  # 人工构造的理想对齐；不是任何现成语言模型输出。
U,s,Vt=np.linalg.svd(X[:8].T@Y[:8],full_matrices=False)
R=U@Vt
assert np.allclose(R.T@R,np.eye(4))
error=np.linalg.norm(X[8:]@R-Y[8:])
assert error<1e-10
mapped=X[8:]@R;gallery=Y[8:]
unit=lambda a:a/np.linalg.norm(a,axis=1,keepdims=True)
pred=np.argmax(unit(mapped)@unit(gallery).T,axis=1)
print('合成留出误差',float(error),'合成互译近邻命中',pred.tolist())
assert np.array_equal(pred,np.arange(4))
```

合成100%只是验证SVD方向、维度和检索实现；真实跨语言检索需非重叠双语集、硬负例、Recall@k、按语言/领域误差分析，不能将人工旋转成绩标成多语言理解能力。

## 8. NLI分类、少样本适配与语言选择

用 NLI做标签分类，将原文作 premise，用 `这段文本关于{标签}` 等作 hypothesis，模型输出 entailment/neutral/contradiction。必须从配置映射找到 entailment ID，不能硬编码 logits第2列。互斥标签可对候选的 entailment logits做跨标签softmax；多标签则对每个候选的 contradiction/entailment二项归一，分数总和不必1。三类softmax下单列 entailment分数又是另一种定义，不能混说。只有一个候选时跨候选softmax恒为1，没有可信度含义；实际工具通常改用该候选的 entailment/contradiction二项评分，使用时核对该分支。

```python
import numpy as np

def softmax(a,axis=-1):
    e=np.exp(a-np.max(a,axis=axis,keepdims=True))
    return e/e.sum(axis=axis,keepdims=True)
def scores(logits,label2id,multi_label=False):
    a=np.asarray(logits,dtype=float)
    if a.ndim!=2 or not np.isfinite(a).all():
        raise ValueError('候选×NLI类别的有限二维 logits')
    mapping={str(k).lower():v for k,v in label2id.items()}
    if 'entailment' not in mapping or 'contradiction' not in mapping:
        raise ValueError('必须确认模型类别语义，不能猜 LABEL_0')
    e,c=mapping['entailment'],mapping['contradiction']
    if any(isinstance(i,bool) or not isinstance(i,int) or not 0<=i<a.shape[1] for i in [e,c]) or e==c:
        raise ValueError('类别索引不合法')
    return softmax(a[:,[c,e]],axis=1)[:,1] if multi_label else softmax(a[:,e],axis=0)

# 人工 logits故意让 entailment在第0列，检查不依赖硬编码位置。
a=np.array([[3.,1.,-1.],[1.,0.,2.],[-1.,2.,3.]])
config={'ENTAILMENT':0,'neutral':1,'contradiction':2}
exclusive=scores(a,config)
independent=scores(a,config,True)
assert abs(exclusive.sum()-1)<1e-12
assert np.all((0<=independent)&(independent<=1))
print('互斥候选分数',np.round(exclusive,4))
print('独立候选分数',np.round(independent,4),'和',round(float(independent.sum()),4))
```

实际模型推理还需 `eval()`、无梯度、配套 Tokenizer、padding/attention mask、长度限制及 premise/hypothesis截断策略。标签词、模板语言和标签互斥性会改变结果；模型置信度不是已验证正确率。本次没有下载 NLI模型，代码只核对评分语义。

源语言选择考虑标签质量、样本量、语系/词形/文字、任务领域与预训练覆盖。用3个属性匹配比例“模拟 accuracy=.45+.45×similarity”不是实验，也不能证明 Hindi一定优于English。语言特征是候选筛选依据，需要在保持预算和验证协议一致时比较。固定模型名/参数量或100–500标签达到源语言95–98%的承诺均不保留。

少样本适配分训练/验证/测试，固定多个seed，报告标签预算和不确定性；检查目标语言提升与其他语言遗忘。学习率过大可破坏已有表示，但适当值依模型、训练步数和可训练参数范围，不把 `2e-5` 当永远最优。需比较冻结编码器+分类头、全量/参数高效微调及单语基线，真实数据足够时也可比较从头训练，不因“多语言”默认一种方案必胜。

## 9. 分语言评测、切分效率与上线契约

总平均会被大样本语言主导，同时报告每语言支持数、macro/weighted指标、主要错误、长尾置信区间和部署分布加权结果。NER可用实体级F1，检索用 Recall/MRR，分类用每类指标，生成/翻译另有语义与人工评估协议，不能所有任务只报 accuracy。

Fertility通常指每词平均子词数，但词边界需定义；中文空格词数不可与英文直接比较。还可报 tokens/码点、tokens/UTF-8字节、相同意义平行文本的Token长度、截断率与实际延迟。不同语言的“相同意义”翻译长短可能不同，也要说明。byte fallback防止未知字符，不保证更短；扩大词表、调整训练语料、字符/字节方法及模型共同适配都可能有帮助，不能宣称再多数据也修不了 tokenizer。

实际例子：某语言200篇评测文本中60篇被截断，低准确率可能由预算丢掉关键后文、标注/领域不一致或训练覆盖造成。先按长度、脚本、混合语言、类别分组查错，再决定改 Tokenizer或模型。无训练适配直接换分词器会破坏已有ID映射，不能作为快捷修复。

## 10. 自检与练习参考答案

1. NB条件独立不成立为何可能仍有用？分类只比较类别分数，某些相关性误差不改变排序；这不是效果保证，概率校准另查。
2. `NOT_`、bigram与Transformer有何差别？前两者增加有限局部特征，后者可训练上下文关系；都要数据与标签验证，不能预设F1增益。
3. 90/10全猜多数类怎样验收？accuracy=.9但少数召回0、macro-F1约.4737；结合每类支持、业务成本和阈值，不能只报.9。
4. LDA为何临时移除当前词？避免该词自己增加其当前主题计数，产生错误的条件分布。重采样前后各总计数必须守恒。
5. LDA主题词和为1、BERTopic代表词权重也必须和为1吗？前者是概率分布；后者是TF×权重，一般不作为概率。
6. `-1` 文档怎么处理？抽样看内容和比例，改阈值/表示前验证，必要时保留未分配状态，不能为了好看全塞进最近簇。
7. coherence最高就最佳吗？不是；还看重复、文档吻合、稳定和应用价值。比较时间主题前先对齐，不能直接按编号统计漂移。
8. 共享词表是否证明翻译句近？不证明；训练目标和数据决定对齐。人工旋转检索只核对方法，不是语言模型实绩。
9. 少量目标标签一定补齐跨语言差距吗？不一定，预算应实测学习曲线，且检查其他语言遗忘、领域与截断。
10. 扩展实验：原课20Newsgroups/BERTopic/gensim coherence、真实多语言零样本/500标签适配和现成句向量检索本次未运行。后续在获准数据上按同协议对照，保留原文错误样本和每语言指标，不用合成程序代替这些结论。
