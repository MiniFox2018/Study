# 07｜深度学习基础

## 1. Representation Learning

传统方式：

```text
人工特征 → 模型
```

深度学习：

```text
原始数据 → 多层表征学习 → 任务输出
```

模型同时学习“如何表示数据”和“如何完成任务”。

## 2. MLP

\[
h^{(l)}=\phi(W^{(l)}h^{(l-1)}+b^{(l)})
\]

深度网络是函数复合。

## 3. 非线性

若每层都是线性：

\[
W_2(W_1x)=(W_2W_1)x
\]

堆很多层仍等价于单层，所以必须引入非线性。

## 4. 常见激活

- Sigmoid：易饱和；
- Tanh：零中心但仍会饱和；
- ReLU：简单高效，但有 dead ReLU；
- GELU / SiLU：现代 Transformer 常见。

## 5. Backpropagation

\[
\frac{\partial L}{\partial x}
=
\frac{\partial L}{\partial y}
\frac{\partial y}{\partial x}
\]

反向传播是在计算图上高效重复应用链式法则。

## 6. Automatic Differentiation

需要理解：

- forward graph；
- gradient accumulation；
- leaf tensor；
- detach；
- no-grad。

即便框架自动求导，也必须能判断梯度为什么是 None、NaN 或接近 0。

## 7. Regularization

包括：

- L1/L2；
- data augmentation；
- dropout；
- early stopping；
- noise injection；
- parameter sharing；
- adversarial training。

## 8. Adversarial Training

\[
\min_\theta E[\max_{\|\delta\|\le\epsilon}L(f_\theta(x+\delta),y)]
\]

训练模型对局部最坏方向扰动更鲁棒。

## 9. 深度优化挑战

- ill-conditioning；
- saddle point；
- exploding gradient；
- vanishing gradient；
- noisy gradient；
- scale drift。

## 10. Initialization

初始化需要保持 activation/gradient 的合理尺度。

常见思想：

- Xavier；
- He。

具体公式取决于 activation 和 fan-in/fan-out。

## 11. Normalization

目的：

- 稳定中间激活；
- 改善优化。

包括 BatchNorm、LayerNorm、RMSNorm 等。

## 12. Mini-batch

Batch 太小：噪声和吞吐问题。

Batch 太大：显存高、更新次数少，也可能改变泛化。

最佳 batch 是优化与系统共同问题。

## 13. 训练诊断

推荐：

1. 极小数据集 overfit；
2. 验证 forward；
3. loss 是否下降；
4. gradient 是否合理；
5. train/val gap；
6. 再扩大数据和模型。
