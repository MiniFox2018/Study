# 10｜图表示与图神经网络

## 1. 图数据

图：

\[
G=(V,E)
\]

其中：

- V：节点；
- E：边。

可附加：

- node feature；
- edge feature；
- graph-level feature；
- edge type；
- direction；
- timestamp。

图的核心区别：

> 数据不是规则网格，而是关系结构。

## 2. Adjacency 与 Degree

邻接矩阵：

\[
A_{ij}
=
\begin{cases}
1,&(i,j)\in E\\
0,&otherwise
\end{cases}
\]

Degree matrix：

\[
D_{ii}=\sum_jA_{ij}
\]

Graph Laplacian：

\[
L=D-A
\]

Normalized Laplacian 常写为：

\[
L_{sym}=I-D^{-1/2}AD^{-1/2}
\]

谱图方法由此建立。

## 3. Graph Embedding：随机游走路线

### DeepWalk

核心流程：

```text
Graph
→ Random Walk
→ Node Sequence
→ Skip-Gram
→ Node Embedding
```

把图上的邻域结构转换成“句子式”共现关系。

### Node2Vec

通过参数控制随机游走在：

- BFS-like 局部邻域；
- DFS-like 结构探索；

之间权衡。

### LINE

直接优化一阶/二阶邻近关系，更适合大规模图。

## 4. Matrix Factorization 视角

很多随机游走 embedding 最终可解释为：

> 对某种节点共现/转移矩阵做隐式矩阵分解。

这连接 DeepWalk、NetMF 与经典 SVD 思想。

## 5. Message Passing

现代 GNN 的统一视角：

\[
m_v^{(l)}
=
AGGREGATE
(
\{h_u^{(l)}:u\in N(v)\}
)
\]

\[
h_v^{(l+1)}
=
UPDATE
(
h_v^{(l)},m_v^{(l)}
)
\]

即：

```text
邻居信息
→ 聚合
→ 与自身状态融合
→ 新节点表示
```

## 6. GCN

经典归一化传播：

\[
H^{(l+1)}
=
\sigma(
\tilde D^{-1/2}
\tilde A
\tilde D^{-1/2}
H^{(l)}W^{(l)}
)
\]

其中：

\[
\tilde A=A+I
\]

加入 self-loop 后，每层融合自身和邻居。

## 7. GraphSAGE

GraphSAGE 不要求为每个节点维护独立 embedding，而是学习邻居聚合函数。

优势：

- inductive；
- 可处理训练时未见的新节点；
- 可以采样固定数量邻居。

## 8. GAT

Graph Attention 给邻居不同权重：

\[
\alpha_{ij}
=
softmax_j(e_{ij})
\]

然后：

\[
h_i'
=
\sum_{j\in N(i)}
\alpha_{ij}Wh_j
\]

核心价值：

> 邻居不再被同等对待。

## 9. Heterogeneous Graph

真实图常有多类节点/边：

- 用户；
- 商品；
- 查询；
- 类目；
- 社交关系。

R-GCN、HAN、HGT 等方法将 type information 纳入 message passing。

## 10. GNN 的核心问题

### Over-smoothing

层数增加后节点表示越来越相似。

### Over-squashing

指数增长的远端信息被压缩进固定维度表示。

### Sampling

大图无法全图训练，需要：

- node sampling；
- neighbor sampling；
- cluster sampling。

### Distribution Shift

动态图中新节点、新边持续加入。

## 11. Graph Self-Supervision

没有标签时可利用：

- graph augmentation；
- contrastive learning；
- context prediction；
- link prediction；
- masked feature。

DGI 等工作推动图自监督表示学习。

## 12. 图任务

### Node-level

- node classification；
- node regression。

### Edge-level

- link prediction；
- recommendation；
- relation prediction。

### Graph-level

- graph classification；
- molecule property。

## 13. 推荐系统中的图

用户-物品交互天然构成 bipartite graph。

因此：

- PinSage；
- NGCF；
- LightGCN；

都把推荐理解为图传播或图表征问题。

LightGCN 的重要思想是：

> 在协同过滤图中，去掉不必要的 feature transform 和 nonlinear activation，保留邻居传播本身。

## 14. GNN 评估陷阱

必须检查：

- train/test edge leakage；
- transductive vs inductive；
- split 是否公平；
- 不同方法 preprocessing 是否一致；
- neighbor sampling 是否导致不可比。

很多 GNN 论文差异来自实验协议，而不仅是模型本身。

## 15. 选择图模型前先问

1. 关系是否真的提供额外信息？
2. 图是否稳定？
3. 推理时能否访问邻居？
4. 新节点是否频繁出现？
5. 需要 node、edge 还是 graph prediction？
6. 全图还是大规模采样？

如果没有强关系结构，GNN 不一定优于普通特征模型。
