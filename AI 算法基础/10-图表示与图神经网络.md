## 1. 图数据

图：

$$
G=(V,E)
$$

其中：

- V：节点；
- E：边。

可附加：

- node feature；
- edge feature；
- graph-level feature；
- edge type；
- direction；
- timestamp。

图的核心区别：

> 数据不是规则网格，而是关系结构。

## 2. Adjacency 与 Degree

邻接矩阵：

$$
A_{ij}
=
\begin{cases}
1,&(i,j)\in E\\
0,&otherwise
\end{cases}
$$

Degree matrix：

$$
D_{ii}=\sum_jA_{ij}
$$

Graph Laplacian：

$$
L=D-A
$$

Normalized Laplacian 常写为：

$$
L_{sym}=I-D^{-1/2}AD^{-1/2}
$$

这里主要讨论无向非负权图。$D^{-1/2}$ 遇到零度节点需明确约定（常将对应元素置零）；GCN 加自环后的度矩阵必须从 $\tilde A$ 重新计算。对有向图不能直接套用无向对称谱结论。

## 3. Graph Embedding：随机游走路线

### DeepWalk

核心流程：

```text
Graph
→ Random Walk
→ Node Sequence
→ Skip-Gram
→ Node Embedding
```

把图上的邻域结构转换成“句子式”共现关系。

### Node2Vec

通过参数控制随机游走在：

- BFS-like 局部邻域；
- DFS-like 结构探索；

之间权衡。

### LINE

直接优化一阶/二阶邻近关系，更适合大规模图。

## 4. Matrix Factorization 视角

很多随机游走 embedding 最终可解释为：

> 对某种节点共现/转移矩阵做隐式矩阵分解。

这连接 DeepWalk、NetMF 与经典 SVD 思想。

## 5. Message Passing

现代 GNN 的统一视角：

$$
m_v^{(l)}
=
AGGREGATE
(
\{h_u^{(l)}:u\in N(v)\}
)
$$

$$
h_v^{(l+1)}
=
UPDATE
(
h_v^{(l)},m_v^{(l)}
)
$$

即：

```text
邻居信息
→ 聚合
→ 与自身状态融合
→ 新节点表示
```

## 6. GCN

经典归一化传播：

$$
H^{(l+1)}
=
\sigma(
\tilde D^{-1/2}
\tilde A
\tilde D^{-1/2}
H^{(l)}W^{(l)}
)
$$

其中：

$$
\tilde A=A+I
$$

加入 self-loop 后，每层融合自身和邻居。

## 7. GraphSAGE

GraphSAGE 不要求为每个节点维护独立 embedding，而是学习邻居聚合函数。

优势：

- inductive；
- 可处理训练时未见的新节点；
- 可以采样固定数量邻居。

## 8. GAT

Graph Attention 给邻居不同权重：

$$
\alpha_{ij}
=
softmax_j(e_{ij})
$$

然后：

$$
h_i'
=
\sum_{j\in N(i)}
\alpha_{ij}Wh_j
$$

核心价值：

> 邻居不再被同等对待。

## 9. Heterogeneous Graph

真实图常有多类节点/边：

- 用户；
- 商品；
- 查询；
- 类目；
- 社交关系。

R-GCN、HAN、HGT 等方法将 type information 纳入 message passing。

## 10. GNN 的核心问题

### Over-smoothing

层数增加后节点表示越来越相似。

### Over-squashing

指数增长的远端信息被压缩进固定维度表示。

### Sampling

大图无法全图训练，需要：

- node sampling；
- neighbor sampling；
- cluster sampling。

### Distribution Shift

动态图中新节点、新边持续加入。

## 11. Graph Self-Supervision

没有标签时可利用：

- graph augmentation；
- contrastive learning；
- context prediction；
- link prediction；
- masked feature。

DGI 等工作推动图自监督表示学习。

## 12. 图任务

### Node-level

- node classification；

### Edge-level

- link prediction；

### Graph-level

- graph classification；

## 13. 推荐系统中的图

用户-物品交互天然构成 bipartite graph。

因此：

- PinSage；
- NGCF；
- LightGCN；

都把推荐理解为图传播或图表征问题。

LightGCN 的重要思想是：

> 在协同过滤图中，去掉不必要的 feature transform 和 nonlinear activation，保留邻居传播本身。

## 14. GNN 评估陷阱

必须检查：

- train/test edge leakage；
- transductive vs inductive；
- split 是否公平；
- 不同方法 preprocessing 是否一致；
- neighbor sampling 是否导致不可比。

很多 GNN 论文差异来自实验协议，而不仅是模型本身。

## 15. 选择图模型前先问

1. 关系是否真的提供额外信息？
2. 图是否稳定？
3. 推理时能否访问邻居？
4. 新节点是否频繁出现？
5. 需要 node、edge 还是 graph prediction？
6. 全图还是大规模采样？

如果没有强关系结构，GNN 不一定优于普通特征模型。

## 16. UDL 补充：Inductive / Transductive

### Transductive

训练时已经知道完整图结构，只是部分节点没有标签。

典型：

- citation network；
- 固定社交图上的节点分类。

模型可以利用测试节点的图位置和未标注结构，但不能使用其标签。

### Inductive

推理时会出现训练阶段不存在的新节点或新图。

模型必须学习可泛化的聚合函数，而不是只记住节点 ID 对应 embedding。

GraphSAGE 是典型 inductive 思路。

实际评估时必须明确：

> 测试节点是否在训练阶段已经出现在图结构中？

否则 transductive 与 inductive 结果不可直接比较。

## 17. UDL 补充：邻居聚合的设计空间

GCN 并不是唯一聚合方式。

常见选择：

- sum；
- mean；
- max；
- normalized adjacency；
- attention-weighted aggregation；
- learned message function。

设计时需要同时考虑：

- permutation equivariance；
- degree scale；
- self feature；
- edge feature；
- computational cost。

## 18. Edge / Line Graph 视角

有些任务的预测对象是边而不是节点。

可以：

1. 直接构造 edge representation；
2. 把原图的 edge 变成新图中的 node，即 line graph / edge graph；
3. 在新图上继续 message passing。

这适合：

- relation classification；
- molecular bond reasoning；
- link-level structured prediction。

## 20. Compendium 补充：Geometric Deep Learning

Geometric Deep Learning 的核心不是“只研究图”，而是问：

> 数据在什么对称变换下应该保持不变，模型又应该如何尊重这种结构？

### Invariance

若变换 (g) 作用在输入上：

$$
f(gx)=f(x)
$$

则模型对该变换 invariant。

### Equivariance

若：

$$
f(\rho_{\mathrm{in}}(g)x)=\rho_{\mathrm{out}}(g)f(x)
$$

则模型对该变换等变。$\rho_{\mathrm{in}}$ 与 $\rho_{\mathrm{out}}$ 表示同一个群元素在输入/输出空间的作用，不一定是同一个矩阵。

图神经网络最基本的要求之一，是对节点重排保持 permutation equivariance：重新编号节点不应改变图本身的语义。

## 21. GIN 与表达能力

Graph Isomorphism Network 使用 sum aggregation + MLP：

$$
h_v^{(k)}=\operatorname{MLP}^{(k)}\left((1+\epsilon^{(k)})h_v^{(k-1)}+\sum_{u\in N(v)}h_u^{(k-1)}\right)
$$

它的重要意义是把 GNN 的区分能力与 Weisfeiler-Lehman 图同构测试联系起来。

选择聚合器时不仅要看速度，也要看它会不会把不同邻域结构压成相同表示。

## 22. GATv2 与动态注意力

早期 GAT 的 attention ranking 存在表达限制。GATv2 调整打分结构，使注意力权重更能依赖 query node 与 neighbor 的联合关系。

长期结论：

> “用 attention”并不自动意味着关系建模足够灵活，attention score 的函数形式本身也限制表达能力。

## 23. Graph Transformer

传统 message passing 擅长局部邻域，但远距离信息传播会受到 over-squashing 和层数限制。

Graph Transformer 引入更全局的交互，但必须补入图结构信息，例如：

- shortest-path / distance encoding；
- degree / centrality；
- edge features；
- positional / spectral encoding。

Graphormer 是“给全局 attention 注入图结构偏置”的代表；GPS 类架构则把 local message passing 与 global attention 结合。

## 24. Temporal Graph

如果节点和边随时间变化，仅使用静态图会丢失事件顺序。

动态图需要区分：

- snapshot sequence；
- timestamped event stream；
- temporal neighborhood。

适用于交易网络、社交互动、推荐和风控。

## 25. 3D Graph 与 SE(3) Equivariance

分子、蛋白质和 3D 点云中的节点带有空间坐标。

理想模型应正确处理旋转和平移：

- 标量性质应保持 invariant；
- 向量/几何表示应按相同变换 equivariant。

典型路线：

- SchNet：基于原子间距离建模；
- DimeNet：显式加入角度关系；
- EGNN：用更简洁方式实现等变消息传播；
- MACE 等：进一步利用高阶几何表示。

## 26. 分子建模与图生成

3D GNN 可用于：

- molecular property prediction；
- energy / force prediction；
- protein / material modeling；
- drug discovery。

更进一步还可以直接生成：

- graph structure；
- atom type；
- 3D coordinates。

因此图学习已经从“在固定图上做预测”扩展到“生成满足结构与几何约束的对象”。

## 三个节点做一次传播

取无向链 $1-2-3$，每个节点加入自环，初始标量特征为 $(1,2,3)$。先用便于手算的“邻域均值”（这不是对称归一化 GCN）：

- 节点 1 平均自身和节点 2：$(1+2)/2=1.5$。
- 节点 2 平均三者：$(1+2+3)/3=2$。
- 节点 3 平均自身和节点 2：$(2+3)/2=2.5$。

对称 GCN 的度数是 $(2,3,2)$，边权为 $1/\sqrt{d_i d_j}$；其输出不等同上述简单均值。实现前必须写出自己使用哪种归一化。

自查：将节点 1 和 3 编号互换，均值输出应怎样变化？**答案：**对应交换成 $(2.5,2,1.5)$，体现节点级等变；图级分类通常还需不变的读出操作。

核验（2026-10-02）：[GIN 原论文](https://arxiv.org/abs/1810.00826)。表达能力与聚合器和假设有关，不等同于识别所有非同构图。
