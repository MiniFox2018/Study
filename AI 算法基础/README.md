## 时效性处理

**保留“旧但仍有效”的基础理论，删除“已经失效的实现”。**

- SVM、EM、HMM、PCA、ResNet、Transformer 等不会因为年份早而删除；
- 旧版框架/API 写法不固化；
- 历史 benchmark 数字只作背景，不作为当前性能结论；
- 快速变化的 LLM/Agent/硬件生态只保存稳定原理和决策框架。

原则：**主干负责知识地图，专题负责推导、训练、实现、诊断与领域深化；多来源去重吸收，不复制原教材目录。**

## 第一遍怎样学（2026-10-02 修订）

本目录的 18 篇主干是概念地图，深度学习专题负责进一步计算和诊断。不要按目录一次读完，也不要把来源覆盖表当成已学清单。

| 层次 | 入口与范围 | 过关证据 |
|---|---|---|
| 基础必修 | 01～05、07、14 的 NumPy/表格/评估部分 | 手算一次预测与梯度；说明训练/验证/测试职责；辨认广播或泄漏错误 |
| 深度学习主线 | 08、09 + 专题 01～05、09 | 跑通最小训练；计算卷积尺寸和注意力；解释训练差/验证差的下一步检查 |
| 按任务选修 | 06、10～13、感知与多模态专题 | 只选一个问题，给出输入输出、假设、指标和一个失败例子 |
| 深化与查阅 | 专题 10～15、15/16 主干 | 能说明理论的假设和适用范围；不要求背全部算法名 |

每篇新增的小例子用于验证概念，不代表已完成真实项目或真实泛化测试。先自己计算/运行再看答案；若错在矩阵形状、概率条件或数据划分，返回相应基础段，不必硬读后续章节。

当前仍有边界：本地保存的原始 Notebook 保持来源版本，未全部在现代环境中运行；本目录也未重写所有教材证明、图片与习题。主题有入口、原文有保全、代码已跑通、读者已掌握，应分别记录。
