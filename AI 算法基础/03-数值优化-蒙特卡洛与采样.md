# 03｜数值优化、蒙特卡洛与采样

## 1. 数值稳定性

浮点数不是实数。常见问题包括 overflow、underflow、catastrophic cancellation。

### Log-Sum-Exp

直接计算 `log Σ exp(x_i)` 可能溢出。稳定写法：

\[
m=\max_i x_i
\]

\[
\log\sum_i e^{x_i}=m+\log\sum_i e^{x_i-m}
\]

Softmax 同理。

## 2. Gradient Descent

\[
\theta_{t+1}=\theta_t-\eta\nabla f(\theta_t)
\]

学习率决定单步更新尺度。

## 3. SGD 与 Mini-batch

\[
g_t=\frac1{|B|}\sum_{i\in B}\nabla_\theta L_i
\]

SGD 用噪声梯度换取更低单步成本与更高数据吞吐。

## 4. Momentum

\[
v_t=\beta v_{t-1}+g_t
\]

\[
\theta_{t+1}=\theta_t-\eta v_t
\]

作用：平滑梯度、减少震荡、沿持续方向加速。

## 5. 自适应优化

AdaGrad、RMSProp、Adam 等都根据历史梯度调整每个参数的有效步长。理解重点是：不同参数不再共享完全相同的更新尺度。

## 6. Hessian 与二阶方法

\[
H=\nabla^2 f(\theta)
\]

Newton：

\[
\theta_{t+1}=\theta_t-H^{-1}\nabla f(\theta_t)
\]

深度网络中完整 Hessian 太大，因此常用 quasi-Newton、Hessian-vector product 与曲率近似。

## 7. 约束优化

```text
min f(x)
s.t. g_i(x) <= 0
     h_j(x) = 0
```

关键工具：

- Lagrangian；
- KKT 条件。

SVM 的对偶推导就是典型应用。

## 8. Monte Carlo

若 `x_i ~ p(x)`：

\[
E_p[f(x)]\approx\frac1N\sum_i f(x_i)
\]

用于高维积分和期望近似。

## 9. Importance Sampling

\[
E_p[f(x)]
=
E_q[f(x)\frac{p(x)}{q(x)}]
\]

当 p 难采样、q 易采样时非常有用，但 q 必须覆盖 p 的重要区域。

## 10. Markov Chain 与 MCMC

Markov 性：

\[
P(X_{t+1}|X_t,\ldots,X_0)=P(X_{t+1}|X_t)
\]

MCMC 构造一条 Markov Chain，使其平稳分布等于目标分布。

常见：

- Metropolis-Hastings；
- Gibbs Sampling。

## 11. 优化诊断顺序

```text
数据
→ Loss
→ 数值稳定性
→ Initialization
→ Learning Rate
→ Gradient
→ Optimizer
```

不要一开始就通过更复杂 optimizer 掩盖数据或 loss 错误。
