## 2. 局部模型、曲率与一步更新

对标量目标 $f:\mathbb R^d\to\mathbb R$，梯度是偏导向量，Jacobian 描述向量输出的导数，Hessian 描述二阶曲率。局部二阶模型为

$$
f(x+s)\approx f(x)+\nabla f(x)^{\mathsf T}s+\frac12s^{\mathsf T}H(x)s.
$$

GD 用 $s=-\eta\nabla f$；Newton 在合适正定二阶模型下解 $Hs=-\nabla f$。实际解线性方程而非显式求逆，非凸/远离最优点时还需阻尼、线搜索或信赖域。Adam 利用梯度与平方梯度的滑动矩调整坐标尺度，不能称为直接 Hessian 近似。

**手算。** $f(x)=(x-3)^2$，从 $x_0=0$ 出发，梯度为 -6。$\eta=0.1$ 得 $x_1=0.6$，损失 9 降到 5.76；$\eta=1.1$ 得 6.6，损失升到 12.96。凸函数也会因步长过大而发散。

凸性意味着每个局部最小点都是全局最小点，不意味着最小点存在、唯一或任意算法一定收敛。$\nabla f=0$ 也可能是极大点或鞍点。约束优化需要进一步检查可行域、Lagrange 乘子与 KKT 的适用条件，详见优化专题。

自查：若 $f(x,y)=x^2-y^2$，在原点梯度为零，是好最小点吗？**答案：**不是；Hessian 特征值为 2 和 -2，沿 $y$ 方向还可下降，且该目标向下无界。

## 3. 数值稳定是训练正确性的组成部分

浮点数在有限范围内保存有限精度，不是精确实数。指数上溢、极小梯度下溢、近等大数相减和累计舍入都可能影响训练。有限 logits 的稳定 log-sum-exp 为

$$
m=\max_i z_i,\qquad
\log\sum_i e^{z_i}=m+\log\sum_i e^{z_i-m}.
$$

例如 $[1000,1001,1002]$ 转成 $[-2,-1,0]$ 后指数最大为 1；softmax 约为 $(0.09003,0.24473,0.66524)$。真实类别为 0 的交叉熵可直接用 $-(z_0-m)+\log\sum_i e^{z_i-m}$，约 2.407606，不必先求概率再取 log。

还要检查空输入、全部类别屏蔽、NaN 和 inf，不能认为“减最大值”能修好任意非法输入。用 NumPy float32 与 Python `math.exp` 讲溢出时需分清类型；后者通常使用 float64，边界不同。完整代码、稳定 sigmoid/BCE、Welford/Kahan、梯度检查、loss scaling 与裁剪顺序均在数值稳定专题维护。

## 4. 积分为什么变成 Monte Carlo 平均

概率期望是加权积分：$\mu=E_p[f(X)]=\int f(x)p(x)dx$。能从 $p$ 独立采样时，$\hat\mu=N^{-1}\sum_i f(X_i)$ 可近似它；有限一阶矩支持大数定律，有限方差下标准误约为样本标准差除 $\sqrt N$。典型误差尺度是 $N^{-1/2}$，误差降至原来的十分之一通常需要约百倍样本，而不是十倍。

例如估 $\int_0^1 x^2dx=1/3$，取 $U_i\sim U(0,1)$，对 $U_i^2$ 平均。以下完整 NumPy 例同时报告点估计与标准误：

```python
import numpy as np
rng = np.random.default_rng(42)
values = rng.random(100000)**2
estimate = values.mean()
se = values.std(ddof=1)/np.sqrt(len(values))
print("积分估计、标准误、真值：", estimate, se, 1/3)
```

随机标准误不是每次误差的保证界，也不表示高维难题不需付出代价：方差、稀有事件、相关性和采样成本都会影响结果。训练的经验平均损失同样与总体期望相连；Bayes 归一化常数和潜变量边缘化也经常需要近似积分。

## 5. 重要性采样：更换提议后怎样不改变目标

如果 $p$ 难采样但可计算，从提议分布 $q$ 采样并加权：

$$
E_p[f(X)]=E_q\!\left[f(X)\frac{p(X)}{q(X)}\right].
$$

要求在 $p(x)f(x)\ne0$ 区域有 $q(x)>0$，且相关积分存在。支持集覆盖只是基本正确性条件，不保证低方差；提议尾部过轻会出现极大权重。若只知道未归一化目标，可用自归一化权重，但有限样本一般有偏，需另外说明。

**完整手算。** $p=(0.2,0.8)$、$q=(0.5,0.5)$ 定义在 $\{0,1\}$，估 $E_p[X]$。对应权重为 0.4 与 1.6，于是 $E_q[Xp(X)/q(X)]=0.5\times0+0.5\times1.6=0.8$。

自查：若 $q(1)=0$ 会怎样？**答案：**无法看到对目标期望有贡献的 1，权重没有定义；增加样本量不能修复这个支持集缺口。方差降低、拒绝采样与重要性采样之间的区别见采样专题。

## 6. Markov 链与 MCMC：平稳不等于已经混合

Markov 性指给定当前状态后，下一状态条件分布不再依赖更早历史：

$$
P(X_{t+1}\mid X_t,\ldots,X_0)=P(X_{t+1}\mid X_t).
$$

MCMC 构造以目标 $p$ 为平稳分布的链，再用链状态估期望。有限状态链不可约且非周期等条件可保证从初值趋向唯一平稳分布；一般连续空间需要相应遍历性条件。目标为平稳分布还不足以证明从任意初值快速收敛。

Metropolis–Hastings 使用提议与接受/拒绝校正，Gibbs 依次采条件分布；各方法的选择取决于目标与计算成本。拒绝当前提议后重复旧状态也是有效链的一部分，不能随意删掉，否则会改变抽样过程。

链样本通常相关，独立样本的 $s/\sqrt N$ 不能原封不动当作标准误。要结合轨迹、多个初值/多链、相关性、有效样本量和合适收敛诊断；丢弃前若干步不会自动证明已混合。随机过程和采样专题分别维护其原理与方法。

## 7. 实践诊断与学习验收

诊断训练的顺序：数据与标签 → Loss 定义 → 数值稳定 → 初始化 → 梯度检查 → 学习率 → 优化器。诊断采样则先看目标与提议支持集，再看接受率/权重、相关性、方差与误差估计。不要让更复杂算法掩盖前面的错误。

学习验收有三个独立结果：能手算一步梯度更新并说明步长条件；能解释稳定损失为何与原目标数学等价；能用随机样本估一个已知积分并报告误差。再进一步做到自己改例子、核对失败原因。代码能运行与已经掌握、目标值很低与实际泛化、资料齐全与理论正确，都需分别判断。
