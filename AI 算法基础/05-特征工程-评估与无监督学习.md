# 05｜特征工程、评估与无监督学习

## 1. 缺失值

处理方式：

- 删除；
- 常量；
- 均值/中位数；
- 分组统计；
- 模型预测；
- missing indicator。

先判断缺失是否本身带业务信息。

## 2. 类别特征编码

常见：

- one-hot；
- ordinal；
- frequency；
- target encoding；
- learned embedding。

Target encoding 必须防 label leakage。

## 3. Scaling

Standardization：

\[
z=\frac{x-\mu}{\sigma}
\]

Min-max：

\[
x'=\frac{x-x_{min}}{x_{max}-x_{min}}
\]

KNN、SVM、线性模型和神经网络通常比树模型更依赖尺度。

## 4. Feature Selection

### Filter

模型外评估：相关性、互信息、统计检验。

### Wrapper

反复训练模型搜索特征子集。

### Embedded

选择发生在训练内部，如 L1、tree importance。

## 5. Train / Validation / Test

- Train：拟合参数；
- Validation：选择超参数；
- Test：最终估计泛化性能。

不要用 test 调参。

## 6. Cross Validation

K-fold 适合数据量有限时稳定估计泛化；时间序列必须保持时间方向，不应用随机 K-fold。

## 7. Bias-Variance

Underfitting 通常对应高 bias；Overfitting 通常对应高 variance。

解决方案应针对来源，而不是统一“加正则”。

## 8. 分类指标

Precision：

\[
\frac{TP}{TP+FP}
\]

Recall：

\[
\frac{TP}{TP+FN}
\]

F1：

\[
2\frac{PR}{P+R}
\]

类别极不平衡时 accuracy 往往误导。

## 9. ROC / PR / Calibration

ROC 关注 TPR/FPR；PR 更适合稀有正类。

概率模型还应关注 calibration：预测 0.8 的样本长期是否约 80% 为正。

## 10. Hyperparameter Search

- grid；
- random；
- Bayesian optimization。

高维超参中 random search 往往比 grid 更有效。

## 11. PCA

中心化数据的主要方差方向可由协方差矩阵特征分解或 SVD 得到。

PCA 的目标不是“压到二维”，而是用较少正交方向保留尽量多方差。

## 12. Manifold / Visualization

包括：

- Isomap；
- LLE；
- t-SNE。

t-SNE 适合局部可视化，不应把二维全局距离当成严格真实距离。

## 13. Clustering

### K-Means

\[
\min\sum_i\|x_i-\mu_{c_i}\|_2^2
\]

### DBSCAN

基于局部密度，可识别任意形状簇和噪声。

### Hierarchical

产生层级结构。

### Spectral

利用图 Laplacian 的谱结构。

## 14. Semi-Supervised Learning

利用少量标签 + 大量无标签。

典型假设：

- smoothness；
- cluster；
- manifold。

方法包括 generative、graph label propagation、co-training、semi-supervised SVM。

## 15. 类别不平衡

解决方式：

- sampling；
- class weight；
- threshold；
- task-specific loss；
- 更合理指标。

关键先问：FP 和 FN 代价是否相同？
