# 14｜科学计算与工具生态

> 工具查阅章，先会 Python 变量、列表、函数。第一遍用 NumPy 完成形状计算，再用 pandas 与 scikit-learn 完成一个小表格任务；Spark/Scala 按项目需要选学。

> 本章吸收工具章节中的稳定抽象；版本相关 API、安装命令和已弃用接口不固化。

## 1. NumPy

### ndarray

核心属性：

- shape；
- dtype；
- ndim；
- strides。

关键能力：

- vectorization；
- broadcasting；
- slicing；
- advanced indexing；
- ufunc；
- reduction。

### Broadcasting

从右到左比较维度：

- 相等；
- 或其中一个为 1；

即可扩展。

正确使用广播能避免 Python loop，但错误广播也可能静默产生错误结果。

### View vs Copy

切片常产生 view；高级索引常产生 copy。

这直接影响：

- 内存；
- 原地修改；
- 性能。

## 7. Spark

Spark 的长期抽象：

### RDD

分布式 immutable collection，强调 transformation/action。

### DataFrame

具有 schema 的分布式表格，能够让优化器理解执行计划。

### Lazy Evaluation

Transformation 不立即执行，action 触发 job。

### Partition

数据分区决定：

- parallelism；
- data locality；
- shuffle cost。

### Shuffle

join/groupBy/repartition 等可能产生网络与磁盘大开销。

大数据性能问题通常先看：

- partition；
- skew；
- shuffle；
- serialization；
- cache。

## 12. 工具选择原则

不要按“最流行”选工具，先按任务层级：

```text
单机向量计算 → NumPy
科学计算 → SciPy
中等表格 → pandas
传统 ML → scikit-learn / GBDT
分布式数据 → Spark / other distributed engine
LLM research → PyTorch + HF ecosystem

```

## 最容易静默出错的广播

若预测数组形状为 `(3, 1)`，标签为 `(3,)`，直接相减会广播成 `(3, 3)`，而不是期望的 3 个逐样本误差。例如预测 `[1, 2, 3]`、标签 `[1, 2, 4]`，正确残差应是 `[0, 0, -1]`。

动手步骤：先打印两个 `shape`；将两者显式整理为同一约定（都为 `(3,)` 或都为 `(3, 1)`）；再计算残差和均方误差。**应得结果：**$1/3$。

自查：NumPy 广播规则允许这次相减，为什么仍是错误？**答案：**数组运算合法不代表样本语义匹配；必须同时核对轴的含义。pandas 的索引对齐同样需要检查，不能只看行数相等。

核验（2026-10-02）：[NumPy 广播规则](https://numpy.org/doc/stable/user/basics.broadcasting.html)。运行具体库代码时应在学习记录中保存实际版本。
