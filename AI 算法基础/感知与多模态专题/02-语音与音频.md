# 02｜语音与音频

## 1. 音频是时间信号

声音先以连续波形存在，数字化需要：

- sampling rate；
- bit depth；
- anti-aliasing。

Nyquist 直觉：采样率必须足以覆盖目标频率范围。

## 2. 时域与频域

Fourier transform 把波形分解为频率成分。

真实语音随时间变化，所以常用短时分析：

```text
waveform
→ framing/window
→ STFT
→ spectrogram
```

Mel filterbank 与 MFCC 进一步把频谱映射到更接近人类听觉的尺度。

## 3. ASR

自动语音识别目标：

```text
audio → text
```

主要建模难点：

- 语音帧远多于文本 token；
- 对齐未知；
- 口音、噪声、说话速度变化。

代表路线：

- CTC；
- RNN-T / transducer；
- attention encoder-decoder；
- Conformer；
- self-supervised speech representation。

Whisper、wav2vec 等作为典型架构理解，不把具体版本能力写成长期结论。

## 4. CTC

CTC 通过 blank token 和路径折叠，在不知道精确帧级对齐时训练序列映射。

核心价值：

> 将“长输入—短输出”的未知单调对齐边缘化。

## 5. Conformer

Conformer 将 Transformer 的全局依赖与 convolution 的局部模式结合，特别适合语音。

## 6. TTS

文本转语音通常包含：

```text
text/phoneme
→ acoustic model
→ mel / acoustic representation
→ vocoder
→ waveform
```

WaveNet、Tacotron、VITS 分别代表自回归波形、seq2seq 声学建模和更统一的生成路线。

## 7. Speaker Tasks

- speaker verification：是不是同一个人；
- speaker identification：是谁；
- diarization：谁在什么时候说话。

说话人 embedding 常用于聚类和匹配。

## 8. VAD 与 Acoustic Event

Voice Activity Detection 判断语音区间，是 ASR/会议系统的基础前处理。

更一般的 audio classification 还包括事件、环境和音乐等声音识别。

## 9. Source Separation

目标是从混合信号中恢复独立源。

方法从频谱掩码发展到端到端时域网络。Conv-TasNet 是理解“直接对 waveform 分离”的典型路线。

## 10. Noise Cancellation

Active Noise Cancellation 通过生成反相信号抵消噪声，需要实时估计、滤波和低延迟控制。

## 11. 与多模态的连接

音频模型最终会进入：

- speech-language model；
- audio-text contrastive learning；
- multimodal assistant；
- audio generation。
