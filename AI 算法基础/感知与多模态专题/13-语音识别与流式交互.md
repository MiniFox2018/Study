> 先修：[音频概览](02-语音与音频.md)、[频域与采样](../数学与数值计算专题/09-复数傅里叶与频域理解.md)、[序列模型](../深度学习专题/03-序列模型与机器翻译.md)。先学习采样/时间/长度合同，再比较识别建模与训练，最后实现缓冲和会话状态。本章只用合成输入验证机制，不采集麦克风、不播放音频、不下载模型，不将规则、随机概率或固定答案当实际识别/通话。

## 1. 输入合同：样本、帧与物理时间

ASR 将音频序列映射为文字序列，音频帧与字符/子词没有一一位置标注；同一个词因语速可能占用不同时间。它不是“每一帧分类后用懂英语的模块拼接”的完整定义，模型可以多语言、非自回归或带语言历史。

每份音频记录采样率、通道、样本格式/范围、真实样本数、时钟与首样本时间。单声道浮点输入通常约定幅度在[-1,1]；PCM16要明确字节序、双字节采样和通道交错。把48kHz数据只改metadata成16kHz会让音频慢三倍，不是重采样。采样率由录音/通信/codec/模型规定，不把16kHz当所有阶段的通用单位。

20ms在16kHz为320样本，在48kHz为960样本；2秒的16kHz环形缓冲容量为32000个样本，容量不等于当前实际等待2秒。STFT帧长度、hop、中心padding、卷积步幅决定encoder时间步数，不能从输入秒数只乘一个默认频率就得到所有模型的输出长度。时间戳的物理零点与音频被删除的静音区间必须保留映射。

对一维卷积，合法输入长度 $L$ 经kernel $k$、stride $s$、padding $p$、dilation $d$ 后：

$$
L_{out}=\left\lfloor\frac{L+2p-d(k-1)-1}{s}\right\rfloor+1.
$$

每层都要递推有效长度；batch填到最大长度不能让PAD进入双向状态或有效损失。CTC/RNN-T的输入长度来自实际encoder步数，而不是原始波形采样点。针对卷积边界，可逐项有效序列编码或明确逐层mask/crop，最后才padding；仅给loss传length不能证明整个模型不受padding污染。

### 1.1 碎包、固定帧与EOF的完整程序

网络包或读取块不一定恰好是一帧，PCM16甚至可能在一个采样的两个字节中间分包。先合并未完成采样字节，再拼成帧，保留连续首样本序号；EOF的短尾帧是真实音频，不能静默丢弃，也不能把人工padding算进时间。下面只在内存中构造PCM，不接设备或网络。

```python
from dataclasses import dataclass
import numpy as np

@dataclass
class Frame:
    start: int
    valid_n: int
    samples: np.ndarray

class PCM16Frames:
    def __init__(self, frame_n=320):
        if type(frame_n) is not int or frame_n <= 0:
            raise ValueError("帧长度必须正整数")
        self.frame_n, self.next_sample = frame_n, 0
        self.bytes = bytearray()
        self.tail = np.empty(0, dtype=np.float32)
        self.closed = False
    def feed(self, packet):
        if self.closed or not isinstance(packet, (bytes, bytearray)):
            raise ValueError("EOF后不可写入，输入必须是小端单声道PCM16字节")
        self.bytes.extend(packet)
        nbytes = len(self.bytes) // 2 * 2
        if nbytes:
            data = np.frombuffer(bytes(self.bytes[:nbytes]), dtype="<i2").astype(np.float32) / 32768.
            del self.bytes[:nbytes]
            self.tail = np.concatenate((self.tail, data))
        out = []
        while len(self.tail) >= self.frame_n:
            out.append(Frame(self.next_sample, self.frame_n, self.tail[:self.frame_n].copy()))
            self.next_sample += self.frame_n
            self.tail = self.tail[self.frame_n:]
        return out
    def finish(self):
        if self.closed:
            raise ValueError("EOF重复")
        if self.bytes:
            raise ValueError("EOF剩余半个PCM16采样，不能猜测补字节")
        self.closed = True
        if not len(self.tail):
            return []
        out = [Frame(self.next_sample, len(self.tail), self.tail.copy())]
        self.next_sample += len(self.tail)
        self.tail = np.empty(0, dtype=np.float32)
        return out

raw = np.arange(650, dtype="<i2")
packets = [1, 7, 100, 2, 1190]  # 字节数，含奇数碎包；总1300字节
assembler = PCM16Frames()
frames, cursor = [], 0
for size in packets:
    frames += assembler.feed(raw.tobytes()[cursor:cursor+size])
    cursor += size
frames += assembler.finish()
assert [(f.start, f.valid_n) for f in frames] == [(0,320),(320,320),(640,10)]
assert np.array_equal(np.concatenate([f.samples for f in frames]), raw.astype(np.float32)/32768.)
print("碎包/EOF帧", [(f.start,f.valid_n) for f in frames], "真实秒数", assembler.next_sample/16000)
bad = PCM16Frames()
bad.feed(b"\x01")
try:
    bad.finish()
except ValueError:
    print("半个PCM采样EOF已拒绝")
```

输出总真实时长0.040625秒，尾部10样本不丢失。此代码会为教学批次复制/拼接内存，不宣称可以直接放进高优先级audio callback。立体声需按每采样帧的通道数解交错/混音；不能把所有通道样本flatten后仍当单声道时间。

### 1.2 有界环形缓冲与显式背压

producer和consumer速度不一致时，容量给的是最大存储量，不提供无限吞吐；当前积压样本数/采样率才是队列等待的音频时长。`deque(maxlen=...)`默认覆盖最早元素，若不记录丢失就会把不连续音频当连续送进模型。选择阻塞、拒绝新包、丢最旧或断开/重置要按系统需求制定，任何丢失都要携带gap及重新初始化状态的策略。

下面单线程教学实现预分配FIFO，拒绝越界写而保持旧数据，验证环绕、连续时间与无静默丢样。真实多线程需要锁或正确的SPSC原子协议，Python对象不因为叫RingBuffer就自动lock-free。

```python
import numpy as np

class SampleRing:
    def __init__(self, capacity, sr):
        if type(capacity) is not int or capacity <= 0 or sr <= 0:
            raise ValueError("容量/采样率非法")
        self.data = np.empty(capacity, dtype=np.float32)
        self.capacity, self.sr = capacity, sr
        self.head = self.level = self.first = self.next_write = 0
    def put(self, start, samples):
        x = np.asarray(samples, dtype=np.float32)
        if x.ndim != 1 or not np.isfinite(x).all():
            raise ValueError("要求有限单声道序列")
        if start != self.next_write:
            raise ValueError("时间不连续：应显式处理gap/重复/乱序")
        if len(x) > self.capacity-self.level:
            raise BufferError("容量不足：拒绝整包，未覆盖旧音频")
        position = (self.head+self.level) % self.capacity
        first_part = min(len(x), self.capacity-position)
        self.data[position:position+first_part] = x[:first_part]
        self.data[:len(x)-first_part] = x[first_part:]
        self.level += len(x)
        self.next_write += len(x)
    def take(self, n, partial=False):
        if type(n) is not int or n <= 0:
            raise ValueError("读取长度非法")
        if self.level < n and not partial:
            return None
        count = min(n, self.level)
        indexes = (self.head+np.arange(count)) % self.capacity
        result = (self.first, self.data[indexes].copy())
        self.head = (self.head+count) % self.capacity
        self.level -= count
        self.first += count
        return result
    @property
    def backlog_s(self):
        return self.level/self.sr

ring = SampleRing(8, sr=16000)
ring.put(0, np.arange(6))
a = ring.take(4)
ring.put(6, np.arange(6,12))
b = ring.take(8)
assert a[0] == 0 and np.array_equal(a[1], np.arange(4))
assert b[0] == 4 and np.array_equal(b[1], np.arange(4,12))
assert ring.take(1) is None
try:
    ring.put(12, np.arange(9))
except BufferError:
    assert ring.level == 0 and ring.next_write == 12
    print("溢出整包拒绝，旧状态未变")
try:
    ring.put(13, [1.])
except ValueError:
    print("采样gap已识别")
ring.put(12, [1.,2.])
assert ring.take(8, partial=True)[1].size == 2
print("环绕FIFO/部分EOF读取通过")
```

接收端另需有界jitter buffer：按序号/采样时间重排，超过播放deadline的迟到包应丢弃或补偿，不能无限等缺包。记录插补/丢失区间而不伪造原音频；重连换session ID，旧包不进入新会话。音频采样时钟与网络到达墙钟不同，长会话设备clock drift会使缓冲持续增减，需测时钟偏差与适当异步重采样，而不是只调大队列。

### 1.3 保留滤波历史和重采样相位

重采样需要低通与采样位置更新。逐包独立 `resample_poly` 会为每包重建边界/相位，可能产生接缝和累计长度错；必须使用支持流式状态的resampler或自己定义有状态滤波/相位合同。零相位离线重采样不代表实时零延迟：对称FIR需要右侧样本或承担因果group delay。

下例以48→16kHz的整数3倍降采样实现因果FIR+全局相位，任意碎块拼接结果与整段因果处理一致。滤波器61 tap的群延迟为30/48000=0.000625秒；没有自动移除延迟或恢复Nyquist以上信息。

```python
import numpy as np
from scipy.signal import firwin, lfilter

class Downsample3:
    def __init__(self):
        self.taps = firwin(61, 7200, fs=48000)
        self.state = np.zeros(len(self.taps)-1)
        self.seen = 0
    def feed(self, x):
        x = np.asarray(x, dtype=float)
        if x.ndim != 1 or not np.isfinite(x).all():
            raise ValueError("有限单声道输入")
        if not len(x):
            return np.zeros(0)
        filtered, self.state = lfilter(self.taps, [1.], x, zi=self.state)
        global_positions = self.seen+np.arange(len(x))
        self.seen += len(x)
        return filtered[global_positions % 3 == 0]

n = 1001
t = np.arange(n)/48000
x = .2*np.sin(2*np.pi*1000*t)+.05*np.sin(2*np.pi*12000*t)
processor = Downsample3()
parts, start = [], 0
for stop in [13, 57, 102, 381, 749, n]:
    parts.append(processor.feed(x[start:stop]));start=stop
stream = np.concatenate(parts)
whole = lfilter(processor.taps, [1.], x)[::3]
assert np.allclose(stream, whole, atol=1e-12)
assert len(stream) == (n+2)//3
print("整段/碎块一致",len(stream),"输出采样；群延迟秒",(len(processor.taps)-1)/2/48000)
# 输出第m项的滤波支持中心相对源时间： (3*m-30)/48000。
# 开头负中心时间属于滤波startup；EOF若另flush尾部，必须标成滤波补零，不增长原音频时长。
```

幅度增益g dB对应乘数 $10^{g/20}$，如-3dB约0.7079；原Rust的9 tap对称FIR保存前8样本跨帧，群延迟4/16000=0.25ms。这些DSP操作不推出ASR/LLM/TTS的耗时。

一般比率p/q需要持续维护多相滤波器和分数相位，不能把本例换一个数组步长当任意重采样。anti-alias/STFT/mel推导由[频域先修](../数学与数值计算专题/09-复数傅里叶与频域理解.md)与[音频概览](02-语音与音频.md)维护，本章重点是跨块状态、长度与物理时间。

### 1.4 乱序包、播放deadline与迟到包的小实现

jitter buffer不能等所有包才播放：按采样时钟安排每帧deadline，期限到达时有对应包就输出，没有就给明确gap/PLC策略。下面用确定性的 `pull_at_deadline` 调用表示时钟tick，演示有界乱序队列；不模拟网络或实现完整RTP、时钟同步/序号回绕和真实PLC。补零只标为concealed替代，不当原始录音。

```python
import numpy as np
class JitterFixture:
    def __init__(self,frame_n=10,capacity=3):
        self.frame_n=frame_n;self.capacity=capacity;self.expected=0;self.pending={};self.late=0
    def push(self,sequence,audio):
        if type(sequence) is not int or sequence<0:
            raise ValueError("序号应非负整数")
        x=np.asarray(audio,dtype=float)
        if x.shape!=(self.frame_n,) or not np.isfinite(x).all():
            raise ValueError("本fixture要求固定帧长度与有限波形")
        if sequence<self.expected:
            self.late+=1;return False
        if sequence in self.pending:
            raise ValueError("重复包")
        if len(self.pending)>=self.capacity:
            raise BufferError("jitter队列已满，不无限等待未来")
        self.pending[sequence]=x.copy();return True
    def pull_at_deadline(self):
        sequence=self.expected;self.expected+=1
        audio=self.pending.pop(sequence,None)
        concealed=audio is None
        if concealed:audio=np.zeros(self.frame_n)
        return {"sequence":sequence,"start_sample":sequence*self.frame_n,
                "audio":audio,"concealed":concealed}

buffer=JitterFixture()
buffer.push(1,np.ones(10)*.2);buffer.push(0,np.ones(10)*.1)
a,b=buffer.pull_at_deadline(),buffer.pull_at_deadline()
assert a["sequence"]==0 and b["sequence"]==1 and not a["concealed"] and not b["concealed"]
gap=buffer.pull_at_deadline()
assert gap["sequence"]==2 and gap["concealed"]
assert not buffer.push(2,np.ones(10)*.3) and buffer.late==1
for i in [4,5,6]:buffer.push(i,np.zeros(10))
try:buffer.push(7,np.zeros(10))
except BufferError:print("有界jitter队列溢出已拒绝")
print("乱序还原",a["sequence"],b["sequence"],"gap标记",gap["start_sample"],"迟到包",buffer.late)
```

deadline由接收端时钟映射与playout delay决定；提高delay改善迟到容忍度却增用户等待。该固定帧fixture产生的gap可交给识别器丢失事件/状态重置，不能让它看补零后就声称原文只有静音。long stream需限制最大序号跃迁并处理RTP wrap、设备clock drift、adaptive playout和session重连；这不由一个字典自动完成。

## 2. 三种识别建模及流式条件

### 2.1 CTC：边缘化单调路径

encoder在每个有效步输出包含blank的概率。$P(y\mid x)=\sum_{\pi:B(\pi)=y}\prod_tP(\pi_t\mid x)$，其中collapse先合并连续重复，再删除blank。`a a blank a b b`得到aab；先删blank再合并会错成ab。重复目标a a至少需要3个时间步，长度上界一般还要加相邻重复次数，不只是U≤T。

Greedy选择最佳路径再collapse，不一定得到总概率最大的字符串；prefix beam需分别累计同前缀的blank/非blank结尾概率。完整动态规划/解码及小穷举见[CTC与prefix beam](08-OCR视觉语言与可靠管道.md#2-ctc求和所有合法对齐而非强配每字符位置)，此处复用这一数学机制，不另维护错误版本。源课的普通beam骨架丢掉blank分隔重复与同前缀概率合并，不能当正确prefix beam。

CTC发射在给定encoder表示下条件独立，不代表encoder不包含上下文或绝不学语言统计。“CTC天然零lookahead”是误导：双向encoder/全局attention仍看未来；只有因果或有限右上下文encoder加合适缓存才有明确流式延迟。外部LM融合用CTC得分+权重×LM log概率及可选长度项，会改变搜索目标，权重在验证集选择。

### 2.2 RNN-T：时间与输出历史的二维格

RNN-T由audio encoder、token-history prediction network与joiner组成。状态(t,u)表示已推进t个声学步、已输出u个目标token；joiner组合encoder表示h_t与预测器表示g_u，经softmax产生blank和下一个token概率。blank把格点推进到(t+1,u)，非blank输出y_u并前进到(t,u+1)，所以同一声学步可输出多个符号。不同于CTC，连续重复文字不需要靠blank分隔的collapse规则。

训练对所有合法时间/输出路径求和，动态规划复杂度与T×U有关，若materialize所有vocab logits还受V影响；不能把它简称成“CTC加LM”而忽略不同格点转移。prediction network的token历史建模类似内部语言模型，但不是可无条件当独立LM使用的概率接口。流式仍取决encoder因果性/右上下文与实现状态，joiner/predictor自己不会使双向encoder变因果。

### 2.3 一个可反向传播的RNN-T格点程序

下面统一三类概率表，每个(t,u)都给blank/a/其他字符概率；目标aa不靠CTC collapse。递推对blank前进时间与正确token前进输出分别累积，用logaddexp保持数值稳定。最后一步必须消费最后的blank，本例不允许声学时间T耗尽后继续发射；其他实现须明确其边界协议。

```python
import math
import torch

torch.set_num_threads(1)
T, U, V, BLANK = 2, 2, 3, 0
target = [1,1]
logits = torch.zeros(T, U+1, V, requires_grad=True)
logp = logits.log_softmax(-1)

def rnnt_logprob(logp, target, blank=0):
    tmax, umax, vocab = logp.shape
    if tmax <= 0 or umax != len(target)+1 or not 0 <= blank < vocab:
        raise ValueError("RNN-T格形状/blank非法")
    if any(type(y) is not int or y == blank or not 0 <= y < vocab for y in target):
        raise ValueError("目标不能含blank/越界")
    if not torch.isfinite(logp).all() or not torch.allclose(logp.logsumexp(-1), torch.zeros_like(logp[...,0]), atol=1e-5):
        raise ValueError("要求每个格点规范有限log概率")
    alpha = [[logp.new_tensor(-torch.inf) for _ in range(umax)] for _ in range(tmax+1)]
    alpha[0][0] = logp.new_tensor(0.)
    for t in range(tmax+1):
        for u in range(umax):
            if t < tmax:
                alpha[t+1][u] = torch.logaddexp(alpha[t+1][u], alpha[t][u]+logp[t,u,blank])
                if u < len(target):
                    alpha[t][u+1] = torch.logaddexp(alpha[t][u+1], alpha[t][u]+logp[t,u,target[u]])
    return alpha[tmax][-1]

def enumerate_paths(t=0,u=0,score=0.):
    if t == T:
        return [score] if u == U else []
    paths = enumerate_paths(t+1,u,score+float(logp[t,u,BLANK].detach()))
    if u < U:
        paths += enumerate_paths(t,u+1,score+float(logp[t,u,target[u]].detach()))
    return paths

lp = rnnt_logprob(logp,target)
paths = enumerate_paths()
assert len(paths) == 3
assert abs(math.exp(lp.item())-sum(math.exp(p) for p in paths)) < 1e-7
assert abs(math.exp(lp.item())-1/27) < 1e-7
loss = -lp
loss.backward()
assert torch.isfinite(logits.grad).all()
print("aa三条RNN-T路径，概率",round(math.exp(lp.item()),6),"loss",round(loss.item(),6),"梯度有限")
```

预期概率1/27、NLL约3.295837，目标两个a可以在同一声学步连续发射。这个程序实现损失核心、不是训练好的ASR；真实T/U大时需经过验证的内核、合理batch与显存预算，不把全格logits当低成本缓存。推理还要限制每个frame最大符号数、防无限非blank循环、EOS/结束规则及保存predictor状态。

### 2.4 Attention encoder–decoder、Conformer与训练目标

条件自回归解码器在每个目标步读取encoder表示，teacher forcing与EOS/目标移位原则接[Seq2Seq](../深度学习专题/03-序列模型与机器翻译.md#5-seq2seq从训练错位到结束状态)。离线全局attention可读取全部输入；流式设计需限制可见块/右上下文、维护cache并处理partial revision。无法由架构名称给出谁一定WER最低。源cross-attention图把四个预设token按索引移到十二个画框上，既没有Q/K概率归一化也没执行识别，不能把该对角高亮当测得词时间。

Conformer把前后两个半权重FFN、self-attention、卷积模块与残差/归一化组合：FFN→MHSA→局部卷积→FFN。卷积捕捉局部声学模式，attention连接长程；卷积的padding、BatchNorm统计与attention mask会影响因果性。Conformer是encoder结构，可以配CTC或RNN-T等不同loss，不能把它当与CTC并列的互斥识别损失。

### 2.5 自含的小型因果Conformer + CTC训练图

下面用8通道合成特征、两层**左padding**步幅2卷积和一层小Conformer验证：不同输入长度得到正确有效T、前缀不读取未来、CTC能有限反向。它不是Whisper，也未学习声学；真实Conformer的相对位置、复杂卷积/缓存和训练配方不能因这个小例省略。

```python
import torch
from torch import nn
from torch.nn import functional as F
from torch.nn.utils.rnn import pad_sequence

torch.set_num_threads(1)
torch.manual_seed(23)
D=8
class FeedForward(nn.Module):
    def __init__(self):
        super().__init__()
        self.net=nn.Sequential(nn.LayerNorm(D),nn.Linear(D,2*D),nn.SiLU(),nn.Linear(2*D,D))
    def forward(self,x):
        return self.net(x)

class CausalConformer(nn.Module):
    def __init__(self):
        super().__init__()
        self.ff1,self.ff2=FeedForward(),FeedForward()
        self.anorm=nn.LayerNorm(D)
        self.attn=nn.MultiheadAttention(D,2,dropout=0.,batch_first=True)
        self.cnorm=nn.LayerNorm(D)
        self.point1=nn.Conv1d(D,2*D,1)
        self.depth=nn.Conv1d(D,D,5,groups=D)
        self.local_norm=nn.LayerNorm(D)  # 每位置归一化；不跨未来时间统计BatchNorm
        self.point2=nn.Conv1d(D,D,1)
        self.final=nn.LayerNorm(D)
    def forward(self,x,lengths):
        valid=torch.arange(x.shape[1])[None,:]<lengths[:,None]
        if not valid.any(-1).all():
            raise ValueError("每项需非空有效key")
        keep=lambda y:y.masked_fill(~valid[...,None],0.)
        x=keep(x+.5*self.ff1(x))
        q=self.anorm(x)
        causal=torch.ones(x.shape[1],x.shape[1],dtype=torch.bool).triu(1)
        a,_=self.attn(q,q,q,attn_mask=causal,key_padding_mask=~valid,need_weights=False)
        x=keep(x+a)
        c=F.glu(self.point1(self.cnorm(x).transpose(1,2)),dim=1)
        c=self.depth(F.pad(c,(4,0))).transpose(1,2)
        c=F.silu(self.local_norm(c)).transpose(1,2)
        x=keep(x+self.point2(c).transpose(1,2))
        x=keep(x+.5*self.ff2(x))
        return keep(self.final(x))

class SpeechCTC(nn.Module):
    def __init__(self):
        super().__init__()
        self.c1=nn.Conv1d(8,D,3,stride=2)
        self.c2=nn.Conv1d(D,D,3,stride=2)
        self.encoder=CausalConformer()
        self.head=nn.Linear(D,4)
    def forward(self,features,raw_lengths):
        seqs=[]
        for b,n in enumerate(raw_lengths.tolist()):
            if not 0<n<=features.shape[-1]:
                raise ValueError("有效特征长度非法")
            z=features[b:b+1,:,:n]
            z=F.gelu(self.c1(F.pad(z,(2,0))))
            z=F.gelu(self.c2(F.pad(z,(2,0))))
            seqs.append(z[0].transpose(0,1))
        lengths=torch.tensor([len(z) for z in seqs],dtype=torch.long)
        padded=pad_sequence(seqs,batch_first=True)
        state=self.encoder(padded,lengths)
        return self.head(state).log_softmax(-1).transpose(0,1),lengths

features=torch.randn(2,8,13)
lengths=torch.tensor([9,13])
model=SpeechCTC()
logp,enc_lengths=model(features,lengths)
assert enc_lengths.tolist()==[3,4] and logp.shape==(4,2,4)
targets=torch.tensor([1,1,2]);target_lengths=torch.tensor([2,1])
loss=F.ctc_loss(logp,targets,enc_lengths,target_lengths,blank=0,zero_infinity=False)
loss.backward()
assert torch.isfinite(loss) and all(p.grad is None or torch.isfinite(p.grad).all() for p in model.parameters())
model.eval()
with torch.no_grad():
    prefix,_=model(features[1:2,:,:9],torch.tensor([9]))
    full,_=model(features[1:2],torch.tensor([13]))
    assert torch.allclose(prefix,full[:3],atol=1e-5)
print("encoder有效T",enc_lengths.tolist(),"CTC shape",tuple(logp.shape),"有限反向/前缀因果检查通过")
```

两次ceil/2使9→5→3、13→7→4；同一源前9步在后续音频到达前已能得到3个输出，与整段前三个相同。此程序每次重算有效前缀，没有实现生产cache；流式实现需保存卷积历史、attention KV和位置offset，只对新片段计算，明确右上下文、最大cache及截断策略。追加未到达未来特征应不改变已承诺的输出；若允许partial修订，须单独管理提交规则。

## 3. Whisper：模型输入、任务token与训练合同

Whisper是条件生成encoder–decoder。其经典实现以固定长的log-mel特征经两层卷积（第二层stride2）到encoder，再由causal decoder读取音频表示并生成文本/任务/时间token。约30秒是具体训练与实现的窗口配置，长音频需窗口调度/上下文管理，不是所有ASR或所有API强制30秒，也不是只能处理30秒文件。

必须使用对应checkpoint的feature配置：采样率、FFT/hop、mel滤波器与n_mels、log压缩/截断/归一化、音频padding规则。不同Whisper版本mel数不全相同，2026-10-04读取large-v3与large-v3-turbo官方config均为128-mel、vocab_size=51866；前者encoder/decoder均32层，后者encoder32/decoder4层，不能把所有checkpoint的词表或层数固定为来源51865/同层数。large-v3需检查128-mel配置；不能普遍照搬来源80-mel。原资料“减训练均值除标准差”与官方Whisper流程不一致，正式使用以配套processor/官方audio代码核对，避免自行额外z-score。

多任务token包括SOT、源语言标记、transcribe/translate、是否允许timestamp和EOT。语言token不是“指定任意目标翻译语种”；经典Whisper translate任务主要翻成英语，transcribe对应源语言文字。`notimestamps`控制timestamp-token生成，不保证改变就获得精确word alignment。时间token是窗口内相对时间编码，segment、word、说话人标签是不同输出；attention峰值或图中对角不自动是正确词时间戳。

训练decoder输入为正确前缀，labels错位、EOS合法、PAD通常置ignore index（如-100）。需说明prompt token是否参与loss、是否已含SOT，避免重复BOS；audio feature mask与decoder padding/causal mask作用于不同轴。数据按说话人/来源/会话分组去重拆分，口音、领域术语、静音/背景音乐、短音频与数字分别评估。LoRA目标层/可训参数比例/显存节省取决实际模块与设置；不按少于10小时一律冻结encoder，不承诺固定WER提升或训练小时门槛。

本章后续用可运行长度/CTC/RNN-T/状态机例检查合同；真实Whisper权重加载、语料训练与模型排名没有执行。官方核验与完整程序结果会在本章来源备注记录。

### 3.1 特征规范化、token目标与参数预算的完整小例

2026-10-04读取官方Whisper `audio.py`：16kHz、FFT400、hop160、中心STFT后去掉最后一帧；mel能量取log10，下限1e-10，最大值以下8个log单位截断，再 `(log+4)/4`。这是具体实现合同，不是“训练均值/方差标准化”。经典30秒480000采样→3000特征帧→stride2卷积1500encoder步；源main用无中心 `1+(L-400)//160` 得2998，却又用3000解释同一流程，混用了两种边界。

下面计算STFT步数与log压缩，并构造显式prompt/labels和LoRA参数计数。mel矩阵用简化正权重fixture，**不是官方80/128-mel滤波器**，不产生实际Whisper输入或识别；官方processor权重文件未下载。

```python
import torch
from torch import nn

torch.set_num_threads(1)
sr, nfft, hop = 16000, 400, 160
wave = .1*torch.sin(2*torch.pi*440*torch.arange(3200)/sr)
spectrum = torch.stft(wave,nfft,hop,window=torch.hann_window(nfft),return_complex=True)

for i in range(8):
    lo,hi = i*201//8,(i+1)*201//8
    filters[i,lo:hi] = 1/(hi-lo)
energy = filters @ power

for b,seq in enumerate(sequences):

print("教学特征",tuple(feature.shape),"有效文字/EOT目标",int((labels!=-100).sum()),"loss有限")

# Linear dout×din的LoRA A(r×din),B(dout×r)共r*(din+dout)，只数选中矩阵。
def lora_count(d,rank,encoder_layers,decoder_layers,targets_per_attention=2):
    # encoder一组self-attn；decoder有self+cross两组。只算LoRA，不含bias/head。
    return rank*(d+d)*targets_per_attention*(encoder_layers+2*decoder_layers)
```

预期有效目标5，示意LoRA为3276800参数；真实模型要枚举实际模块/shape/是否冻结，不能把源0.65M、3M或某百分比当同一个配置的保证。LoRA并不消除基座权重、activations、优化器状态与通信。冻结encoder与否用领域差异、数据质量和验证集比较；训练loop应固定随机性、gradient clipping、epoch/checkpoint/早停与WER协议，原资料 `generate_with_loss` 不作为通用Trainer合法参数。

官方README还说明turbo未按翻译任务训练，`translate`标记不能使它自动获得可靠英语翻译能力。`no_speech_threshold`/语言检测/temperature fallback/previous_text是不同控制；VAD漏掉低声或短词也会丢内容。关previous_text可减弱跨窗口错误传播，同时丢掉上下文线索，应该比较而不是全部任务无条件设False。源 `pad=False` 不复制为所有库的通用参数；不同runtime的版本、audio数组/路径、sr与timestamp接口必须独立核对。

## 4. 长音频切片、时间戳与partial稳定性

区分窗口长W、重叠O、实际步进H=W-O。源chunk_schedule名为stride_s却表示overlap；W=30、O=5时从0、25、50开始，不是每5秒开始。参数必须W>0、0≤O<W，空音频明确返回空；否则步进0/负会无限循环。重叠提高边缘上下文，却会重复文字和时间区间，需要明确owner区间或根据稳定前缀/对齐去重。

纯文本拼接不能用集合去重：正常连续“很很慢”或不同地方重复的词可能被删。保留每个片段原采样范围/绝对时间、文段版本与置信度；将local timestamp加回window offset，若VAD压紧音频还须通过分段映射回原时间。词时间是模型估计或forced alignment，不是准确真值；说话人diarization另有输入、标注和指标。

### 4.1 完整窗口合同与删静音后的时间映射

```python
from dataclasses import dataclass

def schedule(total_n,window_n,overlap_n):
    if type(total_n) is not int or total_n<0 or window_n<=0 or not 0<=overlap_n<window_n:
        raise ValueError("总长/窗口/重叠合同非法")
    if not total_n:
        return []
    result=[];start=0
    while start<total_n:
        end=min(total_n,start+window_n)
        result.append((start,end))
        if end==total_n:
            break
        start+=window_n-overlap_n
    return result

@dataclass
class Piece:
    original_start: int
    original_end: int
    compact_start: int

def pack_time_map(intervals):
    pieces=[];cursor=0;previous_end=0
    for start,end in intervals:
        if not previous_end<=start<end:
            raise ValueError("区间必须有序且不重叠")
        pieces.append(Piece(start,end,cursor))
        cursor+=end-start;previous_end=end
    return pieces,cursor

def restore_span(start,end,pieces):
    if not 0<=start<end:
        raise ValueError("compact半开时间跨度非法")
    result=[];covered=0
    for p in pieces:
        compact_end=p.compact_start+p.original_end-p.original_start
        lo,hi=max(start,p.compact_start),min(end,compact_end)
        if lo<hi:
            result.append((p.original_start+lo-p.compact_start,p.original_start+hi-p.compact_start))
            covered+=hi-lo
    if covered!=end-start:
        raise ValueError("span超出有效compact时间")
    return result

windows=schedule(65,30,5)
assert windows==[(0,30),(25,55),(50,65)]
assert schedule(0,30,5)==[]
try:
    schedule(10,30,30)
except ValueError:
    print("零步进窗口已拒绝")
pieces,total=pack_time_map([(100,200),(400,500)])
assert restore_span(80,120,pieces)==[(180,200),(400,420)]
print("窗口",windows,"删静音后跨段还原",restore_span(80,120,pieces))
```

这里用采样索引而非浮点秒，跨删静音边界的文字span映回两个区间，不能伪造为原180～420的连续发声。实时partial可能从“开灯”改成“关灯”；保存revision与final标志。向用户显示临时文本可以标成未稳定，执行动作或朗读回复前需确认稳定/最终输入，避免按被修订的识别结果调用工具。

## 5. VAD、SAD与endpoint：不是同一个决策

VAD/SAD检测语音活动，有些工具按frame概率、有些按segment给区间。它们通常不判断哪位说话人、不判断一句话完整，也不等于wake word/意图识别。音量大不等于语音：键盘、咳嗽、音乐也可高RMS；低声短“好”又可能被能量门或最短时长过滤掉。RMS为 $\sqrt{\sum x_i^2/N}$，归一化浮点音频dBFS为 $20\log_{10}(\mathrm{RMS})$，数字0要定义为负无穷或明确数值floor，不能取log0。

阈值、onset确认时长、结束静音hangover、pre-roll、speech padding各有职责。降低阈值增召回也会误触发；pre-roll补回触发前音频，但不保证检测模型不漏词；长hangover避免中句停顿被截断，也增长endpoint延迟。用高阈值启动、低阈值退出的hysteresis减少边界抖动，参数要在目标语言、噪声、距离、短词和重叠说话上验证，不能把固定500～800ms称为通用最优。

frame尺寸也要服从模型接口。WebRTC VAD常要求特定采样率的10/20/30ms PCM16；2026-10-04核对的Silero ONNX wrapper在16kHz要求512采样、8kHz要求256采样（均32ms），并维护前文/context与循环state；其他版本路径要独立核对，20ms网络块应先重组到模型需要的窗口，不直接照抄 `vad(frame,16000)` 就假定320采样总合法。模型/采样率/会话切换时重置其state，不能在两个用户之间复用声学状态。

语义endpoint利用最近文本/声学语调/上下文估计是否结束，有的具体产品只使用文本，不能泛称全部都有intonation输入。它与静音规则结合，处理“让我想一下……”和被打断的长停顿；识别错误或域外语句也可能误判。不要先用高能量门删除所有低声后再声称后级神经VAD能够救回漏掉的内容。

### 5.1 完整hysteresis、连续onset、pre-roll与EOF状态机

输入概率是手工fixture，不是Silero推理。下面采用采样数计时，允许每块不同长度；候选语音在未确认前遇静音就归零，防止间隔短声累计成START。事件同时给声学区间和检测确认时间；提取音频按半开区间一次切片，不重复append触发块。

```python
from dataclasses import dataclass
import numpy as np

@dataclass
class Event:
    kind:str
    start:int
    speech_end:int
    confirmed:int
    reason:str

class Endpoint:
    def __init__(self,sr,on=.6,off=.3,min_ms=60,hang_ms=80,pre_ms=40):
        if sr<=0 or not 0<=off<on<=1 or min_ms<=0 or hang_ms<0 or pre_ms<0:
            raise ValueError("endpoint参数非法")
        self.sr,self.on,self.off=sr,on,off
        self.minimum=round(sr*min_ms/1000);self.hang=round(sr*hang_ms/1000)
        self.pre=round(sr*pre_ms/1000)
        self.position=0;self.active=False;self.voiced=False
        self.candidate=None;self.run=0;self.quiet=0;self.start=0;self.last_voice_end=0
        self.closed=False
    def feed(self,start,n,prob):
        if self.closed or start!=self.position or type(n) is not int or n<=0 or not np.isfinite(prob) or not 0<=prob<=1:
            raise ValueError("连续采样/正长度/概率合同错误")
        end=start+n;self.position=end
        self.voiced = prob>self.off if self.voiced else prob>=self.on
        events=[]
        if not self.active:
            if self.voiced:
                if self.candidate is None:
                    self.candidate=start
                self.run+=n
                if self.run>=self.minimum:
                    self.active=True;self.start=max(0,self.candidate-self.pre)
                    self.last_voice_end=end;self.quiet=0
                    events.append(Event("START",self.start,end,end,"confirmed_onset"))
            else:
                self.candidate=None;self.run=0
        else:
            if self.voiced:
                self.last_voice_end=end;self.quiet=0
            else:
                self.quiet+=n
                if self.quiet>=self.hang:
                    events.append(Event("END",self.start,self.last_voice_end,end,"silence"))
                    self.active=False;self.candidate=None;self.run=0;self.quiet=0
        return events
    def finish(self):
        if self.closed:
            raise ValueError("EOF重复")
        self.closed=True
        return [Event("END",self.start,self.last_voice_end,self.position,"EOF")] if self.active else []

sr=1000  # 时间合同fixture；不是实际VAD支持的音频采样率
probabilities=[.05]*5+[.9]*6+[.05]*4
endpoint=Endpoint(sr)
events=[]
for i,prob in enumerate(probabilities):
    events+=endpoint.feed(i*20,20,prob)
events+=endpoint.finish()
assert [e.kind for e in events]==["START","END"]
assert (events[0].start,events[0].confirmed)==(60,160)
assert (events[1].speech_end,events[1].confirmed)==(220,300)
```

### 5.2 flush与末端延迟的边界

flush/EOS是协议动作：告诉支持该语义的识别器“当前输入结束，请提交剩余缓存”。某些系统以补规定静音/结束标记实现，某些有明确事件；不能通用调用一个猜出的 `send_flush()`，更不能重复发送已上传audio_buffer。它可能减少等未来采样的时间，但实际消耗仍含endpoint等待、队列、模型计算、传输和结果提交；500ms缓存×四倍实时速度只计算某个部分的理想125ms，不是全链路保证。API/模型streaming状态、final文本与连接复用条件必须先核对。

## 6. 可取消的会话管道与迟到结果

流水线可拆为接收/重组→VAD+turn→ASR partial/final→LLM/工具→文本块→TTS→输出队列/播放时钟。并发可以重叠阶段，但每个阶段还会等待上下游数据，不能仅把最长阶段当端到端延迟。逐token启动TTS会破坏分词/韵律，固定“第20token”也非通用规则；按稳定句片、标点、最小/最大等待和模型接口制定text chunk策略。

会话状态至少区分LISTENING、等待最终识别、RESPONDING与CLOSED。每次用户新发声或显式取消，增加generation epoch；所有ASR/LLM/TTS回调、队列项和播放项都带session/turn/epoch。取消task只是请求：后台推理、已经送出的HTTP或缓冲声音可能继续返回，因此执行/入队/播放三处都要检查epoch，清空未播放输出并停止设备当前输出。清除未播声音与把已生成全文加入历史是不同操作，只保留确实已交付的上下文。

### 6.1 完整异步fixture：中断、取消不合作的producer与旧partial

没有网络/音频设备，played只记录已交付的字符串块；用asyncio事件精确制造迟到回调，不sleep伪造模型速度。旧producer模拟在取消后还发送一块；epoch应拒绝它。最终新回答可完成，旧turn的ASR结果不会触发新回答。

```python
import asyncio
from dataclasses import dataclass

@dataclass
class Transcript:
    turn:int
    epoch:int
    revision:int
    final:bool
    text:str

class Assistant:
    def __init__(self):
        self.epoch=0;self.turn=0;self.state="IDLE"
        self.task=None;self.queue=[];self.played=[];self.dropped=[]
        self.revision=-1;self.finalized=False
    def user_start(self):
        if self.state=="CLOSED":raise RuntimeError("会话已关")
        self.epoch+=1;self.turn+=1
        if self.task and not self.task.done():self.task.cancel()
        self.queue.clear()  # 模拟清空未播放输出；真实设备另需立即stop/clear
        self.state="LISTENING";self.revision=-1;self.finalized=False
        return self.turn
    def transcript(self,event):
        if self.state!="LISTENING" or event.turn!=self.turn or event.epoch!=self.epoch or self.finalized or event.revision<=self.revision:
            self.dropped.append(("ASR",event.turn,event.revision));return False
        self.revision=event.revision
        if event.final:
            self.finalized=True;self.state="READY"
        return True
    def deliver(self,epoch,text):
        if epoch!=self.epoch or self.state=="CLOSED":
            self.dropped.append(("AUDIO",epoch,text));return False
        self.queue.append((epoch,text));return True
    def play_one(self):
        if not self.queue:return False
        epoch,text=self.queue.pop(0)
        if epoch!=self.epoch:return False
        self.played.append((epoch,text))  # 仅记录被消费项，未播剩余不进入已听历史
        return True
    def respond(self,producer):
        if self.state!="READY":raise RuntimeError("须先接受当前turn最终识别")
        epoch=self.epoch;self.state="RESPONDING"
        async def run():
            try:
                await producer(self,epoch)
            finally:
                if epoch==self.epoch and self.state!="CLOSED":self.state="IDLE"
        self.task=asyncio.create_task(run());return self.task
    async def close(self):
        self.epoch+=1;self.state="CLOSED";self.queue.clear()
        if self.task:
            self.task.cancel()
            await asyncio.gather(self.task,return_exceptions=True)

async def demo():
    first_ready=asyncio.Event();allow_old=asyncio.Event()
    assistant=Assistant();t1=assistant.user_start();e1=assistant.epoch
    assert assistant.transcript(Transcript(t1,e1,0,False,"开灯"))
    assert assistant.transcript(Transcript(t1,e1,1,True,"关灯"))
    async def old(a,epoch):
        a.deliver(epoch,"旧回答第一块");a.deliver(epoch,"旧回答未播放块")
        first_ready.set()
        try:
            await allow_old.wait()
        except asyncio.CancelledError:
            pass  # 模拟后台不合作：取消后仍返回一个回调
        a.deliver(epoch,"旧回答迟到块")
    old_task=assistant.respond(old)
    await first_ready.wait()
    assert assistant.play_one()
    t2=assistant.user_start()  # barge-in：旧队列清除，epoch增加
    assert not assistant.transcript(Transcript(t1,e1,2,True,"迟到旧识别"))
    allow_old.set();await old_task
    assert not assistant.queue
    assert assistant.transcript(Transcript(t2,assistant.epoch,0,True,"新请求"))
    async def new(a,epoch):
        a.deliver(epoch,"新回答")
    await assistant.respond(new)
    assert assistant.play_one()
    assert [text for epoch,text in assistant.played]==["旧回答第一块","新回答"]
    assert any(x[0]=="AUDIO" and x[2]=="旧回答迟到块" for x in assistant.dropped)
    print("已交付",assistant.played,"被拒绝",assistant.dropped)
    await assistant.close()
    assert not assistant.deliver(assistant.epoch,"关闭后的音频")
    # 关闭发生在partial后、final前，迟到最终识别不能把CLOSED重开为READY。
    pending=Assistant();pending_turn=pending.user_start();pending_epoch=pending.epoch
    assert pending.transcript(Transcript(pending_turn,pending_epoch,0,False,"未完成识别"))
    await pending.close()
    assert not pending.transcript(Transcript(pending_turn,pending_epoch,1,True,"迟到final"))
    assert not pending.transcript(Transcript(pending_turn,pending.epoch,2,True,"关闭后伪造新epoch"))
    assert pending.state=="CLOSED"
    try:
        pending.respond(new)
    except RuntimeError:
        pass
    else:
        raise AssertionError("关闭后不可发起回复")
    print("取消/迟到回调/partial后关闭再final状态验证通过")

asyncio.run(demo())
```

此例不实现真实audio playback；producer最终会退出，实装close还应有有限deadline并隔离不合作worker。实装要按实际播放采样计数/硬件回调知道已听到多少，并对外部会话截断未播放内容；不能用网络已收到或生成完成代替已播完。2026-10-04核对[OpenAI Realtime会话文档](https://developers.openai.com/api/docs/guides/realtime-conversations)：WebSocket客户端负责停播放并通过 `conversation.item.truncate` 同步实际已播 `audio_end_ms`；WebRTC/SIP的服务端缓冲可按配置自动处理，需核对中断参数。`response.cancel`、输出buffer清除、历史截断是不同层面，本次只读文档，没有调用服务。

### 6.2 工具、错误和回声

工具调用是有类型的请求→校验→执行→把结果/错误送回模型；格式正确不等于授权或意图正确。计时器seconds应为正整数且有范围，拒绝未知字段/工具；call_id用作幂等键，防重试执行两遍。取消生成不能撤回已完成的外部操作，所以非幂等工具必须有单独完成状态和确认/补偿策略，不能靠epoch悄悄当作没发生。工具异常不编造成功，重试依据错误类型和幂等性，不统一规定“失败两次都拒答”。本章不调用天气/日历/真实计时器。

AEC使用播放参考估计扬声器→麦克风回声路径，跟噪声抑制/说话人识别/主动降噪不同。double-talk时用户与助手同时发声，不能把用户音一起抹掉；否则错误VAD或回声触发会自我打断。耳机、离线单向音频与远场通话需求不同，不能把某实现AEC3版本称为所有场景必需。wake word、push-to-talk、明确会话模式各有取舍；始终采音与保留原音频应按真实授权/最小化目的决定，不照搬来源固定30天或地区法律结论。

## 7. Full duplex、Moshi与同步翻译

Barge-in通常是用户发声→中断旧回复，恢复听取；full duplex允许输入与输出音频流持续同时活跃，包括重叠、back-channel和自然插话。上下文条件TTS（例如CSM）用文字和已给历史音频生成讲话，属于speech generation；不因有历史或Mimi codec就自动成为同时听说的对话模型。市场“最有presence”评价或固定TTFA不进入模型任务定义；合成结构与任务评价见[语音合成生成与音频语言模型](14-语音合成生成与音频语言模型.md)。传输全双工、模型支持双流和产品的会话策略是三层，不是两个async协程同时运行就证明模型懂双向对话。流水线也可并发收听和说话，原生S2S也有codec、缓存、网络和播放延迟；不存在任意硬件“零延迟”。

Moshi的关键分解为：Temporal Transformer建模跨帧的用户音频、自身已生成音频与自身文字；先生成当步文字，再用Depth Transformer建模同一帧多个codebook的条件依赖。文字流通常对应自身讲话的语言内容，不是可当事实/推理过程的“内心独白”。用户音频在推理时是外部输入，不是把用户未来讲话预测出来再冒充接收。

Mimi的典型配置为24kHz、12.5帧/秒，所以80ms=1920波形样本；当前配置最大32 codebooks、每层2048值，默认active层数可为8。固定长度理论码率为 $K\log_2(2048)\times12.5$：8层1.1kbps，32层4.4kbps，不含传输头/其他码流。最大配置、实际启用K、网络压缩码率不同；依checkpoint与实际loader读取，不能把“所有Mimi固定8层”当一般定义。源动态图三条正弦/固定单词并未运行codec/模型；source fake_mimi_encode的随机0～1023数也不是实际2048值的神经编码结果。codec原理与训练由[神经音频编码与说话人表征](12-神经音频编码与说话人表征.md)维护，这里关注跨帧和跨codebook因果分解。

### 7.1 完整缩小的双流文字/音频token训练图

使用人工离散token，不运行Mimi、没有音频波形或真实对话；缩小Temporal/Depth Transformer保留核心依赖：自身音频/文字输入右移一帧，当帧depth读取已生成/监督的文字和更早codebooks。用户当前frame可读，未来frame不能读。大小Q=2、codebook vocab=16仅用于教学，与实际模型配置不同。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1)
torch.manual_seed(31)
D,Q,A,TV=8,2,16,7
class TinyDuplex(nn.Module):
    def __init__(self):
        super().__init__()
        self.user=nn.ModuleList(nn.Embedding(A,D) for _ in range(Q))
        self.own=nn.ModuleList(nn.Embedding(A+1,D) for _ in range(Q))
        self.text=nn.Embedding(TV+1,D)
        self.time_pos=nn.Embedding(16,D);self.depth_pos=nn.Embedding(Q,D)
        self.depth_previous=nn.Embedding(A+1,D)
        layer=lambda:nn.TransformerEncoderLayer(D,2,2*D,dropout=0.,batch_first=True)
        self.temporal=nn.TransformerEncoder(layer(),1,enable_nested_tensor=False)
        self.depth=nn.TransformerEncoder(layer(),1,enable_nested_tensor=False)
        self.text_head=nn.Linear(D,TV);self.audio_head=nn.Linear(D,A)
    def forward(self,user,own,text):
        b,t,q=user.shape
        if q!=Q or own.shape!=user.shape or text.shape!=(b,t) or not 0<t<=16:
            raise ValueError("双流/文字形状非法")
        previous_own=F.pad(own[:,:-1],(0,0,1,0),value=A)
        previous_text=F.pad(text[:,:-1],(1,0),value=TV)
        state=self.text(previous_text)+self.time_pos(torch.arange(t))[None,:,:]
        for k in range(Q):
            state=state+self.user[k](user[:,:,k])+self.own[k](previous_own[:,:,k])
        temporal_mask=torch.ones(t,t,dtype=torch.bool).triu(1)
        context=self.temporal(state,mask=temporal_mask)
        text_logits=self.text_head(context)
        # teacher forcing当步文字，推理须换成采样/生成文字，不偷看未来gold。
        depth_state=context[:,:,None,:]+self.text(text)[:,:,None,:]+self.depth_pos(torch.arange(Q))[None,None,:,:]
        prev_code=F.pad(own[:,:,:-1],(1,0),value=A)
        depth_state=depth_state+self.depth_previous(prev_code)
        encoded=self.depth(depth_state.reshape(b*t,Q,D),mask=torch.ones(Q,Q,dtype=torch.bool).triu(1))
        audio_logits=self.audio_head(encoded).reshape(b,t,Q,A)
        return text_logits,audio_logits,context

model=TinyDuplex()
user=torch.randint(A,(1,3,Q));own=torch.randint(A,(1,3,Q));text=torch.randint(TV,(1,3))
text_logits,audio_logits,context=model(user,own,text)
loss=F.cross_entropy(text_logits.reshape(-1,TV),text.reshape(-1))+F.cross_entropy(audio_logits.reshape(-1,A),own.reshape(-1))
loss.backward()
assert torch.isfinite(loss) and all(p.grad is None or torch.isfinite(p.grad).all() for p in model.parameters())
model.eval()
with torch.no_grad():
    original=model(user,own,text)
    changed_user=user.clone();changed_user[:,2]=torch.randint(A,(1,Q))
    changed=model(changed_user,own,text)
    assert torch.allclose(original[2][:,:2],changed[2][:,:2],atol=1e-6)
    # 第t帧自身最后codebook的gold不影响该帧第一个codebook预测。
    changed_own=own.clone();changed_own[:,0,1]=(changed_own[:,0,1]+1)%A
    changed=model(user,changed_own,text)
    assert torch.allclose(original[1][:,0,0],changed[1][:,0,0],atol=1e-6)
print("双流文字/音频logits",tuple(text_logits.shape),tuple(audio_logits.shape),"有限反向/两级因果检查通过")
```

预期文字 `(1,3,7)`、音频 `(1,3,2,16)`，未来用户帧不改变早期状态，当帧较晚codebook不泄漏进较早codebook。真实生成每步采样文字/音频并更新cache，codec encoder/decoder、delay pattern、文本对齐、稀疏文字token与音频frame调度还需具体checkpoint实现；这个训练图没有复现Moshi完整模型、Mimi或其延迟。

### 7.2 Hibiki、Hibiki-Zero与实时协议

流式翻译还面对词序重排：过早输出可能在源语句后半段出现条件/动词前就承诺错误译法；等待更多源上下文又增延迟。策略应同时评价翻译质量、发声自然度、voice transfer与延迟/落后量，不将音频frame rate12.5Hz当端到端响应时长。Hibiki由多流模型同步处理源/目标音频与文字，具体发布checkpoint的方向须按官方README；2026-10-04核对Hibiki仓库为法语→英语，不能写成任意法英双向。

Hibiki-Zero论文[实际入口2602.11072](https://arxiv.org/abs/2602.11072)使用句级对齐语料先学较高延迟翻译，再通过GRPO优化质量/延迟，无需词级对齐不等于无需配对语音或无需监督。论文报告五个X→英语评估任务与新语言适配实验；当前官方仓库声明法/西/葡/德→英语，评估语言和公开权重支持范围不可混用。“小于1000小时可适配”的论文实验不是每种语言所需固定数量。源码原引文2602.12345不作为这篇论文来源。

## 8. 验证：WER、延迟、丢样和用户体验

WER=(替换S+删除D+插入I)/参考词N，可能大于100%（一个参考词却额外插入多个词）；它不是准确率。空参考需单列插入/静音误识别事件，不能随意把任意长幻觉都设成同一个WER1后与正常音频平均。中文CER按明确字符/Unicode规范统计，WER则需词切分；标点/大小写/数字规范化应在协议中声明，规范化/未经规范化可同时报，不能把有业务意义的数字/否定错误洗掉。

### 8.1 完整S/D/I回溯与语料聚合

```python
from collections import Counter

def edits(reference,hypothesis):
    n,m=len(reference),len(hypothesis)
    dp=[[(0,"M") for _ in range(m+1)] for _ in range(n+1)]
    for i in range(1,n+1):dp[i][0]=(i,"D")
    for j in range(1,m+1):dp[0][j]=(j,"I")
    for i in range(1,n+1):
        for j in range(1,m+1):
            equal=reference[i-1]==hypothesis[j-1]
            candidates=[(dp[i-1][j-1][0]+int(not equal),"M" if equal else "S"),
                        (dp[i-1][j][0]+1,"D"),(dp[i][j-1][0]+1,"I")]
            dp[i][j]=min(candidates,key=lambda x:x[0])  # 平局协议：先对角再D再I
    counts=Counter();i,j=n,m
    while i or j:
        op=dp[i][j][1]
        if op in ["M","S"]:i-=1;j-=1
        elif op=="D":i-=1
        else:j-=1
        counts[op]+=1
    return counts

pairs=[(["开","灯"],["关","灯"]),(["打开"],["打开","厨房","灯"]),([],["谢谢观看"])]
total=Counter();words=0;silence_insertions=0
for ref,hyp in pairs:
    count=edits(ref,hyp)
    total.update(count);words+=len(ref)  # 空参考插入也进入语料错误总数
    if not ref:
        silence_insertions+=count["I"]  # 同时单列静音误识别，分母不新增虚构词
assert edits(["a"],["a","b","c"])["I"]==2
assert sum(edits(["a","b"],["a","c"])[k] for k in ["S","D","I"])==1
wer=sum(total[k] for k in ["S","D","I"])/words if words else None
assert abs(wer-4/3)<1e-12
print("语料S/D/I",[total[k] for k in ["S","D","I"]],"参考词",words,"WER",wer,"空参考插入",silence_insertions)
print("额外插入可使WER>1",2/1)
```

示例包含空参考的一次插入，全语料四个错误/三个参考词，WER=4/3；同时报告silence_insertions=1。若只评非空参考子集，则三错误/三词=1，应明确子集名称，不能与全量Corpus WER混称。整个语料N=0时WER未定义，单列插入/静音事件而不伪造分母；非空句的逐句WER0.5和2的均值1.25也不是语料WER。替换/删除/插入分类在多个最短对齐平局时可能不同，但总edit distance相同，需固定回溯协议。完整音频安全/评价协议由[音频安全与评价方法](15-音频安全与评价方法.md)统一维护，本节保留ASR的S/D/I实现与流式延迟边界。业务另检查数字单位、术语、人名、语码切换、说话人、静音/背景音乐与低声短词，并按来源/说话人/噪声分层，不能由LibriSpeech read speech的公开分数宣布目标场景“人类水平”。

端到端延迟先定义起止：物理最后用户发声→首次**实际播放**回复；另报endpoint等待、最后音频到达→final transcript、LLM首token、TTS首可播放块、网络与设备排队、interrupt onset→停输出。TTFA网络字节不等于用户已听到。源voice-latency动态图的750ms/800ms线是硬编码时序，不是计时benchmark，也不能证明从尚未稳定的partial发起回复一定安全。各阶段p95不能直接相加成总p95，需要同turn的完整时间轨迹；重叠依赖用critical path分析并在实际目标硬件/负载/并发下记录端到端分位。

RTF=处理墙钟/音频时长，RTF<1说明这一测试处理快于实时，但不能证明deadline从不超、长会话队列不增长或模型质量好。CPU合成FIR微基准只测DSP成本，不能证明VAD/ASR/LLM/TTS都塞得进20ms；sleep模拟只测设定等待，不包含真实采样/endpoint/模型/网络。需要同时报队列年龄、buffer高水位/丢包/underflow、deadline miss、错误取消/误打断、语音漏检、工具错误与冷启动。

## 9. 练习、自查与完成判据

1. CTC路径a a blank a是什么？**答**：aa，先合并再删blank；prefix beam要保blank/nonblank两种末态与同前缀概率合并，不能复用源错误骨架。
2. CTC或RNN-T是否天然零lookahead？**答**：不是，流式由encoder、窗口与缓存决定，predictor不能把全局attention自动变因果。
3. 同一段48kHzPCM只标16kHz为何不合法？**答**：时长/频率被改变，须真实重采样并管理滤波历史/相位/延迟。
4. 环缓冲容量32000就固定延迟2秒吗？**答**：容量是上限，实际积压才决定音频队列时长；覆盖旧数据必须记gap。
5. Whisper large-v3与早期checkpoint可否固定用80mel？**答**：不可，检查checkpoint n_mels/processor。translate语言token也不提供任意目标语言，turbo尤其不能视为可靠翻译模型。
6. 怎么防止触发块被存两次？**答**：按首采样/半开区间提取或一次从pre-roll搬移后不再append同块，验证样本序号严格连续不重复。
7. START最低语音时长能否跨多次静音累积？**答**：本例明确要求连续onset，未确认遇静音清零；可采用别的平滑策略但需写出协议。
8. cancel task能否防全部旧声音？**答**：不保证，后台/网络/队列可迟到；session/turn/epoch在收结果、入队、播放三处检查，实际设备停输出、历史同步截断。
9. full duplex是否等于barge-in？**答**：前者能持续重叠收发，后者是中断策略；传输/模型/会话策略分开。
10. 多层codebook固定8×11×12.5是多少？**答**：1100bit/s，不是4.4kbps，后者对应32层同配置，不含传输头。
11. 为什么ASR“WER低于5%必人类水平”不成立？**答**：数据/语言/切分/规范/人类条件不同；业务数字/否定错误可能关键。
12. 接到flush即可承诺125ms全链路吗？**答**：不可以，等待结束、队列、模型和协议响应都还存在，补零/EOS不生出尚未到达信息。
