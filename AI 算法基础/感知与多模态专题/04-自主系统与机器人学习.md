# 04｜自主系统与机器人学习

## 1. 自主系统的闭环

```text
感知
→ 状态估计
→ 预测
→ 规划
→ 控制
→ 环境反馈
```

只做视觉识别不是自主系统；系统必须把感知结果转化为动作并承受真实后果。

## 2. Sensors

常见传感器：

- camera；
- LiDAR；
- radar；
- IMU；
- GPS/GNSS；
- proprioception。

没有单一传感器在所有条件下都可靠，因此需要 sensor fusion。

## 3. Perception 与 3D

自主系统常把多视角信息统一到 3D 或 BEV 表示。

关键任务：

- 3D detection；
- depth；
- tracking；
- occupancy；
- free-space。

BEVFusion 等方法的长期意义是“跨传感器统一到可规划空间”，不是记某个模型名字。

## 4. Kinematics 与 Dynamics

- kinematics：动作和位置/姿态之间的几何关系；
- dynamics：加入质量、力、惯性与时间。

机器人控制必须理解状态、动作、约束与物理动态。

## 5. Classical Control

基础控制：

- PID；
- state feedback；
- MPC；
- impedance control。

MPC 的重要思想：

> 在有限未来窗口内预测并优化动作，同时显式考虑约束。

## 6. Robot Learning

学习方法包括：

- imitation learning；
- reinforcement learning；
- behavior cloning；
- offline RL；
- model-based / world-model methods。

难点：

- real-world data expensive；
- safety；
- sim-to-real gap；
- exploration cost。

## 7. Sim-to-Real

常见方法：

- domain randomization；
- system identification；
- robust policy；
- real-world fine-tuning。

模拟器必须覆盖真实世界关键变化，否则高模拟分数不等于能落地。

## 8. Vision-Language-Action

VLA 将视觉、语言指令和动作统一建模。

RT-2、Octo、OpenVLA、π0 等可作为理解“视觉语言表征如何落到 action token / continuous action”的例子。

长期概念：

- action representation；
- embodiment；
- multimodal pretraining；
- policy fine-tuning；
- closed-loop evaluation。

## 9. 自动驾驶

典型栈：

```text
perception
→ localization
→ prediction
→ planning
→ control
```

另一条路线尝试 end-to-end 直接从多传感器输入预测轨迹/动作。

无论路线如何，安全评估都必须覆盖 long-tail 和闭环行为。

## 10. Extreme Robotics

太空、深海和灾害环境增加：

- communication delay；
- limited energy；
- harsh sensing；
- sparse supervision；
- recovery difficulty。

这迫使系统拥有更高自主性和容错能力。

## 11. Swarm 与 HRI

多机器人系统还涉及：

- coordination；
- decentralized control；
- communication constraints。

Human-Robot Interaction 则要处理人的意图、可解释性和安全边界。
