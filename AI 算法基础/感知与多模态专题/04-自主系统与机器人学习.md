# 04｜自主系统与机器人学习

> 进阶选修。先修：坐标系、速度/加速度、基本反馈；强化学习背景有帮助，但不替代控制与动力学。第一遍只在纸上或模拟环境理解闭环。

## 1. 自主系统的闭环

```text
感知
→ 状态估计
→ 预测
→ 规划
→ 控制
→ 环境反馈
```

只做视觉识别不是自主系统；系统必须把感知结果转化为动作并承受真实后果。

## 2. Sensors

常见传感器：

- camera；
- LiDAR；
- radar；
- IMU；
- GPS/GNSS；
- proprioception。

没有单一传感器在所有条件下都可靠，因此需要 sensor fusion。

## 3. Perception 与 3D

自主系统常把多视角信息统一到 3D 或 BEV 表示。

关键任务：

- 3D detection；
- depth；
- tracking；
- occupancy；
- free-space。

BEVFusion 等方法的长期意义是“跨传感器统一到可规划空间”，不是记某个模型名字。

## 4. Kinematics 与 Dynamics

- kinematics（运动学）：描述位置、姿态、速度与加速度的关系，不引入导致运动的力；
- dynamics（动力学）：研究质量、力、力矩、惯性与运动变化之间的关系。

机器人控制必须理解状态、动作、约束与物理动态。

## 5. Classical Control

基础控制：

- PID；
- state feedback；
- MPC；
- impedance control。

MPC 的重要思想：

> 在有限未来窗口内预测并优化动作，同时显式考虑约束。

## 6. Robot Learning

学习方法包括：

- imitation learning；
- reinforcement learning；
- behavior cloning；
- offline RL；
- model-based / world-model methods。

难点：

- real-world data expensive；
- safety；
- sim-to-real gap；
- exploration cost。

## 7. Sim-to-Real

常见方法：

- domain randomization；
- system identification；
- robust policy；
- real-world fine-tuning。

模拟器必须覆盖真实世界关键变化，否则高模拟分数不等于能落地。具体目标、标定、随机化、适配和合成反例由[第12节](#12-从仿真分布到真实系统随机化标定与适配)维护。

## 8. Vision-Language-Action

VLA 将视觉、语言指令和动作统一建模。

RT-2、Octo、OpenVLA、π0 等可作为不同历史方法的阅读例子，观察视觉/语言条件如何映射到离散或连续动作；该名单不表示当前最佳模型，也不能保证跨机器人本体直接复用。

长期概念：

- action representation；
- embodiment；
- multimodal pretraining；
- policy fine-tuning；
- closed-loop evaluation。

## 9. 自动驾驶

典型栈：

```text
perception
→ localization
→ prediction
→ planning
→ control
```

另一条路线尝试 end-to-end 直接从多传感器输入预测轨迹/动作。

无论路线如何，安全评估都必须覆盖 long-tail 和闭环行为。

## 10. Extreme Robotics

太空、深海和灾害环境增加：

- communication delay；
- limited energy；
- harsh sensing；
- sparse supervision；
- recovery difficulty。

这迫使系统拥有更高自主性和容错能力。

## 11. Swarm 与 HRI

多机器人系统还涉及：

- coordination；
- decentralized control；
- communication constraints。

Human-Robot Interaction 则要处理人的意图、可解释性和安全边界。

## 一个离散位置控制例子

简化模型为 $x_{t+1}=x_t+\Delta t\,u_t$，其中位置单位 m，控制量 $u_t$ 是速度 m/s。目标 1 m，当前 0 m，$\Delta t=0.1$ s，比例系数 $K=2\ \mathrm{s}^{-1}$，令 $u_t=K(1-x_t)$，第一步得到 $u_0=2$ m/s，位置 0.2 m。

若速度上限为 0.5 m/s，先饱和裁剪速度，第一步仅到 0.05 m。此例假定速度指令立刻实现；真实机器人还要考虑执行器动态、延迟、噪声、摩擦与碰撞。

自查：把位置误差的单位从 m 换成 cm，却保持系数和输出单位不变，会怎样？**答案：**数值尺度错 100 倍，可能产生过大动作。单位、坐标系、时间戳和执行约束是闭环正确性的组成部分，策略模型分数无法代替它们。


## 12. 从仿真分布到真实系统：随机化、标定与适配

### 12.1 先列出gap及其单位，不能把失败都称背住sim

真实迁移失败可来自参数误差、接触/柔性等未建模机制、感知漂移、控制频率/时延、动作单位/坐标错误、训练探索不足或部署代码问题，不一定是策略“记忆仿真器”。第4/5节的动力学与反馈是诊断基础；照片逼真也不能修复电机延迟。

| 项目 | 要核对的合同 | 怎样构造可解释的留出条件 |
|---|---|---|
| 动力学 | 质量kg、惯量、摩擦/接触、载荷及范围 | 变参数组合/接触条件，而非只换seed |
| 执行 | 力N/力矩N·m/速度m/s/位置rad、饱和、死区、采样周期s | 延迟、限幅、指令丢失和不同频率 |
| 感知 | 外参、时间戳、畸变、曝光、噪声、坐标 | 相机/通道变动与遮挡；按校准协议更新 |
| 环境/任务 | 初态、目标、地形、碰撞及终止 | 未见初态、目标和联合变化 |
| 模型/软件 | obs归一化、动作scale、历史长度、reset和模型版本 | 检查训练/执行同一输入输出，不把接口错当RL差 |

System identification先用有信息量的测量估参数，不等于“观察一次机器人就知道摩擦”；参数可不唯一，需激励、可观测性/可辨识性、残差和独立轨迹。DR对未能精确确定的参数分布做训练；标定与DR可组合。域适配可以是观测/表示、动力学或策略微调，其训练目标和分布不同，不能保证少量真实数据总够。[动力学随机化](https://arxiv.org/abs/1710.06537)

### 12.2 Domain randomization优化的是一个分布上的表现

参数θ每episode或某些时刻按明确分布p_train抽样，策略最大化 `Eθ Etrajectory[return]`。质量/摩擦可在一次episode固定，传感器噪声可每帧改变；若参数隐藏但影响转移，单帧观测未必Markov，历史/在线估计可以帮助。策略只有在输入θ或从历史推断时才“知道今天是哪种sim”；源把所有DR都说成学到条件参数分布并不成立。

范围、概率质量、参数相关性、物理可实现性和测试任务共同影响结果。真实参数落入训练范围也不保证策略学好每个点；平均回报不保证worst-case或安全。过宽随机化可能损害名义表现，也可能有必要，不能固定以“超过3倍实测波动”禁用；随机错轴更可能无效。[视觉域随机化原论文](https://arxiv.org/abs/1703.06907)

### 12.3 完整小型DR训练：平均改善仍可能损害某个支持点

令 `x_next=x+Δt·b·u`，b为无量纲执行增益，u是m/s速度命令，Δt=1s；目标1m、起点0，u=k(1−x)，k单位s⁻¹。训练仅在b=.5/1.5等权两点，不是连续Uniform范围。单步平均误差的最优k=E[b]/(Δt·E[b²])=.8；名义b=1的k=1。此模型没有惯性/接触或真实硬件，仅验证分布目标与留出误差。

```python
import torch
import numpy as np
torch.set_num_threads(1);torch.manual_seed(51)
b=torch.tensor([.5,1.5],dtype=torch.float64);dt=1.
k=torch.nn.Parameter(torch.tensor(0.,dtype=torch.float64))
opt=torch.optim.SGD([k],lr=.1)
for _ in range(160):
    loss=(1-dt*b*k).square().mean();opt.zero_grad();loss.backward();opt.step()
closed=b.mean()/(dt*b.square().mean())
assert torch.allclose(k,closed,atol=1e-10)
k_dr=float(k.detach());k_nominal=1.
cost=lambda gain,gain_k:(1-dt*gain*gain_k)**2
assert np.mean([cost(x,k_dr) for x in (.5,1.5)])<np.mean([cost(x,k_nominal) for x in (.5,1.5)])
assert cost(.5,k_dr)>cost(.5,k_nominal)  # 训练支持点仍可能变差。
assert cost(.2,k_dr)>cost(.2,k_nominal)  # 一个分布外反例。
for gain in (.5,1.,1.5,.2,3.):
    print('b',gain,'nominal/DR单步误差',round(cost(gain,k_nominal),4),round(cost(gain,k_dr),4))
# 多步线性误差的稳定条件是|1-dt*b*k|<1，不能用单步loss代替。
assert abs(1-dt*3*k_dr)>1 and abs(1-dt*3*k_nominal)>1
print('DR参数',round(k_dr,3),'平均改善/支持点损害/OOD/多步失稳边界通过')
```

源GridWorld固定slip与Uniform[0,.3]训练都为3000episode，但实际交互步数并不相同，所以不是完全同样本预算。固定seed、200回合评估得到：slip0两者−8、.1两者−8.78、.2固定−10.05/DR−9.78、.3固定−11.35/DR−11.04、.5固定−16.72/DR−15.78、.7两者−28.73。固定训练并未在任何非零slip“立即灾难”，DR也没有处处更优；评价对象仍是两个网格sim，不是sim→真实机器人。

自动域随机化/课程可逐渐扩大或调整参数分布，但扩展条件要用已固定的任务/成功/失败评估、保留回退与较旧条件；没有普遍“达到90%最优就扩范围”的依据。ADR研究例可从[作者论文](https://arxiv.org/abs/1910.07113)核验，不把几千GPU环境或分钟级真实微调当默认需求。

### 12.4 完整SI、残差动力学与限幅闭环

合成系统为 `v_next=a·v+b·u`、`x_next=x+Δt·v_next`：v为m/s、u为N、a无量纲、b单位(m/s)/N。已知Δt=.1s，需用不同输入激励识别a/b。学习残差动力学是 `f_hat=f_sim+δf`，控制残差策略则是 `u=u_base+δu_policy`；一个修预测模型，一个修动作，不应都叫“residual policy”。[残差控制原论文](https://arxiv.org/abs/1812.03201)

```python
import numpy as np
rng=np.random.default_rng(52);a_true,b_true=.82,.045;dt=.1
v=0.;rows=[];targets=[]
for force in rng.uniform(-4,4,80):
    next_v=a_true*v+b_true*force;rows.append([v,force]);targets.append(next_v);v=next_v
X=np.asarray(rows);y=np.asarray(targets)
if np.linalg.matrix_rank(X)<2:raise ValueError('激励不足，两个参数不可辨识')
a,b=np.linalg.lstsq(X,y,rcond=None)[0]
assert np.allclose([a,b],[a_true,b_true],atol=1e-12)
nominal=np.array([.9,.035]);residual=np.array([a,b])-nominal
check=np.array([[-.4,2.],[0.,-3.],[.6,1.]])
assert np.allclose(check@nominal+check@residual,check@np.array([a_true,b_true]))
# 全零动作无法识别动作增益；不能把某个最小二乘值当已识别参数。
unexcited=np.c_[np.linspace(0,1,10),np.zeros(10)]
assert np.linalg.matrix_rank(unexcited)<2
x=v=0.;forces=[]
for _ in range(40):
    desired_v=1.;u_base=(desired_v-nominal[0]*v)/nominal[1]
    # 校准逆模型相对名义控制的动作修正；不是RL学得的残差策略。
    delta_u=(desired_v-a*v)/b-u_base
    u=float(np.clip(u_base+delta_u,-4,4));forces.append(u)
    v=a_true*v+b_true*u;x+=dt*v
assert np.isfinite([x,v]).all() and np.max(np.abs(forces))<=4
# 同一个可观测初态，却有不同隐藏增益：教师动作不可能都被无记忆student复制。
needed=np.array([.1/.04,.1/.08])
assert needed[0]!=needed[1]
print('合成SI参数',round(a,3),round(b,3),'残差预测/秩不足/4N限幅通过；最终速度',round(v,3),'m/s')
```

该程序无测量噪声，精确恢复是人工可辨识基准；真实测量中的输入噪声、非线性、接触、模型阶次和时间对齐会破坏这种精确性。独立验证包括多步残差、动作/速度范围、时延/未知扰动；校准准确不自动意味着控制稳定或没有碰撞。

### 12.5 特权教师、学生与部署证据

sim teacher可看到地形/真实速度/摩擦，student只能接实际传感器/历史。若两种隐藏参数给同一个可观察历史，却需要不同动作，student不能无损复制teacher；上例v=0、目标下一速度.1，b=.04/.08分别需2.5/1.25N。需要可辨识历史、主动小激励、鲁棒折中或改变教师任务，不能只换一个encoder就保证复制。蒸馏用teacher action/分布或latent监督，说明谁冻结、谁更新、对齐/时序与loss，训练可用特权标签不意味着执行也能偷用。

观测适配把真实图像/特征映射到训练表示，可能改变任务语义；动力学适配重新估model，策略微调直接改行为，均需独立条件比较。安全层的限幅/关节/动作速率、监督停止、备用控制及恢复流程是工程接口；限幅只保证该项约束，不证明全局安全。这里仅在合成程序检查力限幅，没有运行真实部署。

证据按层记录：仿真训练→未见参数/联合扰动sim验证→传感/执行接口核对→对应真实系统的闭环测试。sim-variant通过不能代替真实测试，某个variant失败也不能逻辑证明所有真实任务必失败。记录失败/碰撞/超时和实际交互步数，不能只留成功轨迹或“zero-shot10场景”宣传值。规划/world-model多步误差继续由[强化学习进阶](../深度学习专题/15-强化学习进阶与世界模型.md)维护。
