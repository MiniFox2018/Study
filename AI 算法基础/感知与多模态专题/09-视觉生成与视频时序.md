## 1. 同一个采样循环的六个部件

先区分数据表示、条件编码器、去噪/速度骨干、训练目标、采样器、后处理/解码。传统latent diffusion常是image→autoencoder latent→在latent训练噪声模型，采样后decoder；文本token通过cross-attention或多模态joint attention进入骨干。Text encoder、autoencoder、denoiser可能冻结或微调，具体配置不是整个模型家族的永恒事实。

历史SD1.x的`3×512×512`到`4×64×64`仅说明元素数约48倍减少；**不能推出总FLOPs/显存/耗时都降48倍，也不能说无质量损失**。autoencoder丢细节，latent分布和缩放参数依模型；`0.18215`不是所有VAE通用常数。编码可能采样posterior或取均值，训练/inference必须用一致的scale/shift契约。

图像latent不是保证线性语义的万能manifold：插值、随机latent解码、prompt嵌入操作不同，需要分别验证。主生成章的VAE/ELBO解释了为何重构好与prior采样好仍是两件事。

## 2. 条件生成、编辑与CFG的可操作流程

Text-to-image：tokenize→text embedding→初始化符合日程的噪声→多步模型预测/solver更新→latent解码；记录模型/adapter、precision、seed/RNG、尺寸、日程、prediction_type和步数。固定seed便于同环境对照，不承诺跨设备/版本完全一样。

Img2img：encode输入→按选定t0加噪→从t0反向→decode；strength通常影响起点/有效步数，不等于直接线性混合原图和输出，库的映射可能依scheduler。在高噪起点更多结构可改变，仍可能有图像/结构条件，所以strength1并非所有pipeline都完全无视输入。

Inpainting：把mask、原图/latent与必要编码传入专用模型或重绘流程；若迭代保留非mask区，应按该时刻噪声日程混合已知区域，不总直接塞干净latent。解码可能让非mask附近也变化，要检查边界/最终合成。mask白黑语义、resize与对齐按具体接口确认。

结构条件如边缘、pose、depth常经独立可训练分支产生多尺度残差，冻结大基模型仍可学习控制；ControlNet是一种实现。正确形状还要正确坐标/预处理，不把相对depth假装米深度。没有数学依据把Euler ancestral统一禁用于ControlNet，采样器需和训练参数化、条件强度、实现匹配后验证。

CFG公式 $f=f_u+w(f_c-f_u)$ 在w1是普通条件、w0无条件；原SD演示把w≤1叫unconditional是错误的。库可能只在w>1启用双分支，API参数与公式不能混用。将两分支拼batch节约某些调度开销并不只算一次样本量工作。条件guidance强度过高可损害色彩/覆盖，但没有通用15必失真、7.5必最佳。

```python
import numpy as np
unconditional=np.array([.2,-.1]); conditional=np.array([.5,.3])
def cfg(w): return unconditional+w*(conditional-unconditional)
assert np.array_equal(cfg(0),unconditional)
assert np.allclose(cfg(1),conditional)
assert np.allclose(cfg(2),[.8,.7])
print('CFG的0/1/2',cfg(0),cfg(1),cfg(2))
```

## 3. LoRA微调：小参数不等于自动泛化

对权重$W\in R^{out\times in}$，增加$\Delta W=(\alpha/r)BA$，$A\in R^{r\times in},B\in R^{out\times r}$。新增参数$r(in+out)$，比全矩阵$in\cdot out$少仅当r足够小。零初始化B等设置使初始增量0，训练只更新选定adapter；目标可不只attention，也可能其他线性/卷积映射。

数据准备明确subject/style/concept、caption与变化范围；同时覆盖主体与环境姿态，保留新prompt/新视角验证，防记住背景或训练照片。rank/alpha/lr/步数按容量和验证选择，不能固定subject8～16或小于5张必过拟合。罕见trigger字串也可能被tokenizer拆成常见subtokens，不能保证自动独立新语义。

冻结基模型/编码器时检查需要的梯度路径，构造匹配noise/v/flow目标；优化器每批清零、backward/step、schedule、EMA与恢复状态都明确。加载adapter须匹配架构/权重版本/目标模块；融合是修改基权重的具体操作，是否可撤销由库决定，不靠模型名字推断。许可证、输入数据与权重可得性只留核验入口，不固化未经查证的当前“最安全商用型号”列表。

下面完整CPU矩阵例子固定 $\alpha=r$，因此 $\alpha/r=1$，只验LoRA初始等价、参数量与adapter梯度，不是SD训练。

```python
import torch
from torch import nn

torch.manual_seed(7)
in_dim,out_dim,r=6,4,2
W=torch.randn(out_dim,in_dim)
A=nn.Parameter(torch.randn(r,in_dim)*.02); B=nn.Parameter(torch.zeros(out_dim,r))
x=torch.randn(5,in_dim)
base=x@W.T
adapted=x@(W+B@A).T
assert torch.equal(base,adapted)
(adapted**2).mean().backward()
assert B.grad is not None and B.grad.abs().sum()>0
assert A.numel()+B.numel()==r*(in_dim+out_dim)
print('LoRA参数',A.numel()+B.numel(),'全权重',W.numel(),'首轮B有梯度')
```

## 4. 可运行的微型时间条件U-Net

U-Net的skip保留高分辨率，time embedding告诉模型噪声水平，再在feature channel加入投影；时间可用sin/cos或学习编码，不能把sinusoids当唯一条件方法。该程序训练合成8×8圆形的noise预测，并走完短DDPM循环；有限/形状/更新检查不证明圆形生成质量，更不叫Stable Diffusion复现。

```python
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1); torch.manual_seed(7)
T=24
beta=torch.cat([torch.zeros(1),torch.linspace(.02,.3,T)])
alpha=1-beta; abar=torch.cumprod(alpha,0)
class MicroUNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.time=nn.Sequential(nn.Linear(2,16),nn.SiLU(),nn.Linear(16,8))
        self.enc=nn.Conv2d(1,4,3,padding=1)
        self.down=nn.Conv2d(4,8,4,2,1)
        self.up=nn.ConvTranspose2d(8,4,4,2,1)
        self.out=nn.Conv2d(8,1,3,padding=1)
    def forward(self,x,t):
        u=t.float()/T
        time=self.time(torch.stack([torch.sin(u*torch.pi),torch.cos(u*torch.pi)],-1))[:,:,None,None]
        skip=F.silu(self.enc(x))
        hidden=F.silu(self.down(skip)+time)
        return self.out(torch.cat([F.silu(self.up(hidden)),skip],dim=1))
yy,xx=torch.meshgrid(torch.arange(8),torch.arange(8),indexing='ij')
x0=(((xx-3.5)**2+(yy-3.5)**2)<7).float()[None,None].repeat(8,1,1,1)*2-1
model=MicroUNet(); opt=torch.optim.Adam(model.parameters(),lr=.003)
before=model.out.weight.detach().clone()
for step in range(70):
    t=torch.randint(1,T+1,(8,)); noise=torch.randn_like(x0)
    a=abar[t][:,None,None,None]
    xt=a.sqrt()*x0+(1-a).sqrt()*noise
    loss=F.mse_loss(model(xt,t),noise)
    opt.zero_grad(set_to_none=True); loss.backward(); opt.step()
assert not torch.equal(before,model.out.weight)
model.eval()
with torch.no_grad():
    x=torch.randn(2,1,8,8)
    for t in range(T,0,-1):
        pred=model(x,torch.full((2,),t,dtype=torch.long))
        mean=(x-beta[t]/(1-abar[t]).sqrt()*pred)/alpha[t].sqrt()
        var=beta[t]*(1-abar[t-1])/(1-abar[t])
        x=mean+(var.sqrt()*torch.randn_like(x) if t>1 else 0)
assert x.shape==(2,1,8,8) and torch.isfinite(x).all()
print('MicroUNet训练loss',round(loss.item(),3),'完整短DDPM结果形状',tuple(x.shape))
```

部署大pipeline还需文本/autoencoder、有效训练数据与一致目标，实际用官方库能复用模块但不省掉契约核对。本批没有安装diffusers或下载其模型，旧具体模型ID/默认scheduler/precision效益不写成当前保证。

## 5. DiT、AdaLN与多模态流

把latent$(B,C,H,W)$分为p×p patch，token数$N=(H/p)(W/p)$，嵌入维d；Transformer保持token序列，输出头每token给$p^2C$，unpatchify严格恢复轴。对像素/latent一律不能只reshape而不检查顺序。

AdaLN将条件投影成scale/shift，用$LN(h)\odot(1+s)+b$；residual branch再乘gate。Zero-init的是调制/gate等具体层，使**整个residual block**初始identity，AdaLN归一化本身不是identity。初始gate0时attention/MLP梯度可能暂0、gate收到梯度，是设计行为，不自动叫死网络。DiT是骨干，原DiT可配DDPM；换Transformer不自动把目标换成RF。

MMDiT让text/image有各自投影与权重，再共享joint attention，使两边信息交互；与SD1/2的cross-attention不是“以前concat所有tokens用相同权重”。Double/single stream组合是在一些具体架构中选不同权重共享方式，不能说所有新模型唯一使用它。

以下完整CPU微型DiT用RF目标做5次训练及4步形状采样；**没有蒸馏，也不宣称4步高质量**。输入整除、patch轴恢复、初始化identity与训练更新都有检验。

```python
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1); torch.manual_seed(7)
class Block(nn.Module):
    def __init__(self,d=16):
        super().__init__()
        self.ln=nn.LayerNorm(d,elementwise_affine=False)
        self.mod=nn.Linear(d,3*d)
        nn.init.zeros_(self.mod.weight); nn.init.zeros_(self.mod.bias)
        self.attn=nn.MultiheadAttention(d,2,batch_first=True)
        self.ln2=nn.LayerNorm(d,elementwise_affine=False)
        self.mod2=nn.Linear(d,3*d)
        nn.init.zeros_(self.mod2.weight); nn.init.zeros_(self.mod2.bias)
        self.ff=nn.Sequential(nn.Linear(d,4*d),nn.GELU(),nn.Linear(4*d,d))
    def forward(self,x,c):
        scale,shift,gate=self.mod(c).chunk(3,-1)
        h=self.ln(x)*(1+scale[:,None])+shift[:,None]
        update,_=self.attn(h,h,h,need_weights=False)
        x=x+gate[:,None]*update
        scale2,shift2,gate2=self.mod2(c).chunk(3,-1)
        hidden=self.ln2(x)*(1+scale2[:,None])+shift2[:,None]
        return x+gate2[:,None]*self.ff(hidden)
class TinyDiT(nn.Module):
    def __init__(self):
        super().__init__()
        self.patch=nn.Conv2d(1,16,2,2); self.pos=nn.Parameter(torch.randn(1,16,16)*.01)
        self.time=nn.Sequential(nn.Linear(1,16),nn.SiLU(),nn.Linear(16,16))
        self.block=Block(); self.head=nn.Linear(16,4)
    def forward(self,x,t):
        if x.shape[-2:]!=(8,8): raise ValueError('本例限定8×8且可被p2整除')
        h=self.patch(x).flatten(2).transpose(1,2)+self.pos
        h=self.block(h,self.time(t[:,None]))
        out=self.head(h).reshape(len(x),4,4,2,2,1)
        return out.permute(0,5,1,3,2,4).reshape(len(x),1,8,8)
block=Block(); tokens=torch.randn(2,4,16); c=torch.randn(2,16)
assert torch.equal(block(tokens,c),tokens)
model=TinyDiT(); opt=torch.optim.Adam(model.parameters(),lr=.003)
x0=torch.rand(4,1,8,8)*2-1
for _ in range(5):
    t=torch.rand(4); eps=torch.randn_like(x0); u=t[:,None,None,None]
    loss=F.mse_loss(model((1-u)*x0+u*eps,t),eps-x0)
    opt.zero_grad(set_to_none=True); loss.backward(); opt.step()
with torch.no_grad():
    x=torch.randn(2,1,8,8)
    for i in range(4):
        t=torch.full((2,),1-i/4)
        x-=model(x,t)/4
assert x.shape==(2,1,8,8) and torch.isfinite(x).all()
print('DiT block初始identity、RF训练和4步形状机制通过')
```

少步能力取决于场学习、耦合与蒸馏；不能把普通Euler步数设4就叫Turbo。RF方向/conditional velocity详见生成主章，不再重复第二份推导。

## 6. 视频先决定采样的真实时间

数据常是(B,T,C,H,W)便于逐帧，Conv3d通常(B,C,T,H,W)；采样window的T是帧数，真实跨度还依fps与stride。可变帧率需按PTS时间取样，不能把frame index等同秒。短动作可能被均匀低频采样漏掉；短clip重复尾帧会偏置池化，用有效mask或明确重复策略。

训练按原video/人物/场景划分，不能同video的两个窗口分入train/test。空video和T≤0应拒绝，T等于总数返回每帧；随机采样用新建同seed RNG复现，同一个已经消费的RNG对象调用两次不保证相同。通常空间crop/色彩增强在同clip内一致，避免造假motion；刻意时序增强需另说明标签一致性。

```python
import numpy as np

def sample_indices(n,T,mode='uniform',seed=7):
    if n<=0 or T<=0: raise ValueError('帧数和T必须正')
    if n<T:
        return np.r_[np.arange(n),np.full(T-n,n-1)],np.r_[np.ones(n,bool),np.zeros(T-n,bool)]
    if mode=='uniform': idx=np.floor(np.arange(T)*n/T).astype(int)
    elif mode=='dense':
        start=np.random.default_rng(seed).integers(0,n-T+1); idx=np.arange(start,start+T)
    else: raise ValueError('未知采样')
    return idx,np.ones(T,bool)
for n in [3,8,9,80]:
    idx,mask=sample_indices(n,8)
    assert len(idx)==8 and np.all((idx>=0)&(idx<n))
a,_=sample_indices(30,8,'dense'); b,_=sample_indices(30,8,'dense')
assert np.array_equal(a,b) and np.all(np.diff(a)==1)
print('采样边界、短片mask和随机seed复现通过')
```

## 7. 视频理解：顺序、局部motion与开销

2D+mean/max pool对独立帧特征作对称聚合，所以同一组帧完全逆序时输出相同；不能辨这类纯方向标签。但真实dataset可能有外观捷径，不能说某dataset整个必chance/无法有分数。带位置或时序卷积/attention的pool已不是纯order-invariant baseline。

3D conv核$(k_t,k_h,k_w)$把短时关系与空间结合；MAC约 $T_{out}H_{out}W_{out}C_{out}(C_{in}/groups)k_tk_hk_w$，对照2D逐帧需同分辨率/stride/层数，不能固定T/8或3～5倍。I3D把2D核沿t重复并除$k_t$，对重复同一图像的**内部时间位置**近似保持输出，padding边缘不同；要保持bias/groups/dilation/stride和dtype/device。

(2+1)D先$(1,k,k)$再$(k_t,1,1)$，中间有BN/非线性。若中间宽度m，权重数是$C_{in}mk^2+mC_{out}k_t$；选m可与原3D的$C_{in}C_{out}k_tk^2$约相等，不天然“更少参数”。它不等于任意3D核精确分解；新增非线性使表达不同。重建完整R(2+1)D还要改pool/downsample/residual/head，不是只换一个Conv2d名字。

以下完整CPU程序证明纯pool的逆序不变与inflation内部输出，未下载ImageNet或torchvision权重。

```python
import torch
from torch import nn

torch.set_num_threads(1); torch.manual_seed(7)
frames=torch.randn(2,5,1,6,6)
encoder=nn.Sequential(nn.Conv2d(1,3,3,padding=1),nn.ReLU(),nn.AdaptiveAvgPool2d(1))
def pooled(x):
    B,T=x.shape[:2]
    return encoder(x.reshape(B*T,*x.shape[2:])).reshape(B,T,-1).mean(1)
assert torch.allclose(pooled(frames),pooled(frames.flip(1)),atol=1e-7)
c2=nn.Conv2d(1,2,3,padding=1,bias=True)
c3=nn.Conv3d(1,2,(3,3,3),padding=1,bias=True)
with torch.no_grad():
    c3.weight.copy_(c2.weight[:,:,None].repeat(1,1,3,1,1)/3)
    c3.bias.copy_(c2.bias)
image=torch.randn(1,1,6,6); video=image[:,:,None].repeat(1,1,5,1,1)
assert torch.allclose(c3(video)[:,:,2],c2(image),atol=1e-6)
print('纯pool逆序不变；I3D inflation内部帧等价通过')
```

Video transformer有时间/空间/联合/窗口注意力。空间patch数S、时间token数T：joint pair数$T^2S^2$；divided是$ST^2+TS^2$，**不是遗漏ST倍数的$T^2+S^2$，也不是一般线性复杂度**。Window只看局部、稀疏模式需明确跨窗口通信；没有所有新视频模型唯一用同种attention。

## 8. Video DiT、真实RoPE与形状

视频latent$(B,C,T,H,W)$按$(p_t,p_h,p_w)$分patch，token数$N=(T/p_t)(H/p_h)(W/p_w)$，有不可整除时显式padding/mask或拒绝，不可floor丢尾。预测头每token给$Cp_tp_hp_w$，必须按相同轴顺序unpatchify。

Joint attention是否causal由mask/生成任务决定；diffusion可同时去噪未来整段，不必是自回归next-token。视频模型还需噪声/flow时间和文本/动作条件、训练损失、sampler、latent decoder；一个shape正确的block不能叫真实视频生成器。

原课`rope_3d`是把sin/cos相加到tokens，**不是RoPE**。RoPE在Q/K成对通道施旋转，保持每对范数，并使点积含相对位置；additive encoding没有同样性质。3D可把通道分给时间/高/宽各轴，每段偶数。以下完整double小例子检验范数与相对点积，不训练video。

```python
import torch

def rope3(x,coords,dims=(2,2,2)):
    if sum(dims)!=x.shape[-1] or any(d<=0 or d%2 for d in dims):
        raise ValueError('轴通道必须正偶数且总和匹配')
    parts=[]; start=0
    for axis,d in enumerate(dims):
        z=x[...,start:start+d].reshape(*x.shape[:-1],d//2,2)
        freq=10000.**(-torch.arange(d//2,dtype=x.dtype)/max(1,d//2))
        angle=coords[...,axis,None]*freq
        c,s=angle.cos(),angle.sin()
        parts.append(torch.stack([z[...,0]*c-z[...,1]*s,z[...,0]*s+z[...,1]*c],-1).flatten(-2))
        start+=d
    return torch.cat(parts,-1)
torch.manual_seed(7)
x,y=torch.randn(6,dtype=torch.double),torch.randn(6,dtype=torch.double)
m=torch.tensor([1.,2.,3.],dtype=torch.double); n=torch.tensor([3.,1.,4.],dtype=torch.double)
assert torch.allclose(rope3(x,m).norm(),x.norm(),atol=1e-12)
left=(rope3(x,m)*rope3(y,n)).sum()
right=(x*rope3(y,n-m)).sum()
assert torch.allclose(left,right,atol=1e-12)
print('3D RoPE范数/相对点积通过')
```

比如5秒、30fps、360×480且patch=(2,8,8)：T=75、S=45×60=2700、N=202500；joint约410.06亿pair，divided约5.62亿pair。若显式存单head float32 score，joint约164GB，仅是score载荷，尚未含梯度/层/其他内存；某些高效attention减少存储但算术和token复杂度仍要分析。原quiz混用了150帧与150时间token。

### 8.1 完整3D patch顺序与divided attention小程序

以下CPU结构实验先用可逆raw patch排列核对每个元素，再加可学习投影与时间/空间attention、映射回每patch数值并反向。它没有diffusion时间、文本/动作条件或有效生成训练，所以只称video block形状/梯度验证。

```python
import torch
from torch import nn

torch.set_num_threads(1); torch.manual_seed(7)
def patchify(x,p=(2,2,2)):
    B,C,T,H,W=x.shape; pt,ph,pw=p
    if T%pt or H%ph or W%pw: raise ValueError('本例拒绝不可整除尺寸')
    nt,nh,nw=T//pt,H//ph,W//pw
    tokens=x.reshape(B,C,nt,pt,nh,ph,nw,pw).permute(0,2,4,6,1,3,5,7)
    return tokens.reshape(B,nt*nh*nw,C*pt*ph*pw),(nt,nh,nw)
def unpatchify(tokens,grid,C=1,p=(2,2,2)):
    B,N,_=tokens.shape; nt,nh,nw=grid; pt,ph,pw=p
    if N!=nt*nh*nw or tokens.shape[-1]!=C*pt*ph*pw: raise ValueError('token契约不符')
    x=tokens.reshape(B,nt,nh,nw,C,pt,ph,pw).permute(0,4,1,5,2,6,3,7)
    return x.reshape(B,C,nt*pt,nh*ph,nw*pw)
class DividedBlock(nn.Module):
    def __init__(self,d=8):
        super().__init__(); self.norm=nn.LayerNorm(d)
        self.time=nn.MultiheadAttention(d,2,batch_first=True)
        self.space=nn.MultiheadAttention(d,2,batch_first=True)
    def forward(self,x,grid):
        B,N,D=x.shape; T,H,W=grid; S=H*W
        t=x.reshape(B,T,S,D).permute(0,2,1,3).reshape(B*S,T,D)
        q=self.norm(t); update,_=self.time(q,q,q,need_weights=False)
        x=(t+update).reshape(B,S,T,D).permute(0,2,1,3).reshape(B*T,S,D)
        q=self.norm(x); update,_=self.space(q,q,q,need_weights=False)
        return (x+update).reshape(B,N,D)
x=torch.arange(64.).reshape(1,1,4,4,4)/64
tokens,grid=patchify(x)
assert torch.equal(unpatchify(tokens,grid),x)
proj,block,head=nn.Linear(8,8),DividedBlock(),nn.Linear(8,8)
pred=unpatchify(head(block(proj(tokens),grid)),grid)
loss=(pred-x).square().mean(); loss.backward()
assert pred.shape==x.shape
assert all(p.grad is not None and torch.isfinite(p.grad).all() for m in [proj,block,head] for p in m.parameters())
print('Video patch往返、divided block与梯度通过',grid,tuple(tokens.shape))
```

### 8.2 生成视频的内存口径与时序退化反例

生成器可联合处理视频latent，以文本、首帧、关键帧或音频作条件；是否支持每种条件由训练目标决定。空间/时间因子化降低某些配对数，却不等于完整3D注意力，不能说所有视频模型都采取同一因子化路线。训练时间、文本tokenizer、时空VAE和未知服务内部结构不能从产品名推断。

240帧1920×1080、RGB若为uint8原始像素，是1492992000字节（约1.49GB）；float32则约5.97GB。latent需按实际时间/空间压缩、通道数、dtype和边界计算，不存在仅写“4倍VAE”就得到100MB的通用公式。峰值内存、每步数据流量、总步数与模型权重访问是不同量，不能用一个latent大小直接断言一定带宽瓶颈。

扩散每个去噪时间的latent/隐藏状态会变化，不能照搬LLM“旧token永远不变”的KV契约跨步骤缓存。只有明确不随噪声时间/状态变化的条件分支或经过验证的近似才能复用，并需记录误差。将完整固定clip当“独立帧continuous batching”也不等于视频模型的联合时序计算；分块需约定重叠、上下文、噪声与首尾条件。

```python
import numpy as np

raw=T*H*W*C
assert raw==1492992000 and raw*4==5971968000
# 人工设定4×时间/8×空间、16通道、fp16，仅核对预算，不指代具体VAE。

assert latent==62208000
reference=np.linspace(0,1,6)
```

相邻帧差小只说明某种平滑程度，静止不动也能“最好”；运动幅度、动作完成、身份/结构与条件一致需要共同评价。source toy的joint MLP与independent baseline采样过程不同，没有Transformer、同预算训练或真实帧，不能仅凭较小delta证明Video DiT学到物理。首帧固定应在每步按该模型噪声/条件协议处理，不能把一个clean pixel直接替换所有时间的latent；相关编辑/端点原理见生成主章。

## 9. 从视频预测到动作条件世界模型

分清prompt-conditioned video、动作/latent action条件的环境预测，以及控制用途的latent transition/reward/termination模型。既有[世界模型主章](../深度学习专题/15-强化学习进阶与世界模型.md)维护VAE/MDN-RNN、imagination与RL；[机器人学习](04-自主系统与机器人学习.md)维护闭环/单位/动作约束，这里补视觉时序的接口。

形式可写$p(o_{t+1}\mid o_{\le t},a_t)$，或latent history→next latent+reward+termination。Latent action从观测对中推断变化因素，不自动等同真实电机指令，也可能混入相机/外部物体运动；inverse dynamics学观测转移到动作，可能多解/不可达。目标→VLM计划→预测观测→inverse dynamics是一条研究方案，不是任何系统替代RL/控制的定理。

Teacher forcing用真实历史，部署自由rollout用自身预测，误差会累积；复用过去状态、遮挡后再出现、camera motion、动作不同造成不同结果都需评估。漂亮长video不能证明学到object permanence、重力或反事实因果，不能替代可信仿真/真实闭环验证。

下面完整动作条件线性系统实验，学习$s'=0.95s+0.1a$并比较两动作rollout/反推动作；它只有低维合成状态，**不是视频模型、真实robot或Dreamer复现**。

```python
import numpy as np
rng=np.random.default_rng(7)
s=rng.uniform(-1,1,500); a=rng.choice([-1.,1.],500)
next_state=.95*s+.1*a
X=np.c_[s,a,np.ones(len(s))]
w=np.linalg.lstsq(X[:400],next_state[:400],rcond=None)[0]
assert np.max(np.abs(X[400:]@w-next_state[400:]))<1e-12
rollouts=[]
for action in [-1.,1.]:
    state=0.; history=[state]
    for _ in range(8):
        state=float(np.array([state,action,1.])@w); history.append(state)
    rollouts.append(history)
assert rollouts[0][-1]<0<rollouts[1][-1]
recovered=(next_state[:5]-.95*s[:5])/.1
assert np.allclose(recovered,a[:5])
print('动作条件参数',w.round(3),'两rollout终点',np.array(rollouts)[:,-1].round(3))
```

单步、自由多步、动作响应、奖励/终止、极端状态、重置/可逆操作分别验。预测模型在数据覆盖外可能被策略利用；合成驾驶corner case可以补数据，但是否提升真实任务需保留真实测试和sim-to-real证据，不声称省掉所有真实采集。

## 10. 图像/视频评价与物理检查

图像可看固定/新seed样本、质量/覆盖、条件匹配、FID/IS/生成precision-recall。视频另看每段动作、身份/结构、时间一致、FVD等时空特征距离、人工任务评价。FVD受特征网络/采样长度/fps/数量影响，不是物理模型验证。每帧CLIP高分可能完全忽略动作方向或前后顺序。

clip-level与multi-clip video-level评价报告各自窗口、crop数量、聚合方法、成本；多个clip的均值可能更稳也可能更差，不是accuracy按定义必提高。动作分类top-k与时空定位任务指标不同，不把Kinetics、UCF/HMDB、Something-Something、AVA结果混排或只列名当教程。

IS公式是 $IS=\exp(E_x KL(p(y|x)\|p(y)))$：希望单图类别分布尖锐、整体类别分散；不使用真实参考分布，也不奖励同类内部覆盖，分类器不适配领域时解释更弱。

生成流形precision/recall可在特征空间用近邻半径等方法近似support：precision是generated样本落在real近似流形内的比例，偏质量；recall是real样本落在generated近似流形内的比例，偏覆盖。它不是二分类precision/recall混淆矩阵同一对象，近邻k、样本量、特征与半径定义会改变分数。

小特征Fréchet代理可检验公式，但不是用真实Inception提取的FID：

$$
D=\|\mu_r-\mu_g\|^2+\operatorname{tr}(\Sigma_r+\Sigma_g-2(\Sigma_r^{1/2}\Sigma_g\Sigma_r^{1/2})^{1/2}).
$$

完整协方差算法、奇异PSD检查与向量fixture统一见下方第10.1节的共用实现入口；图像的定义、手算和评价边界保留在本章。


物理/连续性检查需要相机、时间、遮挡与坐标语义：画面中心object消失也可能被遮挡，屏幕y方向上升不等于物理违反重力，flow尖峰可能镜头切换，少数可见手指可以被合法遮挡。track/pose/face/OCR工具都有误差，固定0.8余弦或20%CER不是普遍质量门槛。把这些结果做可复查证据和任务阈值，不能自动证明“物理正确”或“一票发布”。本批没有接视频API或下载这些检测模型。

### 10.1 FID、特征协议与有限样本

正式FID先按固定图像加载/resize/色彩/网络版本提取Inception特征，再对参考与生成特征估计均值及**完整协方差**，使用上面的高斯距离。FID不逐图评分，也不直接看prompt；只匹配一阶/二阶统计会漏掉不同的高阶或多峰结构。使用DINO/CLIP/领域网络则应标明是哪个feature distance，不能沿用“标准Inception FID”名字或直接混排分数。

有限样本FID有偏差且受模型/特征分布影响；同一总体的两组有限样本也常得到正距离。不是“小N一定给假低分”，也不能把10000当通用有效/无效分界。比较保持样本量、参考集合、生成/筛选规则、分辨率预处理一致，做重复子采样/置信分析，报告失败、重复和筛选。小样本只作带范围的回归诊断，不称公开模型排名。

协方差可能奇异，两个PSD矩阵的乘积也未必对称；不对其直接做依赖逆矩阵的迭代并宣称全部PSD都稳定，更不能用任意1e-12假pivot伪造逆。利用对称夹心 `C_r^(1/2) C_g C_r^(1/2)` 的PSD平方根计算trace项。**数值算法主要维护入口**是 [15§8.1完整协方差与半正定平方根](15-音频安全与评价方法.md#81-完整协方差与半正定平方根)：算法通用，FID与FAD的特征/预处理/数据协议分别确定。本章仍保留图像定义与手算：协方差相同且均值差 `[1,2]`，距离为5；均值/协方差都同则0；这不能证明两份原图分布所有属性相同。

特征缓存记录数据ID与版本、网络/层、预处理、数量、dtype及统计方式；这些改变就失效，不能“参考features永远只算一次”。离线生成可提高batch利用率，但任务失败、OOM、重复样本及最终数量要保存，不用固定设备小时数/每日CI样本门槛当知识定律。

### 10.2 CLIPScore、CMMD与匹配对必须分开

raw CLIP cosine、Hessel等CLIPScore的 `2.5×max(0,cos)`、某些实现的100倍尺度不是同一分数；须写网络、文本截断/前缀、归一化与聚合约定。CLIP/CLAP的关联不保证数量、关系、否定、动作或业务正确，不能把“短prompt机械总更高”当所有输入定律。

CMMD比较两池**图像CLIP特征的边缘分布**，用Gaussian RBF核的MMD取代高斯Fréchet近似。它不是“prompt与图片是否对应”的指标。RBF `k(x,y)=exp(-||x-y||²/(2σ²))`；包含对角的V-statistic为 `mean(Kxx)+mean(Kyy)−2mean(Kxy)`，总体MMD²非负，有限样本的无偏U-statistic可能为负。带宽、scale、归一化与估计器要固定。作者CMMD实现使用σ=10、scale=1000的特定协议；下面仅用合成向量σ=1、scale=1核对，未运行CLIP或发布CMMD成绩。[作者实现](https://github.com/google-research/google-research/blob/master/cmmd/distance.py)

```python
import numpy as np

def vectors(x):
    a=np.asarray(x,float)
    if a.ndim!=2 or min(a.shape)<1 or not np.isfinite(a).all():raise ValueError('非空有限N×D特征')
    return a

def paired_cosine(images,texts):
    a,b=vectors(images),vectors(texts)
    if a.shape!=b.shape:raise ValueError('必须逐样本同维配对，不能zip截短')
    na,nb=np.linalg.norm(a,axis=1),np.linalg.norm(b,axis=1)
    if (na==0).any() or (nb==0).any():raise ValueError('零特征没有余弦方向')
    return np.clip((a*b).sum(axis=1)/(na*nb),-1,1)

def mmd_rbf(x,y,sigma=1):
    x,y=vectors(x),vectors(y)
    if x.shape[1]!=y.shape[1] or not np.isfinite(sigma) or sigma<=0:raise ValueError('同维与正带宽')
    kernel=lambda a,b:np.exp(-((a[:,None]-b[None,:])**2).sum(-1)/(2*sigma*sigma))
    return float(kernel(x,x).mean()+kernel(y,y).mean()-2*kernel(x,y).mean())

images=np.array([[1.,0.],[0.,1.]])
texts=images.copy(); shuffled=texts[::-1]
assert np.array_equal(paired_cosine(images,texts),[1.,1.])
assert np.array_equal(paired_cosine(images,shuffled),[0.,0.])
assert abs(mmd_rbf(images,images[::-1]))<1e-12  # 同边缘分布，不看prompt对应关系。
assert mmd_rbf(images,images+3)>0
for bad in ([[0.,0.],[0.,1.]], [[1.,0.,0.],[0.,1.,0.]]):
    try:paired_cosine(images,bad)
    except ValueError:pass
    else:raise AssertionError('零向量/异维应拒绝')
print('配对cos正确/错配=1/0；边缘MMD对顺序不敏感，不能作prompt正确性')
```

KID使用另一特征/核的MMD估计，FD-DINO换特征，HPS/ImageReward/PickScore学习特定偏好；没有一个方法自动修复全部前一指标的缺陷。保留事件/数量/空间关系等可检查题，人工分层复核，评审器和生成器的数据污染/风格偏好按 [实验管理](../../LLM%20工程实践/06-评测与实验管理.md) 检查。

### 10.3 成对偏好、draw与Elo的解释

同prompt、相近预算的盲序A/B比较要先指定“更符合条件”“更美观”“更适合用途”哪种问题。允许平局/无效/无法判断，后两者单列覆盖率而不默认为B赢。固定K的在线Elo依赖评审顺序与对手池；Bradley–Terry是成对胜率的统计模型，不等于任意流式Elo更新。两者都不是绝对画质单位或客观世界真值。

```python
import math

def elo_update(a,b,winner,k=32):
    if winner not in {'a','b','draw'}:raise ValueError('未知结果不能默认为b胜')
    if not all(math.isfinite(x) for x in (a,b,k)) or k<=0:raise ValueError('有限评分与正K')
    z=(b-a)*math.log(10)/400
    expected=math.exp(-z)/(1+math.exp(-z)) if z>=0 else 1/(1+math.exp(z))
    actual={'a':1.,'b':0.,'draw':.5}[winner]
    delta=k*(actual-expected)
    return a+delta,b-delta

assert elo_update(1000,1000,'a')==(1016,984)
assert elo_update(1000,1000,'draw')==(1000,1000)
def stream(order):
    a=b=1000.
    for result in order:a,b=elo_update(a,b,result)
    return a,b
one,two=stream(['a','a','b']),stream(['b','a','a'])
assert not math.isclose(one[0],two[0])
assert math.isclose(sum(one),2000)
try:elo_update(1000,1000,'unknown')
except ValueError:pass
else:raise AssertionError('无效判断必须显式处理')
print('Elo胜/平局/未知结果、总分守恒与顺序敏感通过')
```

报告成对胜/负/平、无效数量、prompt/评审者支持数、按类别结果和不确定性，重复同prompt或同人评分不能当全独立样本。学到偏好分数不等模型普遍正确；高均分不能抵消严重失败，也不采用通用“+5%FID或55%胜率即可签收”的OR门禁。

## 11. 练习与参考判断

1. 圆形GAN第几epoch变圆？**答案：**要在实际数据/多seed看固定样本与覆盖，第生成章20步机制不提供真实质量epoch；不能从loss下降猜。
2. SN比BN必更快吗？**答案：**同配置/多seed、记录梯度和样本/覆盖才比较，SN不是整体严格Lipschitz/收敛保证。
3. DDPM/50步DDIM同seed图像必一样吗？**答案：**采样路径/随机性不同，需同模型目标、终点和起始噪声下比较，主章先排除端点错误。
4. 怎样比较cosine与linear？**答案：**确保合法一致的bar_alpha/beta、损失权重/采样和终点；同训练资源比较质量/覆盖，不预定cosine胜。
5. CFG在何尺度失真？**答案：**任务/model依赖，用固定和新seed、条件/质量/覆盖一起扫；数学w1=conditional，API分支需另核。
6. 怎样为subject LoRA选rank/steps？**答案：**留出新prompt/视角检查身份与背景记忆，记录base/目标模块/参数量和训练状态，不能只看train照片复现。
7. 2Dpool与3D的FLOPs能固定3～5倍吗？**答案：**按同shape/层/stride计算，source(2+1)D的m可能用于参数匹配而非必减少。
8. 纯pool训练motion可能超过chance怎么办？**答案：**查外观捷径/采样和标签；完全逆序配对理论上被pool合并，不把整个真实dataset说成信息完全一致。
9. R(2+1)D替换每Conv2d就完成吗？**答案：**还要改时间轴pool/residual/downsample/head与输入，核对预训练inflation的内部/边界语义。
10. DiT 4步为何不能叫Schnell？**答案：**没有对应蒸馏/训练和质量验收，只有步数相同。
11. Video token数/attention怎么算？**答案：**T/S先在patch后计算，N=TS；joint=N²、divided=ST²+TS²；先声明fps、padding和precision。
12. Additive sin/cos等于RoPE吗？**答案：**不等，RoPE旋转Q/K成对通道，可用范数/相对点积核对，第8节已验证。
13. 动作输入有不同输出就证明worldmodel可规划吗？**答案：**只证明局部响应，仍验多步/反事实/奖励/终止/闭环；视频漂亮不能替代动作可执行性。
14. 图像生成两个方法如何公平比较代理FID？**答案：**同数据/特征提取/样本量/预处理/预算和seed，标明只是代理；真实FID还需指定网络和协议，不预定哪个更快收敛。

## 12. 多尺度视觉自回归：预测下一分辨率

### 12.1 残差量化与尺度条件分布

普通raster AR按一个网格的逐位置顺序预测token；VAR将latent编码成一组逐渐变细的离散网格，并分解 `p(z1,...,zK|c)=∏p(zk|z<k,c)`。每个尺度的所有位置可一次预测，当前位置生成不再读取同尺度“已生成答案”；它依赖较粗结构、位置和条件。减少串行轮数不等于减少相同倍数FLOPs/墙钟，后期尺度可能很大。

多尺度量化先编码原图为连续f：对当前残差下采样到尺度sk，在码本取最近向量；上采样、经对应残差映射φk后加到累计f_hat，再更新残差。所有尺度的和送VAE decoder还原图像。原VAR用共享embedding码本和可共享/配置的残差卷积；不是独立对原f每尺度量化再相加，也不是随意平均码本ID。ID只标识码向量，没有数值“语义均值”。音频RVQ原理可参照 [12音频编码](12-神经音频编码与说话人表征.md)，图像的尺度/卷积/训练目标另定。

尺度列表不必是2的幂；例如作者配置 `[1,2,3,4,5,6,8,10,13,16]` 共680位置，不是源skill写的671。更多尺度或更大码本并不必然质量更好：预算、使用率、量化/预测难度、残差训练和最终decoder共同影响。以重建误差、生成质量/覆盖、各尺度CE、码本使用与真实耗时比较；使用率50%不是通用过关线。

### 12.2 同尺度attention允许，当前答案仍不能输入

训练可使用“真实较低尺度”进行teacher forcing。预测尺度k的输入是较低尺度累计重构，经变尺寸后投影，加level/位置/类别或文本条件；**不是当前尺度gold token的embedding**。块mask允许键尺度≤query尺度，包括同尺度，因为同尺度输入都只含过去条件。GPT的“逐token右移+三角mask”不能原封不动替换这一输入构造。

只改mask而直接把当前gold码输入，会使同尺度其他位置甚至自己读到答案。检验两层：改变尺度k标签时，预测k的输入应不变；由此导致未来尺度输入变化时，mask仍使≤k的输出不变。作者实现使用learned位置表与level embedding，并非强制2D sin/cos、禁止一切flatten位置。code里的尺度summary直方图没有attention，也不能靠打印“看了几token”声称已检验mask。

### 12.3 完整残差网格、真实attention、反向与逐尺度生成例

下面固定共享**标量**码本，8维随机Transformer，只验证尺度输入/块mask/梯度和三轮生成。它没有图像encoder/VAE decoder、学习码本、残差卷积、adaLN/CFG、KV加速或真实图片训练；输出是4×4合成latent，不是已训练VAR或视觉质量成绩。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(12)
SCALES=(1,2,4);TOTAL=sum(s*s for s in SCALES)
BOOK=torch.tensor([-1.,-.5,0.,.5,1.]);V=len(BOOK)
LEVEL=torch.cat([torch.full((s*s,),i,dtype=torch.long) for i,s in enumerate(SCALES)])

def lift(ids):
    return F.interpolate(BOOK[ids][:,None],size=(4,4),mode='nearest')

def tokenize(latent):
    if latent.ndim!=4 or latent.shape[1:]!=(1,4,4) or latent.shape[0]<1 or not torch.isfinite(latent).all():
        raise ValueError('非空有限B×1×4×4合成latent')
    residual=latent.clone();stream=[]
    for s in SCALES:
        coarse=F.adaptive_avg_pool2d(residual,(s,s))[:,0]
        ids=(coarse[...,None]-BOOK).square().argmin(-1)
        stream.append(ids);residual=residual-lift(ids)
    return stream

def conditioning(stream,levels=3):
    if not 1<=levels<=3 or len(stream)<levels-1:raise ValueError('当前尺度需要完整前序尺度')
    B=stream[0].shape[0] if stream else 1
    accumulated=torch.zeros(B,1,4,4);parts=[]
    for i,s in enumerate(SCALES[:levels]):
        # 先构造当前尺度输入，再把当前gold/generated码加入供未来尺度用。
        current=F.adaptive_avg_pool2d(accumulated,(s,s)).flatten(2).transpose(1,2)
        parts.append(current)
        if i<len(stream):
            ids=stream[i]
            if ids.shape!=(B,s,s) or ids.dtype!=torch.int64 or (ids<0).any() or (ids>=V).any():
                raise ValueError('尺度/码本ID契约错误')
            accumulated=accumulated+lift(ids)
    return torch.cat(parts,dim=1)

class NextScale(nn.Module):
    def __init__(self):
        super().__init__();self.input=nn.Linear(1,8);self.pos=nn.Embedding(TOTAL,8);self.level=nn.Embedding(3,8)
        self.block=nn.TransformerEncoder(nn.TransformerEncoderLayer(8,2,16,dropout=0.,batch_first=True),1,
                                         enable_nested_tensor=False)
        self.head=nn.Linear(8,V)
    def forward(self,values):
        B,N,D=values.shape
        if B<1 or D!=1 or N not in (1,5,21) or not torch.isfinite(values).all():raise ValueError('合法完整尺度前缀')
        lv=LEVEL[:N]
        forbidden=lv[None,:]>lv[:,None]  # PyTorch Transformer: True=禁止未来scale。
        h=self.input(values)+self.pos(torch.arange(N))[None]+self.level(lv)[None]
        return self.head(self.block(h,mask=forbidden))

latent=torch.linspace(-1,1,16).reshape(1,1,4,4)
stream=tokenize(latent);inputs=conditioning(stream)
labels=torch.cat([x.flatten(1) for x in stream],dim=1)
assert inputs.shape==(1,21,1) and labels.shape==(1,21)
model=NextScale().eval()
changed=[x.clone() for x in stream];changed[1]=(changed[1]+1)%V
new_inputs=conditioning(changed)
assert torch.equal(inputs[:,:5],new_inputs[:,:5])
with torch.no_grad():
    a,b=model(inputs),model(new_inputs)
    assert torch.allclose(a[:,:5],b[:,:5],atol=1e-6)  # 未来输入不能改变已预测尺度。
loss=F.cross_entropy(model(inputs).reshape(-1,V),labels.reshape(-1))
loss.backward();assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
optimizer=torch.optim.Adam(model.parameters(),lr=1e-3);optimizer.step()
# 逐尺度三次模型调用；同尺度没有把刚采样的某位置喂给其他位置。
drawn=[];calls=0
with torch.no_grad():
    for i,s in enumerate(SCALES):
        values=conditioning(drawn,levels=i+1)
        ids=model(values)[:,-s*s:].argmax(-1).reshape(1,s,s)
        drawn.append(ids);calls+=1
reconstruction=sum(lift(x) for x in drawn)
assert calls==3 and reconstruction.shape==(1,1,4,4)
assert sum(s*s for s in [1,2,3,4,5,6,8,10,13,16])==680
print('VAR机制：21监督位置，输入先前尺度/块mask无泄漏，有限梯度，3轮合成latent生成')
```

全部位置CE平均使细尺度占更大比例；也可按尺度加权，但须明确目标变化。真实训练先学习并验证tokenizer再冻结/按协议联合训练预测器；本例只有一次优化，不能据输出形状称学会了图像分布。共用相同tokenizer时才合理比较重建上限与生成损失。

### 12.4 与diffusion和HART怎样比较

VAR沿分辨率轴做条件离散预测，diffusion沿噪声时间学习连续/离散逆过程；两者不是同一种loss或同样轮数成本。diffusion/flow的训练与条件架构由 [21扩散流匹配与条件生成](../深度学习专题/21-扩散流匹配与条件生成.md) 维护，这里维护尺度AR及比较接口。论文的class-conditional ImageNet比较有数据、模型、tokenizer与评价协议，不能推导所有尺度VAR必胜或“计算翻倍误差一定减半”。拟合幂律的指数/范围与工程14缩放经验式一样需实际数据，不把FID当通用语言PPL。

HART并不只是“VAR加CLIP与MaskGIT”：作者研究用离散分量表示大结构、连续残差补离散tokenizer不能表示的细节，再以轻量残差diffusion生成连续部分，是混合路线。文本条件的编码器、adaLN/交互和训练数据需按具体方法设计，不预设加一个向量就改善FID。

练习核对：源4/6/8/10尺度和512/4096/16384码本消融应同预算/同数据比量化与预测，不预定越大越好；同尺度mask允许是合法的，关键为输入来自过去；改变gold当前尺度仍改变当前预测输入则说明泄漏；680位置≠680串行生成步，也不等680Hz；本例21位置/3轮未证明真实加速。VAR/DiT同任务对照和文本适配未运行，不编造规模/质量结果。

## 13. 视频回答必须回到原始时间与事件证据

视频问答、先后关系、动作分类和事件区间定位解决不同问题。问“有没有猫”可从一帧判断；问“猫先坐下还是先跳起”需要次序；问“跳起发生在哪一秒”需要原视频的时间轴。先掌握本章第6节的PTS和第7节的时间建模，再读下面的采样、匹配和长视频方案。

### 13.1 帧预算、真实时间和压缩各管一件事

每个抽取帧至少保留 `video_id、revision、frame_id、PTS秒、clip_start、有效标记`。变帧率、剪辑和删片段后，数组第15项不能直接称为第15秒。查询某个片段时，局部时间需映回原时间；重复尾帧只用于形状补齐，不能变成新的事件证据。均匀采样、运动密集采样、检测器选事件、镜头边界加邻域应按问题比较；静止画面上的小字也可能重要，不能把“运动大”当“语义相关”。

Qwen2.5-VL作者描述的是变化FPS训练和mRoPE时间ID的绝对时间对齐。它并不证明默认预处理器会自动运行光流、选择高运动区域，也不保证时间编码一变就获得精确定位。[官方模型卡](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct)

给第i秒分配整数帧数 $b_i$ 时，必须同时满足总量 $\sum_i b_i=B$ 和上限 $0\le b_i\le c_i$。逐秒独立 `round(B*motion_i/sum(motion))` 再强制至少1帧，会破坏总预算：来源十秒motion例的“12帧”实际得到15帧。若要求每秒至少1帧而B小于秒数，应明确不可行，而非悄悄超预算。下面从零开始按剩余容量和权重分配，权重全零退回等权；并从已提供的真实时间元数据中选最靠近各时间分段中点的帧。它没有解码视频或估计运动。

```python
from dataclasses import dataclass
from functools import lru_cache
import math

def finite_number(v):
    return type(v) in (int,float) and math.isfinite(v)

def allocate(weights, capacities, budget):
    if (not isinstance(weights,(list,tuple)) or not isinstance(capacities,(list,tuple))
        or not weights or len(weights)!=len(capacities)):
        raise ValueError('需要同长度非空权重/容量')
    if any(type(c) is not int or c<0 for c in capacities):
        raise ValueError('容量需非负整数')
    if type(budget) is not int or not 0<=budget<=sum(capacities):
        raise ValueError('预算或容量不可行')
    if any(not finite_number(w) or w<0 for w in weights) or not math.isfinite(sum(weights)):
        raise ValueError('权重需有限非负，总量不能溢出')
    w=list(weights) if sum(weights)>0 else [1.]*len(weights)
    count=[0]*len(w)
    for _ in range(budget):
        eligible=[i for i in range(len(w)) if count[i]<capacities[i]]
        # 有容量却权重为0的区域仍可吸收剩余预算；确定性下标打破并列。
        i=max(eligible,key=lambda i:(w[i]/(count[i]+1),-i))
        count[i]+=1
    return count

@dataclass(frozen=True)
class Frame:
    video: str
    revision: str
    frame_id: str
    pts: float

def select_frames(frames, start, end, count):
    if (type(count) is not int or count<0 or not finite_number(start)
        or not finite_number(end) or not start<end):
        raise ValueError('时间区间或数量非法')
    if len({f.frame_id for f in frames})!=len(frames):raise ValueError('帧ID重复')
    if len({(f.video,f.revision) for f in frames})>1:raise ValueError('来源混合')
    if any(not finite_number(f.pts) or any(type(v) is not str or not v for v in (f.video,f.revision,f.frame_id)) for f in frames):raise ValueError('非法PTS/来源标识')
    available=sorted((f for f in frames if start<=f.pts<end),key=lambda f:(f.pts,f.frame_id))
    if count>len(available):raise ValueError('有效帧不足，不能复制当新证据')
    chosen=[]
    for i in range(count):
        target=start+(i+.5)*(end-start)/count
        f=min(available,key=lambda f:(abs(f.pts-target),f.pts,f.frame_id))
        chosen.append(f);available.remove(f)
    return sorted(chosen,key=lambda f:(f.pts,f.frame_id))

@dataclass(frozen=True)
class Event:
    video: str
    revision: str
    label: str
    start: float
    end: float

def event_scores(predicted, gold, duration, threshold=.3):
    if not finite_number(duration) or duration<=0 or not finite_number(threshold) or not 0<threshold<=1:
        raise ValueError('时长或IoU阈值非法')
    if len(predicted)>18 or len(gold)>18:raise ValueError('仅小fixture精确匹配，需使用可扩展scorer')
    all_events=list(predicted)+list(gold)
    if len({(e.video,e.revision) for e in all_events})>1:raise ValueError('跨视频误匹配')
    for e in all_events:
        if (any(type(v) is not str or not v for v in (e.video,e.revision,e.label))
            or not finite_number(e.start) or not finite_number(e.end) or not 0<=e.start<e.end<=duration):
            raise ValueError('需同时间轴的有限持续区间')
    def iou(a,b):
        inter=max(0.,min(a.end,b.end)-max(a.start,b.start))
        return inter/((a.end-a.start)+(b.end-b.start)-inter)
    # 小fixture精确求最大一对一命中数；指数复杂度，不是大型AP scorer。
    edges=[[j for j,p in enumerate(predicted) if p.label==g.label and iou(p,g)>=threshold]
           for g in gold]
    @lru_cache(None)
    def match(i, used):
        if i==len(gold):return 0
        best=match(i+1,used)
        for j in edges[i]:
            if not used&(1<<j):best=max(best,1+match(i+1,used|(1<<j)))
        return best
    hits=match(0,0)
    return {'hits':hits,'precision':hits/len(predicted) if predicted else None,
            'recall':hits/len(gold) if gold else None,
            'false_positive':len(predicted)-hits,'missed':len(gold)-hits}

motion=[.1,.1,.8,.9,.9,.2,.1,.5,.9,.9]
counts=allocate(motion,[4]*10,12)
assert sum(counts)==12 and max(counts)<=4
assert sum(allocate([0,0,0],[2,2,2],5))==5
try:allocate([1,1],[1,1],3)
except ValueError:pass
else:raise AssertionError('不可行预算应拒绝')
frames=[Frame('v','r1',str(i),t) for i,t in enumerate([0.,.07,.22,.5,.91])]
selected=select_frames(frames,0,1,3)
assert len(selected)==3 and all(f.pts in [0.,.07,.22,.5,.91] for f in selected)
assert select_frames(frames,0,1,0)==[]
p=[Event('v','r1','jump',4.1,4.7)]
g=[Event('v','r1','jump',4.,4.5),Event('v','r1','jump',4.2,4.6)]
assert event_scores(p,g,10)['recall']==.5
assert event_scores([],[],10)['recall'] is None
try:event_scores([Event('v','r1','jump',math.nan,5)],[],10)
except ValueError:pass
else:raise AssertionError('NaN区间应拒绝')
for args in [([1],[True],0),([True],[1],1),([float('nan')],[1],0),([1],[-1],0),([1],[1],True)]:
    try:allocate(*args)
    except ValueError:pass
    else:raise AssertionError('不合法容量/权重/预算应拒绝')
try:select_frames([Frame('v','r1','bad',True)],0,1,1)
except ValueError:pass
else:raise AssertionError('bool不作为秒')
print('12帧预算' ,counts,'人工PTS被保留',[f.pts for f in selected],
      '一预测不重复命中两个GT',event_scores(p,g,10))
```

### 13.2 定位评价不能只看同名事件最高IoU

持续事件的IoU是交集长度除并集长度。来源三个区间的手算结果约为0.5714、0.2857、0.2727，阈值0.3时只命中1/3。源实现给每个GT反复找同名预测，允许同一预测命中多个GT，同时不统计误报。上例用一对一匹配防重复；公开grounding基准还需按其置信排序、AP/Recall与多阈值协议评分，不能拿这个小scorer冒充官方成绩。

结构输出应声明 `video_id、revision、event、start_s、end_s、status`，验证有限数值和 `0<=start<end<=duration`。没有事件、证据不足、解析失败与模型超时是不同状态。点事件需另定容差，不把零长度区间硬塞IoU。失败保留评价分母；记录采样是否捕获、检索是否命中、回答是否定位正确，才能知道该改哪一层。

### 13.3 长视频的四条路径与公平比较

预算先算有效视觉token，再加问题、音轨转录、历史和输出预留。45分钟×1fps×81token/帧=218,700；两小时同配置为583,200。五分钟×576token/帧=172,800，已经超过128k，还没有算其他输入。实际token数应以固定processor输出复核，而非把这些教学参数当某模型永久规格。

| 路径 | 保留和省去什么 | 需要单独验证 |
|---|---|---|
| 全上下文 | 将采样表示广泛送入模型 | 显存、prefill、长位置与局部细节，不只容量 |
| Ring Attention | 分块Q并轮转KV、重叠通信与计算 | 每设备内存、通信/同步与扩展效率 |
| 压缩/层次摘要 | 减视觉向量或用摘要组织片段 | 小字、短事件、跨片关系是否丢失 |
| 检索后读片 | 问题召回相关原clip及邻域 | 召回遗漏、索引成本、引用时间和全局问题 |

Ring Attention分散存储及计算位置；完整dense attention的全局pair数仍为 $N^2$，理想均分到P设备约为每设备 $N^2/P$ 的pair工作，并未使总算法变为线性。不轮转KV，设备只看到局部块。原论文的非近似分块与通信重叠可帮助理解这一点，摘要核验不等于在本库运行多卡实现。[Ring Attention](https://arxiv.org/abs/2310.01889)

检索链应是问题→真实索引召回clip ID和原时间→补邻域→读原clip→逐主张引用，必要时再检索并限制次数/预算/无增益循环。摘要和caption是派生资料；问具体数字或瞬间时要回到原帧。证据合同接[文档与RAG工程](../../LLM%20工程实践/12-文本检索与RAG文档工程.md)，控制循环接[有界Agentic RAG](../../Agentic%20Design%20Patterns/01-核心章节/14-知识检索-RAG.md)。

Needle测试要固定marker内容、时长、位置与干扰，跨视频、多个位置和seed重复，按长度/位置分别报告。源程序随机选位置后返回写死的 `recall_prob`，既没插入真实marker也没问模型；随机三个时间点不是检索。7490与583200只是两个假定输入的token比较，不能称“99%省费用”或真实召回。比较方案需同视频/问题/硬件/预算，并计入索引、检索、prefill、decode、失败与拒答。局部needle能力不代替整个视频的因果、人物和全局总结。

### 13.4 来源17/18十项练习的参考核对

1. **17-1｜三分钟烹饪演示选均匀还是动态FPS，并给token数。** 1fps、81token/帧假设下为14,580。先看短动作和静态文字是否被保留，再比较局部密采；运动proxy不足以自动选“动态必胜”，不得超总预算。
2. **17-2｜时间RoPE增加什么，普通位置表缺什么？** 时间ID保留不等间隔和速度信息；单纯数组索引丢这层含义。带时间的其他位置设计也可表达，需同骨干/采样/数据的ablation，不能说embedding表天然无法处理时间。
3. **17-3｜设计grounding JSON及错误情况。** 使用13.2的来源、秒单位、区间和status合同；覆盖NaN、越界、混视频、空事件、未知/失败和重复预测。格式合法不证明定位正确。
4. **17-4｜阅读Video-LLaVA第3节，比较alignment-before-projection与独立编码器。** 2026-10-08补核作者§3.1：复用LanguageBind将图像与视频先对齐到共同语言特征空间，再用共享projector接入语言骨干；两种visual encoder不是硬宣称完全同一前端。对照是未对齐的特征分别经projection，不能从一个方法的结果推出所有独立encoder都差。作者§3.2也联合图/视频训练；本库未复现其模型及完整消融。[作者方法](https://arxiv.org/html/2311.10122v3)。
5. **17-5｜2026 VideoMME开源/闭源差距及时间编码贡献。** 需记录当日榜单版本、视频采样/字幕开关、模型与评分协议。不同模型分数差不能归因时间编码；用固定骨干的时间编码/规模消融。这里没有当前gap数字或模型实测。
6. **18-1｜45分钟、1fps、81token/帧是否fits？** 218,700视觉token；实际checkpoint总序列容量扣除文本和输出预留后再判，不按源硬编码型号标签决定。
7. **18-2｜如何放needle并定义问题？** 给原时间轴上可验证的唯一marker，问题问具体内容/发生区间，覆盖不同位置和短时长；先验证采样捕获，再评价召回/答案，记录无答案与失败。
8. **18-3｜一小时全上下文与VideoAgent谁赢召回/延迟？** 无通用胜者。用同问题集分局部/全局，测索引、检索、读取与生成；检索漏掉的证据后段无法恢复，源随机trace不能回答。
9. **18-4｜Ring内存、设备和不轮转的后果。** 每设备保存序列片段、逐块处理全KV；全局dense计算仍二次，增加设备改变分摊与通信，不能笼统称总内存/总计算均线性。停止轮转会失去跨块attention。
10. **18-5｜Gemini1.5第5节1M/10M边界的needle结果。** 该节未整文核读，原精度与型号命名不作当前事实。阅读时逐项取出测试模态、长度/位置、指标、重复数与模型版本；只可复述对应论文实验，不能推所有视频都可靠或今天的产品容量。

2026-10-08增量来自固定Phase12第17/18课。静态SVG解释架构/采样/输出，不能提供排行证据；实际 `video-temporal-patches` 只按224²、floor帧/tubelet/patch算形状，F不足tubelet仍显示1，需按真实padding/drop策略修正；`mm-video-token-budget` 的五根柱高为人为函数，没有视频时长或真实模型context。整数采样与区间程序仅验证人工元数据和控制逻辑，未处理真实视频、运行VLM或分布式attention。旧程序和2026-10-04/05核验范围保持原记录。
