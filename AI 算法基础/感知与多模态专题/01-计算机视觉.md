# 01｜计算机视觉

> 统一任务概览。先修：张量、分类损失、训练/验证划分。本页用来定位任务与前后关系；先读[图像表征、卷积与视觉训练](05-图像表征卷积与视觉训练.md)做基础，再读[自监督视觉与检索](06-自监督视觉与检索学习.md)。检测/分割等细节接[任务实践](07-检测分割姿态与跟踪.md)与既有[深度视觉任务](../深度学习专题/07-计算机视觉任务.md)，经典CNN由[卷积架构](../深度学习专题/02-卷积神经网络与经典架构.md)维护。

## 1. 图像是什么

数字图像是规则网格上的信号：

- spatial dimension：H×W；
- channel：灰度、RGB 或其他谱段；
- pixel value：离散采样后的亮度/颜色。

核心预处理包括 resize、normalization、augmentation 和颜色空间变换。

像素是经过光学/曝光/采样与编码形成的信号，8位RGB只是常见接口。先明确RGB/BGR、编码颜色、范围、dtype与HWC/CHW；逻辑NCHW和channels_last内存格式不同。裁剪/重采样通常丢信息，不能统称可逆。完整HSV分段、灰度与标准化的1×1变换、边界/抗混叠例子统一在基础实践第1～4节。

## 2. 传统视觉基础

深度学习之前仍值得理解：

- convolution/filtering；
- Gaussian blur；
- edge detection；
- gradients；
- corners；
- SIFT/局部特征。

这些方法建立“局部模式 + 不变性”的直觉。

梯度核响应的方向、核是否翻转与边界延拓必须说明：常数亮图配zero padding也可产生边缘，锐化也可能放大噪声。图像FFT乘法默认是周期卷积，JPEG分块DCT不等于普通卷积。实际手算和程序见[图像基础实践](05-图像表征卷积与视觉训练.md)，不将图中高对比当模型已经识别物体。

## 3. CNN

卷积通过：

- local connectivity；
- weight sharing；
- translation equivariance；

显著减少图像建模参数。

经典网络演进的长期价值：

```text
LeNet
→ AlexNet
→ VGG
→ ResNet
→ EfficientNet / MobileNet
```

重点不是背模型，而是理解 depth、skip connection、scaling 与 efficiency。

平移等变受边界和stride影响，池化不保证完整不变。分组卷积参数少、depthwise+pointwise MAC低也不保证目标设备更快；经典网络历史精度不能当当前默认。用尺寸/参数/感受野表和具体block前后向验收，而不是看型号大小。深度架构章节保留UDL的shattered梯度、残差方差与归一化条件。

## 4. Detection

目标检测同时预测“是什么”和“在哪里”。

主要范式：

- two-stage：proposal → classification/regression；
- one-stage：直接密集预测。

需要理解：

- anchor / anchor-free；
- IoU；
- box regression；
- NMS；
- class imbalance。

YOLO、SSD、Faster R-CNN、RetinaNet 是理解范式的典型代表。

## 5. Segmentation

- semantic：每个像素类别；
- instance：区分同类不同实例；
- panoptic：统一语义与实例。

U-Net 的 encoder-decoder + skip connection 是密集预测的重要模式；Mask R-CNN 将 detection 与 instance mask 结合。

## 6. Vision Transformer

ViT 把图像切成 patch token，再用 Transformer 建模全局关系。

重要演进：

- hierarchical window；
- self-supervised representation；
- masked image modeling；
- distillation。

Swin、DINO、MAE 等可理解为不同的结构/训练策略，而不是需要追逐的“当前最强型号”。

patch本身有局部划分先验，位置embedding增加坐标结构，不是“完全无先验”。CLS是读出方案之一；新分辨率要对二维patch网格位置插值，保持特殊token。自监督分对比、teacher/student、遮挡重建，目标/防坍缩/评价协议不同；完整小ViT在基础实践第8节，teacher/MAE在自监督实践第3～4节。

## 7. 生成视觉

主要路线：

- GAN；
- VAE；
- diffusion；
- flow matching。

它们分别通过对抗、潜变量、逐步去噪或连续概率流建模图像分布。

## 8. Video

视频多一个时间维度，需要同时建模：

- appearance；
- motion；
- temporal consistency。

典型思路：

- optical flow；
- 3D convolution；
- two-stream / SlowFast；
- video transformer；
- tracking。

## 9. 3D Vision

关键任务：

- stereo/depth；
- point cloud；
- pose；
- SLAM；
- scene reconstruction。

NeRF 与 3D Gaussian Splatting 都是在多视角观测下重建可渲染 3D 场景的代表路线。

## 先画出输出，再决定任务

同一张有两只猫的图：分类输出“有猫”；检测输出两个框；语义分割把所有猫像素标成同一类别；实例分割还要给两只猫不同实例编号。它们所需标注和评价不能互换。

自查：仅有“图片里有猫”的标签，是否足以直接监督每只猫的准确轮廓？**答案：**不足。那是图像级标签，精确轮廓还需要像素标注或专门的弱监督假设。

做第一个视觉练习时，先抽看 10 张原图及标签，记录尺寸、颜色通道、标注坐标和同源样本分组；再检查增强后的标签是否同步变化。邻近视频帧或同一场景重复图不要随机散入训练与测试，防止用场景记忆冒充泛化。

## 11. 分类、迁移、检索和端侧的学习闭环

| 要回答的问题 | 主要学习入口 | 最小判断证据 |
|---|---|---|
| 像素/颜色/轴怎么到模型 | [图像与训练基础](05-图像表征卷积与视觉训练.md)第1～5节 | 手算颜色/核响应、轴往返、VJP对照，解释边界 |
| 分类模型到底学了什么 | 同章第6节 | 同源划分、合法增强、每类指标/失败图，测试不参与调参 |
| 预训练怎样迁移 | 同章第7节 | 参数/BNbuffer/优化器分别核查，probe与微调同预算比较 |
| ViT怎样处理分辨率 | 同章第8节 | patch/CLS/位置/输出形状、梯度与新网格插值 |
| 自监督特征怎样形成 | [自监督与检索](06-自监督视觉与检索学习.md)第1～5节 | 正负关系、EMA/center、mask恢复、下游probe协议 |
| 图像相似究竟指什么 | 同章第6～9节 | 类别/实例/重复定义，排self，区分Hit、Recall、AP及ANN recall |
| 手机/边缘能否达标 | 基础实践第9节 | 目标设备端到端冷/暖p95/峰值/任务指标；不以FLOPs代替时间 |

先做到能读/算/改基础程序，再选择一个任务分支。XOR、合成图和随机网络能运行分别验证数学/接口/计算，不能变成“用户已经掌握视觉”或真实分类成绩。冻结backbone并不自动冻结BN统计；图像检索self命中1.0也不等于跨视角检索好。
