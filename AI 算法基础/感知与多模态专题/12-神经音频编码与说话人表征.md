# 12｜神经音频编码与说话人表征

本章连接两种不同的音频表示：说话人向量用于比较身份线索，神经codec把波形压成可解码的离散序列。先读[数字音频特征与分类](11-数字音频特征与分类.md)的采样、通道和前端契约；相似度和分类损失接[距离专题](../数学与数值计算专题/05-范数距离与相似性.md)、[前向反向与损失](../深度学习专题/16-前向反向与损失实现.md)。本章不下载真实声纹/codec模型，不录人声；随机张量和合成波形只验证构造与计算。

## 1. 说话人任务先区分输出与训练目标

Verification是已声明身份与测试语音的1:1验证；identification在注册集合中寻找1:N身份；open-set允许未注册身份并需拒识；diarization找“谁在什么时候说话”，通常输出匿名说话人区段。Closed-set不等于“1:1才可做”，也不能把验证天然归为closed-set、云验证天然归为open-set。

说话人表征要尽量保留稳定的发声/音色线索，并对说的文本、响度、噪声、麦克风和会话变化稳健。单纯基频、MFCC均值/标准差、随机哈希或某几频率的混合可以做教学特征，不能据合成“不同speaker”分类或0%EER证明真实身份可辨。相同人可改变音高，不同人可相似；通道和背景也可能比身份更容易学到。

历史路线用于理解：GMM-UBM以通用背景混合高斯作适配参照；i-vector将说话人与通道等变化压到总变异空间；x-vector用TDNN等帧编码+统计池化学习固定向量。原x-vector不意味着必用角度margin训练；交叉熵、角度损失和自监督适配是可区分的选择。ECAPA-TDNN强调通道注意力、多尺度残差和跨层聚合等，用注意力统计池化；WavLM可作为语音自监督编码器再适配任务。输出维度、模型容量和效果取决于具体checkpoint，不固定为所有模型统一192/256维，也不宣称某路线当前必胜。

## 2. 时间编码、统计池化与变长输入

设帧表示 $h_t\in\mathbb R^d$。统计池化为 $\mu=\frac1T\sum h_t$、$\sigma=\sqrt{\frac1T\sum(h_t-\mu)^2}$，拼接形成2d向量再投影。它丢掉次序但保留分布概括；短音频估计方差不稳定，padding不能进入T计数。注意力池化以 $a_t\ge0,\sum a_t=1$ 形成加权均值和标准差，权重应mask无效帧。

TDNN/一维卷积利用局部时间上下文；空洞、残差、通道注意力可扩展感受野和聚合。x-vector/ECAPA都不只是“MFCC算余弦”的改名，学习目标、可训练编码器和统计聚合共同形成表征。仅在输入和池化处mask还不够：卷积bias会在无效帧产生非零值，下一层卷积再把它带回有效尾部。本例每层后重新mask，使额外padding不改变有效编码；若引入BatchNorm等跨时间统计，还需进一步设计有效帧统计。

### 2.1 完整小TDNN、mask注意力池化与角度损失

这不是ECAPA复刻，而是可自学的最小构造。输入为人为随机的帧特征，运行只检查长度、归一与梯度；不声称训练了真实声纹。

```python
import torch
from torch import nn
import torch.nn.functional as F
import math
torch.set_num_threads(1);torch.manual_seed(8)
class TinySpeaker(nn.Module):
    def __init__(self,features=8,hidden=16,dim=6):
        super().__init__()
        self.encoder=nn.Sequential(nn.Conv1d(features,hidden,3,padding=1),nn.ReLU(),
                                  nn.Conv1d(hidden,hidden,3,padding=1),nn.ReLU())
        self.att=nn.Conv1d(hidden,1,1)
        self.project=nn.Linear(2*hidden,dim)
    def forward(self,x,lengths):
        if x.ndim!=3 or lengths.ndim!=1 or len(lengths)!=len(x) or not torch.isfinite(x).all():
            raise ValueError('有限B×F×T与每样本有效帧数')
        if lengths.dtype not in (torch.int32,torch.int64) or (lengths<1).any() or (lengths>x.shape[-1]).any():
            raise ValueError('长度在[1,T]的整数')
        mask=torch.arange(x.shape[-1],device=x.device)[None,:]<lengths[:,None]
        h=x*mask[:,None,:]
        for layer in self.encoder:
            h=layer(h)
            h=h*mask[:,None,:]  # 避免无效位置bias再污染下一卷积的有效尾部
        score=self.att(h).squeeze(1).masked_fill(~mask,-torch.inf)
        a=torch.softmax(score,dim=1)
        mean=(h*a[:,None,:]).sum(-1)
        variance=((h-mean[:,:,None]).square()*a[:,None,:]).sum(-1)
        z=self.project(torch.cat([mean,torch.sqrt(variance.clamp_min(1e-8))],dim=1))
        return F.normalize(z,dim=1),a

def angular_logits(embedding,weights,labels,scale=15.,margin=.2):
    # 权重与输入归一；实际非目标类仍用cos(theta)。
    cosine=F.linear(F.normalize(embedding,dim=1),F.normalize(weights,dim=1)).clamp(-1+1e-6,1-1e-6)
    phi=cosine*math.cos(margin)-torch.sqrt(1-cosine.square())*math.sin(margin)
    # theta+m超过pi时采用常见单调修正，明确不直接套非单调cos。
    phi=torch.where(cosine>math.cos(math.pi-margin),phi,
                    cosine-math.sin(math.pi-margin)*margin)
    onehot=F.one_hot(labels,weights.shape[0]).to(cosine.dtype)
    return scale*(onehot*phi+(1-onehot)*cosine)

model=TinySpeaker();x=torch.randn(4,8,20);lengths=torch.tensor([20,13,8,4])
z,a=model(x,lengths);weights=nn.Parameter(torch.randn(3,6));labels=torch.tensor([0,1,2,0])
assert torch.allclose(z.norm(dim=1),torch.ones(4),atol=1e-6)
assert torch.allclose(a.sum(1),torch.ones(4)) and torch.all(a[1,13:]==0)
# 追加任意无效内容，但有效长度不变；逐层mask后向量与有效注意力不变。
zpad,apad=model(torch.cat([x,torch.randn(4,8,7)],dim=-1),lengths)
assert torch.allclose(z,zpad,atol=1e-6) and torch.allclose(a,apad[:,:20],atol=1e-6)
assert torch.all(apad[:,20:]==0)
loss=F.cross_entropy(angular_logits(z,weights,labels),labels);loss.backward()
assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
assert weights.grad is not None and torch.isfinite(weights.grad).all()
print('向量形状',tuple(z.shape),'角度loss',float(loss.detach()))
print('每段有效注意力和',a.sum(1).tolist())
```

AAM-softmax的思想是目标类别logit用 $s\cos(\theta_y+m)$，非目标用 $s\cos\theta_j$，角度margin拉开分类边界；m与s是调参，不能永久照搬.2/30。归一化去掉表长差异，分类头权重方向可作训练类别原型，但不自动是部署注册向量。代码中的常见单调修正、clamp和标准差floor都是明确实现条件。

## 3. 注册、打分与评测的输入契约

注册可从多段合适语音提向量，去掉空/过短/严重污染的片段，按明确质量权重聚合，再归一化。不是任意“至少3段、每段3秒”就保证可靠。不同文本、设备和会话覆盖应接部署任务，但测试样本不能回流参与注册。均值聚合前是否先单位化、是否按时长/质量加权决定方法，不只记录最终维数。

```python
import numpy as np

def unit(v):
    v=np.asarray(v,dtype=float)
    if v.ndim!=1 or not len(v) or not np.isfinite(v).all():raise ValueError('有限非空一维向量')
    n=np.linalg.norm(v)
    if n<=1e-12:raise ValueError('零向量无有效身份方向')
    return v/n

def enroll(vectors,quality):
    a=np.asarray(vectors,dtype=float);q=np.asarray(quality,dtype=float)
    if a.ndim!=2 or not len(a) or q.ndim!=1 or len(q)!=len(a) or not np.isfinite(q).all() or (q<0).any() or q.sum()<=0:
        raise ValueError('注册矩阵与非负同长质量权重')
    rows=np.stack([unit(v) for v in a])
    return unit(np.average(rows,axis=0,weights=q))

# 人为数学向量：检验均值后归一、cosine与缩放不变，不是音频模型输出。
anchor=enroll([[1.,.1,0],[.9,-.1,.1]],[1.,.8]);test=np.array([.8,.1,0])
score=float(anchor@unit(test))
assert np.isclose(score,anchor@unit(100*test))
print('合成注册向量',anchor,'合成余弦',score)
# 原余弦定义已除范数；只有直接dot需先单位化。
raw=float(anchor@test);print('原始dot与cosine',raw,score)
```

余弦 $e^Tv/(\|e\|\|v\|)$ 自带范数除法，不先单位化也合法；直接dot只有两向量单位化后才是余弦。原多次注册平均会降低范数，若之后直接dot便不等同单位余弦。维度、版本、前端、有效时长和样本ID都要检查，不能zip不同长度向量静默截断。

PLDA是Probabilistic Linear Discriminant Analysis，用说话人潜变量与会话内变化模型，比较同人/不同人假设的似然比；不是主题模型LDA，也不是只做投影后余弦，更不限于closed-set。是否胜出依训练后端、通道和评测，不保“固定EER改善10–20%”。S-norm通常对注册侧与测试侧分别用cohort分数均值/标准差标准化后平均；AS-norm会选择相关cohort子集，需防评测数据泄漏及标准差近零。

判定分数≥阈值时，阈值升高通常降低FAR、提高FRR。EER是二者相等或离散曲线的约定插值位置，不等于部署必须使用的阈值。严格的trial/ROC/EER、目标FAR与安全评测由[音频安全与评价方法](15-音频安全与评价方法.md)统一维护。本章不复制另一套评测算法。原docs初始化 `best=(1,1,0)`，差为0，后续严格更小不可能，永远返回1；原main已改成inf起步，但仍只搜索观察分数的最近离散差，不保证真正插值EER，缺极端阈值/空输入契约。

源动画设 $FAR=e^{-3.2t}$、$FRR=e^{-3.2(1-t)}$，在t=.5交点约.2019，纯示意函数，不是真试验曲线。源“100对”练习实际main是50同人对、250异人对；同一段被复用多次，不能把每对当独立样本计算置信区间，也没有固定注册/开发/测试分离。0%EER合成结果只属于预设的谐波分组。

## 4. Diarization与模型选择的边界

常见流程是VAD/语音区段→说话人表征→聚类→边界平滑；分段错误、短片段、重叠说话和聚类阈值会相互影响。DER分漏检、误报、说话人混淆，需说明边界collar和重叠处理；它不是speaker verification的EER。匿名聚类编号不等于真实姓名，若要实名匹配还需注册及拒识。

实际库要使用当时的官方接口、配套采样率与长度协议，不直接复制旧 `speechbrain.pretrained` 或固定pyannote3.1模型名作长期安装方案。源片段只加载与推理也不等于训练/验收已完成。模型和阈值选择先考虑任务、语言、通道、延迟、注册预算，再用目标数据验证；榜单数字不能替代自己的开发集。重放/合成/变声攻击与身份相似度是不同判别目标，评测方法见15；本次不做真实声纹采集或身份验证服务。

## 5. 神经codec不是“标量量化就变成音频token”

一般结构为波形 $x\to Encoder\to z_t\in\mathbb R^d\to Quantizer\to q_t\to Decoder\to\hat x$。encoder压缩时间并学习局部表示，码本离散化，decoder根据量化向量重建波形。码本索引本身不能直接当波形振幅；必须查对应向量并过配套decoder。模型权重、码本顺序、索引映射、采样率、帧率和增益/scale元数据共同组成编解码协议。

普通PCM是每采样标量量化，RVQ处理的通常是每潜在帧向量；原程序直接对每个信号值学习标量码本，是RVQ递推的教学例，不是神经音频codec。把它显示的“每值”码率乘任意50fps，只有这些值确实代表每秒50个潜在帧才可叫音频码率。

### 5.1 RVQ原理与可手算构造

设 $r_0=z$，第j级码本 $E_j$ 中选 $i_j=\arg\min_i\|r_{j-1}-E_{j,i}\|^2$，$q_j=E_{j,i_j}$，$r_j=r_{j-1}-q_j$。总量化向量 $\hat z=\sum_jq_j$。每级针对之前残差训练；不能只对原z反复独立查所有码本再宣称残差量化。

例：z=[.9,.2]，第一级选[1,0]，残差[-.1,.2]；第二级若有码[-.1,.2]，相加恢复z，误差0。两码本各K项提供至多 $K^Q$ 种索引组合，但不同组合的向量和可能相同，也未必每个组合都训练过；“有效词表=K^Q”不等于存了那么多独立码向量。

固定码本如果不含零，增加一级的最近码也可能反而增误差；包含零候选时至少可以“不变”。独立样本上多级MSE不保证单调改善，decoder感知误差也不按级数线性改善。

### 5.2 完整向量码本训练、编码与反解

教学码本显式加入零候选，所以潜在空间最近距离不增。码本只在train上训练，test不参与；不把测试重新拟合码本当留出重建。

```python
import numpy as np
rng=np.random.default_rng(5)

def kmeans_book(values,K=8,steps=20):
    x=np.asarray(values,dtype=float)
    if x.ndim!=2 or not len(x) or K<2 or not np.isfinite(x).all():raise ValueError('非空有限帧向量与K>=2')
    # 0固定、余下候选随机抽训练帧，不是复杂神经量化器的码本更新。
    C=np.vstack([np.zeros(x.shape[1]),x[rng.choice(len(x),K-1,replace=len(x)<K-1)]])
    for _ in range(steps):
        idx=np.argmin(((x[:,None,:]-C[None,:,:])**2).sum(-1),axis=1)
        for k in range(1,K):
            if np.any(idx==k):C[k]=x[idx==k].mean(0)
    return C

def encode(z,books):
    r=np.asarray(z,dtype=float).copy();indices=[]
    if r.ndim!=2 or not len(r) or not np.isfinite(r).all() or not books:raise ValueError('非空帧向量与码本')
    for C in books:
        C=np.asarray(C,dtype=float)
        if C.ndim!=2 or C.shape[1]!=r.shape[1] or not len(C) or not np.isfinite(C).all():raise ValueError('码本维度/数值契约')
        idx=np.argmin(((r[:,None,:]-C[None,:,:])**2).sum(-1),axis=1)
        indices.append(idx);r-=C[idx]
    return np.stack(indices,axis=1),r

def decode(indices,books):
    a=np.asarray(indices)
    if not books or a.ndim!=2 or not len(a) or a.shape[1]!=len(books) or not np.issubdtype(a.dtype,np.integer):raise ValueError('非空帧×码本整数索引')
    result=np.zeros((len(a),books[0].shape[1]))
    for j,C in enumerate(books):
        if (a[:,j]<0).any() or (a[:,j]>=len(C)).any():raise ValueError('码本ID越界')
        result+=C[a[:,j]]
    return result

train=rng.normal(size=(120,3));test=rng.normal(size=(30,3));res=train.copy();books=[];errors=[]
for level in range(4):
    C=kmeans_book(res);books.append(C)
    ix,_=encode(train,books);res=train-decode(ix,books)
    tx,r=encode(test,books);recon=decode(tx,books)
    assert np.allclose(test-recon,r)
    err=float(np.mean((test-recon)**2));errors.append(err)
    print('层数',level+1,'索引形状',tx.shape,'留出latent MSE',err)
assert all(b<=a+1e-12 for a,b in zip(errors,errors[1:]))
# 不含零时的反例：残差0、唯一可用码1会增误差。
ix,r=encode(np.array([[0.]]),[np.array([[1.]])]);assert float(r[0,0]**2)==1
print('零候选保证与不含零反例均通过')
```

## 6. 训练离散瓶颈：直通估计、码本与承诺损失

argmin索引没有通常的连续导数。VQ常用 straight-through estimator（STE）：前向取量化值，反向把量化近似为恒等；这是有偏代理，不是argmin精确梯度。若 $q$ 是查表结果，写 $z_{st}=z+stopgrad(q-z)$，前向=q，反向对z的导数=I。

常见目标包括重建损失、码本损失 $\|stopgrad(z)-q\|^2$、承诺损失 $\beta\|z-stopgrad(q)\|^2$。前者训练decoder/encoder代理路径，码本项把选中码靠近encoder输出，承诺项避免encoder随意逃逸。部分实现改用EMA更新码本、残差量化/因子化量化、感知/多尺度谱/对抗损失，不能把本例当所有codec统一训练代码。

### 6.1 完整encoder→VQ→decoder训练与索引解码

使用一维卷积每4采样压成一个潜在帧，8维latent、16个码向量，单码本用于把核心链条讲清；前节给出多码本RVQ扩展。本程序合成正弦训练，不做真实音频模型能力评价。

```python
import torch
from torch import nn
import torch.nn.functional as F
import numpy as np
torch.set_num_threads(1);torch.manual_seed(10)
class TinyCodec(nn.Module):
    def __init__(self,K=16,D=8):
        super().__init__()
        self.encoder=nn.Conv1d(1,D,kernel_size=4,stride=4)
        self.book=nn.Parameter(torch.randn(K,D)*.2)
        self.decoder=nn.ConvTranspose1d(D,1,kernel_size=4,stride=4)
    def indices(self,z):
        distance=(z[:,:,None,:]-self.book[None,None,:,:]).square().sum(-1)
        return distance.argmin(-1)
    def forward(self,x):
        if x.ndim!=3 or x.shape[0]<1 or x.shape[1]!=1 or x.shape[-1]<4 or x.shape[-1]%4 or not torch.isfinite(x).all():raise ValueError('非空有限B×1×T，T>=4且是4倍数')
        z=self.encoder(x).transpose(1,2);ids=self.indices(z);q=F.embedding(ids,self.book)
        zst=z+(q-z).detach()
        recon=self.decoder(zst.transpose(1,2))
        rec=F.mse_loss(recon,x)
        book=F.mse_loss(q,z.detach())
        commit=F.mse_loss(z,q.detach())
        return recon,ids,rec+book+.25*commit,rec
    @torch.no_grad()
    def decode(self,ids):
        if ids.ndim!=2 or ids.shape[0]<1 or ids.shape[1]<1 or ids.dtype!=torch.int64 or (ids<0).any() or (ids>=len(self.book)).any():raise ValueError('B×帧合法int64码索引')
        return self.decoder(F.embedding(ids,self.book).transpose(1,2))

n=128;t=torch.arange(n)/128
x=torch.stack([.5*torch.sin(2*torch.pi*f*t+p) for f,p in [(3.,0.),(5.,.3),(7.,.6),(9.,.9)]])[:,None,:]
model=TinyCodec();opt=torch.optim.Adam(model.parameters(),lr=.015)
with torch.no_grad():before=float(model(x)[3])
for _ in range(160):
    recon,ids,loss,rec=model(x);opt.zero_grad();loss.backward();opt.step()
    assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
with torch.no_grad():
    recon,ids,loss,rec=model(x);back=model.decode(ids)
    assert torch.allclose(recon,back,atol=1e-6)
    after=float(rec);assert after<before
    counts=torch.bincount(ids.flatten(),minlength=16).float();p=counts[counts>0]/counts.sum()
    perplexity=float(torch.exp(-(p*p.log()).sum()))
print('训练内重建MSE',before,'→',after,'码形状',tuple(ids.shape))
print('使用码数',int((counts>0).sum()),'码本使用perplexity',perplexity)
# STE的前向/反向单独核对，与argmin真导数区分。
z=torch.tensor([.2],requires_grad=True);q=torch.tensor([.7])
y=z+(q-z).detach();y.sum().backward()
assert torch.allclose(y,q) and torch.allclose(z.grad,torch.ones_like(z))
```

训练内MSE下降不代表泛化、听感或语音可懂度，码本perplexity也不是语言模型困惑度。未使用码/高度集中码可能表示容量闲置或坍缩，但“所有码均匀使用”也不是单一目标；需与重建、时序、频带和生成任务一起诊断。死码可用重初始化、EMA/训练稳定性、码本尺寸等处理，验证改变是否有真实收益。

## 7. 码率、帧率与LM序列长度

无熵编码时，每层每帧一个K项索引需 $\lceil\log_2K\rceil$ bit（K为2次幂时刚好log2K）；Q层同帧率F时固定长码率 $R=F\sum_j\lceil\log_2K_j\rceil$ bits/s。多尺度codec不同层有不同 $F_j$，改为 $\sum_jF_j\lceil\log_2K_j\rceil$。代码字节文件可能以int64存一索引，文件大小不是理论压缩比；还需元数据、熵编码和帧补齐。

10秒、12.5帧/s、8码本共有125帧、1000个索引；K2048每索引11bit，固定长理论码率1100bps，32码本是4400bps。原来源把8层同时叫4.4kbps混淆配置。核验日期2026-10-04，官方Mimi配置可有32层、2048项，加载器常用默认选择8层；具体checkpoint与选择应一起记录，不能把数字泛化所有版本。

EnCodec24k的典型75帧/s、K1024，1.5kbps对应2层，3kbps4层，6kbps8层；原“4层1.5”不成立。8层的6kbps=$75×8×10$；若有码scale/分块等额外信息，实际传输率另算。源码原“86Hz×8码本×10秒=5504索引”算错，应为6880（若实际86.1328则按真实帧计）；理论位宽和索引数量又是不同单位。

```python
import math

def budget(seconds,frame_rates,code_sizes):
    if seconds<=0 or len(frame_rates)!=len(code_sizes) or not frame_rates:raise ValueError('正时长/对应层配置')
    if any(f<=0 for f in frame_rates) or any(not isinstance(k,int) or isinstance(k,bool) or k<2 for k in code_sizes):raise ValueError('正帧率/整数码容量')
    bits=sum(f*math.ceil(math.log2(k)) for f,k in zip(frame_rates,code_sizes))
    indices=sum(math.ceil(seconds*f) for f in frame_rates)
    return bits,indices
for Q in [8,32]:
    print('Mimi数学配置示例',Q,budget(10,[12.5]*Q,[2048]*Q))
assert budget(10,[12.5]*8,[2048]*8)==(1100.,1000)
assert budget(10,[75]*8,[1024]*8)==(6000,6000)
print('多尺度3层示例',budget(2,[12.5,25,50],[1024]*3))
```

低F减少时间步但每帧声学内容更长，可能增延迟/重建难度；帧率不直接等于生成速度。flat把时间×码本摊成序列，Q影响自回归步数；延迟/并行/分层/深度Transformer可改变预测安排，因此1000索引不一定1000串行解码步。码本层顺序、时间对齐、上下文和因果性在LM训练/推理必须一致；不能任意换codec只看索引都是整数。

## 8. 重建型、语义辅助与多尺度codec

EnCodec、SoundStream说明encoder/RVQ/decoder与感知训练的基本路线；EnCodec官方SEANet等编码器可含卷积与循环模块，不能把整个架构固定写成“conv+Transformer+conv”。DAC使用改进的向量量化、激活和损失等；SNAC探索不同时间分辨率码本；Mimi引入来自WavLM等语音教师的语义辅助约束。它们用来理解设计，不作为当前效果/价格排名。

把第一层辅助对齐语音内容、其他层重建细节，可以减轻生成器同时预测内容和声学细节的负担；但semantic和acoustic不保证严格解耦，仍可能含说话人、语调或文本信息。不是任意RVQ天然第0层语义，也不意味着删除最后层永远听不出或篡改第一层必定达到固定程度毁坏。

真正语义辅助需要冻结或明确训练的教师、与codec帧对齐的教师特征/投影、辅助loss及重建目标共同训练。例如每帧latent经预测头 $g$拟合teacher $h$，损失 $\|g(z^{semantic}_t)-stopgrad(h_t)\|^2$ 或适合离散目标的交叉熵；采样/帧率不同需要对齐，不能只把第一索引改名字叫semantic就完成蒸馏。具体Mimi分支和loss以论文/源码为准，本批不训练教师或模拟“已经分离语义”。

重建指标与LM生成效用是不同验收。MSE受幅度/相位和时移影响；谱/感知指标也有带宽、采样率、对齐及适用领域条件，不能把PESQ/ViSQOL随意贴到不同模型/数据集并排。声学质量、可懂度、身份、延迟、码率、生成稳定性需按目标比较，详见15。传统Opus等也输出离散比特流，区别是码流是否提供适合生成建模的符号结构，不是“传统codec没有任何离散信息”。

无需外部vocoder的神经codec是因为已有波形decoder，不是可以省去任何解码器。LM输出码索引时仍必须查码本并过配套decoder；若输出的是Mel或其他声学特征则可能需要另一vocoder。音乐/语音/流式任务按训练分布、因果结构、端到端延迟及实验选择，不保原prompt对DAC/Mimi/EnCodec的绝对禁用或“必须选一种”的规则。
