## 为什么单独做专题

现有 AI 算法主干已经覆盖通用数学、机器学习、深度学习和图学习，但对“模型如何处理图像、声音、多模态输入和真实世界动作”缺少完整横向结构。

本专题补齐：

```text
视觉
→ 语音/音频
→ 多模态表征与生成
→ 机器人/自动驾驶/自主系统
```

## 选择入口与学习边界

四篇是任务概览，可按需要任选，不构成必须依次完成的职业路线。视觉先学输出粒度与标签；音频先学采样率与对齐；多模态先学配对与评估；机器人先学坐标、单位与反馈。

通过标准是能完成各章的小例子并指出失败条件。模型名称仅作查阅入口，具身/机器人方向的阅读也不等于已具备实机集成能力。完整推导、训练实验或硬件验证仍需对应来源和实践材料。
