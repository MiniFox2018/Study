## 为什么单独做专题

现有 AI 算法主干已经覆盖通用数学、机器学习、深度学习和图学习，但对“模型如何处理图像、声音、多模态输入和真实世界动作”缺少完整横向结构。

本专题补齐：

```text
视觉
→ 语音/音频
→ 多模态表征与生成
→ 机器人/自动驾驶/自主系统
```

## 选择入口与学习边界

音频详细路线由[语音与音频入口](02-语音与音频.md)组织11～15篇：先学习信号/时间与特征，再按编码、身份、识别/流式、生成或评价选择任务。Phase06语音音频17课当批已完成融合验收，37个独立CPU程序通过；源读取、纠错与真实实验边界见[第6批验收](../../维护/五站吸收/06-语音音频批次验收.md)。

01～04是领域入口，05～10是视觉深化，可按需要选读，不构成必须依次完成的职业路线。视觉先学输出粒度与标签；音频先学采样率与对齐；多模态先学配对与评估；机器人先学坐标、单位与反馈。

通过标准是能完成所选章节的小例子并指出失败条件。CPU几何/梯度/匹配检查不代表已经训练真实视觉或语音大模型；官方API核对不代表模型在当前设备可用。VLA的单位、归一统计、动作编码和控制时钟已在04第13节深化；实机集成与真实任务评估仍未运行。来源与本批实际验证见[五站进度](../../维护/五站吸收/进度与续接.md)。

## 生成任务与数学主线的分工

AE/VAE、GAN训练与风格机制由[深度学习20](../深度学习专题/20-自编码器与对抗生成实践.md)深化；扩散、流匹配、条件和编辑时刻由[21](../深度学习专题/21-扩散流匹配与条件生成.md)维护。本专题09接图像/视频/VAR与图像评价，10接三维几何/生成/PBR交接，14接音频生成和码流，15维护音频安全/评价及通用高斯特征距离数值例。

同一种骨干不等于同一种输入、目标或测量：图片FID和音频FAD有各自特征协议；CMMD边缘分布不能判断prompt配对；帧数、码本索引和串行生成步数也不同。沿任务选择入口，保留先修回链，避免重复建立来源课程。


## 视觉接入的深化顺序

[16 视觉编码与语言接入实践](16-视觉编码与语言接入实践.md)按输入/读出→图文梯度→query或外部媒体桥接→多图序列训练→动态尺寸与packing→预算→时空位置展开。先读03的双塔与05的ViT，再根据问题进入16；做文档证据回08，做视频时间定位回09。

16新增八个CPU程序，核对数值、实际梯度和失败条件；第10节给50项原练习的计算答案或评价判据，真实模型/论文整表实验未实做的题明确说明。它是知识主题入口；统一生成与应用合同接下表。Phase12二十五课的逐项覆盖、程序与整体验收以[本批验收](../../维护/五站吸收/12-多模态批次验收.md)为准，整站和五站范围见五站进度。
