## 为什么单独做专题

现有 AI 算法主干已经覆盖通用数学、机器学习、深度学习和图学习，但对“模型如何处理图像、声音、多模态输入和真实世界动作”缺少完整横向结构。

本专题补齐：

```text
视觉
→ 语音/音频
→ 多模态表征与生成
→ 机器人/自动驾驶/自主系统
```
