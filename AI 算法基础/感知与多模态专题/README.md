## 为什么单独做专题

现有 AI 算法主干已经覆盖通用数学、机器学习、深度学习和图学习，但对“模型如何处理图像、声音、多模态输入和真实世界动作”缺少完整横向结构。

本专题补齐：

```text
视觉
→ 语音/音频
→ 多模态表征与生成
→ 机器人/自动驾驶/自主系统
```

## 视觉的详细学习路线

先修是矩阵与张量形状、概率/损失、反向传播和最小训练循环，可从[前向反向与损失](../深度学习专题/16-前向反向与损失实现.md)及[张量框架与模型调试](../深度学习专题/18-张量框架与模型调试.md)补齐。先把像素、坐标和标签对齐，再选输出任务。

| 学习目标 | 主要维护入口 | 可核对的学习结果 |
|---|---|---|
| 正确读图并训练表征 | [05 图像表征、卷积与视觉训练](./05-图像表征卷积与视觉训练.md)；经典结构接[卷积神经网络](../深度学习专题/02-卷积神经网络与经典架构.md) | 能说明HWC/CHW、颜色/范围、卷积输出与参数；训练/验证变换分开；冻结参数、BN状态和部署测量各自有检查 |
| 无标签学习和相似图检索 | [06 自监督视觉与检索学习](./06-自监督视觉与检索学习.md) | 能构造正负样本、解释温度/坍缩；区分Hit@K与Recall@K，排除自匹配及同源泄漏 |
| 找到对象、像素和时序身份 | [07 检测、分割、姿态与跟踪](./07-检测分割姿态与跟踪.md) | 能从框/掩码/热图/轨迹计算指标，处理空集、边界与匹配；检测成功不直接推出跟踪身份正确 |
| 文档、开放词汇和视觉服务 | [08 OCR、视觉语言与可靠管道](./08-OCR视觉语言与可靠管道.md) | 能解释CTC对齐、图文匹配与视觉语言输入；完成坐标/数据合同的失败例检查，给出拒答与错误定位依据 |
| 图像生成和视频时序 | [09 视觉生成与视频时序](./09-视觉生成与视频时序.md)；通用机制接[深度生成模型](../深度学习专题/10-深度生成模型.md) | 能推演一个噪声/速度更新，说明条件引导、潜空间与时序假设；小去噪程序、完整模型与真实质量分别评价 |
| 从相机像素到三维表示 | [10 几何、深度与三维表示](./10-几何深度与三维表示.md) | 能算投影/反投影与单位，区分相对深度/米制深度，解释NeRF与Gaussian Splatting的表示、可见性及计算边界 |

05是共同基础，06～10按当前问题选择。需要做检测服务时走05→07→08；需要做图像检索时走05→06；需要理解生成与空间表示时先读生成机制，再选09或10。完整程序的输入、断言和限制在各章，练习答案用于核对思路，不是必须完成所有方向的清单。

## 选择入口与学习边界

01～04是领域入口，05～10是视觉深化，可按需要选读，不构成必须依次完成的职业路线。视觉先学输出粒度与标签；音频先学采样率与对齐；多模态先学配对与评估；机器人先学坐标、单位与反馈。

通过标准是能完成所选章节的小例子并指出失败条件。CPU几何/梯度/匹配检查不代表已经训练真实视觉大模型；官方API核对不代表模型在当前设备可用。音频、机器人等领域尚未在本批做同等深度扩展，实机集成与真实任务评估也未运行。来源与本批实际验证见[五站进度](../../维护/五站吸收/进度与续接.md)。
