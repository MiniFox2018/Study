# 06｜自监督视觉与检索学习

> 先修：[图像/视觉训练](05-图像表征卷积与视觉训练.md)、[稳定损失与InfoNCE梯度](../深度学习专题/16-前向反向与损失实现.md)、[距离与ANN](../数学与数值计算专题/05-范数距离与相似性.md)。本章建立“图像→表示→训练目标→检索协议”的统一链；先懂样本关系和完整分母，再学teacher/MAE和检索评价。所有程序仅用本地NumPy/PyTorch合成输入，没有下载视觉模型或公开图像集。

## 1. 表示的用途决定什么信息应该保留

自监督用数据自身构造目标，例如两次增强的同一图、遮挡后的原像素、跨视图teacher分布。它减少外部标签需求，但数据清洗、去重、增强设计、算力和下游验证仍有成本；不保证未标注数据越多越好。

图像分类要类间可分；实例检索要同一物品的不同视图靠近、外观类似的不同物品仍可区分；重复检测又关心内容/编辑一致性。类别标签可把所有猫拉一起，却未必能区分具体两只猫。不能先选一个预训练型号，再让业务“相似”迁就模型。

读一个表示时记录：输入预处理、编码器版本、读出层（CLS/patch平均/多层）、投影头是否保留、向量维度、归一化、距离定义。自监督projection space不一定是下游最佳特征空间；MAE decoder通常移除，SimCLR常用encoder表示，DINO的分类prototype分布也不同于直接embedding。

图像-only模型可做图像间比较，却不自动有文本查询能力。文本/图像须共享训练过的空间，CLIP/SigLIP这类对齐方法的机制见[多模态学习](03-多模态学习.md)；不能把任意文本向量与DINO式图像向量因维数相同就相乘。

## 2. 对比学习：正对、候选与温度要一起定义

SimCLR通常让同一图两种增强经共享encoder/projection后靠近，将batch中其他图的视图作为候选负例。N个原图有2N视图，anchor排除自己，分母包含其正对及其他2N-2负例：

$$
\ell_{i,j}=-s(z_i,z_j)/\tau+\log\sum_{k\ne i}\exp(s(z_i,z_k)/\tau),\qquad\tau>0.
$$

两个方向都算、再按2N平均。候选可能包含同类/近重复假负例，要按任务判断能否接受。归一化内积是cosine；批量/队列变化改变负例构成与任务难度，**没有batch32必失败、batch512必成功的理论门槛**。MoCo用动量encoder/旧特征队列提供更多候选，但要管理时间滞后和队列一致性，不是无代价扩大数据。

完整原始embedding归一化链和手推VJP在[深度16第9节](../深度学习专题/16-前向反向与损失实现.md)维护。这里补两视图批处理与可验证反例：温度低会突出相似度差，正对明显领先时可降低loss，错正对可能升高；所有候选同分才是精确$\log(2N-1)$基线。随机向量的有限维/温度相似度并非完全同分，loss不必恰好log(2N-1)。

```python
import torch
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(42)
def info_nce(z1,z2,temperature=0.2):
    if z1.shape!=z2.shape or z1.ndim!=2 or len(z1)<2 or temperature<=0:
        raise ValueError("需要至少两对同形状二维embedding及正温度")
    z = torch.cat([z1,z2],0)
    if not torch.isfinite(z).all() or (z.norm(dim=1)==0).any(): raise ValueError("embedding须有限非零")
    z = F.normalize(z,dim=1);n = len(z1)
    logits = z@z.T/temperature
    logits = logits.masked_fill(torch.eye(2*n,dtype=torch.bool),float("-inf"))
    target = torch.cat([torch.arange(n,2*n),torch.arange(n)])
    return F.cross_entropy(logits,target)

# 同一合成小图的独立视图；翻转是否合法取决于任务，本例只演示形状。
images = torch.rand(8,3,8,8)
def view(x):
    out = x.flip(-1) if torch.rand(())<0.5 else x.clone()
    return (out+0.02*torch.randn_like(out)).clamp(0,1)
first,second = view(images),view(images)
print("两视图形状",first.shape,second.shape)
encoder = torch.nn.Sequential(torch.nn.Flatten(),torch.nn.Linear(3*8*8,16))
loss = info_nce(encoder(first),encoder(second));loss.backward()
assert encoder[1].weight.grad is not None
same = F.normalize(torch.randn(8,16),dim=1)
random = F.normalize(torch.randn(8,16),dim=1)
for temperature in [.05,.1,.2,.5]:
    print("温度",temperature,"相同对/随机对loss",round(info_nce(same,same,temperature).item(),4),
          round(info_nce(same,random,temperature).item(),4))
collapsed = torch.ones(8,16)
assert torch.allclose(info_nce(collapsed,collapsed),torch.log(torch.tensor(15.)))
print("完全坍缩loss=log15，不是0")
```

这段只验证构造/反向和相似度条件，不把随机encoder的loss称作有用视觉特征。两视图的随机crop、颜色扰动、灰度、blur等需保留任务关联：crop裁掉唯一目标、颜色定义类别时乱颜色，都可能破坏“同一语义”。增强图的复制数不等于独立新标签数据。

## 3. 非对比teacher/student：stop-gradient、EMA与中心缓冲分工

DINO式student预测teacher跨视图分布，teacher参数用student的EMA而非直接梯度：$\theta_T\leftarrow m\theta_T+(1-m)\theta_S$。teacher目标常为 $softmax((v_T-c)/\tau_T)$，student用 `log_softmax(v_S/τS)`，中心c通过**原始teacher logits**的批均值EMA更新；两种动量和两个温度不同。

teacher stop-gradient避免把目标本身随student损失共同即时优化，EMA平滑目标；centering降低单一prototype长期占据的偏好，sharpening避免过度均匀目标。它们是与数据、增强、头归一化、调度等共同作用的机制，**不能承诺加中心就绝不坍缩、去中心几轮必坍缩**。源DinoHead用同一个投影对象作两路，并未实现独立EMA teacher，属于中心演示，不是完整DINO。

下面完整CPU程序用小向量模拟多视图输出，确实持有独立teacher和center buffer，核对teacher无梯度、EMA算式和center更新。它没有多尺度crop、真实视觉encoder或完整DINO训练配方，不作为论文复现。

```python
import copy
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(42)
student = nn.Sequential(nn.Linear(8,16),nn.GELU(),nn.Linear(16,6))
teacher = copy.deepcopy(student).eval()
for p in teacher.parameters(): p.requires_grad_(False)
centre = torch.zeros(1,6)
optimizer = torch.optim.SGD(student.parameters(),lr=0.02)
base = torch.randn(12,8)
for step in range(8):
    first,second = base+0.05*torch.randn_like(base),base+0.05*torch.randn_like(base)
    with torch.no_grad():
        raw1,raw2 = teacher(first),teacher(second)
        target1 = F.softmax((raw1-centre)/0.04,dim=1)
        target2 = F.softmax((raw2-centre)/0.04,dim=1)
    pred1,pred2 = F.log_softmax(student(first)/0.1,dim=1),F.log_softmax(student(second)/0.1,dim=1)
    loss = -((target1*pred2).sum(1).mean()+(target2*pred1).sum(1).mean())/2
    optimizer.zero_grad(set_to_none=True);loss.backward();optimizer.step()
    old = [p.detach().clone() for p in teacher.parameters()]
    with torch.no_grad():
        for t,s in zip(teacher.parameters(),student.parameters()): t.mul_(0.9).add_(s,alpha=0.1)
        centre.mul_(0.9).add_(torch.cat([raw1,raw2]).mean(0,keepdim=True),alpha=0.1)
    assert all(p.grad is None for p in teacher.parameters())
    assert all(torch.allclose(t,.9*before+.1*s) for t,before,s in zip(teacher.parameters(),old,student.parameters()))
    print("步骤",step,"loss",round(loss.item(),4),"teacher平均分布熵",
          round((-(target1.mean(0)*target1.mean(0).clamp_min(1e-12).log()).sum()).item(),4))
print("center buffer",centre.round(decimals=4))
```

判断坍缩应同时看逐样本输出熵、跨样本平均分布、embedding方差/协方差与下游probe；单一平均中心变化不足以证明学得语义。低loss也可能teacher已输出常数。BYOL、MoCo、DINO虽有动量组件，预测目标/负例/防坍缩策略不相同，不能只按“都有EMA”互换。

## 4. MAE：昂贵encoder只看可见patch，decoder负责恢复坐标

典型MAE把图切patch，随机遮掉较大比例，encoder仅处理可见patch；轻decoder补mask tokens和位置，在被遮位置预测像素。原方法75%是自然图/ViT实验里的有效选择，不是视觉恒定信息熵定律，也不是所有masked方法都遮75%。BERT的15%属于不同目标/配方，不能由这两个数字断言邻像素几乎决定所有内容。

masked-only MSE应按真实被遮patch数平均；可选目标按每patch均值/方差归一化，需明确其含义。encoder没有处理mask token，不代表总计算严格减少4倍：attention随token数二次变，而decoder/投影仍有成本。reconstruction可能学低级纹理，是否有可迁移语义要另验probe/dense任务。

完整CPU小MAE如下：16×16图、4×4patch、每图独立mask；先核对patchify/unpatchify，再做可见encoder、mask恢复和masked-only反向。十步只用于检查计算/更新，不证明已预训练有用特征。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(42)
class TinyMAE(nn.Module):
    def __init__(self,image=16,patch=4,dim=24):
        super().__init__();self.image,self.patch,self.count = image,patch,(image//patch)**2
        self.embed = nn.Linear(3*patch*patch,dim)
        self.pos_encoder = nn.Parameter(torch.randn(1,self.count,dim)*.02)
        self.pos_decoder = nn.Parameter(torch.randn(1,self.count,dim)*.02)
        self.mask_token = nn.Parameter(torch.randn(1,1,dim)*.02)
        layer = lambda: nn.TransformerEncoderLayer(dim,3,dim_feedforward=dim*2,dropout=0,
                                                   batch_first=True,norm_first=True)
        self.encoder = nn.TransformerEncoder(layer(),1,enable_nested_tensor=False)
        self.decoder = nn.TransformerEncoder(layer(),1,enable_nested_tensor=False)
        self.predict = nn.Linear(dim,3*patch*patch)
    def patches(self,x): return F.unfold(x,kernel_size=self.patch,stride=self.patch).transpose(1,2)
    def forward(self,x,ratio=.75,generator=None):
        if x.ndim!=4 or x.shape[1]!=3 or tuple(x.shape[-2:])!=(self.image,self.image):
            raise ValueError("本例要求固定方形RGB网格，不能只按patch数判兼容")
        target = self.patches(x);batch,length,_ = target.shape
        keep = int(length*(1-ratio))
        if length!=self.count or not 1<=keep<length: raise ValueError("图像或mask比例不兼容")
        perm = torch.rand(batch,length,generator=generator).argsort(1)
        visible = perm[:,:keep]
        token = self.embed(target)+self.pos_encoder
        encoded = self.encoder(token.gather(1,visible[:,:,None].expand(-1,-1,token.shape[-1])))
        restored = self.mask_token.expand(batch,length,-1).clone()
        restored = restored.scatter(1,visible[:,:,None].expand(-1,-1,encoded.shape[-1]),encoded)
        prediction = self.predict(self.decoder(restored+self.pos_decoder))
        mask = torch.ones(batch,length,dtype=torch.bool).scatter(1,visible,False)
        per_patch = (prediction-target).square().mean(-1)
        loss = per_patch[mask].mean()
        return loss,mask,encoded
model = TinyMAE();x = torch.rand(4,3,16,16)
patches = model.patches(x)
roundtrip = F.fold(patches.transpose(1,2),output_size=(16,16),kernel_size=4,stride=4)
assert torch.equal(x,roundtrip)
optimizer = torch.optim.Adam(model.parameters(),lr=.003)
for step in range(10):
    loss,mask,encoded = model(x,generator=torch.Generator().manual_seed(step))
    optimizer.zero_grad(set_to_none=True);loss.backward();optimizer.step()
    assert mask.sum(1).eq(12).all() and encoded.shape==(4,4,24)
    assert model.embed.weight.grad is not None and torch.isfinite(loss)
    if step in [0,9]: print("步骤",step,"mask数",mask.sum(1).tolist(),"可见token",encoded.shape,"重建loss",round(loss.item(),5))
```

坐标恢复必须使用同一mask/visible索引，把第一个可见token误放原序列首位就错；原图像shape和patch内通道顺序也要匹配。UNet遮像素重建是可以研究的另一预任务，不是原MAE的稀疏ViT encoder结构。decoder丢弃后，encoder特征提取方式/CLS或池化、目标预处理与下游训练仍需定义。

这个机制例为降低代码复杂度让encoder/decoder同宽、各一层，未模拟论文“小decoder每token计算量”的比例；它验证可见token、位置恢复和masked-only loss，不能把本例十步时间称为原方法3倍加速实验。

## 5. Linear probe是条件明确的下游评价，不是“纯特征质量”绝对值

冻结encoder参数/合适状态，用标注训练集拟合单个Linear；验证选择LR/轮次，最终测试冻结。缓存特征可省重复计算，但如果每轮需要重新随机训练增强，缓存一次的协议和在线增强协议不同，需报告。encoderBN默认eval，头训练模式独立，特征/标签必须在同一设备批送。

结果同时受输入分辨率、预处理、取特征层、归一化、标注与划分、头优化器/搜索预算影响；不同论文的probe数字不能当永久型号排名。训练过线性头是有监督评价，不叫zero-shot分类；直接未微调图像embedding检索可称没有下游训练的检索，但仍要说明对比协议。

下面完整CPU例用固定合成特征隔离probe的状态与选择；验证选快照，最终测试一次。可将特征替换为冻结图像encoder输出，本例不虚称已评价某预训练视觉模型。

```python
import copy
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(42)
prototypes = torch.randn(3,8)
labels = torch.arange(3).repeat_interleave(40)
features = prototypes[labels]+0.3*torch.randn(120,8)
order = torch.randperm(120);train,valid,test = order[:80],order[80:100],order[100:]
head = nn.Linear(8,3);optimizer = torch.optim.SGD(head.parameters(),lr=.1)
best,state = float("inf"),None
for epoch in range(100):
    head.train();loss = F.cross_entropy(head(features[train]),labels[train])
    optimizer.zero_grad(set_to_none=True);loss.backward();optimizer.step()
    head.eval()
    with torch.no_grad(): value = F.cross_entropy(head(features[valid]),labels[valid]).item()
    if value<best: best,state = value,copy.deepcopy(head.state_dict())
head.load_state_dict(state);head.eval()
with torch.no_grad(): accuracy = (head(features[test]).argmax(1)==labels[test]).float().mean().item()
print("验证选中CE",round(best,4),"最终合成特征测试准确率",accuracy)
```

若pretraining随机切分看到了测试图/同场景近重复，也可能有评估泄漏，即使没用测试标签。是否允许transductive无标签数据参与预训练，必须事先声明；不能让“自监督”成为忽略数据边界的理由。

## 6. 度量学习：对比、Triplet和代理目标的区别

pairwise contrastive的一种形式：同类对优化$\|a-p\|^2$，异类对优化$\max(0,m-\|a-n\|)^2$；y编码必须注明。Triplet对相对排序优化$\max(0,d(a,p)-d(a,n)+m)$；InfoNCE同时在多个候选中作概率排名；proxy类方法引入可学习类代表避免枚举全部样本对。不同目标可组合，但需明确权重/收益，不能机械规定绝不能组合或instance任务必须Triplet。

源正文用平方距离Triplet，代码却用未平方`pairwise_distance`，margin单位不同；必须选择一种并一致。这里选平方L2，在活跃区域对a/p/n的导数分别$2(n-p),2(p-a),2(a-n)$，见深度16。归一化后平方L2范围[0,4]；非平方范围[0,2]。不同数值margin不能直接比较。

semi-hard要求 $d_{ap}<d_{an}<d_{ap}+m$，选其中较近负例；batch-hard通常选最远同类正例/最近异类负例。类里只有anchor，不能让全负无穷矩阵argmax到某个异类“positive”；应跳过或用P类×K样本的平衡批。没有有效半难负例时明确skip或hard/easy fallback，不能把fallback也叫semi-hard。

下面完整CPU玩具学习用人工特征隔离损失和挖掘。平衡批每类至少3样本，训练Triplet与包含正proxy分母的proxy-softmax对照；后者是常用代理分类基线，不声称逐项复刻原ProxyNCA/ProxyAnchor论文目标。最终只评预定两方案，同一人工类关系不证明真实物品检索效果。

```python
import copy
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(42)
centres = F.normalize(torch.randn(4,12),dim=1)
def sample(per_class):
    labels = torch.arange(4).repeat_interleave(per_class)
    data = centres[labels]+.15*torch.randn(len(labels),12)
    return data,labels
class Encoder(nn.Module):
    def __init__(self):
        super().__init__();self.net = nn.Sequential(nn.Linear(12,24),nn.ReLU(),nn.Linear(24,6))
    def forward(self,x): return F.normalize(self.net(x),dim=1)
def mine(embedding,labels,margin=.3):
    distance = torch.cdist(embedding.detach(),embedding.detach()).square()
    anchors,positive,negative,used_semi = [],[],[],[]
    for i in range(len(labels)):
        pos = torch.nonzero((labels==labels[i])&(torch.arange(len(labels))!=i)).flatten()
        neg = torch.nonzero(labels!=labels[i]).flatten()
        if len(pos)==0 or len(neg)==0: continue
        p = pos[distance[i,pos].argmax()]
        eligible = neg[(distance[i,neg]>distance[i,p])&(distance[i,neg]<distance[i,p]+margin)]
        n = eligible[distance[i,eligible].argmin()] if len(eligible) else neg[distance[i,neg].argmin()]
        anchors.append(i);positive.append(int(p));negative.append(int(n));used_semi.append(bool(len(eligible)))
    return [torch.tensor(v,dtype=torch.long) for v in [anchors,positive,negative]],used_semi

initial = copy.deepcopy(Encoder().state_dict())
gallery_x,gallery_y = sample(20);query_x,query_y = sample(8)
for regime in ["triplet","proxy-softmax"]:
    torch.manual_seed(7);encoder = Encoder();encoder.load_state_dict(initial)
    proxy = nn.Parameter(torch.randn(4,6))
    optimizer = torch.optim.Adam(list(encoder.parameters())+([proxy] if regime=="proxy-softmax" else []),lr=.005)
    fallback = 0
    for step in range(120):
        x,y = sample(3);e = encoder(x)
        if regime=="triplet":
            (a,p,n),flags = mine(e,y)
            assert len(a)>0 and torch.all(y[a]==y[p]) and torch.all(y[a]!=y[n]) and torch.all(a!=p)
            loss = F.relu((e[a]-e[p]).square().sum(1)-(e[a]-e[n]).square().sum(1)+.3).mean()
            fallback += sum(not flag for flag in flags)
        else:
            loss = F.cross_entropy(e@F.normalize(proxy,dim=1).T/.2,y)
        optimizer.zero_grad(set_to_none=True);loss.backward();optimizer.step()
    encoder.eval()
    with torch.no_grad():
        scores = encoder(query_x)@encoder(gallery_x).T
        hit = (gallery_y[scores.argmax(1)]==query_y).float().mean().item()
    print(regime,"最终toy loss",round(loss.item(),5),"独立query Hit@1",round(hit,4),"fallback数",fallback)
```

难负例可能是错标签/同实例未归组，不应越难越好。原始物品/身份关系应与类标签区分，训练样本按真实组构造而不是让每个近重复都变负例。代理有参数/类覆盖成本，稀有类代理也可能训练不足；它不天然更快/更稳。

## 7. 精确检索与评价：Hit、Recall、AP以及自匹配边界

一般cosine是 $a\cdot b/(\|a\|\|b\|)$，并不是“未归一化向量不能算cosine”；**直接点积不除范数**才混入长度。单位向量有$\|a-b\|^2=2-2cos(a,b)$，排序等价；零向量无定义，先定义拒绝/回退策略。模型若按原始点积训练，是否归一化也须验证，不能永远一刀切。

- **Hit@K**：每query至少一个相关项进入top-K的0/1均值。很多图像论文把它称Recall@K，应在报告明确这一定义。
- **集合Recall@K**：相关返回数/该query全部可返回相关数，逐query平均；当每query只有1个相关项才与Hit相同。
- **Precision@K**：相关返回数/实际返回数；同样注明k越界和过滤后候选不足。
- **AP/mAP**：在相关项排名处累积precision，按相关项数归一化再逐query平均；截断AP@K有不同分母约定，不能只写一个名字。

query自身、相同文件/重复内容/同采集帧的处理按目标明确。仅同图作为query和gallery得到1.0通常只证明自匹配路径，不证明跨视角泛化；先移除self，再检查真实相关集合。无相关项query是排除后做条件评价、还是算未命中，应事先决定并报告数量，不能为提高分数默默过滤。

下方 `q_ids/g_ids`是样本或内容副本ID，用于排除同一图；`q_labels/g_labels`才是类别/相关实例ID。不要把同一物品所有不同视图都用同样self ID排除，否则真正应检索的正例也会被移走。

下方完整NumPy评测显式排self、稳定处理同分，分别返回Hit和真正集合Recall，且不让被屏蔽self以负无穷又进top-K。它按单query扫描，避免构造巨大Q×G矩阵。

```python
import numpy as np

def unit(x):
    x = np.asarray(x,float)
    if x.ndim!=2 or not np.isfinite(x).all(): raise ValueError("embedding须为有限二维矩阵")
    norm = np.linalg.norm(x,axis=1,keepdims=True)
    if (norm==0).any(): raise ValueError("零embedding无法归一化")
    return x/norm
def retrieval_metrics(q,g,q_labels,g_labels,q_ids,g_ids,ks=(1,2,5),no_match="zero"):
    q,g = unit(q),unit(g)
    q_labels,g_labels,q_ids,g_ids = [np.asarray(a) for a in [q_labels,g_labels,q_ids,g_ids]]
    if q.shape[1]!=g.shape[1]: raise ValueError("query/gallery向量维数不同")
    for values,size in [(q_labels,len(q)),(q_ids,len(q)),(g_labels,len(g)),(g_ids,len(g))]:
        if values.ndim!=1 or len(values)!=size: raise ValueError("labels/ids均须一维且逐行匹配embedding")
    if not ks or any(not isinstance(k,(int,np.integer)) or isinstance(k,bool) or k<1 for k in ks) or no_match not in {"zero","exclude"}:
        raise ValueError("ks须为非空正整数序列，no_match策略须合法")
    rows = [];missing = 0
    for i in range(len(q)):
        valid = np.flatnonzero(g_ids!=q_ids[i])
        relevant = g_labels[valid]==q_labels[i]
        total = relevant.sum()
        if total==0:
            missing += 1
            if no_match=="exclude": continue
        score = g[valid]@q[i]
        order = np.lexsort((valid,-score));rel = relevant[order]
        row = {}
        for k in ks:
            selected = rel[:min(k,len(rel))];count = selected.sum()
            row[f"Hit@{k}"] = float(count>0)
            row[f"Recall@{k}"] = float(count/total) if total else 0.
            row[f"Precision@{k}"] = float(count/len(selected)) if len(selected) else 0.
        if total:
            precision = np.cumsum(rel)/np.arange(1,len(rel)+1)
            row["AP"] = float((precision*rel).sum()/total)
        else: row["AP"] = 0.
        rows.append(row)
    result = {key:float(np.mean([r[key] for r in rows])) for key in rows[0]} if rows else {}
    return result,{"queries":len(q),"evaluated":len(rows),"no_relevant_after_filter":missing}

q = np.array([[1,0],[0,1],[1,1]],float)
g = np.array([[1,0],[.99,.1],[0,1],[.1,.99],[-1,-1]],float)
result,counts = retrieval_metrics(q,g,[0,1,2],[0,0,1,1,2],[10,20,30],[10,11,20,21,40])
print("显式排self后",result,counts)
assert np.isclose(result["Hit@1"],2/3)
# 同类有多个相关项时Hit与集合Recall不同。
result,_ = retrieval_metrics([[1,0]],[[1,0],[.9,.1],[0,1]],[0],[0,0,1],[9],[1,2,3],ks=(1,))
assert result["Hit@1"]==1 and result["Recall@1"]==.5
print("Hit1但Recall0.5的反例",result)
```

高Hit@10/低Hit@1只表示按当前标签和候选，相关项经常在前十但未排第一；可能适合reranking，也可能标签定义粗、近似索引/筛选错误或差异很难。精排不能找回候选集外相关项，也不保证@1提升且@10不变。应检查失败query、候选召回、过滤和ranking预算，再决定改encoder或加第二阶段。

## 8. ANN和版本：先建立精确基线，再讨论服务

`IndexFlatIP`/`IndexFlatL2`是精确扫描，无聚类训练；前者配单位向量就是cosine，后者通常返回平方L2。IVF先聚类并搜索选定列表，HNSW用近邻图，PQ压缩/近似距离；参数、内存和更新需求共同决定选择，没有“100k必flat、10M必IVF、100M必PQ”的通用容量表。

图像相关性评价与**ANN recall**要分开：ANN recall@K是近似结果命中精确top-K的比例，不是类别Hit@K。可以ANN recall高而语义错，也可以语义合理但不等于精确模型分数排序。数学距离专题维护具体索引结构与验收；本章补图像契约。

使用FAISS的调用形状示意如下，属于依赖库API片段而非已在本环境执行的程序：`IndexFlatIP(D)`接收一致float32向量，`add(gallery)`后 `search(query,k)`返回分数/内部行号；按训练目标归一化并映射到业务ID。零向量、维数、非连续数组、重复ID和self过滤在加索引前确认。本次未安装FAISS，不把NumPy精确扫描称作FAISS测试。

每批向量记录encoder/预处理/读出/归一化版本和数据ID；更换encoder/维度/坐标系通常需整库重编码，不能混两版本向量。新增/删除/权限过滤、分布变化、IVF/PQ训练代表性和近重复去重都会影响线上结果。返回gallery标签不等于RAG生成答案正确，检索candidate更不能代替图像任务的真实有效性。

## 9. 用已有视觉encoder时怎样核验

先读权重的官方预处理与输出定义，eval/no-grad提特征；CLS、平均patch、多尺度或中间层均须匹配目标。图像检索可比较图像-only encoder与图文encoder的图像分支；文本查询则需配套文本分支。模型名、2023论文结果或“2026最强”不能替代当前任务验证。

不微调的初始encoder、线性probe、局部/全量微调都可作预定比较；小样本新head不自动最好，instance检索也不一定必做度量微调。对整个流程报告训练/验证/query/gallery关系、checkpoint与特征版本、指标定义、距离/索引、延迟和失败样本。raw动画里聚类点按预设坐标移动，不是优化器实际训练的证据。

## 10. 自查与练习参考答案

1. 两视图与InfoNCE如何对应？**答案：**第2节拼 `[z1,z2]`，前半正例在后半同索引，排除自己，包含正例；深度16的相邻配对是另一排列，不能混用target索引。
2. 温度越低为何不总loss越高？**答案：**若正例最高，softmax更集中、loss可减；随机分数和假负例另有情况，不能固定随机loss等于log31。
3. 中心去掉是否必坍缩？**答案：**没有保证；第3节只验证机制，完整DINO还受EMA、stop-grad、头、增强和调度影响。teacher目标常数时低loss也可能坏。
4. 75%mask、encoder/decoder怎么算？**答案：**第4节16patch保留4、遮12，encoder只处理4token，decoder补回16并只对12遮挡patch算MSE；计算降低不等于固定3倍速度。
5. 线性probe是无标签或zero-shot吗？**答案：**头用了标注训练，并不是zero-shot分类；冻结encoder也不自动给完全公平的跨论文比较。第5节验证选快照/最终测试。
6. Triplet的有效正负与margin怎么检查？**答案：**每类≥2或跳过singleton，正例非self且同目标标签，负例异目标；第6节平方距离和margin一致，明确fallback计数。
7. Proxy类损失是不是原ProxyNCA公式？**答案：**代理思想相同不代表分母/归一化完全相同；本章实现包含正类分母的proxy-softmax教学基线，比较同任务指标而不冒充论文实现。
8. 同图query/gallery为何不能证明检索好？**答案：**可能只命中自身，先剔self/重复，再定义相关集；第7节演示Hit1却Recall0.5，且无相关query按预定规则计数。
9. 用PCA看六簇怎样验证？**方法：**投影仅可视化、可能丢原空间关系；还要独立query/gallery的Hit/Recall/AP、类内/类间距离和多个种子。不能把源动画或“簇看起来形成”当实测。
10. 是否已完成公开图像SSL/FAISS验收？**答案：**没有。本批完整CPU机制与合成特征训练已按记录验证，公开数据/预训练权重/FAISS/GPU/大规模训练均未执行；资料保留的是实现原理和可继续的评价协议。
