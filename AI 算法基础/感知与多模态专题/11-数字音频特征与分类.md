# 11｜数字音频特征与分类

先把采样率、幅度和通道搞清楚，再谈音频特征。DFT、复数频率坐标、Parseval、泄漏和 STFT的通用推导见[复数傅里叶专题](../数学与数值计算专题/09-复数傅里叶与频域理解.md)，本章重点是音频输入契约、可重复的特征和分类实验。所有信号人为合成，不录音、不播放，不把合成分类成绩当真实声音识别能力。

## 1. 样本、秒、通道和位深

采样率 $f_s$ 是每秒每通道采样次数，长度 $N$ 对应 $N/f_s$ 秒。2秒16kHz单声道16-bit PCM裸数据为 $2×16000×2=64000$ 字节；双声道翻倍，WAV容器头和压缩流另算。采样率不是FFT长度，位深也不是神经特征维数。

int16取值为 $[-32768,32767]$，共65536级，不是对称±32767。映射成归一浮点可用除32768，使负满量程为-1、正端略小于1。8-bit WAV PCM常用无符号uint8，中心在128；24-bit PCM的存储/左对齐约定取决于库。float32有约24-bit有效二进制精度，但指数让可表示范围远大于[-1,1]，不能把float32说成只有固定65536或某个统一“音频级数”。内部DSP浮点可暂时超过1，文件类型和模型输入范围需单独检查。

常见数组契约有 `(samples,)`、`(samples,channels)`、`(channels,samples)`；明确轴再做平均，不能猜。双声道均值可消掉反相分量；选左声道会丢右路信息，多通道模型可能需要保留阵列结构。合成反相双声道时平均得到零，这是信号含义，不是正确降噪或总能量保持。

8/16/24/44.1/48kHz只是常见任务设置：电话带宽、某些语音模型输入、音乐/制作协议不同。低采样率音频仍可做窄带识别，不能一律“禁止8kHz ASR”；模型所需采样率、声道和前端参数按其训练配置确认。改文件头不等于重采样。

### 1.1 完整PCM16读写和输入验证

此加载器刻意只支持未压缩PCM16 WAV，遇其他格式明确拒绝，不伪装万能加载器。临时文件仅用于数值往返，未播放。

```python
import numpy as np
import wave
import tempfile
from pathlib import Path

def validate_audio(x,sr):
    a=np.asarray(x)
    if isinstance(sr,bool) or not isinstance(sr,int) or sr<=0:
        raise ValueError('采样率为正整数Hz')
    if a.ndim not in (1,2) or a.shape[0]==0 or (a.ndim==2 and a.shape[1]==0):
        raise ValueError('非空样本×通道或单声道数组')
    if not np.issubdtype(a.dtype,np.floating) or not np.isfinite(a).all():
        raise ValueError('先显式解码整数PCM；拒绝NaN/Inf')
    return a.astype(np.float64,copy=False)

def write_pcm16(path,x,sr):
    a=validate_audio(x,sr)
    if np.max(np.abs(a))>1:
        raise ValueError('保存前选择增益/限幅策略，不能静默clip')
    channels=1 if a.ndim==1 else a.shape[1]
    pcm=np.clip(np.rint(a*32768),-32768,32767).astype('<i2')
    with wave.open(str(path),'wb') as f:
        f.setnchannels(channels);f.setsampwidth(2);f.setframerate(sr)
        f.writeframes(pcm.tobytes(order='C'))

def read_pcm16(path):
    with wave.open(str(path),'rb') as f:
        if f.getcomptype()!='NONE' or f.getsampwidth()!=2:
            raise ValueError('教学加载器仅支持未压缩PCM16')
        sr,c,n=f.getframerate(),f.getnchannels(),f.getnframes()
        raw=f.readframes(n)
    if len(raw)!=n*c*2:
        raise ValueError('PCM字节长度与帧/通道不一致')
    x=np.frombuffer(raw,dtype='<i2').astype(np.float64).reshape(n,c)/32768
    return validate_audio(x[:,0] if c==1 else x,sr),sr

sr=16000;t=np.arange(sr//10)/sr;x=.4*np.sin(2*np.pi*1000*t)
with tempfile.TemporaryDirectory() as d:
    p=Path(d)/'synthetic.wav';write_pcm16(p,x,sr);y,rate=read_pcm16(p)
    assert rate==sr and y.shape==x.shape and np.max(np.abs(x-y))<=1/65536+1e-12
    print('PCM往返',len(x),'采样点','最大误差',float(np.max(np.abs(x-y))))
    stereo=np.column_stack([x,-x]);write_pcm16(p,stereo,sr);z,_=read_pcm16(p)
    assert z.shape==(len(x),2) and np.allclose(z.mean(axis=1),0)
print('uint8示例转换',(np.array([0,128,255],dtype=np.uint8).astype(float)-128)/128)
```

通用库如soundfile可读多种格式；其默认dtype不等于float32，若模型要求float32应明确指定，并检查立体声返回形状。库/API和后端支持按版本核验，不复制旧接口或宣称某库永远最快。流式输入另需缓冲、设备时钟和掉帧协议，本次不访问麦克风设备。

## 2. 振幅、RMS、DC与dB不能混用

DC均值 $\mu=\frac1N\sum x[n]$，信号均方 $P=\frac1N\sum x[n]^2$，RMS=$\sqrt P$，峰值=$\max|x[n]|$。正弦幅度A的整周期RMS为 $A/\sqrt2$；RMS不是能量，离散能量是样本平方和，若近似物理时间积分还要乘采样间隔并说明单位。

归一波形的幅度dBFS可定义 $20\log_{10}(RMS/1)$，功率定义 $10\log_{10}(P/1)$等价。满幅正弦RMS约-3.0103dBFS；某些计量标准采用“满幅正弦RMS=0”的参照，比较前说明约定。声压级dB SPL参照空气中20µPa，还需传感器灵敏度和校准；不能由未校准浮点样本直接得到。

```python
import numpy as np
x=.5*np.sin(2*np.pi*1000*np.arange(16000)/16000)
mean=float(x.mean());rms=float(np.sqrt(np.mean(x*x)));peak=float(np.max(np.abs(x)))
db=20*np.log10(rms) if rms>0 else -np.inf
assert np.isclose(rms,.5/np.sqrt(2)) and np.isclose(db,-9.0308998699)
print('DC/RMS/peak/dBFS',mean,rms,peak,float(db))
# RMS增益会把峰放大，需要同时检查，不能因目标RMS合法就静默削波。
target=10**(-6/20);gain=target/rms;scaled=x*gain
print('RMS归一目标-6dBFS，峰值',float(np.max(np.abs(scaled))))
assert abs(np.mean(scaled*scaled)-target**2)<1e-12
```

峰值归一、RMS归一、响度归一解决不同目标；数字满幅、削波比例、DC偏置和静音都应记录。`abs(x)>.999`不是所有音频的“确定削波”，它也可能是合法高峰；持续贴顶、波形/文件量化规则和模型要求更有判断力。静音不能除以零做增益；去DC可改变低频信息，不能无条件清洗。

## 3. 重采样先滤波，插值不恢复丢失内容

将 $f_{old}$ 换成 $f_{new}$，先按新旧Nyquist较小值限制带宽，再在新采样时刻取值。整数抽取前需要抗混叠，升采样也需要插值/重建滤波以抑制镜像，不存在“超过2倍才需要滤波”的门槛。模拟ADC之前就混叠的成分不能靠数字重采样恢复。

频率f在新采样率下可折叠为 $|((f+f_s/2)\bmod f_s)-f_s/2|$。24kHz的7kHz降到8kHz若只取每三点，会成为1kHz伪分量；正弦还要考虑折叠相位，不能声称原样仍是7kHz。

```python
import numpy as np
from scipy.signal import resample_poly
from math import gcd
old,new=24000,8000
x=.5*np.sin(2*np.pi*7000*np.arange(old)/old)
naive=x[::3]
g=gcd(old,new);proper=resample_poly(x,new//g,old//g)
assert len(proper)==new
# 排除边缘滤波瞬态后比均方；不是声压/真实录音比较。
rms=lambda a:float(np.sqrt(np.mean(a*a)))
a,b=rms(naive[100:-100]),rms(proper[100:-100])
f=np.fft.rfftfreq(len(naive),1/new)[np.argmax(np.abs(np.fft.rfft(naive)))]
print('naive伪峰Hz',float(f),'两者内部RMS',a,b)
assert f==1000 and b<a/100
```

polyphase FIR以有理采样比实现；滤波长度/过渡带、边缘补法、输出长度和延迟都要考虑。幅度、物理时间和采样率元数据要一起更新，分类标签的音高/时长是否随增广改变也要说明。

## 4. 音频前端的参数与形状契约

设窗长L、hop H、FFT长度K≥L。无补边的完整帧数为 $1+\lfloor(N-L)/H\rfloor$（N≥L），否则0。10秒16kHz、L400/H160共有998帧；K400的实数FFT有201个非负频率bin，不是200。K1024有513个，含DC和偶数K的Nyquist。FFT不要求长度是2次幂，某种radix-2实现才有此限制。

窗长决定真实观测时长与主瓣宽；仅增加FFT零填充只让频率网格更密，不增加真实分辨率。Hann减少旁瓣泄漏并非完全消灭泄漏，Hamming端点不为零。对称窗与周期窗定义不同；标定功率谱/PSD时需考虑窗能量，幅度峰值另需coherent-gain。详推在数学09，本章特征固定约定并可复算。

对空/短音频选择拒绝、补边或返回零帧，必须明确；不能索引不存在的第一帧。补零、反射和复制边界并不等价。对称补边不自动消除数据泄漏，复制也可制造虚假的稳定声音；无效帧用长度mask排除统计和池化，训练/推理保持一致。

## 5. Mel、log-mel、MFCC与听觉滤波

下面选HTK风格 $m=2595\log_{10}(1+f/700)$，逆 $f=700(10^{m/2595}-1)$。还有Slaney等约定，默认库配置可能不同。Mel是感知频率尺度，近似低频线性/高频对数，不能把“频率加倍听起来等距”的音乐音程对数关系完全当作Mel定义。

在Mel轴上等距放 $M+2$ 个节点，转Hz后构建M个三角滤波器。第m带由左/中/右节点定义上升与下降权重，以实际FFT频率坐标取值，避免将节点取整到同一bin后产生空带。Mel矩阵B形状 $M×(K/2+1)$，非负功率谱P形状 $frames×bins$，$E=PB^T$。

可以对幅度或功率加权，但两者不是同一特征：$\sum B|X|$的平方不等于 $\sum B|X|^2$。本章固定原始FFT系数平方的功率读数（不声称带物理单位PSD）、不做面积归一HTK三角带，再 $\ln\max(E,\epsilon)$。每个模型还需明确功率次方、log底数、floor/动态范围、mel标度、滤波器面积归一及均方归一化；“80log-mel都是统一输入”不成立。

MFCC对log-mel做DCT-II，保留低阶系数，常见正交化定义：

$$c_k=a_k\sum_{m=0}^{M-1}L_m\cos[\pi k(m+.5)/M],\quad a_0=\sqrt{1/M},\ a_{k>0}=\sqrt{2/M}.$$

来源程序未乘 $a_k$，是未归一教学DCT；与库正交DCT数值不同。$c_0$是各log频带之和的缩放，不自动等于波形总能量的log；是否保留/替换它由模型配置决定，不一律丢弃。DCT本身是固定正交变换，不保证任何数据统计独立；低阶概括平滑谱包络，也不保证完全去掉音高和噪声。

Delta可用 $\Delta c_t=\sum_{i=1}^R i(c_{t+i}-c_{t-i})/[2\sum i^2]$，边界按复制等规则明确。delta-delta再应用一次，增加动态信息，不是简单把最后一帧和第一帧相减。

Gammatone是听觉滤波器族，典型脉冲响应 $a t^{n-1}e^{-2\pi bt}\cos(2\pi f_ct+\phi)$，带宽可依ERB尺度选择；不等同Mel三角频带或随意高斯权重。需要使用时可核对SciPy的gammatone FIR/IIR实现及参数，本批不把未出现的gammatone实现冒充原站完整内容。

### 5.1 完整前端、DCT和动态特征

本程序明确选择无补边、周期Hann、K=L、HTK三角带、不做面积归一、功率及自然log。短音频可补到一帧，但有效长度另留给上层，不将补边帧当真实观测。

```python
import numpy as np
from scipy.fft import dct

def frontend(x,sr=8000,L=256,H=128,M=24,C=13,pad_short=False):
    x=np.asarray(x,dtype=float)
    if x.ndim!=1 or not len(x) or not np.isfinite(x).all():
        raise ValueError('非空有限单声道')
    if any(isinstance(v,bool) or not isinstance(v,int) for v in [sr,L,H,M,C]) or sr<=0 or L<2 or H<=0 or not 1<=C<=M:
        raise ValueError('参数契约错误')
    if len(x)<L:
        if not pad_short:raise ValueError('音频短于窗')
        x=np.pad(x,(0,L-len(x)))
    start=np.arange(0,len(x)-L+1,H)
    frame=x[start[:,None]+np.arange(L)]
    window=.5-.5*np.cos(2*np.pi*np.arange(L)/L)
    X=np.fft.rfft(frame*window,axis=1);P=np.abs(X)**2
    f=np.fft.rfftfreq(L,1/sr)
    edge=700*(10**(np.linspace(0,2595*np.log10(1+(sr/2)/700),M+2)/2595)-1)
    B=np.empty((M,len(f)))
    for m in range(M):
        a,b,c=edge[m:m+3]
        B[m]=np.maximum(0,np.minimum((f-a)/(b-a),(c-f)/(c-b)))
    if (B.sum(axis=1)==0).any():
        raise ValueError('空Mel带：减少M/提高实际观测FFT网格并检查配置')
    E=P@B.T;logmel=np.log(np.maximum(E,1e-10))
    mfcc=dct(logmel,type=2,norm='ortho',axis=1)[:,:C]
    return logmel,mfcc,start/sr,B

def delta(c,R=2):
    c=np.asarray(c,dtype=float)
    if c.ndim!=2 or not len(c) or c.shape[1]<1 or not np.isfinite(c).all() or not isinstance(R,int) or isinstance(R,bool) or R<1:
        raise ValueError('非空帧×系数与正整数R')
    padded=np.pad(c,((R,R),(0,0)),mode='edge')
    return sum(i*(padded[R+i:R+i+len(c)]-padded[R-i:R-i+len(c)])
               for i in range(1,R+1))/(2*sum(i*i for i in range(1,R+1)))

sr=8000;t=np.arange(4000)/sr;x=.5*np.sin(2*np.pi*1000*t)
lm,c,times,B=frontend(x)
assert lm.shape==(30,24) and c.shape==(30,13)
assert np.isfinite(lm).all() and np.all(B>=0)
# 与定义的正交DCT手算核对一个帧。
M=lm.shape[1];D=np.cos(np.pi*np.arange(M)[:,None]*(np.arange(M)+.5)/M)
D*=np.r_[np.sqrt(1/M),np.repeat(np.sqrt(2/M),M-1)][:,None]
assert np.allclose(D@D.T,np.eye(M))
assert np.allclose(lm[0]@D[:13].T,c[0])
d=delta(c);dd=delta(d);assert d.shape==dd.shape==c.shape
print('logmel/MFCC/delta形状',lm.shape,c.shape,d.shape)
print('滤波器非零宽度',(B>0).sum(axis=1).tolist())
# 原始功率的dB参照必须明确，静音floor不作实际有限声压。
E=np.exp(lm);db=10*np.log10(np.maximum(E,1e-10)/E.max())
assert np.isclose(db.max(),0)
print('ref=max功率dB范围',float(db.min()),float(db.max()))
```

$10\log_{10}P$与 $20\log_{10}|X|$仅对同一幅度/功率及参照等价；log-mel是先频带汇总再log，不等于先log逐频点再加权。`ref=max`对每段去掉全局增益，固定参照保留相对幅度信息，不能未经训练适配任意替换。

### 5.2 正确线性chirp与时间频率权衡

瞬时频率是相位导数除 $2\pi$。若 $f(t)=f_0+kt$，相位应为 $2\pi(f_0t+kt^2/2)$。源函数直接用 $2\pi f(t)t$，导数得到 $f_0+2kt$，设200→4000Hz会到约7800Hz，8k采样导致后半混叠；不能把它当正确单调扫频。

```python
import numpy as np
from scipy.signal import chirp, stft
sr=16000;T=.4;t=np.arange(round(sr*T))/sr;f0,f1=200,4000
phase=2*np.pi*(f0*t+(f1-f0)*t*t/(2*T))
x=np.cos(phase)
assert np.allclose(x,chirp(t,f0=f0,f1=f1,t1=T,method='linear'))
for L in [200,400,800]:
    f,tt,z=stft(x,fs=sr,window='hann',nperseg=L,noverlap=L-160,boundary=None,padded=False)
    peak=f[np.argmax(np.abs(z),axis=0)]
    expected=f0+(f1-f0)*tt/T
    print('窗长',L,'ms',L/sr*1000,'网格Hz',sr/L,'峰误差中位Hz',float(np.median(np.abs(peak-expected))))
    assert np.all(np.diff(peak)>=0)
print('相位与真实线性chirp核对通过')
```

长窗扫频会在一个窗里跨更大频带，不能仅按FFT格间隔宣布“最佳”；还查时间定位、峰宽、轨迹偏差和任务。增加Mel带数也可能产生空滤波器，不能只用40/80/128这三个数字断言提升。

## 6. 固定长度摘要与分类管线

部分新型音频网络直接处理波形或学习出的离散表示，Mel并非每个模型必须攀爬的阶梯；既定模型以其训练前端为准。

MFCC的帧×系数序列可以用均值+方差或均值+标准差转固定向量。两个方案的单位和尺度不同，不能互换叫26维就兼容。均值/方差丢掉时间次序；均值+方差+偏度+峰度可描述分布形状，但少帧/近零方差时高阶矩不稳定。常用偏度 $E[(x-\mu)^3]/\sigma^3$、超额峰度 $E[(x-\mu)^4]/\sigma^4-3$，明确方差分母N与常数列约定。

k-NN的距离/余弦、训练集尺度变换、k和并列策略影响结果，完整方法见[近邻主要入口](../机器学习专题/04-近邻方法与距离搜索.md)。对原始MFCC摘要直接算余弦可能受c0和尺度主导，训练集标准化与不同摘要方式需对照。不能flatten不等长序列后用zip静默截断维度。

### 6.1 完整合成四类实验：真实输出仅属于纯音任务

此独立程序重复上节前端的必要构造，使复制后可直接运行：HTK三角带、功率→自然log→正交DCT。均值/方差与四矩消融保持底层波形、划分、k相同；前端完整边界仍以上节主要实现维护。

```python
import numpy as np
from scipy.fft import dct
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import confusion_matrix
rng=np.random.default_rng(42);sr=8000;L=256;H=128

def mfcc(signal,M=24,C=13):
    signal=np.asarray(signal,dtype=float)
    if signal.ndim!=1 or len(signal)<L or not np.isfinite(signal).all():
        raise ValueError('本例要求有限单声道且至少一整帧')
    frames=np.stack([signal[i:i+L] for i in range(0,len(signal)-L+1,H)])
    win=.5-.5*np.cos(2*np.pi*np.arange(L)/L)
    power=np.abs(np.fft.rfft(frames*win,axis=1))**2
    f=np.fft.rfftfreq(L,1/sr)
    edge=700*(10**(np.linspace(0,2595*np.log10(1+sr/2/700),M+2)/2595)-1)
    B=np.array([np.maximum(0,np.minimum((f-a)/(b-a),(c-f)/(c-b)))
                for a,b,c in zip(edge[:-2],edge[1:-1],edge[2:])])
    if (B.sum(1)==0).any():raise ValueError('空Mel带')
    return dct(np.log(np.maximum(power@B.T,1e-10)),type=2,norm='ortho',axis=1)[:,:C]

def features(freq,mode):
    t=np.arange(2000)/sr
    x=rng.uniform(.3,.7)*np.sin(2*np.pi*freq*t+rng.uniform(0,2*np.pi))+rng.normal(0,.04,len(t))
    c=mfcc(x)
    mean=c.mean(0);v=c.var(0);parts=[mean,v]
    if mode=='four':
        centered=c-mean;sd=np.sqrt(v)
        z=np.divide(centered,sd,out=np.zeros_like(centered),where=sd>1e-8)
        parts.extend([(z**3).mean(0),(z**4).mean(0)-3])
    return np.concatenate(parts)
# 重置同seed，保证两表示比较时底层波形相同。
for mode in ['two','four']:
    rng=np.random.default_rng(42);train=[];test=[];y=[];truth=[]
    for label,freq in enumerate([200,400,800,1600]):
        for _ in range(12):train.append(features(freq,mode));y.append(label)
        for _ in range(5):test.append(features(freq,mode));truth.append(label)
    model=make_pipeline(StandardScaler(),KNeighborsClassifier(n_neighbors=3))
    model.fit(train,y);pred=model.predict(test)
    print(mode,'维数',len(train[0]),'正确率',float(np.mean(pred==truth)))
    print('行真列预测\n',confusion_matrix(truth,pred,labels=[0,1,2,3]))
```

真实声音不是几条不同频率的正弦。该对照用于验证表示/尺度/分类流程，原课的简化MFCC完整原程序也另行运行并记录；真实环境/语音识别按原录音、会话、设备或实际部署单位分组留出；闭集事件分类通常仍评训练定义的事件类别，不能误解成必须测试未见类别。表征泛化可用说话人互斥集合，闭集身份识别需已注册类别；按任务选择协议。

## 7. CNN、Transformer与预训练音频表示

log-mel图输入可用 `(B,1,time,mel)` 的CNN，局部卷积再做时间/频率池化。短样本补边后须防止池化偏向静音长度，BatchNorm统计、训练增强与推理前端也要一致。AST将谱图分成patch并用位置表示和Transformer建模；与视觉patch的核心关系见[视觉训练专题](05-图像表征卷积与视觉训练.md)。BEATs用声学tokenizer等自监督目标学表征；WavLM偏重语音预训练，不能从名字推出它是非语音事件统一默认。冻结编码器+头、微调或从头训练按标签、领域、资源和错误类型比较，不以<1000/<10000等阈值强制选择。

### 7.1 可运行的CNN形状、损失与增广核对

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(4)
class AudioCNN(nn.Module):
    def __init__(self,classes=4):
        super().__init__()
        self.body=nn.Sequential(nn.Conv2d(1,32,3,padding=1),nn.ReLU(),nn.MaxPool2d(2),
                   nn.Conv2d(32,64,3,padding=1),nn.ReLU(),nn.MaxPool2d(2),
                   nn.Conv2d(64,128,3,padding=1),nn.ReLU(),nn.AdaptiveAvgPool2d(1))
        self.head=nn.Linear(128,classes)
    def forward(self,x):
        if x.ndim!=4 or x.shape[1]!=1 or min(x.shape[2:])<4:
            raise ValueError('B×1×T×mel，最小两维均4')
        return self.head(self.body(x).flatten(1))
model=AudioCNN();x=torch.randn(3,1,32,24);labels=torch.tensor([0,2,1])
logits=model(x);assert logits.shape==(3,4)
loss=F.cross_entropy(logits,labels);loss.backward()
assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
print('4类模型参数',sum(p.numel() for p in model.parameters()),'loss',loss.item())
# SpecAugment在训练特征上遮蔽，填充值的含义取决于归一/log约定。
aug=x.clone();aug[:,:,5:10,:]=0;aug[:,:,:,3:6]=0
lam=.3;perm=torch.tensor([2,0,1]);mixed=lam*x+(1-lam)*x[perm]
target=F.one_hot(labels,4).float();soft=lam*target+(1-lam)*target[perm]
assert torch.allclose(soft.sum(1),torch.ones(3))
mixloss=-(soft*F.log_softmax(model(mixed),dim=1)).sum(1).mean()
print('mixup软标签loss',mixloss.item(),'遮蔽元素数',int((aug==0).sum()))
```

原课同卷积体配50类时参数是99122，而非3M；本程序4类是93188。时间/设备/训练成绩需要实测，不复制“十分钟80%”承诺。`ignore_mismatched_sizes`仅重置不匹配分类头等参数，不等于已完成微调；真实模型下载/加载、训练和验证本次未做。

Mixup的标签要同步混合。互斥分类可用软标签交叉熵，多标签用逐类sigmoid/BCE；把混合标签强制argmax再CE会丢失训练目标。波形混合需考虑SNR/峰值和语义标签，谱图混合是另一种操作。SpecAugment的time/frequency遮蔽范围由特征形状决定，0在log域未必是静音；规范化后0常是均值，二者不能混称。

## 8. 分类验收、学习练习与来源

互斥多类分类看top1、每类recall、混淆矩阵与macroF1；多标签用各类AP/mAP、阈值后的P/R等，不能只softmax/top1。AP是按排序的精确率/召回增量聚合，mAP是类别平均，不只是“跨阈值平均accuracy”。任务标签协议决定互斥/多标签，不能将UrbanSound8K等数据集名自动当多标签。AudioMNIST是语音数字分类，并非完整ASR转录评测。

同一原始录音切出的片段必须按原始录音分组，语音任务还查说话人/会话/设备是否泄漏。环境声音按场景、来源、时间或官方fold划分，不能先随机切片再拆训练测试；标准化、类别重采样和增强仅在训练集进行。分类与说话人检索评测更详细协议由[音频评分与评测专题](15-音频安全与评价方法.md)维护。

练习核对：

1. 混合220/440/880Hz，1秒16k采样时三频恰在FFT格点，三峰应匹配；短64ms片段的频率网格15.625Hz，440Hz不在整数bin，读数应近似而非精确。本章数学09提供DFT基础实现，正文使用FFT。
2. 原“录自己的声音降采样”练习本次改用24kHz7kHz合成信号，滤波前后RMS与伪峰实算，不录人声。语音真实混叠的位置取决于原高频内容，不保证每段都明显。
3. STFT手写练习关键是窗/帧/FFT/轴和短输入契约；FFT替代直接DFT保同一数学结果。无补边10秒400/160为998帧。
4. chirp检查以相位导数和SciPy一致为先，再查峰轨迹；40/80/128mel及不同窗的最佳组合按任务/轨迹/主瓣宽测，不预设赢家。
5. log功率、ref=max dB、MFCC+动态特征都能作为比较，但须明确单位、归一和训练适配。AudioMNIST真实CNN比较本次未下载运行，不编造准确率。
6. 四矩池化的变化见合成消融输出；高阶矩不是额外时间次序，也不保证更好。真实ESC-50五折/SpecAugment实验未做，后续复现遵守官方fold和标签协议。
