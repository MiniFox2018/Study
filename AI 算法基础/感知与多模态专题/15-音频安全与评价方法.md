# 15｜音频安全与评价方法

音频质量、内容正确、声线相似、是否生成、水印存在和来源签名是不同问题。不能拿一种分数回答全部问题。本章维护音频评价协议及安全边界；合成与音频语言模型见 [14](14-语音合成生成与音频语言模型.md)，通用实验、judge 与统计判断见 [LLM 评测](../../LLM%20工程实践/06-评测与实验管理.md)。程序只处理合成信号、分数、人工标签和时间区间。

## 1. 检测、水印和来源分别能说明什么

反欺骗检测器对音频分配“像真实/像合成/像重放”的统计分数，训练域、攻击方法、录音设备和编码会改变分布。单一频谱平坦度、高频能量或声纹余弦不是真伪判定。频谱rolloff是累积到约定比例的谱量对应频率，必须说明累计幅度还是功率；高频占比要固定频带、采样率、窗和FFT。正常噪声/设备也可改变这些量，不能把高频较多直接标假；信号与频谱实现回到 [数字音频特征与分类](11-数字音频特征与分类.md)。AASIST 的谱时图注意力、RawNet 类波形编码和自监督特征适配是学习检测特征的路线，不是万能识假机制。

水印生成器向己方生成内容加入可检测的信号，检测器判断水印及可能的载荷；它适合合作系统的标记，不能要求不合作生成器主动加入。局部水印检测可以帮助定位被标记片段，输出每样本分数不等于真实定位精度达到一个采样点。未检出可能是无水印、攻击、短片段、错误密钥或检测失效，不证明录音来自真人。

签名来源记录绑定文件或内容、工具、编辑声明和签名者；校验能够检查绑定与完整性，不能证明音频描述的事实、说话人真实身份或签名者声明诚实。重编码后字节 hash 改变，需相应记录、软绑定或明确断链；去掉 manifest 不会把内容变成“已证明真实”。C2PA 是来源表达/验证体系，水印是信号标记，检测是统计推断，三者可组合但不能互相代替。

## 2. 授权、许可证和更新记录

涉及声线参考时记录来源、权利人的授权、目的/范围、使用对象、期限与撤回机制，以及生成/导出记录。声纹相似不能作为授权凭证；哈希文件只标识那份文件，也不能凭文件 hash 证明说话人身份。授权撤回、参考变更或用途扩展需要重新检查已有记录与缓存。检查签名、范围、期限和参考关联必须是实际执行的控制逻辑，失败时明确停止或返回错误；不能仅用Python `assert` 作授权门禁，因为优化执行可跳过assert。

分别核查代码许可证、权重/训练材料说明、参考音频及歌词/旋律素材权利、生成输出条款和服务合同。开放代码不自动意味着权重和输出可商用；例如2026-10-04核对AudioCraft作者README，代码许可证为MIT，模型权重列为CC-BY-NC 4.0，源课以“MusicGen MIT”推导完整商用权利不成立。[作者许可证说明](https://github.com/facebookresearch/audiocraft#license) 购买服务也不能替代所有素材与人格权益的范围核对。音乐的“只有器乐就无版权风险”、某许可必给完整商业权利或未经核验的和解金额不作为知识结论。

具体法规、合同和司法状态有地域、适用对象和日期条件，使用时回到官方文本及相应专业审核；本章不复制源课“所有地区所有克隆都强制某水印”“保存7年/10年”等未核义务。水印和来源记录在这里是可验证的工程方法，不是自动法律合规证明。

载荷容量也有限：16 bit 只有65536种值，不能无损装下 model ID、user ID 和完整时间戳。可用不含个人信息的短索引连接受控的来源记录，处理冲突和密钥轮换；载荷泄漏、可伪造和隐私风险应按部署目的考虑，不把 patient_id 等敏感信息直接塞入公开音频。

## 3. 从分数到 EER：方向、阈值和相同分数

以下约定高分表示 genuine/目标说话人，应接受 `score>=threshold`。对真实/同人集合 G，FRR 为被拒比例；对伪造/异人集合 I，FAR 为被接受比例：

$$\operatorname{FRR}(t)=\frac{|\{s\in G:s<t\}|}{|G|},\qquad
\operatorname{FAR}(t)=\frac{|\{s\in I:s\ge t\}|}{|I|}.$$

若检测器输出高分表示 fake，先变换分数方向或直接交换决策定义，不能用同一公式却仍称高分真实。有限样本通常没有确定阈值让两率完全相等；“差最小处取两者平均”是一种近似，ROC点间插值是另一协议，二者需区分。相同分数必须作为整体阈值组处理，不能按标签打破排序来制造更低错误率。

### 3.1 完整阈值扫描与插值 EER

此实现枚举相同分数组、接受全部和拒绝全部端点，在 FAR−FRR 变号处线性混合相邻操作点。`mix` 是理论随机化混合比例，不意味着中间存在同样效果的确定阈值；实际部署需从开发集选择阈值再在锁定测试集报告 FAR/FRR。

```python
import numpy as np

def eer(genuine, impostor):
    g,i = np.asarray(genuine,float),np.asarray(impostor,float)
    if g.ndim!=1 or i.ndim!=1 or len(g)==0 or len(i)==0 or not np.isfinite(g).all() or not np.isfinite(i).all():
        raise ValueError("两组非空有限分数，且高分表示应接受")
    thresholds = [-np.inf] + sorted(set(g.tolist()+i.tolist())) + [np.inf]
    points = [(float(t),float(np.mean(i>=t)),float(np.mean(g<t))) for t in thresholds]
    for index,(t,far,frr) in enumerate(points):
        if far==frr:
            return {"eer":far,"thresholds":(t,t),"mix":0.0,"points":points}
        if index and far-frr<0:
            a=points[index-1]; gap_a=a[1]-a[2]; gap_b=far-frr
            mix=gap_a/(gap_a-gap_b)
            return {"eer":(1-mix)*a[1]+mix*far,"thresholds":(a[0],t),"mix":mix,"points":points}
    raise AssertionError("端点应确保交叉")

assert eer([.8,.9],[.1,.2])["eer"]==0
assert eer([.1,.2],[.8,.9])["eer"]==1
assert eer([.5,.5],[.5,.5])["eer"]==.5
# 输入高分fake时，取负号后按高分genuine约定使用。
assert eer(-np.array([.1,.2]),-np.array([.8,.9]))["eer"]==0
for a,b in (([],[.1]),([np.nan],[.1])):
    try: eer(a,b)
    except ValueError: pass
    else: raise AssertionError("空组/NaN不能默认为0错误")
print("EER：完美0、反向1、相同分数0.5、方向转换及非法输入通过")
```

EER 描述这份二类试验的曲线交点，不是部署阈值或身份认证保证。CM、说话人 verification 和 spoofing-robust verification 的标签、负例与风险不同，不能跨协议直接排名。minDCF 是扫描阈值取得的最低检测成本；某个实际阈值的 DCF 则为 `C_miss*P_target*FRR + C_fa*(1-P_target)*FAR`，需写清先验、代价和归一化。minDCF 不是“选定 FAR 后的成本”的同义词。

## 4. 音频水印：将能力与攻击条件写成实验

神经水印联合训练 generator/detector，用失真/感知损失限制改动，用检测与载荷损失学习信号，并通过重采样、编码、噪声、裁剪等增强训练鲁棒性。AudioSeal 是局部水印和可选消息载荷的研究实现；并非所有水印都能承受所有压缩或变调，也不是某一种 pitch shift 普遍消灭未来全部水印。

评价至少包括未标记音频的误报率、标记音频检测率、局部时间掩码准确性、bit error/recovery、完整消息恢复率、音质影响和各攻击条件。16 bit每位准确率0.99并不代表整条消息成功率0.99；若独立才有 `0.99^16≈0.851`，实际错误还可能相关。payload错误/检测失败均保留完整消息分母。

### 4.1 合成 spread-spectrum 载荷与无原文检测

以下按消息块加入伪随机载波，检测时只使用载波，展示噪声和同步条件。不使用真人录音；没有证明不可闻、加密、抗伪造或生产鲁棒性。与“拿原音减掉水印音再解码”的实验不同，这里明确不依赖原音。

```python
import numpy as np

def carriers(n_bits, block=256, seed=9):
    if type(n_bits) is not int or n_bits<=0 or type(block) is not int or block<2:
        raise ValueError("载荷与块长无效")
    rng=np.random.default_rng(seed)
    codes=rng.choice([-1.,1.],size=(n_bits,block))
    return codes/np.linalg.norm(codes,axis=1,keepdims=True)

def embed(signal,bits,codes,strength=0.1):
    x=np.asarray(signal,float); bits=np.asarray(bits)
    if codes.ndim!=2 or x.shape!=(codes.size,) or bits.shape!=(len(codes),):
        raise ValueError("形状不匹配")
    if not np.isfinite(x).all() or not np.isfinite(codes).all() or not np.isfinite(strength) or strength<=0:
        raise ValueError("信号、载波与强度必须有效")
    if not np.isin(bits,[0,1]).all(): raise ValueError("载荷必须为bit")
    return (x.reshape(codes.shape)+strength*(2*bits[:,None]-1)*codes).ravel()

def decode(signal,codes):
    x=np.asarray(signal,float)
    if x.shape!=(codes.size,) or not np.isfinite(x).all():
        raise ValueError("缺失/裁剪/错长度须返回失败，不能静默补齐")
    score=(x.reshape(codes.shape)*codes).sum(axis=1)
    return (score>=0).astype(int),score

rng=np.random.default_rng(4)
bits=np.array([1,0,1,1,0,0,1,0]);codes=carriers(len(bits))
# 用合成随机宿主，并正交去掉宿主在各载波上的分量以得到可核对fixture。
host=rng.normal(0,.005,codes.shape)
host-= (host*codes).sum(axis=1,keepdims=True)*codes
wm=embed(host.ravel(),bits,codes)
recovered,_=decode(wm,codes)
assert np.array_equal(recovered,bits)
noisy=wm+rng.normal(0,.002,len(wm))
recovered,_=decode(noisy,codes)
assert np.array_equal(recovered,bits)
# 截断后的输入必须失败；现实检测器需要额外同步/局部处理机制。
try: decode(wm[10:],codes)
except ValueError: pass
else: raise AssertionError("同步条件破坏不能声称仍完整恢复")
print("合成8bit载荷/固定噪声fixture恢复通过；裁剪明确失败，未测试压缩或不可闻")
```

载波是分块伪随机向量，并没有跨消息块正交比较的需要；宿主与每块载波正交只为构造可核对 fixture。真实音频宿主会干扰相关得分，密钥、同步和感知约束还需专门设计。公开载波方法可被伪造，不能拿完整消息命中当签名真实性。

## 5. WER/CER：编辑距离与评价口径

编辑距离最短路径包含替换 S、删除 D、插入 I，WER 为 `(S+D+I)/N_reference_words`，CER 以约定字符单位替换 word。二者可能超过100%，插入不受参考长度限制。中文词边界需分词契约；CER不是只有声调语言才适用。标点、大小写、数字、Unicode规范化、空格及专名处理会影响得分。

不得用只保留 `[a-z0-9]` 的清洗把中文参考和预测都删为空并得到0错误。空参考需明确：两边空时无识别错误，有预测时统计幻觉插入数；百分比没有普通分母，不能用 `max(1,N)` 伪装可比较的 WER。宏平均逐句 WER与微平均总编辑数/总参考词数是不同指标，均需说明。JiWER 4.0明确约定空参考/空预测为0，空参考/非空预测返回插入计数；这是库的已声明行为。本篇单例rate采用不适用并另报插入数，不冒称与库所有分支相同。[JiWER官方说明](https://github.com/jitsi/jiwer#readme)

### 5.1 完整 S/D/I 回溯及全量聚合

```python
import unicodedata

def edit_counts(reference,hypothesis):
    r,h=list(reference),list(hypothesis); n,m=len(r),len(h)
    dp=[[0]*(m+1) for _ in range(n+1)]
    for i in range(n+1): dp[i][0]=i
    for j in range(m+1): dp[0][j]=j
    for i in range(1,n+1):
        for j in range(1,m+1):
            dp[i][j]=min(dp[i-1][j]+1,dp[i][j-1]+1,dp[i-1][j-1]+(r[i-1]!=h[j-1]))
    i,j=n,m; s=d=ins=0
    while i or j:
        # 同代价优先match/sub，再delete、insert；总距离相同，细项可能随规则变。
        if i and j and dp[i][j]==dp[i-1][j-1]+(r[i-1]!=h[j-1]):
            s+=int(r[i-1]!=h[j-1]); i-=1; j-=1
        elif i and dp[i][j]==dp[i-1][j]+1: d+=1; i-=1
        else: ins+=1; j-=1
    return {"S":s,"D":d,"I":ins,"N":n,"errors":s+d+ins,
            "rate":(s+d+ins)/n if n else None}

def micro_rate(records):
    if not records: raise ValueError("评价集合不能为空")
    n=sum(x['N'] for x in records); errors=sum(x['errors'] for x in records)
    return {"rate":errors/n if n else None,"N":n,"errors":errors,
            "empty_reference_cases":sum(x['N']==0 for x in records)}

a=edit_counts("turn on lights".split(),"turn off lights".split())
assert a=={"S":1,"D":0,"I":0,"N":3,"errors":1,"rate":1/3}
# 源动态图给出1S+1D+1I的非最短对齐；最短路径只需2替换。
alignment=edit_counts("turn on the kitchen lights".split(),"turn on chicken now lights".split())
assert alignment["errors"]==2 and alignment["rate"]==0.4
b=edit_counts(["a"],["a","b","c"]); assert b['rate']==2
empty=edit_counts([],['hallucinated']);assert empty['rate'] is None and empty['I']==1
# 中文只做NFC规范化，保留所有文字；不默认删除空格/标点。
c=edit_counts(unicodedata.normalize('NFC','打开灯'),unicodedata.normalize('NFC','关闭灯'))
assert c['N']==3 and c['S']==2
summary=micro_rate([a,b,empty]);assert summary['rate']==1 and summary['errors']==4
print("编辑距离：替换/插入/空参考/中文保留；微平均",summary)
```

源 `sp-wer-align` 图将上例画为删除the、替换kitchen→chicken、插入now，得60%；但the→chicken、kitchen→now两次替换即可完成，最短编辑距离为2，WER为40%。编辑示意路径不能替代最小路径算法。

若一次服务超时没有 hypothesis，应记录失败，再按预定协议将其视为全部删除或单列失败与coverage；不要直接从样本中删掉。TTS→ASR回译分数同时包含 TTS 和 ASR 误差，不能将低WER当音色自然或所有发音正确的证明。人工规范化后可能隐藏原本读错数字，应另报关键字段/未经规范化误差。

## 6. Diarization：DER 的时间分母与重叠

Diarization 输出说话人标号和时间段，标号本身任意；计算前做全局最优 speaker 映射，不能逐段任意换标号得到虚假满分。DER 分子为 missed speaker-time、false-alarm speaker-time、confusion speaker-time，分母是参考说话人时间的总和，重叠区域两人同时说话计两份。评测协议指定 UEM 有效区域、是否计重叠、边界 collar 以及映射策略。

一秒参考两人同时说话、系统只找到一人：参考时间2 speaker-seconds，漏掉1，DER=1/2；不是按墙钟一秒除成100%。collar 会从指定边界附近排除容忍区间，不代表模型时间精度提高；排除重叠会省掉难题，所以不同collar/overlap协议不可直接比较。

### 6.1 已知映射下的完整事件区间核对

这个程序按所有起止事件点划分区间，支持overlap；输入 ID 已映射到参考，**没有自动实现最优映射或collar扩张**。`regions`可以表示已算好的有效区间，从而不把排除时间误计到分母。完整基准需使用版本固定的正式scorer，例如pyannote.metrics明确区分全局label映射、UEM、collar和skip_overlap。[官方指标说明](https://pyannote.github.io/pyannote-metrics/reference.html)

```python
import math

def der_known_mapping(reference,hypothesis,regions):
    for segments in (reference,hypothesis):
        for a,b,s in segments:
            if not math.isfinite(a) or not math.isfinite(b) or a>=b or not isinstance(s,str):
                raise ValueError("区间必须有限递增且有speaker ID")
    if not regions or any(not math.isfinite(a) or not math.isfinite(b) or a>=b for a,b in regions):
        raise ValueError("有效评价区域不能为空")
    ordered=sorted(regions)
    if any(ordered[i][1]>ordered[i+1][0] for i in range(len(ordered)-1)):
        raise ValueError("评价区域不能重复计时")
    totals={"miss":0.,"false_alarm":0.,"confusion":0.,"reference_time":0.}
    for left,right in ordered:
        edges=sorted({left,right}|{t for seg in reference+hypothesis for t in seg[:2] if left<t<right})
        for a,b in zip(edges,edges[1:]):
            mid=(a+b)/2;dt=b-a
            r={s for x,y,s in reference if x<=mid<y};h={s for x,y,s in hypothesis if x<=mid<y}
            common=len(r&h); totals['reference_time']+=len(r)*dt
            totals['miss']+=max(len(r)-len(h),0)*dt
            totals['false_alarm']+=max(len(h)-len(r),0)*dt
            totals['confusion']+=(min(len(r),len(h))-common)*dt
    n=totals['reference_time']
    return dict(totals,der=(totals['miss']+totals['false_alarm']+totals['confusion'])/n if n else None)

ref=[(0.,1.,'A'),(0.,1.,'B')];hyp=[(0.,1.,'A')]
assert der_known_mapping(ref,hyp,[(0.,1.)])['der']==.5
assert der_known_mapping([(0,1,'A')],[(0,1,'B')],[(0,1)])['confusion']==1
assert der_known_mapping(ref,ref,[(0.,1.)])['der']==0
assert der_known_mapping([],[(0,1,'A')],[(0,1)])['der'] is None
print("DER：重叠speaker-time、漏检、已映射身份混淆、空参考分母通过")
```

JER 通常基于参考speaker与匹配假设speaker的时段交并比，按参考speaker平均 `1-intersection/union`；具体无匹配和映射规则按scorer核验。它与DER加权方式不同，不简单声称“对短段更稳健”而忽略任务条件。

## 7. MOS、预测MOS与声线相似

MOS 是人在明确量表与说明下的平均主观评分，例如自然度1～5；CMOS比较两段的相对差异，偏好测试与Elo则是另一协议。固定同一文本、声线范围、响度处理、随机盲序和听者条件，按clip/听者聚类或分层报告不确定性；同一人给100分不是100独立听者。没有普适“20听者×100样本就够”保证。

UTMOS/DNSMOS等预测器学习人工质量标签，是特定训练域的代理，不是替代所有语言、情绪和录音条件的金标准；固定模型、输入处理与验证域，检查误差及失败。SECS是说话人encoder余弦相似，依赖模型与参考选择；同文本、通道或背景也会影响表示，不具有通用0.7/0.75身份阈值。

克隆评价至少分声线相似、自然度、内容可懂度、关键事实与授权；高SECS也可能漏读或背景噪声重，不同speaker encoder分数不可直接排名。指标程序必须检查向量同维、非零有限，并保留编码失败；余弦实现可复用 [Embedding 契约](../../LLM%20工程实践/07-Embedding与检索模型训练.md#2-编码契约决定向量能不能比较)。

## 8. FAD、CLAP与音乐分布

FAD用固定音频embedding提取器估计参考和生成分布的均值/协方差，近似为高斯后的距离为：

$$D=\|\mu_r-\mu_g\|^2+\operatorname{tr}(\Sigma_r+\Sigma_g-2(\Sigma_r^{1/2}\Sigma_g\Sigma_r^{1/2})^{1/2}).$$

这个式子不再额外整体开平方，协方差包含维度相关性。源课“只比较每维方差再sqrt”只能称对角代理，不是真实FAD。固定embedding模型/层、采样率/声道、片段、参考集合和协方差估计（N或N−1）才能比较；短小样本导致协方差秩不足、估计偏差，应报告数量和范围。

### 8.1 完整协方差与半正定平方根

```python
import numpy as np

def psd_sqrt(matrix):
    matrix=(matrix+matrix.T)/2
    values,vectors=np.linalg.eigh(matrix)
    if values.min() < -1e-8: raise ValueError("协方差明显非半正定")
    return (vectors*np.sqrt(np.maximum(values,0)))@vectors.T

def frechet_embeddings(reference,generated):
    r,g=np.asarray(reference,float),np.asarray(generated,float)
    if r.ndim!=2 or g.ndim!=2 or r.shape[1]!=g.shape[1] or min(len(r),len(g))<2 or r.shape[1]<1:
        raise ValueError("同维二维表示且各至少两样本")
    if not np.isfinite(r).all() or not np.isfinite(g).all(): raise ValueError("表示必须有限")
    mr,mg=r.mean(axis=0),g.mean(axis=0)
    # 本协议使用N−1样本协方差；真实指标必须与官方协议对齐。
    cr=(r-mr).T@(r-mr)/(len(r)-1);cg=(g-mg).T@(g-mg)/(len(g)-1)
    root=psd_sqrt(cr);cross=psd_sqrt(root@cg@root)
    value=float(np.sum((mr-mg)**2)+np.trace(cr+cg-2*cross))
    if value < -1e-7: raise ValueError("数值误差或协方差计算异常")
    return max(0.,value)

r=np.array([[-1.,0.],[0.,0.],[1.,0.]])
assert frechet_embeddings(r,r)<1e-8
assert abs(frechet_embeddings(r,r+np.array([2.,0.]))-4)<1e-8
# 协方差方向变化，不能只看逐维方差。
a=np.array([[-1.,-1.],[0.,0.],[1.,1.]])
b=np.array([[-1.,1.],[0.,0.],[1.,-1.]])
assert np.allclose(a.var(axis=0),b.var(axis=0))
assert frechet_embeddings(a,b)>0
print("高斯Fréchet：同分布0、均值平移4、同方差异相关非零通过")
```

这里输入合成向量，没有使用音频embedding模型，不能称MusicCaps或真实音乐的FAD成绩。FAD是集合分布指标，不能判断每条是否可用，也可能对相同低多样输出或参考类别偏差给误导结论。CLAP测音频/文本表示关联，仍不证明歌词、节拍、音色细节、声音事实或使用许可；听感与任务判据要共同评价。

## 9. 分类、ALM与流式互动

互斥分类报top-1/混淆矩阵/每类支持数，多标签报各类AP及mAP、阈值相关P/R/F1，失衡报macro及重要类别；明确空正例类、标签缺失和阈值选择。一种非插值AP按相关项排名求 `Σ(P@rank×是否正例)/正例数`；阈值式实现可按同分数组汇总precision/recall增量，必须固定ties约定。mAP对类别AP平均，某类无正例时标不适用并报覆盖类数，不默认满分；micro聚合和macro每类等权回答的问题不同。分类模型与标签合同回到 [数字音频特征与分类](11-数字音频特征与分类.md)。分类标签正确也不代表时间定位或事件因果正确。MMAU、长音频/字幕基准用于不同任务，版本、split、prompt、选项解析与官方scorer必须固定；简单exact-match MCQ fixture不能与采用不同解析/judge的公开成绩直接对比。

### 9.1 缺失答案、选项解析与完整分母

下面不是MMAU官方scorer，仅展示本地确定性选项协议：gold为已知选项，预测必须为同一案例ID的已解析选项，缺失/超时记失败且保留分母，按类别同时报告。`all`是保留汇总名，真实类别禁止使用它，避免同一案例在汇总中双计。它不实现embedding或LLM评分，也不能拿结果比较公开排名。

```python
from collections import defaultdict

def choice_scores(cases,predictions):
    ids=[c['id'] for c in cases]
    if not ids or len(set(ids))!=len(ids) or set(predictions)-set(ids):
        raise ValueError("case ID需唯一非空，预测不能含未知ID")
    if any(c["category"]=="all" for c in cases):
        raise ValueError("all是保留汇总名，不能作为真实类别")
    groups=defaultdict(lambda:{'total':0,'scored':0,'correct':0,'failed':[]})
    for c in cases:
        if not c['choices'] or c['gold'] not in c['choices']:
            raise ValueError("gold必须属于已固定选项")
        p=predictions.get(c['id'])
        scored=(type(p) is dict and p.get('status')=='ok' and p.get('answer') in c['choices'])
        correct=scored and p['answer']==c['gold']
        for key in ('all',c['category']):
            row=groups[key];row['total']+=1;row['scored']+=int(scored);row['correct']+=int(correct)
            if not scored:row['failed'].append(c['id'])
    return {k:dict(v,accuracy_all=v['correct']/v['total'],coverage=v['scored']/v['total'])
            for k,v in groups.items()}

cases=[{'id':'a','choices':['A','B'],'gold':'A','category':'speech'},
       {'id':'b','choices':['A','B'],'gold':'B','category':'speech'},
       {'id':'c','choices':['A','B'],'gold':'A','category':'multi_audio'}]
pred={'a':{'status':'ok','answer':'A'},'b':{'status':'ok','answer':'A'}}
r=choice_scores(cases,pred)
assert r['all']['accuracy_all']==1/3 and r['all']['coverage']==2/3
assert r['speech']['accuracy_all']==.5 and r['multi_audio']['failed']==['c']
try:
    choice_scores([dict(cases[0],category="all")],{'a':pred['a']})
except ValueError:
    pass
else:
    raise AssertionError("保留汇总名all不能双计真实案例")
print("选项fixture：完整3题分母、缺失1题、类别结果、保留名all拒绝通过")
```

captioning 的CIDEr、SPICE、FENSE等比较描述的不同方面，参考覆盖和评分模型也会造成偏差；指令遵循、事件正确与时间定位需分别验证。成对音频比较应绑定两个clip ID及问题，不能只回答其中一个clip再据关键词出现给满分。

音频互动需区分输入开始/结束、首个转录token、首个音频chunk、首个可听响应、尾部完成，以及打断到停止输出。TTFA/端到端响应包括网络、VAD结束判定、排队、模型、缓存和播放器缓冲的不同范围。RTF=处理墙钟时间/音频时长，RTFx是其倒数；批处理吞吐不能当单请求流式延迟。

下面的互动fixture只度量用户turn已经结束后开始响应的回合式请求，因此要求结束时间≤首chunk≤可听响应≤完成。它不是full duplex、back-channel或同步翻译的通用时间协议；持续双流/提前响应需另定义起点、重叠与落后量，不能直接套用本函数。

```python
import numpy as np

def interaction_summary(cases):
    if not cases: raise ValueError("案例不能为空")
    good=[];failed=[]
    for c in cases:
        if c['status']!='ok': failed.append(c['id']);continue
        end,chunk,audible,done=c['user_end'],c['first_chunk'],c['audible'],c['done']
        if not np.isfinite([end,chunk,audible,done]).all() or not end<=chunk<=audible<=done:
            raise ValueError("时间戳必须有限且有序")
        good.append({'chunk_delay':chunk-end,'audible_delay':audible-end,
                     'completion':done-end,'cache':c['cache']})
    def summarize(group):
        if not group:return {'count':0,'p50':None,'p95':None,'p99':None}
        a=np.array([x['audible_delay'] for x in group])
        p=np.quantile(a,[.5,.95,.99],method='linear')
        return dict(count=len(group),p50=float(p[0]),p95=float(p[1]),p99=float(p[2]))
    return {'all_requests':len(cases),'success':len(good),'failures':failed,
            'failure_rate':len(failed)/len(cases),'latency_success_only':summarize(good),
            'cache_hit':summarize([x for x in good if x['cache']]),
            'cache_miss':summarize([x for x in good if not x['cache']])}

cases=[{'id':'a','status':'ok','user_end':1.,'first_chunk':1.1,'audible':1.2,'done':2.,'cache':True},
       {'id':'b','status':'ok','user_end':1.,'first_chunk':1.4,'audible':1.5,'done':2.4,'cache':False},
       {'id':'c','status':'timeout'}]
r=interaction_summary(cases)
assert r['failure_rate']==1/3 and r['latency_success_only']['count']==2
assert np.isclose(r['cache_hit']['p50'],.2) and np.isclose(r['cache_miss']['p50'],.5)
print("互动fixture：成功延迟与失败分母、缓存命中/未命中分别保留",r['failure_rate'])
```

成功请求的P95不包含超时，要一起展示失败率和超时规则，不能以更少成功请求美化尾延迟。小样本P99只是插值描述，不是稳定估计或置信区间。流式状态和取消协议回到 [语音识别与流式交互](13-语音识别与流式交互.md)。首个chunk可能只有静音/元数据，须区分可听响应；打断延迟需真实输出停止时间而非取消请求发出时间。所有基准数字和固定“150ms目标”按任务条件重新测量。

## 10. 可复查的验收与练习答案

1. 高分fake却按高分genuine算FAR：会把决策方向颠倒，先核对模型score含义，再扫阈值。
2. 两类全为0.5：不能按真实/伪造顺序排序创造完美分类；按组处理，插值EER为0.5。
3. 参考一词、预测多插两词：WER=2，即200%。空参考有插入时单列插入计数，无普通百分比分母。
4. 一秒A/B重叠，系统只A：漏检1 speaker-second，分母2，DER=0.5。去重叠协议是另一任务。
5. FAD-like按对角方差为0、真实协方差方向不同：完整Fréchet可非零，不能把代理名称换成FAD。
6. SECS高能否证明本人/许可/不可识别克隆？不能；相似、身份、授权与听感分别验证。
7. 检出水印但payload错误：检测存在成功不等于消息成功；bit accuracy与完整消息恢复率分别报。
8. C2PA校验通过：证明绑定/签名验证按协议通过，不证明内容事实或说话人声明正确；无manifest也不证明是假。
9. 三请求一超时：失败率1/3；成功P95需注明只含2请求，缓存冷热分开，不能声称整体服务可靠。
10. 许可核验至少分代码、权重、参考素材、输出条款和服务合同，记录版本与日期；源榜单和未核法律说法不作为验收条件。
