> 先修：Embedding相似度、基本概率、Transformer。先解决配对、缺失模态和共享空间，再学习零样本检索及[OCR/VLM可靠管道](08-OCR视觉语言与可靠管道.md)。之后可选[视觉生成与视频时序](09-视觉生成与视频时序.md)及[世界模型](../深度学习专题/15-强化学习进阶与世界模型.md)。

## 1. 问题定义

多模态学习要让模型联合处理不同信息通道：

- text；
- image；
- video；
- audio；
- sensor / action。

难点不是简单拼接，而是让不同模态进入可对齐、可交互的表示空间。

## 2. Fusion

常见策略：

- early fusion：低层或输入附近融合；
- late fusion：各模态独立建模后融合；
- intermediate fusion：在中间层跨模态交互。

选择取决于：

- 模态是否同步；
- 是否可能缺失；
- 计算成本；
- 任务需要多深的交互。

## 3. 图文对齐：CLIP与SigLIP分别学什么

双塔分别编码图像和文本，再投影到共同的d维空间。图像输出与文本输出要用**同一个配套模型**的投影；相同维数不代表可以混用。纯图像DINO特征没有天然配套文本塔，不能直接和任意CLIP文本向量作“图文事实校验”。视觉内部hidden size与共同projection size也不是同一项，源课程混淆了部分CLIP型号的两种维度；实际读取模型配置和输出shape。

对一批N个配对，归一化向量 $i_a,t_b$构成：

$$
S_{ab}=\frac{i_a^Tt_b}{\tau},\qquad
L=-\frac1{2N}\sum_a\left[\log\frac{e^{S_{aa}}}{\sum_b e^{S_{ab}}}
+\log\frac{e^{S_{aa}}}{\sum_b e^{S_{ba}}}\right].
$$

行是图像查询文本，列是文本查询图像，两方向让配对在各自候选中排名靠前。温度tau越小，分布越尖，梯度/数值更敏感；实现常学习logit scale的对数后取exp，注意约束和稳定log-softmax。二阶矩/优化器不是这条损失的语义，初始化随机模型的loss也不保证恰为logN；只有所有候选分数相同时才等于logN。

正确配对不要求两向量恰在同一点，只希望比不匹配候选更相似。图像有多段正确描述、同类多张图、重复caption都可能产生假负例；可去重、设计多正样本目标或按实际配对定义采样。只追更大batch不会自动修复错误配对。目标把所有非对角项都当负例，必须先确认这个假设。

SigLIP改为逐图文对的Sigmoid损失。设 $y_{ab}=+1$为配对，-1为不配对，分数 $s_{ab}=\alpha i_a^Tt_b+b$，损失可用 $\log(1+e^{-y_{ab}s_{ab}})$稳定计算，并明确负样本采样和归一化。它不使用CLIP每行/列的Softmax分母，但仍有负例数量、正负比例、偏置和数据质量问题；不能推出任意小batch都一定比CLIP好。

### 3.1 一个完整双塔和损失形状实验

下例仅使用小型线性投影和合成配对特征，验证梯度与形状，**不是训练真实CLIP或视觉语义能力**。

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1)
torch.manual_seed(42)
class TwoTower(nn.Module):
    def __init__(self):
        super().__init__()
        self.image = nn.Linear(8, 4)
        self.text = nn.Linear(6, 4)
        self.log_scale = nn.Parameter(torch.tensor(1.))
    def forward(self, image, text):
        a = F.normalize(self.image(image), dim=-1)
        b = F.normalize(self.text(text), dim=-1)
        return self.log_scale.exp()*a@b.T
model = TwoTower()
image, text = torch.randn(3, 8), torch.randn(3, 6)
scores = model(image, text)
labels = torch.arange(3)
loss = (F.cross_entropy(scores, labels)+F.cross_entropy(scores.T, labels))/2
loss.backward()
assert scores.shape == (3, 3) and all(p.grad is not None for p in model.parameters())
uniform = torch.zeros(3, 3)
assert torch.isclose(F.cross_entropy(uniform, labels), torch.tensor(3.).log())
pair_labels = 2*torch.eye(3)-1
sigmoid_loss = F.softplus(-pair_labels*scores.detach()).mean()
print("相似度/CLIP损失/逐对Sigmoid损失", tuple(scores.shape), round(loss.item(), 6),
      round(sigmoid_loss.item(), 6))
```

小随机模型只证明计算图连通。逐对loss的`mean`是本教学约定；作者逐行求和再平均的`sum/N`与之相差N倍。真实SigLIP对双塔、scale、bias的反向及多正对合同在[16第2节](16-视觉编码与语言接入实践.md#2-图文对齐sigmoid目标也要有真实梯度)维护，不把本段detach后的数值示范叫完整SigLIP训练。

## 3.2 零样本分类、模板集成与图文检索

对C个候选类写描述、文本编码得到 `[C,d]`；查询图像编码得到 `[N,d]`，归一化后 $I T^T$为 `[N,C]`，按行取最高相似候选。这里“零样本”指没有为**目标任务类别**使用有监督样本进行适配，不是模型从没训练过图文。源程序先以所有合成类别训练，再评估同类新样本，属于已见类泛化的双塔示范，不足以证明未见类别零样本迁移。

多模板应每条编码后归一化、每类平均，再对类向量归一化。平均**编码前的输入特征**后再过非线性编码器不等价。模板描述应适合影像域与类别可见特征，不设80条或小写必有效的固定规则；模板改善幅度由数据验证。候选集合改变，Softmax分数也改变；高分不是“世界中确有这个类别”的概率。加入明确背景/未知候选、阈值与验证拒识，但仍要单独测开放集失败。

以下已对齐三维向量fixture把分类与检索的计算完全展开，不用加载任何模型：

```python
import numpy as np

def normalized(a):
    a = np.asarray(a, dtype=float)
    norms = np.linalg.norm(a, axis=-1, keepdims=True)
    if not np.isfinite(a).all() or np.any(norms <= 1e-12):
        raise ValueError("有限非零向量才可归一化")
    return a/norms

names = ["猫", "汽车", "杯子"]
templates = np.array([[[1.,0.,0.],[0.9,0.1,0.]],
                      [[0.,1.,0.],[0.1,0.9,0.]],
                      [[0.,0.,1.],[0.,0.1,0.9]]])  # [类,模板,d]
class_vectors = normalized(normalized(templates).mean(axis=1))
images = normalized([[0.9,0.1,0.],[0.1,0.8,0.1],[0.,0.1,1.]])
similarity = images@class_vectors.T
print("分类", [names[i] for i in similarity.argmax(axis=1)])
# 查询杯子，用同一共享空间文本向量检索图像。
query = normalized([[0.,0.,1.]])
order = np.argsort(-(query@images.T)[0], kind="stable")
print("杯子查询图像序号", order.tolist())
assert similarity.argmax(axis=1).tolist() == [0,1,2] and order[0] == 2
```

索引保存模型/权重revision、预处理、维度、归一化方式与图像ID对应关系；改了编码器或输入处理，旧索引可能需重建。精确内积可用NumPy/Flat索引，IVF/HNSW/PQ等近似索引需根据数量、维度、内存与召回-延迟实测选择，不按100k/10M硬阈值推荐。空库、k大于库大小、近似搜索返回-1、坏图像和重复ID都要处理；不能把-1作为Python最后一项索引。

检索Recall@K需先有独立查询及正确图像集合；分清“至少检索一个相关图”的命中率与“相关图召回比例”，来源的20条手写查询不能没有相关标注就给Recall。检索、检测、分割、VQA是不同输出任务：CLIP相似度不提供坐标、像素边界或生成推理；并非所有视觉语言任务都是距离计算。

## 4. Vision-Language Models

视觉编码、Q-Former三任务mask、Flamingo媒体门控、变长多图与冻结语言模型的桥接反向见[16视觉编码与语言接入](16-视觉编码与语言接入实践.md)。CTC文档识别、事实证据与自定义对齐告警见[OCR与视觉语言专题](08-OCR视觉语言与可靠管道.md)。这里保持跨模态任务关系，机制只保留一个主要解释入口。

VLM 需要解决：

- visual encoding；
- modality projection / connector；
- cross-modal attention；
- language decoding；
- grounding。

应用：

- caption；
- VQA；
- OCR/document understanding；
- visual grounding；
- multimodal dialogue。

## 5. Visual Tokenisation

要让统一序列模型生成图像/视频，可以把连续视觉信号变成离散或潜空间 token。

典型方法：

- VQ-VAE；
- VQ-GAN；
- residual quantization；
- learned video tokenizer。

## 6. Cross-modal Generation

主要任务：

- text-to-image；
- text-to-video；
- text-to-audio；
- image editing / conditioning。

生成核心由[深度生成模型](../深度学习专题/10-深度生成模型.md)维护VAE、GAN、diffusion、flow等机制；图像条件、视频轴和视觉评价进入[视觉生成与视频时序](09-视觉生成与视频时序.md)，避免重复建立另一份生成讲解。

## 7. Unified Architecture

更进一步的路线是把文本、图像、音频甚至动作统一到共享 token / latent 空间，使一个模型可以：

- understand；
- generate；
- reason；
- act。

统一程度需要分开检查：输入encoder与表示是否共享、哪些骨干参数共享、每个模态预测什么、loss及监督位置怎样路由。统一系统可以有不同encoder和预测head，甚至text CE与连续图像去噪两种目标；不能只因loss不同就否认共享骨干，也不能只因维度相同就认为表示天然兼容。理解视觉输入、产生视觉输出和执行动作是不同接口，分别验证。

## 8. World Model

World model 学习环境动态：

```text
state / observation + action
→ next latent state / observation
```

它连接多模态理解、视频生成、机器人和Agent。动作条件、自由rollout和视觉证据的边界见[视觉时序实践](09-视觉生成与视频时序.md#9-从视频预测到动作条件世界模型)，控制与想象学习见[强化学习进阶与世界模型](../深度学习专题/15-强化学习进阶与世界模型.md)。

## 9. 训练与评估风险

必须关注：

- modality imbalance；
- shortcut learning；
- hallucinated grounding；
- temporal consistency；
- cross-modal data quality；
- benchmark contamination。

多模态“能说对”不代表“真的看对/听对”。

## 两张图与两段文字如何构成监督

有猫图 A、汽车图 B，配文分别为“猫躺在地上”“汽车停在路边”。构造 2×2 相似度矩阵，行对应图、列对应文；正确配对在对角线上。图到文和文到图的目标都希望对应项排名靠前。

自查：批里另有一段“猫在休息”，能把它对猫图无条件当作真负例吗？**答案：**不能，它可能也是正确描述，形成假负样本。配对质量和重复语义会影响对比训练，不能只追求更大 batch。

评估多模态模型时，可分别保留图像、遮住图像、换成不相关图像，再比较回答。如果三者几乎一样正确，任务可能主要由文字先验完成，不能据此证明视觉理解。
