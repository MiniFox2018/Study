# 03｜多模态学习

> 选修概览。先修：Embedding 相似度、对比学习直觉、Transformer。先解决样本配对与缺失模态，再考虑复杂统一架构。

## 1. 问题定义

多模态学习要让模型联合处理不同信息通道：

- text；
- image；
- video；
- audio；
- sensor / action。

难点不是简单拼接，而是让不同模态进入可对齐、可交互的表示空间。

## 2. Fusion

常见策略：

- early fusion：低层或输入附近融合；
- late fusion：各模态独立建模后融合；
- intermediate fusion：在中间层跨模态交互。

选择取决于：

- 模态是否同步；
- 是否可能缺失；
- 计算成本；
- 任务需要多深的交互。

## 3. Contrastive Alignment

CLIP 类方法通过正负配对让图像和文本靠近或远离。

核心目标可抽象为：

```text
matched pair → similarity ↑
mismatched pair → similarity ↓
```

InfoNCE 是常用对比目标。

ALIGN、SigLIP 等代表不同数据或训练目标设计。CLIP 常用批内双向 Softmax 对比目标；SigLIP 使用图文对的 Sigmoid 损失，不能把所有图文对齐方法都说成 InfoNCE。

## 4. Vision-Language Models

VLM 需要解决：

- visual encoding；
- modality projection / connector；
- cross-modal attention；
- language decoding；
- grounding。

应用：

- caption；
- VQA；
- OCR/document understanding；
- visual grounding；
- multimodal dialogue。

## 5. Visual Tokenisation

要让统一序列模型生成图像/视频，可以把连续视觉信号变成离散或潜空间 token。

典型方法：

- VQ-VAE；
- VQ-GAN；
- residual quantization；
- learned video tokenizer。

## 6. Cross-modal Generation

主要任务：

- text-to-image；
- text-to-video；
- text-to-audio；
- image editing / conditioning。

生成核心仍建立在 Study 的 VAE、GAN、diffusion、flow 等通用生成模型之上。

## 7. Unified Architecture

更进一步的路线是把文本、图像、音频甚至动作统一到共享 token / latent 空间，使一个模型可以：

- understand；
- generate；
- reason；
- act。

这里的关键不是某个产品名字，而是：

> 是否存在统一表示、统一序列建模和统一训练目标。

## 8. World Model

World model 学习环境动态：

```text
state / observation + action
→ next latent state / observation
```

它连接多模态理解、视频生成、机器人和 Agent。

## 9. 训练与评估风险

必须关注：

- modality imbalance；
- shortcut learning；
- hallucinated grounding；
- temporal consistency；
- cross-modal data quality；
- benchmark contamination。

多模态“能说对”不代表“真的看对/听对”。

来源：Compendium Chapter 10。

## 两张图与两段文字如何构成监督

有猫图 A、汽车图 B，配文分别为“猫躺在地上”“汽车停在路边”。构造 2×2 相似度矩阵，行对应图、列对应文；正确配对在对角线上。图到文和文到图的目标都希望对应项排名靠前。

自查：批里另有一段“猫在休息”，能把它对猫图无条件当作真负例吗？**答案：**不能，它可能也是正确描述，形成假负样本。配对质量和重复语义会影响对比训练，不能只追求更大 batch。

评估多模态模型时，可分别保留图像、遮住图像、换成不相关图像，再比较回答。如果三者几乎一样正确，任务可能主要由文字先验完成，不能据此证明视觉理解。

核验（2026-10-02）：[CLIP 原论文](https://proceedings.mlr.press/v139/radford21a.html)、[SigLIP 原论文](https://arxiv.org/abs/2303.15343)。
