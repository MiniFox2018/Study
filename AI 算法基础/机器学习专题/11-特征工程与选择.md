# 11｜特征工程与选择

> 先修：训练/验证/测试边界、均值方差、[线性模型](../04-经典监督学习.md)。本章把原始字段变成可部署的模型输入，再判断哪些字段值得保留。时间和发布时间对齐统一见[时间序列专题](13-时间序列与异常检测.md)，特征处理不是先在全数据上做一次清洗。

## 1. 从数据字典开始，不从“多造列”开始

一条样本是什么，目标何时发生，推理时能拿到哪些字段，决定了特征的合法性。例如预测客户下月流失，上月访问次数合法，“下月最后一次登录时间”不合法；预测售出前房价可以用面积，不能用成交后才计算的单价。每个字段记录单位、来源、更新时间、缺失含义、上线可得性，再提出变换。

有用的表示能让简单模型发现原来难学的关系：BMI 把身高和体重按机制组合；周期小时用正余弦使23点和0点相邻。特征的价值最终由匹配部署场景的验证评估决定，不凭名字把“预期影响高”当实证。

特征工程改变表示，如平方项或 TF-IDF；特征选择删掉表示中的部分列；PCA 把列混成新的方向。三个操作不同，PCA 不保留原始字段解释，见[降维专题](../数学与数值计算专题/03-SVD-PCA与降维.md)。

## 2. 缺失：先解释原因，再选填补

“没有购买”“设备没有上报”“字段未采集”不是同一状态。删行会改变人群，缺失若与目标相关可能产生选择偏差。均值填补保留样本数，但会压低该列方差、扭曲协方差，**不会保持原分布形状**；中位数较不受极端值影响，众数适合类别。缺失指示器给模型一个“这列原本缺失”的信号，部署时缺失机制改变仍会导致漂移。

具体例子 $[1,3,\text{缺失},100]$：已知值均值 $104/3=34.67$，中位数3。填补后的中间值代表一种估计，不能写成真实观测。训练集中整列缺失时，不能凭默认补0掩盖采集失败，应选业务允许的常量、明确丢弃或阻断训练，并保持输入 schema。

分组填补可以用地区内中位数，但地区统计必须只来自当前训练折，未见地区回退到训练总体值。模型填补也须遵守同样边界。时间数据前向填充只用过去，反向填充和双向插值常借用了未来，离线修复图表与在线预测须分开。

## 3. 数值变换：公式、目的和边界

| 变换 | 计算 | 何时考虑 | 必须检查 |
|---|---|---|---|
| 标准化 | $(x-\mu_{train})/\sigma_{train}$ | 距离、正则线性模型、梯度优化 | 零方差、异常值、训练统计复用 |
| Min-max | $(x-min_{train})/(max_{train}-min_{train})$ | 明确范围的比较 | 测试值可超出 $[0,1]$；不要暗中重新拟合 |
| Robust scaling | $(x-median_{train})/IQR_{train}$ | 少量极端值污染均值尺度 | IQR=0；不会删除或消灭异常 |
| 对数 | $\log x$ 或 $\log(1+x)$ | 正数右偏、乘法关系 | log 要 $x>0$，log1p 要 $x>-1$；不保证正态 |
| 分箱 | 按固定边界/训练分位点分段 | 可解释阈值、分段关系 | 丢信息、边界外值、重复分位点 |
| 多项式 | $x_1^2,x_1x_2,\ldots$ | 让线性模型学习曲线/交互 | 列数膨胀、尺度、正则化 |

StandardScaler 的标准差用总体约定 `ddof=0`，与某些统计函数默认样本标准差不同。缩放不把任意分布变成高斯。原图用狭长等高线与接近圆的等高线表示优化条件数改善：单位差异会导致梯度之字形；标准化有时缓解，但强相关列仍可让等高线细长，不能保证损失面变圆。

例如 $[1,2,3,100]$ 的均值/标准差受100影响，RobustScaler 用中位数2.5和四分位距减少极端值对普通样本尺度的支配。树按阈值分裂，对严格单调变换通常较不敏感；正则线性模型、SVM/KNN/K-Means 更依赖表示。离散化、缺失编码、有限精度仍可能改变树结果。

交互项以机制为先：价格/面积、销量/曝光、两个数值乘积；分母接近0要定义缺失、截断或业务分组，不能无限大。小时 $h$ 可编码 $(\sin(2\pi h/24),\cos(2\pi h/24))$，两个值一起用；只用正弦会让某些不同小时重合。

## 4. 类别编码：无序类别不能凭整数制造次序

One-hot 为每类生成一列，红/蓝/绿不自带大小关系。高基数会增加列数，可用稀疏输出、合并低频类别、哈希，或在有足够重复样本时考虑目标编码。未知类别要有明确策略，如 `handle_unknown="ignore"` 得全0；同时监控未知率，避免上线静默失去信号。

Ordinal 编码适合本身有序的“小/中/大”，应指定真实次序。给无序城市编号0/1/2再送入按数值阈值分裂的普通树，仍然施加了人为排序，树可能需要多层才能表达任意子集；不能说“树模型整数编码总是安全”。支持原生 categorical 分裂的库是另一实现。`LabelEncoder` 常用于目标 y，特征列优先用相应 encoder。

频率编码替换为训练中出现频率，成本低但不同类别可能得到相同值；哈希固定维度但会碰撞，须用实验选维度；embedding 需学习数据和训练过程，既不是自动更好，也不能把任意预训练向量直接认作业务类别含义。

### 4.1 目标编码与折外计算

类别 c 的平滑均值：

$$
TE(c)=\frac{n_c\bar y_c+\alpha\bar y}{n_c+\alpha},\quad\alpha\ge0.
$$

小样本类别向整体均值收缩。例如整体正率0.2，某类别2条且都正，$\alpha=8$ 得 $(2+1.6)/10=0.36$，比1保守。平滑不是泄漏免疫：若每类别只有一人，无平滑训练编码直接等于标签。

训练样本用其他折学习到的映射编码；验证/测试用全部训练样本拟合的映射，未知类别回退训练均值。外层做交叉验证时，目标编码的整个内部过程又须在外层训练折内完成。对时间/重复实体，内部折也须符合时间或分组边界，不能用普通随机折掩盖未来和同人重复。

完整教学代码假定类别已是完整字符串；缺失先转为明确token。程序展示训练 OOF 与测试映射，数据假定近似独立；实际 pipeline 可以用官方 `TargetEncoder`。其 `fit_transform(X,y)` 有内部 cross fitting，与 `fit(X,y).transform(X)` 不等价。

```python
import numpy as np
from sklearn.model_selection import KFold

def target_mapping(cats, y, alpha=5.):
    cats, y = np.asarray(cats), np.asarray(y, dtype=float)
    mean = float(y.mean())
    mapping = {}
    for c in np.unique(cats):
        values = y[cats == c]
        mapping[c] = (values.sum() + alpha * mean) / (len(values) + alpha)
    return mapping, mean

def encode(cats, mapping, fallback):
    return np.array([mapping.get(c, fallback) for c in cats])

def oof_target_encode(cats, y, test_cats, n_splits=3, alpha=5.):
    cats, y = np.asarray(cats), np.asarray(y)
    result = np.empty(len(y))
    splitter = KFold(n_splits=n_splits, shuffle=True, random_state=7)
    for train, valid in splitter.split(cats):
        mapping, mean = target_mapping(cats[train], y[train], alpha)
        result[valid] = encode(cats[valid], mapping, mean)
    mapping, mean = target_mapping(cats, y, alpha)
    return result, encode(test_cats, mapping, mean)

cats = np.array(["甲", "甲", "乙", "乙", "丙", "丙"])
y = np.array([1, 1, 0, 1, 0, 0])
train_enc, test_enc = oof_target_encode(cats, y, ["甲", "未知"])
assert np.isclose(test_enc[-1], y.mean())
print("训练折外编码", train_enc.round(3), "测试", test_enc.round(3))
```

Leave-one-out 是从类别统计中减掉自己的目标；单例必须回退。它比直接自编码少一条泄漏路径，但同人多行、时间穿越、相互依赖和弱正则仍可能导致过拟合；优先使用符合部署切分的 cross fitting。不能仅“不使用测试标签”就算目标编码做好。

## 5. 文本：从词计数到 TF-IDF

先在训练文本建立词表，对每文档统计词数。TF 可用次数或次数/文档词数；IDF 一种教材定义为 $\log(N/df(w))$。若3篇文本都含“模型”，它的 IDF=0；“核函数”仅在1篇出现，则 IDF=$\log3$。这样把常见词降权，但罕见拼写错误也可能高权，不能等同于“稀有词就是好特征”。

sklearn 默认用平滑 $idf=\log((1+N)/(1+df))+1$，TF 默认为原始词数，最后 L2 归一化。两种定义都可用，须写明约定，不把手写未平滑输出与库输出差异视为错误。词表和 IDF 都只从训练集学习，测试未见词通常被忽略。

中文原文不能照搬按空格分词；可使用合适分词器，或字符/字 n-gram 建立不依赖分词的基线。TF-IDF适合很多短文本和长文本分类任务，embedding 也可用于短文本；不是按“长/短”一条规则选型。文本长度、符号数等结构特征可补充，但要检查它们是否仅反映采集批次。

## 6. 完整预处理程序：只在训练上 fit

下面人工生成“面积、房龄、地区、描述”预测房价，示例只演示数据边界，不代表真实房产估值。未知地区仍可处理，文本按字符 n-gram；模型为带正则线性回归。

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_absolute_error

rng = np.random.default_rng(7)
n = 160
area = rng.uniform(40, 160, n)
age = rng.uniform(0, 30, n)
region = rng.choice(["中心", "郊区", "乡镇"], n)
y = 1.5 * area - .8 * age + np.where(region == "中心", 40, 0) + rng.normal(0, 5, n)
df = pd.DataFrame({"面积": area, "房龄": age, "地区": region,
                   "描述": np.where(area > 100, "空间宽敞采光好", "小户型交通方便")})
df.loc[rng.choice(n, 12, replace=False), "面积"] = np.nan
X_train, X_test, y_train, y_test = train_test_split(df, y, test_size=.25, random_state=7)
numeric = Pipeline([("填补", SimpleImputer(strategy="median", add_indicator=True)),
                    ("缩放", StandardScaler())])
category = Pipeline([("填补", SimpleImputer(strategy="most_frequent")),
                     ("编码", OneHotEncoder(handle_unknown="ignore"))])
preprocess = ColumnTransformer([
    ("数值", numeric, ["面积", "房龄"]),
    ("类别", category, ["地区"]),
    ("文本", TfidfVectorizer(analyzer="char", ngram_range=(1, 2)), "描述"),
])
pipe = Pipeline([("预处理", preprocess), ("回归", Ridge(alpha=1., solver="lsqr"))])
pipe.fit(X_train, y_train)
pred = pipe.predict(X_test)
assert np.isfinite(pred).all() and pred.shape == y_test.shape
print("房价合成实验 MAE", round(mean_absolute_error(y_test, pred), 3))
new = pd.DataFrame({"面积": [80.], "房龄": [5.], "地区": ["未见地区"], "描述": ["交通便利"]})
print("新样本预测", pipe.predict(new).round(2))
```

本次固定种子合成实验的MAE约8.280、未见地区新样本预测约126.82，只用于核对程序。`SimpleImputer(add_indicator=True)`默认只为fit时见过缺失的列增加指示列；若上线新列缺失，要另有完整schema和监测，不能假设自动覆盖。

类别字段的缺失 token、数值单位和输入 dtype 应固定；文本空值要在业务层变成空串或适当占位。上线保存整个 pipeline，不只保存模型系数。修改 encoder 的词表、类别顺序或列顺序会让旧模型失配。

## 7. 特征选择：四种证据不能互换

### 7.1 Filter：统计筛选

VarianceThreshold 不用 y，只能删除常量或按阈值删除低变异列。方差受单位影响；一个仅千分之一出现的故障信号可能非常重要，不能按“低于0.01必无用”删除。先查业务意义和训练支持度，再定阈值。

Pearson 相关只描述线性关系。两个高度相关列可能冗余，但细微差异也可能有用；保留谁应考虑测量成本、缺失、上线稳定性及折内验证。相关高不自动证明“没有额外信息”。

互信息 $I(X;Y)=\sum p(x,y)\log[p(x,y)/(p(x)p(y))]$ 衡量统计依赖，独立时为0。连续分箱得到估计，分箱太细会把有限样本噪声当依赖；sklearn 连续特征通常使用近邻估计，离散标识须设对。单变量 MI 不看组合：两个独立公平比特 $X_1,X_2$，$Y=X_1\oplus X_2$，各自 MI 都为0，但组合完全决定目标。

下面手算 MI 单位为 nat，完整程序同时展示线性相关失灵和 XOR：

```python
import numpy as np

def discrete_mi(x, y):
    x, y = np.asarray(x), np.asarray(y)
    if len(x) != len(y) or not len(y):
        raise ValueError("样本数不匹配或为空")
    total = 0.
    for a in np.unique(x):
        for b in np.unique(y):
            pxy = np.mean((x == a) & (y == b))
            if pxy:
                total += pxy * np.log(pxy / (np.mean(x == a) * np.mean(y == b)))
    return total

x = np.array([-2, -1, 0, 1, 2])
y = x ** 2
assert abs(np.corrcoef(x, y)[0, 1]) < 1e-12
assert discrete_mi(x, y) > 0
a = np.array([0, 0, 1, 1]); b = np.array([0, 1, 0, 1]); target = a ^ b
assert abs(discrete_mi(a, target)) < 1e-12
print("二次关系 MI", round(discrete_mi(x, y), 3), "XOR 单列 MI", discrete_mi(a, target))
```

卡方检验适合非负计数或合理离散特征与类别目标，比较观测与独立性期望计数：$\chi^2=\sum(O-E)^2/E$。例如文档词频可以；标准化后的负值列不能直接传给 sklearn `chi2`。显著性不是因果，也不是多重检验后的自动选列许可证，列数多时须考虑错误发现与外部验证。

### 7.2 Wrapper：反复拟合子集

RFE 每轮拟合、排序、删除较弱列、重新拟合，直到目标列数；能重新评估冗余替代，不保证找到最佳组合，也只反映基模型能表达的关系。线性系数排序前需标准化。逐列删除成本高，可按比例删；RFECV/外层验证选择列数，最终测试不参与。

Forward selection 从空集起，每轮选使折内验证最好的一列；一般约评估 $d+(d-1)+\ldots$ 个候选，RFE 逐轮通常只拟合一个模型，所以“前向必更快”不成立。可设最小增益与预算，候选选择仍放在训练部分。稀疏输入、强交互和不稳定小样本要特别核对。

### 7.3 Embedded：训练时稀疏化

L1 惩罚 $\alpha\sum_j|w_j|$ 可得到精确0；对光滑损失一次近端梯度为先算 $u=w-\eta\nabla L$，再做 $w_j=\operatorname{sign}(u_j)\max(|u_j|-\eta\alpha,0)$，截距通常不惩罚。回归用 Lasso，分类用合适的 L1 LogisticRegression；不要把上游手写“逻辑损失+L1”叫成平方损失 Lasso。

高度相关列中 L1 可能不稳定地选择其中之一，不能宣称可靠自动识别真实变量；Elastic Net 混合 L1/L2 可缓解组内竞争。L1 是惩罚方式，不限于原始线性特征；加入非线性基函数后也能筛它们，但无法凭稀疏系数证明因果。

Tree impurity importance 累加各分裂对不纯度的加权下降并归一化。高基数和随机ID可能因可尝试阈值多得到偏高训练重要性，需验证集核对。真正随机森林通常每个节点再抽特征；上游选一组列给整棵树，更接近随机子空间的简化，不能混为完整实现。

### 7.4 Permutation：模型在验证数据依赖哪列

保持模型固定，打乱验证集某一列，计算基准分数减去打乱分数，多次重复报告平均与离散度。它衡量**该拟合模型**在**该数据**的依赖，不是该特征内在信息，更不是因果贡献。模型本来很差，重要性低也不能说所有列无用；两个相关列可互相替代，单列置换得分下降较小，可再做按相关组联合置换。

时间数据逐行任意打乱可能造出不可能样本；需块置换或符合业务的扰动。反复用验证置换结果改特征，本身也在调参；最终保留未参与选择的测试集。图中的“低条形变淡”表示一个筛选候选，而不是证明删除后过拟合消失。

## 8. 完整选择实验：同一切分比较，测试保持独立

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, StratifiedKFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import VarianceThreshold, SelectKBest, mutual_info_classif, RFE
from sklearn.linear_model import LogisticRegression
from sklearn.inspection import permutation_importance
from sklearn.metrics import f1_score

X, y = make_classification(n_samples=500, n_features=16, n_informative=5,
                           n_redundant=3, class_sep=1.2, random_state=7)
X = np.c_[X, np.zeros(len(X))]
Xtr, Xte, ytr, yte = train_test_split(X, y, stratify=y, test_size=.25, random_state=7)
cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=7)
def mi(X, y):
    return mutual_info_classif(X, y, random_state=7)
def pipeline(select=False):
    steps = [("常量筛选", VarianceThreshold()), ("缩放", StandardScaler())]
    if select:
        steps += [("互信息", SelectKBest(mi, k=10)),
                  ("递归选择", RFE(LogisticRegression(C=1., max_iter=1000), n_features_to_select=6, step=2))]
    return Pipeline(steps + [("分类", LogisticRegression(C=1., max_iter=1000))])

models = {"全部非恒定列": pipeline(), "MI加RFE": pipeline(True)}
scores = {}
for name, model in models.items():
    scores[name] = cross_val_score(model, Xtr, ytr, cv=cv, scoring="f1").mean()
    print(name, "训练内部 CV F1", round(scores[name], 3))
name = max(scores, key=scores.get)
best = models[name].fit(Xtr, ytr)
pred = best.predict(Xte)
print("内部选中", name, "最终测试 F1", round(f1_score(yte, pred), 3))
# 以下仅做解释；若依据它改特征，此测试集已不再是独立最终测试。
importance = permutation_importance(best, Xte, yte, scoring="f1", n_repeats=5, random_state=7)
print("测试解释前五列", np.argsort(importance.importances_mean)[-5:][::-1])
assert np.isfinite(importance.importances_mean).all()
```

若筛选没改善分数，可因成本、稳定性或可解释性仍选简化版，但要报告取舍。不能保证“10好列一定胜10好列加90噪声”；有效正则和大数据也可能控制噪声，实验才能判断。筛掉列后还要记录原始字段到变换后字段映射，防把第5个输出列误当原表第5列。

## 9. 练习与参考判断

1. 对 $[1,3,\text{缺失},100]$ 均值和中位数填补各是什么？**答案：**34.67与3；都人为插入值，不能说分布保真。
2. RobustScaler 面对异常值为什么有用，为什么还不能当检测器？**答案：**中位数与 IQR 更少受少数极端值影响，但不定义异常身份、也不消除极端点。可用同数据运行两个 scaler，对比普通点尺度；IQR=0须单独处理。
3. 类别只有一条样本，leave-one-out 怎么算？**答案：**类别分母变0，回退不包含该样本的整体训练统计或使用内部折映射；不能除0或回退本行标签。
4. 高相关列怎么去重更稳妥？**答案：**训练折内计算相关与 MI，构造相关组，结合成本/稳定性选代表，或保留做正则比较；按遍历顺序随手删只是一种启发式。
5. 50 次80%子采样做 L1 稳定性选择，选择频率大于80%代表什么？**答案：**在当前采样、alpha和模型下较稳定；相关替代列频率可能被分摊。这个经验阈值不自动获得论文错误率保证，须记录设置与留出性能。
6. MI→RFE为何可能比直接RFE快又更差？**答案：**候选列少减少拟合成本，但 MI 可能提前丢掉仅交互有用的列，RFE无法恢复；同时记录耗时、选择数和外层分数。
7. 怎么手写置换重要性？**答案：**复制验证矩阵，每次只打乱列j，预测算F1，保存基准减F1；重复10次求均值/标准差，原矩阵不被原地破坏。强相关列尝试联合置换，并说明不代表因果。
8. 上游房价演示先用全部数据填补/缩放，是不是可直接部署流程？**答案：**不是，只展示变换算术。训练评估须先切分、每折拟合；本章第6节给出完整安全边界。

9. 怎样从零实现前向选择？**答案：**训练开发集内做CV；从空集起，逐个试加未选列，选择CV增益最高者，只在增益超过预先定阈值时继续。保存列序与每轮分数，最终外层验收；其候选拟合次数常比RFE多，二者谁快谁准不能预定。
