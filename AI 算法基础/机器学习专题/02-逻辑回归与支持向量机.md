# 02｜逻辑回归与支持向量机

> 先修：[线性回归](01-线性回归与正则化.md)、点积、[优化与凸性](../数学与数值计算专题/07-优化方法与凸性条件.md)。先学第 1～5 节的概率分类，再学第 6～10 节的间隔分类。两个模型都可作线性基线，但优化目标、输出含义和非线性扩展不同。

## 1. 分类需要区分分数、概率和决策

线性回归可以拟合 0/1 标签，却可能输出 -0.2 或 1.3，无法直接解释为事件概率。逻辑回归用：

$$
z=w^\mathsf Tx+b,\quad p=\sigma(z)=\frac1{1+e^{-z}},\quad
\log\frac p{1-p}=w^\mathsf Tx+b.
$$

$z$ 是 logit，$p$ 是模型给出的 $P(y=1\mid x)$，$\hat y=\mathbf1[p\ge t]$ 才是类别。数学上有限 logit 给 $0<p<1$，但浮点计算可能舍入成 0 或 1。它不是把预测“随便裁到 0～1”，而是对**对数几率**建立线性模型；因此仍称回归，同时可用于分类。

$\sigma(0)=0.5$，$\sigma(2)\approx0.8808$，$\sigma(-2)\approx0.1192$。导数为 $\sigma'(z)=p(1-p)$。在其他输入固定时，特征增加 1 单位让几率乘 $e^{w_j}$，并不让概率增加固定 $w_j$，更不说明该变量是因果因素。

阈值 $t=0.5$ 的边界是 $w^\mathsf Tx+b=0$；一般阈值满足：

$$
w^\mathsf Tx+b=\log\frac t{1-t}.
$$

来源 S 曲线图改变 $|w|$ 会改变过渡陡峭程度，改变 $b$ 会平移边界。单特征且 $w\ne0$ 时，0.5 边界是 $x^*=-b/w$；$w=0$ 时概率处处相同，不存在普通单点边界。多特征在线性输入空间中给超平面；先映射 $x^2$、交互或其他非线性特征，则原输入中的边界可以弯曲。

Sigmoid 不会自动消除异常值、标签错误和数据偏移。高杠杆样本仍可能影响拟合；概率输出也不自动意味着已校准。

## 2. 从 Bernoulli 似然推导交叉熵与梯度

标签 $y_i\in\{0,1\}$。在样本条件独立的模型下，似然是 $\prod_i p_i^{y_i}(1-p_i)^{1-y_i}$；取负对数并平均：

$$
L=-\frac1N\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)].
$$

$y=1,p=0.9$ 时单样本损失约 0.1054，$p=0.1$ 时约 2.3026，因此对“自信地错”罚得更重。化为 logit 形式更稳定：

$$
\ell(z,y)=\log(1+e^z)-yz,
\quad\partial_z\ell=p-y.
$$

NumPy 用 `np.logaddexp(0, z)-y*z`，不先算 `log(sigmoid(z))`。按符号分支计算 sigmoid 可避免 `exp(1000)` 溢出。裁概率用于报告能避免取对数零，但若训练时把裁剪函数的值和未裁剪梯度混用，应明确这是数值近似。

最终梯度是：

$$
\nabla_w L=\frac1N X^\mathsf T(p-y),\qquad
\partial_bL=\frac1N\sum_i(p_i-y_i).
$$

初始零参数给每条 $p_i=0.5$。对 $x=(-1,1),y=(0,1)$，权重梯度是 $[(-1)(0.5)+(1)(-0.5)]/2=-0.5$，偏置梯度为 0；学习率 0.2 给 $w=0.1$。此时正点概率约 0.525，开始朝正确方向移动。

### 2.1 为什么不用平方误差，以及凸性的边界

Sigmoid 加平方误差**可以计算和训练**，不是数学上禁止；但它不是 Bernoulli 的负对数似然，一般对参数非凸，且梯度额外乘 $p(1-p)$，饱和时即使分类错也可能很小。标准逻辑回归优先交叉熵。

线性 logit 的 Hessian 是 $X^\mathsf T\operatorname{diag}(p_i(1-p_i))X/N$，因此目标凸。凸性不保证“唯一有限全局最小值”：重复特征可能非唯一；完全可分数据的未正则似然可以靠系数越来越大逼近上确界，却没有有限 MLE。正则化和正确停止仍重要。Softmax 也有把各类分数一起平移不变的参数冗余。

## 3. 完整手写二分类与多分类

NumPy 程序使用训练集标准化和 L2 权重惩罚。二分类目标为平均 BCE 加 $\lambda\|w\|^2/2$，所以权重梯度增加 $\lambda w$；截距不罚。多分类使用同一约定，类别必须互斥且为 0 到 $K-1$。

```python
import numpy as np

def sigmoid(z):
    z = np.asarray(z, dtype=float)
    out = np.empty_like(z)
    positive = z >= 0
    out[positive] = 1/(1+np.exp(-z[positive]))
    e = np.exp(z[~positive])
    out[~positive] = e/(1+e)
    return out

def fit_binary(X, y, steps=2000, rate=0.2, lam=0.01):
    if X.ndim != 2 or y.shape != (len(X),) or not np.isin(y, [0, 1]).all():
        raise ValueError("二维特征及0/1标签不匹配")
    w, b = np.zeros(X.shape[1]), 0.0
    history = []
    for _ in range(steps):
        z = X @ w+b
        error = sigmoid(z)-y
        dw, db = X.T @ error/len(y)+lam*w, error.mean()
        history.append(np.mean(np.logaddexp(0, z)-y*z)+lam*(w @ w)/2)
        w, b = w-rate*dw, b-rate*db
    return w, b, history

def softmax(scores):
    scores = scores-scores.max(axis=1, keepdims=True)
    weights = np.exp(scores)
    return weights/weights.sum(axis=1, keepdims=True)

def fit_softmax(X, y, classes, steps=2000, rate=0.2, lam=0.01):
    if y.shape != (len(X),) or not np.isin(y, np.arange(classes)).all():
        raise ValueError("标签应在0到类别数减1之间")
    W, b = np.zeros((X.shape[1], classes)), np.zeros(classes)
    targets = np.eye(classes)[y]
    for _ in range(steps):
        error = softmax(X @ W+b)-targets
        dW, db = X.T @ error/len(y)+lam*W, error.mean(0)
        W, b = W-rate*dW, b-rate*db
    return W, b

rng = np.random.default_rng(42)
centers = np.array([[-2, -1], [2, -1], [0, 2]])
X = np.vstack([rng.normal(c, 0.6, (60, 2)) for c in centers])
y = np.repeat(np.arange(3), 60)
order = rng.permutation(len(y))
tr, te = order[:135], order[135:]
mean, scale = X[tr].mean(0), X[tr].std(0)
Z = (X-mean)/np.where(scale == 0, 1, scale)
W, b = fit_softmax(Z[tr], y[tr], 3)
p = softmax(Z[te] @ W+b)
pred = p.argmax(1)
cm = np.zeros((3, 3), dtype=int)
np.add.at(cm, (y[te], pred), 1)
print("Softmax测试准确率", round(np.mean(pred == y[te]), 4))
print("行是真实类，列是预测类\n", cm)
for c in range(3):
    precision = cm[c, c]/cm[:, c].sum() if cm[:, c].sum() else 0.0
    recall = cm[c, c]/cm[c].sum() if cm[c].sum() else 0.0
    print("类别", c, "precision", round(precision, 4), "recall", round(recall, 4))
assert np.allclose(p.sum(1), 1)
binary_tr = tr[y[tr] < 2]
binary_te = te[y[te] < 2]
w2, b2, history = fit_binary(Z[binary_tr], y[binary_tr])
prob = sigmoid(Z[binary_te] @ w2+b2)
print("二分类准确率", round(np.mean((prob >= 0.5) == y[binary_te]), 4))
print("二分类损失首末", round(history[0], 4), round(history[-1], 4))
assert history[-1] < history[0]
assert np.isfinite(sigmoid(np.array([-1000., 1000.]))).all()
```

多分类公式为 $z_{ik}=x_i^\mathsf Tw_k+b_k$，$p_{ik}=e^{z_{ik}}/\sum_j e^{z_{ij}}$；减每行最大值不改变比例，却避免溢出。交叉熵 $-\sum_i\log p_{i,y_i}/N$，矩阵梯度为 $X^\mathsf T(P-Y)/N$。多标签任务可能一条记录有多个成立标签，应独立 sigmoid 与逐标签目标，不能强制 Softmax 只能选一个。

## 4. 混淆矩阵、阈值与 ROC 的可核对例子

规定正类为 1。Precision 是 $TP/(TP+FP)$；Recall 是 $TP/(TP+FN)$；F1 是 $2TP/(2TP+FP+FN)$。F1 **不是 balanced accuracy**，后者在二分类中为 $(TPR+TNR)/2$。某个分母为零时要记录未定义或软件采用的零值约定。

例如 TP=6、FP=2、FN=4、TN=88，准确率 0.94，Precision=0.75，Recall=0.60，F1=2/3。这个模型仍漏掉 40% 正例；“准确率94%”不能替代此信息。Precision=0.95、Recall=0.60 表示被标为垃圾的邮件95%确实是垃圾，但实际垃圾只抓到60%，两个条件的分母不能互换。

降低阈值会扩大预测正例集合，同一批固定分数上的 Recall 不下降、FPR 不下降；Precision **可能升也可能降**，并非严格单调。阈值应在验证数据选择并冻结，不能扫测试集后报告其中最好一项。

若模型概率已适当校准，误报成本为 $c_{FP}$、漏报成本为 $c_{FN}$，正确预测的损失设为零，比较 $c_{FP}(1-p)$ 与 $c_{FN}p$，得阈值 $c_{FP}/(c_{FP}+c_{FN})$。成本、概率校准、样本分布变化都会影响这一决策，不能把 0.5 永久当最优。

ROC 横轴 $FPR=FP/(FP+TN)$，纵轴 $TPR=Recall$。精确经验 ROC 按**不同分数**变化阈值，并将同分记录一起处理；只扫 100 个等间距阈值可能漏掉窄区间变化。

```python
import numpy as np

y = np.array([0, 0, 1, 1])
score = np.array([0.1, 0.4, 0.35, 0.8])
thresholds = np.r_[np.inf, np.sort(np.unique(score))[::-1], -np.inf]
points = []
for t in thresholds:
    pred = score >= t
    tpr = np.mean(pred[y == 1])
    fpr = np.mean(pred[y == 0])
    points.append((fpr, tpr))
points = np.array(points)
auc = np.sum(np.diff(points[:, 0])*(points[1:, 1]+points[:-1, 1])/2)
print("ROC点", points.tolist(), "AUC", auc)
assert np.isclose(auc, 0.75)
```

AUC=0.75 也可由四个正负配对中三对排序正确得到。测试中只有一个类别时，ROC/AUC 不具备通常定义。极不平衡任务还应看 PR 曲线、类别分布与操作阈值成本；AUC 不是上线收益。

## 5. 圆形边界例子：先改变表示，再增加模型复杂度

以下完整程序需要 scikit-learn。先用训练/验证选择表示和参数，最终测试一次；两个模型在同一划分比较。用平方半径可以线性分离同心圆，说明失败可能来自表示，而不是优化器。

```python
from sklearn.datasets import make_circles
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler, PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC

X, y = make_circles(n_samples=300, factor=0.4, noise=0.06, random_state=42)
Xdev, Xtest, ydev, ytest = train_test_split(X, y, test_size=0.2, stratify=y, random_state=5)
Xtr, Xval, ytr, yval = train_test_split(Xdev, ydev, test_size=0.25, stratify=ydev, random_state=6)
candidates = {
    "线性Logistic": make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)),
    "二次Logistic": make_pipeline(PolynomialFeatures(2, include_bias=False),
                                   StandardScaler(), LogisticRegression(C=10, max_iter=2000)),
    "线性SVM": make_pipeline(StandardScaler(), SVC(kernel="linear", C=1)),
    "RBFSVM": make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1, gamma="scale")),
}
scores = []
for name, model in candidates.items():
    model.fit(Xtr, ytr)
    value = model.score(Xval, yval)
    scores.append((value, name))
    print(name, "验证准确率", round(value, 4))
_, chosen = max(scores)
candidates[chosen].fit(Xdev, ydev)
print("验证选中", chosen, "最终测试准确率", round(candidates[chosen].score(Xtest, ytest), 4))
```

不能说库版本和手写程序必给完全相同的系数：默认正则、求解器、数据随机流和停止条件可能不同。比较机制正确性应对齐数据、损失、正则及容差；不应拿两份不同生成数据上的相近准确率证明实现相同。

Logistic 基线流程是先切分，再每折拟合缺失填充、类别编码、缩放和模型。稀疏文本通常直接用 TF-IDF，可选择不中心化的缩放；不因“特征超过一万”就机械规定 L1。加权类别训练改变目标和概率解释，应另验校准。模型升级由验证误差和误判结构决定，不由固定样本行数决定。

## 6. SVM：用间隔比较多个分隔面

SVM 本节标签用 $y_i\in\{-1,+1\}$。令 $f(x)=w^\mathsf Tx+b$，点到超平面的距离是 $|f(x)|/\|w\|$。由于同时放大 $w,b$ 不改变分类面，硬间隔用规范化约束固定尺度：

$$
\min_{w,b}\frac12\|w\|^2,\qquad y_if(x_i)\ge1.
$$

两条边界 $f(x)=\pm1$ 之间宽度为 $2/\|w\|$，单侧几何间隔为 $1/\|w\|$；两者不能混称成同一个距离。硬间隔必须线性可分。权重目标严格凸，但偏置及对偶解仍有退化边界，不能只因“凸”就无条件承诺任何参数都唯一。

简单一维例子：负点 -2、-1，正点 1、2。硬间隔最优 $w=1,b=0$，支持点 -1、1，街宽为 2；其余点的规范化间隔为 2。源图旋转超平面、改变虚线宽度是在解释几何；任意手动位置不一定满足所有约束，金色圈的阈值识别也不是求出最优 SVM 的算法。

在固定训练最优解、已满足约束的条件下，去掉不活跃点通常不改变这个解；**把非支持点任意移动到间隔内**会改变约束和模型，不能说“移动所有其他点都不影响”。更宽间隔的泛化结论依赖特征尺度、样本分布与模型假设，不能跨不同数据集只比街宽就排性能。

## 7. 软间隔、Hinge 与支持向量的正确判定

真实数据含噪声，软间隔加入违约量 $\xi_i\ge0$：

$$
\min_{w,b,\xi}\frac12\|w\|^2+C\sum_i\xi_i,
\quad y_if(x_i)\ge1-\xi_i.
$$

等价于 $\frac12\|w\|^2+C\sum_i\max(0,1-y_if(x_i))$。$C$ 大更重视违约惩罚，$C$ 小相对更重视权重正则；“大 C 必过拟合、小 C 必欠拟合”只是可能趋势，必须验证。违约包含分类正确但进了间隔的点，不只误分类。

设 $m_i=y_if(x_i)$：

| $m_i$ | 含义 | Hinge 值 |
|---|---|---|
| -0.5 | 分类错误 | 1.5 |
| 0 | 在决策面，类别由并列约定决定 | 1 |
| 0.5 | 分类正确，仍在间隔内 | 0.5 |
| 1 | 在间隔边界 | 0 |
| 2 | 正确且在间隔外 | 0 |

在软间隔最优解中，支持向量对应对偶乘子 $\alpha_i>0$。$0<\alpha_i<C$ 通常在 $m_i=1$；$\alpha_i=C$ 可在间隔内，甚至误分类。只统计 `abs(m-1)<tol` 会漏掉后者，也无法在未收敛原始迭代中严格恢复对偶支持集。成熟 `SVC.support_` 是实现返回的支持索引；教学程序的 active hinge 点只能叫“当前活跃样本”。

改成平均 Hinge 的目标：

$$
J=\frac\lambda2\|w\|^2+\frac1N\sum_i\max(0,1-y_if_i),
\qquad \lambda=\frac1{CN}.
$$

这里是损失缩放下的对应关系，不能忽略 $N$ 把 $C=1/\lambda$ 套到所有实现。批量次梯度是 $\lambda w-\sum_{m_i<1}y_ix_i/N$，偏置次梯度为 $-\sum_{m_i<1}y_i/N$。在 $m=1$ 不可微，可选合法次梯度，常取该样本损失贡献为零。

```python
import numpy as np

X = np.array([[-2.], [-1.], [1.], [2.]])
y = np.array([-1., -1., 1., 1.])
w, b, lam = np.zeros(1), 0.0, 0.2
history = []
for step in range(4000):
    margin = y*(X @ w+b)
    active = margin < 1
    dw = lam*w-(X[active].T @ y[active])/len(y)
    db = -y[active].sum()/len(y)
    rate = 0.1/np.sqrt(step+1)
    history.append(lam*(w @ w)/2+np.maximum(0, 1-margin).mean())
    w, b = w-rate*dw, b-rate*db
margin = y*(X @ w+b)
print("权重/偏置", np.round(w, 4), round(b, 4))
print("规范化间隔", np.round(margin, 4), "街宽", round(2/np.linalg.norm(w), 4))
print("活跃Hinge索引", np.flatnonzero(margin < 1).tolist())
assert np.all((X @ w+b)*y > 0) and history[-1] < history[0]
```

这是凸非光滑目标的次梯度教学实现，用递减步长改善振荡；不是完整生产 QP 求解器。Hinge 到 1 即截断，Logistic 的 $\log(1+e^{-m})$ 在有限 $m$ 下不为零，所以训练梯度关注样本不同。**线性** SVM 和 Logistic 预测都可只存 $w,b$，都是 $O(d)$ 点积；不能因 SVM 有支持向量就宣称 Logistic 预测要存所有训练点。

## 8. 对偶与核：相似度为什么必须有条件

软间隔对偶为：

$$
\max_\alpha\sum_i\alpha_i-\frac12\sum_{ij}\alpha_i\alpha_jy_iy_jK(x_i,x_j),
\quad0\le\alpha_i\le C,\quad\sum_i\alpha_i y_i=0.
$$

预测 $f(x)=\sum_{i:\alpha_i>0}\alpha_iy_iK(x_i,x)+b$。若 $K(x,z)=\phi(x)^\mathsf T\phi(z)$，就能在原空间计算特征空间内积。任意“相似度函数”不自动是合法核；需要相应对称、半正定条件。

- 线性核 $x^\mathsf Tz$：适合线性表示、高维稀疏文本的首个对照，但不能保证文本一定线性可分。
- 多项式核 $(\gamma x^\mathsf Tz+r)^q$：通常选择整数 $q\ge1,\gamma\ge0,r\ge0$ 保持标准半正定构造；阶数和尺度要验证。比如二维齐次二次核的映射为 $(x_1^2,\sqrt2x_1x_2,x_2^2)$，其点积恰好等于 $(x^\mathsf Tz)^2$，不能漏交叉项的 $\sqrt2$。
- RBF 核 $\exp(-\gamma\|x-z\|^2)$，$\gamma>0$：局部相似度，对应无限维特征空间。高 gamma 缩小影响范围，常更灵活；低 gamma 扩大范围，常更平滑。它有丰富表达能力，有限数据、参数与训练不保证学会任何真实边界。

RBF 的 $C$ 和 gamma 一起验证：低 gamma 可能欠拟合，高 gamma 可能记住局部噪声；C 可能部分补偿，但不存在“低gamma高C必过拟合”的固定组合表。当前 `SVC(gamma="scale")` 使用 $1/(d\operatorname{Var}(X))$，`"auto"` 才是 $1/d$。标准化是在训练折内进行，稀疏输入注意不能中心化成稠密巨矩阵。

可从 $C\in\{0.01,0.1,1,10,100\}$、$\gamma\in\{0.01,0.1,1,10\}$ 作粗对数网格；验证最优在边界时按预算扩范围，再局部细化。搜索范围是起点，折数由类别数量、时间或分组限制决定，不永远是 5 折。

```python
import numpy as np
x = np.array([1., 2.])
z = np.array([3., -1.])
phi = lambda a: np.array([a[0]**2, np.sqrt(2)*a[0]*a[1], a[1]**2])
print("二次核与显式映射", (x @ z)**2, phi(x) @ phi(z))
X = np.array([[0., 0.], [1., 0.], [0., 1.]])
D2 = ((X[:, None]-X[None, :])**2).sum(2)
K = np.exp(-0.5*D2)
print("RBF Gram矩阵\n", np.round(K, 4))
assert np.allclose(K, K.T) and np.linalg.eigvalsh(K).min() > -1e-10
```

核矩阵对称且数值半正定是小样本检查，不是所有输入上合法性的证明；“同类核值平均更大”也不构成训练和泛化的验收。圆形数据完整比较见第 5 节。

## 9. 工程选择：线性求解器、核模型与概率

核 SVC 的时间、核缓存与支持点数随样本增长，显式 $N\times N$ 核矩阵存储是 $O(N^2)$。线性模型可用 `LinearSVC` 或 `SGDClassifier(loss="hinge")`，后者适合小批量/流式训练。`SVC(kernel="linear")` 仍是核求解路线，不因选了线性核就自动获得线性 SGD 的训练复杂度。

当前 `LinearSVC` 可按 `dual` 选择原始或对偶路线，默认 `dual="auto"`；默认还采用 squared hinge，并有截距处理差别。它不等于本文手写原始 Hinge 模型。判断速度需注明样本数、特征数、稀疏度、求解器和容差，固定“一万/五万/十万样本不能用核”并非理论边界。

SVM 的 `decision_function` 是有符号分数，不是概率，也不一定就是几何距离。需要概率时，可对整个预处理加模型 pipeline 交叉拟合校准器，保留数据评估 Brier/log loss 与校准曲线；不能直接把 SVM 分数套 sigmoid 就宣布可靠概率。概率校准本身也不能保证跨分布长期有效。

只有正常样本的异常检测还可用One-Class SVM：学习包含大部分正常数据的区域，`nu`在标准优化条件下关联训练错误比例上界与支持点比例下界，不能直接解释为未来异常率。需要按正常机制、污染和实际误报校验，详见[时间序列与异常检测](13-时间序列与异常检测.md)。它和本章有标签二分类SVC的目标不同。

人像等问题应先明确任务：若是识别**已知身份**，训练与测试必须包含相应身份，但照片/会话/来源级隔离避免近重复泄漏；若评估对**未知身份**的泛化，则按人划分，并使用匹配该目标的识别/验证协议。笼统要求所有人像分类都按人切分会使闭集分类测试标签根本没见过。PCA、缩放也只在训练折拟合。

## 10. SVR：连续值也可用间隔思想

SVR 的 $\epsilon$ 是**半管宽**：预测两侧各 $\epsilon$，全宽 $2\epsilon$。损失为 $\max(0,|y-f(x)|-\epsilon)$，目标是 $\|w\|^2/2+C\sum_i\ell_\epsilon$。管内不罚，管外罚超出的部分；支持点可在管边界或管外，不是必须全部在外。

$$
y_i-f_i\le\epsilon+\xi_i,\quad
f_i-y_i\le\epsilon+\xi_i^*,\quad\xi_i,\xi_i^*\ge0.
$$

原始次梯度：$f_i-y_i>\epsilon$ 时损失对 $f_i$ 的导数为 1；$f_i-y_i<-\epsilon$ 时为 -1；管内为 0。按这一导数可把第 7 节分类梯度替换成回归梯度；生产实践用成熟 `SVR`，不要只算一个 epsilon loss 便称实现了核 SVR 求解器。

```python
import numpy as np
from sklearn.svm import SVR
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import mean_squared_error

rng = np.random.default_rng(42)
X = np.linspace(-3, 3, 120)[:, None]
y = np.sin(X[:, 0])+rng.normal(0, 0.08, 120)
train = np.arange(120) % 3 != 0
valid = ~train
for epsilon in [0.05, 0.2]:
    model = make_pipeline(StandardScaler(), SVR(C=2, gamma="scale", epsilon=epsilon))
    model.fit(X[train], y[train])
    prediction = model.predict(X[valid])
    tube_coverage = np.mean(np.abs(y[valid]-prediction) <= epsilon)
    print("epsilon", epsilon, "支持点数", len(model[-1].support_),
          "验证MSE", round(mean_squared_error(y[valid], prediction), 4),
          "验证管内比例", round(tube_coverage, 4))
```

绘图时画 $\hat y\pm\epsilon$，标出训练支持点，比较变化；管内比例只是对该误差容忍的覆盖，**不是95%预测区间**。更宽管通常减少活跃样本，但支持点数及测试误差未必严格单调。

本次合成圆数据实测，线性Logistic/线性SVM验证准确率约0.45/0.55，二次Logistic与RBF SVM均1.0；验证并列按程序固定规则选二次Logistic，最终测试1.0。手写一维次梯度SVM得到 $w\approx0.9999,b=0$、街宽约2.0003。SVR的epsilon0.05/0.2分别得到39/6个支持点，验证MSE约0.0053/0.0157；更宽容忍管减少支持点，在这份数据上也降低了拟合精度。这些是明确合成输入下的运行观察，不推广成跨任务排名。

## 11. 自查与练习参考答案

1. Sigmoid 范围、logit=0、名称由来？**答案：**有限实数在数学上给 (0,1)，0 给0.5，模型对数几率线性；浮点端点与决策阈值另有约定。
2. BCE 凸为何不等于唯一有限最小解？**答案：**共线性带来参数冗余；完全可分未正则模型可能没有有限 MLE，见第2节。
3. 四类 Softmax 输出应满足什么？**答案：**每类非负、合计1、互斥分类通常取最大；多标签不适用这一互斥假设。
4. 如何完成多类混淆矩阵、哪个类最难？**答案：**第3节按真实行/预测列计数；每类 Precision 看列、Recall 看行。哪个最难应由实际运行和多个划分判断，不能预指定。
5. 为什么 ROC 要包括端点且同分一起处理？**答案：**否则可能漏面积或制造不存在的排序；第4节 AUC 手算为0.75。100点扫描只能是近似。
6. 软间隔支持向量为何不等于最近正确点？**答案：**$\alpha=C$ 可对应间隔内及误分类点；不能只找 $m\approx1$。
7. 增大 C、街宽和误分类是否必单调？**答案：**优化目标更重视违约，实际指标仍需核查；特征缩放和gamma也改变几何。
8. 圆形边界如何改善？**答案：**加入 $x_1^2,x_2^2$ 等可表达半径，或用RBF核；对齐划分后验证模型，第5节已给完整程序。
9. Hinge 与 Logistic 谁使用全部样本、谁预测更省内存？**答案：**Hinge 梯度对 $m>1$ 截断，Logistic有限logit的梯度一般不为零；线性预测二者都可只存参数，核SVC才需支持点展开。
10. SVR 怎样验证实现？**答案：**先手算管内/外的损失与次梯度，再对正弦噪声数据比较管边界、支持点和留出误差；不把epsilon管当统计区间。
