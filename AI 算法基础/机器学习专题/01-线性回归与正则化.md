# 01｜线性回归与正则化

> 先修：[矩阵与线性系统](../数学与数值计算专题/02-矩阵变换与线性系统.md)、[梯度与微积分](../数学与数值计算专题/06-微积分梯度与自动微分.md)。第一遍完成第 1～5 节的手算与程序；再学多项式、正则化和残差诊断。所有房屋数据均为人工教学数据，不是实际房价模型。

## 1. 从预测连续值开始：模型、目标与单位

例如用面积、房龄预测价格。对一条样本 $x\in\mathbb R^d$，模型是 $\hat y=w^\mathsf Tx+b$。面积系数的单位是“价格单位/面积单位”；截距是所有输入为零时的模型值，但零面积可能不在合理数据范围内，不能强行解释成真实房屋价格。

设 $X\in\mathbb R^{N\times d}$，行是样本，列是特征，$y\in\mathbb R^N$。定义预测误差 $e=Xw+b\mathbf1-y$，平方误差目标为：

$$
L(w,b)=\frac1N\sum_{i=1}^N e_i^2.
$$

平方把正负误差变成非负数，并更强地惩罚大偏差。它不是所有任务的最佳损失：严重异常值会支配平方误差，绝对损失、Huber 损失可以作为对照。平方误差单位是价格单位的平方，RMSE 才回到价格单位。

“线性”指**对参数线性**。$w_1x+w_2x^2+b$ 对输入是曲线，对参数仍线性。反过来，把模型命名为线性并不能证明真实世界关系就是直线，也不能把拟合系数当作因果效应。

来源图中的散点是真实目标，拟合线是预测，每条竖线是残差 $y_i-\hat y_i$；最小二乘最小化竖直残差平方和，**不是点到拟合线的垂直距离平方和**。改变截距会整体平移拟合线，改变斜率会旋转它；单条残差很小不代表整体 MSE 很小。

## 2. 一次梯度更新要能手算

由链式法则，$\partial e_i^2/\partial w=2e_ix_i$，因此：

$$
\nabla_wL=\frac2N X^\mathsf Te,\qquad
\frac{\partial L}{\partial b}=\frac2N\mathbf1^\mathsf Te.
$$

更新 $w\leftarrow w-\eta\nabla_wL$，$b\leftarrow b-\eta\partial_bL$。**两项梯度必须来自同一旧参数状态**，不能更新 $w$ 后再用新 $w$ 计算本轮 $b$ 的梯度。

取 $x=(0,1,2)$，$y=(1,3,5)$，初始 $w=b=0$。误差为 $(-1,-3,-5)$，所以 $\partial_wL=-26/3$、$\partial_bL=-6$。学习率 0.1 给 $w=13/15\approx0.8667$、$b=0.6$；新预测为 $(0.6,1.4667,2.3333)$，MSE 由 $35/3\approx11.6667$ 降到约 3.2074。此处结果仍远离最优 $w=2,b=1$，只是验证一步更新。

有的教材用 $\|e\|^2/(2N)$，其梯度没有系数 2。两种约定都正确，但学习率和正则强度要匹配，不能前面写 MSE、后面抄另一目标的梯度。

### 2.1 凸不等于随便选步长都能收敛

将截距并入 $A=[X,\mathbf1]$，$\theta=[w,b]$，Hessian 为 $H=2A^\mathsf TA/N$，它是半正定，所以目标凸；只有 $A$ 列满秩时才严格凸且最小二乘参数唯一。若特征重复，可有多组同样好的参数。

当最大特征值 $L_H>0$ 时，全批量更新的充分稳定区间为 $0<\eta<2/L_H$；步长越大不意味着越快。特征尺度差异会使等高线狭长，标准化通常改善条件数，但高度相关特征仍可能让狭谷存在。停止应看目标变化、梯度范数和步数上限；含噪声数据不应追求训练 MSE 为零。

## 3. 闭式解：用于理解，不要显式求逆

令梯度为零得正规方程 $A^\mathsf TA\theta=A^\mathsf Ty$。$A$ 列满秩时，形式上：

$$
\hat\theta=(A^\mathsf TA)^{-1}A^\mathsf Ty.
$$

实际调用 `np.linalg.lstsq(A, y, rcond=None)`，借助成熟分解处理最小二乘，而不是 `inv(A.T @ A)`。后者显式形成 Gram 矩阵，在满秩情况下也可能放大条件数；秩亏时根本不能普通求逆。伪逆可以给出最小范数解，参数可解释性仍受共线性影响。

单特征且包含截距时，可手算：

$$
\hat w=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\qquad
\hat b=\bar y-\hat w\bar x.
$$

若所有 $x_i$ 相同，分母为零，斜率无法由数据识别；可以用预测均值的常数模型，但不能报告唯一的真实斜率。

复杂度不能只看行数。对稠密 $N\times d$ 数据，形成 Gram 矩阵约 $O(Nd^2)$，解 $d\times d$ 系统约 $O(d^3)$；一次批量梯度约 $O(Nd)$，总成本还要乘迭代次数。百万行但少量特征未必不能直接求解；特征极多、稀疏或流式数据更常考虑迭代法。不存在“不到一万行必须正规方程”的规则。

## 4. 完整 NumPy 例子：批量、SGD、小批量与闭式解

以下程序只依赖 NumPy。训练与验证先切分，均值和标准差只从训练集计算。每轮重新打乱索引；小批量/SGD 使用本批量的平均误差梯度。

```python
import numpy as np

rng = np.random.default_rng(42)
X = rng.normal(size=(160, 2))
y = 3*X[:, 0] - 2*X[:, 1] + 7 + rng.normal(0, 0.4, len(X))
train, valid = np.arange(120), np.arange(120, 160)
mean, scale = X[train].mean(0), X[train].std(0)
scale = np.where(scale == 0, 1.0, scale)
Z = (X - mean) / scale
A = np.column_stack([Z, np.ones(len(Z))])

def fit_batches(A, y, batch_size, epochs=300, lr=0.05, seed=7):
    if A.ndim != 2 or y.shape != (len(A),) or not np.isfinite(A).all():
        raise ValueError("输入应是有限二维特征与等长一维标签")
    if not np.isfinite(y).all() or not 1 <= batch_size <= len(A):
        raise ValueError("标签须有限，批量大小须在1到样本数之间")
    theta = np.zeros(A.shape[1])
    generator = np.random.default_rng(seed)
    history = []
    for epoch in range(epochs):
        rate = lr / (1 + epoch/50)
        order = generator.permutation(len(A))
        for start in range(0, len(A), batch_size):
            ids = order[start:start+batch_size]
            error = A[ids] @ theta - y[ids]
            theta -= rate * (2/len(ids)) * (A[ids].T @ error)
        history.append(np.mean((A @ theta-y)**2))
    return theta, np.array(history)

direct = np.linalg.lstsq(A[train], y[train], rcond=None)[0]
for label, size in [("全批量", len(train)), ("SGD", 1), ("小批量", 16)]:
    theta, history = fit_batches(A[train], y[train], size)
    w_raw = theta[:-1] / scale
    b_raw = theta[-1] - mean @ w_raw
    print(label, "原单位系数", np.round(w_raw, 4),
          "截距", round(b_raw, 4),
          "验证MSE", round(np.mean((A[valid] @ theta-y[valid])**2), 4),
          "到闭式解距离", round(np.linalg.norm(theta-direct), 5))
    assert history[-1] < history[0]
print("闭式解验证MSE", round(np.mean((A[valid] @ direct-y[valid])**2), 4))
```

判断重点是三种结果是否接近、残差是否合理，而不是哪种每轮最省时间。SGD 每轮做约 $N$ 次更新，全批量只做一次，按 epoch 比“收敛速度”不公平；同时比较处理样本数、更新数和墙钟时间。SGD 曲线会有噪声；递减步长能改善后期波动，不能保证任何步长配方都有效。

若仅 $X$ 标准化，$w_{raw,j}=w_{std,j}/s_j$，$b_{raw}=b_{std}-\sum_jw_{raw,j}\mu_j$。若还用 $z_y=(y-\mu_y)/s_y$，则 $w_{raw,j}=s_yw_{std,j}/s_j$、$b_{raw}=\mu_y+s_yb_{std}-\sum_jw_{raw,j}\mu_j$。标准化系数不能直接当“面积增加一平方米涨多少钱”。

## 5. 评价与诊断：分数后面还有误差结构

$$
\operatorname{MAE}=\frac1N\sum|e_i|,\quad
\operatorname{RMSE}=\sqrt{\frac1N\sum e_i^2},\quad
R^2=1-\frac{\sum e_i^2}{\sum(y_i-\bar y)^2}.
$$

$R^2=0$ 表示与**该评价集合自己的目标均值**有相同平方误差；$R^2<0$ 表示更差，不能截成 0 隐瞒失败。实际可部署常数 baseline 必须用训练目标均值，不是在测试时偷看测试均值。目标完全为常数时上述分母为零，理论公式未定义；软件可能按约定返回有限值，要注明而不是除零。

读残差时依次检查：

- 弯曲结构：遗漏非线性或交互，尝试适当特征映射，而不只增加训练轮数。
- 随拟合值扩散：可能有异方差，检查分组误差、变换与区间估计假设。
- 个别极大误差：先核验单位、标签和录入错误，再比较稳健损失；不能只为提高分数删点。
- 随时间有结构：检查时间切分、漂移与自相关，随机切分可能掩盖真实预测困难。
- 训练好、验证差：检查重复样本、泄漏、模型复杂度与代表性，适当正则化。

回归模型可用于需求估计等连续值任务，但观测相关不自动支持 A/B 因果结论、金融交易收益或跨地区房价外推。

## 6. 多项式：增强表达，也扩大外推与数值风险

二维二次映射可含 $x_1,x_2,x_1^2,x_1x_2,x_2^2$；交互项描述一个变量的效应随另一个变量改变。参数数量会快速增长，宜先低阶并用验证选复杂度。

对固定数据、嵌套特征空间、充分求解的**未正则最小二乘**，增加次数不会提高最优训练平方误差。实际迭代未收敛、病态矩阵和正则目标不同，则训练分数未必单调。十个不同 $x$ 的点，可用不超过九次的插值多项式穿过；不能据此说“十次恰好对应十点”，也不能断言任何五次以上都必然过拟合。

训练区间外，高次项迅速增大。例如在 $[-1,1]$ 上拟合得到的小系数，乘到 $x=3$ 的 $x^{10}$ 会被放大为 59049 倍。多项式模型应明确允许的输入范围；数据外推需要领域依据。

## 7. Ridge、Lasso、Elastic Net：目标约定与选择

本节统一使用平均平方误差：

$$
L_{Ridge}=\frac1N\|Xw+b-y\|^2+\lambda\|w\|^2,
\quad
L_{Lasso}=\frac1N\|Xw+b-y\|^2+\lambda\|w\|_1.
$$

截距默认不罚。Ridge 的权重梯度增加 $2\lambda w$。数据中心化后，闭式系统是：

$$
(X_c^\mathsf TX_c+N\lambda I)w=X_c^\mathsf Ty_c,
\qquad b=\bar y-\bar x^\mathsf Tw.
$$

如果目标是**平方误差求和**加 $\alpha\|w\|^2$，矩阵增加的是 $\alpha I$。所以这里与 `sklearn.Ridge(alpha=...)` 对应 $\alpha=N\lambda$；不能把相同数字当相同模型。正的 Ridge 系数使权重系统正定，即使特征共线也可解；它减少方差但引入收缩偏差，并不保证验证误差改善。

Lasso 在零处不可微。近端梯度先按数据损失更新 $z=w-\eta\nabla L_{data}$，再做：

$$
w_j\leftarrow\operatorname{sign}(z_j)\max(|z_j|-\eta\lambda,0).
$$

这是 soft-threshold，能产生精确零；普通 L2 通常只是连续收缩，但特殊情形也会为零。高度相关的列中，Lasso 可能不稳定地选一列，不能把被保留者视作唯一重要原因。Elastic Net 混合 L1 与 L2，在希望稀疏又有相关列时值得比较。

下面完整 NumPy 例子使用均值为零、彼此正交的特征，便于核对稀疏机制。它包含真实数据拟合项，**不是只循环缩小权重**。

```python
import numpy as np

X = np.array([[-1, -1], [-1, 1], [1, -1], [1, 1]], dtype=float)
y = 2*X[:, 0] + 0.1*X[:, 1] + 3
Xc, yc = X-X.mean(0), y-y.mean()
lam, n = 0.5, len(y)
ridge = np.linalg.solve(Xc.T @ Xc+n*lam*np.eye(2), Xc.T @ yc)
w, b = np.zeros(2), 0.0
eta = 0.2
for _ in range(300):
    error = X @ w+b-y
    z = w-eta*(2/n)*(X.T @ error)
    w = np.sign(z)*np.maximum(np.abs(z)-eta*lam, 0)
    b -= eta*2*error.mean()
print("Ridge", np.round(ridge, 4), "截距", y.mean())
print("Lasso", np.round(w, 4), "截距", round(b, 4))
assert np.allclose(ridge, [4/3, 1/15])
assert np.allclose(w, [1.75, 0]) and np.isclose(b, 3)
```

预期 Ridge 约 `[1.3333, 0.0667]`，Lasso `[1.75, 0.]`；这里 Lasso 的阈值是 $\lambda/2$，因为数据损失没有 1/2。不同目标缩放下零阈值会变，正则化数值不能照搬。

## 8. 实践完整例子：先验证挑次数，最后才测试

需要 NumPy 与 scikit-learn。固定三次真实函数、30 个训练点，再分别比较 1、3、10 次；新增列在 `PolynomialFeatures` 后缩放，以免高次项支配惩罚。独立验证只负责选择，测试用于最终评价。

```python
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_squared_error, r2_score

rng = np.random.default_rng(42)
X = rng.uniform(-1, 1, (130, 1))
y = 1+2*X[:, 0]-X[:, 0]**2+3*X[:, 0]**3+rng.normal(0, 0.4, 130)
tr, va, te = np.arange(30), np.arange(30, 80), np.arange(80, 130)
models, rows = {}, []
for degree in [1, 3, 10]:
    model = make_pipeline(PolynomialFeatures(degree, include_bias=False),
                          StandardScaler(), Ridge(alpha=0.05))
    model.fit(X[tr], y[tr])
    score = mean_squared_error(y[va], model.predict(X[va]))
    models[degree] = model
    rows.append((score, degree))
    print("次数", degree, "训练R2", round(model.score(X[tr], y[tr]), 4),
          "验证MSE", round(score, 4))
_, chosen = min(rows)
prediction = models[chosen].predict(X[te])
print("验证选中次数", chosen,
      "最终测试MSE", round(mean_squared_error(y[te], prediction), 4),
      "最终测试R2", round(r2_score(y[te], prediction), 4))
```

这只是一次合成实验。次数 3 对应真实函数不意味着带噪有限样本下必然验证最佳；报告真实输出，不预写“10 次一定最差”。真实数据应按时间、用户或设备分组切分；交叉验证时缩放必须每折重新拟合。

本次固定种子实测：全批量/SGD/小批量验证MSE约0.1872/0.1906/0.1876，闭式解约0.1870，三者接近但不完全相同。多项式1/3/10次验证MSE约0.4115/0.1761/0.1950，选中3次后最终测试MSE约0.2282、$R^2\approx0.9518$。这些值只用于核对这份教学输入及实现，不能作为真实需求预测性能承诺。

## 9. 自查与源练习的参考答案

1. 学习率控制什么？**答案：**更新步幅，不控制特征数量或训练测试比例。缩放改善优化几何，但不能修复缺失的预测信息，也不能独自保证收敛。
2. $R^2=0$ 和负值各表示什么？**答案：**见第 5 节；常数目标时公式另有边界，测试均值 baseline 只是指标参考。
3. 何时更愿意用梯度法而非直接求解？**答案：**特征多、稀疏、流式或受内存限制时；同时比较迭代次数、误差容忍与分解成本，而不是只看样本行数。
4. 批量、SGD、小批量哪种最快、最平滑？**判断标准：**在第 4 节记录同一目标下的损失、梯度评价次数与时间；批量通常更平滑，速度随硬件、噪声、批量和学习率改变，无通用赢家。
5. 三次函数拟合 1、3、10 次，如何判断过拟合？**答案：**看验证误差、多个划分及区间边缘残差；训练好而验证差才支持过拟合判断。最终测试表现不能用于继续选择次数。
6. 为什么 Lasso 更容易精确为零？**答案：**零点的次梯度区间允许数据梯度被 L1 抵消；第 7 节给完整近端实现。检查非零个数、系数稳定与验证误差，不能以稀疏本身宣布更好。
7. 训练 $R^2=1$、验证很差，下一步是什么？**答案：**先核对泄漏和分布，再比较降低次数、加强正则、增加有效数据；不能丢弃验证集或只报告训练分数。
