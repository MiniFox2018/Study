## 1. 要评价的是哪一种“新数据”

训练集拟合参数和预处理；验证集选择模型、特征、超参数、阈值与停止轮数；测试集在这些选择冻结后评价完整程序。测试集可以重复计算相同冻结模型的指标或作预定分组分析，关键是不能用其反馈继续选择而仍称其独立测试。“只看一次”是保护独立性的操作约定，不是神秘的文件访问次数要求。

测试估计还要求采样与目标使用场景一致：随机测试未必反映未来季度，新用户测试未必反映老用户后续行为。保存独立测试不保证完全无偏或未来一定有效；它减少选择污染，但还存在有限样本、分布变化与切分目标不匹配。

| 预测对象 | 可选划分 | 需要保护的信息边界 |
|---|---|---|
| 近似独立同分布样本 | 随机训练/验证/测试、KFold | 预处理只拟合训练部分 |
| 同分布分类、稀有类 | StratifiedKFold | 每折尽量保留类比例；不消除实体依赖 |
| 新患者、新用户、新设备 | GroupKFold、GroupShuffleSplit | 同实体全部进入同一集合 |
| 同时保留实体隔离与类比例 | StratifiedGroupKFold | 两约束未必能完美同时满足 |
| 未来预测 | 时间块/滚动原点、TimeSeriesSplit | 训练早于验证；标签窗口和延迟不能跨界 |

K折对每个验证折重新创建模型，不能复用上一折已拟合对象。在普通KFold/分层KFold中，每个样本每一轮划分用作验证一次、训练 $K-1$ 次；时间扩展窗口不保证每样本验证一次。$K=5$、10是常见选择，不是最优定律；更大K增加训练成本，也不必然使估计更稳定。

### 1.1 手写分层K折：余数不能全部堆在最后一折

先各类别随机打乱，再轮流分配索引；每类至少K个样本时才能让每折包含此类。成熟库可能对不足类别警告或允许一些折缺类，教学实现这里选择显式拒绝。稀有类过少时，应减少K、改变设计或清楚报告不能计算的指标。

```python
import numpy as np

def stratified_folds(y, k=5, seed=42):
    y = np.asarray(y)
    if y.ndim != 1 or not 2 <= k <= len(y):
        raise ValueError("标签须为一维，2 <= k <= n")
    rng = np.random.default_rng(seed)
    bins = [[] for _ in range(k)]
    offset = 0
    for c in np.unique(y):
        idx = rng.permutation(np.flatnonzero(y == c))
        if len(idx) < k:
            raise ValueError("本实现要求每类至少k条，以便每折包含每类")
        for j, i in enumerate(idx):
            bins[(offset + j) % k].append(int(i))
        offset = (offset + len(idx)) % k
    all_idx = np.arange(len(y))
    out = []
    for b in bins:
        val = np.array(sorted(b), dtype=int)
        train = np.setdiff1d(all_idx, val)
        out.append((train, val))
    return out

y = np.array([0]*23 + [1]*7)
folds = stratified_folds(y, 5)
held = np.concatenate([v for _, v in folds])
assert np.array_equal(np.sort(held), np.arange(len(y)))
for train, val in folds:
    assert not set(train).intersection(val)
    print("验证样本数", len(val), "类别计数", np.bincount(y[val], minlength=2).tolist())
```

预期每折6条，正类计数为1或2，所有样本验证一次、训练/验证交集为空。原来源把每类余数全放最后一折可能造成明显不均衡，这里改为轮转分配。没有分组/时间结构时才适用这段程序。

### 1.2 用索引验证实体与时间划分

```python
import numpy as np
from sklearn.model_selection import GroupKFold, TimeSeriesSplit
X = np.arange(36).reshape(18, 2)
groups = np.repeat(np.arange(6), 3)
for train, val in GroupKFold(n_splits=3).split(X, groups=groups):
    assert set(groups[train]).isdisjoint(set(groups[val]))
    print("验证实体", np.unique(groups[val]).tolist())
for train, val in TimeSeriesSplit(n_splits=3, test_size=3, gap=2).split(X):
    assert train.max() < val.min()
    assert val.min() - train.max() - 1 == 2
    print("训练末尾", int(train.max()), "验证起点", int(val.min()))
```

`gap=2`是两行而非必然两天。TimeSeriesSplit通常以样本索引切分，等间距数据更便于比较同样时间长度；不规则时间、滑动窗口跨界、多步标签与事件延迟需自行构造时间边界和隔离区。重复拍摄同一对象、同一文章改写与患者切片也需要实体隔离，不能只检查行重复。

## 2. 从混淆矩阵选择决策指标

约定正类=1，矩阵按真实类别为行、预测类别为列，依次为 $[[TN,FP],[FN,TP]]$。要写清正类是哪一种事件，不能把软件输出方向混淆。

$$
\operatorname{Acc}=\frac{TP+TN}{N},\quad
P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad
\operatorname{Specificity}=\frac{TN}{TN+FP}.
$$

Precision回答“发出的告警有多少是真的”，Recall回答“实际事件抓到多少”，Specificity回答“实际正常放过多少”。Precision的分母是预测正类，Recall的分母是真实正类。分母为0时数学上未定义，若软件设0或1必须说明；无正类测试集不能评估正类召回或二分类ROC-AUC。

$$
F_\beta=\frac{(1+\beta^2)PR}{\beta^2P+R},\qquad
F_1=\frac{2TP}{2TP+FP+FN}.
$$

$\beta>1$相对强调Recall，$\beta<1$相对强调Precision；F1不计算TN，不是“所有错误同成本”的完整表达。安全告警可能更需要“Recall至少0.9且每日告警不超过100条”，推荐排序可能关心Precision@K。单独最大化Recall会允许全部预测正类，单独最大化Precision可能只报一条，必须加任务约束。

平衡准确率为每类Recall的平均，二分类是 $(R+\operatorname{Specificity})/2$。Matthews相关系数为：

$$
\operatorname{MCC}=\frac{TP\,TN-FP\,FN}
{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}.
$$

范围 $[-1,1]$，完美预测为1、完全反向为-1；分母为0时原相关系数退化，常用库约定返回0。MCC综合四格，但并非不受基率影响，也不是跨数据集可无条件比较的万能指标。

1000条中10条正类，全部预测负类：Accuracy=99%，Recall=0，F1和MCC按常用约定为0。Accuracy没有“撒谎”，它准确回答了整体正确比例；错误在于把整体比例当作唯一目标。报告Accuracy可作辅助，但需要关键类的Recall、Precision、误报数量与成本。

### 2.1 多类与多标签不能只报一个平均F1

多分类分别以每类为正类计算；macro平均每类等权，weighted按真实支持数加权，micro先合计TP/FP/FN再算。单标签多分类且覆盖所有类时，micro-F1等于Accuracy，未额外突出稀有类；weighted-F1也可能被多数类掩盖。多标签样本可同时有多个正类，sample平均是先对每个样本标签集合计算，不能与单标签平均混用。

最低报告每类支持数与指标、混淆矩阵、所用平均方式；关键类不因样本少而隐藏。若不同类代价不同，另计算任务成本。

## 3. ROC、PR和概率评价分工不同

### 3.1 ROC与AUC看排名，端点和平局必须处理

把阈值由高到低，预测 $s\ge t$ 为正类，绘制：

$$
\operatorname{TPR}=R,\qquad \operatorname{FPR}=\frac{FP}{FP+TN}.
$$

应从“无正预测”的 $(0,0)$到“全部正预测”的 $(1,1)$，相同分数的样本一起跨过阈值。AUC可以用梯形积分；也等于随机正负对中“正类分数更高”的概率，加上平局概率的一半。范围 $[0,1]$：0.5是无排名信息的参照，0说明完全反向，绝不是合法范围只从0.5开始。

### 3.2 PR关注被报出样本的质量

PR横轴Recall、纵轴Precision。稀有正类下，即使FPR很小，绝对FP仍可能很多。10万正常样本中FPR=1%就是1000次误报；若只有100个正例且Recall=0.8，Precision仅 $80/(80+1000)\approx7.4\%$。ROC并不数学失效，而是没有直接显示告警纯度与基率。

常数无信息分数的Precision参照为正类比例 $\pi$；不同有限样本排名与积分定义下，随机PR面积不是每次都恰等于 $\pi$。改变测试正类比例会改变PR，跨数据集对比先说明基率。

**平均精确率（AP）**常用阶梯权重：$\mathrm{AP}=\sum_k(R_k-R_{k-1})P_k$。**PR梯形面积**在线性连接PR点后积分。二者可能不同，不能将`average_precision_score`都称为梯形PR-AUC。原课练习“AP就是PR面积”在这里具体区分。

### 3.3 手写ROC、AP与小样本核验

```python
import numpy as np
from sklearn.metrics import roc_auc_score, average_precision_score

def ranking_metrics(y, scores):
    y, scores = np.asarray(y), np.asarray(scores, dtype=float)
    if (y.ndim != 1 or scores.shape != y.shape or len(y) == 0
            or not np.isfinite(scores).all() or not np.isin(y, [0, 1]).all()
            or len(np.unique(y)) != 2):
        raise ValueError("需要等长有限分数与同时包含0/1的非空标签")
    order = np.argsort(-scores, kind="stable")
    ys, ss = y[order], scores[order]
    ends = np.r_[np.flatnonzero(np.diff(ss) != 0), len(ss)-1]
    tp = np.cumsum(ys)[ends]
    fp = ends + 1 - tp
    recall, fpr = tp / y.sum(), fp / (len(y)-y.sum())
    precision = tp / (tp + fp)
    roc_x, roc_y = np.r_[0., fpr], np.r_[0., recall]
    auc = np.sum(np.diff(roc_x) * (roc_y[1:]+roc_y[:-1]) / 2)
    ap = np.sum(np.diff(np.r_[0., recall]) * precision)
    return float(auc), float(ap)

y = np.array([1, 0, 1, 0])
scores = np.array([0.9, 0.8, 0.8, 0.1])  # 包含正负平局
auc, ap = ranking_metrics(y, scores)
assert np.isclose(auc, roc_auc_score(y, scores))
assert np.isclose(ap, average_precision_score(y, scores))
print("AUC", auc, "AP", ap)
print("全部同分", ranking_metrics(y, np.ones(4)))
print("完全反向", ranking_metrics([0, 0, 1, 1], [0.9, 0.8, 0.2, 0.1])[0])
```

输出：AUC=0.875，AP=$5/6\approx0.833333$；全部同分时AUC=0.5、AP=0.5；完全反向时AUC=0。原来源只从观测阈值出发遗漏ROC原点，在最大分数包含负类或正负平局时会漏面积；这里按整组平局计算。

### 3.4 排名好不等于概率可信

二分类Brier分数 $N^{-1}\sum_i(p_i-y_i)^2$和log loss $-N^{-1}\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]$同时评价概率准确性，越小越好；log loss对自信但错误的预测处罚很大。概率校准指给定预测概率附近的真实比例是否匹配，不是每个单独案例“有80%的标签”。

Reliability图按概率分箱，对比平均预测概率与观测正率；每箱样本量和区间同样重要。校准不等于辨别能力：始终预测基率可能校准，却没有有用的排名。

Platt缩放用独立校准数据拟合 $p(s)=\sigma(as+b)$；正斜率严格单调、无数值并列时保留排序，负斜率会反向，isotonic可产生平局。成熟库的交叉验证校准若组合多个模型，也不保证与原模型排名完全相同。不能泛称“校准总不改变AUC”。

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score, brier_score_loss

rng = np.random.default_rng(11)
score = rng.normal(size=800)  # 此例模拟已训练模型对独立案例的raw score
true_p = 1 / (1 + np.exp(-score))
y = (rng.random(len(score)) < true_p).astype(int)
calibration, test = np.arange(400), np.arange(400, 800)
platt = LogisticRegression(C=1e6).fit(score[calibration, None], y[calibration])
old_p = 1 / (1 + np.exp(-3*score[test]))  # 排名相同、概率过于自信
new_p = platt.predict_proba(score[test, None])[:, 1]
assert platt.coef_[0, 0] > 0
assert np.isclose(roc_auc_score(y[test], old_p), roc_auc_score(y[test], new_p))
print("AUC", round(roc_auc_score(y[test], new_p), 4))
print("校准前后Brier", round(brier_score_loss(y[test], old_p), 4),
      round(brier_score_loss(y[test], new_p), 4))
```

本例预期AUC相同、校准后Brier改善，但有限校准样本下不保证所有真实任务都改善。校准集若参与基础模型拟合，会过于乐观；可用折外分数，校准和阈值选择后还要独立测试。

## 4. 回归指标与常数目标边界

残差 $e_i=\hat y_i-y_i$：

$$
\mathrm{MSE}=\frac1N\sum_i e_i^2,\quad
\mathrm{RMSE}=\sqrt{\mathrm{MSE}},\quad
\mathrm{MAE}=\frac1N\sum_i|e_i|,\quad
R^2=1-\frac{\sum_i e_i^2}{\sum_i(y_i-\bar y)^2}.
$$

MSE单位是标签单位的平方，RMSE/MAE单位与标签相同。RMSE强调大错误；MAE每单位绝对错误线性计价，相对稳健但仍受极值影响。选择反映任务成本，不因异常点存在就必然改用MAE。

对固定测试标签，MSE越低、$R^2$越高；测试均值只定义 $R^2$的归一化分母，真正可部署基线必须从训练标签取得均值。$R^2$可为负；目标恒定时分母0，数学上完美预测为0/0，非完美为负无穷；某些库用1/0替代以便搜索，使用`force_finite=False`可检查退化。只有一个样本也不能可靠计算 $R^2$。

```python
import numpy as np
y = np.array([1., 2., 3.])
pred = np.array([1., 2., 5.])
mse = np.mean((pred-y)**2)
mae = np.mean(np.abs(pred-y))
denom = np.sum((y-y.mean())**2)
r2 = 1 - np.sum((pred-y)**2)/denom if denom > 0 else np.nan
print("MSE/RMSE/MAE/R2", mse, np.sqrt(mse), mae, r2)
```

输出 $4/3,\sqrt{4/3},2/3,-1$。负 $R^2$说明在这个测试集上比其常数均值参照差，不说明所有输入范围都无信息。跨标签尺度、数据集难度和测试分布的 $R^2$也不能直接公平排名。

## 5. 学习曲线、验证曲线与分组错误分析

在固定切分上训练不同样本量，并重新拟合每一组预处理；对多折平均并同时保留折间变化。scikit-learn把“越大越好”作为评分约定，MSE评分为负，读成误差时需取负号。

```python
import numpy as np
from sklearn.datasets import make_regression
from sklearn.model_selection import KFold, learning_curve, validation_curve
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge
X, y = make_regression(n_samples=180, n_features=12, noise=20, random_state=42)
cv = KFold(3, shuffle=True, random_state=42)
pipe = make_pipeline(StandardScaler(), Ridge(alpha=1.))
sizes, train_scores, val_scores = learning_curve(
    pipe, X, y, cv=cv, train_sizes=[0.25, 0.5, 1.],
    shuffle=True, random_state=42, scoring="neg_mean_squared_error")
for n, tr, va in zip(sizes, -train_scores.mean(axis=1), -val_scores.mean(axis=1)):
    print("样本/训练MSE/验证MSE", int(n), round(tr, 3), round(va, 3))
train_scores, val_scores = validation_curve(
    pipe, X, y, cv=cv, param_name="ridge__alpha", param_range=[0.01, 1., 100.],
    scoring="neg_mean_squared_error")
print("验证曲线MSE", np.round(-val_scores.mean(axis=1), 3).tolist())
```

这是验证示例，不含独立最终测试。较小样本通常训练误差低而验证波动大，实际是否单调取决于数据；误差差距不能唯一证明偏差/方差。检查错误样本是否集中在某用户、时间、缺失特征、罕见类别、标签冲突或分布外区域。分组指标同时报告样本数，不能把只有两例的100%成功当可靠结果。

折间标准差描述这个划分下的变化，不是独立实验标准误；不默认用 $s/\sqrt K$构造置信区间，也不直接对折分数做普通配对t检验。先冻结模型，用独立案例配对Bootstrap/McNemar，或设计与目标匹配的重复训练实验。标签置换检验的是可交换假设下“特征—标签无关联”，不是自动的两模型差异检验，完整例子见统计专题。

## 6. 不平衡策略分别改变什么

类别比例先统计，但不要按70/30、95/5、99/1直接选择固定组合。少数类绝对数量、类重叠、测量质量、特征类型、采样偏差与成本比比例更关键。类别稀有不等于特征空间异常；监督不平衡分类和无监督异常检测不能互换。

| 方法 | 改变对象 | 收益与风险 |
|---|---|---|
| 随机过采样 | 复制训练少数类 | 易实现，不丢原数据；增加训练成本，不增加独立信息 |
| 随机欠采样 | 删除部分训练多数类 | 减训练成本；可能丢边界与子群信息，需多种子检查 |
| SMOTE | 插值生成训练少数类特征 | 可扩展局部区域；也可能跨入多数类或产生不合法样本 |
| 类权重/样本权重 | 训练损失中的样本贡献 | 不改行数；依赖算法支持、优化与正则定义，概率可能偏移 |
| 阈值选择 | 从分数到决策的规则 | 不重新训练排名模型；需代表性验证集，不能凭空增加区分信息 |
| 成本敏感决策 | 明确不同错误的损失 | 可直接对准任务；成本和概率估计错误会导致错误策略 |
| Balanced Bagging | 多个平衡采样模型并组合 | 可能稳定欠采样；模型成本和错误相关性仍要评价 |

先比较无处理模型、类权重和阈值，再按数据结构决定采样。SMOTE后`class_weight="balanced"`会按**重采样后的**比例算权重；平衡后往往就是相同权重。若又手工乘原少数类大权重，可能重复补偿。组合是否有效要在原始分布验证，不设“SMOTE+权重必最好”。

### 6.1 SMOTE的几何与限制

从训练少数类样本 $x_i$中挑一个，再从其k个少数类近邻中选 $x_j$，生成：

$$
x_{new}=x_i+u(x_j-x_i),\qquad u\sim\operatorname{Uniform}(0,1).
$$

$(1,2)$与 $(1.5,2.5)$，$u=0.4$得到 $(1.2,2.2)$。这只是同类线段上的点，**没有证明它是现实中合法的正例**。数据里离群少数点、类重叠、多模态、时间状态和约束会使插值出错；只一条少数类样本不能找不同邻居。距离敏感，先在训练折拟合缩放；通用连续SMOTE不能直接插值城市编号或one-hot指示而仍视为合法类别，混合特征考虑SMOTENC等针对性方法并核对约束。

Borderline-SMOTE先用全体近邻判断少数类点是否靠近混合边界，再从“危险”区域合成；需区分噪声点与边界点，不能把所有邻域含多数类的点都当安全来源。ADASYN向较难的区域分配更多生成量，也可能强化噪声。更多合成数量不等于更多独立监督信息。

重采样必须发生在每折训练部分，验证/测试保留目标分布。先重采样再交叉验证会让原点与其复制/合成后代跨折。训练型采样改变样本数，使用imbalanced-learn的Pipeline而非把`fit_resample`对象当普通scikit-learn Transformer；推理时不应生成新行。

### 6.2 类权重和成本阈值

平衡权重为 $w_c=N/(C n_c)$。950负、50正时 $w_0\approx0.5263,w_1=10$，正类贡献是负类的19倍。加权二分类损失：

$$
L=-\frac1N\sum_i w_{y_i}\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
$$

对可加经验损失，重复样本可等价于整数权重；随机过采样在期望上改变权重。但正则归一化、训练轮数、Bootstrap、随机梯度和算法结构不同，会破坏“完全等价”。权重不提供复制之外不存在的信息，也不保证所有模型都支持。

若 $p=P(Y=1\mid x)$ 是目标分布的可信概率，正确决策成本设0，误报成本 $C_{FP}$、漏报成本 $C_{FN}$，预测正的期望成本为 $C_{FP}(1-p)$，预测负为 $C_{FN}p$。因此选择正类的阈值为：

$$
t^*=\frac{C_{FP}}{C_{FP}+C_{FN}}.
$$

漏报100、误报1时为 $1/101\approx0.0099$；1:10、1:100、1:1000对应 $1/11,1/101,1/1001$。不能把经重采样/加权后的输出未经校准就代入，并认为成本最优。

若只是标签先验由 $\pi$改为 $\pi'$而类条件分布不变，训练概率 $p'$与目标概率的odds关系是：

$$
\frac{p}{1-p}=\frac{p'}{1-p'}\frac{\pi/(1-\pi)}{\pi'/(1-\pi')}.
$$

这是先验变化假设下的纠偏，不对一般特征漂移或错误校准保证有效。更稳妥是在保持实际分布的独立验证数据上校准与选阈值，并报告未知条件。

### 6.3 一个不把测试用于选择的完整比较

下例合成950负/50正，分层60/20/20；只在训练集采样或算权重，在验证集选阈值，在测试集展示冻结设置。普通、过采样、欠采样、SMOTE、权重与阈值均能直接运行。

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_score, recall_score, f1_score, average_precision_score

def smote_small(Xmin, count, k=5, seed=42):
    Xmin = np.asarray(Xmin, dtype=float)
    if Xmin.ndim != 2 or not np.isfinite(Xmin).all() or count < 0 or int(count) != count:
        raise ValueError("有限二维特征和非负整数生成数")
    if count == 0:
        return np.empty((0, Xmin.shape[1]))
    if len(Xmin) < 2 or k < 1:
        raise ValueError("需要至少两条少数样本，k>=1")
    k = min(k, len(Xmin)-1)
    rng = np.random.default_rng(seed)
    distances = ((Xmin[:, None] - Xmin[None, :])**2).sum(axis=2)
    np.fill_diagonal(distances, np.inf)
    neighbors = np.argsort(distances, axis=1)[:, :k]
    base = rng.integers(len(Xmin), size=int(count))
    other = neighbors[base, rng.integers(k, size=int(count))]
    u = rng.random((int(count), 1))
    return Xmin[base] + u*(Xmin[other]-Xmin[base])

rng = np.random.default_rng(42)
X = np.vstack([rng.normal(0, 1, (950, 2)), rng.normal(2.5, 0.8, (50, 2))])
y = np.r_[np.zeros(950, dtype=int), np.ones(50, dtype=int)]
Xpool, Xtest, ypool, ytest = train_test_split(X, y, test_size=0.2, stratify=y, random_state=1)
Xtrain, Xval, ytrain, yval = train_test_split(
    Xpool, ypool, test_size=0.25, stratify=ypool, random_state=2)
zero, one = np.flatnonzero(ytrain == 0), np.flatnonzero(ytrain == 1)
extra = rng.choice(one, len(zero)-len(one), replace=True)
over = np.r_[np.arange(len(ytrain)), extra]
under = np.r_[rng.choice(zero, len(one), replace=False), one]
synthetic = smote_small(Xtrain[one], len(zero)-len(one))
datasets = {
    "普通": (Xtrain, ytrain, None),
    "过采样": (Xtrain[over], ytrain[over], None),
    "欠采样": (Xtrain[under], ytrain[under], None),
    "SMOTE": (np.vstack([Xtrain, synthetic]), np.r_[ytrain, np.ones(len(synthetic), dtype=int)], None),
    "权重": (Xtrain, ytrain, "balanced"),
}
fitted = {}
for name, (Xt, yt, weight) in datasets.items():
    fitted[name] = LogisticRegression(class_weight=weight, max_iter=1000).fit(Xt, yt)

# 验证集阈值：包含所有观测分数及“全部不报”的端点，不局限0.05～0.95。
weighted = fitted["权重"]
pv = weighted.predict_proba(Xval)[:, 1]
thresholds = np.r_[np.unique(pv), np.nextafter(pv.max(), np.inf)]
f1s = [f1_score(yval, pv >= t, zero_division=0) for t in thresholds]
# 同分取较高阈值，减少告警；平局规则要事先声明。
best = max(range(len(thresholds)), key=lambda i: (f1s[i], thresholds[i]))
chosen = thresholds[best]
print("验证选择阈值", round(chosen, 4), "验证F1", round(f1s[best], 4))
for name, model in fitted.items():
    p = model.predict_proba(Xtest)[:, 1]
    pred = p >= 0.5
    print(name, "测试P/R/F1/AP", *[round(v, 4) for v in (
        precision_score(ytest, pred, zero_division=0), recall_score(ytest, pred),
        f1_score(ytest, pred), average_precision_score(ytest, p))])
p = weighted.predict_proba(Xtest)[:, 1]
print("权重+验证阈值 测试F1", round(f1_score(ytest, p >= chosen), 4))
assert smote_small(Xtrain[one], 0).shape == (0, 2)
```

此合成特征本来同尺度；真实数据要把缩放拟合移进每个训练折。预期每集合保留正类，测试只有10正例，指标变化较粗；不能据此证明某策略普遍最好。这里只作一次预定对比，若根据测试榜单再选择策略，另留新测试或外层验证。确定策略后重新训练会改变分数尺度，旧阈值可能不再最优；应用折外阈值选择、留出校准集或重新独立验证。

所测环境普通模型测试F1=0.9000，过采样0.7407、欠采样0.6897、SMOTE0.8696、权重0.7407。权重模型在验证集选择阈值约0.9876后，测试F1=0.8421。这个阈值高于0.5，且处理策略没有全部胜过普通模型，恰好提醒：加权后的分数尺度已变化，不能套“稀有类最优阈值一定更低”或“平衡数据必改善”。这些测试结果只是预定教学对比，不用于反复挑选真实策略。

手写加权逻辑回归的梯度为 $X^T[w\odot(p-y)]/N$，截距梯度为 $\sum_iw_i(p_i-y_i)/N$；实现时权重形状必须是 $(N,)$，否则广播可能生成错误的 $N\times N$误差。来源代码的完整梯度在此吸收为公式，成熟库示例承担可运行比较，避免重复一套训练器。

## 7. 阈值变化中的三种常见误判

1. **降阈值Recall一定降低吗？**固定样本、`>=`规则下，降阈值预测正类集合只会扩大，TP不减，所以Recall不减、FPR不减；未跨过任何分数时两者不变。
2. **Precision一定下降吗？**不一定。新加入的样本可全部为正，Precision可能提高；有限数据PR通常锯齿状。来源高斯示意只是常见趋势，不是单调定理。
3. **排名好就有阈值完美分开吗？**不成立，只有所有正类分数严格高于所有负类才可完全分离；类重叠仍需成本取舍。校准对概率解释和理论成本阈值尤其关键，不能因排名好就忽略。

图示中的两条分数分布相交不决定F1最优阈值。F1由累计TP/FP/FN和类比例决定，应在验证上计算；分布密度交点在另一些成本/先验条件下才可能关联最优决策。

## 8. 练习与参考答案

1. 95%负类全部预测负，Accuracy是多少，模型是否完成检测任务？**答案：**95%；正类Recall=0，没有抓到目标事件。列出支持数与关键类指标。
2. 5折中每样本验证几次？**答案：**普通单轮K折一次；训练四次。不是5个独立完整实验，且时间/分组特殊设计不能随意套。
3. 同一ROC-AUC下为何Precision不同？**答案：**基率和选定阈值不同；用本章80TP、1000FP例算7.4%，不能从AUC推告警纯度。
4. 建立PR曲线并同时算AP和梯形面积。**参考：**按降序分数组合相同分数，记录累积TP/FP；AP用Recall增量乘Precision，梯形用两端平均Precision，两者可不同。无正类时先报告不可识别，不静默给“模型很差”。
5. 仅两条连续少数样本可生成多少独立真实信息？**答案：**仍只有两条观测；SMOTE可生成任意多线段点，但没有新测量或独立标签证据。
6. 改写Borderline-SMOTE、Balanced Bagging和逐步改变类比例，怎样验收？**参考：**按同一训练/验证边界比较，分开记录采样数量、绝对正类数量、类重叠、多种子波动、原分布测试AP/F1/成本。Balanced Bagging每成员保留少数类、抽多数类，再平均概率；不要用同样试过的测试集决定哪种方法最好。不存在固定“达到95/5后必有收益”阈值。
7. 成本比1:100、概率0.02应选哪一类？**答案：**正。预测正成本0.98，预测负成本2；这要求概率可信、代价常数和正确分类成本0。
8. Platt校准为何不总保AUC？**答案：**单模型正斜率严格单调变换才保排名；负斜率、平局、多个校准模型集成都可能改变排名。
