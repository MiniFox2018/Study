## 1. 从“希望业务变好”到可验证的预测任务

传统程序由人明确规则，例如摄氏转华氏 $F=1.8C+32$。机器学习由训练数据选择预测函数 $\hat f$；训练后的参数是程序的一部分，之后用同一函数处理新输入。训练不一定用梯度下降：质心分类只算均值，决策树搜索划分，KNN主要保存样本。预测也不一定输出概率。

“减少用户流失”是业务目标；“在每周一预测仍在订阅的用户未来30天是否取消”才是任务。先把下面七项写清，避免模型看见未来答案：

| 要明确的项 | 流失任务中的具体例子 |
|---|---|
| 样本单位 | 一个用户在某周一的快照；同用户的多周记录并不独立 |
| 预测时点 | 周一00:00；特征截止到这个时点 |
| 标签和窗口 | 此后30天内取消为1；不足30天随访不能直接当0 |
| 可用输入 | 过去28天使用次数、此前客服记录、现有套餐 |
| 不可用输入 | 将来的退款、取消原因、月底汇总收入 |
| 使用预测的方法 | 给一部分用户提供服务；需检查干预是否改变未来标签 |
| 成功和成本 | 固定服务容量下召回多少流失者、误触达成本、实际留存效果 |

离线预测正确不等于干预有效。模型可能善于识别本来就会流失的人，但优惠对他们并无效果；评估干预需要另行设计实验。若预测改变后续数据，应记录反馈循环，不能把新标签仍当作完全相同的采样机制。

### 1.1 学习范式与任务不是同一分类轴

- **监督学习**利用 $(x,y)$；分类的 $y$ 是类别，回归的 $y$ 是数值。价格是数值不代表一定要回归，也可以定义为价格区间分类，代价是丢掉区间内信息。
- **无监督学习**从未标注输入寻找结构，例如聚类和降维。簇编号只是算法结果，不自动等于有价值的业务群体。
- **强化学习**在环境里选择动作、得到奖励和后续状态，目标常是折扣累计回报 $\mathbb E[\sum_t\gamma^t r_t]$；奖励延迟和动作改变未来状态，使它区别于普通独立样本分类。
- **半监督学习**把少量标签和大量无标签一起利用。标签传播依赖相似图；伪标签把高可信预测当监督；一致性正则要求合理扰动前后预测一致。错误图、错误伪标签或破坏语义的扰动会扩大错误。
- **自监督学习**从数据自身构造目标：遮蔽token再预测、从上下文预测下一个token、用同一图像的增强视图建立对比任务。GPT预测token而非必然整个词；自监督描述标签来源，不需要争论它必须被归进监督或无监督的唯一盒子。

分类训练常用交叉熵，回归常用平方损失或绝对损失。Accuracy是可以评价的0-1指标，通常不是直接用于梯度优化的光滑损失。标签、损失、最终决策指标要分别写明。

### 1.2 何时先采用规则或简单模型

先检查规则能否精确写出、训练数据是否代表预测对象、错误是否有可接受的处理机制，以及维护成本是否值得。无标签不等于完全不能用ML，十个样本也不是数学上的禁用线；能否学习取决于任务、先验、噪声与评价证据，少样本尤其不能把偶然分数当可靠效果。

对必须严格满足的约束，用可验证的规则或系统保护；确定性程序同样可能因错误输入和实现缺陷失效。可解释需求也不意味着所有ML都不可用，浅树、线性模型和明确特征常可作为候选。若任务变化快于训练和部署周期，先检查是否存在可维护规则、增量更新或更合适的任务定义。

“没有普遍最优算法”提醒我们比较归纳偏置，不是说现实任务里任何算法都一样。No Free Lunch结论需要相应的平均问题分布等前提，不能替代对当前数据结构的判断。

## 2. 基线给“模型有效”一个参照

基线必须只从训练数据取得信息，并按同一测试集、同一指标比较：

| 任务和目标 | 最小基线 | 为什么这样选 |
|---|---|---|
| 分类准确率 | 始终预测训练多数类 | 比随机猜测更能暴露类别比例问题 |
| 分类概率 | 预测训练正类比例 | 检查概率损失是否真正利用了特征 |
| 回归MSE | 训练标签均值 | 常数预测中最小化训练平方误差 |
| 回归MAE | 训练标签中位数 | 常数预测中最小化训练绝对误差 |
| 时间预测 | 最近值或季节对应值 | 比“随机猜”更贴近序列实际规律 |

模型没超过基线，先查指标、数据量、信号、实现和切分，不直接宣布“没有学到任何东西”。例如正类召回改善但总准确率下降，可能正是任务需要的改变。随机基线自身也有抽样波动，固定一次随机输出不足以证明优势。

## 3. 从零实现最近质心分类器

训练集 $X\in\mathbb R^{n\times d}$，每行一条样本。类别 $c$ 的均值向量为：

$$
\mu_c=\frac1{n_c}\sum_{i:y_i=c}x_i,\qquad
\hat y(x)=\arg\min_c\|x-\mu_c\|_2^2.
$$

不用开方也能选同一个最近中心。二分类边界由两边距离相等得到：

$$
2x^T(\mu_1-\mu_0)=\|\mu_1\|^2-\|\mu_0\|^2.
$$

它是中心连线的垂直平分超平面。来源图展示的“中心从标注点出现、再形成边界”就是这个过程，图中的坐标是示意而非数值实验。

手算：类0的点为 $(0,0),(0,2)$，类1为 $(4,0),(4,2)$，中心为 $(0,1),(4,1)$，边界是 $x_1=2$。查询 $(1,1)$ 的平方距离为1和9，预测0。若距离相等，必须规定平局策略。

下面是完整NumPy学习程序。它检查空输入、维度与有限值；按每类划分，保持训练与测试分离；同时比较随机和多数基线。

```python
import numpy as np

class NearestCentroidScratch:
    def fit(self, X, y):
        X, y = np.asarray(X, dtype=float), np.asarray(y)
        if (X.ndim != 2 or y.ndim != 1 or len(X) != len(y)
                or len(y) == 0 or X.shape[1] == 0 or not np.isfinite(X).all()):
            raise ValueError("输入须为非空有限二维特征及等长一维标签")
        self.classes = np.unique(y)
        self.centroids = np.stack([X[y == c].mean(axis=0) for c in self.classes])
        return self

    def predict(self, X):
        if not hasattr(self, "centroids"):
            raise RuntimeError("先fit再predict")
        X = np.asarray(X, dtype=float)
        if X.ndim != 2 or X.shape[1] != self.centroids.shape[1] or not np.isfinite(X).all():
            raise ValueError("预测特征维度或数值不合法")
        distances = ((X[:, None, :] - self.centroids[None, :, :]) ** 2).sum(axis=2)
        # np.unique的排序与argmin规定：完全平局时选第一个类别。
        return self.classes[distances.argmin(axis=1)]

rng = np.random.default_rng(42)
X = np.vstack([rng.normal([1., 1.], 1., (150, 2)),
               rng.normal([-1., -1.], 1., (150, 2))])
y = np.repeat([0, 1], 150)
train, test = [], []
for c in np.unique(y):
    idx = rng.permutation(np.flatnonzero(y == c))
    train.extend(idx[:105]); test.extend(idx[105:])
train, test = np.array(train), np.array(test)
model = NearestCentroidScratch().fit(X[train], y[train])
random_pred = rng.choice(model.classes, size=len(test))
classes, counts = np.unique(y[train], return_counts=True)
majority = classes[counts.argmax()]
print("中心", model.centroids.round(3))
print("质心准确率", round(np.mean(model.predict(X[test]) == y[test]), 3))
print("随机准确率", round(np.mean(random_pred == y[test]), 3))
print("多数准确率", round(np.mean(majority == y[test]), 3))
assert model.predict([[1., 1.], [-1., -1.]]).tolist() == [0, 1]
```

所测环境的输出：中心约 `[[1.078,0.953],[-1.031,-0.995]]`，测试质心准确率0.844、随机0.544、多数0.500。重复执行同一环境与种子应得到一致输出；这是90条合成测试的结果，不能说明真实文本或欺诈任务也有同样准确率，也不能单凭一次随机基线给出统计显著性。

### 3.1 适用范围与失败方式

训练计算均值约 $O(nd)$，预测 $m$ 个样本需 $O(mCd)$，存储中心约 $O(Cd)$，$C$ 为类别数。简单实现没有迭代训练超参数，但距离、缩放、是否收缩中心和先验处理都是可改变的设计；成熟库实现不保证与这个最小欧氏版本完全相同，应核对所用版本。

如果每类近似一个紧凑团块且尺度合适，中心有解释力；同一类别有两个相距很远的团块时，均值可能落在另一类别内部。环形类别也不能靠一个中心分开。大尺度无关特征会支配距离；缩放参数须只从训练集学习。类别方差或先验差异很大时，等距中心边界也未必是合理决策。

原来源高维实验为每个新增维度都增加相同类别信号，中心距随着 $\sqrt d$ 增大，所以准确率提高；这不证明“维度越高越好”。添加纯噪声维度会增加估计负担，要分别实验信号维与噪声维。

## 4. 平方损失下偏差—方差分解为何成立

固定输入 $x$，设新标签 $Y=f(x)+\epsilon$，其中 $f(x)=\mathbb E[Y\mid x]$，$\mathbb E[\epsilon\mid x]=0$，条件方差为 $\sigma^2(x)$。训练集随机变量 $D$ 与新标签噪声独立，训练算法产生 $\hat f_D(x)$。令 $\bar f(x)=\mathbb E_D[\hat f_D(x)]$，并假设所需二阶矩存在。

把误差拆为 $Y-\hat f_D=(f-\bar f)+(\bar f-\hat f_D)+\epsilon$；平方展开后，含零均值项的交叉期望为0，因此：

$$
\mathbb E_{D,Y\mid x}[(Y-\hat f_D(x))^2]
=\underbrace{(\bar f(x)-f(x))^2}_{\text{偏差平方}}
+\underbrace{\mathbb E_D[(\hat f_D(x)-\bar f(x))^2]}_{\text{方差}}
+\underbrace{\sigma^2(x)}_{\text{条件噪声}}.
$$

再对目标输入分布 $X$ 取期望得到整体误差。分类0-1损失或交叉熵不能直接套这三个平方误差项。“噪声不可约”是相对于现有输入信息；补充真实有效的测量特征可能降低条件噪声，单纯增加相同质量样本不消掉噪声本身。

训练误差不是偏差，训练—验证差也不等于方差。它们提供诊断线索，真正的方差需要观察同一算法在不同训练数据上的预测变化。优化未收敛、标签错误、分布漂移也能产生相似曲线。

### 4.1 知道真函数时的可核对实验

此例在 $[-1,1]$ 用 $f(x)=\sin(3x)$、噪声标准差0.3生成独立训练集，以次数1、3、12拟合。用 `lstsq` 避免显式求正规方程逆；区间缩小可减轻高次幂的数值尺度问题，但仍应留意条件数。

```python
import numpy as np
rng = np.random.default_rng(123)
grid = np.linspace(-1., 1., 200)
truth = np.sin(3 * grid)
noise_std, repeats = 0.3, 200
datasets = []
for _ in range(repeats):
    x = rng.uniform(-1., 1., 30)
    datasets.append((x, np.sin(3*x) + rng.normal(0., noise_std, len(x))))
for degree in [1, 3, 12]:
    predictions = []
    for x, y in datasets:
        w = np.linalg.lstsq(np.vander(x, degree+1, increasing=True), y, rcond=None)[0]
        predictions.append(np.vander(grid, degree+1, increasing=True) @ w)
    P = np.asarray(predictions)
    bias2 = np.mean((P.mean(axis=0) - truth)**2)
    variance = np.mean(P.var(axis=0, ddof=0))
    clean_error = np.mean((P - truth)**2)
    assert np.isclose(clean_error, bias2 + variance)
    print(degree, "偏差平方", round(bias2, 4), "方差", round(variance, 4),
          "含新标签噪声的期望MSE", round(clean_error + noise_std**2, 4))
```

这里有限预测集合对干净函数的平均误差**恰好**等于使用 `ddof=0` 的经验偏差平方加经验方差；200次只是近似总体训练集期望，额外加0.09才是对新标签噪声取期望的MSE。不能把干净函数误差误称为含噪测试MSE。

每轮从生成分布独立重采样，不是Bootstrap。Bootstrap是在某个固定观测集上有放回抽样，两者近似的对象不同。现实中真函数未知，不能凭训练—验证曲线算出精确偏差和不可约噪声。

所测环境中次数1的偏差平方/方差约0.1687/0.0212，次数3约0.0034/0.0171，次数12约33.3096/10273.3490。高次模型在有限随机训练点的边界附近可能严重震荡，且网格端点经常在某次训练样本范围之外；少数极端拟合也会改变平均预测，从而让经验偏差很大。这个实验同时说明“更复杂必降低偏差”不是对任意估计程序的定律。可缩窄评价区间、增加样本、检查设计矩阵条件数并加正则作对照，不能偷偷删掉大误差重跑来制造漂亮曲线。

## 5. 用曲线选择下一项实验

**学习曲线**固定模型设置、改变训练样本量；**验证曲线**固定数据、改变超参数；**训练轨迹**随轮数观察训练/验证变化。三种横轴不可混用。验证曲线顶点用于模型选择，最终效果仍需独立测试或嵌套验证。

| 观察 | 可尝试的假设 | 下一项最有用的核查 |
|---|---|---|
| 训练和验证都差、差距小 | 表达不足、正则太强，也可能未收敛或标签问题 | 先查实现与标签；再试交互特征、容量或减正则 |
| 训练好、验证差 | 对训练集敏感，也可能群体/时间不同 | 查切分与泄漏、分组误差；再试正则、更多代表性数据 |
| 增加样本，验证变好、差距缩小 | 数据受限的证据 | 估算新增数据边际收益并重复划分 |
| 两条曲线平坦且都差 | 当前数据和模型组合已受限制 | 查信息不足、目标噪声与分布差异；“更多数据无用”不能绝对化 |
| 训练持续改善，验证先改善后变差 | 对当前训练轮数存在过拟合风险 | 验证上早停并恢复最佳轮次；测试集不选轮次 |

误差高低必须相对于任务、基线和测量噪声定义，不设“差距10%必为过拟合”的万能线。来源示意图的U形曲线是人为函数，不能当真实测量或证明所有复杂度曲线一定呈U形。

### 5.1 正则化与集成的作用需看条件

L2惩罚限制系数，L1常产生稀疏系数；惩罚增大通常在某些问题上用更大偏差换更小方差，但不是每个点、每个模型必然单调。过强正则可能使模型欠拟合。Dropout与早停是训练过程的约束，不能机械移植到任何算法。

若 $M$ 个预测各有方差 $v$、两两协方差为 $\rho v$，等权平均的方差是：

$$
\operatorname{Var}\left(\frac1M\sum_{j=1}^M\hat f_j\right)
=v\left(\rho+\frac{1-\rho}{M}\right).
$$

独立时 $\rho=0$ 得到 $v/M$；高度相关时再加模型收益小。Bagging重采样并平均，常降低高方差模型波动，但偏差也可能变化；随机森林还加入特征随机性。Boosting逐步修正组合误差，常改善表达，也可能同时改变偏差和方差。Stacking要用折外预测训练元模型，不能把基模型训练内分数当元模型输入。深度学习相关细节沿用[泛化与正则化专题](../深度学习专题/09-泛化评估与正则化.md)。

## 6. 双下降补充了什么，不能推出什么

部分数据、模型与优化设置中，随容量增加，测试误差先下降、在接近能插值训练集的区域上升、随后再次下降。这称容量双下降；也有随轮数或样本量出现类似非单调行为。插值阈值取决于数据秩、噪声、特征和算法，不能普遍设成“参数数等于样本数”。

在过参数化线性模型中，梯度下降等算法可偏向某类最小范数解；在神经网络中，优化路径和架构也构成归纳偏置。但“找到最简单解”不是任意优化器与参数化的保证。双下降与平方损失分解并不矛盾：变化的是偏差和方差随有效复杂度的轨迹。

它否定“更多参数必然更差”的简单直觉，**不保证加大模型就改善任务**。噪声、分布变化、正则和资源限制可能使第二次下降不出现；正则可能削弱甚至避免峰值。“要么很小、要么远超插值阈值”的机械建议不进入操作规范，仍以验证、成本、学习曲线和重复实验决定。

原始证据入口：[Belkin等，2019](https://arxiv.org/abs/1812.11118)、[Nakkiran等，2019](https://arxiv.org/abs/1912.02292)。这里只保留有条件的现象与解释，不把论文某组曲线推广为所有模型的规律。

## 7. 练习与参考判断

1. 给商品退货、下月需求、无标签用户分组定义任务。**参考：**退货可为分类，需求为回归，分组为无监督聚类；还必须写样本单位、预测时点、标签窗口和可用特征。任务名称不能代替这些条件。
2. 训练99%、验证60%，直接下结论“必须加正则”合理吗？**答案：**先排泄漏、实体/时间分布差异、标签与预处理不一致，再用重复划分和曲线判断过拟合；可试简化、正则、更多代表性数据。
3. 70/15/15有固定最优性吗？**答案：**没有。标签数、目标置信度、群体/时间依赖决定比例；最后15%若参与选择就成为验证数据。
4. 把分解程序的噪声设0、样本由30改300、真函数改为 $\sin x$，该观察什么？**答案：**噪声项为0；样本增加通常降低估计波动，但最佳次数由函数、有限样本与数值稳定性决定；不能写死次数。分别报告三个分量，并用相同生成数据公平比较。
5. 对次数12模型扫L2强度，如何解释？**参考：**在固定特征缩放与相同训练重采样下记录偏差平方、方差及总误差；最优强度由验证选。过强约束未必只变成常数，取决于哪些系数被惩罚。
6. 用固定训练集的10个Bootstrap样本拟合并平均，怎样验证Bagging？**参考：**对多个独立训练集分别建立单模型与Bagging，在固定网格上比较两种算法的预测方差与偏差；只看一次平均后的曲线不能测训练集方差。式中的相关性说明下降不一定是10倍。
7. 合成数据维度2→50后准确率提高，可以说高维没有困难吗？**答案：**不能。原程序每一维都含同方向信号；再做只增加噪声维的对照，才能讨论新增维度的信息与样本负担。
