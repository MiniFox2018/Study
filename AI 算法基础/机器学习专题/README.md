# 机器学习专题

本专题深化[经典监督学习](../04-经典监督学习.md)、[特征与评估](../05-特征工程-评估与无监督学习.md)和[实战闭环](../18-机器学习实战闭环与手写验证.md)。按问题组织算法、实验和边界，补足可独立学习的推导、程序与练习；不按来源另建一套课程。

## 先修与第一遍顺序

先能运行Python小程序，读懂数组shape、矩阵乘法、均值/方差和简单条件概率；梯度与数值稳定可随时回到[数学专题](../数学与数值计算专题/README.md)。

第一遍建议：问题与基线06 → 评价/切分07 → 线性回归01或近邻04 → 逻辑回归02 → 特征11与管道09 → 小项目复现。先用小数据解释输出、改一个条件并排错，再选树、集成、聚类、时间序列和调参，不必为了目录完整一次运行全部方法。

## 贯穿各章的三个检查

**输入契约**：观测单位、标签定义、可用时刻、shape/dtype、缺失/未知类别、权限和数据版本是否清楚？

**学习边界**：预处理、特征选择、重采样、调参和校准是否只使用允许的训练/验证信息，是否有群体/时间泄漏？

**结果证据**：与哪个基线比较，用什么指标和样本，结果是否稳定、有什么错误和限制？运行不报错与用户真正掌握是不同状态。
