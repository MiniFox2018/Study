# 13｜时间序列与异常检测

> 先修：回归、概率分布、训练/验证切分；基础购物篮与时间概念见[关联规则与时间序列](../17-关联规则与时间序列.md)。本章是时间建模、可用时间审计和异常检测的主要详解入口。先做滞后对齐与滚动回测，再理解平稳性/ARIMA，最后做异常分数与告警阈值。

## 1. 定义预测时刻、数据时间与可用时间

“预测下周销量”还缺少：每周哪天发预测、一次预测几天、每天是否更新、外部特征何时发布。设在 t 时刻已观察到 $y_t$，预测 $y_{t+h}$；这是 forecast origin=t、horizon=h。若在 t 开始前预测 $y_t$，可用历史截止 $t-1$。两种表定义都可用，但同一程序必须一致。

先检查时间戳、时区、排序、重复、采样间隔、缺行、设备/产品ID，以及事件发生时间与入库/公布时间。预测时不能使用“事件已发生但当时尚未入库”的信息。销售为0、没开店、没上报不是同一个缺失状态。有时间行但值为NaN是字段缺失；本该有每日记录却整行不存在是缺失时间。先按预期日历/营业日重建索引再分开统计，不能只检查isna就宣称完整。前向填充仅在语义允许时用过去，双向插值/反向填充可能借用未来，不能直接用于在线预测。小时汇成日，销售额用和、温度可能均值、库存可能期末值；按业务定义重采样，不能所有列取均值。

外部指标须按**发布时间**关联，不只按它描述哪一个月。以下完整示例10:00预测只能看到09:00发布的20，12:00才能看到11:00发布的25；`nearest` 或 `forward` 可能取未来。带多实体时须按实体匹配，两个表都按关联时间升序，另设 tolerance 限制陈旧值。

```python
import pandas as pd

left = pd.DataFrame({'预测时间': pd.to_datetime(['2026-01-01 10:00', '2026-01-01 12:00'])})
right = pd.DataFrame({'发布时间': pd.to_datetime(['2026-01-01 09:00', '2026-01-01 11:00']),
                      '指标': [20, 25]})
joined = pd.merge_asof(left.sort_values('预测时间'), right.sort_values('发布时间'),
                      left_on='预测时间', right_on='发布时间', direction='backward')
assert joined['指标'].tolist() == [20, 25]
assert (joined['发布时间'] <= joined['预测时间']).all()
print(joined[['预测时间', '指标']].to_string(index=False))
```

## 2. 滞后、滚动、日历特征：错一行即可泄漏

如果目标行是 $y_t$，lag-k 是 $y_{t-k}$，过去 w 项均值为 $\frac1w\sum_{j=1}^w y_{t-j}$。pandas 中先 `shift(1)` 再 `rolling(w)`；直接 `rolling(w)` 包含当前目标。序列 $[10,12,14,13,15]$ 用lag1/2预测14时，输入是12和10；没有14。

如果特征行代表“刚观察到 $y_t$ 的时刻”，目标是 `shift(-h)`，此时允许包含 $y_t$，不允许包含 $y_{t+1}$。滚动、递增均值、最近变化、日历、提前排定的促销可用；未来实际天气不可用，但当时发布的天气预报可以，必须存下预报版本。

时间特征的计算要按设备/商品分组，不能把上一商品最后值变成下一商品第一lag。`dropna()` 应仅按必要输入和目标做，保留时间索引；删除窗口后要检查训练样本的目标时间是否仍满足切分。行数 gap 在不规则时间上不等于固定时长，必要时直接按时间边界切。

## 3. 平稳性、差分与 ACF：检验没有一票保证

弱平稳指均值固定、有限方差固定、协方差只依赖时差；不是“值不变”。趋势和固定季节相位通常破坏均值平稳。加法分解 $y_t=T_t+S_t+R_t$，乘法适合幅度随水平变化；残差仍可能自相关，不能叫成独立白噪声。原分解图表示各项在同一时间点相加，不证明真实数据一定恰有三项。

一阶差分 $\Delta y_t=y_t-y_{t-1}$，季节差分 $y_t-y_{t-s}$。差分是原单位变化；增长率 $r_t=(y_t-y_{t-1})/y_{t-1}$ 是比例。例如 `[100,110,99]` 的差分是 `[10,-11]`，增长率是 `[0.10,-0.10]` 即10%和−10%。pandas `pct_change(fill_method=None)` 返回比例，没有自动乘100%；先确保正确排序/分组，缺失两侧的变化应保持不可计算，不靠隐式填充造变化。前值0导致比例不可定义/无穷，负基数的百分比可能没有业务意义，应改用绝对变化或业务定义的尺度。正数对数收益 $\log y_t-\log y_{t-1}$ 在例子中约为 `[0.09531,-0.10536]`，不能当普通增长率恰好相等。确定线性趋势一次差分变常数，二次趋势通常两次；这只是确定性例子。随机波动、季节、异方差和结构断点不保证由某个固定差分次数修复。**过度差分可引入虚假动态并放大噪声，不是永远无害。**预测差分后须累加还原，季节差分加回相应历史基值。对数预测指数还原通常对应中位数尺度，均值预测需考虑变换偏差；不直接当无偏金额。

ADF 原假设是存在单位根，拒绝它仅是在指定截距/趋势、滞后、样本长度与检验条件下反对单位根，不能证明全部形式平稳。KPSS 原假设则是指定形式的水平/趋势平稳。滚动均值/方差是一种诊断，有限样本波动或“不超过某标准差”的经验规则不是正式检验。先画数据、看结构断点，再解释检验与模型。

对均值中心化序列，一种常见样本 ACF 约定为：

$$
\hat\rho_k=\frac{\sum_{t=k+1}^n(y_t-\bar y)(y_{t-k}-\bar y)}{\sum_{t=1}^n(y_t-\bar y)^2}.
$$

不同软件有有偏/无偏分母约定，不能混用结果。PACF 是控制较短滞后后的线性相关。ACF某处为0不证明过去完全没有非线性信息；多个滞后置信区间不能逐个当独立的发现。lag候选结合领域周期提出，在训练段选择，避免用整条未来序列 ACF 调参。

## 4. AR、MA、ARIMA 与其他基线

AR(p) 用过去值：$y_t=c+\sum_{i=1}^p\phi_i y_{t-i}+\epsilon_t$。MA(q) 用当前与过去**随机冲击**：$y_t=\mu+\epsilon_t+\sum_{j=1}^q\theta_j\epsilon_{t-j}$，与“最近7项均值”的移动平均特征不是一回事。ARIMA(p,d,q) 先对序列做 d 次差分，再建 ARMA。AR稳定性要看根条件，例如AR(1)通常要求 $|\phi|<1$；不是任意回归系数都形成稳定过程。

SARIMA 增加季节 $(P,D,Q,s)$；带外生变量时，未来预测必须提供其未来可用值。statsmodels 的 ARIMA 本身支持 `exog`，不是“ARIMA只能不带外部变量”。误差诊断要看残差自相关、异方差、异常、参数不确定性，以及未来回测；AIC挑得最好不等于业务未来误差最低。

不管模型多复杂，先建立上一值、季节朴素、最近均值。指数平滑直接平滑水平、趋势、季节，有效的趋势模型可以用于非平稳序列；线性回归含时间趋势也可以建非平稳均值。普通树的叶值平均通常难超出训练目标范围，不能说“树会自动外推上涨趋势”。季节朴素胜过复杂模型可能就是合理结论，不必一定归咎程序出错。

下面为完整的statsmodels可选程序。本组初验时缺依赖未执行；随后根级用隔离的statsmodels0.15.0实际运行，ADF统计量约−5.879，p值舍入显示0.0（不表示精确概率为零），未来MAE约0.648。结果仅对应本例数据与划分，不证明全部形式平稳或模型普遍最佳。示例自生成序列，不调用外部数据。

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.arima.model import ARIMA

rng = np.random.default_rng(7)
y = np.empty(160)
y[0] = 0
for t in range(1, len(y)):
    y[t] = .6 * y[t-1] + rng.normal()
train, test = y[:140], y[140:]
stat, pvalue, usedlag, nobs, critical, icbest = adfuller(train, regression='c', autolag='AIC')
fit = ARIMA(train, order=(1, 0, 0)).fit()
forecast = np.asarray(fit.forecast(steps=len(test)))
print('ADF单位根检验', round(stat, 3), round(pvalue, 3), '滞后数', usedlag)
print('ARIMA未来MAE', round(np.mean(np.abs(test - forecast)), 3))
assert forecast.shape == test.shape and np.isfinite(forecast).all()
```

## 5. Walk-forward：模拟真实预测服务

随机把未来样本放进训练，会评估“知道未来时对过去的插值”，不能代表未来预测。普通 KFold 默认也未必shuffle，但其训练折仍包含验证之后的时间，照样不合适。正确回测按 forecast origin推进：训练仅过去、预测之后，再向前。Expanding用所有历史，sliding只留最近固定窗口；数据慢变时历史有用，结构改变时旧数据可能伤害，需验证。

最重要的额外审计是**训练标签的可用时间**。行 origin=t 预测 t+h，在 cutoff=C 处训练只能用 $t+h\le C$ 且标签确实已发布的样本。仅检查特征行 index<C，可能把标签从未来偷回来。存在重叠目标、延迟发布时设 gap/purge，按真实时间计算而不是凭固定经验天数。

一块测试窗口全部先建好真实lag、直接预测，与一个起点一次预测整块未来不同：前者是每步真实值到来后的更新预测，后者未来lag只能来自自己的预测。两者都可评估，但必须明确服务方式，不能把多步“偷看真实未来lag”的误差当部署分数。

完整程序以 origin时刻已观察 y[origin] 为约定。每个起点分别做未来7步 recursive 和每 horizon 独立direct，并与季节朴素比较。每个 direct 模型的训练样本标签最多到当前起点。

```python
import numpy as np
from sklearn.linear_model import Ridge

rng = np.random.default_rng(7)
n, horizon, lags = 240, 7, 14
t = np.arange(n)
y = 30 + .02*t + 4*np.sin(2*np.pi*t/7) + rng.normal(0, .8, n)

def features(series, origin):
    return np.asarray([series[origin-j] for j in range(lags)])

def fit_direct(series, origin, h):
    origins = range(lags-1, origin-h+1)
    X = np.array([features(series, o) for o in origins])
    targets = np.array([series[o+h] for o in origins])
    assert max(o+h for o in range(lags-1, origin-h+1)) <= origin
    return Ridge(alpha=1.).fit(X, targets)

errors = {name: [] for name in ['递归', '直接', '季节朴素']}
for origin in range(100, n-horizon, horizon):
    one_step = fit_direct(y, origin, 1)
    history = list(y[:origin+1])
    recursive = []
    for _ in range(horizon):
        pred = float(one_step.predict(features(history, len(history)-1)[None])[0])
        recursive.append(pred)
        history.append(pred)
    direct = [float(fit_direct(y, origin, h).predict(features(y, origin)[None])[0])
              for h in range(1, horizon+1)]
    seasonal = [y[origin+h-7] for h in range(1, horizon+1)]
    truth = y[origin+1:origin+horizon+1]
    for name, pred in [('递归', recursive), ('直接', direct), ('季节朴素', seasonal)]:
        errors[name].append(np.abs(truth - np.asarray(pred)))
for name, records in errors.items():
    arr = np.array(records)
    assert arr.shape[1] == horizon and np.isfinite(arr).all()
    print(name, '总体MAE', round(arr.mean(), 3), '按horizon', arr.mean(axis=0).round(3))
```

本次固定序列回测：递归总体MAE约0.660，直接约0.668，季节朴素约0.802；直接预测没有保证优于递归。相同种子只是方便核对，模型选择仍需独立时段。

Recursive只用一个1步模型，推理逐步喂自己的预测，误差可能累积；direct每个horizon一个模型，不用其他预测当输入，但每个训练样本数量不同，不能保证更准；multi-output一个模型联合输出多个目标，可共享结构，须统一目标可用边界。上例7步季节朴素都直接来自起点以前，h>7时需反复按季节位置映射，不能直接读取未来。

## 6. 评价、漂移与部署一致性

MAE以原单位解释，RMSE更惩罚大误差；MAPE在0/近0时失真，不能悄悄删0而叫完整人群MAPE。MASE可用测试绝对误差除以训练季节朴素的平均绝对差，分母为0时也须报告不可定义。多个序列汇总需说明按样本、按序列还是按销售规模加权，避免大系列掩盖小系列。

报告总体及每个horizon、时间段、产品组的结果，同时给出基线；区间预测检查覆盖率与宽度，点预测误差不说明不确定性。至少测试业务相关季节与结构变化，只有一个短窗口不能证明长期适用。random与walk-forward分数差异也受训练量、时间段和难度影响，不能仅凭差距断言测出了泄漏大小。

部署时使用与训练一致的时区、频率、lag历史缓存和发布时间查询；记录 model version、forecast origin、horizon、输入可用时间与预测。随真实目标到来监测残差、缺失/未知类别、数据分布、迟到率；候选重训需重新回测。股票示例可以练处理序列，但价格误差小不等于盈利，需额外核对复权、幸存者偏差、交易成本和成交约束。

## 7. 时间序列练习与参考判断

1. `[100,102,106,112,120]` 两次差分是什么？**答案：**一次`[2,4,6,8]`，二次`[2,2,2]`；仅演示确定性二次趋势，不证明任意现实序列平稳。
2. 对 y_t 预测的7日均值应怎么写？**答案：**`series.shift(1).rolling(7).mean()`，按实体分组，检查当前目标不在窗口。
3. ACF周周期在7/14有峰，必须保留lag1～14吗？**答案：**不必；试lag7/14和连续lag候选，在同训练/验证时间上比较。没有线性相关不意味着所有预测信息不存在。
4. cutoff100训练h=7，origin99可以进训练吗？**答案：**不行，目标106未到；origin最多93，且确认标签发布时间。
5. 用真实测试窗口lag一次预测7天，再叫“固定起点7步”，问题在哪？**答案：**后几天特征含起点之后的真实销量；应递归或direct，或如实改名为逐日更新1步评估。
6. 加滚动mean/std和星期是否一定变好？**答案：**不一定，增加冗余或过拟合也可能变差；在一致的多起点回测报告分数、耗时与按horizon结果。
7. 复杂模型输给季节朴素应怎么办？**答案：**先查对齐/训练边界，再接受基线可能适合该数据；不能预设复杂模型必胜。

8. 怎样比较random与walk-forward？**答案：**固定相同特征定义、模型预算与可比时间段，明确random估的是已知总体插值而非未来预测，报告训练量和数据难度差异；不能把两分数相减直接叫泄漏量。
9. 怎样比较5步recursive与direct？**答案：**用第5节程序把horizon设5，同一forecast origin和可得数据，记录各h的误差、训练时间和模型数；direct没有统一更准结论，未来真实lag都禁止使用。

## 8. 异常检测：异常分数不是故障概率

点异常是单个异常值；上下文异常是相对时间/地点/设备状态异常；集体异常是整段模式异常。持续50次失败登录可能每次都正常、整段却可疑。先定义事件/窗口与损失，单点检测器不自动识别序列，可加入过去窗口计数、持续时长、突变、残差和运行工况。

Outlier detection在可能被污染的总体中找罕见点；novelty detection用相对干净的正常基线训练后，对未见新数据评分；有足够异常标签也可用不平衡监督分类。少量标签不必“只能用于评估”，也可帮助训练/阈值，但要另留独立评估。无监督可能捕获偏离正常的新类型，也会漏掉藏在正常分布内的异常；监督模型也可能泛化到某些新形式，不能下绝对判断。

“不常见”不等于“有害”，罕见正常客户可能只是少数群体。原围栏图表达相对训练正常区域偏离的告警候选，不是对所有未知故障的覆盖保证。生产要把分数、阈值、人工确认和已知规则组合记录。

## 9. Z-score、IQR与在线统计

Z-score按正常训练基线算 $z_j=(x_j-\mu_j)/\sigma_j$，可取 $\max_j|z_j|$ 作为多列分数。在单变量高斯假设下3σ外概率约0.27%，不代表任意右偏分布的固定误报率。多维“任一列越界”会放大总体误报率；独立100列各0.27%时，至少一列越界约 $1-(1-.0027)^{100}\approx24\%$。

IQR围栏 $[Q_1-1.5IQR,Q_3+1.5IQR]$ 是箱线图启发式，不需正态，但右偏合法长尾也可能被标记。极端值少时分位数较稳健，不代表永远不受污染。IQR=0/σ=0说明训练常数或离散峰值，应按仪器精度/业务容差处理，不能无说明替换成1让单位改变。

两者单列检查都可能漏掉联合异常：数据集中在 y≈x 对角线，点(x=0.5,y=-0.5)单独两列都正常，组合却异常。可用协方差距离、LOF或其他多变量模型，仍需实测；不能保证 iForest 每次都抓到。

流式均值/方差可用 Welford，先用**既有状态**评分，之后更新，避免新值先改变基线而掩盖自己。对已确认异常可暂停更新；反之可能适应过慢，策略需业务确认。Welford本身没有遗忘，分布变化可用滑动窗口或有明确权重的衰减。

```python
import numpy as np

class RunningStats:
    def __init__(self):
        self.n, self.mean, self.m2 = 0, 0., 0.
    def update(self, x):
        self.n += 1
        delta = x - self.mean
        self.mean += delta / self.n
        self.m2 += delta * (x - self.mean)
    def variance(self):
        return self.m2 / self.n if self.n else np.nan

x = np.array([10., 12., 11., 13., 14.])
state = RunningStats()
for value in x:
    state.update(value)
assert np.isclose(state.mean, x.mean())
assert np.isclose(state.variance(), x.var(ddof=0))
print('流式均值/总体方差', state.mean, state.variance())
```

## 10. Isolation Forest：短路径与分数方向

隔离树不按标签寻找最佳分裂，而是随机取一非恒定特征，再在其范围内随机切阈值。稀少且容易被切开的点平均路径短，形成告警依据；它不是距离算法，也不保证所有低密度/密集区域内异常都能检出。类别字符串仍须有合法编码，不能声称任意混合类型可直接输入。

一棵树可在深度上限处停止；叶子还有 m 个点时，要在已走深度上加预期余下路径 $c(m)$。经典分数 $s(x)=2^{-E[h(x)]/c(\psi)}$，$\psi$是每树子样本数，$c(n)=2H_{n-1}-2(n-1)/n$，$c(1)=0$。越接近1越可疑；0.5是理论参照，不是所有业务通用阈值。

完整 NumPy教学实现使用精确小样本调和和数、树终止修正、非恒定特征选择、固定子样本数；不含生产优化。

```python
import numpy as np

def c_factor(n):
    if n <= 1:
        return 0.
    return 2 * np.sum(1 / np.arange(1, n)) - 2 * (n-1) / n

class IsolationTree:
    def __init__(self, rng, limit):
        self.rng, self.limit = rng, limit
    def fit(self, X, depth=0):
        self.size = len(X)
        varying = np.flatnonzero(np.ptp(X, axis=0) > 0) if len(X) else []
        self.leaf = depth >= self.limit or self.size <= 1 or len(varying) == 0
        if self.leaf:
            return self
        self.j = int(self.rng.choice(varying))
        self.cut = float(self.rng.uniform(X[:, self.j].min(), X[:, self.j].max()))
        mask = X[:, self.j] < self.cut
        self.left = IsolationTree(self.rng, self.limit).fit(X[mask], depth+1)
        self.right = IsolationTree(self.rng, self.limit).fit(X[~mask], depth+1)
        return self
    def path(self, x, depth=0):
        if self.leaf:
            return depth + c_factor(self.size)
        child = self.left if x[self.j] < self.cut else self.right
        return child.path(x, depth+1)

class IsolationForestScratch:
    def __init__(self, trees=50, samples=64, seed=7):
        self.count, self.samples, self.seed = trees, samples, seed
    def fit(self, X):
        X = np.asarray(X, float)
        if X.ndim != 2 or len(X) < 2 or not np.isfinite(X).all() or self.count < 1 or self.samples < 2:
            raise ValueError('需要有效二维数据和至少2个子样本')
        rng = np.random.default_rng(self.seed)
        self.psi, self.trees = min(len(X), self.samples), []
        limit = int(np.ceil(np.log2(self.psi)))
        for _ in range(self.count):
            sample = X[rng.choice(len(X), self.psi, replace=False)]
            self.trees.append(IsolationTree(rng, limit).fit(sample))
        return self
    def score(self, X):
        X = np.asarray(X, float)
        avg = np.array([[tree.path(x) for x in X] for tree in self.trees]).mean(axis=0)
        return 2 ** (-avg / c_factor(self.psi))

rng = np.random.default_rng(7)
normal = rng.normal(0, .5, (200, 2))
model = IsolationForestScratch().fit(normal)
probe = np.r_[normal[:10], [[7., 7.], [-7., -7.]]]
scores = model.score(probe)
assert np.isfinite(scores).all() and scores[-2:].mean() > scores[:10].mean()
print('正常/远点平均分', scores[:10].mean().round(3), scores[-2:].mean().round(3))
```

sklearn `score_samples` 方向相反：更低通常更异常，本章使用负号转成“越大越异常”。`decision_function`是分数减阈值偏移，负值异常。iForest的 `contamination` 控制偏移/二值阈值，不改变固定随机种子的原始隔离分数；不同随机种子训练两模型，分数仍可能不同。取5%污染并不是确认有5%真实故障。

## 11. LOF、One-Class SVM 与重建模型

### 11.1 LOF：相对于邻居的密度

对点 p 和邻点 o，reachability distance 为 $\max(k\text{-distance}(o),d(p,o))$。局部可达密度 $lrd_k(p)$ 是这些可达距离均值的倒数；

$$
LOF_k(p)=\frac1{|N_k(p)|}\sum_{o\in N_k(p)}\frac{lrd_k(o)}{lrd_k(p)}.
$$

接近1表示和邻居密度相似；显著大于1表示局部稀疏。高维无关列、距离、重复点、k和并列距离处理都会影响结果；不是“只要多个密度簇就总能识别”。小k对噪声敏感，大k可能把小正常簇与大簇混合。

下面完整手写训练集LOF，假设无距离并列/重复，邻域固定k；用于与sklearn `negative_outlier_factor_`核对。生产定义对并列邻距可能包含更多点，不能一概保证数值一致。

```python
import numpy as np
from sklearn.neighbors import LocalOutlierFactor

rng = np.random.default_rng(7)
X = np.r_[rng.normal(0, .3, (45, 2)), [[3., 3.]]]
k = 8
d = np.linalg.norm(X[:, None] - X[None], axis=2)
np.fill_diagonal(d, np.inf)
neighbors = np.argsort(d, axis=1)[:, :k]
kdistance = np.take_along_axis(d, neighbors, axis=1)[:, -1]
reach = np.maximum(d[np.arange(len(X))[:, None], neighbors], kdistance[neighbors])
lrd = 1 / np.maximum(reach.mean(axis=1), 1e-12)
lof = (lrd[neighbors] / lrd[:, None]).mean(axis=1)
reference = LocalOutlierFactor(n_neighbors=k).fit(X)
assert np.allclose(lof, -reference.negative_outlier_factor_, rtol=1e-7, atol=1e-7)
assert lof[-1] > 2
print('手写LOF远点', round(lof[-1], 3))
```

默认LOF用于当前训练集合 outlier detection，用 `fit_predict` 和训练 `negative_outlier_factor_`；`novelty=True`用于相对基线的新点，其 `predict/score_samples`只能对未见新数据调用，不能对训练样本当同一评估。下节程序显式使用新样本。

### 11.2 One-Class SVM：正常支持区域

核One-Class SVM在核特征空间寻找把大部分正常训练点与原点分开的边界。RBF gamma控制边界细度，输入需缩放；nu是训练误差比例上界和支持向量比例下界（理论/求解条件下），**不是未来异常率**。污染基线会扭曲边界，核法大规模成本高；可考虑线性近似方案并另验效果。

### 11.3 Autoencoder与低维重建

编码器把 x映成 z，解码器重建 $\hat x$，在正常训练数据最小化重建损失，用 $\|x-\hat x\|^2$ 或适合字段的损失当异常分数。瓶颈、正则、网络能力影响学到的正常结构；过强模型可能连异常也重建好，异常若在正常流形上也可能不被检出。

不等单位列会支配MSE，需按训练尺度和业务成本处理；类别重建宜对应概率损失，而非编号平方误差。阈值在独立校准段选择，不能把训练重建误差分位点当必然泛化阈值。本批用PCA重建演示**线性降维重建基线**；它与特定线性AE目标有关，但不是已经运行深度autoencoder。深度训练接[深度学习基础](../07-深度学习基础.md)，此处不制造“神经网络必检异常”的结论。

## 12. 完整告警实验：训练、校准、测试分开

生成正常对角结构，与少量离开结构的异常。正常训练拟合基线；独立正常校准数据定99%分位阈值；独立带标签测试计算检测结果。这里的1%是校准样本上的期望告警预算，未来分布变化或有限样本不保证恰好1%。因各方法失败模式不同，结果可能有明显差距，不能预设谁获胜。

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.svm import OneClassSVM
from sklearn.decomposition import PCA
from sklearn.metrics import precision_recall_fscore_support, average_precision_score

rng = np.random.default_rng(7)
def normal_data(n):
    x = rng.normal(size=n)
    return np.c_[x, x + rng.normal(0, .12, n)]
Xtrain, Xcal = normal_data(350), normal_data(200)
Xnormal = normal_data(300)
anomalies = np.c_[rng.uniform(-1.5, 1.5, 30), rng.uniform(-1.5, 1.5, 30)]
# 合成标注按生成来源定义，部分异常可能仍接近正常结构。
Xtest = np.r_[Xnormal, anomalies]
ytest = np.r_[np.zeros(len(Xnormal)), np.ones(len(anomalies))]
scaler = StandardScaler().fit(Xtrain)
train, cal, test = map(scaler.transform, [Xtrain, Xcal, Xtest])
mu, sigma = train.mean(axis=0), np.maximum(train.std(axis=0), 1e-12)
q1, q3 = np.quantile(train, [.25, .75], axis=0)
iqr = np.maximum(q3 - q1, 1e-12)
iso = IsolationForest(n_estimators=80, random_state=7, contamination='auto').fit(train)
lof = LocalOutlierFactor(n_neighbors=20, novelty=True).fit(train)
svm = OneClassSVM(nu=.05, gamma='scale').fit(train)
pca = PCA(n_components=1).fit(train)

def scores(X):
    reconstructed = pca.inverse_transform(pca.transform(X))
    return {
        'Z-score': np.max(np.abs((X-mu)/sigma), axis=1),
        'IQR距离': np.max(np.maximum((q1-X)/iqr, (X-q3)/iqr), axis=1),
        'IsolationForest': -iso.score_samples(X),
        'LOF新颖检测': -lof.score_samples(X),
        'OneClassSVM': -svm.score_samples(X),
        'PCA重建': np.mean((X-reconstructed)**2, axis=1),
    }
cal_scores, test_scores = scores(cal), scores(test)
for name, s in test_scores.items():
    threshold = np.quantile(cal_scores[name], .99)
    alert = s > threshold
    precision, recall, f1, _ = precision_recall_fscore_support(ytest, alert, average='binary', zero_division=0)
    topk = np.argsort(s)[-30:]
    pak = ytest[topk].mean()
    ap = average_precision_score(ytest, s)
    assert np.isfinite(s).all()
    print(name, '告警数', int(alert.sum()), 'P/R/F1', np.round([precision, recall, f1], 3),
          'P@30', round(pak, 3), 'AP', round(ap, 3))
```

本次固定生成过程实测：Z/IQR阈值告警没有命中联合异常；iForest在这个99%校准阈值下甚至没有告警。LOF新颖检测召回约0.833/AP约0.859，PCA重建召回约0.900/AP约0.913。这个反例说明多变量检测也不保证成功，需核对正常结构、分数分布与业务阈值，不能只把示例调到全胜。

`average_precision_score`是PR曲线的非插值加权摘要AP，不等同于任意梯形积分AUPRC，记录口径。异常设为正类，并核对分数越大越异常，否则排序指标可能被反转。Precision@k是在top-k里真实异常比例，k必须不超过样本数；没有全量真值时只是核查样本的估计，不能给全部未告警点编真标签。

## 13. 阈值、成本、组合与漂移

只有正常标签时可以用独立基线的分位点控制告警候选数量，须估计未来误报并给抽查反馈。已有有代表性的异常标签时，可在校准集选择最小预期成本 $C_{FP}FP+C_{FN}FN$、目标recall或容量约束，再在测试集评估；稀有率和成本与训练样本不同，需要按部署分布校正。

例如一万人中10个故障，检测召回率90%、正常误报率1%，约9个真告警与100个误告警，precision约8.3%。高accuracy或高ROC-AUC不保证可用的告警precision；报告AP/PR、指定FPR下recall、每天告警数、事件级发现延迟，不能只用一张排行榜。告警只抽查高分区会产生反馈偏差，需抽查低分与未告警区域，否则漏报率不清楚。

多个检测器组合前统一分数方向，并在校准数据学习尺度/排名映射，再应用新点。每批重新min-max归一化会随极端点改变阈值。取交集通常减少告警但会损失召回，取并集增加覆盖也增加误报；共同失败的数据/特征会使所有方法一致误判，**一致不代表几乎确定异常**。用同一真实验证协议选择策略，而非“生产一律多方法投票”。

时间异常可先预测正常工况下值，再检测预测残差/区间越界；负载高时CPU90%可能正常，凌晨低负载下90%异常。对持续偏移用滑动窗口计数、累计残差或变化点方法。它们是补充方式，异常与概念漂移要区分：长期新正常不应永远报故障，但也不能因为系统攻击持续了一周就自动更新为正常。

上线必须先冻结模型和阈值，用历史缓存生成相同特征；记录告警原因、分数、阈值版本、时间和处理结果。监控分数分布、原特征缺失、告警量、确认率、延迟和群体差异；正常基线变化先核查采集/业务变化，再比较重校准或重训方案，不为压低告警量而自动放宽阈值。

## 14. 异常练习与参考判断

1. 将Z阈值从1到5变化，为什么没有统一sweet spot？**答案：**异常率、业务成本、审查容量、分布与标签覆盖决定折中；在校准集绘制P/R/告警量，不在测试集挑最佳点。
2. 构造联合异常怎样核对单列方法不足？**答案：**正常y≈x，异常偏离对角但单列仍落正常范围；比较正常/异常分数分布与PR。不要只挑某一容易检出的远点证明普遍有效。
3. LOF k=10与50哪种更好？**答案：**取决于正常簇规模和密度，k较大可能吞掉小簇，较小对局部噪声敏感；在相同独立评估数据比較，并处理并列距离与novelty边界。
4. Welford评分前先update有何问题？**答案：**新点会拉动均值方差，部分掩盖自己。先评分，再按已确认策略更新；暖启动不足时不能用不可靠σ告警。
5. 知道真实异常25个，就取top25阈值可以部署吗？**答案：**这是使用测试标签给定预算的排序展示，部署时通常不知道异常总数；用实际审查容量或独立校准规则。
6. 重建误差低就证明正常吗？**答案：**不能，异常可能也可重建或落正常流形；检验瓶颈、污染、尺度并与其他基线比较。PCA演示也未替代深度AE的验证。
7. 真实信用卡数据实验怎么验收？**答案：**核验数据许可与时间/实体定义，时间切分，训练/校准/测试分开，报告P@100/P@500、AP、告警负担与漏报估计；当前没有下载运行此公开数据，不编造结果。
