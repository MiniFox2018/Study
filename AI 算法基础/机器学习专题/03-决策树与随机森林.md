# 03｜决策树与随机森林

> 先修：分类/回归任务、样本切分、[信息论](../数学与数值计算专题/12-采样蒙特卡洛与信息论.md)。本章从可手算的划分开始，再给完整分类树、回归树与森林教学实现，最后使用成熟库检查剪枝和重要性。

## 1. 树把输入空间切成规则区域

一个数值节点问“$x_j\le t$ 吗”，左右孩子继续提问，直到叶子给预测。二维轴对齐划分产生矩形区域。例如面积不超过80且房龄超过20的一片区域，可以用该区域训练目标均值预测价格；分类用叶子多数类或类别比例。

树从根向下贪心选择特征和阈值，每步只优化当前节点，不保证整棵树全局最优。浅树可逐条读规则；大森林由大量规则共同作用，不能宣称与三节点小树同样透明。单调改变一个特征且保持训练排序时，数值阈值能相应改变，所以树通常不需要标准化；但数据清洗、类别编码、缺失规则与泄漏检查仍需要。

树常是表格数据的强基线，但“表格任务始终胜过深度学习”不成立，效果随任务、数据量、表示和训练预算变化。图像、文本也可以先转成有效特征后用树或线性模型，不能由原始数据类型机械判定一种模型必不能用。

**实现边界：**某些树算法有原生类别划分，但当前 scikit-learn 通用 `DecisionTree` 不直接接受任意字符串类别列；要在训练折做合适编码。整数编码无序类别会引入人为次序，one-hot 或明确支持原生类别的实现才可能符合含义。当前部分库支持缺失值不代表本章教学代码也支持，本章代码明确拒绝非有限值。

## 2. 不纯度、加权收益和一次手算

节点中类别 $k$ 比例为 $p_k$：

$$
G=1-\sum_kp_k^2,\qquad H=-\sum_{k:p_k>0}p_k\log_2p_k.
$$

Gini可解释为从节点类别分布独立抽两个标签时不相同的概率，不是把所有样本固定预测成多数类时的错误率。8狗2猫：Gini=0.32，而多数类错误率是0.2。6猫4狗：Gini=0.48、熵约0.9710 bit；纯节点两者都为0。$K$类均匀分布的最大值为 $1-1/K$ 和 $\log_2K$，二分类0.5/1不是所有类别数通用上限。

划分把 $N$ 个样本分为 $N_L,N_R$，收益为：

$$
\Delta I=I(parent)-\frac{N_L}NI(left)-\frac{N_R}NI(right).
$$

必须按孩子大小加权。父节点6猫4狗，左4猫，右2猫4狗：左Gini=0，右Gini=$4/9$，孩子加权不纯度为 $0.4\times0+0.6\times4/9=4/15$，收益 $0.48-4/15\approx0.2133$。若另一划分左右都是3猫2狗，收益为0。两种准则常给相近树，但并不数学保证每个阈值排序一致。

连续特征只需考虑相邻**不同**排序值的中点，阈值落在同一空隙产生同样训练分组。枚举全部可行候选，剔除小于最小叶样本数的划分，选最大收益；再递归。纯节点、常数列、无法合法划分、深度/样本预算都是停止条件。

### 2.1 回归把不纯度换成目标方差

平方误差叶子预测均值，因为 $\partial_a\sum_i(y_i-a)^2=0$ 给 $a=\bar y$。节点不纯度可用 $\operatorname{Var}(y)=\sum_i(y_i-\bar y)^2/N$；收益仍是父方差减加权孩子方差。

目标 `(1,1,5,5)` 的父方差为4，分成 `(1,1)` 和 `(5,5)` 后孩子方差为0、收益4。平方损失树给分段常数，不能自然外推斜率，预测一般落在训练目标范围内；绝对损失对应叶子中位数，不能把均值当所有回归树通用定义。

## 3. 完整教学实现：一套递归服务分类、回归和森林

下面只依赖 NumPy，支持数值有限特征、整数分类标签或数值回归标签。候选划分前就检查两侧样本数；`fit` 每次重置模型状态。类的用途是看懂计算，枚举每个阈值重复扫描较慢，真实大数据用成熟库。

```python
import numpy as np

class SmallTree:
    def __init__(self, task="classification", max_depth=3, min_leaf=1,
                 criterion="gini", max_features=None, seed=0, min_gain=0.0):
        if task not in {"classification", "regression"} or criterion not in {"gini", "entropy"}:
            raise ValueError("任务或准则不支持")
        if max_depth < 0 or min_leaf < 1 or min_gain < 0:
            raise ValueError("深度/最小叶样本/收益门槛不合法")
        self.task, self.max_depth, self.min_leaf = task, max_depth, min_leaf
        self.criterion, self.max_features = criterion, max_features
        self.seed, self.min_gain = seed, min_gain

    def impurity(self, y):
        if self.task == "regression":
            return np.var(y)
        counts = np.unique(y, return_counts=True)[1]
        p = counts/counts.sum()
        return 1-p @ p if self.criterion == "gini" else -(p*np.log2(p)).sum()

    def fit(self, X, y):
        X, y = np.asarray(X, float), np.asarray(y)
        if X.ndim != 2 or len(X) == 0 or y.shape != (len(X),):
            raise ValueError("需要非空二维X和等长一维y")
        if not np.isfinite(X).all() or not np.isfinite(y).all():
            raise ValueError("教学实现不支持NaN或无穷值")
        if self.task == "classification" and not np.all(y == y.astype(int)):
            raise ValueError("分类标签应为整数")
        self.d, self.n = X.shape[1], len(y)
        self.rng = np.random.default_rng(self.seed)
        self.importance = np.zeros(self.d)
        if self.max_features is not None and not 1 <= self.max_features <= self.d:
            raise ValueError("候选特征数应在1到特征总数之间")
        self.root = self.build(X, y, 0)
        if self.importance.sum() > 0:
            self.importance /= self.importance.sum()
        return self

    def build(self, X, y, depth):
        values, counts = np.unique(y, return_counts=True)
        value = y.mean() if self.task == "regression" else values[counts.argmax()]
        leaf = {"value": value, "samples": len(y)}
        if depth >= self.max_depth or len(y) < 2*self.min_leaf or len(values) == 1:
            return leaf
        features = np.arange(self.d)
        if self.max_features is not None:
            features = self.rng.choice(features, self.max_features, replace=False)
        base, best = self.impurity(y), None
        for j in features:
            unique = np.unique(X[:, j])
            for left_value, right_value in zip(unique[:-1], unique[1:]):
                t = left_value/2+right_value/2
                left = X[:, j] <= t
                nl, nr = left.sum(), (~left).sum()
                if min(nl, nr) < self.min_leaf:
                    continue
                gain = base-(nl*self.impurity(y[left])+nr*self.impurity(y[~left]))/len(y)
                if best is None or gain > best[0]+1e-12:
                    best = gain, int(j), float(t), left
        if best is None or best[0] < self.min_gain-1e-12:
            return leaf
        gain, j, t, left = best
        self.importance[j] += len(y)/self.n*max(gain, 0)
        return {"feature": j, "threshold": t, "samples": len(y),
                "left": self.build(X[left], y[left], depth+1),
                "right": self.build(X[~left], y[~left], depth+1)}

    def predict(self, X):
        X = np.asarray(X, float)
        if X.ndim != 2 or X.shape[1] != self.d or not np.isfinite(X).all():
            raise ValueError("预测特征形状或取值不合法")
        result = []
        for x in X:
            node = self.root
            while "feature" in node:
                node = node["left"] if x[node["feature"]] <= node["threshold"] else node["right"]
            result.append(node["value"])
        return np.array(result)

class SmallForest:
    def __init__(self, trees=15, task="classification", max_depth=3, seed=0):
        if trees < 1:
            raise ValueError("树数量必须为正")
        self.trees, self.task, self.max_depth, self.seed = trees, task, max_depth, seed

    def fit(self, X, y):
        X, y = np.asarray(X, float), np.asarray(y)
        rng = np.random.default_rng(self.seed)
        self.models = []
        for _ in range(self.trees):
            ids = rng.integers(0, len(y), size=len(y))
            count = max(1, int(np.sqrt(X.shape[1])))
            tree = SmallTree(self.task, self.max_depth, max_features=count,
                             seed=int(rng.integers(2**31)))
            self.models.append(tree.fit(X[ids], y[ids]))
        return self

    def predict(self, X):
        values = np.stack([model.predict(X) for model in self.models])
        if self.task == "regression":
            return values.mean(0)
        def vote(row):
            labels, counts = np.unique(row, return_counts=True)
            return labels[counts.argmax()]
        return np.array([vote(row) for row in values.T])

# XOR需要连续两层划分，根节点的单步收益恰为零。
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([0, 1, 1, 0])
tree = SmallTree(max_depth=2).fit(X, y)
print("XOR预测", tree.predict(X).tolist(), "根规则", tree.root["feature"], tree.root["threshold"])
assert np.array_equal(tree.predict(X), y)

rng = np.random.default_rng(42)
X = rng.uniform(-3, 3, (100, 2))
y = np.where(X[:, 0]**2+X[:, 1]**2 < 2, 0, np.where(X[:, 0] > X[:, 1], 1, 2))
tr, va = np.arange(75), np.arange(75, 100)
for depth in [2, 6]:
    tree = SmallTree(max_depth=depth, min_leaf=2).fit(X[tr], y[tr])
    print("分类树深度上限", depth, "训练", round(np.mean(tree.predict(X[tr]) == y[tr]), 4),
          "验证", round(np.mean(tree.predict(X[va]) == y[va]), 4))
forest = SmallForest(trees=15, max_depth=5, seed=4).fit(X[tr], y[tr])
print("森林验证", round(np.mean(forest.predict(X[va]) == y[va]), 4))

x = np.linspace(-3, 3, 60)[:, None]
target = np.sin(x[:, 0])+rng.normal(0, 0.1, 60)
reg = SmallTree(task="regression", max_depth=4, min_leaf=3).fit(x[::2], target[::2])
rf = SmallForest(trees=15, task="regression", max_depth=4).fit(x[::2], target[::2])
for name, model in [("回归树", reg), ("回归森林", rf)]:
    print(name, "验证MSE", round(np.mean((model.predict(x[1::2])-target[1::2])**2), 4))
```

这里允许零收益划分，并用深度/最小叶样本约束控制复杂度。若源代码在 `gain <= 0` 一律停止，XOR 根分裂收益为0，会失去下一层能完全分类的机会。这说明强预剪枝可能误删有价值的下游分裂；不是鼓励生产无限生长。常数特征或没有合法分裂仍必须停，防止无限递归。

树结构可手追：从根读特征和阈值，按样本进入的左右区域继续，记录叶子预测和样本数。二维画边界时，对每个网格点调用 `predict` 并按类别着色；比较浅树和深树的矩形区域大小，不由图上复杂程度单独宣判过拟合。

## 4. 深度、叶样本数与剪枝

深度从根0计算，二叉树深度不超过 $d$ 时最多 $2^d$ 叶子、$2^d-1$ 内部节点，实际不一定满。来源图展示的是满树上界，深度多1最多把叶子数翻倍，**不是把区域数平方**。

- `max_depth` 控制最长规则链；`min_samples_split` 控制允许尝试分裂的父节点样本数。
- `min_samples_leaf` 检查两个孩子各自最小数量；不能用父节点“少于k就停”代替。
- `min_impurity_decrease` 对小收益加门槛，须注意实现里的节点权重约定。
- `max_leaf_nodes` 控制整体叶子预算。

以上是预剪枝。后剪枝先生长，再比较复杂度惩罚：$R_\alpha(T)=R(T)+\alpha|leaves(T)|$；增大 $\alpha$ 更偏向小树。scikit-learn 的 `ccp_alpha` 使用成本复杂度剪枝；需要在训练/验证阶段选择，而不是在测试上挑最好值。

诊断不能用“深度超过6”“训练测试差超过10%”“深度超过$\sqrt N$”当理论判据。应读实际叶样本、重复标签、误判类别及多个划分的泛化误差：训练高而验证差支持过拟合；两者都差可能是特征、标签、任务、切分或复杂度问题，不能只加深树。

## 5. 随机森林：抽样与随机候选特征怎样降低相关性

每棵树从 $N$ 个训练样本中有放回抽 $N$ 次，一个原样本不被抽到的概率为 $(1-1/N)^N\to e^{-1}\approx0.368$。因此约63.2%是**不同的原样本**被见到，抽样数组总长度仍为 $N$，其中有重复。

每个分裂节点再随机挑候选特征，而不是整棵树只挑一次。强势列若每次都可用，会让树十分相似；随机候选让其他有用列有机会。对等方差 $\sigma^2$、两两相关约 $\rho$ 的 $M$ 个回归预测，平均方差是：

$$
\operatorname{Var}(\bar f)=\sigma^2\left[\rho+\frac{1-\rho}{M}\right].
$$

这是解释“降低相关性”和“继续加树收益递减”的近似模型。树完全相同则平均无效；减少候选特征也可能增加单树偏差，不能保证“只降方差而永不增偏差”。树数更多不会自动使测试准确率单调上升，有限测试集的分数可能上下波动。

教学分类森林用多数票。scikit-learn 分类森林主要平均各树的类别概率，再选最大类，和纯多数票不总一致。回归平均数值。树数、深度、叶样本、候选特征与预算都要联动验证，不能把随机森林理解为永远不过拟合。

核验日期2026-10-03：当前 scikit-learn 分类森林默认 `max_features="sqrt"`，回归森林默认 `1.0`（所有特征候选），**不是通用默认 $d/3$**。本章教学森林为说明随机性，分类/回归都显式选择 $\lfloor\sqrt d\rfloor$，不假装复制库默认。

### 5.1 OOB 与稳定性实验

对每条训练记录，仅用没抽到它的树预测，得到 out-of-bag 估计。OOB节省独立验证数据，但每条看到的树数不同，少树时可能没有OOB预测；时间/用户分组任务不能靠普通bootstrap解决依赖和未来泄漏。使用OOB反复选模型后，仍需要独立最终验收。

稳定性实验应先固定**原始训练/测试身份**，再只对训练抽样扰动，比较同一测试上的单树和森林。源代码先bootstrap全数据再切分，会让同一原样本的重复副本落在两边，造成乐观评估；不保留这一比较结论。记录多个扰动的均值、标准差和误判重合度，才有依据讨论稳定性。

## 6. 特征重要性：模型依赖，不是因果解释

MDI 累加特征 $j$ 每次分裂贡献：$\sum_{node:j}(N_{node}/N)\Delta I_{node}$，再归一化，森林再聚合。根节点样本多，贡献可能大，但“出现早”不自动说明该变量是最大贡献；高基数/很多候选阈值的噪声列也更容易偶然降低训练不纯度。

Permutation importance 在**留出数据**算基准评分，再打乱一列观察评分减少，重复多次估计波动。负值意味着打乱后评分反而提高，可能是噪声、过拟合或样本波动；不是“负因果作用”。两个高度相关的列可相互替代，单列打乱可能显示低重要性，即使该信息总体有用。联合打乱相关列、重新训练去除列等问题又不同，必须说明测的对象。

## 7. 成熟库例子：剪枝、森林树数、MDI与置换

先划分原始记录。所有配置只查看验证，最后按验证选择后在整个开发集重训并测试一次。数据生成、标签和高基数噪声列均为合成，不能把重要性当真实业务解释。

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance

X, y = make_classification(n_samples=240, n_features=4, n_informative=2,
                           n_redundant=0, shuffle=False, random_state=42)
rng = np.random.default_rng(42)
X = np.column_stack([X, rng.uniform(size=len(X))])
Xdev, Xtest, ydev, ytest = train_test_split(X, y, test_size=0.2, stratify=y, random_state=1)
Xtr, Xval, ytr, yval = train_test_split(Xdev, ydev, test_size=0.25, stratify=ydev, random_state=2)
for alpha in [0.0, 0.01, 0.05]:
    tree = DecisionTreeClassifier(ccp_alpha=alpha, min_samples_leaf=2, random_state=3)
    tree.fit(Xtr, ytr)
    print("alpha", alpha, "深度", tree.get_depth(), "叶子", tree.get_n_leaves(),
          "训练", round(tree.score(Xtr, ytr), 4), "验证", round(tree.score(Xval, yval), 4))
shallow = DecisionTreeClassifier(max_depth=2, random_state=3).fit(Xtr, ytr)
print(export_text(shallow, feature_names=["信号0", "信号1", "噪声2", "噪声3", "高基数噪声"]))
choices = []
models = {}
for count in [1, 5, 10, 50, 200]:
    forest = RandomForestClassifier(n_estimators=count, min_samples_leaf=2,
                                    max_features="sqrt", random_state=4, n_jobs=1)
    forest.fit(Xtr, ytr)
    score = forest.score(Xval, yval)
    models[count] = forest
    choices.append((score, -count))
    print("树数", count, "训练", round(forest.score(Xtr, ytr), 4), "验证", round(score, 4))
_, negative_count = max(choices)
chosen = -negative_count
model = models[chosen]
perm = permutation_importance(model, Xval, yval, n_repeats=8, random_state=5, n_jobs=1)
print("MDI", model.feature_importances_.round(4))
print("留出置换均值", perm.importances_mean.round(4))
model.fit(Xdev, ydev)
print("验证选中树数", chosen, "最终测试准确率", round(model.score(Xtest, ytest), 4))
```

不是每次实验MDI都把噪声排到第一、置换都排到最后。评估偏好应跨多次生成重复，报告分布。Gini/entropy比较同样需固定数据、切分、深度和随机流，比较准确率、叶子与规则差别，不能预写“总几乎完全一样”。

本次教学实现实测，深度2/6分类树的训练准确率约0.7467/0.9733、验证约0.76/0.80，森林验证约0.84；加深在这份数据上没有使验证成绩下降，正说明不能预写“深树必然更差”。库示例的50/200棵森林验证均约0.9792，按并列时优先少树选50棵，最终测试约0.9583。信号列1的MDI约0.8052、留出置换均值约0.4427；噪声列MDI有非零值，而本次置换均值为零。

## 8. 自查与练习参考答案

1. 8狗2猫Gini是多少、为何不是0.2？**答案：**$1-0.8^2-0.2^2=0.32$；0.2是多数类训练错误率，两种定义不同。
2. 表格树免所有预处理吗？**答案：**通常免尺度标准化，但编码、缺失、字段单位和训练测试泄漏仍须检查，取决于具体实现。
3. 为什么父孩子不纯度差须加权？**答案：**一个只有一条记录的纯叶不能与大叶等权，否则奖励不合理的小碎片；第2节手算收益约0.2133。
4. 二维三类，深度2与10如何比较？**判断标准：**手追至少3条规则、画矩形区域、记录训练/留出指标和叶样本。边界变细不等于一定泛化差。
5. 怎样写回归树并拟合 $\sin x+noise$？**答案：**第3节将不纯度换方差、叶子换均值，完整代码已含回归；画网格输出可观察分段常数与森林平均。
6. 为什么随机样本和随机特征都要有？**答案：**扰动不同信息源减少树间误差相关；收益还取决于单树质量，不能认为加随机必更好。
7. 1、5、10、50、200棵树，测试是否只升不降？**答案：**没有保证；第7节先比较验证并选模型，留出测试只最终一次，树数收益常逐渐饱和。
8. Gini和entropy哪种最好？**答案：**两者是不同的不纯度，可对多份数据固定参数比较；共同偏好纯节点不说明所有分裂排序一致。
9. 如何比较MDI与置换？**答案：**第7节给完整实现；注意高基数训练偏好、相关列替代、留出指标和重复波动；不把重要性当因果。
10. 为什么零收益预剪枝可能错？**答案：**XOR的第一层单步没有收益，第二层完全分开；第3节用限制深度的零收益分裂演示，不强求每步必须立即增益。
