# 14｜模型监控、数据漂移与告警判断

先修：[评价与切分](07-评估指标验证与不平衡学习.md)、[统计检验](../数学与数值计算专题/11-统计估计检验与实验判断.md)。先问观测对象、分母和时间，再算漂移统计，最后决定是否需要调查、标注、降级或重训。服务返回HTTP200只证明一类运输结果。

## 1. 监控四层及延迟标签

| 层 | 例子 | 可得时刻与限制 |
|---|---|---|
| 系统 | 错误、吞吐、尾延迟、内存 | 通常立即；不证明预测正确 |
| 输入 | 字段/单位、缺失、类别、分布 | 通常立即；变化可能只是管道缺陷 |
| 预测 | 分数/正例率/默认输出率 | 无需真标签；稳定也不证明正确 |
| 结果 | 正确率、校准、业务损失 | 等目标窗口与标签成熟，仍查标注偏差 |

每条预测保request/实体、决策时刻、模型与特征版本、原分数、实际动作，标签另保对应对象、结果窗口与到达时刻。当前已标部分可能偏向容易或较快返回的事件，应按成熟cohort、标签覆盖和缺失原因报告，不把它直接当全部当前流量。教学“延迟500事件”是固定索引模型，真实系统的延迟可因人群/结果而不同。

## 2. 三种漂移是带假设的分解

$$
P_t(x,y)=P_t(x)P_t(y\mid x)=P_t(y)P_t(x\mid y).
$$

Covariate shift通常指P(x)变而P(y|x)保持；label/prior shift指P(y)变、P(x|y)保持；概念漂移指P(y|x)变。这些假设不是三个天然互斥按钮：先验变化可通过Bayes改变后验，输入变化也可能同时伴随概念变化。仅凭无标签边缘分布不能一般地识别全部条件变化。

例：同样的消费特征现在对应不同结果，而输入分布没变，PSI/KS可保持安静；当前预测分布也可不变。相反流量转到已学得好的区域，输入漂移不一定造成损失。标签后准确率下降是需调查的信号，仍先排标签口径/延迟、特征错误、评分逻辑和受众变化，不从一个统计量直接断言原因。

## 3. 参考窗口与当前窗口

参考数据记录来源/版本、选择人群、季节和时期；当前窗口明确按事件数还是时间、边界及步长。滑动窗口会重叠，滚动互不重叠窗口则以完整窗长移动。小窗反应快但噪声大，大窗稳定但迟；周末和工作日应在可比较的季节条件下看。

先用稳定时期的重复窗口估计噪声和误报，再冻结规则；发生异常后不能立刻把异常作为新正常。重训以后是否切参考窗也要经审阅和版本迁移，保旧窗对照，不仅因新模型存在就删除原基线。

## 4. PSI：分箱比例的变化

在参考集上确定边界，并固定到当前集，包括边界归属、重复分位点、缺失/未知与两端溢出箱。设参考和当前同箱比例为p_i、q_i，均为正且各自归一化：

$$
PSI=\sum_i(q_i-p_i)\log(q_i/p_i)
    =D_{KL}(q\Vert p)+D_{KL}(p\Vert q).
$$

两箱p=(0.5,0.5)、q=(0.75,0.25)，得到0.25ln3≈0.274653。一个箱从0.1变0.3贡献0.2ln3≈0.219722；只是该箱贡献，完整PSI还须加其余箱。正向/反向相加使此定义对称，但这不是一个给定显著性水平的检验。

零箱需要声明政策，例如在计数上加伪计数后重新归一化；直接将比例逐项max(eps)会改变总质量，不能不加说明地等同于原概率分布的KL。来源采用这种截断分数。0.1/0.25只是常见经验带，不是普适阈值；分箱、样本量和参考分布都影响数值，样本扩大不保证每次PSI单调下降。

## 5. KS和类别统计各回答什么

两样本KS距离是经验CDF的最大绝对差：

$$
D=\sup_x|F_n(x)-G_m(x)|.
$$

在每个不同观测值处，把该值的所有重复项都计进右连续CDF，再比较。A=(1,3)、B=(2,4)虽然无相同元素，D只有0.5；只有两组的取值范围完全分离等条件下才会达到1。D是效应大小，p还依样本量、假设和算法；小p不等业务影响大。

例如D=0.004在整体CDF上很小，但稀有高损失切片仍可能重要；不能只见“小D”就自动忽略。是否只记录warning，取决于事先声明的效应门、损失与响应政策。

标准连续、独立样本的KS检验与含大量离散重复、时序相关样本不同；应按数据条件选择检验/重采样方案。来源的Kolmogorov极限级数不是所有有限样本的精确p值。[SciPy KS说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ks_2samp.html)区分exact/asymp、自动选择和数值限制（2026-10-16选读Notes与参数）。

类别特征可建“参考/当前×类别”列联表，计算E_rc=行和×列和/总量及χ²=Σ(O−E)²/E；两行k列、非退化时自由度k−1，Cramér V=√(χ²/总量)。例如[8,2]与[2,8]，每格期望5，未作连续性校正的χ²=7.2，V=0.6。只给统计量不保证近似p有效；稀有类别、空行、未知/缺失政策要单独处理。SciPy在自由度1时默认可做Yates修正，也提供重采样入口，不能让不同合同的数字逐位相等成为唯一判断。[官方列联表文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.contingency.chi2_contingency.html)

## 6. 完整小例：求统计量，不伪造推断

下面的自有标准库例只计算KS距离和正比例PSI，不生成p值或运行监控服务。输入最多10000项、有限数值绝对值不超过1e308，是示例明确的范围。零比例需调用方先选择平滑合同；用log差避免先求巨大比值溢出。

```python
from bisect import bisect_right
from math import fsum, isclose, isfinite, log


def finite_sample(values):
    result = tuple(values)
    if not result or len(result) > 10_000:
        raise ValueError("需要1至10000个观测")
    if any(type(x) not in (int, float) or abs(x) > 1e308 or not isfinite(x) for x in result):
        raise ValueError("观测须为有限实数，bool不算")
    return result


def ks_distance(first, second):
    a, b = sorted(finite_sample(first)), sorted(finite_sample(second))
    return max(abs(bisect_right(a, x) / len(a) - bisect_right(b, x) / len(b))
               for x in set(a) | set(b))


def psi_positive_shares(reference, current):
    p, q = finite_sample(reference), finite_sample(current)
    if len(p) != len(q) or any(not 0 < x <= 1 for x in p + q):
        raise ValueError("同一分箱的等长正比例；零箱需先按声明政策平滑")
    if not all(isclose(fsum(x), 1.0, rel_tol=0.0, abs_tol=1e-12) for x in (p, q)):
        raise ValueError("比例各自和为1")
    return fsum((b - a) * (log(b) - log(a)) for a, b in zip(p, q, strict=True))


assert ks_distance([1, 2], [1, 2]) == 0
assert ks_distance([1, 2], [3, 4]) == 1
assert ks_distance([1, 3], [2, 4]) == 0.5
assert isclose(ks_distance([1, 1, 2, 2, 3, 3, 3], [1, 2, 2, 2, 4]), 8 / 35)
p, q = [0.5, 0.5], [0.75, 0.25]
value = psi_positive_shares(p, q)
assert isclose(value, 0.25 * log(3), abs_tol=1e-12)
assert isclose(value, psi_positive_shares(q, p), abs_tol=1e-12)
assert psi_positive_shares(p, p) == 0
assert isfinite(psi_positive_shares([5e-324, 1.0], [0.5, 0.5]))
for bad in [[], [True], [float("nan")], [float("inf")], [1 << 20000]]:
    try:
        ks_distance(bad, [1])
    except ValueError:
        pass
    else:
        raise AssertionError("空/伪数字/非有限观测不能伪装成无漂移")
try:
    psi_positive_shares([0.5, 0.5], [1.0, 0.0])
except ValueError:
    pass
else:
    raise AssertionError("不能悄悄给零箱指定平滑政策")
print(f"KS同分布/分离/交错/重复值通过；两箱PSI={value:.9f}；坏观测拒绝")
```

该程序在2026-10-16以Python3.12.13实际运行通过。它核公式/重复值/边界与拒绝，不是对真实流量的漂移检验或线上可靠性证明。

## 7. 告警还要考虑效应、多次检验与持续性

每小时50项、每项假阳性概率约0.05，24小时共1200项，期望错误标记约60。这个期望用线性相加，不需要假定各项独立；“至少一次误报”的概率则另有依赖问题。Bonferroni按事先定义的检验族分配α，不自动覆盖全天不断重复的所有窗口。相邻滑动窗重叠，连续两次触发不等两个独立证据，也不能直接把α平方。

窗口/步长/连续次数/检验数须先核精确正整数，α和效应阈值需有限且范围明确；空样本、空类别行或非有限统计保不可评价，不用p=1伪装成稳定。

数值信号通常结合效应大小、统计证据、持续窗口和业务损失；warning进入观察，alert关联负责人、响应动作、解决与复审条件。来源数值规则是“PSI越线，或KS越线且p小”的OR，PSI分支并不受p门控制；accuracy分支也不属于其两项Bonferroni族。未声明这些范围就不能声称整套系统有统一误报保证。

## 8. 从信号到行动

先查schema、单位、缺失、默认值、join和采集故障。输入变而成熟结果稳定，可继续观察；新区域缺训练覆盖，可在获取合格标签后比较新模型；先验变化下的重校准/阈值调整依对应假设；条件关系改变通常需要新标签。概率校准的性能估计是模型化推断，不能凭无标签数据一般地识别概念漂移。工具品牌与默认阈值会变，先保任务合同，不要求先装一套监控平台。

最终发布沿原评价、shadow/canary和回滚流程；参考窗、模型、特征、标签定义和告警政策都版本化。重新训练旧标签或降低阈值让仪表盘“终于报警”，都不能替代查因和独立效果验证。

## 9. 五项实践与六项检查的参考判断

1. 窗口200/2000的对照：固定同一流和干净时期，分别报warning/alert数、检测延迟与标签延迟，不预设每次大窗必少误报。
2. n_tests=1、patience=1、V门为0：逐项比较规则改变，不把一次合成段的告警数当全域假阳性率。
3. 缓慢均值漂移：保步长、方差/相关性、固定分箱与重复流；PSI和KS谁先触发依阈值和数据，不能预写赢家。
4. 同箱JS与PSI：注明divergence还是平方根distance、log底和零箱政策，比较分数尺度而非直接共用0.25。
5. 正例预测率：在固定模型且输入分布相同的概念变化例中可保持安静；不能因此把缺标签当正确。

六个原测验的核心判据：HTTP健康不保证预测质量；条件关系变化是概念变化的候选；PSI单箱0.2ln3；期望60假标记有明确族/窗口；小D的大样本小p须结合影响；成熟标签恶化先排管道/标签问题，再收集近期证据和比较适应方案，不直接宣布自动重训成功。
