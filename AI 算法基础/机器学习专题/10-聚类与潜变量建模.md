## 1. 无标签意味着没有唯一正确分组

聚类从特征和相似性定义中寻找结构，不会自动发现业务真相。同一批客户按消费额、访问频率或商品兴趣分组，答案可以不同。先写明分组的用途、数据单位和距离：客户画像是一人一行，行为阶段分析可能是一次会话一行。身份证号、原始地址编号不应直接进入欧氏距离。

距离还带隐含权重。收入相差 10000 与年龄相差 10，在原始欧氏距离里前者几乎决定结果；标准化之后按“几个标准差”比较。标准化有助于减少单位影响，但也可能放大低方差噪声，不能替代业务权重。对文本词频可考虑归一化后的余弦相似性；对混合数值与类别，须明确编码和距离语义。

## 2. K-Means：交替最小化什么

给定 $n$ 个 $d$ 维点 $x_i$，用 $K$ 个中心 $\mu_k$ 和分配 $c_i$ 最小化簇内平方和：

$$
J=\sum_{i=1}^{n}\|x_i-\mu_{c_i}\|_2^2.
$$

Lloyd 迭代交替做两件事：固定中心，把点分给最近中心；固定分配，把各中心改为该簇的均值。这两步分别最小化各自变量，正常非空簇更新不会增加目标，但只能到局部解。最近中心的分区是 Voronoi 区域，不意味着每个真实簇必须严格球形；它更适合尺度接近、紧凑且可用均值代表的簇。

手算一维 $[0,2,8,10]$，初始中心 $[0,8]$：第一次分配为 $\{0,2\},\{8,10\}$，平方和 $0+4+0+4=8$；更新中心为 $[1,9]$，平方和降为 $1+1+1+1=4$，再分配不变。原图中的“中心迁移与 WCSS 下降”就是这条计算链。

K-Means++ 先随机取一个中心，再按每个点到已有最近中心的**平方距离**抽下一个；全部平方距离为 0 时，数据已没有新的独特位置。多次重启选平方和最小的解仍然必要。空簇可以用离现有中心最远的样本重新初始化；这是一种修复策略，不能把它与正常 Lloyd 单调下降混为一谈。达到迭代上限时，返回的标签须重新按最终中心计算。

下面是完整 NumPy 教学程序；包含初始化、空簇处理与最终标签核对，不依赖 sklearn。

```python
import numpy as np

def kmeans(X, k, seed=7, max_iter=100):
    X = np.asarray(X, dtype=float)
    if X.ndim != 2 or len(X) < k or k < 1 or not np.isfinite(X).all():
        raise ValueError("需要有限的二维数据，且 1 <= k <= 样本数")
    if len(np.unique(X, axis=0)) < k:
        raise ValueError("独特样本数不足以形成 k 个非空簇")
    rng = np.random.default_rng(seed)
    centers = [X[rng.integers(len(X))].copy()]
    while len(centers) < k:
        d2 = ((X[:, None] - np.array(centers)[None]) ** 2).sum(axis=2).min(axis=1)
        centers.append(X[rng.choice(len(X), p=d2 / d2.sum())].copy())
    centers = np.array(centers)
    history = []
    for _ in range(max_iter):
        d2 = ((X[:, None] - centers[None]) ** 2).sum(axis=2)
        labels = d2.argmin(axis=1)
        history.append(float(d2[np.arange(len(X)), labels].sum()))
        new = centers.copy()
        for j in range(k):
            members = X[labels == j]
            new[j] = members.mean(axis=0) if len(members) else X[d2.min(axis=1).argmax()]
        if np.allclose(new, centers, rtol=0, atol=1e-8):
            centers = new
            break
        centers = new
    d2 = ((X[:, None] - centers[None]) ** 2).sum(axis=2)
    labels = d2.argmin(axis=1)
    inertia = float(d2[np.arange(len(X)), labels].sum())
    return labels, centers, inertia, history

X = np.array([[0.], [2.], [8.], [10.]])
labels, centers, inertia, history = kmeans(X, 2)
assert np.allclose(np.sort(centers.ravel()), [1, 9])
assert np.isclose(inertia, 4)
print("中心", centers.ravel(), "平方和", inertia)
```

图像颜色量化是同一算法的另一应用：把 RGB 像素展开为 $N\times3$，以中心色替代原色，再还原图像形状。颜色数量减少，但空间纹理不参与聚类；这不是图像语义分割。大图可以采样学习中心、再分配所有像素，或用 MiniBatchKMeans。学习运行时间时，普通 Lloyd 一轮约 $O(nKd)$，不能漏掉维度和迭代次数。

## 3. 怎样选 K，怎样评价

Inertia 随 K 增加通常下降，极端每个点一簇可为 0，所以“最低平方和”不能选 K。肘部法看新增簇的收益是否变小，可能根本没有清晰肘部。

Silhouette 对点 $i$ 定义本簇其余点平均距离 $a_i$，到每个其他簇的平均距离中最小值 $b_i$：

$$
s_i=\frac{b_i-a_i}{\max(a_i,b_i)}.
$$

它在 $[-1,1]$，大值代表按当前距离紧凑且分离；负值表示更靠近别簇，不能直接判定“真实类别错了”。单点簇通常约定为 0；sklearn 整体要求 $2\le K\le n-1$，单簇和一人一簇都不可用。它偏爱凸且分离的结构，弯曲月牙可能得到不高的分数。计算所有点对距离约需平方级工作量，大样本应采样并记录采样方式。

Calinski–Harabasz 比较簇间与簇内离散，越大越好；Davies–Bouldin 比较簇散度相对中心距离，越小越好。它们同样偏向中心可代表的簇，不是跨任意算法的绝对排名。有独立标签时用 ARI 等比较成对分组；标签编号可以互换，直接比较 label=0/1 没有意义。ARI 调整随机一致性，可为负。

最终还要查看各簇人数、代表样本、边界样本、对随机种子和重采样的稳定性。高分但“每组都没法解释”不能完成业务验收。稳定性可以对相同样本重复聚类计算 ARI，或对重采样后的共同样本比较分组，不凭二维图决定高维结构。

## 4. DBSCAN：从密度连接得到簇

给半径 $\epsilon$ 与 `min_samples`，在 sklearn 定义中邻域计数包含点自己。邻域足够多的是核心点；自身不够密但位于核心点邻域的是边界点；不能被密集区域吸收的是噪声。核心点之间的邻域连接可以沿月牙传播；边界点可被吸收，但不能像核心点那样继续把簇连出去。邻近多个簇的边界点归属可能随遍历顺序变化。

这是一种完整的简单实现；全量距离矩阵只适合小数据，内存 $O(n^2)$。

```python
import numpy as np
from collections import deque

def dbscan(X, eps, min_samples):
    X = np.asarray(X, dtype=float)
    if X.ndim != 2 or not np.isfinite(X).all() or eps <= 0 or min_samples < 1:
        raise ValueError("输入或密度参数无效")
    d = np.linalg.norm(X[:, None] - X[None], axis=2)
    neighbors = [np.flatnonzero(row <= eps) for row in d]
    core = np.array([len(nb) >= min_samples for nb in neighbors])
    labels = np.full(len(X), -1, dtype=int)
    visited = np.zeros(len(X), dtype=bool)
    cid = 0
    for i in range(len(X)):
        if visited[i] or not core[i]:
            continue
        queue = deque([i])
        labels[i] = cid
        while queue:
            q = queue.popleft()
            if visited[q]:
                continue
            visited[q] = True
            if core[q]:
                for nb in neighbors[q]:
                    if labels[nb] == -1:
                        labels[nb] = cid
                    if not visited[nb] and core[nb]:
                        queue.append(nb)
        cid += 1
    return labels

X = np.array([[0.], [.1], [.2], [3.], [3.1], [3.2], [9.]])
labels = dbscan(X, eps=.21, min_samples=3)
assert labels[-1] == -1 and len(set(labels) - {-1}) == 2
print("密度分组", labels)
```

调参时可画到第 k 近邻的距离排序图，用转折处提出 eps 候选，再验证噪声率和簇稳定性。若近邻查询包含自身，须同步 k 的计数定义。eps 太小几乎全是噪声，太大形成一簇；不同密度可能没有一个好 eps，可考虑 OPTICS/HDBSCAN，不能宣称 DBSCAN 对任意形状都必成功。

噪声 label=-1 表示当前密度模型没接纳，不等于业务故障。评价 DBSCAN 时明确是排除噪声后计算 silhouette，还是把所有噪声当一组；后者常没有合理几何语义。必须一起报告覆盖率，否则“删除九成点后高 silhouette”有误导性。

## 5. 层次聚类：合并依据比树形图更重要

凝聚聚类从每点一簇开始，反复合并最近两簇。Single 用跨簇最小距离，容易链式连接；complete 用最大距离，更偏紧凑；average 用跨簇点对距离平均；Ward 选择簇内平方和增量最小的合并。在欧氏空间中：

$$
\Delta J(A,B)=\frac{n_A n_B}{n_A+n_B}\|\mu_A-\mu_B\|^2.
$$

合并 $\{0,2\}$ 与 $\{8,10\}$ 时，$n_A=n_B=2$，均值 1 和 9，增量为 $1\times64=64$；合并后平方和 $4+64=68$，等于四点到均值5的平方和。Ward 应配欧氏距离，不能随意换成余弦。

Dendrogram 的纵轴是实现规定的合并距离；SciPy 的 Ward 高度与上式增量有关，但不能把高度直接标成 $\Delta J$。画树前应弄清尺度。按簇数或距离切树得到不同粒度，没有唯一正确切割线。合并一旦发生不可撤销；小噪声“桥”会影响上层结构。常规距离矩阵内存平方增长，运行复杂度取决于 linkage 与实现，不把朴素三重循环复杂度当所有库的统一结论。

## 6. GMM：软分配与 EM 的完整链

混合模型引入未观测的分量 $z_i$：

$$
p(x_i)=\sum_{k=1}^K\pi_k\mathcal N(x_i\mid\mu_k,\Sigma_k),\quad
\pi_k\ge0,\quad\sum_k\pi_k=1.
$$

E 步责任度是当前参数下的后验：

$$
r_{ik}=\frac{\pi_k\mathcal N(x_i\mid\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal N(x_i\mid\mu_j,\Sigma_j)}.
$$

M 步用软人数 $N_k=\sum_i r_{ik}$ 更新：

$$
\pi_k=N_k/n,\qquad\mu_k=\frac{\sum_i r_{ik}x_i}{N_k},\qquad
\Sigma_k=\frac{\sum_i r_{ik}(x_i-\mu_k)(x_i-\mu_k)^T}{N_k}.
$$

两分量均值0和2、方差1、等权，在 $x=0$ 处责任度约 $(0.8808,0.1192)$，在1处各0.5。每个点对两个均值都有贡献，不像 K-Means 只贡献给一个。Exact EM 的辅助目标与单调性见[概率模型与潜变量](../06-概率模型与潜变量方法.md)，单调不等于全局最优。

`full` 协方差可旋转椭圆；`diag` 各轴不同方差但不旋转；`spherical` 一个方差；`tied` 所有分量共享一矩阵。上游手写代码每分量只用一个标量方差，属于 spherical，不能声称已实现一般椭圆 GMM。高维 full 每分量有 $d(d+1)/2$ 个协方差参数，样本不足容易不稳。

下面完整实现**对角协方差 GMM**，用对数概率与 log-sum-exp 防下溢，并在最后重新计算责任度。协方差下界是数值保护；任意正则化/分量重启不能直接继承无约束 exact EM 的单调保证。

```python
import numpy as np
from scipy.special import logsumexp

def gmm_diag(X, k, seed=7, max_iter=200, tol=1e-7):
    X = np.asarray(X, dtype=float)
    n, d = X.shape
    if not np.isfinite(X).all() or not 1 <= k <= n:
        raise ValueError("输入无效")
    rng = np.random.default_rng(seed)
    means = X[rng.choice(n, k, replace=False)].copy()
    var = np.tile(np.maximum(X.var(axis=0), 1e-6), (k, 1))
    weights = np.full(k, 1 / k)
    history = []

    def expectation():
        log_joint = np.log(weights)[None] - .5 * (
            d * np.log(2 * np.pi) + np.log(var).sum(axis=1)[None]
            + (((X[:, None] - means[None]) ** 2) / var[None]).sum(axis=2))
        log_density = logsumexp(log_joint, axis=1)
        resp = np.exp(log_joint - log_density[:, None])
        return resp, log_density

    for _ in range(max_iter):
        resp, log_density = expectation()
        ll = float(log_density.sum())
        history.append(ll)
        if len(history) > 1 and abs(history[-1] - history[-2]) <= tol * (1 + abs(ll)):
            break
        nk = resp.sum(axis=0)
        if np.any(nk < 1e-8):
            raise ValueError("分量几乎为空，请换初始化或减小 k")
        means = (resp.T @ X) / nk[:, None]
        var = (resp[:, :, None] * (X[:, None] - means[None]) ** 2).sum(axis=0) / nk[:, None]
        var = np.maximum(var, 1e-6)
        weights = nk / n
    resp, log_density = expectation()
    return means, var, weights, resp, log_density, history

rng = np.random.default_rng(11)
X = np.r_[rng.normal(-3, .4, (100, 1)), rng.normal(3, .8, (100, 1))]
means, var, weights, resp, log_density, history = gmm_diag(X, 2)
assert np.allclose(resp.sum(axis=1), 1)
assert np.all(var > 0) and np.isclose(weights.sum(), 1)
assert np.all(np.diff(history) > -1e-6)
print("均值", np.sort(means.ravel()).round(2), "权重", weights.round(2))
```

上游高斯实现截断指数以避免下溢，会改变极低密度尾部；这里在log空间计算，再按最终参数重算责任度，不沿用该近似。

GMM 密度很低可以提示异常，最大责任度很低主要表示分量归属不确定。远离所有中心的点仍可能有一个责任度接近1，所以异常要看边缘 log density，而不是 `predict_proba().max()`。协方差收缩包住单点会让无约束似然无界；实际设 `reg_covar`，检查收敛、多个起点和退化分量。

选分量数可用 $AIC=2m-2\ell$、$BIC=m\log n-2\ell$，其中 $m$ 是自由参数数、$\ell$ 是拟合 log likelihood；较小更好，但只比较同一数据与特征表示、同类统计假设。跨不同缩放后的数值密度直接比较不合理。分量数也未必等于业务“类别数”。

## 7. 一个完整的库实现比较

```python
import numpy as np
from sklearn.datasets import make_moons
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.mixture import GaussianMixture
from sklearn.metrics import adjusted_rand_score, silhouette_score
from sklearn.preprocessing import StandardScaler
from scipy.cluster.hierarchy import linkage

X, truth = make_moons(n_samples=300, noise=.04, random_state=7)
X = StandardScaler().fit_transform(X)
models = {
    "K-Means": KMeans(n_clusters=2, n_init=10, random_state=7),
    "DBSCAN": DBSCAN(eps=.25, min_samples=5),
    "层次-single": AgglomerativeClustering(n_clusters=2, linkage="single"),
    "GMM-full": GaussianMixture(n_components=2, covariance_type="full", n_init=5, random_state=7),
}
for name, model in models.items():
    labels = model.fit_predict(X)
    covered = labels != -1
    k = len(np.unique(labels[covered]))
    sil = silhouette_score(X[covered], labels[covered]) if 2 <= k < covered.sum() else np.nan
    print(name, "ARI", round(adjusted_rand_score(truth, labels), 3),
          "覆盖率", round(covered.mean(), 3), "silhouette", round(float(sil), 3))
tree = linkage(X[:20], method="ward")
assert tree.shape == (19, 4)
print("合并表最后一行", tree[-1].round(3))
```

本次固定合成月牙实测：K-Means/GMM的ARI约0.470、silhouette约0.495；DBSCAN与single层次的ARI=1.000、silhouette却约0.384。内部几何分数更高不代表外部真实分组更正确。这些结果仅属于代码所生成数据和参数。

SciPy 合并表每行是两个被合并的簇编号、合并距离、合并后样本数；初始点编号0～n-1，新簇编号 n、n+1……。可用 `dendrogram(tree)` 画图，但解释合并逻辑不依赖图片下载。这里真值仅用于合成实验外部核对，不参与聚类。sklearn 这些常规实现不能统称“自带 GPU 加速”。

## 8. 选型、练习与参考答案

| 需求 | 起点 | 要验证的边界 |
|---|---|---|
| 均值能代表簇、数据较大 | K-Means / MiniBatchKMeans | K、尺度、离群点、初始化 |
| 密度连接且允许拒绝噪声 | DBSCAN | 密度差异、高维距离、覆盖率 |
| 要多层结构与合并解释 | 层次聚类 | linkage、合并不可撤销、距离矩阵内存 |
| 重叠分量与概率解释 | GMM | 高斯假设、协方差退化、分量数 |
| 非凸图连通结构 | 谱聚类，见[图论专题](../数学与数值计算专题/13-图论与随机过程.md) | 相似性图、谱分解成本 |

1. 把手算例子初始中心改成 $[0,2]$，一步之后怎样？**答案：**点0分给0，点2/8/10分给2；中心变0和 $20/3$，之后继续更新可能到1和9。记录每步 J，而非凭中心位置猜。
2. 怎样公平比较 K-Means++ 与随机初始化？**答案：**同数据、同重启数、同停止条件和多个随机种子，记录目标分布、迭代与耗时；单次好结果不证明普遍更快。
3. 怎样实现 Ward 合并与切树？**答案：**维护各簇人数、均值，按 $\Delta J$ 选最小对，合并并记录编号和成员；剩 K 簇时输出标签。可用 SciPy 合并表核对最终切分，不能混淆其高度与 SSE 增量。
4. 为什么 DBSCAN 的非噪声点 silhouette 很高仍可能没用？**答案：**可能仅覆盖少数样本，或距离和业务用途不一致；需报告覆盖率与簇解释。
5. 两个 GMM 分量在某点责任度0.99/0.01，能判断该点正常吗？**答案：**不能，须看整体密度、训练基线与阈值。
6. DBSCAN 噪声与 GMM 低密度取交集有何代价？**答案：**常减少告警也可能漏掉单方法能捕获的异常；统计交集/并集、Precision@k 和人工确认，不能认为“二者一致必是真异常”。
