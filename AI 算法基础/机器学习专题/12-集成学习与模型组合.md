# 12｜集成学习与模型组合

> 先修：[经典监督学习](../04-经典监督学习.md)、训练/验证切分与损失。树的分裂计算留在监督学习章节，这里学习如何组合模型。先做 bagging 的方差手算，再做 AdaBoost 权重更新，最后做梯度提升和无泄漏 stacking。

## 1. 多个模型为什么可能更好，也可能没有收益

在一个预测点，假设 $M$ 个模型误差方差同为 $\sigma^2$、两两相关同为 $\rho$，平均误差方差为：

$$
\operatorname{Var}(\bar e)=\sigma^2\left[\rho+\frac{1-\rho}{M}\right].
$$

独立时降到 $\sigma^2/M$；完全相关时仍为 $\sigma^2$；模型再多也不消除共享偏差。这是原图“多条抖动曲线平均更平滑”的条件：误差并非完全同向。不能把平滑蓝线当作保证优于每个成员。

对奇数 $M$ 个**独立且同准确率** $p>0.5$ 的二分类器，多数正确概率是二项分布尾和 $\sum_{k>M/2}{M\choose k}p^k(1-p)^{M-k}$。$M=3,p=0.6$ 得 $3\times0.6^2\times0.4+0.6^3=0.648$。真实模型训练自同一数据，错误常高度相关，不能直接套这个提升。多数类准确率高也不代表稀有正类能被识别，评价要匹配任务。

## 2. Bagging 与随机森林

Bootstrap 是从 n 条训练样本有放回抽 n 次。同一条完全没被抽到概率 $(1-1/n)^n\to e^{-1}\approx36.8\%$，所以每棵树看到约63.2%的独特样本。各模型可独立并行训练，回归平均预测，分类投票或平均概率。

随机森林在 bootstrap 之外，通常**每个节点**仅尝试随机子集的特征，减少树相关性；给整棵树固定一组列是另一种随机子空间方案。`max_features` 越小可能减少相关也增加偏差，必须调参。分类 `sqrt`、回归 `1.0` 是当前 sklearn 的常见默认；教材中的回归 d/3 是另一经验设置，不能写成所有版本默认。

OOB 对一条训练样本，只用没有抽到它的树预测。它能提供方便的内部评估，但树太少时该点没有足够 OOB 预测；反复按 OOB 调参也在选择模型。同人多记录或时间预测，普通 bootstrap 不自动满足部署独立性，OOB 不能替代分组/未来测试。

增加树数主要减小 Monte Carlo 波动并逐渐饱和；一般不像不断增加深度那样持续增加单树复杂度，但有限数据测试分数可以升降，不能宣称“随机森林永不可能过拟合”。深度、叶子样本数、噪声标签、泄漏特征仍会导致问题。平均也不保证消除异常值污染，因为某个极端点会进入许多 bootstrap。

## 3. AdaBoost：权重更新可以手算

经典二分类用 $y_i,h_t(x_i)\in\{-1,+1\}$：

$$
\epsilon_t=\sum_iw_i\mathbb{1}[h_t(x_i)\ne y_i],\qquad
\alpha_t=\frac12\log\frac{1-\epsilon_t}{\epsilon_t},\qquad
w_i\leftarrow\frac{w_i e^{-\alpha_t y_i h_t(x_i)}}{Z_t}.
$$

最终 $H(x)=\operatorname{sign}\sum_t\alpha_t h_t(x)$。若四个点等权、只错一个，$\epsilon=0.25$，$\alpha=0.5\log3\approx0.5493$，归一化后错点权重0.5，其余各1/6。下一棵树须更重视错点。若它是错误标签，反复聚焦会有害。

弱学习器必须支持样本权重。$\epsilon\ge0.5$ 时不能当有效正权弱分类器继续堆；$\epsilon=0$ 可停止或使用有限上界防无穷，总票相等时规定类别。多分类 SAMME 的公式不同，sklearn 当前 `AdaBoostClassifier` 不能用旧 `algorithm` 参数来写教程；省略过时参数。

完整 NumPy 实现搜索单阈值树桩，覆盖重新 fit 清空模型、完美分类和票数为0；用于理解二分类，不包含多分类与生产级优化。

```python
import numpy as np

class AdaBoostBinary:
    def __init__(self, rounds=20):
        self.rounds = rounds
    def fit(self, X, y):
        X, y = np.asarray(X, float), np.asarray(y)
        if not np.isin(y, [-1, 1]).all() or X.ndim != 2 or not len(y):
            raise ValueError('需要非空二维输入和 -1/+1 标签')
        self.models, self.history = [], []
        w = np.full(len(y), 1 / len(y))
        for _ in range(self.rounds):
            best = None
            for j in range(X.shape[1]):
                values = np.unique(X[:, j])
                thresholds = np.r_[-np.inf, (values[1:] + values[:-1]) / 2, np.inf]
                for threshold in thresholds:
                    for polarity in [-1, 1]:
                        pred = polarity * np.where(X[:, j] <= threshold, -1, 1)
                        error = float(w[pred != y].sum())
                        if best is None or error < best[0]:
                            best = (error, j, threshold, polarity, pred)
            error, j, threshold, polarity, pred = best
            if error >= .5 - 1e-12:
                break
            alpha = .5 * np.log((1 - error) / max(error, 1e-12))
            self.models.append((alpha, j, threshold, polarity))
            w *= np.exp(-alpha * y * pred)
            w /= w.sum()
            self.history.append(float(np.mean(self.predict(X) == y)))
            if error <= 1e-12:
                break
        return self
    def predict(self, X):
        X = np.asarray(X, float)
        votes = np.zeros(len(X))
        for alpha, j, threshold, polarity in self.models:
            votes += alpha * polarity * np.where(X[:, j] <= threshold, -1, 1)
        return np.where(votes >= 0, 1, -1)

X = np.array([[-2.], [-1.], [0.], [1.], [2.]])
y = np.array([-1, -1, 1, -1, 1])
model = AdaBoostBinary(rounds=10).fit(X, y)
assert np.isin(model.predict(X), [-1, 1]).all()
assert model.history[-1] >= model.history[0]
print('每轮训练准确率', model.history)
```

上例断言只核对这个固定玩具数据，AdaBoost 每一轮的训练准确率并没有一般单调保证；优化的指数损失与0-1准确率不同。验证误差需要另行记录。

## 4. 梯度提升：拟合负梯度，不总是原始残差

令当前预测函数 $F_{t-1}$，对每点算 $r_i=-\partial L(y_i,F_{t-1}(x_i))/\partial F$，拟合树 $h_t$，再求步长或叶子输出，更新 $F_t=F_{t-1}+\eta\gamma_t h_t$。这是函数空间的迭代优化。

用 $L=\tfrac12(y-F)^2$ 时 $r=y-F$，初值为训练目标均值。平方损失树叶拟合残差均值，所以可取对应更新。分类 log loss 对 logit 求导得到 $y-p$，预测还需 sigmoid/softmax；不能把直接拟合数值残差的回归树程序叫完整 `GradientBoostingClassifier`。

手算 y=$[1,3]$，初预测均为2，残差$[-1,1]$。若树能分别拟合，学习率0.1后预测$[1.9,2.1]$，平方误差和从2到1.62。减小步长能让每一步更保守，但需更多轮；“学习率越小一定更好”不成立。

下面是完整平方损失梯度提升教学程序，树用 sklearn 实现以免重复树章节；在独立验证集上选轮数，最终保留最好前缀。

```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

class SquaredBoost:
    def __init__(self, rounds=120, lr=.1, depth=2, patience=10):
        self.rounds, self.lr, self.depth, self.patience = rounds, lr, depth, patience
    def fit(self, X, y, Xv, yv):
        self.initial = float(np.mean(y))
        self.trees = []
        pred, pv = np.full(len(y), self.initial), np.full(len(yv), self.initial)
        best, best_count, stale = mean_squared_error(yv, pv), 0, 0
        self.losses = []
        for t in range(self.rounds):
            tree = DecisionTreeRegressor(max_depth=self.depth, min_samples_leaf=5, random_state=t)
            tree.fit(X, y - pred)
            self.trees.append(tree)
            pred += self.lr * tree.predict(X)
            pv += self.lr * tree.predict(Xv)
            loss = mean_squared_error(yv, pv)
            self.losses.append(float(loss))
            if loss < best - 1e-8:
                best, best_count, stale = loss, len(self.trees), 0
            else:
                stale += 1
            if stale >= self.patience:
                break
        self.trees = self.trees[:best_count]
        return self
    def predict(self, X):
        pred = np.full(len(X), self.initial)
        for tree in self.trees:
            pred += self.lr * tree.predict(X)
        return pred

rng = np.random.default_rng(7)
X = rng.uniform(-2, 2, (400, 3))
y = 2 * X[:, 0] + np.sin(3 * X[:, 1]) + rng.normal(0, .3, len(X))
Xdev, Xtest, ydev, ytest = train_test_split(X, y, test_size=.2, random_state=7)
Xtr, Xv, ytr, yv = train_test_split(Xdev, ydev, test_size=.25, random_state=7)
model = SquaredBoost().fit(Xtr, ytr, Xv, yv)
test_mse = mean_squared_error(ytest, model.predict(Xtest))
print('保留树数', len(model.trees), '测试 MSE', round(test_mse, 3))
assert np.isfinite(test_mse)
```

本次固定种子平方提升示例保留119棵树、测试MSE约0.212；这只是当前数据的结果，别的数据不应照搬树数。

学习率、树深、叶子样本数、抽样率、损失和早停一起影响效果。训练轮数多可能拟合噪声；早停不是必须唯一方法，固定轮数经过严格调参也可有效。测试集不能用来选停止轮。

## 5. XGBoost 的二阶目标，及实现选择

在当前预测处把损失对新增输出作二阶展开，$g_i=\partial L/\partial F_i$、$h_i=\partial^2L/\partial F_i^2$。固定树结构、暂只用 L2 叶权惩罚与叶数惩罚：

$$
\widetilde{Obj}=\sum_j\left[G_jw_j+\frac12(H_j+\lambda)w_j^2\right]+\gamma T,\quad
G_j=\sum_{i\in I_j}g_i,\ H_j=\sum_{i\in I_j}h_i.
$$

最优叶权 $w_j^*=-G_j/(H_j+\lambda)$；分裂收益为：

$$
Gain=\frac12\left[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{G^2}{H+\lambda}\right]-\gamma.
$$

例如左右 $G_L=-2,H_L=2,G_R=2,H_R=2$，$\lambda=1,\gamma=0$，父 G=0/H=4，收益 $\frac12(4/3+4/3)=4/3$，叶权分别2/3和-2/3。加大 $\lambda$ 缩小权重，加大 $\gamma$ 提高新增叶门槛。L1、约束和特定损失需要对应公式，不能默认所有目标都有正曲率。

工程优化包括直方图/近似候选切分、稀疏/缺失默认方向、行列抽样、并行和缓存布局等；缺失可走学到的默认方向，但不能把0自动当缺失。XGBoost、LightGBM、CatBoost 是不同提升库，LightGBM不是 XGBoost 的“继任版本”，谁快谁准取决于任务、实现、硬件和调参预算。复杂模型也不能外推出未见的增长趋势保证。

选择时先有简单线性/树基线，在同切分与预算下比较随机森林、提升树；高基数类别可比较原生类别方法与适当编码。神经网络在表格上没有“永远失败”的结论，训练样本、预训练、特征结构、延迟和计算成本都会改变选择。不要保存竞赛/生产普及程度的无来源断言作为长期方法。

本批没有安装/运行 XGBoost、LightGBM、CatBoost；上述是原理与官方实现概念核验，未写死高时效接口参数，也没有编造速度差。要复现库比较，先固定版本、任务、数据切分、早停与计时范围，分别记录加载、拟合、预测成本。

## 6. Voting 和 Stacking：训练边界在哪里

Hard voting 对标签投票；soft voting 对同一类别顺序的概率加权平均，再 argmax。soft 充分利用置信信息，但坏校准的极端概率可以拖累组合；不保证总胜 hard。权重如由验证集选择，也属于调参。二分类 $[0.9,0.6,0.1]$ 的正概率平均0.533会判正；标签多数也判正，但其他组合可能不同。

Stacking 用基模型预测作为元模型输入。对训练样本 i，每个基模型必须用**没见 i 的训练折**预测它，形成 OOF 特征；元模型只拟合这些 OOF 预测。部署时基模型可重新拟合全部开发训练数据，再预测新样本送入元模型。若先在全训练数据拟合树、再把训练预测送给元模型，容易学到“完美记忆”而无法泛化。

元模型不自动成为条件路由器。若它只有线性地组合几个预测，只会学全局权重；要按样本情境改变权重，需能表达非线性或显式传入合适特征，并额外控制过拟合。相同模型家族也可能通过不同表示产生多样性，不必机械要求三个家族；代价要覆盖额外训练、部署、监控和解释。

完整代码比较树、随机森林、AdaBoost、提升、voting、OOF stacking，所有性能比较只在开发集内部；测试只查看选中的模型。

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import (RandomForestClassifier, AdaBoostClassifier,
    GradientBoostingClassifier, VotingClassifier, StackingClassifier)
from sklearn.metrics import f1_score

X, y = make_classification(n_samples=450, n_features=8, n_informative=5, random_state=7)
Xtr, Xte, ytr, yte = train_test_split(X, y, stratify=y, test_size=.25, random_state=7)
base = [
    ('线性', make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))),
    ('树', DecisionTreeClassifier(max_depth=4, random_state=7)),
    ('近邻', make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=9))),
]
cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=7)
models = {
    '单树': DecisionTreeClassifier(max_depth=4, random_state=7),
    '随机森林': RandomForestClassifier(n_estimators=80, min_samples_leaf=3, random_state=7, n_jobs=1),
    'AdaBoost': AdaBoostClassifier(n_estimators=40, random_state=7),
    '梯度提升': GradientBoostingClassifier(n_estimators=60, max_depth=2, random_state=7),
    '概率投票': VotingClassifier(base, voting='soft'),
    '折外Stacking': StackingClassifier(base, final_estimator=LogisticRegression(max_iter=1000), cv=3),
}
scores = {}
for name, model in models.items():
    scores[name] = cross_val_score(model, Xtr, ytr, scoring='f1', cv=cv).mean()
    print(name, '内部CV F1', round(scores[name], 3))
chosen = max(scores, key=scores.get)
model = models[chosen].fit(Xtr, ytr)
print('内部选中', chosen, '测试F1', round(f1_score(yte, model.predict(Xte)), 3))
```

上游手写元模型若以tanh输出最小化平方损失，梯度须含`tanh`导数`1-tanh(logit)**2`；其示例遗漏这一项。本章直接采用规范的逻辑回归元分类器，不把有缺项的梯度写成正确参考。

内层 stacking 的 OOF 只用于训练元模型，外层 CV 才用于估计该整个组合流程。时间预测不能直接沿用随机 OOF：训练须仅使用更早样本，最早一段不能生成合理 OOF；可手工构造时序折外区段，舍弃未覆盖行，再做独立未来验收。

## 7. 怎样检查集成是否值得

保存各模型同一验证样本的预测，比较错误重合率、残差相关以及新增模型在哪类样本改善。不要仅看两个预测序列相关，分类概率、残差和错误事件表达的问题不同。加入一个弱且高度相关成员可能无益甚至伤害。

| 情况 | 尝试 | 判断证据 |
|---|---|---|
| 单树训练好、验证差 | 限制复杂度、bagging/随机森林 | 分组/未来验证、方差稳定性 |
| 所有分数都低且数据合法 | 更好特征、提升树 | 基线与学习曲线，不能先断定只能boosting |
| 几个模型各有强弱 | voting/stacking | 同一验证集的互补错误、校准、额外成本 |
| 部署成本严格 | 保留单模型或简化集成 | 延迟、内存、维护和收益同列比较 |

## 8. 练习与参考答案

1. $\rho=0.5,\sigma^2=1,M=10$ 时平均方差多少，无限模型呢？**答案：**0.55，极限0.5；多样性比单纯增加模型更关键。
2. 四点错一例的 AdaBoost 更新为何给错点0.5？**答案：**错点乘 $e^{\alpha}=\sqrt3$，正确点乘 $e^{-\alpha}=1/\sqrt3$，归一化得0.5和1/6；核对权重总和1。
3. 在梯度提升中加入验证连续10轮无改善早停，如何选树数？**答案：**保留最低验证损失对应的前缀，不是最后10轮前的任意点；重新训练时明确是否复用该轮数，不在测试上选择。
4. 手写随机森林需要改普通回归树哪里？**答案：**每棵 bootstrap，每节点随机抽候选列，分裂仍按合适损失选阈值；回归平均，分类聚合类概率/投票。比较多个数据重采样下预测方差，不能把单次准确率提高叫“测得方差下降”。
5. 手工生成三基模型 OOF 怎么验证没有训练行混入？**答案：**每折 `clone` 新模型、全部预处理在该训练折拟合，断言 train/valid 索引无交集，每行被预测一次；训练元模型后在独立测试比较。各折不能复用旧权重。
6. Stacking 分数低于最佳单模型，一定程序错吗？**答案：**不一定，可能多样性不足、样本少、元模型过拟合或部署分布变化；先核对边界再分析实际收益。
7. 原站声称101个60%独立分类器达84%，该如何核对？**答案：**计算二项尾和；结果约97.9%，而21个约82.6%。这只是独立同率模型假设，不能当真实集成效果。

8. 怎样记录AdaBoost每轮学习曲线？**答案：**第3节history已保存本例每轮训练准确率；另对独立验证集计算相同前缀组合的分数，观察训练指数损失与0-1准确率的不同，不能用测试曲线选轮数。
9. 怎样比较XGBoost与手写提升速度？**答案：**先固定版本与同任务/切分/损失、线程数、调参预算、计时范围，分别量拟合与预测并同时报告误差；不能一个回归一个分类只比accuracy。本批未安装实跑XGBoost，故不给速度倍数。
