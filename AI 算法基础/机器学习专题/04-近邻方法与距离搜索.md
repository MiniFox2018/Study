# 04｜近邻方法与距离搜索

> 先修：[范数、距离与相似性](../数学与数值计算专题/05-范数距离与相似性.md)。数学专题维护距离定义与ANN结构，本章负责KNN分类/回归、边界处理、精确KD搜索和实验。先手算第1～3节，再运行实现和尺度实验。

## 1. KNN把预测推迟到查询时

给新样本 $q$，计算到训练样本的距离，取最近 $k$ 条。分类统计各类票数；回归取目标均值。加权版用非负权重 $a_i$，回归输出 $\sum_i a_iy_i/\sum_i a_i$；分类各类累加权重再选最大。

这称“懒惰学习”：通常不先优化一个紧凑的参数模型，但 `fit` 仍可能复制数据、检查输入、拟合预处理或建立搜索索引。保存 $N\times d$ 数据至少需要相应读取/内存，不应说所有训练时间都是 $O(1)$。训练集标签也不是“没有参数”就免校验。

手算：训练点 $(0,A),(1,A),(2,B),(4,B)$，查询1.6。距离依次1.6、0.6、0.4、2.4。$k=1$判B，$k=3$投A；若三邻居用 $1/d$ 加权，B得2.5，A得 $1/0.6+1/1.6\approx2.2917$，又判B。度量、k和权重共同定义模型。

来源平滑图显示每个位置的正类邻居比例。$k=1$复制最近点的标签，二维对应Voronoi区域；提高k常降低局部方差、增加平滑，但局部票数仍可能跳变，并不保证完全连续。无权重 $k=N$ 处处给整体多数类/目标均值；距离加权 $k=N$ 仍可随位置变化。

$k=1$在无冲突、查询包含自身训练样本时可以零训练误差，不代表泛化。完全相同输入但不同标签会有并列冲突，奇数k也不能消除多分类、距离权重或第k/第k+1距离并列。$k\approx\sqrt N$只是候选起点，必须与其他k在正确验证上比较。

## 2. 距离选择先问“什么差异有意义”

数学公式详见先修，重要使用关系是：

| 数据意义 | 可比较的选择 | 实际条件 |
|---|---|---|
| 同单位空间坐标 | L2 | 距离有真实几何含义；道路限制要用图路径 |
| 多个数值字段 | 缩放后L1/L2或加权距离 | 单位、容差与业务重要性需说明，不能默认等权正确 |
| 方向表达语义的向量 | cosine或归一化点积 | 零向量无定义；向量长度有意义时不能随意丢弃 |
| 二进制属性 | Hamming | 共同缺失也算相同；需要忽略共同缺失时比较Jaccard |
| 无序类别 | 相同/不同的代价、one-hot后距离 | 数字编号本身无大小；合理one-hot距离并非天然无意义 |
| 混合数值/类别 | Gower或字段分组加权 | 训练参考范围、缺失处理和权重必须一致 |
| 时间序列 | 对齐后L2或DTW | DTW允许时间扭曲，要限制窗口并承担计算成本 |

L1较少放大一个很大的坐标差异，但仍对量纲和异常影响敏感，不是自动稳健估计。Minkowski $p\ge1$才是通常范数/度量；$p<1$一般不满足三角不等式。常见 $1-\cos$在一般情况下不是严格度量，不能不检查就套依赖三角不等式的搜索剪枝。

**TF-IDF特别关系：**L2归一化的非零文档向量有 $\|u-v\|^2=2(1-\cos(u,v))$，因此cosine和L2的精确邻居排序相同。不能说cosine必然胜过L2。标准化原始向量会改变方向，embedding应按模型训练目标/检索文档选距离，再用真实相关性验证。

二元Gower的一种简单版本：数值列 $|x_j-z_j|/range_j$，类别列相同0不同1，按有效字段权重平均。range来自训练参考，常数列须定义规则；缺失字段可不参与同时重新归一化，但可能改变对象之间可比较性。时间/图等比较的计算例子统一见数学专题，避免另建一套距离百科。

## 3. 完整KNN：处理形状、k、零距离和并列

下面NumPy实现只支持有限数值输入。分类标签用可排序的同类标量；并列票按 `np.unique` 的固定顺序决定。第k边界并列由距离再训练行号排序，正式数据集若行顺序有含义应另设计规则。

```python
import numpy as np

def distance(a, b, metric="l2", p=2):
    diff = np.abs(a-b)
    if metric == "l2":
        return np.sqrt(np.sum(diff**2))
    if metric == "l1":
        return diff.sum()
    if metric == "minkowski":
        if p < 1:
            raise ValueError("作为度量使用时p须至少为1")
        return diff.max() if np.isinf(p) else np.sum(diff**p)**(1/p)
    if metric == "cosine":
        den = np.linalg.norm(a)*np.linalg.norm(b)
        if den == 0:
            raise ValueError("零向量余弦未定义")
        return 1-np.clip((a @ b)/den, -1, 1)
    raise ValueError("未知度量")

class SmallKNN:
    def __init__(self, k=3, metric="l2", weighted=False, task="classification", p=2):
        if task not in {"classification", "regression"}:
            raise ValueError("任务不支持")
        self.k, self.metric, self.weighted, self.task, self.p = k, metric, weighted, task, p

    def fit(self, X, y):
        self.X, self.y = np.array(X, float, copy=True), np.array(y, copy=True)
        if self.X.ndim != 2 or len(self.X) == 0 or self.y.shape != (len(self.X),):
            raise ValueError("需要非空二维特征和等长一维标签")
        if not isinstance(self.k, (int, np.integer)) or not 1 <= self.k <= len(self.X) or not np.isfinite(self.X).all():
            raise ValueError("k或特征不合法")
        if self.task == "regression" and not np.isfinite(self.y.astype(float)).all():
            raise ValueError("回归标签必须有限")
        self.classes = np.unique(self.y) if self.task == "classification" else None
        return self

    def one(self, q):
        q = np.asarray(q, float)
        if q.shape != (self.X.shape[1],) or not np.isfinite(q).all():
            raise ValueError("查询形状或取值不合法")
        d = np.array([distance(q, row, self.metric, self.p) for row in self.X])
        ids = np.lexsort((np.arange(len(d)), d))[:self.k]
        weights = np.ones(self.k)
        if self.weighted:
            zero = d[ids] == 0
            if zero.any():
                weights = zero.astype(float)
            else:
                weights = 1/d[ids]
        if self.task == "regression":
            value = weights @ self.y[ids]/weights.sum()
        else:
            votes = np.array([weights[self.y[ids] == c].sum() for c in self.classes])
            value = self.classes[votes.argmax()]
        return value, ids, d[ids]

    def predict(self, X):
        return np.array([self.one(row)[0] for row in X])

X, y = np.array([[0.], [1.], [2.], [4.]]), np.array(["A", "A", "B", "B"])
for k, weighted in [(1, False), (3, False), (3, True)]:
    model = SmallKNN(k, weighted=weighted).fit(X, y)
    value, ids, d = model.one([1.6])
    print("k/加权", k, weighted, "预测", value, "邻居", ids.tolist(), "距离", d.round(4))
reg = SmallKNN(3, weighted=True, task="regression").fit([[0], [0], [2]], [2, 4, 100])
print("重复零距离的回归预测", reg.predict([[0]]))
assert np.isclose(reg.predict([[0]])[0], 3)
```

零距离时只让选中的零距离邻居贡献权重，避免 $1/d$ 除零，且保持完全匹配的可解释性。若有超过k个完全重复样本，本实现仍只选k个，要明确这一截断与冲突策略。用 `1/(d+epsilon)` 是另一近似，但epsilon单位会影响结果，不能说只是毫无影响的技术细节。

无权重KNN回归是邻居目标的平均数，非负加权版是凸组合，所以输出在所选目标最小/最大范围内。训练目标全在0～100时不可能外推200。距离权重让近点更有影响，也可能放大错误近点或噪声，**不保证加权比无权重更平滑、更准确**。

### 3.1 完整回归实验：近处噪声也会被加权放大

下例需要NumPy/scikit-learn，比较相同划分中k=3/10/30的两种权重。输入已经是一维、同单位，不额外标准化；验证只用于观察配置，若要最终选模型应另留测试。

```python
import numpy as np
from sklearn.neighbors import KNeighborsRegressor

rng = np.random.default_rng(42)
X = rng.uniform(-3, 3, (160, 1))
y = np.sin(X[:, 0])+rng.normal(0, 0.15, 160)
train, valid = np.arange(120), np.arange(120, 160)
for k in [3, 10, 30]:
    for weights in ["uniform", "distance"]:
        model = KNeighborsRegressor(n_neighbors=k, weights=weights).fit(X[train], y[train])
        prediction = model.predict(X[valid])
        print("k/权重", k, weights, "验证MSE", round(np.mean((prediction-y[valid])**2), 5),
              "范围外x=10预测", round(model.predict([[10]])[0], 5))
        assert prediction.min() >= y[train].min()-1e-12
        assert prediction.max() <= y[train].max()+1e-12
```

查看密集网格上的曲线时，还应看输入范围边缘、局部噪声、邻居集合改变时的跳跃；不只看一项均方误差。x=10的输入已远超训练范围，程序仍会返回数值，但它只是边缘邻居目标的平均，不能拿来证明正弦外推能力。

## 4. 尺度实验：先切分，再在训练拟合变换

面积0～200、年龄0～1直接L2时面积主导；但把两列缩成相近尺度只是建立一种距离假设，不证明两列应同等重要。若领域单位本来表达合理容差，不一定要标准化。常数训练列用scale=1，使所有训练值该列为0；推理出现新变化可能是分布偏移，不能默认忽略。

```python
import numpy as np
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

rng = np.random.default_rng(42)
X = rng.normal(size=(240, 2))
y = (X[:, 0]+0.2*X[:, 1] > 0).astype(int)
X[:, 1] *= 1000  # 无关的大尺度会扰乱距离
Xdev, Xtest, ydev, ytest = train_test_split(X, y, test_size=0.25, stratify=y, random_state=1)
raw = KNeighborsClassifier(n_neighbors=5).fit(Xdev, ydev)
pipeline = make_pipeline(StandardScaler(), KNeighborsClassifier())
search = GridSearchCV(pipeline,
    {"kneighborsclassifier__n_neighbors": [1, 5, 15],
     "kneighborsclassifier__weights": ["uniform", "distance"],
     "kneighborsclassifier__p": [1, 2]}, cv=3, n_jobs=1)
search.fit(Xdev, ydev)
print("交叉验证选中", search.best_params_)
print("未缩放参考测试准确率", round(raw.score(Xtest, ytest), 4))
print("缩放且按CV选择的最终测试准确率", round(search.score(Xtest, ytest), 4))
```

这里未缩放模型是预先固定的参考，不按测试分数继续改模型。时间/用户数据应替换为匹配任务的交叉验证。`algorithm="auto"`由样本、维度、k、稀疏度和metric等共同决定索引，不能承诺数据大了就自动KD-tree加速。

## 5. 高维问题：无关维度会稀释邻居信息

如果每个坐标贡献独立且有有限方差，平方距离是很多贡献的和，其相对波动可随维度增长缩小。在固定或受控样本规模等条件下，近远距离相对差异可能减小。**不是任意分布的100维都给max/min=1.01**；极值比还依赖样本数、采样方式、离群点和本征维度。

更严重的是局部数据稀疏：单位立方中要覆盖一定数量的邻居，半径会变大，局部平均越来越包含不同区域。高维体积靠近边界等几何直觉有条件，不能简化成“所有点都一样远、近邻永远没意义”。有结构且训练适当的高维embedding仍广泛用于检索。

```python
import numpy as np

rng = np.random.default_rng(42)
for dims in [2, 5, 10, 50, 100, 500]:
    X = rng.uniform(size=(1000, dims))
    # 用全部不重复样本对，排除对角的自身距离；不创建N×N×d张量。
    squared = np.maximum((X*X).sum(1)[:, None]+(X*X).sum(1)[None, :]-2*(X @ X.T), 0)
    distances = np.sqrt(squared[np.triu_indices(len(X), 1)])
    print("维数", dims, "max/min", round(distances.max()/distances.min(), 4),
          "变异系数", round(distances.std()/distances.mean(), 4))
```

这一个固定随机实验实测100维max/min约1.8246、500维约1.2848，变异系数约0.0594/0.0265；说明相对距离差在此设置下减少，但远未等于来源无条件给出的1.01/1.001。真实诊断可在固定信号列外增加噪声列，看相同划分中KNN误差是否增长；做特征筛选、PCA或度量学习后重新验证。t-SNE主要用于可视化，不能默认当能稳定变换新样本的生产预处理；学习降维也必须训练折拟合。没有通用20/50维“截止线”，ANN索引更快也不能恢复已经丢掉的语义相关性。

## 6. 精确KD-tree：剪枝为什么不会漏真邻居

KD-tree沿坐标轴递归按中位点切分。查询先走靠近的一侧，维护当前k个最近候选，最差距离为 $r$；查询到分割平面的距离若大于 $r$，另一侧不可能更近，才可以剪枝。等距离的边界要保守检查，避免漏掉确定并列规则要保留的点。

下面完整实现用Python标准库，欧氏距离专用。最大候选堆保存负平方距离与负行号，最差候选在堆顶；距离相同优先小行号。

```python
import heapq
import math
import random

class ExactKD:
    def __init__(self, points):
        self.points = [tuple(map(float, p)) for p in points]
        if not self.points or not self.points[0]:
            raise ValueError("需要非空点集")
        self.d = len(self.points[0])
        if any(len(p) != self.d or not all(map(math.isfinite, p)) for p in self.points):
            raise ValueError("维度或取值不合法")
        self.root = self.build(list(range(len(self.points))), 0)

    def build(self, ids, depth):
        if not ids:
            return None
        axis = depth % self.d
        ids.sort(key=lambda i: (self.points[i][axis], i))
        mid = len(ids)//2
        return (ids[mid], axis, self.build(ids[:mid], depth+1),
                self.build(ids[mid+1:], depth+1))

    def query(self, q, k=1):
        q = tuple(map(float, q))
        if len(q) != self.d or not all(map(math.isfinite, q)) or not 1 <= k <= len(self.points):
            raise ValueError("查询或k不合法")
        best = []
        def search(node):
            if node is None:
                return
            index, axis, left, right = node
            point = self.points[index]
            dist2 = sum((a-b)**2 for a, b in zip(q, point))
            item = (-dist2, -index)
            if len(best) < k:
                heapq.heappush(best, item)
            elif item > best[0]:
                heapq.heapreplace(best, item)
            diff = q[axis]-point[axis]
            near, far = (left, right) if diff <= 0 else (right, left)
            search(near)
            if len(best) < k or diff*diff <= -best[0][0]:
                search(far)
        search(self.root)
        return sorted((math.sqrt(-dist2), -index) for dist2, index in best)

rng = random.Random(42)
points = [(rng.random(), rng.random()) for _ in range(100)]
points += [(0.5, 0.5), (0.5, 0.5)]  # 验证重复点与零距离
tree = ExactKD(points)
for q in [(0.5, 0.5), (0, 0), (1, 1)]:
    got = tree.query(q, k=5)
    expected = sorted((math.dist(q, p), i) for i, p in enumerate(points))[:5]
    assert [i for _, i in got] == [i for _, i in expected]
    assert all(math.isclose(a[0], b[0], abs_tol=1e-12) for a, b in zip(got, expected))
    print("查询", q, "近邻行号", [i for _, i in got])
```

这一实现每层排序，构建约 $O(N\log^2N)$，不是最优工程实现。暴力扫描距离约 $O(Nd)$，若完整排序还需 $O(N\log N)$；只top-k可部分选择或用堆。低维合适分布下KD查询常能剪去大量点，不能把所有查询保证为 $O(\log N)$；最坏会检查全点，高维也会退化。

Ball tree以球包围子树，用查询到中心距离减半径给下界，须所用度量支持合法的界。KD/Ball的分工受数据几何和度量影响，不是“20维以下KD、50维以下Ball”的硬规则。

## 7. 性能实验与ANN：速度和邻居正确性分开

基准要固定同一数据与查询，分别报告构建、查询、内存、精确结果匹配。批量NumPy扫描往往比Python循环快；不能让Python暴力与C实现KD比较后把差异全归功算法。只查询一次时，构图费用也可能抵消查询收益。

下面用SciPy KD与NumPy暴力，默认1k/10k、2/10/50维、20个查询，能在普通环境跑。将sizes加100000可扩展源练习，当前验收不把更大规模标成已测。无需下载外部数据。

```python
import time
import numpy as np
from scipy.spatial import KDTree

rng = np.random.default_rng(42)
sizes = [1000, 10000]
for dims in [2, 10, 50]:
    for n in sizes:
        X, Q = rng.normal(size=(n, dims)), rng.normal(size=(20, dims))
        start = time.perf_counter()
        tree = KDTree(X)
        build = time.perf_counter()-start
        start = time.perf_counter()
        distances, ids = tree.query(Q, k=5)
        query = time.perf_counter()-start
        start = time.perf_counter()
        truth = []
        for q in Q:
            d2 = ((X-q)**2).sum(1)
            pick = np.argpartition(d2, 4)[:5]
            truth.append(pick[np.argsort(d2[pick])])
        brute = time.perf_counter()-start
        assert np.array_equal(ids, np.array(truth))
        print("N/d", n, dims, "构建/查询/暴力秒", tuple(round(t, 5) for t in [build, query, brute]))
```

超大高维检索常用HNSW、IVF、PQ等近似法，原理及recall@k验收已在数学专题。`FAISS.IndexFlatL2`是**精确平面扫描**，不是看到FAISS就默认ANN；返回的L2分数通常是平方距离，排序与L2一致，但权重和阈值要用正确单位。

RAG/向量库的近邻检索只负责选候选；它还包含embedding、过滤、去重、权限、reranking与生成评价，不等于把检索文档做KNN标签投票。ANN recall高也不证明文档相关，必须额外评估真实检索任务。

## 8. 完成练习的参考答案与判断标准

1. KNN为何叫懒惰、k如何选？**答案：**拟合通常保存数据，主要预测计算延后；复制/预处理/索引仍有成本。验证同时考虑k、metric、weight，奇数只能缓解部分二类无权重票数并列。
2. 三类二维边界比较 $k=1,5,15,N$？**方法：**固定原始划分，密集网格预测并着色，报告留出指标；无权重N给总体多数，多类并列有规则；不能用训练自身零误差证明泛化。
3. 1000点、2/5/10/50/100/500维max/min怎么测？**答案：**第5节排除自身对、检查零重复，固定种子并报告实际值和变异系数；不要抄1.01等无依据常数。
4. TF-IDF用L1/L2/cosine哪种最好？**答案：**同划分验证，不承诺cosine必胜。L2归一化后cosine和L2邻居顺序一致；权重函数不同仍可改变投票。
5. 1k/10k/100k与2/10/50维KD何时不快？**判断标准：**第7节可扩sizes测构建和查询，多次重复；临界点依赖硬件、分布、k和实现。当前运行仅默认较小规模，100k未标为已测。
6. $\sin x+noise$的加权回归该看什么？**方法：**固定训练/验证对k=3/10/30比较RMSE、预测范围、局部噪声与边缘结果，画网格输出。加权不是必更平滑；非负权重平均不能外推训练目标范围。
7. 值完全等于训练样本怎么处理？**答案：**先明确重复/冲突规则，第3节只让选中的零距离邻居投票或平均，避免除零；未知类别、零向量和缺失输入要显式处理。
