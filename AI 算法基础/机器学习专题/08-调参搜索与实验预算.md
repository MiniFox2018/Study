# 08｜调参搜索与实验预算

> 先修：[评估与数据边界](07-评估指标验证与不平衡学习.md)、训练/验证划分。先做预算计算与随机搜索，再看贝叶斯优化和资源分配。调参搜索的是完整训练程序，不只是一串模型构造参数。

## 1. 参数、超参数与评价程序

模型参数在训练中估计，例如权重、树阈值、质心；超参数控制拟合规则，例如惩罚强度、深度、学习率、特征变换。选择训练轮数、阈值、特征集合也属于模型选择。超参数可由自动搜索选择，因此“人为设置”的区别不够准确；关键是它们在一次拟合外层被选择。

定义搜索前写清：目标指标及最大化/最小化方向、输入数据版本、切分、预处理、随机性、一次评价的时间与内存、总预算、无效组合和停止规则。scikit-learn的`neg_mean_squared_error`越大越好，报告MSE时取负，不能选最小负数。

假设6个参数各5个值，网格 $5^6=15625$种；每次完整评价10秒，串行约43.4小时。如果10秒只是单次拟合且5折，每组合约50秒，总约217小时，另加最终重拟合。记清“trial”是一个超参数组合，“fit”是一次模型训练。

### 1.1 搜索空间与尺度要匹配

| 类型 | 采样方法 | 例子和原因 |
|---|---|---|
| 正值、按倍率生效 | log-uniform | `alpha`、`C`、学习率可跨数量级 |
| 有限离散方案 | categorical | 模型族、激活、batch size候选；需保证合法组合 |
| 有界整数 | integer | 树深度、层数；区间端点约定要核对 |
| 有界比例 | uniform或任务分布 | subsample等，必须满足算法范围 |
| 条件参数 | 分支搜索空间 | 只有RBF核才需gamma；按solver/penalty约束组合 |

log-uniform正数 $z=\exp[\operatorname{Uniform}(\log a,\log b)]$，为数量级分配近似相等概率。0不在定义域，要把“无惩罚”单列成类别。并非所有学习率都必须用这种分布，也不是batch size不能按倍数选；分布由先验范围与预算决定。

缩放、度量和模型实现变化会改变合理数值范围。下面只作起始候选，不是所有数据的默认最优区间：

- Ridge/Lasso：主要扫`alpha`，先规范特征尺度；SVM/RBF联合扫`C`、`gamma`。
- 随机森林：深度、叶最小样本数、`max_features`及树数量；随机森林没有梯度学习率，不能套“总先调学习率”。更多树主要稳定集成、增加成本，不保证单调泛化改善。
- Boosting：学习率与迭代数强交互，小步往往需要更多树；还要看叶复杂度、采样与正则。
- 神经网络：学习率、架构、训练预算与正则交互；batch size影响优化、显存和吞吐，没有固定低重要性排名。

参数重要性依赖数据、范围、条件参数和搜索分布。相关性不是因果：某参数只在另一模型族中取值时，简单排名会混入模型族差异。最优点贴边可能提示范围过窄，也可能真实最优或噪声；先核查合法范围，再扩展验证。

## 2. 网格与随机搜索

网格枚举有限笛卡尔积，适合少量参数、有理由的离散候选和可承受预算。它只能保证找到**给定网格、给定评分结果**中的最好值，不保证连续全局最优。超过三个参数不等于绝对不能网格，只是组合成本应算清。

随机搜索按预定分布独立抽样。若只有少数维真正影响结果，同预算下网格在重要维上的不同值很少，随机搜索通常覆盖更多位置。这是有效维度低时的优势，不是随机方法必然胜出。

若“足够好”的区域在所选采样分布下质量为 $q$，$m$次独立试验至少命中一次概率为：

$$
1-(1-q)^m.
$$

$q=0.05,m=60$约95.39%。它指命中采样空间中占概率5%的好区域，**不是保证分数距全局最优5%以内**。好区域多小、采样分布是否覆盖它通常未知。多次随机种子和best-so-far轨迹才是比较方法的证据。

### 2.1 完整随机搜索：预处理也在折内

```python
import numpy as np
from scipy.stats import loguniform
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split, KFold, RandomizedSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_squared_error

X, y = make_regression(n_samples=180, n_features=12, noise=20., random_state=42)
Xtrain, Xtest, ytrain, ytest = train_test_split(X, y, test_size=0.25, random_state=42)
pipe = Pipeline([("scale", StandardScaler()), ("model", Ridge())])
search = RandomizedSearchCV(pipe, {"model__alpha": loguniform(1e-4, 1e3)},
    n_iter=8, cv=KFold(3, shuffle=True, random_state=42),
    scoring="neg_mean_squared_error", random_state=42, n_jobs=1, refit=True)
search.fit(Xtrain, ytrain)
print("最优alpha", round(search.best_params_["model__alpha"], 6))
print("选择中的CV MSE", round(-search.best_score_, 3))
print("冻结后测试MSE", round(mean_squared_error(ytest, search.predict(Xtest)), 3))
print("拟合次数", 8*3+1)
```

共24折拟合+1次全训练集重拟合。`best_score_`参与了选择，不能冒充最终泛化成绩；测试在固定候选程序完成后才评价。记录`cv_results_`中的全部候选、分数、拟合时间和失败，而非只保留冠军。

每一候选/每折创建全新模型，重新fit须重置已学状态。原来源手写`GBMForTuning.fit`未清空树列表，实测同一实例连续fit两次时树数由2变4；不能将这种对象复用当成独立候选训练。本章成熟库搜索通过克隆训练，GP教学程序则独立记录每次观测。

## 3. 贝叶斯优化：为昂贵评价选择下一点

设超参数向量为 $h$，昂贵目标为 $g(h)$。先评价一些初始点，拟合便宜代理 $g$；代理给候选的预测均值 $\mu(h)$和不确定性 $\sigma(h)$，采集函数选择下一点，再真训练、加入结果、重复。

高斯过程常用于低到中等维连续搜索；树代理、TPE等也常用，Optuna的默认采样器不是“必然高斯过程”。代理的不确定性依赖模型假设，不能保证自动代表真实训练波动；重复种子、观察噪声和预算仍重要。

### 3.1 期望改进EI的符号与极限

对**最大化**目标，已知最好值为 $g_*$，改进 $I=\max(g(h)-g_*-\xi,0)$，$\xi\ge0$是额外探索参数。若代理预测为高斯，令 $a=\mu-g_*-\xi,z=a/\sigma$：

$$
\mathrm{EI}=a\Phi(z)+\sigma\phi(z),\quad \sigma>0.
$$

$\Phi$为标准正态CDF，$\phi$为密度。$\sigma=0$时EI为 $\max(a,0)$。均值好但不确定性小的点有利用价值；均值不占优但不确定性大的点也可能有改进机会。最小化时要改成 $g_*-\mu-\xi$，不能直接照抄最大化符号。

PI看改进概率 $\Phi(z)$，可能偏好很小但确定的改进；最大化UCB是 $\mu+\kappa\sigma$，最小化常用LCB $\mu-\kappa\sigma$。采集函数由优化目标选择，不必对昂贵真实目标求导。

### 3.2 能独立运行的1维GP+EI循环

此例用 $u\in[0,1]$模拟某个归一化/对数超参数，昂贵目标替换为已知的合成函数。RBF核、Cholesky求解和EI完整写出；目的为解释流程，不是生产级优化器。

```python
import numpy as np
from scipy.special import ndtr

def objective(u):
    return 1.0 - (u-0.7)**2 + 0.08*np.sin(12*u)

def kernel(a, b, length=0.18):
    return np.exp(-0.5*((a[:, None]-b[None, :])/length)**2)

def gp_predict(x, y, candidate):
    # 目标标准化使固定核幅度更合理；噪声jitter保证数值求解。
    center, scale = y.mean(), max(y.std(), 1e-8)
    yn = (y-center)/scale
    K = kernel(x, x) + 1e-6*np.eye(len(x))
    L = np.linalg.cholesky(K)
    cross = kernel(candidate, x)
    alpha = np.linalg.solve(L.T, np.linalg.solve(L, yn))
    mu = center + scale*(cross @ alpha)
    v = np.linalg.solve(L, cross.T)
    variance = scale**2*np.maximum(1-np.sum(v*v, axis=0), 0.)
    return mu, np.sqrt(variance)

def expected_improvement(mu, sigma, best, xi=0.005):
    a = mu-best-xi
    out = np.maximum(a, 0.)
    nz = sigma > 1e-12
    z = a[nz]/sigma[nz]
    out[nz] = a[nz]*ndtr(z) + sigma[nz]*np.exp(-0.5*z*z)/np.sqrt(2*np.pi)
    return out

def bayes_run(seed, budget=12):
    rng = np.random.default_rng(seed)
    x = rng.uniform(0., 1., 3)
    y = objective(x)
    for _ in range(3, budget):
        candidates = np.linspace(0., 1., 501)
        candidates = candidates[np.min(np.abs(candidates[:, None]-x[None, :]), axis=1) > 1e-6]
        mu, sigma = gp_predict(x, y, candidates)
        chosen = candidates[np.argmax(expected_improvement(mu, sigma, y.max()))]
        x = np.r_[x, chosen]; y = np.r_[y, objective(chosen)]
    return float(y.max()), np.maximum.accumulate(y)

grid_best = float(objective(np.linspace(0., 1., 12)).max())
for seed in range(5):
    rng = np.random.default_rng(seed)
    random_best = float(objective(rng.uniform(0., 1., 12)).max())
    bayes_best, curve = bayes_run(seed)
    assert np.all(np.diff(curve) >= 0)
    print(seed, "同为12评价 网格/随机/BO", round(grid_best, 5),
          round(random_best, 5), round(bayes_best, 5))
print("60次命中5%概率区域", round(1-0.95**60, 6))
```

这里用正确正态CDF，替代上游`tanh`的粗近似；每次候选避开已观察点，目标按尺度标准化。GP长度尺度固定、候选网格有限、无条件类别变量也未学习噪声，不能据此断言BO普遍节省2～5倍。评价很便宜时代理开销可能比真目标还大；高维、离散、嘈杂或可大规模并行时随机搜索可能更合适。

## 4. 停止坏试验与选择训练轮数是两件事

**模型早停**：一个配置训练时，验证指标若若干轮没有改善，停止并恢复最佳轮次；patience、最小改善量与最大预算也是选择规则。**Trial pruning**：根据与其他配置的可比中间成绩，提前停止不值得继续的配置。两者都需要可比的验证过程，晚熟配置可能被过早淘汰。

### 4.1 用staged_predict选择Boosting轮数

```python
import numpy as np
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.metrics import mean_squared_error
X, y = make_regression(n_samples=120, n_features=6, noise=50, random_state=7)
Xt, Xv, yt, yv = train_test_split(X, y, test_size=0.3, random_state=7)
probe = GradientBoostingRegressor(n_estimators=200, learning_rate=0.1,
                                 max_depth=3, random_state=7).fit(Xt, yt)
losses = np.array([mean_squared_error(yv, p) for p in probe.staged_predict(Xv)])
best_round = int(np.argmin(losses))+1
frozen = GradientBoostingRegressor(n_estimators=best_round, learning_rate=0.1,
                                  max_depth=3, random_state=7).fit(Xt, yt)
assert np.isclose(mean_squared_error(yv, frozen.predict(Xv)), losses[best_round-1])
print("验证选择轮次/MSE", best_round, round(losses[best_round-1], 3))
```

所测环境验证最佳为114轮、MSE约5835.315，200轮约5923.451。这段先训练完整200轮再回看阶段分数，**没有节省训练计算**，仅完整演示轮次选择；真正在线早停要在迭代中读取验证成绩，库实现需核对接口。没有测试集，所以输出是选择分数。重训到全训练池时，样本和最优轮数关系可能改变；不保证“设置最高轮数再早停”严格优于所有迭代数搜索。

### 4.2 successive halving、Hyperband与ASHA

一个折半淘汰括号可从81个配置各1轮开始，按当前指标保留27个到3轮、9个到9轮、3个到27轮、1个到81轮。若每轮重新从零训练，成本为 $81\cdot1+27\cdot3+9\cdot9+3\cdot27+1\cdot81=405$配置轮；若checkpoint可续训，增量成本为 $81+27\cdot2+9\cdot6+3\cdot18+1\cdot54=297$。全部81个训练81轮为6561。

这描述**successive halving的一个括号**；完整Hyperband用多个起始预算与候选数的括号，避免全部依赖极小预算；ASHA以异步方式晋级，降低等待慢任务的成本。实际时间受并发、checkpoint、失败和数据加载影响，不保证固定加速倍数。

小预算排名必须能预测大预算质量。低学习率配置可能早期较差、后期更好；不同模型的“一轮”不一定可比。资源可以是轮数、样本量或树数，但改变样本量也会改变任务难度和采样方差。

### 4.3 Optuna的pruning必须报告中间步骤

如下是可选依赖示例。本组初验时未安装Optuna；随后根级在临时隔离环境以Optuna5.0.0、scikit-learn1.9.1实际执行，15个trial得到alpha约0.0003149、验证log-loss约0.2152。结果限于本例数据/种子/版本，不是固定最优答案。它展示必要调用位置；数据、缩放和评价都在训练/验证边界内，使用能`partial_fit`的分类器。

```python
import optuna
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import SGDClassifier
from sklearn.metrics import log_loss

X, y = load_iris(return_X_y=True)
Xt, Xv, yt, yv = train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)
scale = StandardScaler().fit(Xt)
Xt, Xv = scale.transform(Xt), scale.transform(Xv)

def objective(trial):
    alpha = trial.suggest_float("alpha", 1e-5, 1e-1, log=True)
    model = SGDClassifier(loss="log_loss", alpha=alpha, random_state=42)
    for step in range(30):
        model.partial_fit(Xt, yt, classes=[0, 1, 2])
        value = log_loss(yv, model.predict_proba(Xv), labels=[0, 1, 2])
        trial.report(value, step=step)
        if trial.should_prune():
            raise optuna.TrialPruned()
    return value

study = optuna.create_study(direction="minimize",
    sampler=optuna.samplers.TPESampler(seed=42),
    pruner=optuna.pruners.MedianPruner(n_startup_trials=5, n_warmup_steps=5))
study.optimize(objective, n_trials=15)
print(study.best_params, study.best_value)
```

只在全训练完成后`report(..., step=0)`没有提前节省成本；配上`n_warmup_steps=5`更不会在step0进入预期剪枝。MedianPruner根据已完成trial在可比步骤的中间值等规则判断，要核对方向和启动/warmup条件。Optuna默认TPE是一类自适应采样器，本例显式种子；并行调度与硬件差异仍可能破坏逐次完全复现。

## 5. 学习率调度不要被搜索口诀代替

固定学习率选择“每步走多远”，调度器选择它如何随时间变化。常见：分段乘因子、余弦衰减、先warmup后衰减、One-cycle、验证平台期减小。带最低学习率的余弦为：

$$
\eta_t=\eta_{min}+\frac{\eta_{max}-\eta_{min}}2
\left(1+\cos\frac{\pi t}{T}\right),\quad 0\le t\le T.
$$

```python
import numpy as np
t = np.array([0., 5., 10.])
lr = 0.001 + 0.5*(0.1-0.001)*(1+np.cos(np.pi*t/10))
print("余弦起点/中点/终点", lr.tolist())
assert np.allclose(lr, [0.1, 0.0505, 0.001])
```

warmup的初始步数、调度按batch还是epoch、恢复checkpoint的计数状态都应记录。warmup与余弦不是所有Transformer或CNN的必然最佳策略。Boosting的阶段系数可以扩展成逐阶段学习率，但不是每个库支持把普通神经网络scheduler直接挂上；公平比较还要保持总预算和数据切分一致。

## 6. 嵌套交叉验证评价的是搜索程序

内层只在外层训练部分选择超参数，使用全体外层训练数据重拟合，然后在外层验证折评分。每个外层折应独立搜索自己的参数；不能先用全数据选一个参数再做外层验证。所有学习型预处理和特征选择也属于内层程序。

```python
import numpy as np
from sklearn.datasets import make_regression
from sklearn.model_selection import KFold, GridSearchCV, cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.linear_model import Ridge
X, y = make_regression(n_samples=150, n_features=10, noise=25, random_state=9)
pipe = Pipeline([("scale", StandardScaler()), ("model", Ridge())])
inner = KFold(3, shuffle=True, random_state=1)
outer = KFold(3, shuffle=True, random_state=2)
selection = GridSearchCV(pipe, {"model__alpha": [0.01, 1., 100.]},
                         cv=inner, scoring="neg_mean_squared_error", n_jobs=1)
scores = cross_val_score(selection, X, y, cv=outer,
                         scoring="neg_mean_squared_error", n_jobs=1)
print("外层MSE", (-scores).round(3).tolist())
print("外层平均MSE", round(-scores.mean(), 3))
print("含每外层重拟合的fit数", 3*(3*3+1))
# 需要最终模型时，再在全体开发数据上独立执行同一搜索程序；此score仍是选择分数。
selection.fit(X, y)
print("最终开发模型alpha", selection.best_params_["model__alpha"])
```

外层3折共30fit，最后开发全数据搜索另10fit，总40。外层分数估计的是“这个样本规模与划分下的选参+训练程序”，并非某组固定参数在全部数据训练后的精确成绩；也不是无条件无偏或上线保证。外层训练集重叠，分数仍相关，标准差是描述性波动。实体/时间目标要在内外层都采用相应切分，普通KFold示例只适用近似独立样本。

## 7. 可执行的预算与停止规则

先跑默认与基线，测几次单fit耗时；估算候选数×折数×拟合成本，以及重拟合、代理与日志开销。并行受内存与线程限制，不默认`n_jobs=-1`无限占满资源。对同一数据尽量复用相同CV索引与随机种子，避免比较混入不同划分。

粗搜后看best-so-far、边界、失败与方差，必要时收窄范围再搜索；不要固定“60%给前两参数”或“参数个数两倍trial必够”。在预算耗尽、连续多批没有超过最小有用改善、分数噪声大于候选差异或数据/标签问题成为主限制时停止或转向。报告总尝试次数，包括不成功搜索；只报告最佳一次会掩盖选择成本。

改良搜索不是无限试验。候选和特征反复针对验证调整，会过拟合验证；最后留出测试或采用嵌套评估。若用了外层成绩继续改搜索空间，此外层也变成开发依据，需要重新解释结论。

## 8. 练习与参考判断

1. 4参数各5值、5折、最佳重拟合，多少fit？**答案：**$625\times5+1=3126$；如又嵌套5外层，每外层都搜索需 $5(3125+1)=15630$，另计最终开发搜索。
2. 同50trial跑网格/随机并换10种子，如何判断谁好？**参考：**预定同一目标、切分、合法空间和预算，报告最佳验证值的分布及真实时间；网格对重要维覆盖弱时随机可能赢，但不是固定答案。最终选择结果需独立评价。
3. 单个81→27→9→3→1括号算Hyperband完整实现吗？**答案：**是successive halving的一个括号；Hyperband还要组合不同起始预算。重训405、续训297配置轮与全部6561的比较只为算例，不保证真实加速。
4. EI选择均值较低但方差大的一点，是错了吗？**答案：**可能是在探索；算 $a\Phi(z)+\sigma\phi(z)$，同时注意最大化/最小化符号。后续真实观测才能判断收益。
5. 模型全训后只报一次step0、warmup5能prune吗？**答案：**不能按预期提前剪枝；应在迭代中报告step，明确相同资源下的中间成绩。
6. 优化随机森林后参数重要性和教程固定排行不同怎么办？**答案：**保留实际数据、空间与种子下的证据；排行本来不是定律。若用可选Optuna重要性工具，记录工具方法和条件搜索空间，不将可视化当因果证明。
7. 比较Boosting固定学习率与余弦调度怎么做？**参考：**需要支持逐阶段步长的实现，固定基学习器和总训练预算，记录每阶段系数并在相同验证划分选择；当前库不支持时不能伪称直接套scheduler完成。
