# 05｜朴素贝叶斯与概率分类

> 先修：[概率分布与贝叶斯推断](../数学与数值计算专题/10-概率分布与贝叶斯推断.md)。该章第8节保留可直接读原始词串的 `WordCountNB`；本章接着解释事件模型、三种数值实现、模型比较和概率校准，不再复制同一词袋程序。

## 1. 先验、似然、后验，不能把分数叫成概率

类别 $c$、特征 $x$ 满足 $P(c\mid x)=P(c)P(x\mid c)/P(x)$。分类比较时，$P(x)$对所有类相同，可以暂不算；模型得分是：

$$
s_c=\log P(c)+\log P(x\mid c).
$$

这是对数联合分数，**不是已归一化的对数后验**。真正后验对数还需减 $\log\sum_k e^{s_k}$，概率为 $e^{s_c}/\sum_ke^{s_k}$。先减最大分数再指数化，避免很多小概率连乘下溢与指数溢出。

朴素贝叶斯以简单类别条件模型代替昂贵联合分布。对多元Bernoulli或Gaussian，常假设 $P(x\mid c)=\prod_jP(x_j\mid c)$；这里是**给定类别后的条件独立**，不等于总体中独立。例如两个测量都随类别改变，总体可相关，即使类内独立。

对词频的Multinomial模型，文档长度给定后词次数有总和约束，本身不彼此独立；更准确的生成解释是词token在类别给定后按同一词分布独立抽样，最后统计频数。其多项式系数与类别无关，做argmax时抵消。这比把词频列一概称相互独立更精确。

假设常是近似，但不等于“数学上必须错误”。分类只需类别排序正确，概率不准仍可能有用；强约束有时降低小样本估计方差，但独立错误**不保证各类相同抵消**。重复强相关证据可能导致过度自信，甚至改变类别。

例：先验垃圾/正常比为1:10，一个出现信号的似然比为6，真实后验几率为0.6，仍偏正常。把同一信号复制成两个完全相关字段，NB误当独立，相乘为36，模型后验几率变3.6，反而判垃圾。去掉冗余、加入组合表示或换能利用交互的模型，应根据保留集判断。

## 2. 多项式NB：次数是指数，分母是类别总词数

训练词表 $V$ 大小为 $d$，类别 $c$中词 $j$总次数为 $N_{cj}$，类别全部词次数 $N_c=\sum_jN_{cj}$。正数平滑 $\alpha$ 给：

$$
\theta_{cj}=\frac{N_{cj}+\alpha}{N_c+\alpha d},\quad
s_c=\log\pi_c+\sum_jx_j\log\theta_{cj}.
$$

类别先验 $\pi_c$ 来自**文档数**，词分母来自**词次数**，不能混用。$\alpha=1$是加一/Laplace平滑；一般正$\alpha$称加性/Lidstone平滑。它可看作对称Dirichlet先验下的后验均值/预测概率；别和需减1的MAP公式混为同一件事。

### 2.1 核对一个完整分类

词表“免费、钱、会议”；垃圾词次数 `(80,60,10)`，正常 `(5,10,100)`，先验 `(0.4,0.6)`。加一后概率分别 `(81,61,11)/153` 和 `(6,11,101)/118`。新文档频数 `(2,1,0)`：

$$
s_{垃}=\log0.4+2\log(81/153)+\log(61/153),
$$

$$
s_{正}=\log0.6+2\log(6/118)+\log(11/118).
$$

不先把概率四舍五入再累加。归一化后垃圾概率约0.9968；该数值是此模型下后验，不自动是现实可靠置信度。会议未出现，对多项式NB贡献为零，因为 $x_j=0$；Bernoulli版本则要计算“会议不存在”的概率。

平滑解决的是**训练词表内已知词在某类别没有见过**的零计数，不自动创建完全不在词表的词。词表外词可以忽略或训练 `<UNK>`，必须训练/推理一致。完全未知或空文本若映射为全零，Multinomial就只剩先验；需要监控空向量和未知比例。

词表、分词、停用词、n-gram、IDF都要仅训练集拟合。词袋丢弃顺序，不理解“不是很好”和“很好”的逻辑关系；可比较字符/词n-gram，不能声称NB已经理解语义。

### 2.2 TF-IDF和混合数值的边界

标准TF-IDF是非负数，可作为MultinomialNB实践输入，但非整数权重不是原始多项式词计数生成机制；它是经验有效的加权特征，须验证。非负不代表任意连续测量都适合多项式模型。把温度、身高平移为正数，只是消除了API报错，改变了相对计数含义，不能证明模型合理。

很常见的词可能信息量小，IDF降低普遍词权重；罕见词不一定有判别价值，也可能拼写噪声。IDF和词表可随时间变化；推理不能重新拟合一套不同列顺序的词表。

## 3. BernoulliNB：缺席也有证据

输入为 $x_j\in\{0,1\}$，类别 $c$中有 $n_c$份文档，其中 $m_{cj}$份含词 $j$：

$$
\theta_{cj}=\frac{m_{cj}+\alpha}{n_c+2\alpha},
\quad
s_c=\log\pi_c+\sum_j[x_j\log\theta_{cj}+(1-x_j)\log(1-\theta_{cj})].
$$

分母的2对应出现/不出现两种结果，不是词表大小。一个短文本没有常见垃圾词，可能降低垃圾分数；同一个词出现10次仍只算出现一次。是否优于多项式取决于频次信号、长度、词表和任务，不能“短信必Bernoulli”。

当前 scikit-learn `BernoulliNB(binarize=0.0)`默认可将非二元特征按大于0转换；若已传二值矩阵可明确 `binarize=None`。`CountVectorizer(binary=True)`直接建出现矩阵，方便解释；不能说传计数给默认Bernoulli必然没二值化。改变binarize阈值会改变事件含义，须训练/推断一致。

## 4. GaussianNB：估类内均值、方差与密度

连续输入在类别给定时，各列假设 $x_j\mid c\sim\mathcal N(\mu_{cj},\sigma_{cj}^2)$。极大似然参数是类内均值和**除以$n_c$**的方差；除以$n_c-1$是另一无偏估计约定。对数分数为：

$$
s_c=\log\pi_c-\frac12\sum_j\left[\log(2\pi\sigma_{cj}^2)
+\frac{(x_j-\mu_{cj})^2}{\sigma_{cj}^2}\right].
$$

这里是密度，单个密度可大于1，不是“样本点的概率超1”。若类别方差不同，类间分数差含二次项，**GaussianNB一般不是线性边界**；Multinomial和Bernoulli在其特征表示中才有线性分数形式。

类内零方差需要平滑/方差下限。固定加 $10^{-9}$与原单位有关；当前scikit-learn的 `var_smoothing` 按训练数据最大整体方差比例构造epsilon。因此手写固定绝对epsilon与库结果不必完全一样。理想无平滑高斯模型对一致的每列非零仿射缩放有相同类别排序，因为公共密度变换因子抵消；实际方差平滑、异常与数值问题仍可能受尺度影响。

来源图用均值0.38、0.66、共同标准差0.12两条钟形，拖动观测值比较似然；相同先验/方差时后验由两个密度比决定。观测位于中点0.52时两类各0.5；若先验不等，边界不再恰是中点。图中纵轴省去共同高斯归一化常数可以用于比值，但不能把曲线高度当已经归一化PDF。

## 5. 三种模型的完整NumPy实现与库对照

代码每次fit重置参数、拒绝非法输入，输出正规化概率；联合分数另命名 `joint_scores`，避免源实现的 `predict_log_proba`实际上只返回未归一化分数的问题。Gaussian平滑与本次核对的scikit-learn约定一致。

```python
import numpy as np

class SmallNB:
    def __init__(self, kind="multinomial", alpha=1.0, var_smoothing=1e-9):
        if kind not in {"multinomial", "bernoulli", "gaussian"} or alpha <= 0 or var_smoothing <= 0:
            raise ValueError("模型类型、平滑参数不合法")
        self.kind, self.alpha, self.var_smoothing = kind, alpha, var_smoothing

    def validate(self, X):
        X = np.asarray(X, float)
        if X.ndim != 2 or X.shape[1] == 0 or not np.isfinite(X).all():
            raise ValueError("需要有限二维特征")
        if self.kind == "multinomial" and (X < 0).any():
            raise ValueError("Multinomial要求非负输入")
        if self.kind == "bernoulli" and not np.isin(X, [0, 1]).all():
            raise ValueError("本教学Bernoulli要求已二值化输入")
        return X

    def fit(self, X, y):
        X, y = self.validate(X), np.asarray(y)
        if len(X) == 0 or y.shape != (len(X),):
            raise ValueError("样本非空且标签等长")
        self.d = X.shape[1]
        self.classes, counts = np.unique(y, return_counts=True)
        self.log_prior = np.log(counts/counts.sum())
        epsilon = max(self.var_smoothing*np.var(X, axis=0).max(), np.finfo(float).eps)
        parameters, variances = [], []
        for c in self.classes:
            rows = X[y == c]
            if self.kind == "multinomial":
                count = rows.sum(0)+self.alpha
                parameters.append(count/count.sum())
            elif self.kind == "bernoulli":
                parameters.append((rows.sum(0)+self.alpha)/(len(rows)+2*self.alpha))
            else:
                parameters.append(rows.mean(0))
                variances.append(rows.var(0)+epsilon)
        self.parameters = np.array(parameters)
        self.variances = np.array(variances)
        return self

    def joint_scores(self, X):
        X = self.validate(X)
        if X.shape[1] != self.d:
            raise ValueError("训练/预测特征数量不一致")
        if self.kind == "multinomial":
            return X @ np.log(self.parameters).T+self.log_prior
        if self.kind == "bernoulli":
            return X @ np.log(self.parameters).T+(1-X) @ np.log1p(-self.parameters).T+self.log_prior
        values = []
        for mean, var, prior in zip(self.parameters, self.variances, self.log_prior):
            values.append(prior-0.5*(np.log(2*np.pi*var)+(X-mean)**2/var).sum(1))
        return np.column_stack(values)

    def predict_log_proba(self, X):
        scores = self.joint_scores(X)
        peak = scores.max(1, keepdims=True)
        log_z = peak+np.log(np.exp(scores-peak).sum(1, keepdims=True))
        return scores-log_z

    def predict_proba(self, X):
        return np.exp(self.predict_log_proba(X))

    def predict(self, X):
        return self.classes[self.joint_scores(X).argmax(1)]

X = np.array([[3, 2, 0], [2, 1, 0], [0, 0, 3], [0, 1, 2]], float)
y = np.array([0, 0, 1, 1])
Q = np.array([[2, 1, 0], [0, 0, 2], [0, 0, 0]], float)
from sklearn.naive_bayes import MultinomialNB, BernoulliNB, GaussianNB
for kind, library, train, query in [
    ("multinomial", MultinomialNB(alpha=1), X, Q),
    ("bernoulli", BernoulliNB(alpha=1, binarize=None), (X > 0).astype(float), (Q > 0).astype(float)),
    ("gaussian", GaussianNB(var_smoothing=1e-9), X, Q),
]:
    own = SmallNB(kind).fit(train, y)
    library.fit(train, y)
    probabilities = own.predict_proba(query)
    print(kind, "预测", own.predict(query), "概率\n", probabilities.round(4))
    assert np.allclose(probabilities.sum(1), 1)
    assert np.allclose(probabilities, library.predict_proba(query), atol=1e-10)
    assert np.allclose(np.exp(own.predict_log_proba(query)).sum(1), 1)
```

该例三种概率与库结果在容差内一致。全零查询对Multinomial给先验 `[0.5,0.5]`，Bernoulli约 `[0.3333,0.6667]`，因为缺席也贡献证据；Gaussian把零当真实测量，约 `[0.018,0.982]`，不是“所有字段缺失”。模型不同，零输入含义不同。

这是稠密小例子。大型词袋要用稀疏矩阵，Multinomial预测约 $O(nnz(X)K)$；稠密约 $O(NdK)$。Gaussian仍需按每类/每维评价密度。NB通常快，但不存在所有数据上“比SVM快几个数量级”的保证；线性SVM/Logistic预测也只是矩阵乘。

## 6. 完整中文文本管线：词表、分类、校准都防泄漏

以下文档人为用空格分词，不假装默认 `CountVectorizer` 能自动完成中文语义分词。真实文本先明确用词切分还是字符n-gram，再按事件/来源/时间隔离重复数据。

校准器包住**整个管线**，让每个校准折的词表也只在该折训练样本拟合。若先全训练数据拟合词表/IDF，然后只对分类器内部做CV，校准留出折的信息可能已经参与表示学习。

```python
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB, BernoulliNB
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.calibration import CalibratedClassifierCV
from sklearn.metrics import precision_score, recall_score, log_loss

train_text = ["免费 奖品 领取", "中奖 免费 奖品", "领取 优惠 免费", "奖金 中奖 领取",
              "会议 项目 报告", "项目 进度 会议", "报告 进度 审核", "会议 审核 项目"]
train_y = [1, 1, 1, 1, 0, 0, 0, 0]
test_text = ["免费 领取 奖品", "会议 项目 进度", "中奖 奖金", "审核 报告"]
test_y = [1, 0, 1, 0]

def vectorizer(kind="count", binary=False):
    cls = CountVectorizer if kind == "count" else TfidfVectorizer
    return cls(tokenizer=str.split, token_pattern=None, lowercase=False, binary=binary)

models = {
    "词频NB": make_pipeline(vectorizer(), MultinomialNB(alpha=1)),
    "出现NB": make_pipeline(vectorizer(binary=True), BernoulliNB(alpha=1, binarize=None)),
    "TFIDF-NB": make_pipeline(vectorizer("tfidf"), MultinomialNB(alpha=0.1)),
    "TFIDF-Logistic": make_pipeline(vectorizer("tfidf"), LogisticRegression(max_iter=2000)),
    "交叉拟合校准NB": CalibratedClassifierCV(
        make_pipeline(vectorizer(), MultinomialNB(alpha=1)), cv=2, method="sigmoid"),
}
for name, model in models.items():
    model.fit(train_text, train_y)
    prediction, probability = model.predict(test_text), model.predict_proba(test_text)
    print(name, "precision", precision_score(test_y, prediction, zero_division=0),
          "recall", recall_score(test_y, prediction, zero_division=0),
          "logloss", round(log_loss(test_y, probability), 4))
```

校准需要足够的每类样本、合适分折，微型例子仅验证API和信息流；这几条特别容易分的文本不证明真实垃圾过滤效果。本次所有管线在4条留出文本上Precision/Recall均1.0，但词频NB与校准NB的logloss约0.0752/0.3147，校准没有在这小样本上改善。`method="sigmoid"`学习分数到概率的S形映射，多类通常逐类映射再归一化；不能简单说“自动学出真实概率”。数据多时可比较isotonic，但它也有过拟合风险。

评估校准需看Brier/log loss和可靠性图：某概率分箱中平均预测概率与实际正类比例是否接近。校准可能改善概率而不改善准确率，甚至改变类别排序；遇到部署先验或语言漂移要重新验证，不可只保留一个训练期logloss。

## 7. 模型选择与失效诊断

| 问题 | 候选与检查 |
|---|---|
| 非负词频/权重 | MultinomialNB与稀疏Logistic/线性SVM同划分比较 |
| 二元存在特征 | BernoulliNB；是否应把缺席当证据、词表是否过大 |
| 连续类内近高斯特征 | GaussianNB；类内直方图、方差下限、相关性 |
| 类别数量不平衡 | 检查每类Recall/Precision、先验与预测阈值，不只准确率 |
| 混合连续/二元/类别 | 可分别选似然再加共同类别先验一次；跨组条件独立仍需说明 |
| 词义组合或XOR交互 | 比较n-gram、组合特征、树/其他表示；NB的单列信息可能不足 |
| 可靠概率需求 | 使用训练期交叉拟合校准，独立验证概率与漂移 |

先验正常0.99、垃圾0.01时，垃圾后验占优需似然比超过99，**不是先验一定压倒所有证据**。任意把先验改50/50会改变目标，不自动修复真实业务概率；过采样也改变训练分布，应依据部署类别比例与代价解释。

NB相对Logistic的常见倾向是计数估计快、强假设可能小样本稳定；判别模型更直接针对分类损失。但“1000以下NB必好、超过50000Logistic必好”不成立。高维稀疏Logistic有正则化，并不需要样本数大于每个词维度才能训练。概率校准、数据量阈值、NB/LR曲线交点都依赖任务。

不要因为标准化产生负值就盲目切Gaussian，也不要为通过Multinomial输入检查而平移所有值。先看特征生成机制，再选模型。常规计数无需缩放至均值0；词频归一化、TF-IDF、特征加权则会改变模型，属于可验证的选择。

## 8. 练习、学习曲线与参考答案

1. 朴素假设是什么？**答案：**类条件的简化分布，Bernoulli/Gaussian是列条件独立；词频Multinomial更精确是条件独立token采样。总体独立不是条件。
2. 平滑能否处理完全新词？**答案：**不能自动扩大训练词表；已知词类内零计数才按公式平滑，新词忽略或有训练的UNK。$\alpha$大把词概率趋向均匀，但何处最佳取决于验证。
3. “免费”两次、“钱”一次如何评分？**答案：**$\log\pi_c+2\log\theta_{c,免费}+\log\theta_{c,钱}$；多项式词缺席贡献0。归一化时减共同logsumexp，联合分数不能直接叫对数后验。
4. Gaussian与Multinomial怎么选？**答案：**先看类内连续分布还是非负词次数；不是按二/多类别选择。Gaussian有独立列方差时可为二次边界。
5. $\alpha=0.01,0.1,1,10,100$实验如何做？**方法：**固定训练/验证，记录每类指标与概率损失，重复划分；最终测试不参与选alpha。全部alpha准确率一样也可能，因为数据太简单，不能编造峰值。
6. 检查“机器/学习”相关如何计算？**方法：**先用每份文档二值事件，在同一类别内估两边缘与共现概率，比较 $P(A,B\mid c)$ 和 $P(A\mid c)P(B\mid c)$，再检查加入/删除冗余特征对保留集预测和校准的影响。词频期望乘积不是这个二值独立检验。
7. 实现Bernoulli并比较何时赢？**答案：**第5节完整实现包含未出现项，第6节给完整管线；胜负是实验结果，不能预写短文必胜。
8. NB与Logistic从100到10000样本学习曲线怎么比？**方法：**固定独立最终评估集，对每种训练规模从开发数据抽多个分层子集，两个完整管线共享这些子集；每个规模内部验证参数，分别记录均值/波动、训练时间、类别指标与logloss。若没有交点，报告没有，不强行宣布某行数必反超。当前微型文本与上游合成计数示例不替代这项真实文本规模实验。
9. 完整垃圾过滤为什么不用准确率单独验收？**答案：**多数正常时恒正常已很高；误封正常与漏垃圾代价不同，需Precision/Recall、校准、阈值成本、重复事件隔离和时间外推，示例参见第6节。
10. 哪些概率失败不是校准器就能解决？**答案：**交互表示缺失、词表错位、标签泄漏、分布漂移；校准仅重新映射分数，不恢复丢失信息。
