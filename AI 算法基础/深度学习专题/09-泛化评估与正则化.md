# 09｜泛化、评估与正则化

> 先修：数据划分、训练误差、基本概率。先用真实划分诊断过拟合，double descent 与高维几何作为解释视角，不作为继续盲目加大模型的理由。

> 主要吸收 Understanding Deep Learning 第 8～9 章及配套 Notebook。  
> 目标：不只会看训练/验证曲线，而是理解误差来自哪里、为什么过参数化网络仍能泛化，以及各种正则化到底在约束什么。

## 1. 泛化误差不是单一来源

预测误差可以从三个层面理解：

- **不可约噪声**：标签或观测本身存在随机性；
- **偏差（bias）**：模型族或训练过程不足以表达真实规律；
- **方差（variance）**：模型对训练集的随机变化过于敏感。

平方损失、条件噪声和独立训练/测试等前提下的偏差—方差分解提醒我们，具体推导见[问题建模与泛化诊断](../机器学习专题/06-问题建模基线与泛化诊断.md)：

> 训练误差低，不等于测试误差低；真正关心的是模型对未见数据的稳定性。

在深度学习中，模型通常远超“刚好拟合数据”所需的容量，因此不能只用“容量越大越容易过拟合”的经典直觉判断。

## 2. 数据集划分的职责

- **训练集**：优化参数；
- **验证集**：选择超参数、模型、阈值和训练轮数；
- **测试集**：在所有选择结束后，只用于估计最终泛化性能。

如果反复根据测试集修改模型，测试集就事实上变成了验证集。

对于小数据集，应优先考虑交叉验证；对于时间序列、图、用户行为等有结构的数据，划分必须尊重时间、实体或边的依赖关系，避免泄漏。

## 3. 偏差—方差权衡在深度网络中的变化

经典统计学习里，模型容量增大通常经历：

```text
欠拟合 → 最佳复杂度 → 过拟合
```

现代深度学习中常出现 **double descent（双下降）**：

1. 小模型阶段：增加容量降低偏差；
2. 接近插值阈值时：测试误差可能上升；
3. 进入高度过参数化后：继续增大模型，测试误差反而再次下降。

这说明“参数量 > 样本数”本身并不能判定模型会过拟合。

## 4. 为什么过参数化模型仍能工作

关键不只在“模型能表示多少函数”，还在于**训练算法倾向于找到哪一类解**。

影响最终解的因素包括：

- 参数初始化；
- SGD 的随机性；
- 学习率与 batch size；
- 网络结构；
- 显式正则项；
- 数据增强；
- 训练停止位置。

因此现代深度学习中的泛化更适合写成：

```text
模型族
+ 数据分布
+ 优化算法
+ 初始化
+ 训练噪声
+ 正则化
→ 最终函数
```

## 5. 显式正则化

### L2 / Weight Decay

目标函数：

$$
\mathcal L_{\mathrm{reg}}(\theta)=\mathcal L(\theta)+\lambda\|\theta\|_2^2
$$

直觉是限制权重规模，使模型倾向于更平滑、较低复杂度的解。

注意：

- L2 penalty 与 decoupled weight decay 在某些优化器中并不完全等价；
- 正则强度必须与学习率、优化器和参数化共同考虑。

## 6. 隐式正则化

即使没有显式 penalty，训练过程本身也会偏向某些解。下列因素包含优化路径带来的隐式偏置，也包含数据与架构的显式设计，不能全部理解成同一种惩罚。

典型来源：

- Gradient Descent / SGD 的优化路径；
- mini-batch 噪声；
- early stopping；
- 初始化尺度；
- 架构中的参数共享和局部连接；
- normalization；
- 数据增强。

重要结论：

> “没有写正则项”不等于“没有正则化”。

## 7. Early Stopping

训练集 loss 往往继续下降，但验证误差可能先降后升。

Early stopping 本质上限制了优化过程能够走多远，因此同时是：

- 训练策略；
- 超参数选择；
- 隐式正则化。

## 8. Dropout

训练时随机屏蔽部分激活：

$$
\tilde h=\frac{m\odot h}{1-p},\qquad m_j\sim\operatorname{Bernoulli}(1-p)
$$

这里 $p\in[0,1)$ 是丢弃概率，$m$ 是逐元素保留 mask，除以 $1-p$ 使训练时激活期望保持不变；这是常见的 inverted dropout，推理时不再缩放。

它可以理解为：

- 对内部表示注入噪声；
- 降低单一路径共适应；
- 近似训练大量共享参数的子网络。

实际是否有效依赖模型架构；在现代大规模 Transformer 中通常不能机械照搬早期 CNN/MLP 的经验。

## 9. 集成学习

若多个模型误差不完全相关，平均预测通常能降低方差。

常见方式：

- 独立训练多模型；
- 不同初始化；
- 不同数据子集；
- 不同架构；
- checkpoint / snapshot ensemble。

收益来自**误差多样性**，而不是简单“模型越多越好”。

## 10. 数据增强

数据增强应保持任务语义，同时扩展训练分布。

它同时实现：

1. 增加有效样本多样性；
2. 将领域先验注入模型；
3. 对某些变换建立不变性或等变性。

增强错误会造成 label corruption，因此应从任务假设出发，而不是堆操作。

## 11. 迁移学习与多任务学习

### Transfer Learning

从源任务获得表示，再适配目标任务。

适合：

- 目标数据较少；
- 源任务与目标任务共享结构；
- 预训练模型具备更丰富表征。

### Multi-task Learning

多个任务共享部分参数，通过联合训练形成归纳偏置。

风险包括：

- 任务冲突；
- 梯度方向冲突；
- 数据量不平衡；
- 一个任务压制其他任务。

## 12. 贝叶斯视角

贝叶斯方法不是寻找单一最佳参数，而是建模：

$$
p(\theta\mid D)
$$

预测时积分：

$$
p(y\mid x,D)=\int p(y\mid x,\theta)p(\theta\mid D)\,d\theta
$$

实际深度网络中常通过：

- 变分近似；
- MCMC；
- MC Dropout；
- SWAG / MultiSWAG；
- deep ensembles（通常并非严格的后验采样）；

估计参数或函数不确定性。近似方法的置信度仍需校准，不能自动保证分布外可靠。

## 13. 实验诊断顺序

遇到泛化问题时优先检查：

1. 是否存在数据泄漏？
2. train/val/test 是否同分布？
3. 训练误差是否已经足够低？
4. 是高偏差还是高方差？
5. 模型容量是否不足或过强？
6. 正则化是否过度？
7. 数据增强是否破坏标签语义？
8. batch size / learning rate 是否改变了优化路径？
9. validation 是否足够稳定？
10. 指标是否与真实业务目标一致？

## 15. 高维空间与泛化

最新版 UDL 第 8 章强调：泛化问题不能只靠二维直觉理解，因为真实深度学习任务处于高维空间。

### Curse of Dimensionality

若每个输入维度只粗略量化成 10 个取值，$D$ 维空间就有：

$$
10^D
$$

种组合。维度上升后，有限训练数据只覆盖输入空间极小的一部分；测试点甚至可能在训练点凸包之外，不能笼统视为几何插值。

这说明泛化依赖模型的归纳偏置与数据的有效结构：需要判断哪些方向可平滑推广、哪些是分布外区域。

### 高维空间的反直觉性质

对独立、各向同性或有相应集中性质的分布，在适当维度和样本数条件下常见下列现象；不是所有高维数据都满足：

- 随机向量彼此接近正交；
- 样本到原点的距离会集中在较窄范围；
- 高维球的大部分体积靠近表面；
- 单位半径球在包含它的 $[-1,1]^D$ 立方体中所占体积随维度快速下降；
- 随机点之间“最近距离 / 最远距离”的比值趋近 1。

因此，低维可视化适合建立直觉，但不能直接当作高维神经网络行为的证明。

### 与 Double Descent 的联系

进入插值区以后，增加容量不会继续降低训练误差，而是改变训练点之间的函数形状。高度过参数化模型可能拥有更多自由度去选择更平滑的插值，从而出现第二次测试误差下降。

评估模型容量时，不应只问“是否能拟合训练集”，还要问：

- 数据流形附近如何插值；
- 离开数据流形后如何行为；
- 优化算法偏向哪类零训练误差解。

## 用两组曲线决定下一步

情形 A：训练误差 0.02、验证误差 0.30；情形 B：训练误差 0.28、验证误差 0.30。两组验证误差相同，诊断顺序不同：A 先检查泄漏、分布差异、过拟合和正则；B 先检查标签/优化实现、容量和欠拟合。单凭两点还不能作最终归因，应看学习曲线和样本。

## 16. 正则强度与训练/评估模式的完整边界

误差差距先由同一个冻结参数状态、相同评价模式和同样指标计算。在线训练过程中“每条样本先预测再更新”的平均分，与训练完后`eval`的验证分不是同一对象；Dropout与BatchNorm还会改变模式。不要按差距3%、10%、20%固定推荐一套强度，先查数据划分、分布变化、标签与优化状态，再做对照。

L1目标 $L+\lambda\sum_i|w_i|$在非零处增加 $\lambda\operatorname{sign}(w_i)$；0处是次梯度区间，普通梯度小步不保证精确稀疏。近端方法先走任务梯度，再软阈值 $w\leftarrow\operatorname{sign}(u)\max(|u|-\eta\lambda,0)$。例如 $u=(0.1,-0.4,0.02)$、$\eta\lambda=0.05$，结果为 $(0.05,-0.35,0)$。L1/L2取和或均值、是否包含偏置、权重尺度与优化器都会影响强度意义；AdamW与L2区别见[优化专题](05-深度学习优化.md)。

### 16.1 Dropout不只是前向乘mask

若保存同一次前向的缩放mask $a=m/(1-p)$，反向同样乘它：$\partial L/\partial h=a\odot\partial L/\partial\tilde h$。上游正文网络遗漏了这个链式项，独立程序已补上；本库采用明确缓存与梯度核查，不能把两个版本当同样正确的实现。

```python
import numpy as np
rng = np.random.default_rng(42)
x = np.array([1., 2., 3., 4.])
p = 0.25
mask = (rng.random(x.shape) >= p)/(1-p)
dout = np.array([0.2, -0.4, 0.8, 1.])
out = x*mask
analytic = dout*mask
# 检查同一固定mask的计算图，差分时不能重新随机抽取。
numeric = np.empty_like(x)
for i in range(len(x)):
    d = np.zeros_like(x); d[i] = 1e-6
    numeric[i] = (np.dot((x+d)*mask, dout)-np.dot((x-d)*mask, dout))/(2e-6)
assert np.allclose(analytic, numeric, atol=1e-9)
trials = (rng.random((10000, len(x))) >= p)/(1-p)
print("多次前向均值", (trials*x).mean(axis=0).round(3).tolist())
print("固定mask反向检查", True)
# 对[N,C,H,W]特征，通道Dropout共享每个样本每个通道的空间mask。
feature = np.ones((2, 3, 4, 4))
channel_mask = (rng.random((2, 3, 1, 1)) >= p)/(1-p)
spatial = feature*channel_mask
assert np.all(spatial == spatial[:, :, :1, :1])
print("通道mask", channel_mask[:, :, 0, 0].tolist())
```

期望接近 `[1,2,3,4]`，单次会出现0或按 $1/(1-p)$放大。必须 $0\le p<1$；p=0是恒等，p=1需明确特殊定义而不能直接除0。Dropout保的是该激活条件期望，不保证后续非线性网络输出等于所有子网络算术平均；“2^N种mask”是组合直觉，不是把2^N网络各自完整训练的等价证明。

普通Dropout逐元素，空间/通道Dropout整张feature map一起屏蔽；选择看相关结构。SELU的自归一化配方需相应AlphaDropout等条件，普通inverted Dropout不能自动维持该分布。推理通常关闭Dropout，MC Dropout是另行明确的不确定性估计设计，不能顺带让BatchNorm也进入训练模式。

### 16.2 BatchNorm、LayerNorm、RMSNorm按哪条轴计算

对 $X\in\mathbb R^{B\times D}$：BatchNorm每特征跨B行估均值方差，LayerNorm每行跨D列估计，RMSNorm每行除均方根但不减均值。对Transformer `[B,T,D]`，常见LN/RMS沿每token最后D维，不混入其他token；`normalized_shape`不同会改变所用轴。CNN BatchNorm通常跨B及空间轴统计每通道，故batch=1且空间元素足够时不等于完全无法估计。

| 层 | 训练与推理所用统计 | 要关注的状态/限制 |
|---|---|---|
| BatchNorm | 训练用当前批/空间统计；常见eval用running统计 | 小有效样本或非独立元素使估计差；无固定“至少32”门槛 |
| LayerNorm | 每输入自己选定特征轴 | 不依赖其他batch样本；均值方差行为不因train/eval改变 |
| RMSNorm | 每输入自己的均方根 | 保尺度但不保中心化；可学习gamma使最终RMS不必为1 |

常见形式分别为 $(x-\mu)/\sqrt{\operatorname{Var}(x)+\epsilon}$与 $x/\sqrt{\operatorname{mean}(x^2)+\epsilon}$，再施加各层定义的仿射参数。PyTorch BatchNorm训练归一化用有偏方差，更新`running_var`用无偏估计；上游玩具代码两者都除B，不与框架逐值等价。PyTorch BN的`momentum=0.1`表示10%新统计、90%旧统计，和优化器momentum=0.9含义不要互换。`track_running_stats=False`时eval也可能用当前batch统计，不能泛称eval永远用历史均值。

```python
import numpy as np
rng = np.random.default_rng(8)
X = rng.normal(3., 2., (6, 4))
eps = 1e-5
mu, var = X.mean(axis=0), X.var(axis=0, ddof=0)
xhat = (X-mu)/np.sqrt(var+eps)
dout = rng.normal(size=X.shape)
B = len(X)
dx = (B*dout-dout.sum(axis=0)-xhat*(dout*xhat).sum(axis=0))/(B*np.sqrt(var+eps))
def value(A):
    normalized = (A-A.mean(axis=0))/np.sqrt(A.var(axis=0)+eps)
    return np.sum(normalized*dout)
num = np.zeros_like(X)
for idx in np.ndindex(X.shape):
    shift = np.zeros_like(X); shift[idx] = 1e-6
    num[idx] = (value(X+shift)-value(X-shift))/(2e-6)
assert np.allclose(dx, num, atol=1e-8)
running_mean = 0.9*np.zeros(4)+0.1*mu
running_var = 0.9*np.ones(4)+0.1*X.var(axis=0, ddof=1)
eval_out = (X-running_mean)/np.sqrt(running_var+eps)
ln = (X-X.mean(axis=1, keepdims=True))/np.sqrt(X.var(axis=1, keepdims=True)+eps)
rms = X/np.sqrt(np.mean(X*X, axis=1, keepdims=True)+eps)
print("BN反向最大误差", float(np.max(np.abs(dx-num))))
print("LN每行均值", ln.mean(axis=1).round(6).tolist())
print("RMS每行均方根", np.sqrt(np.mean(rms*rms, axis=1)).round(6).tolist())
print("BN训练/初期eval相同?", bool(np.allclose(xhat, eval_out)))
```

gamma=1、beta=0时LN行均值约0、RMS均方根接近1而均值不必0；BN训练和刚开始积累running统计的eval可以明显不同。BN反向包含均值与方差对每个输入的依赖，不能只把输出梯度除标准差。正式使用自动微分层，手写有限差分只验证本例小矩阵。

归一化主要调尺度和优化几何，batch噪声有时带正则作用；不等同“自动消除过拟合”。关于内部协变量变化或景观平滑的研究解释不能当作所有架构/所有数据的唯一已证机制。RMSNorm不保证固定10%加速或相同准确率，实际需同硬件、相同输入shape与完整训练比较。Pre-LN与Post-LN的残差位置也有训练行为差异，连接[注意力专题](04-注意力机制与Transformer.md)，不把LN固定为只能在残差之后。

## 17. 数据增强、软标签与早停怎样验收

增强要求保持任务关系：图像分类可翻转不代表字符6/9可任意旋转；检测/分割要同步变换框或mask；时间序列随机打乱可能毁掉方向；文本同义词替换可改变否定与术语，语音调速/变调也可能改变目标。增强样本不是新的独立真实测量，训练增强不能造成近重复跨验证边界。

Mixup可用 $x'=\lambda x_i+(1-\lambda)x_j$、$y'=\lambda y_i+(1-\lambda)y_j$；CutMix替换图块并按面积混标签。Label smoothing让硬标签变成软目标，减少训练对极端信心的推动，但可能影响校准和蒸馏。都要明确任务语义与支持软标签的loss，不按“gap大就增强越强越好”叠加。

Early stopping只看验证指标，保存**当时独立复制**的最佳模型状态，patience次未达到`min_delta`改善后停。PyTorch `best=model.state_dict()`可继续引用变动的张量，应使用deepcopy或显式clone；恢复最佳权重后再做一次固定eval。若继续训练，还需同一时刻的optimizer/scheduler/随机状态。首个最佳epoch、loss最佳与accuracy最佳可能不同，预先定义主标准。

源练习要求每轮看“test loss”并据此停，应改称validation；真正测试留到全部选择冻结后。模式切换也要明确：`model.eval()`改变Dropout/BN等行为，`no_grad()`/`inference_mode()`减少自动微分记录，二者不互相替代，也不保证所有硬件运算逐bit确定。完整CPU验证选择、快照恢复及模式检查见[实践专题](17-初始化优化器与学习率实践.md)。

### 17.1 正则实验参考答案

1. 比较Dropout、label smoothing及二者组合，用什么指标？**参考：**同冻结模型eval下训练/验证loss与任务指标、同划分多种子、相同预算；仅缩小gap但两者都变差不算好。软标签训练目标与硬标签评估loss要分开解释。
2. BN能否保证更高lr不发散？**答案：**不能。对几档lr记录第一异常位置和更新范数，排错loss、数据与状态；成功个案不是普遍保证。
3. spatial Dropout要怎样实现？**答案：**对 `[N,C,H,W]`采 `[N,C,1,1]`mask广播；反向复用同mask。不要误把整个batch同通道都关掉而不说明设计。
4. LN/RMSNorm4层实验要证明什么？**参考：**匹配初始权重、预算、dtype与输入，报告验证结果、首层梯度、热身后重复耗时和方差；允许RMS较慢或结果不同，不能以“必须10%更快”作为验收答案。
5. 1000轮中第120轮validation最佳、patience20在140轮停，省多少？**答案：**计划1000实际140，约省860轮；加载120轮快照。实际是否在140停取决于`min_delta`、比较和计数约定，测试集不参与选择。
