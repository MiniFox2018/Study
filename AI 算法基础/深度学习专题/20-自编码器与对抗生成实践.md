# 20｜自编码器与对抗生成实践

[深度生成模型](10-深度生成模型.md)维护分布、GAN/Flow/VAE/Diffusion的统一理论，本章深入可运行的AE/VAE、对抗目标、成对图像翻译和StyleGAN机制。先修是概率、链式求导和MLP，后面的Pix2Pix/Style卷积部分再接CNN；不要求先跑完整Transformer capstone。程序只用CPU合成数据，不下载模型或真实图像，不把机制输出写成真实生成质量。

## 1. 模型分类要分清概率对象与接口

可以分别问：建模pixels/连续latent/离散码？能否算密度或只有下界/采样接口？训练是似然、变分、对抗、去噪还是速度回归？采样是自回归、一次前向、SDE或ODE？这些是多个轴，不是五个互斥篮子。离散code+AR是表示方式与AR目标的组合；score模型可对应扩散，flow matching学velocity而非自动等于score。可算latent似然不自动可算经过有损decoder的像素似然。

连续随机变量在某点的概率通常是0，density可以大于1；区间概率是密度积分。自回归和适当可逆Flow都能提供相应对象的可计算密度，不是只有Flow能做likelihood。KDE对数据真实分布是估计，但其给定模型密度可以精确求值，“近似真实密度”与“只会给ELBO”不同。

来源代码的`histogram_density`以查询x为中心移动区间，更准确是均匀核KDE，不是固定分箱直方图。`implicit_generator`均匀抽训练点再加标准差.1的高斯，实际密度是 $N^{-1}\sum_i\mathcal N(x;x_i,.1^2)$，完全可求；代码没有提供接口不证明分布隐式，更不是训练了GAN。

历史可按训练信号的变化理解，论文预印本与会议年份不必相同：

| 里程碑 | 解决的学习问题 | 在本库的连接 |
|---|---|---|
| VAE，2013预印本 | 可用变分后验与路径梯度训练潜变量模型 | 第3～4节ELBO/KL/重参数化 |
| GAN，2014 | 不直接计算数据密度，用学得判别信号训练采样器 | 第5～6节对抗目标与两网更新 |
| Pix2Pix，2016预印本/2017会议 | 利用成对条件与局部判别做图像翻译 | 第8节pair/L1/PatchGAN |
| VQ-VAE，2017 | 学离散latent，再把先验建模与decoder分开 | 第4节量化链与音频12 |
| StyleGAN，2018预印本/2019会议；StyleGAN2，2019预印本/2020会议 | 分层风格控制、权重解调与正则改进 | 第10～13节，不把全系列叫AdaIN |
| DDPM，2020；score SDE，2020预印本/2021会议 | 将去噪、概率反向链与连续时间视角连接 | 主10及扩散/流专题，不把score等同velocity |

方法可以成为新模型的组件，并不因后续路线出现就全部过时。不能把未公开服务或每年产品名单当作已知数学演进。

### 1.1 完整显式密度与区间概率核对

```python
import numpy as np
from scipy.stats import norm
rng=np.random.default_rng(42)
N=2000;component=rng.random(N)<.4
samples=np.where(component,rng.normal(-2,.6,N),rng.normal(2,.9,N))
def sampled_then_noise_density(x,bandwidth=.1):
    if bandwidth<=0 or not np.isfinite(bandwidth):raise ValueError('正有限带宽')
    x=np.asarray(x,dtype=float)
    return norm.pdf((x[...,None]-samples)/bandwidth).mean(-1)/bandwidth
true_probability=.4*(norm.cdf((.5+2)/.6)-norm.cdf((-.5+2)/.6))+.6*(norm.cdf((.5-2)/.9)-norm.cdf((-.5-2)/.9))
kde_probability=(norm.cdf((.5-samples)/.1)-norm.cdf((-.5-samples)/.1)).mean()
# 重采样+噪声与有限Gaussian-mixture是同一分布，整轴积分为1。
wide_mass=(norm.cdf((20-samples)/.1)-norm.cdf((-20-samples)/.1)).mean()
assert np.isclose(wide_mass,1) and 0<true_probability<.05
print('真实混合区间概率',true_probability,'重采样噪声模型区间概率',float(kde_probability))
print('x=0密度',float(sampled_then_noise_density(0.)))
```

源文档的.38/.41不是这组±2均值混合的有效核对值；真实概率约.0295，有限样本估计有波动。训练点+小噪声仍可能记住数据，明确sampler和density不等于泛化或隐私保证。模型历史有用的是目标与机制演进，不保未经证据的产品内部结构、当前赢家、GPU成本或固定“快100倍”。总成本还包括条件编码、采样、latent解码、后处理与调度；普通VAE/GAN常可一次decoder/G前向，自回归与迭代生成有各自序列/步数成本。一次forward不等没有batcher或调度需求，静态batch也不是所有请求/尺寸/时限下都最优。比较速度需同任务/分辨率/条件/精度/质量覆盖与端到端编码解码成本。

## 2. 普通AE、去噪、稀疏与潜变量分布

AE学习 $x\to f_\phi(x)=z\to g_\theta(z)=\hat x$，用重建损失塑造表示。低维瓶颈能压缩，宽瓶颈也可能在正则/去噪/数据结构下学习有用特征；不能说它必记忆或“宽就学不到东西”。若只训练重建，没有定义latent先验与采样规则，直接对任意随机z解码没有质量保证。可以另拟合latent分布形成采样器，因此AE不是原则上永远不能生成。

Denoising AE以污染输入重建干净目标；稀疏AE加入激活约束；contractive AE限制局部编码Jacobian。这些改变要保存污染/正则假设并用留出任务验证，不把重建低错率当全部信息保留。异常检测若训练没学到所有正常模式、或异常也容易重建，重建误差会误判，需要真实正负样本与阈值协议。

观测似然决定损失：固定方差高斯对应按尺度的平方误差与常数，独立Bernoulli对应二值的BCE，categorical对应分类交叉熵。连续灰度用Bernoulli式损失是一种建模/代理选择，不自动是真二值概率模型。NN decoder预测均值还是完整分布的参数、输出范围和数据归一要匹配。

### 2.1 完整普通AE与去噪AE桥梁

这两种AE的encoder都确定性地产生z，参数正常训练；不引入mu/logvar/KL或训练时latent采样。普通AE用clean输入重建clean；去噪AE污染**输入**，目标仍是clean，不能把noise当监督目标。留出集独立生成，评测clean与固定污染输入两种情况；重构表现不自动证明z可按标准正态生成。

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1)
def dataset(n,seed):
    gen=torch.Generator().manual_seed(seed)
    sign=torch.where(torch.rand(n,1,generator=gen)<.5,-1.,1.)
    center=sign*torch.tensor([[1.,1.,1.,1.,-1.,-1.,-1.,-1.]])
    return center+.2*torch.randn(n,8,generator=gen)
class AE(nn.Module):
    def __init__(self):
        super().__init__();self.enc=nn.Sequential(nn.Linear(8,24),nn.ReLU(),nn.Linear(24,2))
        self.dec=nn.Sequential(nn.Linear(2,24),nn.ReLU(),nn.Linear(24,8))
    def forward(self,x):
        z=self.enc(x);return self.dec(z),z
train,held=dataset(96,1),dataset(32,2)
gen=torch.Generator().manual_seed(16);noisy_held=held+.3*torch.randn(held.shape,generator=gen)
for sigma in [0.,.3]:
    torch.manual_seed(15);model=AE();opt=torch.optim.Adam(model.parameters(),lr=.003)
    with torch.no_grad():before=float(F.mse_loss(model(held)[0],held))
    for _ in range(200):
        corrupted=train+sigma*torch.randn_like(train)
        prediction,z=model(corrupted);loss=F.mse_loss(prediction,train)
        opt.zero_grad(set_to_none=True);loss.backward();opt.step()
    model.eval()
    with torch.no_grad():
        clean_error=float(F.mse_loss(model(held)[0],held));noise_error=float(F.mse_loss(model(noisy_held)[0],held))
        reconstruction,z=model(held)
    assert reconstruction.shape==held.shape and z.shape==(len(held),2) and clean_error<before
    print('输入noise sigma',sigma,'初始/heldout clean/固定noisy MSE',before,clean_error,noise_error)
```

与下一节VAE对照：AE是一条确定性z路径；VAE用分布编码、重参数噪声及先验KL，并指定观测似然尺度。AE的MSE按全元素mean，VAE示例Gaussian按每样本NLL求和，数值量纲不同，不能拿loss数直接排名。

## 3. ELBO推导、KL与重参数化

$q_\phi(z|x)$支持应覆盖积分所需区域，利用Jensen：

$$\log p_\theta(x)=\log E_q[p_\theta(x,z)/q_\phi(z|x)]\ge
E_q[\log p_\theta(x|z)]-KL(q_\phi(z|x)\|p(z)).$$

更精确的差是到真实posterior的KL，见主章第5节。最小化负ELBO是**负重构log-likelihood+KL**，不是 `logp≥正重构误差−KL`。Gaussian的SSE是否sum/mean、固定方差及batch归约改变相对KL权重，不能在一个任务用`MSE.mean`而另一个用每样本SSE再称相同β。

若 $q=\mathcal N(\mu,diag(e^\ell)),p=\mathcal N(0,I)$，

$$KL=\frac12\sum_j(e^{\ell_j}+\mu_j^2-1-\ell_j),\quad
\partial_\mu KL=\mu,\quad\partial_\ell KL=(e^\ell-1)/2.$$

$z=\mu+e^{\ell/2}\odot\epsilon,\epsilon\sim\mathcal N(0,I)$，$\partial_\mu z=I$、$\partial_\ell z=\frac12e^{\ell/2}\odot\epsilon$。随机分布的参数依赖通过这个路径估梯度，不是“任何随机采样永远不可微”。也可用softplus参数化标准差，不能说它一律陷阱；logvar的exp也有overflow/underflow风险。

### 3.1 完整手写路径导数与裁剪条件

源手反向对clip后的logvar继续传原梯度，raw输出超[-6,6]时不正确；未触及边界的样本不受此问题影响。裁剪点本身不可微，有限差分避开边界。下面以固定epsilon和线性decoder做所有mu/rawlogvar参数的梯度核对，包含剪裁活跃反例。

```python
import numpy as np
mu=np.array([.2,-.3]);raw=np.array([.1,8.]);eps=np.array([.7,-.4]);target=np.array([.4,.1])
W=np.array([[1.,.3],[-.2,.8]])
def objective(mu,raw):
    lv=np.clip(raw,-6,6);sigma=np.exp(lv/2);z=mu+sigma*eps;out=W@z
    recon=.5*np.sum((out-target)**2)
    kl=.5*np.sum(np.exp(lv)+mu*mu-1-lv)
    return recon+.2*kl
lv=np.clip(raw,-6,6);sigma=np.exp(lv/2);dz=W.T@(W@(mu+sigma*eps)-target)
dmu=dz+.2*mu
dlv=(.5*dz*sigma*eps+.1*(np.exp(lv)-1))*((raw>-6)&(raw<6))
error=0.
for x,g in [(mu,dmu),(raw,dlv)]:
    for i in range(len(x)):
        old=x[i];h=1e-6;x[i]=old+h;a=objective(mu,raw);x[i]=old-h;b=objective(mu,raw);x[i]=old
        error=max(error,abs((a-b)/(2*h)-g[i]))
assert error<1e-6 and dlv[1]==0
print('重参数/闭式KL/clip路径最大梯度误差',error)
```

β-VAE用 $L=NLL+\beta KL$。β1是普通负ELBO；β<1不保证仍为logp下界对应目标，β>1可看作加大惩罚但不是同一等权ELBO。高β不保证解耦，小β不保证更锐利。posterior collapse是z几乎不携带x信息/decoder忽视它，可因目标、强decoder、训练状态共同产生；看每维KL、latent响应、重构与prior样本，不一律用β>某数判断。

KL annealing、free bits和decoder能力调整是候选方法，非必救。free bits常将每维/组KL置最低预算，低于预算处不给继续压低的梯度；不等随意删掉所有小KL维度。先说明单位、分组和对ELBO的改动。聚合 $q(z)=E_{data}q(z|x)$ 与单个 $q(z|x)$不是同一分布，均值/协方差相近也不证明完整先验匹配。

## 4. 完整小VAE：Gaussian/Bernoulli与β对照

8维合成Gaussian mixture，train/heldout独立生成；编码输出mu/logvar，32宽MLP decoder。Gaussian固定观测标准差1，所以重构NLL为`.5*SSE+4log(2π)`；Bernoulli将同任务数据二值化，使用logits BCE。两类数据/观测单位不同，NLL不能直接排名。评测固定noise，报告重构项与KL；prior采样只输出向量，无图像质量宣称。

```python
import math
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1)
def data(n,seed):
    gen=torch.Generator().manual_seed(seed)
    sign=torch.where(torch.rand(n,1,generator=gen)<.5,-1.,1.)
    center=sign*torch.tensor([[1.,1.,1.,1.,-1.,-1.,-1.,-1.]])
    return center+.2*torch.randn(n,8,generator=gen)
class VAE(nn.Module):
    def __init__(self):
        super().__init__();self.enc=nn.Sequential(nn.Linear(8,32),nn.Tanh())
        self.mu=nn.Linear(32,2);self.lv=nn.Linear(32,2)
        self.dec=nn.Sequential(nn.Linear(2,32),nn.Tanh(),nn.Linear(32,8))
    def forward(self,x,eps):
        h=self.enc(x);mu=self.mu(h);lv=self.lv(h).clamp(-8,8)
        z=mu+torch.exp(.5*lv)*eps
        return self.dec(z),mu,lv

def terms(x,out,mu,lv,kind):
    if kind=='gaussian':recon=.5*(x-out).square().sum(1)+.5*8*math.log(2*math.pi)
    elif kind=='bernoulli':
        if not torch.all((x==0)|(x==1)):raise ValueError('本例Bernoulli需真正二值目标')
        recon=F.binary_cross_entropy_with_logits(out,x,reduction='none').sum(1)
    else:raise ValueError(kind)
    kl=.5*(lv.exp()+mu.square()-1-lv).sum(1)
    return recon,kl
train,held=data(96,1),data(32,2)
for kind,betas in [('gaussian',[.01,.1,1.,5.]),('bernoulli',[1.])]:
    x=(train>0).float() if kind=='bernoulli' else train
    test=(held>0).float() if kind=='bernoulli' else held
    for beta in betas:
        torch.manual_seed(3);model=VAE();opt=torch.optim.Adam(model.parameters(),lr=.003)
        for step in range(250):
            out,mu,lv=model(x,torch.randn(len(x),2));rec,kl=terms(x,out,mu,lv,kind)
            loss=(rec+beta*kl).mean();opt.zero_grad(set_to_none=True);loss.backward();opt.step()
        model.eval()
        with torch.no_grad():
            torch.manual_seed(4);out,mu,lv=model(test,torch.randn(len(test),2));rec,kl=terms(test,out,mu,lv,kind)
            sample=model.dec(torch.randn(3,2));sample=sample.sigmoid() if kind=='bernoulli' else sample
        assert torch.isfinite(sample).all() and sample.shape==(3,8)
        print(kind,'beta',beta,'heldout recon-NLL/KL',float(rec.mean()),float(kl.mean()))
        print('prior向量首四维',sample[0,:4].tolist())
```

不是每个图像latent都来自Gaussian VAE；NVAE是分层连续VAE，VQ-VAE/RVQ以离散码本量化，EnCodec等codec不自动属于同一ELBO家族。空间512²×3到64²×4是空间面积64倍、通道4/3倍、元素总数48倍，不是源码的两个32倍；真实压缩率还需量化/熵编码/容器，不拿float元素数当bits。

实际latent生成管线还需latent shape/scale/shift、posterior采样或均值、decoder输出范围和训练分布一致。普通text-to-image可能只在末尾decode，img2img/inpaint还需要输入encode；不能说每请求必调用VAE两次。Decoder激活也可能是显存瓶颈，但取决于分辨率、batch、denoiser和实现，不能断言总是最大峰。

Slicing常按batch拆开decoder；tiling按空间重叠切片、拼接/融合输出，边界和跨片归一统计可能改变结果。它们减少某部分峰值而不是保证整pipeline严格只用tile²内存或无损无缝；按具体库版本查官方接口并验证差异。fp16范围/BF16精度与内部累加、权重或force-upcast设置有关，遇NaN先查数值与模型合同，不一律宣称SD1x某分辨率以上必NaN、某个修复checkpoint永远最优。未安装diffusers或测大型pipeline。

VQ-VAE最近码查表、codebook/commitment loss、STE及encoder-decoder完整代码已在[神经音频编码的训练链](../感知与多模态专题/12-神经音频编码与说话人表征.md#6-训练离散瓶颈直通估计码本与承诺损失)维护。原K32练习可换同一向量量化模块用于8维数据，记录有效码数/熵及留出重构；不用20%使用率一票断言reset配置错误。离散/连续先验、训练目标与decoder条件分别说明。

## 5. GAN目标、标签与梯度不能互相替名

主章第2～3节推导经典D*与JS及Wasserstein。这里区分可实现目标（critic/logit a）：

| 目标 | D最小化 | G最小化 | 说明 |
|---|---|---|---|
| Logistic非饱和 | `softplus(-a_real)+softplus(a_fake)` | `softplus(-a_fake)` | D有sigmoid概率解释，G对a导数σ(a)−1 |
| 原minimax G | 同上 | `-softplus(a_fake)` | 等log(1−σ(a))，对a导数−σ(a) |
| Hinge | `relu(1−a_real)+relu(1+a_fake)` | `−a_fake` | D是无界分数，不能又接sigmoid |
| WGAN | `a_fake−a_real` | `−a_fake` | 需要Lipschitz约束；不是只换loss就足够 |
| Least-squares | 平方逼real1/fake0 | 平方逼fake1 | 标定/标签约定影响公式，不等于BCE |

D阶段fake detach，G阶段保留D到输入的梯度但冻结D参数。复用z可以，只要重新计算当前D/G的图与参数，fresh noise不是防“stale梯度”的必要条件。D准确率95%不必使非饱和G的logit梯度消失；真正还需检查D输入Jacobian、G路径、更新尺度和样本覆盖。

### 5.1 logits的梯度手算

```python
import torch
import torch.nn.functional as F
a=torch.tensor([-10.,0.,10.],dtype=torch.float64,requires_grad=True)
sat=-F.softplus(a);ns=F.softplus(-a)
gsat=torch.autograd.grad(sat.sum(),a,retain_graph=True)[0]
gns=torch.autograd.grad(ns.sum(),a)[0]
assert torch.allclose(gsat,-torch.sigmoid(a)) and torch.allclose(gns,-torch.sigmoid(-a))
# sigmoid(a)-1与-sigmoid(-a)数学等价，后者避免大正logit的数值抵消。
assert gns[0].abs()>.99 and gsat[0].abs()<.001
print('minimax/non-saturating对logit梯度',gsat.tolist(),gns.tolist())
```

WGAN-GP约束真实/生成之间插值点的输入梯度范数，有限点惩罚不等全空间严格1-Lipschitz；weight clipping是不同近似，容易限制容量。R1惩罚真实点上D输入梯度平方，目标梯度0，与GP期望范数1不是一回事。SN控制权重算子范数，BN/IN和其他非线性、估计误差仍影响整体条件。TTUR、LR比例、训练次数、输入噪声、minibatch判别都要用同数据/预算复核，不能由单曲线指定唯一病因或必救方。

## 6. 完整1D GAN：BCE、Hinge与WGAN-GP真实更新

合成两模态Gaussian，三种目标都实际做D/G交替更新。相同结构/seed/步数，但GP增加工作量，不能将loss值跨目标排序。0左右各分多少样本是粗模式检查，不证明位于真实±2峰或覆盖尾部。

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1)
def real(n):
    sign=torch.where(torch.rand(n,1)<.5,-1.,1.)
    return 2*sign+.4*torch.randn(n,1)
for objective in ['logistic','hinge','wgan-gp']:
    torch.manual_seed(4)
    G=nn.Sequential(nn.Linear(4,16),nn.LeakyReLU(.2),nn.Linear(16,1))
    D=nn.Sequential(nn.Linear(1,16),nn.LeakyReLU(.2),nn.Linear(16,1))
    og=torch.optim.Adam(G.parameters(),lr=.002,betas=(.5,.9));od=torch.optim.Adam(D.parameters(),lr=.002,betas=(.5,.9))
    g0=G[0].weight.detach().clone();d0=D[0].weight.detach().clone()
    for step in range(180):
        x=real(32);z=torch.randn(32,4);fake=G(z)
        od.zero_grad(set_to_none=True);ar,af=D(x),D(fake.detach())
        if objective=='logistic':ld=F.softplus(-ar).mean()+F.softplus(af).mean()
        elif objective=='hinge':ld=F.relu(1-ar).mean()+F.relu(1+af).mean()
        else:
            u=torch.rand(32,1);mixed=(u*x+(1-u)*fake.detach()).requires_grad_(True)
            grad=torch.autograd.grad(D(mixed).sum(),mixed,create_graph=True)[0]
            ld=af.mean()-ar.mean()+5*(grad.norm(dim=1)-1).square().mean()
        ld.backward();od.step()
        for p in D.parameters():p.requires_grad_(False)
        og.zero_grad(set_to_none=True);a=D(G(z))
        lg=F.softplus(-a).mean() if objective=='logistic' else -a.mean()
        lg.backward();assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in G.parameters());og.step()
        for p in D.parameters():p.requires_grad_(True)
    assert not torch.equal(g0,G[0].weight) and not torch.equal(d0,D[0].weight)
    with torch.no_grad():samples=G(torch.randn(400,4))
    assert torch.isfinite(samples).all()
    print(objective,'最终D/G loss',float(ld.detach()),float(lg.detach()),'左/右计数',int((samples<0).sum()),int((samples>=0).sum()))
```

记录环境的180步三种目标均出现粗模式覆盖不足；这不是由loss公式自动修复的问题。训练返回成功只证明实现的更新/梯度路径，没证明任意目标的收敛或图像质量。Loss振荡、D欠拟合、G坍缩、数据重复与评价误差可能相互混淆；看固定/新z、模式覆盖、距离和训练/留出判别，而非把D≈.5视为达到真分布。

## 7. 条件GAN、projection、FiLM与SPADE

条件c同时输入G和D，才能比较 $p_G(x|c)$ 与 $p_{data}(x|c)$。类别one-hot/embedding可拼z与输入；projection D形如 $D(x,c)=u(h(x))+e(c)^Th(x)$，让类别与图像表示交互。FiLM做 $\gamma(c)\odot h+\beta(c)$；SPADE以语义布局产生**空间变化的**归一化调制，不等所有位置用同一个标签标量。

每类都可能collapse。条件正确不等新z多样；各类样本量、条件取值范围、未知标签和条件置换应测试。缺条件的D是不能检验条件一致，不叫“ground truth泄漏”；paired D输入真pair是预期监督。

### 7.1 可运行三类采样与更新合同

## 8. Pix2Pix：配对、U-Net与PatchGAN

Pix2Pix以成对 $(x,y)$监督 $G(x)$，D看 `(x,y)` 真pair和 `(x,G(x))` 假pair；常将patch层面的对抗loss与像素L1加权。U-Net的skip帮助保空间细节，不能保证所有高频信息不丢。PatchGAN网格每项对应重叠感受野，不是完全独立切块的分类；70×70是特定结构下的感受野，不由输出网格N×N自动决定。

BCE应逐patch后归约，通常**不等于先平均概率再取log**。L1的条件中位数与L2的条件均值是相应风险最小解，但L1仍可能模糊/折中，不保证锐边。λ=100来自特定尺度/归约/实验，换为sum/mean或换目标分辨率会改变相对权重。单一paired target约束与希望同x多样生成有张力，噪声/dropout可能被忽略；不能仅把它加到G就宣称多模态输出。

Paired翻译需配准、共同crop/flip及训练/验证按原主体/场景分组；非对应图片的L1会训练错误配对。未配对数据可比较cycle、明确域条件或其它监督，不能把训练过的ControlNet直接称不需要数据协议的CycleGAN替代。

### 8.1 完整8×8 paired U-Net与patch损失训练

合成输入是竖条带，目标横向移动一格；不同条位置train/test拆分，并固定坐标约定。它是微型配对构造，不是原课只做label-cGAN的main、也不是70×70正式Pix2Pix。

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(7)
class TinyUNet(nn.Module):
    def __init__(self):
        super().__init__();self.e=nn.Conv2d(1,8,3,padding=1);self.down=nn.Conv2d(8,16,4,2,1)
        self.mid=nn.Conv2d(16,16,3,padding=1);self.up=nn.ConvTranspose2d(16,8,4,2,1)
        self.out=nn.Conv2d(16,1,3,padding=1)
    def forward(self,x):
        if x.ndim!=4 or x.shape[1:]!=(1,8,8) or not torch.isfinite(x).all():raise ValueError('有限B×1×8×8')
        skip=F.leaky_relu(self.e(x),.2);h=F.leaky_relu(self.mid(F.leaky_relu(self.down(skip),.2)),.2)
        return torch.tanh(self.out(torch.cat([F.relu(self.up(h)),skip],1)))
G=TinyUNet()
# 三个3×3 stride1卷积，每patch感受野7×7，输出仍8×8，非70×70。
D=nn.Sequential(nn.Conv2d(2,8,3,padding=1),nn.LeakyReLU(.2),
                nn.Conv2d(8,8,3,padding=1),nn.LeakyReLU(.2),nn.Conv2d(8,1,3,padding=1))
def pair(columns):
    x=torch.full((len(columns),1,8,8),-1.)
    for i,c in enumerate(columns):x[i,0,:,c]=1
    return x,torch.roll(x,1,dims=-1)
train_x,train_y=pair([1,2,4,5]);test_x,test_y=pair([3,6])
og=torch.optim.Adam(G.parameters(),lr=.003);od=torch.optim.Adam(D.parameters(),lr=.002)
with torch.no_grad():before=float((G(test_x)-test_y).abs().mean())
for _ in range(140):
    fake=G(train_x);od.zero_grad(set_to_none=True)
    real_score=D(torch.cat([train_x,train_y],1));fake_score=D(torch.cat([train_x,fake.detach()],1))
    ld=F.softplus(-real_score).mean()+F.softplus(fake_score).mean();ld.backward();od.step()
    for p in D.parameters():p.requires_grad_(False)
    og.zero_grad(set_to_none=True);fake=G(train_x)
    lg=F.softplus(-D(torch.cat([train_x,fake],1))).mean()+10*F.l1_loss(fake,train_y)
    lg.backward();assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in G.parameters());og.step()
    for p in D.parameters():p.requires_grad_(True)
with torch.no_grad():out=G(test_x);after=float((out-test_y).abs().mean())
assert out.shape==test_y.shape and torch.isfinite(out).all()
assert real_score.shape==(4,1,8,8)
foreground=float((out-test_y).abs()[test_y>0].mean());background=float((out-test_y).abs()[test_y<0].mean())
print('heldout paired L1初始/最终',before,after,'patch logits',tuple(real_score.shape))
print('前景/背景L1',foreground,background,'全背景预测的全局L1基线',.25)
# 非线性归约差别：不是平均概率后做一次BCE。
a=torch.tensor([.01,.99]);print('逐patch负log均值/均值后负log',float(-a.log().mean()),float(-a.mean().log()))
```

是否学会移动还要看前景、背景和条件对应。本环境短训练的heldout L1约.25，恰是全背景基线，不能称成功移动；前景误差可揭示其失败。下一步先分别看前景、背景和边界的误差，逐对核对输入/目标是否配对及移动方向/坐标，再查训练位置覆盖与输出饱和。此后才按同协议比较数据覆盖、loss权重或训练预算；前景加权会改变原优化目标，要同时报告权重和原始指标，并保留全背景基线。模型对边界/域偏移也要另测。像素质量、条件服从、覆盖和感知指标一起看。源600步1D cGAN没有U-Net、PatchGAN和paired L1，不能把其mean输出说成Pix2Pix复现。

## 9. Cycle consistency的训练与不可辨识性

两个生成器 $G:X\to Y,F:Y\to X$，两个D区分各自域，加循环项 $\|F(G(x))-x\|_1+\|G(F(y))-y\|_1$。identity项等可抑制某些不必要变化，但不证明真实语义被保存。对应关系由数据、结构与损失偏置决定，多个映射可能同样满足目标。

### 9.1 完整1D双生成器、双判别器和反例

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(8)
net=lambda:nn.Sequential(nn.Linear(1,16),nn.Tanh(),nn.Linear(16,1))
G,Fnet,DX,DY=net(),net(),net(),net()
og=torch.optim.Adam(list(G.parameters())+list(Fnet.parameters()),lr=.002)

for _ in range(220):
    x=-2+.3*torch.randn(32,1);y=2+.3*torch.randn(32,1)
    fx,gy=Fnet(y),G(x);od.zero_grad(set_to_none=True)
    ld=.5*((DX(x)-1).square().mean()+DX(fx.detach()).square().mean()+
            (DY(y)-1).square().mean()+DY(gy.detach()).square().mean())
    ld.backward();od.step()
    for d in [DX,DY]:
        for p in d.parameters():p.requires_grad_(False)
    og.zero_grad(set_to_none=True);fx,gy=Fnet(y),G(x)
    cycle=F.l1_loss(Fnet(gy),x)+F.l1_loss(G(fx),y)
    lg=(DY(gy)-1).square().mean()+(DX(fx)-1).square().mean()+5*cycle
    lg.backward();og.step()
    for d in [DX,DY]:
        for p in d.parameters():p.requires_grad_(True)
with torch.no_grad():
    x=-2+.3*torch.randn(200,1);y=2+.3*torch.randn(200,1)
    err=F.l1_loss(Fnet(G(x)),x)+F.l1_loss(G(Fnet(y)),y)
    print('训练后cycle L1',float(err),'G/F输出域均值',float(G(x).mean()),float(Fnet(y).mean()))
    assert torch.isfinite(err)
# 两个精确合法解：平移与反射，均把N(-2,.3²)映至N(2,.3²)，但对应不同。
x=torch.tensor([[-2.3],[-1.7]])
translation=x+4;reflection=-x
assert torch.allclose(translation-4,x) and torch.allclose(-reflection,x)
assert not torch.allclose(translation,reflection)

```

此小实验实际更新四网络，但不预言必须学到平移。源“冻结小D作perceptual 1D loss”是特征距离代理，需指定冻结网络、层、训练数据和量纲，不把低代理loss自动叫更锐利图像。训练好的特征可比裸像素更适合某些目标，也可能忽略任务关键变化。

## 10. StyleGAN三个版本，空间与语义控制

StyleGAN1从可学constant开始，用映射网络 $f:Z\to W$产生每层风格参数，AdaIN逐样本/逐通道在空间轴归一后affine；增加独立空间noise经可学通道强度控制细节。8层mapping、512维、4×4constant等是经典配置例，非所有变体硬约定。

StyleGAN2改变为权重调制/解调、结构/训练正则等；不是“StyleGAN全系列都用AdaIN”。StyleGAN3强调信号与重采样的抗混叠以缓解像素坐标纹理黏着，等变性质还受具体配置、采样、边界影响；不是加一个sinc滤波就保证整个生成器严格等变或所有伪影消失。

W比直接z可更便于某些编辑，是经验结构，不保证正交的pose/light轴或完全解耦。W+为每层分别选w，更多自由度可利于重构也更容易偏离训练映射空间；StyleSpace是经affine后的分层/通道style空间，不是任意把w维改名。跨层mixing鼓励模型不依赖相邻层风格完全关联，但不证明语义因素被完美分离。

### 10.1 正确空间AdaIN

```python
import torch
x=torch.arange(24,dtype=torch.float64).reshape(2,3,2,2)
scale=torch.tensor([[1.,2.,3.],[.5,1.,2.]],dtype=torch.float64)[:,:,None,None]
bias=torch.tensor([[0.,1.,-1.],[2.,0.,1.]],dtype=torch.float64)[:,:,None,None]
mean=x.mean((2,3),keepdim=True);var=x.var((2,3),unbiased=False,keepdim=True)
y=scale*(x-mean)/torch.sqrt(var+1e-8)+bias
assert torch.allclose(y.mean((2,3),keepdim=True),bias,atol=1e-6)
assert torch.allclose(y.var((2,3),unbiased=False,keepdim=True),scale.square(),atol=1e-6)
print('每样本每通道AdaIN均值/方差合同通过')
```

原05源码是六元素dense向量的全向量归一，不是图像每通道空间归一；参数和constant都随机且无训练。`adain_on=False`使w完全不进入synthesis、noise0时所有z产生同一输出，不能据此称优于“z拼接生成器”。跨样本每坐标spread与把样本+所有通道摊平的std不同，后者即使输出每次一样也可非零。

## 11. 调制、解调与完整微型synthesis

基础卷积权重 $W_{o,i,k}$，每样本style $s_{b,i}$ 在**输入通道**调制：$W'_{b,o,i,k}=s_{b,i}W_{o,i,k}$；输出通道解调系数 $d_{b,o}=(\sum_{i,k}(W'_{b,o,i,k})^2+\epsilon)^{-1/2}$，$W''=dW'$再卷积。它控制基于输入独立单位方差近似下的输出尺度，不保证对任意相关输入/边界输出方差恰1。

Noise常是每样本单通道空间场，广播到各通道后乘可学通道强度；不保证只有毛发/皮肤等局部语义变化。ToRGB等层可不解调。下面grouped conv实现逐样本不同核，省去Python batch循环，并以循环版逐值核对；随机tiny synthesis只有4→8空间层和普通输出conv，不复刻完整StyleGAN2/3。

```python
import math
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(9)
def modconv(x,weight,style,demod=True):
    B,C,H,W=x.shape;O,I,K,K2=weight.shape
    if B<1 or C!=I or K!=K2 or K%2==0 or style.shape!=(B,I):raise ValueError('非空B/C/奇方核/style合同')
    if not all(torch.isfinite(a).all() for a in [x,weight,style]):raise ValueError('有限输入')
    w=weight[None]*style[:,None,:,None,None]
    if demod:w=w*torch.rsqrt(w.square().sum((2,3,4),keepdim=True)+1e-8)
    out=F.conv2d(x.reshape(1,B*C,H,W),w.reshape(B*O,I,K,K),padding=K//2,groups=B)
    return out.reshape(B,O,H,W)
class Layer(nn.Module):
    def __init__(self):
        super().__init__();self.weight=nn.Parameter(torch.randn(4,4,3,3)/6)
        self.affine=nn.Linear(8,4);nn.init.ones_(self.affine.bias)
        self.strength=nn.Parameter(torch.ones(4)*.02)
    def forward(self,x,w,noise):
        x=modconv(x,self.weight,self.affine(w))
        return F.leaky_relu(x+noise*self.strength[None,:,None,None],.2)
class Synthesis(nn.Module):
    def __init__(self):
        super().__init__();self.constant=nn.Parameter(torch.randn(1,4,4,4))
        self.layers=nn.ModuleList([Layer(),Layer()]);self.out=nn.Conv2d(4,1,1)
    def forward(self,ws,noises):
        if ws.ndim!=3 or ws.shape[1:]!=(2,8) or len(noises)!=2:raise ValueError('B×2×8层风格/两noise')
        x=self.constant.expand(len(ws),-1,-1,-1)
        x=self.layers[0](x,ws[:,0],noises[0])
        x=F.interpolate(x,scale_factor=2,mode='bilinear',align_corners=False)
        x=self.layers[1](x,ws[:,1],noises[1])
        return self.out(x)

x=torch.randn(2,4,5,5);weight=torch.randn(3,4,3,3);s=torch.randn(2,4)
y=modconv(x,weight,s)
reference=[]
for b in range(2):
    w=weight*s[b][None,:,None,None];w=w*torch.rsqrt(w.square().sum((1,2,3),keepdim=True)+1e-8)
    reference.append(F.conv2d(x[b:b+1],w,padding=1))
assert torch.allclose(y,torch.cat(reference),atol=1e-6)
assert torch.allclose(y,modconv(x,weight,s*7),atol=1e-5)  # 正整体缩放近似被解调抵消，eps明确。
mapping=nn.Sequential(nn.Linear(8,8),nn.LeakyReLU(.2),nn.Linear(8,8));synth=Synthesis()
a,b=mapping(torch.randn(2,8)),mapping(torch.randn(2,8))
noise=[torch.zeros(2,1,4,4),torch.zeros(2,1,8,8)]
wa=a[:,None,:].repeat(1,2,1);mixed=torch.stack([a,b],1)
image=synth(wa,noise);mix_image=synth(mixed,noise)
assert image.shape==(2,1,8,8) and not torch.allclose(image,mix_image)
print('grouped/逐样本调制解调一致，混合风格形状',tuple(mix_image.shape))
# 固定noise排除随机因素后，latent插值/psi只说明数值控制，不是pose/smile方向。
wbar=mapping(torch.randn(200,8)).mean(0)
psi0=wbar[None,None,:].expand(2,2,8)
same=synth(psi0,noise);assert torch.allclose(same[0],same[1])
print('psi0固定noise时同输出，非训练人脸；w与noise条件分开')
```

本例bilinear上采样不是StyleGAN3的整套alias-free滤波/坐标设计。正缩放抵消也不是所有style变化都无效，负缩放可翻转符号，零style由eps处理；这些是算法条件。

## 12. R1与path-length正则：真正计算二阶路径

R1为 $\gamma/2\,E_{real}\|\nabla_xD(x)\|^2$，以真实x为变量并保持图，后续梯度才可训练D权重。PL对image-space随机投影的 $J_w^Ty$范数惩罚其偏離运行均值，鼓励变化尺度更均匀，**不是一律限制所有大变化、更不是证明W解耦**。典型style多层w时先对style维平方求和，再对层平均开根。

以下自含程序实现tiny style generator的对抗+D R1+G PL一次真实更新，检查create_graph与两网梯度；正则target简化固定为1，而非完整EMA/lazy-reg配置。真实StyleGAN正则频率、系数、optimizer修正和初始化都需要配套核验。

```python
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(10)
class TinyStyledG(nn.Module):
    def __init__(self):
        super().__init__();self.constant=nn.Parameter(torch.randn(1,4,4,4))
        self.style=nn.Linear(8,8);self.conv=nn.Conv2d(4,4,3,padding=1);self.out=nn.Conv2d(4,1,1)
    def forward(self,w):
        scale,bias=self.style(w).chunk(2,-1)
        x=self.constant.expand(len(w),-1,-1,-1)
        # 有意使用简单affine风格，而非冒充上一节modconv完整StyleGAN。
        x=F.leaky_relu(self.conv(x)*(1+scale[:,:,None,None])+bias[:,:,None,None],.2)
        return self.out(x)
G=TinyStyledG();D=nn.Sequential(nn.Conv2d(1,4,3,padding=1),nn.LeakyReLU(.2),nn.Flatten(),nn.Linear(64,1))
og=torch.optim.Adam(G.parameters(),lr=.002);od=torch.optim.Adam(D.parameters(),lr=.002)
real=torch.randn(3,1,4,4).requires_grad_(True);w=torch.randn(3,8);fake=G(w)
od.zero_grad(set_to_none=True);ar,af=D(real),D(fake.detach())
grad=torch.autograd.grad(ar.sum(),real,create_graph=True)[0]
r1=grad.square().sum((1,2,3)).mean()
ld=F.softplus(-ar).mean()+F.softplus(af).mean()+.5*r1
ld.backward();assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in D.parameters());od.step()
for p in D.parameters():p.requires_grad_(False)
og.zero_grad(set_to_none=True);w=torch.randn(3,8,requires_grad=True);image=G(w)
y=torch.randn_like(image)/4  # sqrt(4×4)，空间随机投影标定。
gw=torch.autograd.grad((image*y).sum(),w,create_graph=True)[0]
length=torch.sqrt(gw.square().sum(1)+1e-8);pl=(length-1).square().mean()
lg=F.softplus(-D(image)).mean()+.1*pl
lg.backward();assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in G.parameters());og.step()
print('R1/PL及两网真实更新梯度',float(r1.detach()),float(pl.detach()))
```

R1、GP和PL的输入、目标和优化网络不同，不能都叫“梯度惩罚所以同一实现”。学习率与lazy频率缩放会影响强度，单步梯度正确不证明有效生成训练，长期真实质量本次未运行。

## 13. 潜空间控制、truncation与inversion

Truncation $w'=\bar w+\psi(w-\bar w)$ 对固定latent分布使协方差缩为 $\psi^2Cov(w)$，decoder非线性和独立noise使image多样性不必按此比例。ψ0且noise固定时输出一个样本，**不是数据均值图像**；noise可仍产生差异。它是特定质量/覆盖取舍参数，不是安全开关或“降psi就减少服务负载”的成本控制。

Inversion可优化w、每层W+或noise，也可用encoder初始化，再按目标决定是否适配G。loss可以结合像素、适配的感知特征、身份/属性等，但不同loss冲突需要验证。直接Z优化也合法，W不自动最解耦/W+不自动最高质量；越多自由度可能重构更好而编辑更不稳。PTI等更新生成器参数需与只优化latent区分。

### 13.1 完整toy latent inversion

只拟合人为已知linear decoder的latent，验证梯度和还原边界；不是预训练人脸inversion或身份保持。冻结decoder参数但保留前向梯度到w，原理同固定骨干适配。

```python
import torch
from torch import nn
torch.manual_seed(11)
decoder=nn.Linear(3,5,bias=False)
for p in decoder.parameters():p.requires_grad_(False)
true_w=torch.tensor([[.3,-.4,.7]])
with torch.no_grad():target=decoder(true_w)
w=nn.Parameter(torch.zeros_like(true_w));opt=torch.optim.Adam([w],lr=.05)
for _ in range(250):
    loss=(decoder(w)-target).square().mean();opt.zero_grad(set_to_none=True);loss.backward();opt.step()
assert all(p.grad is None for p in decoder.parameters()) and w.grad is not None
err=float((decoder(w)-target).square().mean().detach());assert err<1e-7
print('toy inversion重建MSE',err,'latent',w.detach().tolist())
# decoder非injective时可有多解；真实图像也可在生成器表示范围之外。
```

SVM/PCA/分类器方向属于特定checkpoint、层、属性标签和特征空间。要报告原与编辑后属性、内容/身份和失败边界，不能照搬“1.5sigma任意编辑”阈值；原smile/FFHQ权重练习未下载运行，也没有生成人脸。

## 14. 学习练习与参考判断

1. 五种产品的内部生成架构怎样确认？找对应公开技术报告，按日期、可证据层级分别记录；未公开的组件标未知。不能把视频patch自动当离散AR或从产品名推所有模型“同family”。本批不制作当前API排行/价格或猜闭源实现。
2. “100倍更快”查什么？同尺寸/条件/样本质量覆盖、端到端编码/解码/传输、设备/精度/批量、生成步数与每步成本、训练/蒸馏额外成本；不只看num_steps。
3. 怎样选β Pareto方案？看留出重构/每维KL、prior样本和下游任务，指标取舍与单位先定；本章4β实测不预定唯一最好，更不把β>.5一律禁用。
4. Gaussian换Bernoulli要改什么？目标二值/似然、decoder logits与BCE、预测概率解释和评价；两数据的NLL不直接排序。原softplus“必陷阱”、Monte-Carlo KL“永远无用”都过强，非标准prior时闭式KL可能不可得。
5. VQ K32为何不必使用每个码？数据模式、encoder/训练预算/初始化都影响；记录usage/entropy/重构，参考音频12的完整量化链，不用20%一票判坏。
6. D LR=5G会必崩吗？不保证；同seed/预算看D输入梯度、两网更新、真实峰覆盖，不由G loss常数判唯一根因。本批多目标真实训练不运行所有比率扫参。
7. 只把sigmoid BCE换WGAN是否足够？不够，critic输出不加sigmoid，还需约束/更新策略；clipping与GP不同，不预言谁更稳定或更快。
8. 八环Gaussians+minibatch discrimination怎么验？定义每个峰的半径/拒绝区、配对样本量/seed，检查真实覆盖而不是只分正负；10k训练与长消融本次未做。
9. 三类cGAN：同时改真实采样、条件维度、G/D与每类均值/方差；源`else`把2+映到+2不能自动创造第三峰，正文三类程序已运行。
10. PatchGAN+L1为何要paired？对抗学域条件，L1学具体对应；错配L1会把正确输出惩罚掉。逐patchloss与平均概率后loss不同，感受野和网格大小分开。
11. Cycle能证明正确对应吗？不能，平移/反射精确反例都满足Gaussian域与cycle；toy四网训练只记录实际cycle和输出域，不叫真实图像翻译。
12. AdaIN on/off是什么对照？原off断开w，不能比较z-concat能力；比较相同训练目标、容量、latent/noise与预算才有效。混style后数值变化不证明解耦。
13. PL是否只压所有大导数？不是，接近运行目标的长度均匀；R1真实x梯度目标0，GP插值梯度范数目标1，网络/对象不同。
14. 复制官方StyleGAN当前权重就证明质量吗？不，输入/代码/权重/尺寸/noise/truncation/指标皆需核验；本章不下载weights、不测真实FFHQ/PESQ等领域指标。
