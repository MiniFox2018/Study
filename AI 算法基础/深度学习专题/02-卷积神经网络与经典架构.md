# 02｜卷积神经网络与经典架构

> 先修：MLP、矩阵形状和链式法则。先会 2～4 节的尺寸/参数量计算，再读 ResNet；15～19 节的梯度理论可第二遍学习。

## 1. CNN 的核心归纳偏置

图像具有空间局部性和平移结构。CNN 用两个约束降低参数量：

- **局部连接**：一个输出只依赖局部邻域；
- **权重共享**：同一个卷积核在不同空间位置复用。

这使模型不必为每个像素位置学习独立参数。

平移等变有条件：步长1、相应边界延拓和坐标对齐下成立，有限填充边缘/下采样会改变关系；并不等于分类输出天然完全平移不变。完整图像编码、滤波、分组卷积及反向实践见[图像表征、卷积与视觉训练](../感知与多模态专题/05-图像表征卷积与视觉训练.md)。

## 2. 二维卷积

对输入 $X$ 和卷积核 $K$，输出位置是局部加权和。多数深度学习框架实际计算互相关（不翻转卷积核），沿用“卷积层”名称；可学习卷积核下不影响该层的表达能力。

需要能够手算：

- 输出尺寸；
- kernel size；
- padding；
- stride；
- dilation；
- channel 数。

最常见的工程错误之一是 shape 推导错误。

## 3. Padding 与 Stride

Padding 控制边界信息与空间尺寸；Stride 控制采样密度并改变特征图分辨率。

卷积输出大小可按：

$$
n_{\mathrm{out}}=\left\lfloor\frac{n+2p-d(k-1)-1}{s}\right\rfloor+1
$$

这里 $n$ 为单轴输入长度，$p$ 为该轴两侧相同填充，$k$ 为核大小，$s$ 为步长，$d$ 为 dilation。高、宽分别计算；$d=1$ 时退化为常见公式。

## 4. 多通道

彩色图像和中间特征都具有 channel 维。

- 普通卷积（groups=1）的每个输出通道聚合全部输入通道；分组/深度卷积只聚合所属组；
- 多个输出通道对应多个不同特征探测器；
- $1\times1$ 卷积主要用于通道混合和维度变换，而不是空间邻域建模。

## 5. Pooling

Max/Average Pooling 用于局部汇聚和下采样。

它的价值包括：

- 减少空间分辨率；
- 扩大后续单元有效感受野；
- 提供一定局部不变性。

现代架构也常用 stride convolution 替代部分 pooling。

## 6. LeNet：完整 CNN 原型

LeNet 代表经典结构：

```text
Conv → Pool → Conv → Pool → FC
```

它的重要性不是今天的性能，而是完整展示“局部特征 → 高级表征 → 分类”的层级抽象。

## 7. AlexNet

关键历史贡献包括：

- 深层 CNN 在大规模视觉数据上的有效性；
- GPU 训练；
- ReLU；
- Dropout；
- 数据增强。

今天不必复刻原始超参数，但应理解“大数据 + 更大模型 + 高性能计算”共同触发突破。

## 8. VGG：重复块

VGG 用多个小卷积核构成规则 block，强调：

> 复杂架构可以由简单、可重复组件堆叠而成。

这一设计哲学后来成为模块化网络的基础。

## 9. NiN 与 1×1 卷积

Network in Network 使用 $1\times1$ 卷积增强通道维非线性表达，并用全局平均池化弱化大规模全连接层。

长期价值：

- channel mixing；
- bottleneck/projection；
- 参数效率。

## 10. GoogLeNet / Inception

Inception 在同一层并行使用不同感受野：

```text
1×1
3×3
5×5
pool
  ↓ concat
```

它体现“多尺度并行特征抽取”和“用 1×1 控制计算量”。

## 11. Batch Normalization

BatchNorm 对 mini-batch 统计量进行标准化，再学习缩放和平移。

需要理解：

- train 与 eval 行为不同；
- running statistics；
- batch 太小时统计不稳定；
- BN 能改善优化，但不等价于所有场景下的最佳归一化。

现代 Transformer 通常更多使用 LayerNorm/RMSNorm。

## 12. ResNet

残差块：

$$
y=F(x)+x
$$

核心价值是为深层网络提供近似恒等路径，使优化器更容易训练“对已有表示的增量修正”。

残差连接后来扩展到 Transformer、扩散模型等大量架构，是必须掌握的通用设计模式。

## 13. DenseNet

DenseNet 把前面层的特征直接拼接给后续层：

$$
x_l=H_l([x_0,\ldots,x_{l-1}])
$$

优点是特征复用和梯度路径短；代价是显存和连接复杂度增加。

## 14. 如何阅读新视觉架构

面对一个 CNN/视觉模型，优先分析：

1. 特征图分辨率如何变化？
2. channel 如何变化？
3. 用什么 block？
4. 是否有 residual / dense / parallel path？
5. normalization 在哪里？
6. 下采样在哪里？
7. 参数量和 FLOPs 主要花在哪里？

这样比记模型名称更可迁移。

## 15. Shattered Gradients

本仓库已核验的 UDL 第 11 章强调，深层顺序网络不仅可能出现梯度消失/爆炸，还可能出现 **shattered gradients**：

> 输入发生很小变化时，输出对输入的梯度会剧烈、无规律地变化。

浅层网络中，相邻输入位置的梯度通常高度相关；网络变深后，这种梯度自相关会快速衰减。

这提示深层网络的梯度相关结构可能变得不利于优化；输入梯度去相关不直接等于参数空间梯度不连续，也不是证明训练必然失败。

## 16. Residual Connection 为什么改善梯度

残差块：

$$
h_{k+1}=h_k+F_k(h_k)
$$

在此直接相加形式下，局部Jacobian为 $I+J_{F_k}$，反向连乘展开含全程选择I、经过少量残差分支、经过全部残差分支的路径。这给出更直接的传播通路，也是减少某些梯度去相关/改善优化的解释。

连乘仍可放大、消失或相互抵消：例如 $F(x)=-x$时 $I+J_F=0$，$F(x)=2x$时则为3I。因此路径较短并不自动意味着任意网络更稳定。原post-activation块 $h_{k+1}=ReLU(h_k+F_k(h_k))$还乘输出ReLU门，不能把所有输入上纯identity传播当保证；pre-activation设计更接近直接skip通路，但也需尺度与训练方案。

“可以表达恒等/残差映射”是模型能力，不等于优化器必找到，也不保证一千层性能至少和一层一样。它与shattered gradients、归一化和前向方差的关系应一起看，不能缩成“残差彻底防止梯度消失”。

## 17. Residual Network 的方差增长问题

相加后的方差为 $\operatorname{Var}(h+F)=\operatorname{Var}(h)+\operatorname{Var}(F)+2\operatorname{Cov}(h,F)$。在相关项不抵消且各分支尺度未受控制时，方差可能随深度增长；不能仅凭“方差相近”就断言必然增长。

因此：

> residual connection 本身解决了一类梯度问题，但也引入了前向尺度和梯度尺度稳定性问题。

UDL 给出的两类思路是：

- 对相加后的信号做适当缩放；
- 使用 normalization 控制每层激活尺度。

## 18. BatchNorm 在残差网络中的作用

BatchNorm 不只是“让均值为 0、方差为 1”。

在残差网络中，它还帮助：

- 控制深层激活方差；
- 稳定 forward propagation；
- 稳定 backward gradient；
- 允许更大学习率；
- 平滑部分 loss geometry。

训练和推理必须区分：

- 训练：使用 batch statistics；
- 推理：使用训练阶段积累/重新估计并冻结的统计量。

## 19. 为什么 Residual Network 有效仍非单一答案

现有解释包括：

- 减少 shattered gradients；
- 提供大量短计算路径；
- 使损失表面更平滑；
- 更容易接近 identity mapping；
- 与 normalization 一起稳定超深网络训练。

但 UDL 也强调：**残差网络的性能提升不能简单等同于“越深越好”。**

Wide ResNet 等结果说明，较浅但更宽的 residual network 也能表现很好。因此 residual connection 的核心价值首先是改善可训练性和架构归纳偏置，而不是单纯增加层数。

## 尺寸、参数与边界的检查

输入形状 `(批量=2, 通道=3, 高=32, 宽=32)`，输出通道 8，卷积核 3、步长 2、填充 1、dilation 1、groups 1。每轴输出为 $\lfloor(32+2-2-1)/2\rfloor+1=16$，总形状 `(2, 8, 16, 16)`；含偏置参数为 $(3\times3\times3+1)\times8=224$。

自查：保持其他参数，仅令 dilation=2，输出尺寸是多少？**答案：**15×15，因为有效核宽为 $2(3-1)+1=5$。参数数量仍为 224；扩大采样间隔不增加核内可学习权重数量。

核验（2026-10-02）：[PyTorch Conv2d 定义、分组与尺寸公式](https://pytorch.org/docs/stable/generated/torch.nn.Conv2d.html)。

## 20. 比较架构时保留思想，按明确变体算形状和预算

| 家族 | 应学习的结构思想 | 不能由名字直接推出的结论 |
|---|---|---|
| LeNet风格 | 小核/局部特征、汇聚、全连接读出 | 常用现代复现不等于原论文逐层/连接/训练目标完全相同 |
| AlexNet | 更大数据/计算、ReLU、Dropout、增强共同作用 | 不将单次论文ReLU速度差当所有任务6倍加速，也不说原手工特征因此彻底消失 |
| VGG | 相同小核块堆叠，多次非线性 | 原VGG16为13卷积+3FC，VGG19为16卷积+3FC；不是16/19个卷积，原版也不是默认带BN |
| NiN/Inception | 通道非线性/1×1降维、并行多尺度、concat | concat需空间尺寸一致，不代表每分支自动学会特定语义 |
| ResNet/DenseNet | 相加残差或拼接复用，改变信息通路 | 跨步长/通道需对齐；更深、更多路径不自动更高准确率 |
| MobileNet | depthwise空间滤波+pointwise通道混合 | 更少MAC不自动低延迟；小Cout时也不总减少9倍 |
| EfficientNet | 共同调整深度/宽度/分辨率的预算思想 | 指数/缩放系数是特定搜索结果，不是跨设备最佳配方 |
| ConvNeXt | 现代卷积块、depthwise/归一化/倒瓶颈及训练配方 | 它仍是CNN，不能称其只是ViT换一两步，也没有永久最强型号 |

两次3×3在步长1、相同通道宽度C时理论RF5，权重18C²（不含bias），一次5×5是25C²；通道变化/瓶颈/分组不同则需重新算。两次操作中有非线性，表达的不是同一个任意5×5线性核，不能认为只是数值等价加速。

分类头Flatten→大FC可能占大量参数；global average pool→小Linear将空间维汇聚，保留通道而丢部分位置信息。某一标准权重的参数/历史准确率只用于该模型/输入/训练配方，不能用名称代替同任务预算对照。

## 21. 完整CPU结构例子：VGG、残差、瓶颈、Inception与深度可分离

以下只依赖PyTorch，不加载预训练权重。演示LeNet风格完整分类器和可组合块，每次先形状断言再跑前向；随机网络输出shape/参数通过只说明结构，不是任何公开数据上的性能。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(42)
class LeNetStyle(nn.Module):
    def __init__(self,classes=10):
        super().__init__()
        self.c1,self.c2 = nn.Conv2d(1,6,5),nn.Conv2d(6,16,5)
        self.f1,self.f2,self.f3 = nn.Linear(400,120),nn.Linear(120,84),nn.Linear(84,classes)
    def forward(self,x):
        x = F.avg_pool2d(torch.tanh(self.c1(x)),2)
        x = F.avg_pool2d(torch.tanh(self.c2(x)),2)
        x = torch.flatten(x,1)
        return self.f3(torch.tanh(self.f2(torch.tanh(self.f1(x)))))

def conv_bn(ci,co,k,stride=1,pad=0,groups=1):
    return nn.Sequential(nn.Conv2d(ci,co,k,stride,pad,groups=groups,bias=False),nn.BatchNorm2d(co))
class VGGBlock(nn.Module):
    def __init__(self,ci,co):
        super().__init__()
        self.layers = nn.Sequential(conv_bn(ci,co,3,pad=1),nn.ReLU(),
                                    conv_bn(co,co,3,pad=1),nn.ReLU(),nn.MaxPool2d(2))
    def forward(self,x): return self.layers(x)

class BasicBlock(nn.Module):
    def __init__(self,ci,co,stride=1):
        super().__init__();self.first,self.second = conv_bn(ci,co,3,stride,1),conv_bn(co,co,3,pad=1)
        self.shortcut = nn.Identity() if ci==co and stride==1 else conv_bn(ci,co,1,stride)
    def forward(self,x):
        residual = self.second(F.relu(self.first(x)))
        shortcut = self.shortcut(x)
        if residual.shape!=shortcut.shape: raise ValueError("残差相加形状不一致")
        return F.relu(residual+shortcut)

class Bottleneck(nn.Module):
    def __init__(self,ci,width,stride=1,expansion=4):
        super().__init__();co = width*expansion
        self.one,self.three,self.last = conv_bn(ci,width,1),conv_bn(width,width,3,stride,1),conv_bn(width,co,1)
        self.shortcut = nn.Identity() if ci==co and stride==1 else conv_bn(ci,co,1,stride)
    def forward(self,x):
        residual = self.last(F.relu(self.three(F.relu(self.one(x)))))
        shortcut = self.shortcut(x)
        assert residual.shape==shortcut.shape
        return F.relu(residual+shortcut)

class InceptionMini(nn.Module):
    def __init__(self,ci,width=4):
        super().__init__()
        self.branches = nn.ModuleList([
            nn.Sequential(nn.Conv2d(ci,width,1),nn.ReLU()),
            nn.Sequential(nn.Conv2d(ci,width,1),nn.ReLU(),nn.Conv2d(width,width,3,padding=1),nn.ReLU()),
            nn.Sequential(nn.Conv2d(ci,width,1),nn.ReLU(),nn.Conv2d(width,width,5,padding=2),nn.ReLU()),
            nn.Sequential(nn.MaxPool2d(3,stride=1,padding=1),nn.Conv2d(ci,width,1),nn.ReLU())])
    def forward(self,x): return torch.cat([branch(x) for branch in self.branches],dim=1)

class DepthSeparable(nn.Module):
    def __init__(self,ci,co,stride=1):
        super().__init__()
        self.layers = nn.Sequential(conv_bn(ci,ci,3,stride,1,groups=ci),nn.ReLU(),conv_bn(ci,co,1),nn.ReLU())
    def forward(self,x): return self.layers(x)

x = torch.randn(2,3,32,32)
for name,block in [("VGG风格",VGGBlock(3,8)),("Basic投影",BasicBlock(3,8,2)),
                   ("Bottleneck",Bottleneck(3,4,2)),("Inception",InceptionMini(3)),
                   ("Depthwise+pointwise",DepthSeparable(3,8,2))]:
    block.eval()
    with torch.no_grad(): out = block(x)
    print(name,"输入/输出",tuple(x.shape),tuple(out.shape),"参数",sum(p.numel() for p in block.parameters()))
lenet = LeNetStyle().eval()
with torch.no_grad(): print("LeNet风格输出",lenet(torch.randn(2,1,32,32)).shape)
assert sum(p.numel() for p in lenet.parameters())==61706

# 恒等路径可以抵消：反向不是无条件保证。
scalar = torch.tensor(2.,requires_grad=True)
cancelled = scalar+(-scalar)
assert torch.autograd.grad(cancelled,scalar)[0].item()==0
print("残差I+JF抵消例子的梯度=0")
```

块中Conv后直接BN采用bias=False，是常用减少冗余参数的设计；不等于所有BN相关情况下bias都违法。BN仿射2×C参数与running buffers分别计算，eval/冻结和前向统计的精确定义见[框架调试专题](18-张量框架与模型调试.md)。同尺寸相加可identity，变尺寸可projection/明确下采样映射；concat是另一机制，不能混用。

代码的BN/ReLU顺序是明确的post-activation变体；pre-activation、SE/门控、其他shortcut需按声明分析，不能因没长得一样就判错。若原地修改被多分支复用的张量，可能影响shortcut与autograd缓存，应针对计算图检查；不是所有inplace ReLU都必错。

## 22. 阅读/修改一个CNN的验收

1. 输入layout、通道、范围与预处理已确定，按层列出输出H/W/C、参数、有效jump和理论RF。
2. 普通/组/深度卷积分别核对groups条件；尺寸公式允许合法floor，核大于填充输入才会无有效输出。
3. 残差/并行路径真实同shape，梯度检查/CPU前后向运行；不能靠模型能创建就称通过。
4. 参数预算与FLOPs定义明确，BN缓冲/共享参数/训练参数不同计数；真实效率另测目标设备。
5. 不将LeNet/MiniVGG随机forward当分类正确，不预写几轮CIFAR必达某准确率；若比较plain/residual深网络，固定数据/增强/初始化预算与多个种子，不强求某一实验复刻既定结论。

自查：为什么1×1 stride2 shortcut必要？**答案：**空间/通道不匹配无法相加，投影可对齐；它不再是纯identity。为什么global平均池化减少FC参数？**答案：**Linear输入从$C H W$变为C，但位置信息损失是否适合任务仍需验证。
