# 02｜卷积神经网络与经典架构

> 先修：MLP、矩阵形状和链式法则。先会 2～4 节的尺寸/参数量计算，再读 ResNet；15～19 节的梯度理论可第二遍学习。

## 1. CNN 的核心归纳偏置

图像具有空间局部性和平移结构。CNN 用两个约束降低参数量：

- **局部连接**：一个输出只依赖局部邻域；
- **权重共享**：同一个卷积核在不同空间位置复用。

这使模型不必为每个像素位置学习独立参数。

## 2. 二维卷积

对输入 $X$ 和卷积核 $K$，输出位置是局部加权和。多数深度学习框架实际计算互相关（不翻转卷积核），沿用“卷积层”名称；可学习卷积核下不影响该层的表达能力。

需要能够手算：

- 输出尺寸；
- kernel size；
- padding；
- stride；
- dilation；
- channel 数。

最常见的工程错误之一是 shape 推导错误。

## 3. Padding 与 Stride

Padding 控制边界信息与空间尺寸；Stride 控制采样密度并改变特征图分辨率。

卷积输出大小可按：

$$
n_{\mathrm{out}}=\left\lfloor\frac{n+2p-d(k-1)-1}{s}\right\rfloor+1
$$

这里 $n$ 为单轴输入长度，$p$ 为该轴两侧相同填充，$k$ 为核大小，$s$ 为步长，$d$ 为 dilation。高、宽分别计算；$d=1$ 时退化为常见公式。

## 4. 多通道

彩色图像和中间特征都具有 channel 维。

- 普通卷积（groups=1）的每个输出通道聚合全部输入通道；分组/深度卷积只聚合所属组；
- 多个输出通道对应多个不同特征探测器；
- $1\times1$ 卷积主要用于通道混合和维度变换，而不是空间邻域建模。

## 5. Pooling

Max/Average Pooling 用于局部汇聚和下采样。

它的价值包括：

- 减少空间分辨率；
- 扩大后续单元有效感受野；
- 提供一定局部不变性。

现代架构也常用 stride convolution 替代部分 pooling。

## 6. LeNet：完整 CNN 原型

LeNet 代表经典结构：

```text
Conv → Pool → Conv → Pool → FC
```

它的重要性不是今天的性能，而是完整展示“局部特征 → 高级表征 → 分类”的层级抽象。

## 7. AlexNet

关键历史贡献包括：

- 深层 CNN 在大规模视觉数据上的有效性；
- GPU 训练；
- ReLU；
- Dropout；
- 数据增强。

今天不必复刻原始超参数，但应理解“大数据 + 更大模型 + 高性能计算”共同触发突破。

## 8. VGG：重复块

VGG 用多个小卷积核构成规则 block，强调：

> 复杂架构可以由简单、可重复组件堆叠而成。

这一设计哲学后来成为模块化网络的基础。

## 9. NiN 与 1×1 卷积

Network in Network 使用 $1\times1$ 卷积增强通道维非线性表达，并用全局平均池化弱化大规模全连接层。

长期价值：

- channel mixing；
- bottleneck/projection；
- 参数效率。

## 10. GoogLeNet / Inception

Inception 在同一层并行使用不同感受野：

```text
1×1
3×3
5×5
pool
  ↓ concat
```

它体现“多尺度并行特征抽取”和“用 1×1 控制计算量”。

## 11. Batch Normalization

BatchNorm 对 mini-batch 统计量进行标准化，再学习缩放和平移。

需要理解：

- train 与 eval 行为不同；
- running statistics；
- batch 太小时统计不稳定；
- BN 能改善优化，但不等价于所有场景下的最佳归一化。

现代 Transformer 通常更多使用 LayerNorm/RMSNorm。

## 12. ResNet

残差块：

$$
y=F(x)+x
$$

核心价值是为深层网络提供近似恒等路径，使优化器更容易训练“对已有表示的增量修正”。

残差连接后来扩展到 Transformer、扩散模型等大量架构，是必须掌握的通用设计模式。

## 13. DenseNet

DenseNet 把前面层的特征直接拼接给后续层：

$$
x_l=H_l([x_0,\ldots,x_{l-1}])
$$

优点是特征复用和梯度路径短；代价是显存和连接复杂度增加。

## 14. 如何阅读新视觉架构

面对一个 CNN/视觉模型，优先分析：

1. 特征图分辨率如何变化？
2. channel 如何变化？
3. 用什么 block？
4. 是否有 residual / dense / parallel path？
5. normalization 在哪里？
6. 下采样在哪里？
7. 参数量和 FLOPs 主要花在哪里？

这样比记模型名称更可迁移。

## 15. Shattered Gradients

最新版 UDL 第 11 章强调，深层顺序网络不仅可能出现梯度消失/爆炸，还可能出现 **shattered gradients**：

> 输入发生很小变化时，输出对输入的梯度会剧烈、无规律地变化。

浅层网络中，相邻输入位置的梯度通常高度相关；网络变深后，这种梯度自相关会快速衰减。

这提示深层网络的梯度相关结构可能变得不利于优化；输入梯度去相关不直接等于参数空间梯度不连续，也不是证明训练必然失败。

## 16. Residual Connection 为什么改善梯度

残差块：

$$
h_{k+1}=h_k+F_k(h_k)
$$

在反向传播时，梯度中天然包含 identity path。

因此从后层到前层存在：

- 完整长路径；
- 多条较短路径；
- 纯 identity 路径。

短路径的梯度通常更稳定，所以残差连接能减少 shattered gradients。

这比单纯说“残差连接防止梯度消失”更准确。

## 17. Residual Network 的方差增长问题

相加后的方差为 $\operatorname{Var}(h+F)=\operatorname{Var}(h)+\operatorname{Var}(F)+2\operatorname{Cov}(h,F)$。在相关项不抵消且各分支尺度未受控制时，方差可能随深度增长；不能仅凭“方差相近”就断言必然增长。

因此：

> residual connection 本身解决了一类梯度问题，但也引入了前向尺度和梯度尺度稳定性问题。

UDL 给出的两类思路是：

- 对相加后的信号做适当缩放；
- 使用 normalization 控制每层激活尺度。

## 18. BatchNorm 在残差网络中的作用

BatchNorm 不只是“让均值为 0、方差为 1”。

在残差网络中，它还帮助：

- 控制深层激活方差；
- 稳定 forward propagation；
- 稳定 backward gradient；
- 允许更大学习率；
- 平滑部分 loss geometry。

训练和推理必须区分：

- 训练：使用 batch statistics；
- 推理：使用训练阶段积累/重新估计并冻结的统计量。

## 19. 为什么 Residual Network 有效仍非单一答案

现有解释包括：

- 减少 shattered gradients；
- 提供大量短计算路径；
- 使损失表面更平滑；
- 更容易接近 identity mapping；
- 与 normalization 一起稳定超深网络训练。

但 UDL 也强调：**残差网络的性能提升不能简单等同于“越深越好”。**

Wide ResNet 等结果说明，较浅但更宽的 residual network 也能表现很好。因此 residual connection 的核心价值首先是改善可训练性和架构归纳偏置，而不是单纯增加层数。

## 尺寸、参数与边界的检查

输入形状 `(批量=2, 通道=3, 高=32, 宽=32)`，输出通道 8，卷积核 3、步长 2、填充 1、dilation 1、groups 1。每轴输出为 $\lfloor(32+2-2-1)/2\rfloor+1=16$，总形状 `(2, 8, 16, 16)`；含偏置参数为 $(3\times3\times3+1)\times8=224$。

自查：保持其他参数，仅令 dilation=2，输出尺寸是多少？**答案：**15×15，因为有效核宽为 $2(3-1)+1=5$。参数数量仍为 224；扩大采样间隔不增加核内可学习权重数量。
