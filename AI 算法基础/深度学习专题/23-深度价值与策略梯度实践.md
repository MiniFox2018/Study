## 1. 先把训练数据的边界定义正确

### 1.1 一条 transition 至少要保存什么

观测 $s_t$ 经策略选动作 $a_t$，环境给出 $r_{t+1}$ 和实际后继观测 $s_{t+1}$。建议保存 `obs, action, reward, final_obs, terminated, truncated`；策略算法另外保存采样时的 `log_prob, value, policy_version`。这里 `final_obs` 是**当前动作真正到达的观测**，不是环境自动重置后的初始观测。

`terminated` 表示任务定义中的终止，例如到达目标、失败或内生有限时域结束。`truncated` 表示采样因外部时间或资源限制中断，底层任务仍可继续。二者都要求重置环境；但价值目标通常只有 `terminated` 才清掉未来价值。若规定“第十步后游戏真正结束”，剩余时间影响最优决策，应把时间纳入状态以保持 Markov 性，并按真正终止处理。若无限时域任务只是每十步截一次采样，则属于截断。不要仅看代码里是否有 `max_steps` 来决定数学语义。[Gymnasium 官方边界说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

DQN 的一步目标为 $y_t=r_{t+1}+\gamma(1-z_t)\widehat Q(s_{t+1})$，$z_t$ 仅表示真实终止。若 $r=1,\gamma=0.9,\widehat Q=3$，终止目标为 $1$，外部截断目标为 $3.7$。后者是**估计的 bootstrap target**，不是已经观测到的真实完整回报；Critic 错误会进入这个估计。

向量环境是否在当前 `step` 自动重置、下一次 `step` 才重置，或禁用自动重置，取决于其版本与模式。接入真实库时查该模式的 `info` 与末观测字段，不把旧版本固定字段名套到所有包装器。本章手动重置，始终先记录真实后继观测，再 reset。

### 1.2 GAE 的两个掩码与 rollout 边界

给定采集时冻结的 $V_t,V_{t+1}^{\mathrm{final}}$，定义

$$
\delta_t=r_{t+1}+\gamma b_t V_{t+1}^{\mathrm{final}}-V_t,
\qquad
\widehat A_t=\delta_t+\gamma\lambda c_t\widehat A_{t+1}.
$$

$b_t=1-\mathrm{terminated}_t$ 决定 bootstrap；$c_t=1-(\mathrm{terminated}_t\lor\mathrm{truncated}_t)$ 决定是否继续同一回合的优势链。最后一条 rollout 记录把后续优势初始为零，但仍可用其真实末观测的 $V$；这不等于回合真正终止。若把多个非连续采样片段拼接，片段连接处也必须关闭 trace。不同环境须按 `[T,N]` 的列分别递推，不能把扁平数组的相邻元素当同一轨迹。

$\lambda=0$ 为一步 TD residual；$\lambda=1$ 在完整终止回合中望远镜消去中间 $V$，得到 $G_t-V_t$。截断时得到含末状态 bootstrap 的 n-step target，不是纯 MC。$0<\lambda<1$ 混合不同长度估计，通常在方差与 Critic 偏差之间取舍；不存在与所有任务无关的最佳 $0.95$。[GAE 原论文](https://arxiv.org/abs/1506.02438)

下面第一列终止后故意插入下一回合奖励 100，第二列外部截断后也插入 100。正确输出的第一行仍为 `[1,3.7]`；任何混入 100 的实现都存在跨回合泄漏。

```python
import torch
torch.set_num_threads(1)

def gae(r, v, next_v, terminated, truncated, gamma=.9, lam=.95):
    # All tensors are [T,N]; next_v belongs to the real final observation.
    assert r.ndim == 2 and r.numel() > 0
    assert all(z.shape == r.shape for z in (v, next_v, terminated, truncated))
    assert terminated.dtype == truncated.dtype == torch.bool
    assert 0 <= gamma <= 1 and 0 <= lam <= 1
    assert all(torch.isfinite(z).all() for z in (r,v,next_v))
    delta = r + gamma * (~terminated).to(r.dtype) * next_v - v
    a = torch.zeros_like(r); tail = torch.zeros(r.shape[1],dtype=r.dtype)
    for t in reversed(range(r.shape[0])):
        tail = delta[t] + gamma*lam*(~(terminated[t]|truncated[t])).to(r.dtype)*tail
        a[t] = tail
    return a.detach(), (a+v).detach()

# Column 0: terminal at t=0 followed by a new episode reward 100.
# Column 1: external cutoff at t=0 with V(final_obs)=3, then a new episode.
r = torch.tensor([[1.,1.],[100.,100.]])
v = torch.zeros_like(r); nv = torch.tensor([[9.,3.],[0.,0.]])
term = torch.tensor([[True,False],[True,True]])
trunc = torch.tensor([[False,True],[False,False]])
a, ret = gae(r,v,nv,term,trunc)
assert torch.allclose(a[0],torch.tensor([1.,3.7]))
assert torch.allclose(a[1],torch.tensor([100.,100.]))
# Lambda=1 telescopes to MC only with the appropriate final bootstrap.
r2=torch.tensor([[1.],[2.]])
v2=torch.tensor([[.4],[.6]])
nv2=torch.tensor([[.6],[0.]])
a2,ret2=gae(r2,v2,nv2,torch.tensor([[False],[True]]),torch.zeros(2,1,dtype=torch.bool),lam=1.)
assert torch.allclose(ret2[:,0],torch.tensor([2.8,2.]))
print('terminal/trunc targets:',ret[0].tolist(),'MC:',ret2[:,0].tolist())
```

## 2. DQN：用真实网络学习动作价值

### 2.1 从 Bellman 目标到半梯度回归

网络 $Q_\theta(s)\in\mathbb R^{|\mathcal A|}$ 一次给出所有离散动作价值。一个 minibatch 的 `gather(1,actions[:,None])` 只取实际执行动作的 $Q_\theta(s,a)$，不要把同一标量奖励广播成所有动作的监督。

目标网络参数 $\theta^-$ 暂时冻结，标准 DQN 用

$$
y=r+\gamma(1-z)\max_{a'}Q_{\theta^-}(s',a'),\quad
\mathcal L=\frac1B\sum_i\ell(Q_\theta(s_i,a_i)-y_i).
$$

MSE 可以使用，Huber 对大 TD 残差从二次过渡为线性，减少极端误差支配更新。目标用 `no_grad` 计算，是半梯度方法：更新当前预测，不同时追着目标网络反向传播。把目标网络也放入优化器，或仅复制 Python 引用 `target=q`，都会破坏冻结合同。[DQN 奠基论文](https://arxiv.org/abs/1312.5602)

没有神经网络时是表格 Q-learning；换成 MLP、CNN 或 Transformer 后，参数共享让一个状态的更新同时改变其他状态的估计。函数近似、bootstrap、off-policy 三者组合可能失稳，常称 deadly triad。这是风险条件，不是“任何实现必然发散”。经验回放随机抽样降低相邻观测相关性、提高数据复用；数据仍来自有限且偏置的轨迹，不能保证样本独立或收敛。

### 2.2 Replay、target 与探索的实际合同

Replay 有限容量，保存原始 transition。可用 deque/ring buffer；容量满时淘汰最旧记录。存 NumPy 数组或环境复用的图像缓冲时要复制，否则后续 `step` 会覆写历史。离线只存梯度图中的旧 logits，不等价于可复用的观测。先积累足够多样的 warmup，再均匀抽取 minibatch；重复抽样、是否放回、随机种子都要记录。

hard update 为每 $C$ 次**梯度更新**执行 `target.load_state_dict(q.state_dict())`；也可按环境步计数，但必须明确单位。soft update 为 $\theta^-\leftarrow(1-\tau)\theta^-+\tau\theta$，应在 `no_grad` 中更新，每次小幅变化。太快使目标追随预测，太慢使目标陈旧；一万步不是定理。带 BatchNorm/Dropout 的模型还要处理运行状态和训练/推断模式，本例不用这些层。

$\epsilon$-greedy 在采样阶段以 $\epsilon$ 随机动作，其余取最大 $Q$；训练过程中衰减，评估时固定所声明的规则。全程 $\epsilon=1$ 仍可生成学习数据，只是行为策略一直随机；不能把它写成算法必然无效。帧堆叠可帮助像素观测推断速度，但不能保证有限帧把任意 POMDP 变成 MDP。

DQN 允许连续、高维**观测**。困难主要在大规模或连续**动作**的 $\arg\max$：有限离散输出头无法直接枚举任意实数动作。可以有依据地离散化，但误差与组合数增长需评估；连续控制通常比较 TD3/SAC 等方法，而不是把 softmax 换成高斯就得到 DQN。

### 2.3 Double DQN 与扩展各解决什么

同一估计器既选最大值又评估，会挑中噪声偏大的动作。Double DQN 用 online 网络选择 $a^*=\arg\max Q_\theta(s',a)$，target 网络评估 $Q_{\theta^-}(s',a^*)$。例如 online `[1,4]` 选第二个动作，target `[5,2]` 评估得 2；标准 max target 得 5。两网络仍相关，偏差没有保证完全消失，也不保证每个任务最终回报更高。[Double DQN 原论文](https://arxiv.org/abs/1509.06461)

其他扩展在[强化学习](11-深度强化学习.md)主干维护：Dueling 用 $Q=V+A-\mathrm{mean}(A)$ 解决分解可辨识性；PER 用 TD-error 优先级改变采样分布，并用重要性权重控制偏差；n-step 改变目标长度和终止/截断处理；NoisyNet 学习参数化探索；分布式回报表示学习回报分布，区别于多个设备的分布式训练。Rainbow 组合这些机制，组件交互需消融检验，不能把各自增益直接相加。

### 2.4 完整 CPU DQN：采集、回放、目标与梯度

自建五个位置的 Line 任务，动作左/右，到 4 奖励 1，其余每步 -0.02。底层任务没有七步内生终止，七步只是采样截断。观测 one-hot 是为了让机制容易检查；MLP 会真实求梯度并更新。800 个环境步、32 条 minibatch、40 次梯度更新同步、$\gamma=.9$ 都只属于本例。

```python
import random, copy
from collections import deque
import torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(5); rng=random.Random(5)

class Line:
    # Infinite-horizon underlying task, absorbing goal; 7-step sampling cutoff.
    def reset(self): self.s=0;self.steps=0;return self.s
    def step(self,a):
        assert a in (0,1)
        self.s=max(0,min(4,self.s+(-1 if a==0 else 1)));self.steps+=1
        term=self.s==4;trunc=self.steps==7 and not term
        return self.s, (1. if term else -.02), term, trunc

def obs(s):return F.one_hot(torch.as_tensor(s),5).float()
q=nn.Sequential(nn.Linear(5,16),nn.ReLU(),nn.Linear(16,2))
target=copy.deepcopy(q).requires_grad_(False)
opt=torch.optim.Adam(q.parameters(),lr=.003); replay=deque(maxlen=512)
updates=0; syncs=0; losses=[]; env=Line();s=env.reset()
for env_step in range(800):
    eps=max(.1,1.-env_step/500)
    with torch.no_grad():a=rng.randrange(2) if rng.random()<eps else int(q(obs(s)).argmax())
    ns,r,term,trunc=env.step(a)
    # Immutable integer fixture; image arrays would need copies, not references.
    replay.append((s,a,r,ns,term,trunc))
    s=env.reset() if term or trunc else ns
    if len(replay)<32:continue
    batch=rng.sample(list(replay),32)
    ss,aa,rr,nss,tt,cut=zip(*batch)
    aa=torch.tensor(aa); rr=torch.tensor(rr);tt=torch.tensor(tt)
    old_target=[p.clone() for p in target.parameters()]
    with torch.no_grad():
        next_action=q(obs(nss)).argmax(-1)   # online selects, target evaluates
        nxt=target(obs(nss)).gather(1,next_action[:,None]).squeeze(1)
        y=rr+.9*(~tt).float()*nxt           # truncation does NOT zero bootstrap
    pred=q(obs(ss)).gather(1,aa[:,None]).squeeze(1)
    loss=F.smooth_l1_loss(pred,y,beta=1.)
    opt.zero_grad();loss.backward()
    assert all(p.grad is None for p in target.parameters())
    assert all(torch.isfinite(p.grad).all() for p in q.parameters())
    nn.utils.clip_grad_norm_(q.parameters(),10.);opt.step();updates+=1
    assert all(torch.equal(a,b) for a,b in zip(old_target,target.parameters()))
    if updates%40==0:target.load_state_dict(q.state_dict());syncs+=1
    losses.append(float(loss.detach()))
# Deliberately discordant estimators prove the Double-DQN action selection.
online_next=torch.tensor([[1.,4.]]); target_next=torch.tensor([[5.,2.]])
double=target_next.gather(1,online_next.argmax(-1,keepdim=True)).item()
assert double==2 and target_next.max().item()==5
assert torch.allclose(torch.tensor([1.,1.])+.9*torch.tensor([0.,1.])*3,torch.tensor([1.,3.7]))
env=Line();s=env.reset();path=[s];score=0.
for _ in range(7):
    with torch.no_grad():a=int(q(obs(s)).argmax())
    s,r,term,trunc=env.step(a);path.append(s);score+=r
    if term or trunc:break
print('updates',updates,'target_syncs',syncs,'mean_last_loss',round(sum(losses[-50:])/50,6))
print('greedy_path',path,'return',round(score,3),'Double/max',double,5)
```

本次输出 `updates 769 target_syncs 19`，greedy 路径 `[0,1,2,3,4]`，未折扣累计回报 `.94`，与三次 `.02` 代价及终点奖励一致。尾部平均损失打印为六位小数的 `0.0`，不意味着所有误差严格为零。断言验证 target 参数在普通更新中逐位不变、target 无梯度、Double 的选择/评估分离、终止与截断目标不同。这个简单任务不测试高维图像、随机转移、稀疏长时回报或离线分布外动作。

## 3. REINFORCE：把概率梯度与回报正确相乘

### 3.1 推导中的概率、时间与符号

设策略为可微的 $\pi_\theta(a|s)$，初始分布和环境转移不依赖 $\theta$，动作概率支持集合在求导范围内稳定，可以交换导数与期望。轨迹概率中只有策略项产生梯度：$\nabla\log P_\theta(\tau)=\sum_t\nabla\log\pi_\theta(a_t|s_t)$。用 score-function 恒等式，将不可微的采样环境与可微策略连接起来。

对于明确的有限回合起点目标

$$
J(\theta)=\mathbb E\left[\sum_{t=0}^{T-1}\gamma^t r_{t+1}\right],\quad
G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_{k+1},
$$

有 $\nabla J=\mathbb E[\sum_t\gamma^tG_t\nabla\log\pi_\theta(a_t|s_t)]$。移去过去奖励，利用其对当前 score 的条件期望为零，得到 reward-to-go；不是任意删掉一段奖励。若选择 $\gamma=1$ 或用折扣状态占用分布定义其他 surrogate，表达形式可不同；不要无说明丢掉外层 $\gamma^t$ 后仍称同一个起点目标的精确梯度。

最大化 $J$ 是梯度上升；PyTorch 优化器通常最小化，因此 `loss=-(log_prob*advantage.detach()).sum()`。正优势增加该动作概率，负优势降低它。softmax 多类 logits 的 score 是 $e_a-p$，改变一个动作概率会通过归一化影响其他动作，不可独立相加后忘记归一化。

### 3.2 Baseline 的无偏条件与有限样本陷阱

状态基线 $b(s_t)$ 在给定状态、历史与基线拟合数据后不能依赖当前随机动作，且 Actor 更新中作为常数：

$$
\mathbb E_{a\sim\pi}[b(s)\nabla\log\pi(a|s)]
=b(s)\nabla\sum_a\pi(a|s)=0.
$$

可用以前批次的 running mean、独立拟合的 Critic、留一法等。把当前动作回报本身当基线，会让优势全为零并消灭真实梯度。先用同一回合 $G_0$ 更新均值，再立即乘该回合的所有 score，也会引入统计依赖；不能仅因变量名是 `baseline` 就保证无偏。

减去任意合法基线不改期望，但不保证降低方差；在给定状态的平方梯度范数意义下，最优标量基线涉及 $\mathbb E[G\|\nabla\log\pi\|^2]/\mathbb E[\|\nabla\log\pi\|^2]$，不总等于普通 $V(s)$。批内减均值、除样本标准差是实用尺度控制，会引入有限样本依赖、改变权重，须声明采用整批还是 minibatch；不是无偏定理。单样本归一化还可能直接把优势归零。

### 3.3 离散采样、连续动作与熵梯度

`Categorical(logits=...)` 内部稳定归一化；`sample()` 选动作，`log_prob(action)` 返回该动作的对数概率。不要用 `log(max(p,1e-12))` 的截断替代稳定 log-softmax 后误以为数学完全等价；极小概率的梯度会改变。

连续动作可用 $a\sim\mathcal N(\mu(s),\sigma(s)^2)$，输出 `log_std` 后取指数，限制数值范围并区分标准差与方差。普通 REINFORCE 的动作对 score 求导时必须视为固定样本；若 `rsample()` 的 $a=\mu+\sigma\epsilon$ 仍连着 $\mu$，再算 `log_prob(a)`，均值梯度会沿两条路径抵消。路径导数方法可以正确用于可微的 $Q(s,a)$ 等目标，但属于另一种估计器。[PyTorch 官方随机梯度说明](https://github.com/pytorch/pytorch/blob/main/torch/distributions/__init__.py)

若执行器把高斯动作剪到上下界，执行动作的分布含边界点质量，不等于原高斯密度。用 `tanh` 变换时 $\log\pi(a)=\log p(u)-\sum_j\log(1-\tanh^2u_j)$，再按动作范围缩放还要减去尺度的 log-Jacobian。必要时用稳定的 transformed-distribution 实现，不把被剪后的动作直接代进未变换的 Normal。多个独立动作维的 log-prob 通常相加，不能遗漏一维。

熵 $H=-\sum_i p_i\log p_i$ 的 logits 导数为 $-p_i(\log p_i+H)$，包含 softmax Jacobian 的中心项；仅用 $p_i(-\log p_i-1)$ 是漏项。梯度**下降**损失中的熵项是 $-\beta H$。熵激励分散概率，可能减缓早期确定化，但不保证探索到稀有状态；适当收敛到确定动作也不是故障。

```python
import torch
from torch.distributions import Categorical,Normal
torch.set_num_threads(1)
z=torch.tensor([.3,-.2],dtype=torch.float64,requires_grad=True)
p=z.softmax(-1); rewards=torch.tensor([0.,1.],dtype=torch.float64)
true=torch.autograd.grad((p*rewards).sum(),z,retain_graph=True)[0]
score=torch.eye(2,dtype=torch.float64)-p[None,:]
plain=(p[:,None]*rewards[:,None]*score).sum(0)
constant=(p[:,None]*(rewards-.7)[:,None]*score).sum(0)
wrong=(p[:,None]*(rewards-rewards)[:,None]*score).sum(0)
assert torch.allclose(true,plain) and torch.allclose(true,constant)
assert not torch.allclose(true,wrong)
# Baseline sign under gradient DESCENT on negative log-probability.
a=torch.tensor(1); old=float(p[a].detach())
opt=torch.optim.SGD([z],lr=.1)
loss=-Categorical(logits=z).log_prob(a)*torch.tensor(1.)
opt.zero_grad();loss.backward();opt.step()
assert float(z.softmax(-1)[a].detach())>old
# Score-function sampling must treat the action as fixed during log_prob.
mu=torch.tensor(.4,requires_grad=True);dist=Normal(mu,torch.tensor(1.))
noise=torch.tensor(.7); action=mu+noise      # controlled rsample-like path
wrong_g=torch.autograd.grad(dist.log_prob(action),mu,retain_graph=True)[0]
score_g=torch.autograd.grad(dist.log_prob(action.detach()),mu)[0]
assert abs(float(wrong_g))<1e-7 and torch.allclose(score_g,noise)
# Correct softmax-entropy Jacobian, unlike a per-coordinate p*(-log p-1).
z2=torch.tensor([.3,-.2],requires_grad=True);pp=z2.softmax(-1)
H=-(pp*pp.log()).sum();hg=torch.autograd.grad(H,z2)[0]
formula=-pp*(pp.log()+H.detach())
assert torch.allclose(hg,formula,atol=1e-7) and abs(float(hg.sum()))<1e-7
print('expected gradients',true.tolist(),'bad action baseline',wrong.tolist())
print('Normal log_prob gradients through action/detached:',float(wrong_g),float(score_g))
print('entropy gradient sum',round(float(hg.sum()),8))
```

输出的真实期望梯度约 `[-.235,.235]`，合法常数基线保持同值，动作回报基线得 `[0,0]`。Normal 错误连着动作的 score 梯度为 0，detach 后为 `.7`。这些是枚举/自动求导的机制验证，未声称对任意环境都有低方差。

### 3.4 完整 REINFORCE 小训练与数据新鲜度

本例每回合两次决策；状态含时间，终止真正发生在第二步。第一步最佳动作为 0，第二步为 1，每步命中得 1。一次采样 32 回合，只进行一次 Actor 更新；基线先使用上一批状态均值，随后才更新。目标上限 $1+.9=1.9$。

```python
import torch
from torch import nn
from torch.distributions import Categorical
torch.set_num_threads(1);torch.manual_seed(8)
# Two-decision episodic task: desired actions are 0 at t=0, 1 at t=1.
# State includes time; both rewards are immediate; termination is truly at T=2.
policy=nn.Sequential(nn.Linear(2,16),nn.Tanh(),nn.Linear(16,2))
opt=torch.optim.Adam(policy.parameters(),lr=.02);gamma=.9
baseline=torch.zeros(2)  # frozen PRIOR-batch state/time baselines
for update in range(80):
    obs=torch.eye(2).repeat(32,1)   # [episode0 t0,t1, episode1 t0,t1,...]
    dist=Categorical(logits=policy(obs));a=dist.sample()
    rewards=(a.reshape(32,2)==torch.tensor([0,1])).float()
    G=torch.empty_like(rewards);G[:,1]=rewards[:,1];G[:,0]=rewards[:,0]+gamma*G[:,1]
    adv=(G-baseline[None,:]).detach()
    # Exact discounted start-state objective: extra gamma^t is explicit.
    loss=-(dist.log_prob(a).reshape(32,2)*adv*torch.tensor([1.,gamma])).sum(1).mean()
    opt.zero_grad();loss.backward();opt.step()
    # Update baseline only AFTER actor used the prior batch baseline.
    baseline=.9*baseline+.1*G.mean(0).detach()
with torch.no_grad():
    p=policy(torch.eye(2)).softmax(-1)
    expected=p[0,0]+gamma*p[1,1]
assert torch.isfinite(p).all() and torch.isfinite(expected)
print('desired action probabilities:',[round(float(p[0,0]),4),round(float(p[1,1]),4)])
print('expected discounted return',round(float(expected),4),'maximum',1+gamma)
```

本次最佳动作概率约 `[.9999,.9996]`，期望折扣回报 `1.8995`。这验证完整采样→回报→梯度流程。长回合 REINFORCE 可能方差大，可增加完整回合批量、合法基线、reward-to-go，或选择 bootstrap 方法；没有“超过 500 步必须禁止”的数学界限。若外部截断却把未来回报当零，本来追求完整回报的 MC 目标会偏；可以等待完整回合，或明确切换为带末状态价值的估计，并承认 Critic 偏差。

普通 REINFORCE 按当前策略采样，旧样本与已更新策略不再同分布。重要性采样可纠正相应分布，但长轨迹比例乘积方差很大，不能随意把 DQN replay 套进来。DPO 的偏好目标、SAC 的熵正则 Q-learning 与重参数化、GRPO 的组内估计各有自己的假设；“REINFORCE 加一个小技巧”不能代替它们的完整推导。

## 4. Actor–Critic：估计优势与回归价值

### 4.1 MC、TD、n-step 与 GAE 如何连接

Actor 输出策略，Critic 输出预期回报。$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$ 是真实条件期望之差；$G_t-V_\phi(s_t)$、TD residual 和 GAE 是它的**估计器**，不能把一条样本回报叫真实 $Q$。

MC 估计不从后继 Critic bootstrap，完整回合在合法状态基线条件下可保持 Actor score 的无偏性，但长回报方差大。一步 TD 用 $r+\gamma V(s')-V(s)$，当 $V=V^\pi$ 时条件期望等于优势；实际 Critic 的误差会引入偏差。n-step 先累加 $n$ 个折扣奖励，再接 $\gamma^nV(s_{t+n})$；在真实终止处接零，在外部截断处用真实末观测。GAE 是多长度 residual 的指数加权，递推和边界见 §1.2。

Critic 目标可以是 MC 回报，也可以是冻结旧 Critic 计算的 n-step/GAE lambda-return $\widehat R=\widehat A+V_{\mathrm{old}}$。不要把 `V_now + advantage_now` 留在求导图中当自身 target，否则价值头可能通过修改 target 来逃避回归。Critic 快慢、偏差、Actor 步长和采样分布相互影响；“Critic 先训练若干固定轮才允许 Actor”不是所有任务必需的流程。

### 4.2 两个优化器与共享干路的梯度边界

若 Actor 与 Critic 参数完全分离，可用两个优化器，Actor 的优势 detach，Critic 的 target detach。最小化

$$
\mathcal L_{\mathrm{actor}}=-\mathbb E[\log\pi_\theta(a|s)\widehat A]-c_e\mathbb E[H(\pi)],
\qquad
\mathcal L_{\mathrm{critic}}=\mathbb E[(V_\phi(s)-\widehat R)^2].
$$

两个梯度图独立，因此可以分别 backward/step。若共用 trunk，用一个优化器汇总 `actor + c_v*critic - c_e*entropy` 后一次 step。`adv.detach()` 防止策略损失利用 Critic 头改变“优势”，但 Actor 仍通过自身 logits 更新共享 trunk；它不意味着整个 trunk 冻结。

把共享参数重复放进两个 Adam 优化器，分别维护矩估计并连续 step，会对同一参数更新两次。先 step Actor 再对旧的共享图 backward Critic 还可能触发版本错误或使用陈旧梯度。若坚持独立优化器，明确分区或重新前向并说明目标，不能直接复制两网络写法。

### 4.3 完整同步 Actor–Critic：`[T,N]` 采样

两个 Line 环境逻辑同步，每次各取一个 transition，收集 `[12,2]` 后更新。这里用 Python 顺序调用 `step`，**没有声称环境计算并行**；A2C 的同步含义是同一个版本采样、对齐收集、一次批量更新。无优势归一化也可有效运行，熵和损失系数仅用于这个例子。

```python
import torch
from torch import nn
from torch.distributions import Categorical
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(11)
class Line:
    def reset(self):self.s=0;self.n=0;return self.s
    def step(self,a):
        self.s=max(0,min(4,self.s+(-1 if a==0 else 1)));self.n+=1
        term=self.s==4;trunc=self.n>=7 and not term
        return self.s,1. if term else -.02,term,trunc

def features(s):return F.one_hot(torch.as_tensor(s),5).float()
actor=nn.Sequential(nn.Linear(5,16),nn.Tanh(),nn.Linear(16,2))
critic=nn.Sequential(nn.Linear(5,16),nn.Tanh(),nn.Linear(16,1))
actor_opt=torch.optim.Adam(actor.parameters(),lr=.01)
critic_opt=torch.optim.Adam(critic.parameters(),lr=.01)
assert {id(p) for p in actor.parameters()}.isdisjoint({id(p) for p in critic.parameters()})
envs=[Line(),Line()];states=[e.reset() for e in envs];T=12;N=2;gamma=.9;lam=.95
before=[p.detach().clone() for p in actor.parameters()]
for update in range(40):
    xs=[];actions=[];rs=[];vs=[];nvs=[];terms=[];truncs=[]
    for _ in range(T):
        x=features(states)
        with torch.no_grad():
            dist=Categorical(logits=actor(x));a=dist.sample();v=critic(x).squeeze(-1)
        transitions=[e.step(int(ai)) for e,ai in zip(envs,a)]
        ns,r,term,trunc=map(list,zip(*transitions))
        with torch.no_grad():nv=critic(features(ns)).squeeze(-1)  # BEFORE reset
        xs.append(x);actions.append(a);rs.append(torch.tensor(r));vs.append(v);nvs.append(nv)
        terms.append(torch.tensor(term));truncs.append(torch.tensor(trunc))
        states=[e.reset() if te or tr else sn for e,sn,te,tr in zip(envs,ns,term,trunc)]
    r,v,nv=torch.stack(rs),torch.stack(vs),torch.stack(nvs)
    te,tr=torch.stack(terms),torch.stack(truncs)
    delta=r+gamma*(~te).float()*nv-v;a_hat=torch.zeros_like(r);carry=torch.zeros(N)
    for t in reversed(range(T)):
        carry=delta[t]+gamma*lam*(~(te[t]|tr[t])).float()*carry;a_hat[t]=carry
    returns=(a_hat+v).detach();adv=a_hat.detach()  # no advantage normalization here
    x=torch.stack(xs).reshape(T*N,5);act=torch.stack(actions).flatten()
    dist=Categorical(logits=actor(x))
    # Per-transition rollout surrogate, not exact gamma^t start-objective weighting.
    actor_loss=-(dist.log_prob(act)*adv.flatten()).mean()-.01*dist.entropy().mean()
    actor_opt.zero_grad();critic_opt.zero_grad();actor_loss.backward()
    assert all(p.grad is None for p in critic.parameters())
    nn.utils.clip_grad_norm_(actor.parameters(),5.);actor_opt.step()
    actor_opt.zero_grad(set_to_none=True)
    value_loss=F.mse_loss(critic(x).squeeze(-1),returns.flatten())
    critic_opt.zero_grad();value_loss.backward()
    assert all(p.grad is None for p in actor.parameters())
    nn.utils.clip_grad_norm_(critic.parameters(),5.);critic_opt.step()
    assert torch.isfinite(actor_loss) and torch.isfinite(value_loss)
assert any(not torch.equal(a,b) for a,b in zip(before,actor.parameters()))
with torch.no_grad():p=actor(features([0,1,2,3])).softmax(-1)[:,1]
print('synchronous rollout shape',tuple(r.shape),'updates',40)
print('right-action probabilities',[round(float(z),3) for z in p],'last_value_loss',round(float(value_loss.detach()),5))
```

本次输出状态 0–3 的向右动作概率约 `[.990,.964,.979,.990]`。断言确认 Actor 参数实际变化、两优化器参数集合不重叠、Actor backward 后 Critic 无梯度、Critic backward 后 Actor 无梯度。程序采用按 rollout transition 平均的常见训练 surrogate，没有为每个回合重建精确起点目标的外层 $\gamma^t$；它与 §3.1 所定义的精确有限回合梯度须区分。

共享 trunk 的独立检查如下。没有环境训练，只验证 Actor 不对 Critic 头求导、共享干路收到两种目标的梯度，并执行一次真实更新。

```python
import torch
from torch import nn
from torch.distributions import Categorical
torch.set_num_threads(1);torch.manual_seed(2)
trunk=nn.Sequential(nn.Linear(3,5),nn.Tanh());pi=nn.Linear(5,2);value=nn.Linear(5,1)
params=list(trunk.parameters())+list(pi.parameters())+list(value.parameters())
opt=torch.optim.Adam(params,lr=.01);x=torch.eye(3);a=torch.tensor([0,1,0])
h=trunk(x);d=Categorical(logits=pi(h));v=value(h).squeeze(-1)
target=torch.tensor([1.,-.3,.8]);adv=(target-v).detach()
actor_loss=-(d.log_prob(a)*adv).mean()-.01*d.entropy().mean()
critic_loss=.5*(v-target.detach()).square().mean()
actor_grads=torch.autograd.grad(actor_loss,params,retain_graph=True,allow_unused=True)
assert all(g is None for g in actor_grads[-2:])  # actor has no critic-head gradient
assert any(g is not None and g.abs().sum()>0 for g in actor_grads[:2])
opt.zero_grad();(actor_loss+critic_loss).backward()
assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in params)
opt.step()
print('critic head detached from actor; shared trunk receives combined gradients; one optimizer step')
```

## 5. A2C 与 A3C：采样时钟和参数版本

A2C 等待本批各环境的数据，统一估计优势，按同一参数版本更新；一个环境也可以做同步 Actor–Critic，效率由任务和设备决定。增加环境数可能提高状态覆盖和吞吐，但也增加内存，改变每次更新样本数。`N*T` 相同不保证轨迹长度分布和计算成本相同。

A3C 让多个 worker 持有局部参数副本，独立采样一小段 trajectory、累积 Actor/Critic 梯度并推给共享参数，不等待其他 worker 完成。数据和梯度对应的版本会落后于当前参数。真正异步包括并发调度、版本差、共享更新的竞态控制；循环八次 rollout 只是顺序采样。[A3C 原论文](https://arxiv.org/abs/1602.01783)

原 A3C 研究过异步无锁更新，但不是“任何模型和优化器的竞态都无害”。工程实现要决定参数更新锁、共享 optimizer 状态、worker 异常、终止、种子和队列背压；并记录策略滞后。Critic 与 Actor 有理论上的两时间尺度分析，也有实践中的共同优化器方案，不能从一个稳定例子推导所有非线性网络的收敛保证。

下面是真实的两个 worker 线程：均取版本 0 的局部网络，用不同的固定单步终止 transition 计算完整策略/价值梯度；中央 learner 先应用 worker 1，再应用迟到的 worker 0。后者版本滞后 1。Barrier/Event 是为了可重复触发这一情况，更新加锁。**它验证异步梯度传输和版本滞后，不是完整 A3C 训练或吞吐测试**；动作固定为 fixture，没有模拟真实性能数据。

```python
import copy,threading,queue
import torch
from torch import nn
from torch.distributions import Categorical
torch.set_num_threads(1);torch.manual_seed(4)
# A tiny actor/critic with disjoint output heads; actual concurrent worker threads.
class AC(nn.Module):
    def __init__(self):super().__init__();self.pi=nn.Linear(1,2);self.v=nn.Linear(1,1)
    def forward(self,x):return Categorical(logits=self.pi(x)),self.v(x).squeeze(-1)
shared=AC();optimizer=torch.optim.SGD(shared.parameters(),lr=.05)
lock=threading.Lock();barrier=threading.Barrier(2);applied_first=threading.Event()
packets=queue.Queue();version=0

def worker(wid):
    with lock:local=copy.deepcopy(shared);read_version=version
    barrier.wait(timeout=10)  # force both workers to have read version 0
    x=torch.ones(1,1);dist,v=local(x)
    # One terminal bandit transition; fixed realized action makes the demo repeatable.
    a=torch.tensor([wid]);reward=torch.tensor([float(wid)])
    advantage=(reward-v).detach()
    loss=-(dist.log_prob(a)*advantage).mean()+.5*(v-reward).square().mean()
    loss.backward();grads=[p.grad.detach().clone() for p in local.parameters()]
    if wid==0:assert applied_first.wait(timeout=10)
    packets.put((wid,read_version,grads))

threads=[threading.Thread(target=worker,args=(i,),name=f'worker-{i}') for i in range(2)]
for th in threads:th.start()
logs=[]
for _ in range(2):
    wid,read_version,grads=packets.get(timeout=10)
    with lock:
        lag=version-read_version;optimizer.zero_grad()
        for p,g in zip(shared.parameters(),grads):p.grad=g
        optimizer.step();version+=1
    logs.append((wid,read_version,lag,version))
    if wid==1:applied_first.set()
for th in threads:th.join(timeout=10);assert not th.is_alive()
assert logs==[(1,0,0,1),(0,0,1,2)]
print('(worker,read_version,lag,applied_version):',logs)
```

输出 `(worker,read_version,lag,applied_version)` 为 `[(1,0,0,1),(0,0,1,2)]`。若要做真正的训练实验，每个 worker 还需真实策略采样、n-step/GAE、每条记录的回合边界、周期同步、长期停止条件及失败管理。大规模 Actor/Learner 分离系统常有更大滞后，IMPALA 的 V-trace 与策略滞后背景在[强化学习进阶与世界模型](15-强化学习进阶与世界模型.md)概述，本章没有实现完整V-trace校正；它不是简单把 A3C worker 数增加即可得到。

## 6. PPO：固定旧策略的数据，多轮优化 surrogate

### 6.1 Importance ratio 与 clip 的分段数学

采样策略为 $\pi_{\mathrm{old}}$，在 rollout 时记录动作、旧 log-prob、旧 value。更新时 $r=\exp(\log\pi_\theta(a|s)-\log\pi_{\mathrm{old}}(a|s))$，使用固定的 $\widehat A$：

$$
L^{\mathrm{clip}}=\mathbb E[\min(r\widehat A,\mathrm{clip}(r,1-\epsilon,1+\epsilon)\widehat A)].
$$

$\widehat A>0$ 时单样本目标为 $\widehat A\min(r,1+\epsilon)$，只在 $r>1+\epsilon$ 的有利方向变平；$r<1-\epsilon$ 仍有梯度。$\widehat A<0$ 时为 $\widehat A\max(r,1-\epsilon)$，只在 $r<1-\epsilon$ 变平；$r>1+\epsilon$ 仍有梯度。不能根据优势符号把原始两个乘积的 `min` 改成 `max`。边界点导数采用自动微分的次梯度，测试应避开精确拐点。[PPO 原论文](https://arxiv.org/abs/1707.06347)

Clip 不是把策略概率硬夹住，也不是严格 KL 约束。一个动作的平坦项可能同时受到其他动作/状态的参数共享梯度、价值损失与熵更新；其概率仍会继续变。PPO 没有“每轮必定单调提高回报”的一般保证，更不能只因 $K\le30,\epsilon\le.3$ 就宣称安全 trust region。

```python
import torch
torch.set_num_threads(1)
r=torch.tensor([.5,1.5,.5,1.5],requires_grad=True)
a=torch.tensor([1.,1.,-1.,-1.]);eps=.2
L=torch.minimum(r*a,r.clamp(1-eps,1+eps)*a)
g=torch.autograd.grad(L.sum(),r)[0]
assert torch.allclose(L,torch.tensor([.5,1.2,-.8,-1.5]))
assert torch.allclose(g,torch.tensor([1.,0.,0.,-1.]))
old=torch.tensor([.5,.5]);new=torch.tensor([.6,.4])
exact=(old*(old.log()-new.log())).sum()
# A one-action sample under old can have a negative sample estimate.
sample=(old.log()-new.log())[0]
dlog=new.log()-old.log();nonneg=torch.expm1(dlog)-dlog
assert exact>0 and sample<0 and (nonneg>=0).all()
print('surrogate',L.detach().tolist(),'derivative w.r.t. ratio',g.tolist())
print('exact KL(old||new)',round(float(exact),6),'one-sample estimate',round(float(sample),6))
```

四个目标值依次为 `[.5,1.2,-.8,-1.5]`，对 ratio 的导数为 `[1,0,0,-1]`。同块的有限分类分布严格 $D_{KL}(old\|new)\approx.020411$，只取旧策略采到动作 0 的 log-ratio 样本估计为 `-.182322`。有限样本 `mean(old_logp-new_logp)` 可以为负，不意味着真正的 KL 为负。

### 6.2 数据冻结、价值、熵与多 epoch

旧动作 log-prob 以及用于完整分类 KL 的全部动作 log-softmax 从采样时取得并 detach/clone，整个本批 $K$ 个 epoch 中保持同一个分母；每次 minibatch 只重新算 `new_logp`。若用当前策略不断覆盖分母，ratio 近似恒为 1，失去偏离采样策略的度量。旧优势、returns 和必要的 old-values 同样冻结。观测归一化状态、Dropout/BatchNorm 模式、动作 mask 若在采样与更新间变化，也会改变所代表的分布。本例避免这些复杂状态。

将 `[T,N]` 算完 GAE 后才 flatten 成 minibatch。每个 epoch 打乱样本，依次计算

$$
\mathcal L=-L^{\mathrm{clip}}+c_v\mathcal L_V-c_eH,
\quad \mathcal L_V=\tfrac12\mathbb E[(V_{\mathrm{now}}-\widehat R)^2].
$$

value clipping 是可选实现：$V_{\mathrm{clip}}=V_{\mathrm{old}}+\mathrm{clip}(V_{\mathrm{now}}-V_{\mathrm{old}},-\epsilon_V,\epsilon_V)$，用两种平方误差的较大值作为保守目标；是否需要它与奖励尺度、任务有关，$\epsilon_V$ 不是自动等于 policy ratio 的无量纲 $\epsilon$。熵奖励可影响探索，梯度裁剪约束这次梯度范数，均不直接约束最终 KL。

多轮复用只针对近期该策略的一个 rollout，在数据过旧前换新样本。不能任意从多年历史 replay 混入后仍自称 PPO。batch normalization优势的尺度和符号可能随 minibatch 改变，若使用必须说明；本例故意关闭，保留固定原优势。

### 6.3 诊断的定义与异常解释

| 量 | 计算与能解释的范围 |
|---|---|
| 严格分类 KL | 在本批观测上枚举动作：$\sum_a p_{old}(a)(\log p_{old}(a)-\log p_{new}(a))$；本例可计算。是经验状态分布上的均值，不是所有可达状态的界。 |
| 样本 KL 估计 | `mean(old_logp-new_logp)` 按旧策略样本估计同方向 KL，有限样本可负。$e^{\Delta}-1-\Delta$ 非负估计形式在正确旧分布采样下也有相应期望，数值小差可用 `expm1`。 |
| ratio 超带比例 | $r<1-\epsilon$ 或 $r>1+\epsilon$ 的比例。它不等于按优势符号真正落在平坦区的比例。 |
| explained variance | $1-\mathrm{Var}(\widehat R-V)/\mathrm{Var}(\widehat R)$；可以为负，target 方差为 0 时未定义，不能除零后报告好坏。 |
| episode return | 声明是折扣还是未折扣、采样还是 greedy、是否截断，跨多个独立 seed报告分布；不能只看 loss。 |

有限 logits 的 softmax 在极端范围仍可能下溢为零，不能再用 `old_probs.log()` 算完整 KL，否则会出现 `0*log(0)` 的 NaN。采样时另存稳定的完整 `dist.logits`（已归一化 log-softmax），用 `old_probs*(old_all_logp-new_all_logp)`，将零概率项安全地乘有限的 log 差。§6.4包含 `[0,-1000]` 的反例检查。

target-KL early stop 是启发式：一次更新后发现偏离太大，停止余下 epoch；并不会撤销已经发生的越界。若需要回滚，另存参数及 optimizer 状态，再明确接受准则。本批代码没有回滚。KL/clipfraction 过高要检查学习率、数据 freshness、mask、reward/value尺度、epochs；接近零也可能是策略已稳定或梯度太弱，不能机械规定“0.1–0.3 才正确”或“为零就必须加学习率”。

RLHF 的参考策略 KL 是对长期固定/独立的 reference 约束，PPO ratio 是对**采样旧策略**的修正，两个对象不可混为一谈。语言模型还有 token/EOS、prompt 与 padding mask、奖励边界等问题，应另读相应训练章节；本例的两个动作不替代这些合同。

### 6.4 完整 CPU PPO：采样与优化真实网络

下面共享干路的两头网络，用两个自建 Line 环境做同步逻辑采样；保存真实末状态价值、双掩码 GAE、旧概率与价值。每次最多四个 epoch，用同一个联合优化器；旧概率在整批更新后仍逐位不变。采用整批原始优势，没有归一化。评估另创建环境，只按最大动作概率执行。

```python
import torch
from torch import nn
from torch.distributions import Categorical
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(17)
class Line:
    def reset(self):self.s=0;self.n=0;return self.s
    def step(self,a):
        self.s=max(0,min(4,self.s+(-1 if a==0 else 1)));self.n+=1
        terminated=self.s==4;truncated=self.n>=7 and not terminated
        return self.s,1. if terminated else -.02,terminated,truncated

def obs(states):return F.one_hot(torch.as_tensor(states),5).float()
class AC(nn.Module):
    def __init__(self):
        super().__init__();self.trunk=nn.Sequential(nn.Linear(5,16),nn.Tanh())
        self.pi=nn.Linear(16,2);self.v=nn.Linear(16,1)
    def forward(self,x):
        h=self.trunk(x);return Categorical(logits=self.pi(h)),self.v(h).squeeze(-1)

model=AC();opt=torch.optim.Adam(model.parameters(),lr=.003)
envs=[Line(),Line()];states=[e.reset() for e in envs];T=12;N=2
GAMMA=.9;LAM=.95;EPS=.2;EPOCHS=4;MB=12;TARGET_KL=.04
before=[p.detach().clone() for p in model.parameters()];history=[]
for update in range(40):
    X=[];A=[];R=[];V=[];NV=[];TE=[];TR=[];LP=[];ALL_LP=[];P=[];ALL_LP=[]
    # Synchronous logical vector rollout; no claim of parallel execution.
    with torch.no_grad():
        for _ in range(T):
            x=obs(states);dist,v=model(x);a=dist.sample()
            ns,r,te,tr=map(list,zip(*[e.step(int(ai)) for e,ai in zip(envs,a)]))
            _,nv=model(obs(ns))                   # real final obs, before reset
            X.append(x);A.append(a);R.append(torch.tensor(r));V.append(v);NV.append(nv)
            TE.append(torch.tensor(te));TR.append(torch.tensor(tr));LP.append(dist.log_prob(a));P.append(dist.probs);ALL_LP.append(dist.logits)
            states=[e.reset() if end or cut else s for e,s,end,cut in zip(envs,ns,te,tr)]
        r,v,nv=torch.stack(R),torch.stack(V),torch.stack(NV)
        te,tr=torch.stack(TE),torch.stack(TR)
        delta=r+GAMMA*(~te).float()*nv-v;adv=torch.zeros_like(r);carry=torch.zeros(N)
        for t in reversed(range(T)):
            carry=delta[t]+GAMMA*LAM*(~(te[t]|tr[t])).float()*carry;adv[t]=carry
        returns=(adv+v).flatten().detach()
        adv=adv.flatten().detach()                # fixed rollout advantages
        # Optional entire-rollout normalization; deliberately disabled here.
        NORMALIZE_ADV=False
        if NORMALIZE_ADV:adv=(adv-adv.mean())/adv.std(unbiased=False).clamp_min(1e-8)
        x=torch.stack(X).reshape(T*N,5);act=torch.stack(A).flatten()
        old_logp=torch.stack(LP).flatten().detach().clone()
        old_probs=torch.stack(P).reshape(T*N,2).detach().clone()
        old_all_logp=torch.stack(ALL_LP).reshape(T*N,2).detach().clone()
        old_values=v.flatten().detach().clone();old_snapshot=old_logp.clone()
    epochs_done=0
    for epoch in range(EPOCHS):
        for idx in torch.randperm(T*N).split(MB):
            dist,new_v=model(x[idx]);new_logp=dist.log_prob(act[idx])
            ratio=(new_logp-old_logp[idx]).exp()
            assert torch.isfinite(ratio).all()     # do not hide overflow by clamping
            surrogate=torch.minimum(ratio*adv[idx],ratio.clamp(1-EPS,1+EPS)*adv[idx])
            policy_loss=-surrogate.mean()
            value_loss=.5*F.mse_loss(new_v,returns[idx])
            entropy=dist.entropy().mean()
            loss=policy_loss+.5*value_loss-.01*entropy
            opt.zero_grad();loss.backward()
            assert all(torch.isfinite(p.grad).all() for p in model.parameters())
            nn.utils.clip_grad_norm_(model.parameters(),5.);opt.step()
        epochs_done+=1
        with torch.no_grad():
            now,_=model(x)
            exact_kl=(old_probs*(old_all_logp-now.logits)).sum(-1).mean()
        if exact_kl>TARGET_KL:break                # diagnostic early stop, no trust guarantee
    assert torch.equal(old_logp,old_snapshot) and not old_logp.requires_grad
    with torch.no_grad():
        now,pred_v=model(x);logdiff=now.log_prob(act)-old_logp;ratio=logdiff.exp()
        outside=((ratio<1-EPS)|(ratio>1+EPS)).float().mean()
        flat=(((adv>0)&(ratio>1+EPS))|((adv<0)&(ratio<1-EPS))).float().mean()
        var=returns.var(unbiased=False)
        explained=None if var<=1e-12 else float(1-(returns-pred_v).var(unbiased=False)/var)
    history.append((float(exact_kl),float(outside),float(flat),epochs_done,explained))
assert any(not torch.equal(a,b) for a,b in zip(before,model.parameters()))
eval_env=Line();s=eval_env.reset();path=[s];score=0.
for _ in range(7):
    with torch.no_grad():dist,_=model(obs([s]));a=int(dist.probs.argmax(-1))
    s,r,te,tr=eval_env.step(a);path.append(s);score+=r
    if te or tr:break
# Finite logits can softmax-underflow to zero; do not compute log(softmax).
extreme_old=Categorical(logits=torch.tensor([0.,-1000.]))
extreme_new=Categorical(logits=torch.tensor([0.,-1200.]))
assert extreme_old.probs[1]==0
stable_kl=(extreme_old.probs*(extreme_old.logits-extreme_new.logits)).sum()
assert torch.isfinite(stable_kl)
print('extreme finite-logits KL',float(stable_kl))
print('updates',len(history),'fixed_old_logp=True; normalize_adv=False')
print('last (exact_KL,outside_fraction,flat_fraction,epochs,explained_variance):',history[-1])
print('greedy_path',path,'return',round(score,3))
```

本次运行 40 次采样更新，greedy 路径 `[0,1,2,3,4]`、未折扣回报 `.94`。最后经验 KL 约 $1.34\times10^{-7}$，超带比例与平坦比例均为 0，explained variance约 `.9974`；这些是本次简单任务的输出，不是希望所有 PPO 训练达到的阈值。断言验证所有参数梯度有限、参数实际变化、旧 log-prob 不变且无梯度图。当前没有连续动作、循环隐藏状态、分布式 worker 或真实环境吞吐测试。

## 7. 做实验、比较方法与处理源示例问题

### 7.1 匹配什么预算才是公平比较

DQN replay 的每条数据可更新多次，PPO 同批多 epoch，REINFORCE 多完整回合才更新。相同“1000 回合”不代表相同环境步、梯度更新或墙钟成本。分别记录环境交互数、gradient steps、样本重用次数、CPU/设备时间、内存与评估协议。先确定终止语义、奖励单位和评估任务，再做消融。

优先比较表格/简单基线与真实网络。选择 DQN 时确认动作可枚举、replay内存与数据分布；选择 REINFORCE 时确认能获得所定义目标的完整回报并接受样本成本；选择 Actor–Critic 时判断 Critic bootstrap偏差是否可接受；选择 PPO 时确认旧策略数据与 ratio 合同正确，不能因名字常见就跳过这些检查。

Reward clipping 到 $[-1,1]$ 会改变不同奖励大小的偏好关系；全体奖励乘正常数在无正则理想目标下可保持最优策略，但会改变网络、优化器、熵/价值相对尺度。动态归一化还改变训练时的目标/统计状态。遇到极端奖励先核查传感器/接口/定义，再决定如何处理；“最大值超过均值十倍必须 clip”在均值接近零或负值时本身也不合理。

记录训练 seed、初始化、环境版本、数据模式和全部有意义的系数。单 seed曲线只用于调试，多seed和独立评估才能判断变化是否可靠。早期减少探索、过快 value拟合、策略熵下降或 loss下降都不是成功的充分证据。来源输出的所谓 skill 是配置提示词，只吸收检查方法；它们没有被安装或执行为工具。

### 7.2 四个来源程序实跑后应如何阅读

四个原 `code/main.py` 均在 2026-10-05 完整运行、正常退出。DQN 是真正手写 one-hot→ReLU→Q 的 MLP及反向更新，其他三课使用线性 softmax/线性 value，不能把后者称为深层训练。源码没有独立 `quiz.json`，正文各三道 Exercises；本章补了可判定答案。

- 源 DQN 的 50 回合 block mean 第三个块为 `-10.42`，第四块为 `-6.84`，按其打印协议，首次高于 -10 是 150–199 回合的整块均值；打印未给出每一步滑动窗口，所以不能断言首次具体 episode。关闭 target 后是否发散应实测，没有预定答案。
- 源 REINFORCE在同回合更新 running baseline 后立刻使用，外层 $\gamma^t$ 也未保留；本章用 prior-batch基线并明确精确目标。源码把六步路径的折扣回报与 `optimal=-6` 比较，后者是未折扣值。$\gamma=.99$ 下六步全 -1 的折扣最优值为 $-(1-.99^6)/(1-.99)\approx-5.8520$。
- 源 Actor–Critic仅在正常终止 episode末尾结束；末尾到100步外部限时却把next_v设0，改变bootstrap。手写entropy梯度漏softmax中心项；本章用正确autograd并做梯度枚举检查。静态图把entropy写成最小化loss的正号，应为负号。
- 源 PPO顺序采多条rollout后flatten，没有terminal trace掩码，会把后一个回合的优势带到前一个terminal；截断记录next_v还可能取下一reset状态，末尾则0。其名为minibatch的循环逐样本step，未做真正平均批量梯度；报告输出的 `clip_frac` 统计有利方向平坦项，与一般ratio超带比例不同。新程序分别定义两种比例。

源 DQN 动画中的一万步同步、回放完全去相关和“使深度Q收敛”都不是一般保证。REINFORCE动态图是手工双峰函数的有限差分梯度上升，滑块控制步长、步数和起点；没有真实策略采样或奖励估计，不能拿其轨迹证明REINFORCE收敛。AC动态图直接设置`Q=V+delta`，只是相对基线图，不证明一个随机TD误差等于真实条件优势。PPO动态图负优势分支错误地用max：$A=-1,r=.5,\epsilon=.2$画成`-.5`，正确是`-.8`；$r=1.5$画成`-1.2`，正确是`-1.5`。静态PPO曲线的两侧平坦方向则正确，应以公式/§6.1程序为准。

## 8. 练习、答案与验收判据

以下对应四课原有十二题。开放比较题给实验协议，不编造未做的 sweep 或固定胜者。本文完整小程序的实跑与这些扩展实验分开。

1. **DQN曲线何时高于阈值？** 指定回报类型、窗口和训练/评估规则，再计算滑动均值。本次原程序只提供50回合整块值，第四块首次高于-10。要回答逐episode首次 crossing，需输出原始return并按同一窗口重算，不能从图感受估算。
2. **关闭 target会发生什么？** 在相同初始化、环境步、replay抽样及梯度预算下，把target换为online但仍detach，对比多seed回报、TD-error、Q幅度与梯度范数。可能振荡，也可能这个小任务仍稳定；没有target就自动发散是错误答案。若连detach一起去掉，已同时改变目标和求导方法，不是单一消融。
3. **Double能否减少Q过估计？** 在奖励有零均值噪声、其余任务一致的环境分别训练，独立求解/模拟高精度参考 $V^*$，比较 $\max_aQ(s_0,a)-V^*(s_0)$ 与真实策略回报。噪声改变了目标期望、动作选择或终止时必须重新定义参考。§2.4的`2 vs5`只验证选择与评估，不是偏差实验。
4. **REINFORCE无baseline曲线与方差怎么量？** 用相同目标，记录完整回合回报的样本标准差；它不同于策略梯度估计的方差。若要判断方差降低，固定同一策略和状态分布，多批次估计梯度向量，比较各坐标方差/总协方差迹。源线性GridWorld实跑已完成，本章神经两步任务见§3.4；未补做1000回合绘图。
5. **running baseline减少多少收敛步？** 先定义达到固定独立评估阈值的环境步，再用prior/留一基线及多个seed比较。合法基线可能不降方差甚至变差；源码首块baseline回报较差本身不能判定最终样本效率。不要把当前batch均值中心化的结果自动称无偏。
6. **熵系数0/.01/.1/1的最佳点？** 其目标含 $+\beta H$，高系数可能过度保持随机，低系数可能过早确定；按相同交互/算力预算同时报告原任务回报与策略熵，必要时退火，再做多seed。是否“最佳”取决于奖励尺度和目标；零熵的最优确定策略不应被机械拒绝。§3.3给出了完整正确梯度。
7. **MC Actor–Critic对比REINFORCE？** 使用完整终止return和冻结状态value基线，替换§4.3优势估计，对照prior均值基线的REINFORCE；匹配交互数而非更新次数。Critic额外参数/计算也要计入，结果可快可慢。当前40轮程序验证机制，不是这项比较。
8. **TD方差比MC降低多少？** 在同一冻结策略、同一批轨迹和同一Critic下，计算MC与一步TD优势，并报告样本方差；还要报告与参考优势的误差，方差下降但偏差增大不等于更好。把不同训练阶段的两批数据直接比较会混入策略变化。
9. **扫GAE λ=0/.5/.9/.95/1？** 保留双掩码，固定环境步/评估和其他配置；λ越大通常使用更长的residual链，对Critic依赖减少但方差可能增大。λ1只有正确终止/末状态bootstrap才能按§1.2望远镜消去。完整回报和Critic准确时也不能据此预定某λ在所有任务最优。
10. **PPO与A2C样本效率？** 同一obs/reward/终止语义、模型容量、优化目标与评估预算，A2C每批一次更新，PPO可多epoch；同时报告环境步和梯度样本预算。源码顺序八条rollout不是实际多进程加速。本文两程序未作为调参后的公平竞赛。
11. **K=1/4/10/30何时KL爆炸？** 保存同一批oldlogp、advantages与value target，增加K仅改变更新次数。检查严格KL/样本估计差异、ratio非有限、回报及有效平坦比例；不是K30必爆炸。可设置target-KL暂停后续epoch，但一次越界已经发生。分离目标clipfraction与公式的分支是正确诊断起点。
12. **如何替换为自适应KL惩罚？** 在§6.4把policy loss换为 $-\mathbb E[r\widehat A]+\beta\mathbb E[D_{KL}(\pi_{old}\|\pi_\theta)]$，用旧完整分类概率算可微KL；每轮结束若实测KL大于`2*target`则增大下一轮β，小于`target/2`则减小。确定β调整发生在本批epoch之间还是批次之间、上下限与KL方向，维持oldlogp不变。该适应规则是启发式，不是保证；它与RLHF reference惩罚并非同一对象。本次没有执行这项sweep，不能称比clip更稳。

再做三个能直接判定的检查：

- 截断transition实际末状态V3、下一resetV9，奖励1且γ.9，目标应3.7，不是9.1。terminal即使末状态网络给9也只接奖励1。
- 共享trunk时Actor优势detach，Critic头梯度应为None，trunk可有梯度；两个optimizer重复包含trunk不符合本文合同。
- PPO $A=-2,r=.5,\epsilon=.2$，目标为-1.6且ratio梯度0；$r=1.5$目标-3且梯度-2。oldlogp在四个epoch之后仍必须与采样时相同。

后续改代码时用中文说明目标/数据/环境变化，重新运行改变的程序并记录最终代码SHA；只改措辞则无需伪造新运行。接入真实环境时核对版本、action/obs形状、autoreset、time-limit、reward单位、训练/评估模式，再补独立seed评估。本文没有执行高维游戏、控制器、语言模型RLHF、外部服务或异步性能基准；没有把未做的消融/sweep写成已验证结论。
