# 07｜计算机视觉任务

> 先修：卷积、训练集划分、分类损失。先区分分类/检测/分割输出，再选择一种任务做小例子；无需一次复现全部历史检测器。

本章维护视觉任务入口。框编码、NMS/AP、U-Net与mask、RoIAlign、热图、Kalman/关联和SAM概念统一详见[检测、分割、姿态与跟踪](../感知与多模态专题/07-检测分割姿态与跟踪.md)；文字、VLM桥接、类型/坐标合同与管道失败例见[OCR、视觉语言与可靠管道](../感知与多模态专题/08-OCR视觉语言与可靠管道.md)。先跑几何/掩码小例，再决定是否要真实权重训练，不能用fixture跑通代表视觉能力验收。

## 1. 从分类走向通用视觉

图像分类只输出整张图的类别；更真实的视觉任务需要：

- 目标在哪里；
- 每个像素属于什么；
- 如何迁移已有模型；
- 如何增强数据；
- 如何生成或重建图像。

## 2. Image Augmentation

训练阶段对输入施加保标签变换，例如：

- crop；
- flip；
- resize；
- color jitter；
- random erase 等。

本质是注入任务先验，扩大有效训练分布。

增强必须符合任务语义。例如某些字符、医学影像和方向敏感任务不能随意翻转。

## 3. Fine-tuning

迁移学习常见流程：

```text
预训练 backbone
→ 替换 task head
→ 初始化新层
→ 较小学习率微调 backbone
→ 较大学习率训练 head
```

需要根据数据量和域差异决定：

- 是否冻结 backbone；
- 冻结多久；
- 哪些层使用不同学习率。

## 4. Bounding Box

目标检测使用边界框表示物体位置，常见格式：

- $(x_{min},y_{min},x_{max},y_{max})$
- center + width/height

必须明确坐标是像素还是归一化值、边界是闭区间还是半开区间；这些约定会影响面积计算。裁剪、缩放、翻转图像时，框和掩码必须同步变换。

## 5. Anchor

Anchor-based 检测预先在不同位置、尺度、长宽比放置候选框，再预测：

- objectness / class；
- box offset。

核心问题包括：

- 正负样本分配；
- IoU；
- box regression；
- NMS。

现代 anchor-free 方法改变候选生成方式，但 IoU、定位和分类的基本问题仍存在。

## 6. Multiscale Detection

不同大小物体需要不同尺度特征。

常见思想：

- image pyramid；
- feature pyramid；
- 多层输出。

今天 FPN 等架构延续的就是“语义与空间分辨率跨尺度融合”。

## 7. SSD

SSD 直接在多个特征层上预测类别和边界框，实现单阶段检测。

重要历史意义：

- one-stage detector；
- multiscale prediction；
- anchors + class/offset 联合训练。

## 8. R-CNN 系列

典型演进：

```text
R-CNN
→ Fast R-CNN
→ Faster R-CNN
```

核心变化是从外部 region proposal 到共享卷积特征，再到可学习的 RPN。

它代表 two-stage detector 路线。

## 8.1 Mask R-CNN

Mask R-CNN 在 Faster R-CNN 的检测分支之外增加实例掩码预测，使系统同时完成：

- 分类；
- 边界框回归；
- instance mask。

它体现了共享 backbone + 多任务 head 的通用设计，并把目标检测延伸到实例分割。

RPN候选经过RoIAlign对齐特征，类别/框分支与局部mask分支分别训练；实例mask不是整图每类语义mask的简单重复。框AP和mask AP都要看，训练目标/类别槽/冻结范围按实际实现核对，完整五项loss与采样例在对应专题维护。

## 9. Semantic Segmentation

语义分割为每个像素预测类别。

与目标检测相比：

- 输出分辨率更高；
- 需要上采样；
- 边界质量重要；
- 类别不平衡更常见。

## 10. Transposed Convolution

转置卷积是一种可学习上采样，不应简单理解为“卷积的数学逆运算”。

需要掌握：

- 输出尺寸；
- stride/padding；
- checkerboard artifact 风险。

## 11. FCN

Fully Convolutional Network 将分类 CNN 改造为 dense prediction：

```text
backbone feature
→ 1×1 class projection
→ upsampling
→ per-pixel prediction
```

它奠定了现代语义分割的基本范式。

## 12. Neural Style Transfer

优化一张生成图，使其同时接近：

- content feature；
- style statistics。

它的重要性在于展示“预训练网络内部特征可以作为感知空间”，这一思想后来延伸到 perceptual loss 等方法。

## 13. 视觉任务的统一分析方法

阅读现代视觉模型时优先问：

1. 输入/输出粒度是什么？
2. backbone 负责什么？
3. 多尺度如何处理？
4. localization 与 classification 如何耦合？
5. 上采样/下采样如何实现？
6. loss 如何处理类别和空间不平衡？
7. 推理后处理是否必要？

随后检查输出是否需要实例身份/时间、坐标变换是否正反一致、类别与pixel/region/token形状如何对应、最终测试是否尊重场景/视频实体，以及空对象、边缘框、未知概念和不存在目标怎样表达。一个同类双对象例可揭示语义/实例区别，一个短遮挡轨迹可揭示检测/跟踪区别，平均指标不能代替这些失败检验。

## 算一次 IoU，并同步变换标签

连续坐标框 A 为 $(0,0,2,2)$，B 为 $(1,1,3,3)$。面积各为 4，交集面积为 1，并集为 $4+4-1=7$，所以 IoU 为 $1/7\approx0.1429$。这里不使用像素闭区间的 `+1` 约定。

自查：把图像宽高都缩小一半，只缩图而保留原框坐标会怎样？**答案：**框不再对应物体位置，标签已错；框四个坐标也应乘 0.5，离散掩码还要用适合类别标签的重采样方式。

实践验收先可视化 10 个增强后的图像及其标签，再看训练曲线；训练正常下降也无法证明标签坐标正确。
