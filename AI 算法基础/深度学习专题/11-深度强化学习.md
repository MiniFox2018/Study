# 11｜深度强化学习

> 主要吸收 Understanding Deep Learning 第 19 章及 Notebook 19.1～19.5，并与现有优化、Transformer 和 LLM 偏好学习知识去重。

## 1. 强化学习与监督学习的根本区别

监督学习直接给出目标 (y)。

强化学习只有交互产生的奖励信号：

```text
状态 s
→ 选择动作 a
→ 环境转移
→ 奖励 r
→ 新状态 s'
```

模型必须解决：

- 延迟奖励；
- 探索 vs. 利用；
- 当前动作改变未来数据分布；
- 策略与训练数据相互依赖。

## 2. MDP

马尔可夫决策过程：

[
(mathcal S,mathcal A,P,R,gamma)
]

其中：

- (mathcal S)：状态；
- (mathcal A)：动作；
- (P(s'|s,a))：转移；
- (R)：奖励；
- (gamma)：折扣因子。

Markov 性：

[
p(s_{t+1}mid s_{0:t},a_{0:t})
=
p(s_{t+1}mid s_t,a_t)
]

## 3. Return

从时刻 (t) 开始的折扣回报：

[
G_t
=
sum_{k=0}^{infty}
gamma^k r_{t+k+1}
]

(gamma) 决定远期奖励的重要程度。

## 4. Value Function

状态价值：

[
V^pi(s)
=
mathbb E_pi[G_tmid s_t=s]
]

动作价值：

[
Q^pi(s,a)
=
mathbb E_pi[G_tmid s_t=s,a_t=a]
]

价值函数把长期影响压缩成当前状态/动作的标量评估。

## 5. Bellman 方程

[
V^pi(s)
=
mathbb E_pi
[
r+gamma V^pi(s')
]
]

最优动作价值满足：

[
Q^*(s,a)
=
mathbb E
[
r+gammamax_{a'}Q^*(s',a')
]
]

Bellman 递归是大量 RL 算法的统一基础。

## 6. Dynamic Programming

如果环境模型 (P,R) 已知，可以通过：

- policy evaluation；
- policy improvement；
- value iteration；
- policy iteration；

反复使用 Bellman 更新求最优策略。

现实任务通常不知道完整环境模型，因此需要从采样轨迹学习。

## 7. Monte Carlo

Monte Carlo 等 episode 结束后，用真实 return 更新价值。

优点：

- 不需要环境模型；
- 目标无 bootstrap 偏差。

缺点：

- 必须等完整回合；
- 方差较大。

## 8. Temporal Difference

TD 使用一步 bootstrap：

[
V(s_t)
leftarrow
V(s_t)
+
alpha
[
r_{t+1}
+
gamma V(s_{t+1})
-
V(s_t)
]
]

其中：

[
delta_t
=
r_{t+1}
+
gamma V(s_{t+1})
-
V(s_t)
]

称 TD error。

TD 在 Monte Carlo 与 Dynamic Programming 之间取得折中。

## 9. Q-Learning

[
Q(s,a)
leftarrow
Q(s,a)
+
alpha
[
r+gammamax_{a'}Q(s',a')-Q(s,a)
]
]

Q-learning 是 off-policy：行为策略可以探索，但更新目标朝向 greedy 最优策略。

## 10. Deep Q-Network

用神经网络近似：

[
Q_	heta(s,a)
]

两个关键工程设计：

### Replay Buffer

打散连续轨迹，降低样本相关性并重复利用经验。

### Target Network

用延迟更新的参数构造目标，降低“预测值和训练目标同时移动”的不稳定性。

## 11. Double Q-Learning

标准 max 操作容易因为估计噪声产生 overestimation。

Double Q / Double DQN 将：

- 动作选择；
- 动作评估；

分开，降低最大化偏差。

## 12. Policy Gradient

直接优化参数化策略：

[
pi_	heta(amid s)
]

目标：

[
J(	heta)
=
mathbb E_{	ausimpi_	heta}[G(	au)]
]

Policy Gradient Theorem 导出：

[

abla_	heta J
=
mathbb E
[
G_t

abla_	heta
log pi_	heta(a_tmid s_t)
]
]

## 13. REINFORCE

Monte Carlo policy gradient：

[
	heta
leftarrow
	heta+
alpha
G_t

abla_	heta
logpi_	heta(a_t|s_t)
]

优点是简单直接，缺点是方差很高。

## 14. Baseline 与 Advantage

减去不依赖当前动作的 baseline 不改变期望梯度，但能显著降低方差。

常用：

[
A(s,a)=Q(s,a)-V(s)
]

于是更新关注：

> 当前动作比这个状态下“通常水平”好多少。

## 15. Actor–Critic

Actor：

[
pi_	heta(a|s)
]

负责选择动作。

Critic：

[
V_phi(s)
quad	ext{或}quad
Q_phi(s,a)
]

负责评估。

Actor–Critic 把：

- policy optimization；
- value estimation；

结合起来，是现代 PPO、A2C/A3C、SAC 等方法的重要基础。

## 16. Offline RL

Offline RL 只使用固定数据集，不允许继续与环境采样。

最大问题是 **distribution shift**：

> 策略可能选择数据集中几乎没出现过的动作，而价值函数对这些动作的估计最不可靠。

因此需要约束策略不要过度偏离行为分布，或对 OOD action 采取保守价值估计。

## 17. Transformer 与 RL

UDL 网站扩展资料强调 Transformer 可用于：

- representation learning；
- transition modeling；
- reward modeling；
- policy modeling；
- trajectory modeling。

Decision Transformer 的代表性观点是：

> 可以把强化学习轨迹看成序列建模问题，用 return-to-go、状态、动作条件化预测后续动作。

它并没有消除 RL 的分布和控制问题，只是改变了策略建模方式。

## 18. 与 LLM 后训练的关系

RLHF / RLAIF 中仍可看到 RL 核心元素：

- state：上下文与已生成 token；
- action：下一个 token / 完整回答；
- policy：语言模型；
- reward：人类或奖励模型偏好；
- optimization：PPO 等策略更新。

但 DPO 等方法可以绕过显式在线 RL，把偏好学习转成直接优化。

因此：

> “偏好优化”与“强化学习”有关，但二者不应完全等同。

## 20. Sarsa：同策略 TD 控制

EasyRL 第 3 章把 Sarsa 与 Q-learning 放在同一个“免模型控制”框架下比较。

Sarsa 使用实际执行的下一动作 \(a_{t+1}\) 做 bootstrap：

$$
Q(s_t,a_t)
\leftarrow
Q(s_t,a_t)
+
\alpha
\left[
r_{t+1}
+
\gamma Q(s_{t+1},a_{t+1})
-
Q(s_t,a_t)
\right]
$$

因此：

- 行为策略负责探索；
- 更新目标也跟随行为策略；
- 属于 on-policy。

Q-learning 则使用：

$$
\max_a Q(s_{t+1},a)
$$

作为目标，学习的是 greedy target policy，因此是典型 off-policy。

核心区别：Sarsa 学当前实际执行的策略；Q-learning 学目标最优策略。

## 21. PPO：限制策略更新幅度

EasyRL 第 5 章的主线是：

Policy Gradient → Importance Sampling → 新旧策略不能相差过大 → PPO。

### Importance Sampling

若数据由旧策略 \(\pi_{\theta'}\) 采样，但要更新新策略 \(\pi_\theta\)，可使用概率比：

$$
r_t(\theta)
=
\frac{
\pi_\theta(a_t|s_t)
}{
\pi_{\theta'}(a_t|s_t)
}
$$

修正采样分布。

问题是：如果新旧策略差异过大，importance weight 方差会迅速上升，估计不稳定。

### PPO-Penalty

用 KL divergence 约束新旧策略：

$$
J_{\mathrm{PPO}}
=
J(\theta)
-
\beta
D_{KL}
\left(
\pi_{\theta'}
\|
\pi_\theta
\right)
$$

\(\beta\) 可根据实际 KL 大小动态调节。

### PPO-Clip

更常见的形式是裁剪概率比：

$$
L^{CLIP}
=
\mathbb E_t
\left[
\min
\left(
r_t(\theta)A_t,\,
\operatorname{clip}
(r_t(\theta),1-\epsilon,1+\epsilon)A_t
\right)
\right]
$$

直觉是：如果新策略已经相对旧策略改变太多，就不再继续奖励这次变化。

EasyRL 当前勘误特别强调：PPO 虽然使用 importance ratio，但只复用上一轮策略的数据，并约束新旧策略保持接近，因此仍按 on-policy 算法理解。

### PPO 的完整训练目标

EasyRL 的论文解读还把实际 PPO 目标拆成三部分：

- clipped policy objective；
- value-function loss；
- entropy bonus。

因此 PPO 不是只有一条 clip 公式，而是策略更新稳定性、Critic 价值估计和探索熵共同工作。

## 22. DQN 的六类经典改进

EasyRL 第 7 章和 Rainbow 论文解读给出了 DQN 的完整演进链。

### 22.1 Double DQN

DQN 中：

$$
\max_a Q(s',a)
$$

同时负责“选择动作”和“评价动作”，容易放大估计噪声。

Double DQN 拆开：

$$
a^*
=
\arg\max_a Q_{\text{online}}(s',a)
$$

再由 target network 评价：

$$
Q_{\text{target}}(s',a^*)
$$

核心是 Selection 与 Evaluation 解耦。

### 22.2 Dueling DQN

把 Q 分解为：

$$
Q(s,a)
=
V(s)
+
A(s,a)
$$

实际实现通常对 advantage 做零均值约束：

$$
Q(s,a)
=
V(s)
+
\left[
A(s,a)
-
\frac{1}{|\mathcal A|}
\sum_{a'}A(s,a')
\right]
$$

这样模型可以分别学习：

- 当前状态本身有多好；
- 各动作相对于平均水平有多好。

### 22.3 Prioritized Experience Replay

均匀 replay 把所有经验视为同等重要。

PER 根据 TD error 给样本分配优先级：

$$
P(i)
=
\frac{p_i^\alpha}
{\sum_k p_k^\alpha}
$$

典型：

$$
p_i
=
|\delta_i|+\epsilon
$$

由于改变了采样分布，还需 importance-sampling weight 修正训练偏差。

### 22.4 Multi-step Learning

1-step TD 方差较低但 bootstrap 偏差更强；Monte Carlo 使用完整 return，偏差低但方差高。

n-step return 在二者之间折中：

$$
R_t^{(n)}
=
\sum_{k=0}^{n-1}
\gamma^k r_{t+k+1}
$$

再接：

$$
\gamma^n V(s_{t+n})
$$

作为 bootstrap。

### 22.5 NoisyNet

传统 DQN 常用 \(\epsilon\)-greedy 做探索。

NoisyNet 把可学习噪声直接加入网络参数，使探索由参数扰动驱动，而不是只在动作选择阶段随机。

### 22.6 Distributional RL

普通 Q-learning 学：

$$
\mathbb E[G_t]
$$

Distributional RL 则尝试学习 return 的整个概率分布，而不是只有期望。

这保留了不确定性、多峰结构和回报分布形态。

### 22.7 Rainbow

EasyRL 对 Rainbow 的总结是把六种改进组合：

Double DQN + Dueling + PER + Multi-step + Distributional RL + NoisyNet → Rainbow。

价值不只是“组合更多技巧”，更重要的是通过消融实验判断不同组件的实际贡献。

## 23. Actor–Critic、A2C 与 A3C

Actor–Critic 把两个问题分开：

- Actor：更新策略；
- Critic：估计 value / advantage。

EasyRL 第 9 章进一步介绍 Advantage Actor-Critic、Asynchronous Advantage Actor-Critic 与 pathwise / deterministic policy gradient 方向。

### A2C

使用 advantage：

$$
A(s,a)
=
Q(s,a)-V(s)
$$

替代完整 return 直接做策略梯度，可以降低方差。

### A3C

A3C 用多个并行 worker 与环境交互并异步更新共享模型。

EasyRL 勘误特别强调它仍是 on-policy：worker 使用当前策略产生数据，不依赖历史 replay buffer。

异步并行的主要价值是增强探索、降低样本相关性并提升采样吞吐。

## 24. 连续动作：DDPG → TD3 → SAC

### 24.1 DDPG

EasyRL 第 12 章把 DDPG 解释为：

DQN 的经验回放/目标网络 + 确定性 Actor-Critic。

Actor：

$$
a=\mu_\theta(s)
$$

Critic：

$$
Q_w(s,a)
$$

训练时：

- Critic 学 Bellman target；
- Actor 最大化 Critic 给出的 Q 值；
- replay buffer 提高样本复用；
- Actor 与 Critic 都有 target network；
- 探索通过给确定性动作加噪声实现。

因为使用 replay buffer，DDPG 属于 off-policy。

### 24.2 TD3

EasyRL 总结 TD3 的三个关键修正：

1. Clipped Double Q-learning：两个 Critic 取较小 Q 值构造 target；
2. Delayed Policy Update：Critic 更新更频繁，Actor 更新更慢；
3. Target Policy Smoothing：target action 加截断噪声，避免策略利用 Q 函数局部估计误差。

核心问题是抑制 DDPG 中 Q overestimation 与策略被 Critic 误差带偏。

### 24.3 SAC

EasyRL 的经典论文解读与 Notebook 还覆盖 SAC。

SAC 是：

- off-policy；
- stochastic actor；
- maximum-entropy RL。

目标不仅最大化 return，还鼓励策略熵：

$$
J(\pi)
=
\mathbb E
\left[
\sum_t
r(s_t,a_t)
+
\alpha
\mathcal H
\left(
\pi(\cdot|s_t)
\right)
\right]
$$

因此它在连续控制中同时追求高回报与保持探索，并与 DDPG/TD3 的确定性策略形成对照。

## 25. 稀疏奖励

EasyRL 第 10 章单独讨论 sparse reward，给出四条路线。

### Reward Design

奖励函数必须让局部反馈与最终任务一致。若 shaping 不合理，智能体可能优化代理奖励而不是完成真实目标。

### Curiosity / Intrinsic Reward

当外部奖励稀少时，可以让“新奇状态”本身产生内部奖励，驱动探索。

### Curriculum Learning

训练任务从易到难。

EasyRL 还介绍 reverse curriculum：

- 从 goal state 附近开始；
- 只保留“当前能力下既不太简单也不太难”的起点；
- 随能力提高逐渐向更远状态扩展。

### Hierarchical RL

把复杂任务拆成高层和低层：

高层策略提出 goal / subgoal，低层策略执行动作完成 subgoal。

核心价值是把长期 credit assignment 转化为多个较短子任务。

## 26. 模仿学习

EasyRL 第 11 章把 imitation learning 分成几层。

### Behavior Cloning

直接把专家 \((s,a)\) 当监督学习样本。

主要问题：

- 训练只覆盖专家访问到的状态；
- 测试时一个小错误会把智能体带到训练集中从未见过的状态；
- 后续误差会累积。

### DAgger

让当前策略自己运行，同时让专家对当前策略访问到的状态给出正确动作，再把新数据并回训练集。

它直接处理训练分布与策略实际运行分布不一致的问题。

### Inverse Reinforcement Learning

普通 RL：

Reward → 最优策略。

IRL：

专家轨迹 → 推断 Reward → 再求最优策略。

EasyRL 还从 GAN 视角解释：当前策略类似 generator，reward / discriminator 区分专家轨迹和智能体轨迹，策略不断尝试获得更高 reward。

### Third-person Imitation

专家和智能体视角不一致时，需要学习跨 domain 的表示，使第三人称观察能迁移到第一人称执行。

EasyRL 使用 domain-adversarial training 解释这一问题。
