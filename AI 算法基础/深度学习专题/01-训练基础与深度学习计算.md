## 1. 从线性模型到深度网络

线性回归把预测写成：

$$
\hat y=Xw+b
$$

平方损失可从高斯噪声假设推出。训练时常用小批量随机梯度下降，把精确全量梯度换成低成本的随机估计。

高斯噪声等假设支持似然解释，但计算MSE不要求数据先是高斯。分类概率也可用平方/Brier评分；不能认为二分类MSE永远停在0.25。具体差异、稳定logit损失和目标形状由[专题16第7节](16-前向反向与损失实现.md)统一说明。

分类中，Softmax 把 logits 转为概率：

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

配合交叉熵，本质上是在最大化正确类别的对数似然。

长期应掌握的不是某个框架写法，而是统一训练闭环：

```text
数据 → 模型 → loss → 反向传播 → 参数更新 → 评估
```

## 2. 为什么需要隐藏层和非线性

连续堆叠线性层仍等价于一个线性变换，因此深度网络必须引入非线性激活。

MLP 的基本形式：

$$
h=\phi(XW_1+b_1),\qquad o=hW_2+b_2
$$

网络深度增加的是函数组合能力，而不是简单增加矩阵数量。

本文批量行输入的 $W_1$为 `(输入维,隐藏维)`；PyTorch `Linear`权重存 `(隐藏维,输入维)`，计算时会相应转置。2-3-1的批量输出形状 `(B,1)`，共13个权重和偏置。参数数为各层 $n_{in}n_{out}+n_{out}$之和，不能把784个输入像素当784个训练参数，也不按“参数比样本数多5～10倍”保证泛化。

## 3. 前向传播、计算图与反向传播

前向传播保存中间量，反向传播利用链式法则沿计算图反向累积梯度。

调试时必须区分：

- 参数是否参与计算图；
- 梯度是否被意外截断；
- 梯度是否累计未清零；
- 非标量输出反向传播需要怎样的向量—雅可比积；
- train/eval 模式是否影响 Dropout、BatchNorm 等层。

自动微分替代的是手算过程，不替代对梯度流的理解。

梯度是 `None`常表示未参与当前图、没要求存梯度或未执行反向；数值0可能是门关闭、损失局部平坦或已收敛；NaN/Inf须找第一个非有限算子。三者处理不同。多路径的梯度要加和，偏置广播的梯度沿样本轴求和；先算完整旧状态梯度，再统一更新。标量引擎在[数学06](../数学与数值计算专题/06-微积分梯度与自动微分.md)，批量矩阵与全参数差分在[专题16](16-前向反向与损失实现.md)，避免重复维护实现。

## 4. 欠拟合、过拟合与模型选择

训练误差高、验证误差也高，通常更接近欠拟合；训练误差低但验证误差明显更高，通常意味着过拟合。

需要同时控制：

- 模型容量；
- 数据规模与覆盖；
- 正则化强度；
- 训练轮数；
- 验证方案。

常见手段：

### L2 正则与权重衰减

L2 正则：

$$
L'=L+\lambda\|w\|_2^2
$$

它对大权重施加惩罚。对普通 SGD，L2 与适当系数的权重衰减可等价；对 Adam 等自适应优化器，梯度中的 L2 项与解耦权重衰减不同，不能直接互换。

### Dropout

训练阶段随机屏蔽隐藏单元并进行尺度校正；推理阶段使用完整网络。它可被理解为对子网络的随机采样与集成式正则化。

### Early Stopping

根据验证集而非训练集决定停止点。

## 5. 数值稳定性

深层网络常见：

- 梯度消失；
- 梯度爆炸；
- 激活尺度漂移；
- 指数运算上溢/下溢。

Softmax 与交叉熵实现通常应使用数值稳定的 log-sum-exp 形式，而不是先显式算概率再取对数。

初始化的目标是让前向激活和反向梯度在层间保持合理方差。典型思想包括 Xavier 与 He 初始化。

局部Sigmoid导数至多0.25，但完整反向还乘权重Jacobian；只看激活幅度或只乘 $0.25^{层数}$并不足以诊断整网。ReLU正区导数1也不保证所有梯度保留。按层监控梯度、激活与实际参数更新，再判断初始化、激活、归一化或学习率；不能把换GELU或加裁剪当所有问题的自动解法。

## 6. 模型构造的抽象层级

现代深度学习框架通常提供：

```text
Parameter
→ Layer
→ Block / Module
→ Model
```

真正需要掌握的是：

- 参数如何被注册；
- 子模块如何嵌套；
- forward 如何定义数据流；
- 初始化何时发生；
- 参数如何共享；
- 如何创建自定义层和自定义块。

不要把“顺序容器”误解为所有网络结构。残差、分支、多输入/多输出都需要显式定义计算图。

## 7. 延迟初始化

部分框架会在第一次看到输入形状后再确定参数形状。

理解延迟初始化有助于判断：

- 为什么模型创建后参数形状暂不可知；
- 为什么第一次 forward 可能触发额外工作；
- 自定义模块何时能够安全访问参数。

## 8. 模型保存与恢复

长期原则是区分：

- **参数状态**：权重、偏置、优化器状态；
- **模型结构**：代码或配置；
- **训练上下文**：随机种子、数据版本、超参数。

只保存权重不等于可复现实验。

## 9. GPU 使用的长期原则

执行前不记具体 API，只记：

- 参数和输入必须在兼容设备上；
- 设备间拷贝有成本；
- 小模型/小 batch 不一定能吃满 GPU；
- CPU 数据管线可能成为 GPU 的瓶颈；
- mixed precision、kernel fusion、编译优化属于系统层优化，不能替代正确算法。

## 10. 从零实现与高层 API 的关系

D2L 的重要教学方法是同一算法做两遍：

1. 从零实现，理解参数、损失、梯度和更新；
2. 用框架高级 API 实现，理解工程抽象。

学习新模型时也可沿用：

```text
最小数学定义
→ 小数据手写实现
→ 与框架结果对齐
→ 再使用高层组件
```

## 11. 最小训练诊断流程

1. 检查输入、标签、shape、dtype；
2. 用极小数据集尝试完全过拟合；
3. 检查初始 loss 是否符合理论数量级；
4. 检查梯度是否为 0、NaN、Inf；
5. 检查参数是否真正更新；
6. 再看学习率、正则化和容量；
7. 最后扩大数据和模型。

这比直接更换架构更可靠。

## 无需 GPU 的最小训练实验

以下 Python 3 代码仅用标准库，在人为线性数据上拟合斜率和偏置。它验证的是训练闭环，不是泛化能力。

```python
# 四个训练样本；目标关系为 y = 2x + 1。
xs = [0.0, 1.0, 2.0, 3.0]
ys = [1.0, 3.0, 5.0, 7.0]
w, b = 0.0, 0.0
learning_rate = 0.03
for step in range(2000):
    errors = [w * x + b - y for x, y in zip(xs, ys)]
    grad_w = 2 * sum(e * x for e, x in zip(errors, xs)) / len(xs)
    grad_b = 2 * sum(errors) / len(xs)
    w -= learning_rate * grad_w
    b -= learning_rate * grad_b
loss = sum((w * x + b - y) ** 2 for x, y in zip(xs, ys)) / len(xs)
print(f"斜率={w:.4f}，偏置={b:.4f}，训练均方误差={loss:.8f}")
```

应得到斜率接近 2、偏置接近 1、均方误差接近 0。第一步更新前，梯度应为 `grad_w=-17`、`grad_b=-8`。

自查：删除梯度中的 `/ len(xs)` 会发生什么？**答案：**从均方误差改成误差平方和，梯度大 4 倍；同一学习率的有效更新也大 4 倍。能解释这个差别后，再使用框架自动求导。

## 12. PyTorch CPU闭环：训练、诊断、推理和恢复

依赖PyTorch，无需数据下载和GPU。该例输出一个logit，用 `BCEWithLogitsLoss`训练；只有推理才Sigmoid。用同四个XOR点检验表达和更新，是实现验收，不是现实泛化测试。

```python
import io
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(4)
X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]], dtype=torch.float64)
y = torch.tensor([[0.], [1.], [1.], [0.]], dtype=torch.float64)

def build():
    return nn.Sequential(nn.Linear(2, 8), nn.Tanh(), nn.Linear(8, 1)).double()

model = build()
optimizer = torch.optim.SGD(model.parameters(), lr=0.5)
criterion = nn.BCEWithLogitsLoss()
model.train()
for step in range(4000):
    optimizer.zero_grad(set_to_none=True)
    logits = model(X)
    assert logits.shape == y.shape
    loss = criterion(logits, y)
    if not torch.isfinite(loss):
        raise RuntimeError("损失非有限，先定位首次出错而不继续更新")
    loss.backward()
    if step in [0, 1000, 3999]:
        norms = {name: round(p.grad.norm().item(), 6)
                 for name, p in model.named_parameters() if p.grad is not None}
        print("步骤", step, "损失", round(loss.item(), 6), "梯度范数", norms)
    optimizer.step()

model.eval()
with torch.no_grad():
    probabilities = model(X).sigmoid()
print("训练点XOR概率", probabilities.flatten().tolist())
assert torch.equal((probabilities >= 0.5).long(), y.long())

# 用内存流演示保存/恢复；需要持久文件时换成自己选择的.pt路径。
buffer = io.BytesIO()
torch.save({"model": model.state_dict(), "optimizer": optimizer.state_dict(),
            "step": 4000, "sizes": [2, 8, 1], "seed": 4,
            "torch_version": str(torch.__version__)}, buffer)
buffer.seek(0)
checkpoint = torch.load(buffer, map_location="cpu", weights_only=True)
restored = build()
restored.load_state_dict(checkpoint["model"])
restored_optimizer = torch.optim.SGD(restored.parameters(), lr=0.5)
restored_optimizer.load_state_dict(checkpoint["optimizer"])
restored.eval()
with torch.no_grad():
    restored_probabilities = restored(X).sigmoid()
assert torch.equal(probabilities, restored_probabilities)
print("CPU恢复预测逐项相同；参数数量", sum(p.numel() for p in restored.parameters()))
```

代码模型权重需与结构一起恢复，优化器必须指向**恢复模型的参数**。如要严格续训，还需数据版本/切分、随机数与采样器状态、调度器状态等，不是保存一个seed就能完整重现中途采样。实际实验文件应记录输入单位、标签约定、输出/阈值与已运行环境，仓库不提交临时权重缓存。

反向计算后每层参数梯度都存在且有限、损失明显下降、四点类别正确、恢复预测相同，是本例的验收层次。没有Dropout/BatchNorm的此模型切换eval不改变数值，但真实含这些层时仍必须区分模式；`no_grad`并不自动切换eval。

本次PyTorch2.14.1 CPU实测初始/第1000步/第3999步损失约0.707064/0.004214/0.000712，四点概率约 `[0.000613,0.999407,0.999317,0.000959]`，模型33个参数，恢复预测逐项相同。记录的是固定种子与这四点的实现结果，学习者仍须自己解释和修改验证。

## 13. 练习如何算过关

1. **先手算旧线性例子第一步**：$dw=-17,db=-8$；解释归约改变怎样影响步长，再运行核对。
2. **完成矩阵MLP**：在[专题16](16-前向反向与损失实现.md)逐层给出输入/参数/输出形状，BCE、CE、MSE各做一次全参数梯度检查，能发现漏除批量或误用旧/新权重。
3. **运行上方框架CPU例子**：记录初始loss、至少一层梯度、最终四点概率、恢复等价检查；能解释BCE为何不再显式Sigmoid。
4. **再做留出圆形数据**：与恒多数类和平方半径线性基线比较，报告验证指标；不要用XOR四点记忆证明现实能力。
5. **修改后重新核验**：改变隐藏层宽度/激活、损失或归约时，先确认目标、形状和梯度，再比较固定划分和多个种子，不把随机一次结果当通用配方。
