# 01｜训练基础与深度学习计算

## 1. 从线性模型到深度网络

线性回归把预测写成：

[
hat y = Xw + b
]

平方损失可从高斯噪声假设推出。训练时常用小批量随机梯度下降，把精确全量梯度换成低成本的随机估计。

分类中，Softmax 把 logits 转为概率：

[
p_i=rac{e^{z_i}}{sum_j e^{z_j}}
]

配合交叉熵，本质上是在最大化正确类别的对数似然。

长期应掌握的不是某个框架写法，而是统一训练闭环：

```text
数据 → 模型 → loss → 反向传播 → 参数更新 → 评估
```

## 2. 为什么需要隐藏层和非线性

连续堆叠线性层仍等价于一个线性变换，因此深度网络必须引入非线性激活。

MLP 的基本形式：

[
h=phi(XW_1+b_1),qquad
o=hW_2+b_2
]

网络深度增加的是函数组合能力，而不是简单增加矩阵数量。

## 3. 前向传播、计算图与反向传播

前向传播保存中间量，反向传播利用链式法则沿计算图反向累积梯度。

调试时必须区分：

- 参数是否参与计算图；
- 梯度是否被意外截断；
- 梯度是否累计未清零；
- 非标量输出反向传播需要怎样的向量—雅可比积；
- train/eval 模式是否影响 Dropout、BatchNorm 等层。

自动微分替代的是手算过程，不替代对梯度流的理解。

## 4. 欠拟合、过拟合与模型选择

训练误差高、验证误差也高，通常更接近欠拟合；训练误差低但验证误差明显更高，通常意味着过拟合。

需要同时控制：

- 模型容量；
- 数据规模与覆盖；
- 正则化强度；
- 训练轮数；
- 验证方案。

常见手段：

### 权重衰减

L2 正则：

[
L' = L + lambda|w|_2^2
]

它约束参数规模，降低模型对少量特征的极端依赖。

### Dropout

训练阶段随机屏蔽隐藏单元并进行尺度校正；推理阶段使用完整网络。它可被理解为对子网络的随机采样与集成式正则化。

### Early Stopping

根据验证集而非训练集决定停止点。

## 5. 数值稳定性

深层网络常见：

- 梯度消失；
- 梯度爆炸；
- 激活尺度漂移；
- 指数运算上溢/下溢。

Softmax 与交叉熵实现通常应使用数值稳定的 log-sum-exp 形式，而不是先显式算概率再取对数。

初始化的目标是让前向激活和反向梯度在层间保持合理方差。典型思想包括 Xavier 与 He 初始化。

## 6. 模型构造的抽象层级

现代深度学习框架通常提供：

```text
Parameter
→ Layer
→ Block / Module
→ Model
```

真正需要掌握的是：

- 参数如何被注册；
- 子模块如何嵌套；
- forward 如何定义数据流；
- 初始化何时发生；
- 参数如何共享；
- 如何创建自定义层和自定义块。

不要把“顺序容器”误解为所有网络结构。残差、分支、多输入/多输出都需要显式定义计算图。

## 7. 延迟初始化

部分框架会在第一次看到输入形状后再确定参数形状。

理解延迟初始化有助于判断：

- 为什么模型创建后参数形状暂不可知；
- 为什么第一次 forward 可能触发额外工作；
- 自定义模块何时能够安全访问参数。

## 8. 模型保存与恢复

长期原则是区分：

- **参数状态**：权重、偏置、优化器状态；
- **模型结构**：代码或配置；
- **训练上下文**：随机种子、数据版本、超参数。

只保存权重不等于可复现实验。

## 9. GPU 使用的长期原则

执行前不记具体 API，只记：

- 参数和输入必须在兼容设备上；
- 设备间拷贝有成本；
- 小模型/小 batch 不一定能吃满 GPU；
- CPU 数据管线可能成为 GPU 的瓶颈；
- mixed precision、kernel fusion、编译优化属于系统层优化，不能替代正确算法。

## 10. 从零实现与高层 API 的关系

D2L 的重要教学方法是同一算法做两遍：

1. 从零实现，理解参数、损失、梯度和更新；
2. 用框架高级 API 实现，理解工程抽象。

学习新模型时也可沿用：

```text
最小数学定义
→ 小数据手写实现
→ 与框架结果对齐
→ 再使用高层组件
```

## 11. 最小训练诊断流程

1. 检查输入、标签、shape、dtype；
2. 用极小数据集尝试完全过拟合；
3. 检查初始 loss 是否符合理论数量级；
4. 检查梯度是否为 0、NaN、Inf；
5. 检查参数是否真正更新；
6. 再看学习率、正则化和容量；
7. 最后扩大数据和模型。

这比直接更换架构更可靠。
