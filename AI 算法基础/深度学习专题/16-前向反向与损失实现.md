## 1. 感知机：学习一个分隔面，不是输出概率

用0/1标签时，感知机算 $s=w^\mathsf Tx+b$，$\hat y=\mathbf1[s\ge0]$。出错才按 $e=y-\hat y$ 更新 $w\leftarrow w+\eta ex$、$b\leftarrow b+\eta e$。标签为 $\pm1$ 的常见写法则在 $ys\le0$ 时加 $\eta yx$；零分数边界的决策/更新约定需统一。

这不是对阶跃导数做反向传播：阶跃在非零处导数0，零处不连续。感知机有自己的出错更新规则；改成Sigmoid与可微损失才使用通常的梯度训练。权重表示同一特征空间里的线性分数贡献，不直接等于因果重要性。

正步长、有限且有界训练点、存在正间隔分隔面等条件下，感知机有限次出错后可分开训练数据。未收敛到某个epoch上限不单独证明不可分，成功分训练也不证明泛化。标准零初始化、常数正步长的感知机常只是整体缩放参数，不能机械套用“学习率大一定像梯度下降发散”的说法。

### 1.1 XOR为什么不行，而组合门为什么行

XOR输入00/11标签0，01/10标签1。若一个含偏置分隔面可实现它，则 $b<0,w_1+b\ge0,w_2+b\ge0,w_1+w_2+b<0$。前两个正类不等式给 $w_1+w_2+b\ge-b>0$，与最后一个矛盾。**这个矛盾是证明；跑1000轮失败只是示范。**

两层可组合 $h_1=OR(x_1,x_2)$、$h_2=NAND(x_1,x_2)$，输出 $AND(h_1,h_2)$。取OR的权重 `(1,1)`/偏置-0.5，NAND `(-1,-1)`/1.5，AND `(1,1)`/-1.5即可。多数表决“三输入至少两票为1”可用权重 `(1,1,1)`、偏置-1.5，仍线性可分。

单输入NOT取 $w=-1,b=0.5$：输入0得正分数输出1，输入1得负分数输出0；这也说明偏置允许决策面离开原点。

```python
import numpy as np
from itertools import product

def train_perceptron(X, y, epochs=100, rate=0.1):
    X, y = np.asarray(X, float), np.asarray(y)
    if X.ndim != 2 or len(X) == 0 or y.shape != (len(X),) or not np.isin(y, [0, 1]).all():
        raise ValueError("需要二维非空输入和等长0/1标签")
    if not np.isfinite(X).all() or rate <= 0:
        raise ValueError("特征须有限，步长须为正")
    w, b, history = np.zeros(X.shape[1]), 0.0, []
    for epoch in range(epochs):
        mistakes = 0
        for x, target in zip(X, y):
            error = target-int(w @ x+b >= 0)
            if error:
                mistakes += 1
                w, b = w+rate*error*x, b+rate*error
        history.append((w.copy(), b, mistakes))
        if mistakes == 0:
            break
    return w, b, history

X = np.array(list(product([0., 1.], repeat=2)))
for name, y in [("AND", [0, 0, 0, 1]), ("OR", [0, 1, 1, 1]),
                ("NAND", [1, 1, 1, 0]), ("XOR", [0, 1, 1, 0])]:
    w, b, history = train_perceptron(X, y)
    print(name, "预测", (X @ w+b >= 0).astype(int).tolist(),
          "末轮出错数", history[-1][2], "参数", w.round(3), round(b, 3))
step = lambda z: (z >= 0).astype(int)
hidden = np.column_stack([step(X.sum(1)-0.5), step(-X.sum(1)+1.5)])
prediction = step(hidden.sum(1)-1.5)
print("组合门的XOR", prediction.tolist())
assert np.array_equal(prediction, [0, 1, 1, 0])
X3 = np.array(list(product([0., 1.], repeat=3)))
assert np.array_equal(step(X3.sum(1)-1.5), (X3.sum(1) >= 2).astype(int))
from sklearn.linear_model import Perceptron
library = Perceptron(max_iter=1000, tol=None, shuffle=False, eta0=0.1, random_state=0)
library.fit(X, [0, 0, 0, 1])
print("成熟库AND预测", library.predict(X).tolist())
assert np.array_equal(library.predict(X), [0, 0, 0, 1])
```

训练历史每轮保存 $w,b$，二维且 $w_2\ne0$ 可画 $x_2=-(w_1x_1+b)/w_2$，$w_2=0,w_1\ne0$画竖线；$w=0$是常数决策，不能除零。源图手拖权重展示的是旋转/平移几何，不是自动训练证明。NOT、NAND、AND、OR的门机制可逐条代入核验，不需要另一套网站专属笔记。

程序最后五行需要scikit-learn，前面的手写部分仅NumPy/标准库。成熟 `Perceptron`增加停止、打乱、稀疏与正则等工程处理，参数未必和手写相同；其训练损失固定为perceptron，不是源说明所暗示可任意更换多种loss，广义随机梯度分类器则是另一接口。

## 2. 前向传播：单样本列向量与批量行矩阵要对齐

单样本可写 $z=Wx+b$，此时 $W$为 `(输出维,输入维)`；PyTorch `Linear`也按此存权重。本文手写批量采用行输入：

$$
A_0=X\in\mathbb R^{B\times d_0},\quad
Z_l=A_{l-1}W_l+b_l,\quad A_l=\phi_l(Z_l),
$$

此处 $W_l\in\mathbb R^{d_{l-1}\times d_l}$，$b_l\in\mathbb R^{d_l}$。两种约定相差转置，不存在“所有框架权重只能某一个形状”。偏置沿样本维广播，不能把样本维作为特征维求和。

一个2-3-1网络的批量形状是 `X(B,2) → Z1(B,3) → A1(B,3) → logits(B,1)`，参数数为 $2\times3+3+3\times1+1=13$。一般全连接网络参数总数 $\sum_l(d_{l-1}d_l+d_l)$，输入节点通常不是可训练层。

```python
import numpy as np

X = np.array([[0.6, -0.4], [1., 0.]])
W1 = np.array([[1.2, -0.5, 0.9], [-0.8, 1.4, 0.7]])
b1 = np.array([0.1, -0.2, 0.])
W2, b2 = np.array([[1.1], [-1.3], [0.8]]), np.array([0.2])
Z1, H = X @ W1+b1, np.tanh(X @ W1+b1)
output = np.tanh(H @ W2+b2)
print("各层形状", X.shape, Z1.shape, H.shape, output.shape)
print("首样本隐藏值", H[0].round(6), "输出", output[0].round(6))
def count_parameters(sizes):
    return sum(a*b+b for a, b in zip(sizes[:-1], sizes[1:]))
for sizes in [[2, 3, 1], [2, 4, 2, 1], [3, 4, 4, 2], [784, 256, 128, 10]]:
    print(sizes, "参数数", count_parameters(sizes))
assert count_parameters([2, 3, 1]) == 13
assert count_parameters([784, 256, 128, 10]) == 235146
gate_X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.],])
sigmoid = lambda z: 1/(1+np.exp(-z))  # 本例logit范围有限，通用稳定版见下节
gate_H = sigmoid(gate_X @ np.array([[20., -20.], [20., -20.]])+np.array([-10., 30.]))
gate_P = sigmoid(gate_H @ np.array([[20.], [20.]])-30.)
print("手工Sigmoid XOR概率", gate_P.ravel().round(6))
assert np.array_equal((gate_P.ravel() >= 0.5).astype(int), [0, 1, 1, 0])
```

这里重建源前向图的固定tanh网络，首样本 $Z_1=(1.14,-1.06,0.26)$；边的正负表示权重符号，节点深浅表示激活强弱，**tanh输出不是类别概率**。中间表示维数可增、可减、可保持，不能说文本总扩维而图像总降维。

多层没有非线性时，$(XW_1+b_1)W_2+b_2=X(W_1W_2)+(b_1W_2+b_2)$，仍仿射。带非线性才可能扩大函数表达；某些目标本来线性就不必堆深。输入/隐藏层/输出的角色依任务决定，不能仅由“RGB三维”就声称随机3-4-4-2输出能完成颜色分类。

单隐藏层通用逼近定理是在紧致域连续函数、合适激活等条件下说明存在足够宽网络达到任意指定近似误差；**不承诺优化找得到、参数少、无限域有效或数据外泛化**。深度对有组合结构的某些函数可以更高效，不意味着所有函数都深更好。网络还可分支、共享权重或残差组合，顺序容器只是最简单情形。

上方手工Sigmoid XOR用±20模拟OR/NAND的陡门、输出用偏置-30模拟AND；它证明这套参数可表达该任务，却不证明从任何随机初始化都能找到。改变隐藏宽度后的随机前向，应检查中间分布和输出范围，不把未训练准确率用来断定最终容量。

若最终仍是Sigmoid，隐藏宽度2/8/32并不改变数学输出范围(0,1)，却可改变随机输出的均值/方差；先记录激活分布再谈训练。只读随机forward完成的是计算链，不能把圆形准确率偶然高于基线当成已经学习到圆形。

## 3. 批量反向：每个矩阵梯度都要有来源

令 $D_l=\partial L/\partial Z_l$。对两层网络 $H=\phi(XW_1+b_1),Z_2=HW_2+b_2$：

$$
dW_2=H^\mathsf TD_2,\quad db_2=\sum_{i=1}^B(D_2)_i,
$$

$$
dH=D_2W_2^\mathsf T,\quad
D_1=dH\odot\phi'(Z_1),\quad
dW_1=X^\mathsf TD_1,\quad db_1=\sum_i(D_1)_i.
$$

$\odot$为逐元素乘法。梯度与对应参数形状相同，偏置梯度对广播的批量维求和。平均损失的 $1/B$只需在最初 $D_2$里乘一次，不能每层再除一次。先计算所有梯度，再更新所有参数；隐藏层反传必须使用**前向时的旧输出权重**。

二分类logit+BCE：$D_2=(\sigma(Z_2)-Y)/B$。Sigmoid输出+MSE：$D_2=2(P-Y)\odot P\odot(1-P)/B$。多分类交叉熵：$D_2=(P-Y_{onehot})/B$。多输出MSE若对所有元素平均，分母是 $B\times d_{out}$，不是只B。

单样本 $x=2,w=3,b=-1$，ReLU输出5，目标1，$L=(5-1)^2=16$。$dL/dh=8$，局部ReLU导数1，所以 $dL/dw=16,db=8$；步长0.01给 $w=2.84,b=-1.08$，新输出4.6、损失12.96。若先更新w再算偏置梯度，就不是这一同状态更新。

### 3.1 计算图要累加多条路径，拓扑只去重节点

加法把上游梯度分别传给输入；乘法给左输入乘右值、给右输入乘左值。$v=x^2+x$在x=2的梯度是 $2x+1=5$，同一节点复用两次不能覆盖前一路。反向按前向拓扑的逆序执行，让所有下游贡献先累加，再往前传。

完整 `Value`引擎、加/乘/负号/减法/幂和XOR训练已有[数学06第6节](../数学与数值计算专题/06-微积分梯度与自动微分.md)，本章不复制第二套标量引擎。用 $(a-b)^2$验算 $da=2(a-b),db=-2(a-b)$；用 $x^3$验算 $3x^2$；ReLU零点是选定次梯度而非处处可微。重用同一计算图反复backward时，中间节点与叶子梯度状态要符合清零/累积约定，不能只清参数就假定任何引擎都正确。

反向的时间通常与可微前向同量级，复用缓存而不逐参数跑两次。它需要激活缓存，不能宣称比数值差分一定省内存；checkpoint以重算换内存。自动微分不是有限差分/符号推导，也不会修复断图、错误标签或错误目标。

## 4. 完整NumPy MLP：任意层数、三种输出损失与梯度检查

下面是一份完整可运行程序，不依赖GPU。隐藏层支持tanh、Sigmoid、ReLU；最后直接输出logit/连续值。用float64检查每个权重和偏置，对平滑tanh网络核对，再训练XOR和圆形数据。拟合圆形数据时独立留出，不能用训练准确率证明泛化。

```python
import numpy as np

def sigmoid(z):
    z = np.asarray(z, float)
    p = np.empty_like(z)
    pos = z >= 0
    p[pos] = 1/(1+np.exp(-z[pos]))
    exp_z = np.exp(z[~pos])
    p[~pos] = exp_z/(1+exp_z)
    return p

def activation(z, kind):
    if kind == "tanh":
        a = np.tanh(z)
        return a, 1-a*a
    if kind == "sigmoid":
        a = sigmoid(z)
        return a, a*(1-a)
    if kind == "relu":
        return np.maximum(z, 0), (z > 0).astype(float)
    raise ValueError("未知隐藏激活")

class MLP:
    def __init__(self, sizes, hidden="tanh", seed=0):
        if len(sizes) < 2 or any(not isinstance(s, int) or s < 1 for s in sizes):
            raise ValueError("层维数必须为正整数")
        self.sizes, self.hidden = sizes, hidden
        rng = np.random.default_rng(seed)
        self.params = []
        for layer, (fan_in, fan_out) in enumerate(zip(sizes[:-1], sizes[1:])):
            is_hidden = layer < len(sizes)-2
            scale = np.sqrt(2/fan_in) if is_hidden and hidden == "relu" else np.sqrt(2/(fan_in+fan_out))
            self.params.append([rng.normal(0, scale, (fan_in, fan_out)), np.zeros(fan_out)])

    def forward(self, X):
        X = np.asarray(X, dtype=np.float64)
        if X.ndim != 2 or X.shape[1] != self.sizes[0] or not np.isfinite(X).all():
            raise ValueError("输入形状或数值不合法")
        a, cache = X, []
        for layer, (w, b) in enumerate(self.params):
            z = a @ w+b
            if layer < len(self.params)-1:
                next_a, derivative = activation(z, self.hidden)
            else:
                next_a, derivative = z, None
            cache.append((a, derivative))
            a = next_a
        return a, cache

    def loss_and_grads(self, X, y, loss="bce"):
        logits, cache = self.forward(X)
        y = np.asarray(y)
        if len(logits) == 0:
            raise ValueError("训练批量不能为空")
        n = len(logits)
        if loss == "bce":
            if y.shape != logits.shape or not np.isin(y, [0, 1]).all():
                raise ValueError("BCE标签形状应与logit一致，且为0/1")
            value = np.mean(np.logaddexp(0, logits)-y*logits)
            delta = (sigmoid(logits)-y)/logits.size
        elif loss == "mse":
            if y.shape != logits.shape or not np.isfinite(y).all():
                raise ValueError("MSE目标形状/数值不合法")
            value = np.mean((logits-y)**2)
            delta = 2*(logits-y)/logits.size
        elif loss == "ce":
            if y.shape != (n,) or not np.issubdtype(y.dtype, np.integer) or (y < 0).any() or (y >= logits.shape[1]).any():
                raise ValueError("CE要求每样本一个有效整数类别")
            shifted = logits-logits.max(1, keepdims=True)
            log_p = shifted-np.log(np.exp(shifted).sum(1, keepdims=True))
            value = -log_p[np.arange(n), y].mean()
            delta = np.exp(log_p)
            delta[np.arange(n), y] -= 1
            delta /= n
        else:
            raise ValueError("未知损失")
        grads = [None]*len(self.params)
        for layer in reversed(range(len(self.params))):
            previous, _ = cache[layer]
            w, _ = self.params[layer]
            grads[layer] = [previous.T @ delta, delta.sum(0)]
            if layer > 0:
                delta = (delta @ w.T)*cache[layer-1][1]
        return float(value), grads

    def step(self, grads, rate):
        for parameters, gradient in zip(self.params, grads):
            for p, g in zip(parameters, gradient):
                if p.shape != g.shape or not np.isfinite(g).all():
                    raise ValueError("梯度形状不匹配或非有限")
                p -= rate*g

    def check_gradient(self, X, y, loss="bce", h=1e-5):
        _, analytic = self.loss_and_grads(X, y, loss)
        numerical = []
        for layer, parameters in enumerate(self.params):
            for p in parameters:
                g = np.zeros_like(p)
                for index in np.ndindex(p.shape):
                    old = p[index]
                    p[index] = old+h
                    high = self.loss_and_grads(X, y, loss)[0]
                    p[index] = old-h
                    low = self.loss_and_grads(X, y, loss)[0]
                    p[index] = old
                    g[index] = (high-low)/(2*h)
                numerical.append(g.ravel())
        exact = np.concatenate([g.ravel() for pair in analytic for g in pair])
        numeric = np.concatenate(numerical)
        maximum = np.max(np.abs(exact-numeric))
        relative = np.linalg.norm(exact-numeric)/(np.linalg.norm(exact)+np.linalg.norm(numeric)+1e-12)
        return float(maximum), float(relative)

X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = np.array([[0.], [1.], [1.], [0.]])
net = MLP([2, 4, 1], seed=4)
print("BCE全部参数梯度检查", net.check_gradient(X, y))
assert net.check_gradient(X, y)[1] < 1e-7
for step in range(5000):
    value, grads = net.loss_and_grads(X, y)
    net.step(grads, rate=0.5)
p = sigmoid(net.forward(X)[0])
print("XOR概率", p.ravel().round(5), "训练损失", round(value, 6))
assert np.array_equal((p >= 0.5).astype(int), y.astype(int))

rng = np.random.default_rng(42)
X = rng.uniform(-1.5, 1.5, (240, 2))
y = (np.sum(X*X, 1) < 1).astype(float)[:, None]
train, valid = np.arange(180), np.arange(180, 240)
net = MLP([2, 12, 1], hidden="tanh", seed=5)
for step in range(3000):
    ids = rng.choice(train, size=32, replace=False)
    value, grads = net.loss_and_grads(X[ids], y[ids])
    net.step(grads, rate=0.1)
p = sigmoid(net.forward(X[valid])[0])
print("圆形留出准确率", round(np.mean((p >= 0.5) == y[valid]), 4),
      "恒多数类基线", round(max(y[valid].mean(), 1-y[valid].mean()), 4))

small_X = rng.normal(size=(3, 2))
for loss, target, out in [("ce", np.array([0, 2, 1]), 3),
                           ("mse", rng.normal(size=(3, 2)), 2)]:
    model = MLP([2, 3, out], seed=7)
    result = model.check_gradient(small_X, target, loss)
    print(loss, "全部参数梯度检查", result)
    assert result[1] < 1e-7
```

梯度检查只证明给定点、给定实现和损失的一致性；不能证明网络泛化或在所有输入上正确。避免在ReLU折点附近比较中央差分，先用tanh、float64、无Dropout小网络；比较多个步长，统计最大绝对误差和相对范数，不能用大分母掩盖所有小梯度。完整原则由[数值稳定专题第5节](../数学与数值计算专题/08-浮点误差与数值稳定.md)维护。

本次固定输入实测BCE/CE/MSE全参数检查最大绝对差分别约 $1.2\times10^{-11}$、$1.8\times10^{-11}$、$6.1\times10^{-11}$。XOR四点阈值分类全对；圆形60条留出准确率约0.9833、恒多数类基线约0.7167。前者核对求导，后者只是一次合成划分结果，不代表现实图像识别或任意初始化的收敛保证。

圆形标签在当前特征不线性可分，但加平方半径后可由线性模型处理，见[概率分类专题](../机器学习专题/02-逻辑回归与支持向量机.md)。这提醒先改善表示，再决定是否真的需要深度网络。宽度8/12/32或深度1/2不是天然最佳，不能按输入维数的2～4倍、参数量为样本数5～10倍机械选型。

## 5. 激活的函数与导数必须对应同一个前向

| 激活 | 函数与局部导数 | 使用与边界 |
|---|---|---|
| Sigmoid | $s=1/(1+e^{-z}),s'=s(1-s)$ | 有界输出；两端饱和；隐藏值不自动是概率 |
| tanh | $a=\tanh z,a'=1-a^2$ | 零中心；大绝对值饱和，不能保证消除优化锯齿 |
| ReLU | $\max(0,z)$，正区导数1、负区0 | 0不可微，可约定次梯度0；正区也需通过权重Jacobian |
| Leaky ReLU | 正区z，负区$\alpha z$ | 负斜率可固定；允许负区梯度，不保证整网健康 |
| PReLU | 同上，但$\alpha$可学习 | 负区 $\partial a/\partial\alpha=z$；常按通道或共享，注册为参数 |
| ELU | 正区z，负区$\alpha(e^z-1)$ | 负导数$\alpha e^z$仍可饱和；$\alpha=1$在0一阶平滑 |
| GELU精确式 | $z\Phi(z)$，导数$\Phi(z)+z\varphi(z)$ | 平滑但可有负导数/近零梯度；不保证永无训练停滞 |
| SiLU | $z\sigma(z)$，导数$s+zs(1-s)$ | 也称Swish的$\beta=1$情形；与GELU不同，需模型依据 |

GELU的常用tanh近似令 $u=\sqrt{2/\pi}(z+0.044715z^3)$，函数为 $0.5z(1+\tanh u)$，对应导数是：

$$
\frac12(1+\tanh u)+\frac12z(1-\tanh^2u)\sqrt{2/\pi}(1+3\cdot0.044715z^2).
$$

**不能前向用近似、反向却用精确GELU导数。**误差很小也意味着在优化另一个函数，应分别实现并梯度检查；当前PyTorch用 `approximate="none"`/`"tanh"`显式区分。

```python
import math
import numpy as np

def pair(z, kind, alpha=0.01):
    z = np.asarray(z, float)
    s = 1/(1+np.exp(-np.clip(z, -500, 500)))
    if kind == "sigmoid": return s, s*(1-s)
    if kind == "tanh":
        a = np.tanh(z); return a, 1-a*a
    if kind == "relu": return np.maximum(z, 0), (z > 0).astype(float)
    if kind == "leaky": return np.where(z > 0, z, alpha*z), np.where(z > 0, 1., alpha)
    if kind == "elu": return np.where(z > 0, z, alpha*np.expm1(z)), np.where(z > 0, 1., alpha*np.exp(z))
    if kind == "silu": return z*s, s+z*s*(1-s)
    if kind == "gelu":
        cdf = 0.5*(1+np.vectorize(math.erf)(z/np.sqrt(2)))
        pdf = np.exp(-z*z/2)/np.sqrt(2*np.pi)
        return z*cdf, cdf+z*pdf
    if kind == "gelu_tanh":
        u = np.sqrt(2/np.pi)*(z+0.044715*z**3)
        t = np.tanh(u)
        return 0.5*z*(1+t), 0.5*(1+t)+0.5*z*(1-t*t)*np.sqrt(2/np.pi)*(1+3*0.044715*z*z)
    raise ValueError("未知激活")

points = np.array([-2., -0.7, 0.4, 1.5])  # 避开ReLU折点
for kind in ["sigmoid", "tanh", "relu", "leaky", "elu", "silu", "gelu", "gelu_tanh"]:
    output, analytic = pair(points, kind)
    numerical = (pair(points+1e-5, kind)[0]-pair(points-1e-5, kind)[0])/2e-5
    error = np.max(np.abs(analytic-numerical))
    print(kind, "输出", output.round(4), "导数差", f"{error:.2e}")
    assert error < 1e-7
print("GELU两种实现最大差", np.max(np.abs(pair(points, "gelu")[0]-pair(points, "gelu_tanh")[0])))
```

这个扫描用输入网格检查函数性质，不是训练中的死神经元百分比。PReLU斜率若参数化不限制正数，可能学习负斜率，需明确约束；初始化通常正数。激活选择应匹配具体架构和实测，不存在“所有Transformer必须GELU”“有死ReLU只许换GELU”的规则。Transformer内部还可有SiLU门控变体；LSTM门常Sigmoid、状态常tanh，状态维度或稳定性问题仍要按具体模型检查。

GELU/SiLU并非处处单调，负区可先下降再趋近0，局部导数可能负或略大于1；它们不是把数值变成概率的输出函数。平滑减少硬截断不等于阻止饱和、下溢或其他路径带来的零梯度。

### 5.1 Softmax不是逐元素激活，温度也不是正确率按钮

$p_i=\exp(z_i/T)/\sum_j\exp(z_j/T)$，$T>0$，每个类别输出依赖全部logit，Jacobian为 $\partial p_i/\partial z_j=p_i(\mathbf1[i=j]-p_j)/T$，不能只存逐元素导数。它用于互斥输出，也用于注意力和内部软选择；对应的类别/候选维须明确。

相同有限logits下，温度改变分布尖锐程度而不改变argmax排序。$T\to\infty$趋向K类均匀，K不等于2时不是“抛硬币”；$T\to0^+$把质量放在最大项，多个相同最大值则均分，不能任意指定唯一胜者。温度低不自动提升正确率或校准，训练梯度还乘1/T。数值上先对 $z/T$减最大值再求指数，稳定实现见数学08，本章CE与NT-Xent代码已经直接用稳定log概率。

## 6. 梯度健康：测反向量，而不是只画前向激活

一层反向是 $g_{l-1}=W_lg_l\odot\phi'(z_{l-1})$（按列/行约定相应转置）。Sigmoid最大局部导数0.25，但完整梯度还乘权重Jacobian，不能说任何十层网络整体梯度一定不超过 $0.25^{10}$。ReLU正区导数1也不能抵消权重小、死路径、乘积爆炸或错误归一化。

源图的 $0.25^L$、$0.42^L$、$1^L$只是在**固定权重影响并忽略其他路径**的局部导数乘积示意，0.42不是tanh通用导数。源Python“vanishing gradient experiment”只输出前向幅值；幅值小不等于梯度小，幅值大也不证明梯度正常。以下真实链式实验同时测激活、权重范数与输入梯度。

```python
import numpy as np

rng = np.random.default_rng(42)
width, depth = 6, 50
weights = [rng.normal(0, np.sqrt(1/width), (width, width)) for _ in range(depth)]
x = rng.normal(size=width)
for kind in ["sigmoid", "tanh", "relu"]:
    a, derivatives = x.copy(), []
    for w in weights:
        z = a @ w
        if kind == "sigmoid":
            a = 1/(1+np.exp(-np.clip(z, -500, 500))); d = a*(1-a)
        elif kind == "tanh":
            a = np.tanh(z); d = 1-a*a
        else:
            a = np.maximum(z, 0); d = (z > 0).astype(float)
        derivatives.append(d)
    g = np.ones(width)  # L为最后各激活的和
    norms = [np.linalg.norm(g)]
    for w, d in zip(reversed(weights), reversed(derivatives)):
        g = (g*d) @ w.T
        norms.append(np.linalg.norm(g))
    print(kind, "末层激活范数", round(np.linalg.norm(a), 6),
          "输入梯度范数", f"{np.linalg.norm(g):.3e}",
          "反向第1/10/50步范数", [f"{norms[i]:.3e}" for i in [1, 10, 50]])
```

公平比较训练表现需数据/划分/损失一致、合适初始化和学习率、多个种子，并报告时间、指标与梯度；单一网络固定数值不能推出所有激活排名。ReLU常配He方差约$2/fan_{in}$，Sigmoid/tanh可先考虑Xavier方差约$2/(fan_{in}+fan_{out})$，具体gain/分布另有条件。均匀抽 $[-\sqrt{2/n},\sqrt{2/n}]$的方差是 $2/(3n)$，不能把区间端点当高斯标准差，也不能认为He初始化自动防止Sigmoid饱和。

训练监控至少统计每层梯度范数/最大值、激活均值/方差、ReLU在观察数据窗口中的全零单元比例、实际参数更新范数。梯度0.001或100的固定门槛只可示例，受损失缩放、层大小、dtype影响；看趋势和更新/参数比更可靠。零梯度也可能已收敛、断图、当前门关闭或未用参数，不能自动归因死神经元。观察一批不激活不证明永远死，其他层变化、优化器状态或数据变化可能恢复它。

梯度裁剪有逐坐标截断和全局范数缩放之别；clip所有分量到[-1,1]不等于 `clip_grad_norm_(...,1)`。裁剪限制大更新，不修复原先很小梯度，也不修复损失已经NaN。完整剪裁/混合精度/首个非有限算子定位由[数值稳定](../数学与数值计算专题/08-浮点误差与数值稳定.md)和[优化专题](05-深度学习优化.md)统一维护。

上方50层固定权重实测，Sigmoid输入梯度范数约 $6.1\times10^{-32}$，tanh约0.0713，ReLU在此随机链上走到全零，输入梯度为0。这个反例说明“ReLU局部导数1”不保证整条路径健康；采用同一方差也不是各激活最合适的初始化配方，不能据此宣布tanh在真实任务更好。

## 7. 输出、目标与损失：先对齐任务再比较

| 任务 | 训练输出/目标 | 主要目标与条件 |
|---|---|---|
| 连续回归 | 实数输出，与目标同形状 | MSE；异常影响大时比较MAE/Huber，单位须明确 |
| 二分类 | 一个logit，0/1浮点目标同形状 | BCEWithLogits；推理才Sigmoid，阈值按验证/成本 |
| 单标签多分类 | 每类logit，整数类索引；或合法软分布 | CE；类别维正确，不先Softmax再喂CE |
| 多标签 | 每标签logit，多个独立0/1目标 | 每标签BCE，可同时多项成立，不能强迫总和1 |
| 有界回归 | 由领域约束决定输出映射 | Sigmoid/tanh可缩放范围，但边界饱和要检查 |
| 表示/检索 | embedding与正负对应 | InfoNCE/Triplet等，样本构造是目标的一部分 |

**MSE也可用于二分类概率，是二元Brier评分的一种约定。**条件期望平方损失在 $p=P(y=1\mid x)$处最小，常数0.5仅是平衡且不利用输入的最佳常数。若完美可区分，概率0/1给MSE=0，比0.25更好。BCE也在同一真实条件概率处最优；没有信息时它同样接受常数0.5，而不会魔法“强制学到可分信息”。

二者优化差异见第3节：Sigmoid+MSE含额外 $p(1-p)$，自信且错时logit梯度容易小；BCE组合后为 $p-y$，有限logit时在[-1,1]内，**不是指数爆炸**。对概率的 $dL/dp$在端点可发散，对logit的梯度是另一对象。$-\log p$是对数而非指数惩罚；CE比MSE更偏好某些梯度尺度，但神经网络参数目标仍通常非凸。

### 7.1 归约、形状与稳定API

`MSELoss(reduction="mean")`平均所有预测元素；多输出时是$B\times d$。BCElogits也按元素平均。CE硬标签通常是每条样本一个类别损失，再按有效样本平均；类别权重/ignore mask会改变分母，不能统称所有loss的mean都除B。源正文的BCE平均损失代码与导数漏除n曾不一致，写实现必须同一归约。

当前PyTorch：`BCEWithLogitsLoss`直接接原始logit，目标通常浮点同形状；`CrossEntropyLoss`接每类logit，硬目标 `long`形状去掉类别维，软目标浮点与logit同形状且每行非负总和1。软件未完全校验软分布不代表任意负数合法。`NLLLoss(log_softmax(...))`也是稳定组合，不能误读为必须手动softmax后取log。

初始均匀K类预测的CE约$\log K$，二分类零logit BCE约$\log2$，只在无权重、目标/归约相应条件下成立。训练优化的是指定loss，不是自动优化准确率/F1；跨loss数值尺度不一样，不能拿0.1MSE和0.3BCE直接判优。

### 7.2 标签平滑与蒸馏：软目标不是自动可靠

$q=(1-\alpha)onehot+\alpha/K$。K=10、alpha=0.1时真类0.91，其他0.01；K=2则0.95/0.05，不是永远0.9/0.1。每样本理想最小CE为 $H(q)$，平滑改变学习目标并可能降低过度自信，不等于硬概率帽或跨分布校准保证；也没有依据说所有大模型必须平滑。

固定软目标 $q$，$H(q,p)=H(q)+KL(q\|p)$，对模型参数梯度相同，因为 $H(q)$不依赖预测。蒸馏常用teacher/student温度T分布，学生logit梯度 $(p_T-q_T)/T$；乘$T^2$是补偿温度尺度的常见约定，与硬标签损失权重需一起说明，T不是通用4～20。

下面完整CPU对照明确使用固定软分布，检查CE/KL的差值与梯度，再验证极端logit稳定损失。`kl_div`的input是log概率，target是概率；batchmean按批量除，而不是像mean再除类别数。

```python
import torch
from torch.nn import functional as F

torch.set_num_threads(1)
z = torch.tensor([[2., -1., 0.5], [0.2, 0.3, -0.4]], dtype=torch.float64, requires_grad=True)
q = torch.tensor([[0.7, 0.2, 0.1], [0.1, 0.6, 0.3]], dtype=torch.float64)
assert torch.all(q >= 0) and torch.allclose(q.sum(1), torch.ones(2, dtype=torch.float64))
log_p = F.log_softmax(z, dim=1)
ce = -(q*log_p).sum(1).mean()
kl = F.kl_div(log_p, q, reduction="batchmean")
entropy = -(q*q.log()).sum(1).mean()  # 本例q无零；有零时按0log0=0约定处理
g_ce = torch.autograd.grad(ce, z, retain_graph=True)[0]
g_kl = torch.autograd.grad(kl, z)[0]
assert torch.allclose(ce-kl, entropy) and torch.allclose(g_ce, g_kl)
assert torch.allclose(g_ce, (z.softmax(1)-q)/len(z))
print("CE/KL/目标熵", ce.item(), kl.item(), entropy.item(), "梯度完全一致")
extreme = torch.tensor([1000., -1000.], dtype=torch.float64, requires_grad=True)
targets = torch.tensor([0., 1.], dtype=torch.float64)
loss = F.binary_cross_entropy_with_logits(extreme, targets)
gradient = torch.autograd.grad(loss, extreme)[0]
print("极端BCE", loss.item(), "对logit梯度", gradient.tolist())
assert loss.item() == 1000 and torch.allclose(gradient, torch.tensor([0.5, -0.5], dtype=torch.float64))
```

## 8. 回归与焦点损失：公式、次梯度与有限差分

令误差 $r=\hat y-y$，Huber定义 $|r|\le\delta$时$r^2/2$，外部$\delta(|r|-\delta/2)$，导数 $\operatorname{clip}(r,-\delta,\delta)$。MAE用$|r|$，0处取合法次梯度；Huber与PyTorch SmoothL1的关系是 `Huber(delta)=delta*SmoothL1(beta=delta)`，不在所有delta下数值相同。delta单位与目标一致，标准化目标后必须重新解释容差。

焦点损失 $-\alpha_t(1-p_t)^\gamma\log p_t$，$p_t$为真实类概率，$\gamma$增强易样本下权重。gamma=0是**加权**CE；若alpha_t=1才是未加权CE。它可能改善类别不平衡中的困难样本关注，也可能放大错误标签，不能保证召回提升或概率校准。不能仅按10:1类别比自动选固定gamma/alpha。

```python
import numpy as np

def huber(r, delta=1):
    if delta <= 0: raise ValueError("delta须为正")
    r = np.asarray(r, float)
    value = np.where(np.abs(r) <= delta, r*r/2, delta*(np.abs(r)-delta/2))
    return value.mean(), np.clip(r, -delta, delta)/r.size

def focal_logits(z, y, gamma=2, alpha=0.25):
    z, y = np.asarray(z, float), np.asarray(y)
    if z.shape != y.shape or not np.isin(y, [0, 1]).all() or gamma < 0:
        raise ValueError("需要同形状logit/二元标签及非负gamma")
    if z.size == 0 or not np.isfinite(z).all() or (alpha is not None and not 0 <= alpha <= 1):
        raise ValueError("输入须非空有限，alpha须在0到1之间")
    sign = 2*y-1
    log_pt = -np.logaddexp(0, -sign*z)
    pt = np.exp(log_pt)
    weight = np.ones_like(z) if alpha is None else np.where(y == 1, alpha, 1-alpha)
    loss = -weight*(1-pt)**gamma*log_pt
    gradient = weight*sign*(1-pt)**gamma*(gamma*pt*log_pt-(1-pt))/z.size
    return loss.mean(), gradient

r = np.array([-2., -0.4, 0.3, 3.])
z, y = np.array([-2., -0.5, 0.5, 2.]), np.array([0., 1., 0., 1.])
for label, point, func in [("Huber", r, lambda t: huber(t)),
                            ("Focal", z, lambda t: focal_logits(t, y))]:
    value, exact = func(point)
    numeric = np.zeros_like(point)
    for j in range(len(point)):
        delta = np.eye(len(point))[j]*1e-5
        numeric[j] = (func(point+delta)[0]-func(point-delta)[0])/2e-5
    print(label, "损失", round(value, 6), "导数最大差", np.max(np.abs(exact-numeric)))
    assert np.allclose(exact, numeric, atol=1e-7)
plain, _ = focal_logits(z, y, gamma=0, alpha=None)
assert np.isclose(plain, np.mean(np.logaddexp(0, z)-y*z))
```

若做5%异常回归实验，先按干净生成机制定义留出测试，再只污染训练目标，同架构/划分比较MSE与Huber，并报告干净测试MAE/RMSE、尾部误差和delta；不要把测试异常删除当稳健提升。BCE/focal比较应固定少数类定义、阈值选择规则、Precision/Recall与校准；只提高Recall可能靠误报增加，并不自动满足实际目标。

## 9. InfoNCE与Triplet：有效知识在样本关系和完整分母

对anchor i、positive j及候选k，InfoNCE为 $-s_{ij}/\tau+\log\sum_{k\in candidates}e^{s_{ik}/\tau}$，$\tau>0$，分母**包括positive**。SimCLR的N个原图有2N视图，对每个anchor排除自身，剩2N-1候选、其中1个正例和2N-2负例；跨模态N×N一对一版本则每行N候选/N-1负例。不能把这两种批量大小混用。

输入L2归一化时相似度为内积。低温让分布尖、对难负例更敏感，但“低温一定更高loss”不成立：若正例明显最高，低温可使loss更小。所有候选相似度相同时loss=$\log(candidate数)$，**全向量坍缩不是0loss**，却可能成为不理想的驻点。多视图关系、错配正例、同类假负例、增强丢失语义、零向量和温度都要验收。

下面完整实现对2N个原始embedding做归一化、双向样本CE，给出对**原始未归一化embedding**的梯度，并逐分量数值核验。配对是相邻行0↔1、2↔3等。

```python
import numpy as np

def nt_xent(raw, temperature=0.5):
    raw = np.asarray(raw, float)
    if raw.ndim != 2 or len(raw) < 4 or len(raw) % 2 or temperature <= 0:
        raise ValueError("需要至少两对视图及正温度")
    norm = np.linalg.norm(raw, axis=1, keepdims=True)
    if not np.isfinite(raw).all() or (norm == 0).any():
        raise ValueError("embedding须有限且非零")
    u = raw/norm
    score = u @ u.T/temperature
    np.fill_diagonal(score, -np.inf)
    shifted = score-score.max(1, keepdims=True)
    log_p = shifted-np.log(np.exp(shifted).sum(1, keepdims=True))
    partner = np.arange(len(raw)) ^ 1
    loss = -log_p[np.arange(len(raw)), partner].mean()
    delta = np.exp(log_p)
    delta[np.arange(len(raw)), partner] -= 1
    delta /= len(raw)
    du = (delta+delta.T) @ u/temperature
    grad = (du-u*(du*u).sum(1, keepdims=True))/norm
    return float(loss), grad

rng = np.random.default_rng(42)
raw = rng.normal(size=(6, 3))
value, exact = nt_xent(raw)
numeric = np.zeros_like(raw)
for index in np.ndindex(raw.shape):
    change = np.zeros_like(raw); change[index] = 1e-5
    numeric[index] = (nt_xent(raw+change)[0]-nt_xent(raw-change)[0])/2e-5
print("NT-Xent损失", round(value, 6), "全梯度最大差", np.max(np.abs(exact-numeric)))
assert np.allclose(exact, numeric, atol=1e-7)
collapsed = np.ones((6, 3))
collapse_loss, collapse_gradient = nt_xent(collapsed)
print("完全坍缩损失", collapse_loss, "理论log5", np.log(5),
      "梯度范数", np.linalg.norm(collapse_gradient))
assert np.isclose(collapse_loss, np.log(5))
```

这只训练目标计算，不是SimCLR图像训练或可用embedding。本文不把温度0.07、batch≥256作通用需求，也不把更大batch效果数字当当前硬件结论。InfoNCE可自监督或监督构造正例，不是概念上一定“没有标签”；无负样本方案有不同防坍缩机制，不能套这一分母。

Triplet通常 $\max(0,d(a,p)-d(a,n)+m)$。若d为平方L2且活跃，对a/p/n梯度为 $2(n-p),2(p-a),2(a-n)$；若用非平方距离，梯度不同。semi-hard负例满足 $d(a,p)<d(a,n)<d(a,p)+m$，取其中较近者；只要求“更远”可能挑到零损失的过易负例。完全hard负例可能是错标签/假负例，应检查而不无限增加难度。无可用semi-hard时须说明跳过或回退策略。

## 10. 从手写到框架：哪些检查仍不能省

`nn.Linear`存储的权重是本章手写W的转置；迁移同一数据与参数时必须对齐这一点。CE/BCE直接接logits，训练时zero_grad→forward→loss→backward→step，推理分数转换另做。`model.eval()`控制Dropout/BatchNorm等模式，`no_grad()`控制图记录，互不替代；普通forward不执行optimizer更新，但某些训练模式层会更新缓冲统计量。

框架自动求导前先确认参数被注册、优化器包含目标参数、dtype/device一致、没有意外detach或重建tensor、梯度累积符合批量约定。先用极小固定样本过拟合，再比较留出表现。实际框架CPU训练与保存检查的完整例子维护在[训练基础第12节](01-训练基础与深度学习计算.md)，避免在每章复制一套训练模板。

## 11. 练习与可核对答案

1. NAND和三输入多数票怎么设置？**答案：**第1节给权重/偏置和可执行验证；收敛参数不唯一，检查真值表和间隔，不强求与示例相同数字。
2. 2-4-2-1各中间形状、3-4-4-2的RGB输出怎么解释？**答案：**对B批量分别是(B,2)→(B,4)→(B,2)→(B,1)；RGB网络是(B,3)→(B,4)→(B,4)→(B,2)。没有标签与训练，两个随机输出不证明颜色判别；互斥二类可用两logit+CE或一logit+BCE。
3. 784-256-128-10参数数？**答案：**235146，输入像素数量不是训练参数。两隐藏层比一层好是可测试假设，不由参数公式证明。
4. 手工Sigmoid门为啥用±20，不直接这样初始化训练？**答案：**模拟硬门需要陡跃迁，但饱和梯度会极小；手工实现与随机训练是不同任务。所谓“leaky step”负区0.01z、正区常数1，在同一手工门权重的四个XOR输入下输出约 `[-0.12,1,1,-0.12]`，按0.5阈值仍分类正确；但它不是LeakyReLU，正区导数0且0处跳跃，不应当成标准梯度激活。
5. 减法、负号、幂、ReLU怎样检查？**答案：**按第3.1节与数学06引擎算$(a-b)^2,x^3$，复用节点必须累加；ReLU非零处差分核验，折点用次梯度约定。
6. 为什么深Sigmoid梯度未必严格是0.25的层数次幂？**答案：**还含权重Jacobian和多路径；第6节显式反传输入梯度。打印激活不是梯度监控，最后一轮梯度小也可能收敛。
7. GELU导数不一致怎么抓？**答案：**分别对精确式和tanh近似做差分，第5节给同前向导数；不能用两个函数近似接近作为严格gradient check通过。
8. PReLU、ELU、50层与每层监控怎么做？**答案：**第5节给函数/导数和PReLU斜率梯度，第6节给50层真反向；训练比较先对齐初始化、数据、loss、多个种子。固定0.001/100仅示例，不保证适用。
9. MSE是否会被0.5永久“骗过”？**答案：**没有信息的平衡最佳常数0.5，两种适当评分都如此；有预测信息时MSE可更低。应检查表达、初始化/对称性、断图、标签与优化，不只换loss。
10. Huber/focal与MSE/BCE比较怎么验收？**答案：**第8节给实现和差分、实验协议；比较共同任务指标而不是不同尺度的loss数字。正类Recall需与误报成本一起看。
11. Triplet挖掘与InfoNCE怎么避免看似正确？**答案：**标明d是否平方，明确semi-hard区间、正负关系与完整分母；第9节检查全梯度和坍缩log5反例。真实五类embedding训练需再独立评估检索，不把此代码当已完成表示学习。
12. CE与KL何时梯度相同？**答案：**目标q固定且支持条件满足，二者差$H(q)$；teacher变化/参与梯度时结论需重新说明，温度还改变logit梯度尺度。
