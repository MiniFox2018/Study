# 18｜张量框架与模型调试

> 先修：[张量形状与广播](../数学与数值计算专题/04-张量形状广播与批量计算.md)、[链式法则与标量自动微分](../数学与数值计算专题/06-微积分梯度与自动微分.md)、[训练基础](01-训练基础与深度学习计算.md)。这里继续到张量计算图、真实框架的状态与训练、可证伪的排错。通用Python堆栈、日志、CPU计时和内存定位由[调试实践入口](../../Python/实践/02-调试日志与性能定位.md)维护。

## 1. 框架组织的是什么

框架把五种职责分开：张量记录值/形状/类型/设备；自动微分把基本操作连接成图；模块登记参数与状态、定义前向；损失表达任务；优化器按梯度更新登记参数。Dataset/DataLoader提供样本与批量，训练循环决定何时前向、反向、更新和验证。

手写每层backward的Sequential适合一条顺序链；分支、共享参数和重复节点需要计算图管理。PyTorch的`nn.Module`通常不要求用户实现`backward`，由张量autograd处理；不能把教学Module接口原样当其API。框架也不保证随便组合模块就能训练成功，输入轴、目标、损失和梯度仍有契约。

原课4层圆形分类器参数量是465：`2×16+16 + 16×16+16 + 16×8+8 + 8×1+1`。它虽把样本分组，但每个样本清零、反向、step，所以**实际是逐样本更新，不是每批一步**。容器名字叫DataLoader不能证明优化语义。下文用真正批量矩阵与损失平均复建同一职责。

## 2. 从标量引擎扩展到张量VJP

反向传播的是上游梯度乘局部Jacobian，而不必生成巨大完整Jacobian。二维矩阵 $Y=XW+b$，上游 $G=\partial L/\partial Y$，有 $dX=GW^T$、$dW=X^TG$、$db=\sum_{batch}G$。这是本教学版权重 `(in,out)` 约定；PyTorch Linear存`(out,in)`，对应公式要转置。

广播前 `(3,1)` 与 `(1,4)`，前向得到 `(3,4)`；反向对第一输入沿列求和得到 `(3,1)`，对第二沿行求和得到 `(1,4)`。一般先消掉前向额外增加的左轴，再沿原长度为1的轴求和。忘记还原形状会产生错误偏置更新。

节点按拓扑逆序执行一次，复用边的贡献必须累加。`x*x+x`在x=2时梯度5；“遍历去重”不能把两条乘法边合成一次贡献。叶子梯度可跨多次backward累加，非叶子临时梯度每次需重置；否则第二次传播可能重复放大。参数在反向完成前不得修改，当前图的局部规则对应前向当时的值。

下面完整NumPy教学引擎支持广播加/乘、二维矩阵乘、sum/mean、整数幂、ReLU/tanh和稳定多类交叉熵。前向缓存必要值、反向支持显式VJP种子。定义域仍由调用者核对：零分母、非有限输入不因自动微分变合法。它不实现任意切片、批量matmul、高阶导、GPU、稀疏、原地版本检查或生产调度；这些边界必须保留。

```python
import numpy as np

def sum_to(g, shape):
    g = np.asarray(g, dtype=float)
    while g.ndim > len(shape):
        g = g.sum(axis=0)
    for axis, size in enumerate(shape):
        if size == 1 and g.shape[axis] != 1:
            g = g.sum(axis=axis, keepdims=True)
    return g.reshape(shape)

class Tensor:
    def __init__(self, data, parents=(), requires_grad=True):
        self.data = np.array(data, dtype=float, copy=True)
        self.grad = np.zeros_like(self.data)
        self.parents = tuple(parents)
        self.requires_grad = requires_grad
        self.pullback = lambda: None
    @staticmethod
    def wrap(value):
        return value if isinstance(value, Tensor) else Tensor(value, requires_grad=False)
    def add_grad(self, g):
        if self.requires_grad:
            self.grad += sum_to(g, self.data.shape)
    def __add__(self, other):
        other = self.wrap(other)
        out = Tensor(self.data + other.data, (self, other), self.requires_grad or other.requires_grad)
        def back():
            self.add_grad(out.grad)
            other.add_grad(out.grad)
        out.pullback = back
        return out
    __radd__ = __add__
    def __mul__(self, other):
        other = self.wrap(other)
        a, b = self.data.copy(), other.data.copy()
        out = Tensor(a*b, (self, other), self.requires_grad or other.requires_grad)
        def back():
            self.add_grad(out.grad*b)
            other.add_grad(out.grad*a)
        out.pullback = back
        return out
    __rmul__ = __mul__
    def __neg__(self):
        return self * -1
    def __sub__(self, other):
        return self + (-self.wrap(other))
    def __pow__(self, power):
        if not isinstance(power, int):
            raise TypeError('本教学版只支持整数幂')
        a = self.data.copy()
        out = Tensor(a**power, (self,), self.requires_grad)
        derivative = np.zeros_like(a) if power == 0 else power*a**(power-1)
        out.pullback = lambda: self.add_grad(out.grad*derivative)
        return out
    def __truediv__(self, other):
        return self * (self.wrap(other)**-1)
    def __matmul__(self, other):
        other = self.wrap(other)
        a, b = self.data.copy(), other.data.copy()
        if a.ndim != 2 or b.ndim != 2:
            raise ValueError('本教学版matmul只接受二维矩阵')
        out = Tensor(a@b, (self, other), self.requires_grad or other.requires_grad)
        def back():
            self.add_grad(out.grad@b.T)
            other.add_grad(a.T@out.grad)
        out.pullback = back
        return out
    def sum(self, axis=None, keepdims=False):
        out = Tensor(self.data.sum(axis=axis, keepdims=keepdims), (self,), self.requires_grad)
        axes = tuple(range(self.data.ndim)) if axis is None else tuple(
            a % self.data.ndim for a in ((axis,) if isinstance(axis, int) else axis))
        def back():
            g = out.grad
            if not keepdims:
                for a in sorted(axes):
                    g = np.expand_dims(g, a)
            self.add_grad(np.broadcast_to(g, self.data.shape))
        out.pullback = back
        return out
    def mean(self):
        if not self.data.size:
            raise ValueError('空输入均值未定义')
        return self.sum() / self.data.size
    def tanh(self):
        value = np.tanh(self.data)
        out = Tensor(value, (self,), self.requires_grad)
        out.pullback = lambda: self.add_grad(out.grad*(1-value**2))
        return out
    def relu(self):
        mask = self.data > 0
        out = Tensor(np.maximum(self.data, 0), (self,), self.requires_grad)
        out.pullback = lambda: self.add_grad(out.grad*mask)
        return out
    def backward(self, seed=None):
        if not self.requires_grad:
            raise ValueError('输出未启用梯度')
        if seed is None:
            if self.data.shape != ():
                raise ValueError('非标量输出需要同形状VJP种子')
            seed = np.array(1.)
        seed = np.asarray(seed, float)
        if seed.shape != self.data.shape:
            raise ValueError('VJP种子形状不符')
        order, seen = [], set()
        def visit(node):
            if id(node) in seen:
                return
            seen.add(id(node))
            for parent in node.parents:
                visit(parent)
            order.append(node)
        visit(self)
        for node in order:
            if node.parents:
                node.grad.fill(0)
        if self.parents:
            self.grad[...] = seed
        else:
            self.grad += seed
        for node in reversed(order):
            node.pullback()

def cross_entropy(logits, target):
    z = logits.data
    target = np.asarray(target)
    if not np.issubdtype(target.dtype, np.integer):
        raise ValueError('目标须是整数类别索引，不能隐式截断浮点标签')
    if z.ndim != 2 or target.shape != (len(z),) or not len(z):
        raise ValueError('需要(B,C)logits与(B,)类别索引')
    if np.any(target < 0) or np.any(target >= z.shape[1]):
        raise ValueError('类别索引越界')
    shifted = z - z.max(axis=1, keepdims=True)
    exp = np.exp(shifted)
    probabilities = exp / exp.sum(axis=1, keepdims=True)
    loss = (np.log(exp.sum(axis=1)) - shifted[np.arange(len(z)), target]).mean()
    out = Tensor(loss, (logits,), logits.requires_grad)
    derivative = probabilities.copy()
    derivative[np.arange(len(z)), target] -= 1
    out.pullback = lambda: logits.add_grad(out.grad*derivative/len(z))
    return out

x = Tensor(2.)
loss = x*x+x
loss.backward()
assert x.grad == 5
loss.backward()
assert x.grad == 10  # 叶子累加，内部临时梯度不重复累加。
a, b = Tensor(np.arange(3.)[:, None]), Tensor(np.ones((1, 4)))
(a+b).sum().backward()
assert np.array_equal(a.grad, np.full((3, 1), 4.))
assert np.array_equal(b.grad, np.full((1, 4), 3.))
v = Tensor([2., 3.])
(v*v).backward(np.array([1., 2.]))
assert np.array_equal(v.grad, [4., 12.])
print('重复路径、广播还原、显式VJP均通过')
```

`backward`本身不更新参数。需要与当批参数同一对象的优化器，不能把参数副本交给优化器却在另一个模型上前向。`sum_to`还原的是广播轴，不是任意丢失维度；错轴不能用reshape强行抹平。数值检查应在光滑点与float64小数据上进行，方法详见数学自动微分章。

## 3. 模块、参数登记、优化器与真正的小批量

每一层保存Tensor参数而非参数副本；Sequential递归收集参数并按对象身份去重，共享参数不应被step两次。激活层没有可训练参数。模式标记递归传入子模块，但“eval模式”与“没有梯度图”是不同开关。

下面代码**续接第2节完整引擎，在同一Python文件中运行**。Adam状态跟随每个参数，step计数每批增加一次；内部梯度累加由叶子实现。与数学优化章的Adam推导对应，算法原理主要见[优化方法](../数学与数值计算专题/07-优化方法与凸性条件.md)与[深度学习优化](05-深度学习优化.md)。

```python
# 续接第2节Tensor与cross_entropy程序。
import json
import tempfile
from pathlib import Path

class Module:
    training = True
    def __call__(self, x):
        return self.forward(x)
    def parameters(self):
        result, seen = [], set()
        def collect(value):
            if isinstance(value, Tensor):
                if value.requires_grad and id(value) not in seen:
                    seen.add(id(value)); result.append(value)
            elif isinstance(value, Module):
                for item in vars(value).values():
                    collect(item)
            elif isinstance(value, (list, tuple)):
                for item in value:
                    collect(item)
        collect(self)
        return result
    def train(self, mode=True):
        self.training = bool(mode)
        for value in vars(self).values():
            values = value if isinstance(value, (list, tuple)) else [value]
            for child in values:
                if isinstance(child, Module):
                    child.train(mode)
        return self
    def eval(self):
        return self.train(False)

class Linear(Module):
    def __init__(self, nin, nout, rng):
        self.weight = Tensor(rng.normal(0, np.sqrt(2/nin), (nin, nout)))
        self.bias = Tensor(np.zeros(nout))
    def forward(self, x):
        return x @ self.weight + self.bias

class ReLU(Module):
    def forward(self, x):
        return x.relu()

class Sequential(Module):
    def __init__(self, *layers):
        self.layers = list(layers)
    def forward(self, x):
        for layer in self.layers:
            x = layer(x)
        return x

class Adam:
    def __init__(self, parameters, lr=.01, beta1=.9, beta2=.999, eps=1e-8):
        self.params, self.lr, self.b1, self.b2, self.eps = list(parameters), lr, beta1, beta2, eps
        self.m = [np.zeros_like(p.data) for p in self.params]
        self.v = [np.zeros_like(p.data) for p in self.params]
        self.steps = 0
    def zero_grad(self):
        for p in self.params:
            p.grad.fill(0)
    def step(self):
        self.steps += 1
        for i, p in enumerate(self.params):
            self.m[i] = self.b1*self.m[i] + (1-self.b1)*p.grad
            self.v[i] = self.b2*self.v[i] + (1-self.b2)*p.grad**2
            m = self.m[i] / (1-self.b1**self.steps)
            v = self.v[i] / (1-self.b2**self.steps)
            p.data -= self.lr*m/(np.sqrt(v)+self.eps)

rng = np.random.default_rng(7)
X = rng.uniform(-2, 2, (360, 2))
y = (np.sum(X**2, axis=1) < 1.5).astype(int)
train, test = np.arange(280), np.arange(280, 360)
model = Sequential(Linear(2, 16, rng), ReLU(), Linear(16, 16, rng), ReLU(),
                   Linear(16, 8, rng), ReLU(), Linear(8, 2, rng))
optimizer = Adam(model.parameters(), lr=.01)
for epoch in range(100):
    model.train()
    order = rng.permutation(train)
    for start in range(0, len(order), 32):
        ids = order[start:start+32]
        optimizer.zero_grad()
        logits = model(Tensor(X[ids], requires_grad=False))
        loss = cross_entropy(logits, y[ids])  # 已按本批实际样本数取均值。
        loss.backward()
        optimizer.step()  # 一批一次，不是每个样本一次。
model.eval()
prediction = model(Tensor(X[test], requires_grad=False)).data.argmax(axis=1)
accuracy = np.mean(prediction == y[test])
assert accuracy > .85

with tempfile.TemporaryDirectory() as directory:
    path = Path(directory)/'参数.json'
    payload = {'结构': [2, 16, 16, 8, 2], '参数': [p.data.tolist() for p in model.parameters()]}
    path.write_text(json.dumps(payload, ensure_ascii=False))
    baseline = model(Tensor(X[test], requires_grad=False)).data.copy()
    for p in model.parameters():
        p.data.fill(0)  # 先改变参数，确保恢复真的生效。
    for p, value in zip(model.parameters(), json.loads(path.read_text())['参数']):
        arr = np.asarray(value)
        assert arr.shape == p.data.shape
        p.data[...] = arr
    restored = model(Tensor(X[test], requires_grad=False)).data
    assert np.array_equal(restored, baseline)
print('批量Adam步数', optimizer.steps, '测试准确率', round(float(accuracy), 3), '参数恢复一致')
```

在本批固定环境，mini框架900次批更新的测试准确率0.988，权重被先置0再从JSON恢复、输出一致；这些结果仅属于此数据与参数。

例子不使用测试调轮数，固定种子只用于核对合成任务。JSON是教学权重恢复，不是完整续训checkpoint：续训还要保存Adam的m/v/step、学习率日程位置、数据顺序与RNG状态。SGD无动量时只做`p.data -= lr*p.grad`；加动量、AdamW与调度改变状态语义，应按对应优化器实现。

普通单批训练的必要顺序是前向先于损失、损失先于反向、反向先于step，并在本批反向前清掉不需要的旧梯度。zero_grad既可放在forward前，也可放在loss后但backward前；原quiz把后一顺序也列作错误，不是正确的唯一顺序判断。需要微批累加时则只在整个有效批开始清零。

梯度累加是为了一个有效批更新可分多个微批；大小相等时每份均值损失除累加次数，大小不等时按该份样本数/总样本数加权。最后不足累加次数的组也必须step，不能直接丢弃。带BatchNorm/Dropout的微批并不与一次大批完全相同，即使平均梯度计算正确。

## 4. 训练与推理模式：Dropout和BatchNorm不能照抄错误简化

Inverted dropout训练时以概率p置零，保留值除以1-p；推理为恒等。数学期望 $E[mx/(1-p)]=x$ 不代表每一批恰好删掉固定比例。原动画取确定个数隐藏只为示意；真实mask是随机采样，p接近1时尺度不稳，p=1须有专门定义。

BatchNorm训练按同特征跨批统计，$\hat x=(x-\mu_B)/\sqrt{v_B+\epsilon}$，输出 $y=\gamma\hat x+\beta$。归一化后的方差为 $v_B/(v_B+\epsilon)$ 而非严格1，再仿射后的均值/方差也不必0/1。PyTorch默认eval使用running统计；`track_running_stats=False`仍用当批统计。前向批方差用有偏估计，更新running_var用无偏估计，两者不能随意混同。

对每列、批大小B、上游g，完整训练VJP是：

$$
dx=\frac{\gamma}{B\sqrt{v_B+\epsilon}}
\left[B g-\sum_{batch}g-\hat x\sum_{batch}(g\hat x)\right],\quad
d\gamma=\sum g\hat x,\quad d\beta=\sum g.
$$

只算 $g\gamma/\sqrt{v_B+\epsilon}$ 忽略了均值/方差对输入依赖，只在统计固定的推理情境才有相应简单项。原mini源码的单样本forward依赖运行均值、running_var未按同一算法更新，正文版本又按单样本批统计；两者都不能称正确批BN。单个有效值的BN训练并非“必NaN”，PyTorch某些输入会直接拒绝；应换合理批/归一化，不用加epsilon掩盖设计。

完整NumPy批BN/VJP与中央差分核对，教学处理矩阵(B,D)，不包含running统计；真实训练仍使用库实现。

```python
import numpy as np
rng = np.random.default_rng(7)
x = rng.normal(size=(4, 3))
g = rng.normal(size=x.shape)
gamma, beta = rng.normal(size=3), rng.normal(size=3)
eps = 1e-5

def bn(x):
    centered = x-x.mean(axis=0)
    normalized = centered/np.sqrt(x.var(axis=0)+eps)
    return normalized*gamma+beta, normalized

y, normalized = bn(x)
dx = gamma/np.sqrt(x.var(axis=0)+eps) * (
    g-g.mean(axis=0)-normalized*(g*normalized).mean(axis=0))
numeric = np.empty_like(x)
h = 1e-5
for index in np.ndindex(x.shape):
    plus, minus = x.copy(), x.copy()
    plus[index] += h; minus[index] -= h
    numeric[index] = ((bn(plus)[0]*g).sum()-(bn(minus)[0]*g).sum())/(2*h)
assert np.allclose(dx, numeric, rtol=1e-6, atol=1e-7)
print('BN完整VJP最大绝对误差', np.max(np.abs(dx-numeric)))
```

## 5. PyTorch：张量、登记、损失与数据的契约

先核对`shape/dtype/device/requires_grad`。整型索引用于Embedding或类别索引，浮点用于多数连续运算；把float转int8只是数值转换，不是完整量化。张量有无计算图取决于梯度模式、输入和操作，不能说每个操作都无条件记录。

`nn.Linear(in,out)`权重`(out,in)`、偏置`(out,)`。赋给属性的Parameter/子Module会登记；普通Tensor属性不会自动成为训练参数，需`nn.Parameter`或`register_buffer`区分参数/状态。多个层装普通Python列表不会像`nn.ModuleList`一样登记；否则`parameters()`、`.to()`、`state_dict()`可能遗漏。共享参数只应更新一次，核对对象身份和命名。

Leaf的`.grad`默认累加，未被损失使用的参数可能为None；非叶子通常不保留`.grad`，可显式`retain_grad()`用于诊断。`zero_grad(set_to_none=True)`与填0的优化器语义可能不同：某些优化器对None跳过，而对0仍可能动量/衰减更新。`loss.backward()`计算梯度，`optimizer.step()`才更新，二者分工明确。

| 任务 | 模型输出 | 目标与损失 | 关键检查 |
|---|---|---|---|
| 多类分类 | `(B,C)`原始logits | `(B,)`long类别索引，CrossEntropyLoss | 不预先softmax；索引范围合法 |
| 二分类 | `(B,1)`原始logits | 同形float 0/1，BCEWithLogitsLoss | 不预先sigmoid；阈值logit0等于概率.5 |
| 回归 | 与目标匹配形状 | float，MSE/L1等 | `(B,1)`对`(B,)`可能广播出错误矩阵 |
| 序列对齐 | 指定顺序log-probabilities | CTC相应长度/标签 | 与一般分类轴和时间长度不同 |

CrossEntropy也支持概率目标的特定接口，但那是另一个目标契约，不能统一写成“任何float标签都错”。softmax用在概率展示，不能用于替代正确训练logits。CTC接口在对应序列课详解，不在此生成未经运行的大任务。

Dataset决定一条样本，DataLoader决定合批、重排与加载；也有IterableDataset，不能声称都必须`__len__/__getitem__`。map-style自定义数据检查索引、输入标签对齐和可重复预处理。只shuffle训练，数据切分须按任务时间/实体边界；不是“shuffle再split本身一定泄漏”。普通随机IID任务随机打乱可以合理，统计预处理和重复实体才要进一步审计。

设备先迁移模型再创建优化器、每批迁移输入/标签；CPU、CUDA、MPS各有支持范围。许多同一运算要求兼容设备，但具体操作有例外，不套所有API“一律每张量同设备”。本批强制CPU，不代表GPU验证。`num_workers/pin_memory/persistent_workers`按平台、I/O与资源测量，内存小数据num_workers=0常适合起步；persistent_workers需正workers，CUDA页锁定收益不能照搬到所有设备。

### 5.1 二进制样本格式也要校验

原课手读MNIST的IDX文件有可复用知识：gzip是压缩容器；解压后大端32位头，图像magic=2051、随后n/rows/cols，标签magic=2049、随后n；像素/标签为uint8。原代码读取magic却未核对、标签长度未核对，不应把文件名正确当数据正确。以下完整程序只生成两条微型格式夹具，验证解析、大小与dtype，不下载MNIST，不代表手写数字训练验收。

```python
import gzip
import struct
import numpy as np
import torch

def parse_images(blob):
    raw = gzip.decompress(blob)
    if len(raw) < 16:
        raise ValueError('图像头不完整')
    magic, n, rows, cols = struct.unpack('>IIII', raw[:16])
    if magic != 2051 or min(n, rows, cols) <= 0 or len(raw)-16 != n*rows*cols:
        raise ValueError('图像magic/维度/字节数不匹配')
    pixels = np.frombuffer(raw, dtype=np.uint8, offset=16).copy().reshape(n, rows*cols)
    return torch.from_numpy(pixels).float()/255.

def parse_labels(blob):
    raw = gzip.decompress(blob)
    if len(raw) < 8:
        raise ValueError('标签头不完整')
    magic, n = struct.unpack('>II', raw[:8])
    if magic != 2049 or n <= 0 or len(raw)-8 != n:
        raise ValueError('标签magic/字节数不匹配')
    return torch.from_numpy(np.frombuffer(raw, dtype=np.uint8, offset=8).copy()).long()

image_blob = gzip.compress(struct.pack('>IIII', 2051, 2, 2, 2)+bytes([0, 255, 128, 64, 255, 0, 64, 128]))
label_blob = gzip.compress(struct.pack('>II', 2049, 2)+bytes([1, 0]))
images, labels = parse_images(image_blob), parse_labels(label_blob)
assert images.shape == (2, 4) and labels.tolist() == [1, 0]
assert images.dtype == torch.float32 and labels.dtype == torch.long
bad = gzip.compress(struct.pack('>II', 2049, 2)+bytes([1]))
try:
    parse_labels(bad)
except ValueError:
    print('IDX小夹具解析和损坏长度拒绝均通过')
else:
    raise AssertionError('未拒绝截断标签')
```

像素除255映到[0,1]，不等于均值0/标准差1。目标索引范围与输入/标签总数仍须在Dataset构建时核查，数据内容是否与标注一致需样本检查。

## 6. 可运行PyTorch闭环与参数恢复

完整CPU合成圆形数据：自定义Dataset、真小批、CrossEntropy、AdamW、验证选checkpoint、独立测试、state_dict保存/恢复。程序仅在临时目录写权重，不下载数据。

```python
import copy
import tempfile
from pathlib import Path
import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader

torch.set_num_threads(1)
torch.manual_seed(7)
device = torch.device('cpu')
X = torch.rand(360, 2)*4-2
y = (X.square().sum(dim=1) < 1.5).long()

class CircleDataset(Dataset):
    def __init__(self, X, y):
        assert len(X) == len(y)
        self.X, self.y = X, y
    def __len__(self):
        return len(self.y)
    def __getitem__(self, i):
        return self.X[i], self.y[i]

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(nn.Linear(2, 24), nn.ReLU(), nn.Dropout(.1), nn.Linear(24, 2))
    def forward(self, x):
        return self.layers(x)

model = MLP().to(device)
optimizer = torch.optim.AdamW(model.parameters(), lr=.01, weight_decay=1e-3)
criterion = nn.CrossEntropyLoss()
generator = torch.Generator().manual_seed(17)
loader = DataLoader(CircleDataset(X[:260], y[:260]), batch_size=32, shuffle=True,
                    generator=generator, num_workers=0)
Xval, yval = X[260:310].to(device), y[260:310].to(device)
Xtest, ytest = X[310:].to(device), y[310:].to(device)
best_loss, best = float('inf'), None
for epoch in range(70):
    model.train()
    total_loss, total = 0., 0
    for xb, yb in loader:
        xb, yb = xb.to(device), yb.to(device)
        optimizer.zero_grad(set_to_none=True)
        logits = model(xb)
        assert logits.shape == (len(yb), 2) and yb.dtype == torch.long
        loss = criterion(logits, yb)
        if not torch.isfinite(loss):
            raise RuntimeError('首次非有限损失，停止检查现场')
        loss.backward()
        optimizer.step()
        total_loss += loss.item()*len(yb)
        total += len(yb)
    model.eval()
    with torch.no_grad():
        validation_loss = criterion(model(Xval), yval).item()
    if validation_loss < best_loss:
        best_loss = validation_loss
        best = {'epoch': epoch, 'model': copy.deepcopy(model.state_dict()),
                'optimizer': copy.deepcopy(optimizer.state_dict()),
                'rng': torch.get_rng_state().clone(), 'loader_rng': generator.get_state().clone(),
                'config': {'输入': 2, '隐藏': 24, '类别': 2, '数据': '固定种子合成圆形'}}
model.load_state_dict(best['model'])
model.eval()
with torch.inference_mode():
    baseline = model(Xtest).clone()
    accuracy = (baseline.argmax(dim=1) == ytest).float().mean().item()
assert accuracy > .85
with tempfile.TemporaryDirectory() as directory:
    path = Path(directory)/'checkpoint.pt'
    torch.save(best, path)
    checkpoint = torch.load(path, map_location='cpu', weights_only=True)
    restored = MLP().to(device)
    restored.load_state_dict(checkpoint['model'])
    restored.eval()
    with torch.inference_mode():
        assert torch.equal(restored(Xtest), baseline)
print('CPU测试准确率', round(accuracy, 3), '选中epoch', best['epoch'], '参数恢复一致')
```

本批固定CPU实验测试准确率0.960、选中epoch为69，恢复到新Module后的输出逐位一致。不要把这一准确率当MNIST/真实任务结论。

state_dict不只含参数，还可含持久buffer；模型结构/字段意义由代码和配置提供。正在训练的`state_dict()`引用内容会随后变化，保存“最佳”状态需deepcopy或立即序列化。续训恢复matching模型、优化器、调度位置与RNG/采样状态，再开始下一阶段；仅恢复权重用于推理不等于续训复现。

`weights_only=True`限制反序列化范围，但不能因此信任任意外部文件；只加载任务中可信checkpoint。架构不匹配要处理键和形状，不能一律`strict=False`掩盖缺层。改变设备需确认优化器状态迁移与支持，CPU恢复检验不代表所有设备输出逐位相同。

## 7. 梯度累加、调度、AMP与性能的边界

正确微批累加例子见第12节的值级核对：最后不整除的组仍要更新，按真实样本量缩放。OneCycle等调度按训练step、CosineAnnealing示例可按epoch、ReduceLROnPlateau需要验证指标；没有所有任务最佳日程。通常优化器更新后再推进相应scheduler，记录当前lr和global step，避免配置声称批调度而实际每epoch只调用一次。

AMP是在算子层选择适当精度，不是所有前向/反向全改float16或全部内存减半。CUDA float16常用GradScaler：scaled backward后先`unscale_(optimizer)`，再检查/裁剪真实梯度，之后`scaler.step/update`。有效大批的全部微批使用一致scale，完成累加才unscale/step/update；否则梯度尺度混乱。BF16、CPU与MPS支持/收益需按版本/设备核查，不写死速度倍数。

本批未执行CUDA AMP。下面是**需要CUDA、只官方核验的可选流程片段**，它依赖用户提供的model/optimizer/xb/yb/criterion；不是本章独立CPU程序，也不计入实跑数。

```python
# 需CUDA和已定义的model/optimizer/xb/yb/criterion；非独立程序。
import torch
scaler = torch.amp.GradScaler('cuda')
optimizer.zero_grad(set_to_none=True)
with torch.amp.autocast(device_type='cuda', dtype=torch.float16):
    loss = criterion(model(xb), yb)
scaler.scale(loss).backward()
scaler.unscale_(optimizer)
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1., error_if_nonfinite=True)
scaler.step(optimizer)
scaler.update()
```

benchmark分开数据读取/搬运/计算/编译，GPU异步操作用设备同步或事件，不能只量CPU提交时间。固定数据、模型、精度、线程、批量、预热与正确性，再比较。原站“500倍”“半秒一轮”“BN必到98%”没有当前环境测量，删除效果保证。PyTorch也有`torch.compile`与`torch.func`，不能把它固定描述为只有不可编译逐操作Python循环。

## 8. JAX：把状态变成输入输出

JAX核心是可组合变换：`grad`对标量函数求导，`value_and_grad`一起返回值和梯度，`jit`编译，`vmap`映射批轴。它也可以不jit逐步执行，数组可在CPU；PyTorch也可函数式和编译。两者在本章的具体不同是“常用Module内状态与grad累加”对“显式参数/优化状态树返回”，不是谁天生只能一种执行方式。

写成 `new_params,new_state,new_key,metrics = step(params,state,key,batch)`，保存所有变化的值。Pytrees是登记过的树状结构：常见list/tuple/dict和数组叶子，任意自定义类需相应支持。用参数叶子**大小总和**数参数，但不能用叶子数量猜网络深度；一层可能有权重/偏置/其他状态，网络顺序应显式层列表或结构配置。

函数变换不能靠可变全局变量控制训练。全局值可能在trace时被捕获，之后修改未必触发重编译；把学习率、参数、统计和随机key当参数。纯函数并不禁止Python类包装，Flax/Equinox提供这样的组织方式，关键是变换能理解的显式状态。BatchNorm运行统计是独立状态，dropout随机性是key，不混为可训练参数。

JAX数组不可按原地赋值使用，`new = old.at[i].set(value)`返回新值，旧值不变；编译器在允许时可优化物理存储，不要从用户不可变语义推断每次必复制。默认精度配置与NumPy不同，float64要显式确认x64配置；比较差分误差不能悄悄用float32替代double。

### 8.1 层库补上组织方式，但不隐藏状态边界

Flax的Linen接口中，`variables = model.init(key, example_inputs)`生成变量集合；`model.apply(variables, inputs)`执行。`variables`不等于裸权重：可能有`params`和`batch_stats`等集合。训练要更新BN统计时，显式指定允许修改的集合并接收返回的新状态；dropout通过`rngs`传key。不能只把更新后的参数保存、继续用旧统计。这里讲Linen命名空间，不把其接口泛化成所有Flax版本的唯一用法。

Equinox将模型表示成可调用pytree，MLP通常接一条`(in_features,)`向量；批量可`jax.vmap(model)`，输出相应batch维。参数/状态可包含不应求导的静态或非数组字段，需用其筛选变换或显式抽出可训练数组；不能把每个叶都送进数值优化器。这两个库提供层组织，Optax提供梯度变换，checkpoint库管理保存恢复，职责仍和第1节一致。本批官方核验这些接口，但没有安装运行其完整训练工程。

## 9. 完整JAX函数式训练、jit与vmap

以下独立CPU合成程序用显式层tuple与momentum状态，演示真实训练、按样本梯度和与批量梯度的核对；不依赖Optax或下载MNIST。Optax的规范职责是`init(params)`创建状态，`update(grads,state,params)`产出updates/新状态，`apply_updates`应用；组合顺序会改变算法，例如先向gradient加衰减再Adam与AdamW解耦衰减不同，LAMB也不是Hessian二阶优化器。

```python
import numpy as np
import jax
import jax.numpy as jnp

rng = np.random.default_rng(7)
X = rng.uniform(-2, 2, (360, 2)).astype(np.float32)
y = (np.sum(X**2, axis=1) < 1.5).astype(np.int32)
Xj, yj = jnp.asarray(X), jnp.asarray(y)
key = jax.random.key(7)
key, init_key = jax.random.split(key)
sizes = [2, 24, 2]
keys = jax.random.split(init_key, len(sizes)-1)
params = tuple({'w': jax.random.normal(k, (nin, nout))*jnp.sqrt(2/nin),
                'b': jnp.zeros(nout)}
               for k, nin, nout in zip(keys, sizes[:-1], sizes[1:]))
velocity = jax.tree.map(jnp.zeros_like, params)

def forward(params, x):
    for i, layer in enumerate(params):  # 长度静态的小循环允许trace。
        x = x@layer['w'] + layer['b']
        if i < len(params)-1:
            x = jax.nn.relu(x)
    return x

def loss_fn(params, x, y):
    logits = forward(params, x)
    logp = jax.nn.log_softmax(logits, axis=-1)
    return -jnp.mean(logp[jnp.arange(len(y)), y])

@jax.jit
def step(params, velocity, x, y, lr):
    value, grads = jax.value_and_grad(loss_fn)(params, x, y)
    velocity = jax.tree.map(lambda v, g: .9*v+g, velocity, grads)
    params = jax.tree.map(lambda p, v: p-lr*v, params, velocity)
    return params, velocity, value

best, best_loss = None, float('inf')
for epoch in range(70):
    key, shuffle_key = jax.random.split(key)
    order = np.asarray(jax.random.permutation(shuffle_key, 260))
    for start in range(0, 260, 32):
        ids = order[start:start+32]
        params, velocity, value = step(params, velocity, Xj[ids], yj[ids], .03)
    validation = float(loss_fn(params, Xj[260:310], yj[260:310]))
    if validation < best_loss:
        best_loss = validation
        best = params  # 不可变数组，后续update返回新树。
params = best
accuracy = float(jnp.mean(jnp.argmax(forward(params, Xj[310:]), axis=-1) == yj[310:]))
assert accuracy > .85

def single_loss(params, x, y):
    logp = jax.nn.log_softmax(forward(params, x), axis=-1)
    return -logp[y]
per_example = jax.vmap(jax.grad(single_loss), in_axes=(None, 0, 0))(params, Xj[:8], yj[:8])
batch = jax.grad(loss_fn)(params, Xj[:8], yj[:8])
for individual, average in zip(jax.tree.leaves(per_example), jax.tree.leaves(batch)):
    assert np.allclose(np.asarray(individual.mean(axis=0)), np.asarray(average), rtol=1e-4, atol=1e-5)
norm_squared = sum(jnp.sum(g.reshape(8, -1)**2, axis=1) for g in jax.tree.leaves(per_example))
print('JAX CPU测试准确率', round(accuracy, 3), '逐样本梯度范数', np.asarray(jnp.sqrt(norm_squared)).round(3))
```

本批JAX CPU合成测试准确率0.960；逐样本梯度均值与批梯度在程序容差内一致。相同百分比不证明与上节模型优劣相同，因为数据生成器、架构/优化与训练路径并不完全一致。

高梯度样本可能是难例、错标或当前模型误差大，不能直接判其错标/该删。`vmap`的`in_axes=(None,0,0)`让参数共享、映射数据与目标第0轴；输出为每叶多一个batch轴。`grad(mean loss)`通常等于每样本grad均值，交互损失/BatchNorm等跨样本计算下不能机械套用。

`vmap`表达向量化，`jit`可以再优化，不保证单一kernel或固定10～100倍。JAX/torch.func都支持逐样本梯度，不能把后者叫“近乎不可能”。把复杂控制、动态形状或巨大编译图叠上去可能得不偿失。

## 10. 随机key、控制流、异步与存储

同key同调用生成同随机值；需要新的随机性时split或fold_in，传回未消费的主key。重用key有时有意用于复现实验，但不能无意识让每批dropout同mask。明确key只是可复现输入的一部分，软件/算法/硬件/并行变化仍不保证逐位一致。旧`PRNGKey`仍有使用场景，此处采用当前typed `random.key`。

```python
import numpy as np
import jax
import jax.numpy as jnp

key = jax.random.key(7)
key, k1, k2 = jax.random.split(key, 3)
x = jnp.ones((1000,))
def dropout(x, key, p=.25):
    keep = jax.random.bernoulli(key, 1-p, x.shape)
    return jnp.where(keep, x/(1-p), 0)
a, repeated, b = dropout(x, k1), dropout(x, k1), dropout(x, k2)
assert np.array_equal(np.asarray(a), np.asarray(repeated))
assert not np.array_equal(np.asarray(a), np.asarray(b))
old = jnp.array([1., 2.]); new = old.at[0].set(9.)
assert np.array_equal(np.asarray(old), [1, 2]) and np.array_equal(np.asarray(new), [9, 2])
f = jax.jit(lambda value: jax.lax.cond(value > 0, lambda v: v*v, lambda v: -v, value))
assert float(f(jnp.array(-2.))) == 2
print('dropout均值示例', round(float(a.mean()), 3), '分支与不可变更新通过')
```

Python `if traced_array>0`一般不能在jit时求布尔值，用`lax.cond`/适合的`where`等。静态迭代次数Python循环可以被展开，但大循环扩大编译图；可用`lax.scan/fori_loop`保留结构，动态返回长度要改固定形状/mask。分支两边的类型与结构需一致；`where`不是避免所有非法未选分支计算的通用护栏，尤其对NaN梯度要核验。

普通print通常在trace时发生，不是每次编译执行；`jax.debug.print`显示运行值，`jax.debug.breakpoint`可进入调试但自动任务中不要无条件等待人工。`jax.disable_jit()`帮助缩小问题；`checkify`与NaN调试选项提供可组合检查，不能理解为自动捕获全部错误。

jit缓存与函数、输入形状/dtype、静态参数等有关。最后短batch可能触发另一次编译；用固定shape或padding时也要把mask和loss样本权重处理正确，不因为编译便利悄悄丢样本。CPU和GPU计时都应确认异步是否完成，以下完整微基准同步两边并分开首调；没有固定答案，不能拿它证明普遍加速。

```python
import time
import numpy as np
import jax
import jax.numpy as jnp

x = jnp.arange(128., dtype=jnp.float32)
def fn(x):
    return jnp.tanh(x*.01).sum()
compiled = jax.jit(fn)
start = time.perf_counter()
first = compiled(x).block_until_ready()
first_seconds = time.perf_counter()-start
fn(x).block_until_ready()  # 预热非jit路径。

def measure(f, repetitions=30):
    start = time.perf_counter()
    for _ in range(repetitions):
        result = f(x)
        result.block_until_ready()
    return (time.perf_counter()-start)/repetitions
assert np.allclose(np.asarray(first), np.asarray(fn(x)), atol=1e-5)
print('首调含编译秒', first_seconds, '非jit每次秒', measure(fn), '热jit每次秒', measure(compiled))
```

参数之外还要checkpoint optimizer state、统计状态、key、global step、调度/数据版本。简单数组可转NumPy加结构配置保存，复杂分片/异步checkpoint用当前库规范并核验恢复；旧Orbax固定类名/安装命令不直接固化。多设备并不是包一层函数就完工：需要数据分片、设备mesh、通信/平均梯度、状态和恢复策略。当前官方把`pmap`标为旧方式、推荐`shard_map`；保留SPMD/pmean思想，但不为仅CPU学习加入未经验证的TPU集群程序。

## 11. 从症状到证据，不把启发式写成诊断结论

先检查数据与任务契约，再检查loss是否依赖输出、参数是否被优化器登记、梯度与实际更新，之后才试学习率/正则/容量。固定训练曲线不包含数据合法性的保证。数据切分/泄漏详见[机器学习评估](../机器学习专题/07-评估指标验证与不平衡学习.md)，不在框架章重复生成一套审查规则。

| 现象 | 收集的证据 | 可检验的候选解释 |
|---|---|---|
| loss不降 | 同批输入/标签/输出、grad与参数step前后差 | 图截断、冻结/未登记、lr、表示不足、尺度或目标错误 |
| 训练降、验证不降 | 同评价口径、样本/群体/时间、eval模式 | 泛化、分布差异、预处理、评估模式、容量；不是一条曲线证明过拟合 |
| NaN/Inf | 首次非有限的输入/激活/loss/grad/更新 | 定义域、溢出、坏数据、混合精度、lr；不是先给所有式子加epsilon |
| 激活很多0 | 按单元跨多批/样本的活跃率、预激活、grad | ReLU负区、数据覆盖、初始化；50%零值可很正常 |
| 某层grad很小/大 | 层数/参数规模、grad范数、相对更新 | 饱和、链式缩放、损失尺度、正常收敛；不是固定阈值万能 |
| OOM/变慢 | 峰值阶段、活引用、输入长度、同步/数据等待 | graph保留、batch/序列、中间/优化器状态、I/O；不是先清cache就能修 |

本批运行原站标为HEALTHY的网络时，其工具仍把一批52% ReLU零值报成DEAD_NEURONS；这是固定阈值产生误导的具体反例，不是该网络全部健康的证明。

“死亡ReLU”指某单元在相关数据范围长时间都不激活，且有效梯度/更新无法让它恢复；一次批输出一半0不够证明。其他上游参数或输入改变后，当前负区单元也可能恢复。重初始化是会改变模型的实验，应在候选副本评估，并重置对应优化状态，不能生产中静默“复活”。

激活均值0/标准差1常来自特定归一化，不是所有层的健康要求：ReLU输出非负、logits可有大偏置、残差尺度也不同。梯度均值可能正负抵消；看RMS/范数、有限率和相对更新，按层执行/依赖顺序分析，不能按backward hook写入字典的顺序当输入层到输出层。若明确早层grad/晚层grad非常小才可能提示消失；原脚本反用“大于100”与字典顺序，判断有误。

## 12. 可运行的失败、梯度检查与累加核对

下面完整CPU程序包含三项可证伪检查：detach后参数无梯度/无更新，修复后更新；float64光滑函数gradcheck；不等微批的加权平均梯度与整批一致。梯度检查不修改真实训练模型dtype、不强制分类标签变double，避免原脚本污染训练状态。

```python
import copy
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(7)
X = torch.tensor([[1., 2.], [3., 4.], [-1., 2.], [2., -1.], [0., 1.]])
y = 2*X[:, :1]-.5*X[:, 1:]+1
model = nn.Linear(2, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=.01)
criterion = nn.MSELoss()
before = {name: p.detach().clone() for name, p in model.named_parameters()}
optimizer.zero_grad(set_to_none=True)
bad_output = model(X).detach().requires_grad_()
criterion(bad_output, y).backward()
assert all(p.grad is None for p in model.parameters())
optimizer.step()
assert all(torch.equal(p, before[name]) for name, p in model.named_parameters())
optimizer.zero_grad(set_to_none=True)
criterion(model(X), y).backward()
assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in model.parameters())
optimizer.step()
assert any(not torch.equal(p, before[name]) for name, p in model.named_parameters())

x = torch.randn(3, 2, dtype=torch.double, requires_grad=True)
w = torch.randn(2, 2, dtype=torch.double, requires_grad=True)
b = torch.randn(2, dtype=torch.double, requires_grad=True)
def smooth_loss(x, w, b):
    return (torch.tanh(x@w+b)**2).mean()
assert torch.autograd.gradcheck(smooth_loss, (x, w, b), eps=1e-6, atol=1e-5, rtol=1e-3)

full, micro = copy.deepcopy(model), copy.deepcopy(model)
full.zero_grad(set_to_none=True)
criterion(full(X), y).backward()
micro.zero_grad(set_to_none=True)
for start, stop in [(0, 2), (2, 5)]:
    loss = criterion(micro(X[start:stop]), y[start:stop])
    (loss*((stop-start)/len(X))).backward()
for fp, mp in zip(full.parameters(), micro.parameters()):
    assert torch.allclose(fp.grad, mp.grad, atol=1e-5, rtol=1e-5)
print('detach失败被捕获、修复有更新、gradcheck与不等微批梯度核对通过')
```

本批对矩阵权重/偏置、三维广播、多轴归约种子VJP和极端logits交叉熵做了与PyTorch double的额外数值对照，梯度在1e-10～1e-12级容差内一致；BN VJP中央差分最大绝对误差约1.50e-10。范围只覆盖所列操作/小输入。

有效梯度为0不自动错误，可能到驻点、数据在ReLU负区、该分支对当前输入局部无影响；grad=None则检查冻结/未用/截断与zero_grad语义。有限差分在随机dropout、BatchNorm运行状态、非光滑点或共享expand内存处可能误报。应复制模型、关随机/冻结合适状态、用double、扫步长并结合绝对误差，不能凭固定相对误差阈值一票判错。

全局范数裁剪 $g\leftarrow g\min(1,\tau/\|g\|)$ 保持方向，但限的是梯度，不保证Adam预条件/动量后的实际参数更新范数。数值Inf/NaN不能靠裁剪恢复为正确值。原图的“最终norm=min(raw,cap)”是有限梯度理想计算；阈值依赖损失、规模和优化状态，不自动从一次爆炸读出万能值。

## 13. 小批过拟合、LR range test与诊断副作用

在可表达、标签不冲突的小样本关闭随机增强/强正则，用明确损失与合理优化尝试记住样本。通过只证明这个闭环能拟合这一批，不证明泛化/数据全库正确；没通过也可能容量、冲突标签、正则或优化不足，不能等同“必有代码bug”。同一个输入配互斥标签时，不可能同时100%拟合，先核对这个必要条件。

完整CPU小样本实验与hook监测：hook只保存脱离图的标量摘要，按名称记录，不保存整图；用try/finally移除。这里模块输出是张量，真实tuple/dict输出要递归遍历，空/复数/整数按类型处理。

```python
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(7)
X = torch.randn(12, 4)
y = (X[:, 0] > 0).long()
model = nn.Sequential(nn.Linear(4, 24), nn.Tanh(), nn.Linear(24, 2))
optimizer = torch.optim.Adam(model.parameters(), lr=.03)
criterion = nn.CrossEntropyLoss()
activation, handles = {}, []
def make_hook(name):
    def hook(module, inputs, output):
        if not isinstance(output, torch.Tensor) or not output.numel():
            return
        with torch.no_grad():
            value = output.detach().float()
            activation[name] = {'shape': tuple(value.shape), 'finite': bool(torch.isfinite(value).all()),
                                'mean': value.mean().item(), 'std': value.std(correction=0).item(),
                                'zero_fraction': (value == 0).float().mean().item()}
    return hook
for name, module in model.named_modules():
    if isinstance(module, (nn.Linear, nn.Tanh)):
        handles.append(module.register_forward_hook(make_hook(name)))
try:
    for step in range(150):
        optimizer.zero_grad(set_to_none=True)
        loss = criterion(model(X), y)
        if not torch.isfinite(loss):
            raise RuntimeError('小批训练出现非有限损失')
        loss.backward()
        optimizer.step()
    model.eval()
    with torch.no_grad():
        final_loss = criterion(model(X), y).item()
        accuracy = (model(X).argmax(dim=1) == y).float().mean().item()
    assert accuracy == 1. and final_loss < .03
    assert all(v['finite'] for v in activation.values())
    print('小批准确率', accuracy, '损失', round(final_loss, 6), '激活摘要数', len(activation))
finally:
    for handle in handles:
        handle.remove()
```

LR range test从小到大扫学习率记录loss，只提出候选，不给唯一最优lr；应重建候选/恢复模型、优化器、随机与运行统计和模式，扫时模型状态不断变化也会影响曲线。原示例只恢复权重/部分状态，缺少完整训练上下文；不要把扫完的优化器直接继续正式训练。若loss非有限或超过预定保护上限就停止，保存现场与已完成步数，而非让大任务跑完。

下面完整CPU range test在副本上训练，保存CSV到临时目录、核对原参数和模式未改变；它给出可核对的记录，不自动推导最优lr。

```python
import copy
import csv
import tempfile
from pathlib import Path
import torch
from torch import nn

torch.set_num_threads(1)
torch.manual_seed(7)
X = torch.randn(32, 4)
y = (X[:, 0] > 0).long()
base = nn.Sequential(nn.Linear(4, 8), nn.Tanh(), nn.Linear(8, 2)).eval()
before = copy.deepcopy(base.state_dict())

def lr_sweep(base, X, y, low=1e-5, high=2., steps=35):
    candidate = copy.deepcopy(base).train()
    optimizer = torch.optim.SGD(candidate.parameters(), lr=low)
    criterion = nn.CrossEntropyLoss()
    records, best = [], float('inf')
    with torch.random.fork_rng(devices=[]):
        for step in range(steps):
            lr = low*(high/low)**(step/(steps-1))
            optimizer.param_groups[0]['lr'] = lr
            optimizer.zero_grad(set_to_none=True)
            loss = criterion(candidate(X), y)
            value = loss.item()
            if not torch.isfinite(loss) or value > 10*best:
                break  # 此保护倍数是本例预定停止规则，不是最优lr定理。
            loss.backward()
            grad_rms = torch.sqrt(sum(p.grad.square().sum() for p in candidate.parameters()) /
                                  sum(p.numel() for p in candidate.parameters())).item()
            records.append({'step': step, 'lr': lr, 'loss': value, 'grad_rms': grad_rms})
            best = min(best, value)
            optimizer.step()
    return records

records = lr_sweep(base, X, y)
assert len(records) > 5 and not base.training
assert all(torch.equal(base.state_dict()[name], value) for name, value in before.items())
with tempfile.TemporaryDirectory() as directory:
    path = Path(directory)/'学习率扫描.csv'
    with path.open('w', newline='') as stream:
        writer = csv.DictWriter(stream, fieldnames=['step', 'lr', 'loss', 'grad_rms'])
        writer.writeheader(); writer.writerows(records)
    with path.open(newline='') as stream:
        assert len(list(csv.DictReader(stream))) == len(records)
print('LR扫描记录数', len(records), '原参数/模式不变，CSV往返通过')
```

可记录CSV/JSON中的step、lr、loss、grad/RMS、参数更新，绘图只帮助判断。原learning-curves动画用手工函数让train下降/validation U形，并把模型容量与epoch共用一轴；它不是测得真实训练规律，不应推导所有验证曲线必U形或容量增大必泛化变差。真实训练早停以独立验证的模型checkpoint为准，选择容量是另一实验。

## 14. NaN、内存、profiler与可持续排错

第一次非有限输入→层输出→loss→grad→step后的参数，逐层定位，检查log/除法/平方根/指数定义域和dtype。`log(x+eps)`对足够负x依旧非法，epsilon改变表达式；优先使用稳定logits损失、合法输入和明确语义。`detect_anomaly`主要辅助backward问题定位，有开销，不是对全部forward Inf做完整保证。

保存`loss`张量/未detach激活到长期列表，可能持有图；保存需要的标量或detach数值。`retain_graph=True`可能确有多次反向用途，但长循环默认使用会增加内存；不要在需要梯度路径的位置随便detach。CPU RSS、tracemalloc、CUDA allocated/reserved不同，入口说明见[通用调试](../../Python/实践/02-调试日志与性能定位.md)。检查OOM发生在加载、forward、backward还是optimizer step，Adam状态可能在初次step创建，峰值不是只看参数字节。

PyTorch profiler/JAX profiler可以观察算子、设备等待、编译和通信；TensorBoard可本地记录标量/直方图，但要控制频率并flush/close。W&B是外部服务，原课上传片段不进入默认执行流程；日志去向由具体任务授权选择。本批未创建账户或上传训练日志。

性能测量关闭密集hooks/打印/异常检测，分开冷启动和热运行，核对同步与结果等价。CPU的小任务不应照着原站默认开启4workers/pin_memory或编译，任何收益都需要实际测量。出现无法解释的梯度不匹配、数据错位、非有限值或参数不更新，先停放大实验并修最小复现；在未解决原因前继续换架构不能算排错完成。

## 15. 练习、参考过程与验收边界

1. 如何给mini框架加稳定多类loss？**答案：**第2节cross_entropy已给log-sum-exp等价稳定计算与`(p-one_hot)/B` VJP；用极大logits、类别越界、均值缩放与差分核对。三类螺旋可再比较，但本批没有跑该数据，不编造分数。
2. 怎么确认批量更新真与原逐样本不同？**答案：**每批只step一次、梯度对均值loss计算；第3节9批×100epoch共900step。多个微批在权重固定时反向累加，第12节核对不等大小与整批一致；每个样本step改变了后续梯度取值点。
3. 怎样加warmup/cosine或衰减而不混算法？**答案：**明确schedule按哪种step推进，SGD/L2与Adam梯度内L2、AdamW解耦衰减区分，比较同种子/批/验证protocol。原练习“Adam weight decay就是L2”不能直接照搬。原理由优化主章维护。
4. 怎么验JSON/state_dict保存恢复？**答案：**结构/shape一致，在eval且同输入下比较输出；第3/6节已核对。续训另保存optimizer/RNG/采样/日程状态，不能把推理权重恢复叫完整续训。
5. 加BatchNorm或换SGD+momentum会必达某accuracy吗？**答案：**不会；按相同切分/预算比较验证曲线、耗时、样本数和参数，BN按正确批统计，scheduler调用频率明确；原站98%/训练秒数不是当前保证。
6. 怎样做LR finder和图？**答案：**在模型副本与新优化器上扫lr，记录step/lr/loss/finite与梯度证据，发散停止；由CSV/JSON画对数lr轴后给候选范围，再从原始完整上下文重训验证。本批未下载CIFAR-10或跑ResNet，不能给其最优lr。
7. 怎样移GPU并量AMP吞吐？**答案：**确认设备/算子支持、迁移模型与批、正确autocast/scaler/unscale/clip流程，预热后设备同步，记录samples/s、峰值内存和数值结果。本批CPU未验GPU/AMP收益。
8. 自定义Fashion-MNIST Dataset应检查什么？**答案：**正确IDX头、输入/标签数量、索引/shape/dtype、预处理和切分；第5.1节给无下载格式夹具。真实Fashion-MNIST训练尚未执行，不保留88%等效果承诺。
9. JAX dropout为什么要分key，开/关比较怎样做？**答案：**同key重复同随机调用得到同mask；每个需要独立随机的层/步split，eval绕过dropout；保持数据切分/预算与参数起点一致，别拿RNG明确当跨平台逐位保证。
10. 怎么给32个样本计算梯度范数？**答案：**把第9节vmap样本数改32，每叶保留batch轴，展平其余轴求平方和再开方；比较高范数样本输入/标签/损失，不能直接判错标或隐私保护已成立。
11. 任意深度MLP能用tree.leaves推断层数吗？**答案：**不能，显式参数层tuple按forward顺序遍历，参数叶子用来映射更新和计数；第9节已如此实现。
12. jit速度怎么公平比？**答案：**第10节两路径都预热/同步、单列首调编译；如果量训练100step，还要同批和同状态，确认输出与梯度等价。小工作负载可能无收益，不能要求预定倍数。
13. Optax clipping怎样比较？**答案：**明确链顺序，在裁剪前记录全局norm，在后记录是否超过阈值；与不裁剪同验证。目标是检验有限大梯度影响，不给NaN套阈值；本批未实跑Optax。
14. 怎样设计20层梯度异常警告？**答案：**按显式层顺序比较RMS/相对更新、训练历史和任务尺度，先确认NaN/None，不自动用100/1e-7诊断。候选裁剪阈值通过验证和训练稳定性选，未跑20层大网络。
15. ReLU“复活”能保证恢复70%死亡网络吗？**答案：**不能，先跨数据证明单元长期无活动，再在副本重新初始化并清相关优化状态，核对训练/验证是否改善；不能任意把某批零激活比例当病因。
16. 数据pipeline validator有哪些硬错与提示？**答案：**硬错是NaN/Inf、维度/标签类型/范围、错位与非法取未来；跨split重复依任务处理。类别10:1、均值非0/标准差非1本身只是任务特征，不是所有数据的失败条件。
17. 改坏一个backward该如何精确定位？**答案：**用已知小图先核对shape和同参数的解析/差分VJP，分别测输入、权重、偏置与广播；矩阵错转置可能直接shape失败，也可能尺寸碰巧相等产生静默错，第12节提供光滑真实框架检查。
18. 神经网没有异常堆栈就比传统代码特殊吗？**答案：**两类程序都能静默算错；神经网再叠加优化与统计不确定性。先建立输入/结果契约、最小可复现和证据，不根据症状单句给唯一根因。
