# 12｜深度学习为什么有效

> 主要吸收 Understanding Deep Learning 第 20 章，以及官网扩展的 Gradient Flow、NTK、NNGP、Bayesian Neural Networks、ODE/SDE 等理论资料。  
> 这里不追求“一个终极解释”，而是整理今天仍有解释力的几个互补视角。

## 1. 三个核心问题

深度学习理论长期围绕：

1. **Expressivity**：网络能表示什么？
2. **Optimization**：为什么如此非凸的模型可以训练？
3. **Generalization**：为什么高度过参数化模型没有必然过拟合？

这三个问题不能用单一理论完全回答。

## 2. 深度带来的表达效率

浅层网络在足够宽时具有通用逼近能力，但“能表示”不等于“高效表示”。

某些组合结构函数：

- 浅层网络需要指数级宽度；
- 深层网络可以通过层级复用，以更少参数表示。

因此深度的价值之一是：

> 与数据中的层级、组合结构形成归纳偏置。

## 3. 过参数化

现代网络参数数目往往远大于训练样本。

过参数化带来两面性：

### 好处

- 更容易找到低训练误差解；
- 优化空间存在更多可行路径；
- 某些局部几何更平滑。

### 风险

- 可以记住随机标签；
- 参数冗余巨大；
- 泛化不再能仅靠“参数数量”解释。

## 4. 损失曲面的几何

深网损失曲面高维、非凸，但很多直觉来自低维图形，容易误导。

需要关注：

- saddle points；
- connected minima；
- mode connectivity；
- Hessian spectrum；
- curvature；
- flat/sharp regions。

不同参数点即使离得很远，也可能表示几乎相同函数。

## 5. 平坦极小值

直觉上，参数轻微扰动后 loss 仍然较低的区域更“平坦”，通常被认为对噪声更稳健。

但 flatness 不是完全参数化不变的量，同一个函数可以通过重参数化改变表面曲率。

因此：

> “平坦 → 泛化好”是一种有用经验，但不是无条件定理。

## 6. 隐式偏置

Gradient Descent / SGD 并不会在所有零训练误差解中随机选择。

它受到：

- 初始化；
- 步长；
- batch noise；
- parameterization；
- normalization；

影响，从而形成 implicit bias。

在简单线性或可分问题中，可以严格证明优化会偏向特定范数的解；深网中这一现象仍在研究。

## 7. Gradient Flow

把离散梯度下降极限化：

[
rac{d	heta(t)}{dt}
=
-
abla_	heta
mathcal L(	heta(t))
]

这把训练过程看成连续时间动力系统。

可以分析：

- 参数轨迹；
- residual 的演化；
- prediction 的演化；
- covariance / kernel 的变化。

Gradient Flow 是连接优化、ODE 和 NTK 的重要桥梁。

## 8. Neural Tangent Kernel

模型：

[
f(x;	heta)
]

在参数 (	heta) 附近线性化：

[
f(x;	heta+Delta	heta)
approx
f(x;	heta)
+

abla_	heta f(x;	heta)^TDelta	heta
]

NTK：

[
K(x,x')
=

abla_	heta f(x;	heta)^T

abla_	heta f(x';	heta)
]

在某些无限宽极限下，训练期间 kernel 几乎不变，神经网络训练可近似为 kernel regression。

NTK 帮助解释：

- 宽网络训练动力学；
- 收敛；
- 可训练性；
- 预测随时间变化。

但它更像一个特定极限理论，不能解释所有 feature learning 现象。

## 9. NNGP

随机初始化的无限宽神经网络，在一定条件下函数分布趋向 Gaussian Process：

[
f(x)sim GP(0,K(x,x'))
]

这建立了：

```text
随机神经网络
↔ Gaussian Process
```

之间的联系。

NNGP 主要描述**初始化时的函数先验**；NTK 更关注**梯度训练动态**。

## 10. Feature Learning vs. Lazy Training

若训练时网络几乎停留在线性化区域，称为 lazy / kernel regime。

真正的深度学习优势往往还来自参数显著移动并学习新的表示，即 feature learning。

因此理论分析时必须区分：

- “网络当固定 kernel”；
- “网络主动学习 representation”。

## 11. Bayesian Neural Networks

Bayesian NN 将权重视为随机变量：

[
p(	heta|D)
propto
p(D|	heta)p(	heta)
]

理想预测：

[
p(y|x,D)
=
int p(y|x,	heta)p(	heta|D)d	heta
]

实际难点是高维后验不可直接积分。

近似路线：

- MCMC；
- variational inference；
- Bayes by Backprop；
- SWAG / MultiSWAG；
- MC Dropout；
- deep ensemble（虽非严格 Bayesian，但常用于不确定性）。

## 12. Pruning 与 Lottery Ticket

大量参数是否都必要？

### Pruning

训练后移除：

- 小权重；
- 低重要度连接；
- channel/head/block。

### Lottery Ticket Hypothesis

某些大随机网络中存在可训练的稀疏子网络；合适初始化和连接结构可能很重要。

长期启示：

> 过参数化可能帮助优化，但推理阶段并不一定需要完整参数集合。

## 13. Knowledge Distillation

Teacher 提供软目标：

[
p_T(y|x)
]

Student 学习：

- ground-truth；
- teacher distribution；
- hidden representation；
- intermediate feature。

蒸馏说明模型参数数目和“所学函数复杂度”不是一回事。

## 14. Adversarial Examples

神经网络可以在输入加入人眼几乎不可见的扰动后改变预测：

[
x' = x+delta
]

且：

[
|delta|
]

很小。

这揭示：

- 模型决策边界可能与人类感知不一致；
- 离开数据流形时模型行为难预测；
- 高测试准确率不等于鲁棒性。

## 15. ODE / SDE 视角

Residual Network：

[
h_{k+1}
=
h_k
+
f(h_k,	heta_k)
]

可看成 ODE 离散化：

[
rac{dh}{dt}
=
f(h,t,	heta)
]

SGD 的随机梯度噪声可在连续极限下与 SDE 联系。

Diffusion 模型同样可从：

- discrete Markov chain；
- SDE；
- probability flow ODE；

多个视角描述。

这使深度学习与数值分析、动力系统建立统一语言。

## 16. 深度学习理论的使用边界

面对理论结论时必须问：

1. 是否依赖无限宽？
2. 是否是线性化 regime？
3. 是否假设平方损失？
4. 是否要求数据可分？
5. 是否只对全批量 GD 成立？
6. 结论是在参数空间还是函数空间？
7. 是否能解释实际 finite-width 网络？

理论价值在于建立可检验解释，而不是给所有深网一个万能答案。
