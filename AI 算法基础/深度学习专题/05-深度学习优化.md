# 05｜深度学习优化

> 先修：反向传播和损失；梯度下降、凸性条件、Momentum/Adam推导统一在[数学优化专题](../数学与数值计算专题/07-优化方法与凸性条件.md)。第一遍掌握SGD、Momentum、AdamW和裁剪；运行[初始化、优化器与学习率实践](17-初始化优化器与学习率实践.md)后，再比较其余方法。

## 1. 优化与泛化分别评价

优化降低训练目标 $L_{train}(\theta)$，泛化关注未见数据。训练loss降低不意味着部署指标改善，轨迹平滑也不是收敛证明。比较优化器应固定数据、初始权重、模型、损失缩放、更新预算和评价模式，再给各方法合理的学习率搜索预算；还要看计算时间、状态内存与多个种子的波动。

网络通常非凸，存在鞍点、平台、病态曲率和梯度噪声。Adam并不保证越过所有平台或找到全局最优；梯度精确为0且初始动量为0时，普通SGD、Momentum和Adam都可能停住。凸性、学习率下降条件与景观参数化问题沿用数学专题，不在这里叠加另一份理论结论。

## 2. 梯度来源、batch与更新次数

全批量求训练经验目标的精确梯度；均匀随机样本/小批量在相应条件下给其无偏估计。按类重采样、样本权重和数据相关性会改变目标或估计；噪声既可能有助某些探索，也可能使后期不稳定，没有“随机一定泛化更好”。

一个epoch是遍历数据的单位，一次`optimizer.step()`才是参数更新。batch size影响估计、内存和吞吐。若梯度累积A个等大小微批量，每份平均loss除A，累积后更新一次；最后不足A个需按实际样本数归一化。BatchNorm等依赖当前微批量的层，使累积不等于真正大batch前向。

学习率随batch变化不能靠一个万能比例。线性缩放 $\eta'\approx k\eta$与平方根缩放 $\eta'\approx\sqrt{k}\eta$是不同条件下的经验/近似规则；源策略把平方根称为线性是错误。增大batch后重新核查更新数、调度时钟、有效噪声与实际指标。

## 3. 有状态优化器究竟存什么

每个参数的状态必须与同一参数对应，不能在每步新建optimizer，也不能更换参数列表顺序而沿用旧状态。`model.state_dict()`只有模型状态，继续训练通常还需optimizer、scheduler、已完成更新数和随机状态。仅加载权重后重新建Adam会丢失矩估计，属于重新开始优化，不是精确续训。

Momentum的一种约定：$v_t=\beta v_{t-1}+g_t$、$\theta_{t+1}=\theta_t-\eta v_t$；另一种EMA约定乘 $(1-\beta)$，有效尺度不同。$1/(1-\beta)$是有效记忆长度的粗直觉，不代表未归一化速度是最近10梯度的算术平均。

**经典Nesterov lookahead**先在 $\theta_t-\eta\beta v_{t-1}$计算梯度，再更新速度和参数。PyTorch的SGD/Nesterov使用其自己的缓存与改写形式，第一步、dampening和学习率变化的细节须核对；不能用不同约定的状态直接对齐并判库有错。

## 4. 自适应方法比较

以下平方、开方、除法均逐坐标；$\epsilon>0$保护分母，其位置是算法定义的一部分，不能随意挪进或挪出平方根。

| 方法 | 状态与更新方向 | 适用线索与限制 |
|---|---|---|
| SGD | $d_t=g_t$ | 状态小、容易检查；学习率与曲率/噪声敏感 |
| Momentum/Nesterov | 历史速度；Nesterov考虑lookahead | 可能减锯齿和加速，也可能过冲 |
| AdaGrad | $s_t=s_{t-1}+g_t^2$，$d_t=g_t/(\sqrt{s_t}+\epsilon)$ | 累计信息适合一些稀疏特征；累计量不减，后期可能太慢 |
| RMSProp | $s_t=\rho s_{t-1}+(1-\rho)g_t^2$，$d_t=g_t/(\sqrt{s_t}+\epsilon)$ | 忘记很早的平方梯度；不保证各坐标实际移动一样大 |
| AdaDelta | 梯度平方与更新平方的两个EMA，用RMS更新/RMS梯度调尺度 | 减少对原始梯度单位的敏感；成熟实现仍可有全局lr，非“永远不用调参” |
| Adam | 一阶、二阶矩EMA和偏置校正 | 常用起点；仍需调lr，状态成本高于纯SGD，不保证最好泛化 |
| AdamW | Adam状态+独立参数收缩 | 将衰减与自适应梯度分离；效果需验证，不是所有任务必胜 |

AdaDelta一种约定令 $G_t=\rho G_{t-1}+(1-\rho)g_t^2$，$u_t=-\sqrt{U_{t-1}+\epsilon}\,g_t/\sqrt{G_t+\epsilon}$，$U_t=\rho U_{t-1}+(1-\rho)u_t^2$，再按所用实现更新 $\theta\leftarrow\theta+\eta u_t$。比较时记录这些约定。

Adam的 $v_t$是**平方梯度第二矩**，不是中心化方差，更不是Hessian对角线。完整公式见数学专题。对常数梯度，从0初始化的矩经偏置校正后首步分别为 $g,g^2$；非零坐标首步变化约为 $\eta\operatorname{sign}(g)$。

### 4.1 “有效学习率”与实际参数变化不要混叫

标量学习率是 $\eta$，Adam坐标缩放系数可写 $\eta/(\sqrt{\hat v_i}+\epsilon)$，实际梯度更新是该系数乘 $\hat m_i$。源码练习把 $\eta\hat m_i/(\sqrt{\hat v_i}+\epsilon)$叫有效学习率，它其实是有符号的更新量；AdamW还需加衰减变化。记录原始梯度、缩放系数、完整 $\Delta\theta$、相对更新范数 $\|\Delta\theta\|/(\|\theta\|+\epsilon)$才能判断模型在移动多少。

偏置校正没有统一“50步后无关”的界线。$\beta_1=0.9$时50步 $1-\beta_1^{50}\approx0.9948$，但 $\beta_2=0.999$时仅约0.0488，二阶矩校正仍很明显。它和warmup是不同机制，不能用一者完全替代另一者。

## 5. L2梯度与AdamW衰减的操作顺序

若损失加 $\lambda\|w\|^2/2$，梯度增加 $\lambda w$；无动量普通SGD得到 $(1-\eta\lambda)w-\eta g$。若损失写成 $\lambda\|w\|^2$，梯度是 $2\lambda w$。含动量/自适应状态时，这个附加梯度进入缓存，不能简单视作同一种独立收缩。

本库明确采用AdamW：

$$
w_{new}=(1-\eta\lambda)w_{old}-\eta\frac{\hat m}{\sqrt{\hat v}+\epsilon}.
$$

矩状态只接收任务梯度。若先做Adam再衰减**更新后的**参数，会额外缩放梯度步，和上式相差 $O(\eta^2\lambda)$；原课正文与程序的顺序不同，本库按旧参数收缩统一。不同参数组可以有不同学习率/衰减，通常考虑不衰减偏置和归一化缩放，但这是配方选择，不是所有模型不可违背的理论。

即使优化器形式叫weight decay，也要核对库版本是否耦合、损失是否又手动加L2，避免重复处罚。数据梯度可能让权重增大，所以AdamW不保证每一步总范数下降；零任务梯度对照能隔离衰减的真实作用。

## 6. 用可运行数值程序看状态和首步

下例在固定二次目标 $f(x)=\tfrac12(x_1^2+20x_2^2)$上比较八种规则。全批量解析梯度不含随机抽样，因此这里的“SGD规则”运行是确定性梯度下降；不能把轨迹差异归因于数据噪声。

```python
import numpy as np

H = np.array([1., 20.])

def run(method, lr, steps=200):
    p = np.array([-2.6, 0.9])
    velocity = np.zeros(2)
    m, v, update2 = np.zeros(2), np.zeros(2), np.zeros(2)
    history, first = [], None
    for t in range(1, steps+1):
        old = p.copy()
        g = H*(p-lr*0.9*velocity) if method == "Nesterov" else H*p
        if method == "SGD":
            direction = g
        elif method in ("Momentum", "Nesterov"):
            velocity = 0.9*velocity+g
            direction = velocity
        elif method == "AdaGrad":
            v += g*g
            direction = g/(np.sqrt(v)+1e-8)
        elif method == "RMSProp":
            v = 0.99*v+0.01*g*g
            direction = g/(np.sqrt(v)+1e-8)
        elif method == "AdaDelta":
            v = 0.95*v+0.05*g*g
            direction = np.sqrt(update2+1e-6)*g/np.sqrt(v+1e-6)
            update2 = 0.95*update2+0.05*direction**2
        elif method in ("Adam", "AdamW"):
            m, v = 0.9*m+0.1*g, 0.999*v+0.001*g*g
            direction = (m/(1-0.9**t))/(np.sqrt(v/(1-0.999**t))+1e-8)
        else:
            raise ValueError("未知规则")
        p = old*(1-lr*0.1) if method == "AdamW" else old.copy()
        p -= lr*direction
        if first is None:
            first = p-old
        if not np.isfinite(p).all():
            raise FloatingPointError("非有限参数，停止而不伪装收敛")
        history.append(float(0.5*np.sum(H*p*p)))
    return p, history, first

rates = {"SGD":0.04, "Momentum":0.02, "Nesterov":0.02, "AdaGrad":0.15,
         "RMSProp":0.02, "AdaDelta":1., "Adam":0.05, "AdamW":0.05}
for name, rate in rates.items():
    p, hist, first = run(name, rate)
    print(name, "首步Δ", np.round(first, 5).tolist(), "终损失", round(hist[-1], 7))
_, _, adam_first = run("Adam", 0.05, steps=1)
assert np.allclose(adam_first, [0.05, -0.05], atol=1e-8)
print("beta2在50步的校正分母", round(1-0.999**50, 6))
```

预期Adam首步为约 `[0.05,-0.05]`，二阶矩校正分母约0.048794；完整终值见本批验收。各方法采用不同率，AdaDelta尤其可能200步仍进展较慢，不能按本表结果宣称普遍排名。来源交互图额外把Adam步乘8且把离开视窗轨迹截断，不能用那张图做同率公平比较。

## 7. 裁剪和调度的位置

全局L2范数裁剪将所有参数梯度视为同一个向量，$g\leftarrow g\min(1,c/\|g\|_2)$。$(3,4)$、$c=2$得到 $(1.2,1.6)$；按坐标各自裁剪会改变方向。裁剪只直接限制梯度，不限制Momentum/Adam预条件后更新，也不能修复NaN或错误损失。

典型顺序是清空梯度→前向→稳定loss→反向→必要时unscale→裁剪→optimizer更新→对应时钟推进scheduler。具体AMP规则见[数值稳定专题](../数学与数值计算专题/08-浮点误差与数值稳定.md)。AMP跳过更新时，调度计数也要按真正更新的设计处理；不能把每个微批量或跳过的步骤都当更新。

warmup、分段/指数/线性/余弦衰减、循环、restart和平台期调整完整实现放在[实践专题](17-初始化优化器与学习率实践.md)。未知总长度时也可用验证平台期降率，不必硬设完整余弦终点。

## 8. 优化器选择与故障复盘

AdamW是许多现代网络的可用起点，SGD+Momentum也常有竞争力；GAN、CNN、Transformer、微调都不存在仅凭名称就可靠的最优配方。常见Adam参数是起始参考，不是“80%任务有效”的经验证明；GAN也不是绝对禁止衰减或大动量。

先检查小批量能否拟合、标签与logits损失是否正确，记录各层激活/梯度/更新的有限值和量级，再扫学习率、调度与正则。loss平台期可能是容量、标签、实现或噪声上限，不能统一把lr乘3；突升也可能由异常批量或数值问题导致，不只步长。

自查：只有模型权重但Adam状态丢了，能精确续训吗？**答案：**一般不能；权重预测可恢复，优化轨迹不一定。裁剪阈值1能否保证参数每步只动1？**答案：**不能，学习率、矩状态和自适应缩放都会影响更新。
