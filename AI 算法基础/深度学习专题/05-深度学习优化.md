# 05｜深度学习优化

## 1. 优化与泛化不是一回事

训练优化关注降低训练目标：

[
min_	heta L_{train}(	heta)
]

真正目标则是未知数据上的泛化性能。

因此“训练 loss 更低”不自动意味着“模型更好”。

## 2. 非凸优化

深度网络损失面通常非凸，存在：

- saddle point；
- plateau；
- ill-conditioning；
- noisy gradient。

实践中很少要求找到全局最优点，更重要的是稳定找到泛化良好的可用解。

## 3. 凸性为何仍值得学

凸优化提供：

- 局部最优 = 全局最优；
- 可分析的收敛性质；
- 梯度与学习率的清晰直觉。

它是理解复杂非凸训练算法的理论基线。

## 4. Gradient Descent

全批量梯度下降：

[
	heta_{t+1}=	heta_t-eta
abla L(	heta_t)
]

学习率过小收敛慢，过大可能震荡或发散。

## 5. SGD

随机梯度使用单样本/小批量近似真实梯度：

[
g_tapprox
abla L(	heta_t)
]

噪声降低单步成本，也可能帮助跳出部分平坦或不良区域。

## 6. Mini-batch SGD

实际训练通常使用 mini-batch，在三者之间平衡：

- 统计效率；
- GPU/加速器吞吐；
- 内存。

batch size 不是纯算法超参数，而是算法与系统共同超参数。

## 7. Momentum

Momentum 对历史梯度做指数累积：

[
v_t=eta v_{t-1}+g_t,qquad
	heta_{t+1}=	heta_t-eta v_t
]

它能减少高曲率方向震荡并加速一致方向移动。

## 8. AdaGrad

AdaGrad 按参数累计历史平方梯度，为不同参数自动调整有效学习率。

适合稀疏问题，但累计量单调增大，可能导致后期学习率过小。

## 9. RMSProp

RMSProp 用平方梯度的指数滑动平均替代无限累计，缓解 AdaGrad 后期步长衰减过强。

## 10. AdaDelta

AdaDelta 进一步减少对全局学习率尺度的依赖，通过梯度与更新量的滑动统计调节步长。

## 11. Adam

Adam 结合：

- 一阶矩估计；
- 二阶矩估计；
- bias correction。

它通常是稳定的默认起点，但并不意味着所有任务都优于 SGD 系方法。

需要同时理解 AdamW：把 weight decay 与 Adam 的梯度更新解耦，尤其适合现代 Transformer。

## 12. Learning Rate Schedule

学习率策略常比“换优化器”更重要。

常见思想：

- warmup；
- step decay；
- cosine decay；
- linear decay；
- restart。

Warmup 的核心是训练早期先避免大步更新；衰减则让后期优化逐渐精细。

## 14. 优化器选择方法

推荐顺序：

1. 建立简单 optimizer baseline；
2. 先找可用学习率；
3. 再调整 schedule；
4. 再看 batch size、weight decay；
5. 最后比较 optimizer family。

不要同时改变五个变量后再试图解释结果。
