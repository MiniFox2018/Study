> 核验时间：2026-10-01  
> 原则：来源保全目录保持与上游 blob 完全一致，因此不直接修改原始 Notebook；以下记录运行前需要知道的上游问题与最小修复办法。

## 1. Chapter 8.2：Bias-Variance 图横轴被截断

文件：

`Chap08/8_2_Bias_Variance_Trade_Off.ipynb`

上游 issue：#348（open）

问题：

- 最终 cell 先设置 `n_hidden = 12`；
- 后面又被覆盖成 `n_hidden = 5`；
- `ax.set_xlim(0, n_hidden)` 因而只显示到 5，虽然实验实际包含 1～12 个 hidden variables。

运行时处理：

- 删除/注释后面的 `n_hidden = 5`；
- 或把最终 xlim 改为 12 / `max(hidden_variables)`。

这不改变 Bias-Variance 实验结论，只影响最终图的显示范围。

## 2. Chapter 12.4：NumPy 2 下 Beam Search 类型错误

文件：

`Chap12/12_4_Decoding_Strategies.ipynb`

上游 issue：#353（open）

症状：

`TypeError: only 0-dimensional arrays can be converted to Python scalars`

原因：

`np.where(...)` 返回数组，导致累积 `log_prob` 变成 shape (1,)；NumPy 2 不再像 1.x 那样隐式把它格式化成标量。

最小修复思想：

```python
float(np.log(prob_over_tokens[next_token][0]))
```

即显式取出标量再累积。

这是环境兼容问题，不是 beam search 算法本身的问题。

## 3. Chapter 19.3：Monte Carlo Notebook 语法错误

文件：

`Chap19/19_3_Monte_Carlo_Methods.ipynb`

上游 issue：#354（open）

问题 cell 中两条语句被错误拼到同一行：

```python
print('t:', i)        if i == 0:
```

应拆成：

```python
print('t:', i)
if i == 0:
```

否则 Python 无法解析，Notebook 不能完整运行。

## 4. Chapter 19.4：Q-learning “True value” 参考值错误

文件：

`Chap19/19_4_Temporal_Difference_Methods.ipynb`

上游 issue：#355（open）

Notebook 当前打印的参考值：

`0.3024718977397814`

其实是更新**之前**的 Q 值，因此空 stub 也可能“匹配正确答案”。

按 Notebook 自身随机种子和 Eq. 19.15，单步更新后应约为：

`0.4765026241246880`

因此做练习时不要把当前打印的 “True value” 当作正确性依据。

同一 issue 还指出 Chapter 19.1 的一条确定性轨迹示例可能存在陈旧参考输出；奖励序列仍能匹配。

## 5. 教材图示勘误

上游 issue #349（open）指出教材 Figure 19.11 的一个动作箭头可能应为向右而非向左。

这属于教材图示，不影响保全 Notebook 的 blob 一致性；阅读 RL 策略改进示意时需要留意。
