## 1. 先固定时间下标与数据尺度

沿主章统一：DDPM的t=0是干净x0，t=1…T为带噪状态，bar_alpha[0]=1。数组index0若存第一步噪声，就不是纸面t0；模型时间输入、日程索引、反向端点必须一致。Flow matching也采用**数据t0→噪声t1**，训练速度指向时间增加，生成从1向0用负dt，避免把噪声→数据定义的公式只换一半符号。

DDPM前向一步为 $q(x_t\mid x_{t-1})=\mathcal N(\sqrt{\alpha_t}x_{t-1},\beta_t I)$，$\alpha_t=1-\beta_t$；累计得

$$
q(x_t\mid x0)=\mathcal N(\sqrt{\bar\alpha_t}x0,(1-\bar\alpha_t)I),\quad
\bar\alpha_t=\prod_{j=1}^{t}\alpha_j.
$$

训练直接采一个t与epsilon就构造xt，省去前向链模拟；网络训练成本没有因此变O(1)。终点接近标准正态需要bar_alpha_T足够小且数据尺度一致，任何T/β都不保证。源例将1000步的线性β=.0001～.02原封不动缩成40步，bar_alpha_T仍约.667，信号系数约.817；从N(0,1)启动采样已与训练终态明显不匹配，不能把效果差只归因“反向步数少”。

系数SNR为bar_alpha/(1-bar_alpha)，实际信号方差还乘Var(data)。原动态图固定uniform[-1,1]噪声和未单位方差正弦信号，不是DDPM高斯Markov链；滑块只是直接混合，不是在运行学得逆过程。“linear”图曲线 `(1-t/T)^2.2` 也不是标准线性β累积乘积，不能用其图形证明余弦一定胜。

### 1.1 完整日程、前向统计与后验系数核对

$q(x_{t-1}|x_t,x0)$是已知x0时的高斯，未知x0时$q(x_{t-1}|x_t)$一般是数据后验混合，有限步不保证精确高斯。令

$$
\tilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t,
\quad \tilde\mu_t=c_0x0+c_tx_t,
$$

$$
c_0=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t},\qquad
c_t=\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}.
$$

这来自两个高斯相乘的精度相加；t1时退化成干净x0、variance0，不能额外加最后一团噪声。

```python
import numpy as np

def schedule(T,beta_start=.002,beta_end=.18):
    if type(T) is not int or T<2 or not np.isfinite([beta_start,beta_end]).all() or not 0<beta_start<=beta_end<1:
        raise ValueError("正日程与T>=2；β必须在(0,1)")
    beta=np.r_[0.,np.linspace(beta_start,beta_end,T)]
    alpha=1-beta;bar=np.cumprod(alpha)
    assert bar[0]==1 and np.all(np.diff(bar)<0)
    return beta,alpha,bar

def posterior(beta,alpha,bar,t):
    if type(t) is not int or not 1<=t<len(bar):raise ValueError("后验t应1..T")
    denominator=1-bar[t]
    variance=beta[t]*(1-bar[t-1])/denominator
    c0=np.sqrt(bar[t-1])*beta[t]/denominator
    ct=np.sqrt(alpha[t])*(1-bar[t-1])/denominator
    return c0,ct,variance

beta,alpha,bar=schedule(64)
rng=np.random.default_rng(9);x0=.75;t=17;n=40000
closed=np.sqrt(bar[t])*x0+np.sqrt(1-bar[t])*rng.normal(size=n)
chain=np.full(n,x0)
for j in range(1,t+1):chain=np.sqrt(alpha[j])*chain+np.sqrt(beta[j])*rng.normal(size=n)
for x in [closed,chain]:
    assert abs(x.mean()-np.sqrt(bar[t])*x0)<.015
    assert abs(x.var()-(1-bar[t]))<.015
c0,ct,var=posterior(beta,alpha,bar,t)
prior_var=1-bar[t-1]
precision=alpha[t]/beta[t]+1/prior_var
assert np.isclose(var,1/precision)
xt=1.2
precision_mean=var*(np.sqrt(alpha[t])*xt/beta[t]+np.sqrt(bar[t-1])*x0/prior_var)
assert np.isclose(c0*x0+ct*xt,precision_mean)
assert np.allclose(posterior(beta,alpha,bar,1),[1,0,0])
weak=schedule(40,.0001,.02)[2][-1]
print("前向统计/高斯精度后验/t1端点通过；弱40步bar_T",round(weak,6),"新bar_T",round(bar[-1],6))
```

这里核对高斯构造与下标，不是图像模型训练。日程要与checkpoint匹配，不能因想减少**推理步数**就把**训练日程长度**T改小后沿用权重；可以用已定义的solver在训练时间轴上选跳步。

## 2. 噪声回归、diffusion-v与score

常用simple loss为 $E\|\epsilon-\epsilon_\theta(x_t,t,c)\|^2$。网络输入xt、时间和可选条件，不应把真实x0/epsilon经额外字段泄漏到模型。full ELBO含每时间步KL/边界项，特定方差/参数化给带系数的MSE；去掉权重的simple loss是实用目标，不是所有variational目标严格同一个表达式，也不自动给精确likelihood/永不模式缺失的保证。

令a=√bar_alpha、sigma=√(1-bar_alpha)，常见diffusion-v目标为 $v_D=a\epsilon-\sigma x0$：

$$
\hat x0=(x_t-\sigma\hat\epsilon)/a,
\quad \hat x0=ax_t-\sigma\hat v_D,
\quad \hat\epsilon=\sigma x_t+a\hat v_D.
$$

它是该日程的参数化旋转；**不是**flow interpolation的导数。高斯条件score为 $\nabla_x\log q_t(x|x0)=-\epsilon/\sigma$，noise MSE的最优回归是条件期望E[epsilon|xt]，对应边际score。极端a或sigma时换算需数值稳定并说明端点，不能在sigma0直接除0。v/x0/noise的无权MSE有不同时间权重，不能说只改输出名字而训练等价。对于t≥2且model方差sigma_theta,t²固定为正，高斯KL的均值项变为加权noise误差，系数为 $w_t=\beta_t^2/[2\sigma_{\theta,t}^2\alpha_t(1-\bar\alpha_t)]$，另有不依均值参数的项；学方差时这些项也影响训练。t1是重建/边界likelihood项，不能把posterior variance0直接塞进该分母。

### 2.1 三种预测类型与错误scheduler的实际反例

```python
import numpy as np
rng=np.random.default_rng(11)
x0=rng.normal(size=(3,2));noise=rng.normal(size=x0.shape)
a=.8;sigma=.6;xt=a*x0+sigma*noise;v=a*noise-sigma*x0

def prediction(xt,output,kind,a,sigma):
    if not np.isfinite([a,sigma]).all() or a<=0 or sigma<=0 or not np.isclose(a*a+sigma*sigma,1):
        raise ValueError("内部VP时间需正a/sigma且平方和1")
    if xt.shape!=output.shape or not np.isfinite(xt).all() or not np.isfinite(output).all():raise ValueError("有限同形预测")
    if kind=="epsilon":return (xt-sigma*output)/a,output
    if kind=="v_prediction":return a*xt-sigma*output,sigma*xt+a*output
    if kind=="sample":return output,(xt-a*output)/sigma
    raise ValueError("未知prediction_type，不能把flow-v传入DDPM-v接口")
for kind,output in [("epsilon",noise),("v_prediction",v),("sample",x0)]:
    clean,eps=prediction(xt,output,kind,a,sigma)
    assert np.allclose(clean,x0) and np.allclose(eps,noise)
wrong,_=prediction(xt,v,"epsilon",a,sigma)
assert not np.allclose(wrong,x0)
print("三参数化换算通过；把v当epsilon的最大误差",round(float(np.abs(wrong-x0).max()),6))
```

source把SDXL/SD3/Flux统称diffusion-v的说法不保留；具体训练目标要查scheduler/pipeline/model配置，MMDiT/DiT是骨干，不能从Transformer名字推断noise、diffusion-v或flow velocity。

## 3. 完整小型条件DDPM训练与反向循环

此例从两个一维高斯类采样，用MLP接xt、时间sin/cos和class embedding，随机丢条件以学习null分支。训练真的更新参数，采样真的走完T→0；仍只是合成标量任务，不叫Stable Diffusion。posteriorsmall方差、beta_t或learned方差是不同建模/目标选择，本例明确用tilde_beta。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(19)
T=64
beta=torch.cat([torch.zeros(1),torch.linspace(.002,.18,T)])
alpha=1-beta;bar=torch.cumprod(alpha,0)
assert bar[0]==1 and bar[-1]<.005
NULL=2
class NoiseMLP(nn.Module):
    def __init__(self):
        super().__init__();self.class_emb=nn.Embedding(3,4)
        self.net=nn.Sequential(nn.Linear(1+6+4,48),nn.SiLU(),nn.Linear(48,48),nn.SiLU(),nn.Linear(48,1))
    def forward(self,x,t,c):
        u=t.float()/T;freq=torch.tensor([1.,3.,9.])
        angles=u[:,None]*freq[None,:]*torch.pi
        time=torch.cat([angles.sin(),angles.cos()],-1)
        return self.net(torch.cat([x,time,self.class_emb(c)],-1))
model=NoiseMLP();optimizer=torch.optim.Adam(model.parameters(),lr=.002)
initial=model.net[-1].weight.detach().clone();trace=[]
for step in range(500):
    c=torch.randint(0,2,(128,));x0=(c.float()*4-2)[:,None]+.35*torch.randn(128,1)
    t=torch.randint(1,T+1,(128,));eps=torch.randn_like(x0);a=bar[t][:,None]
    xt=a.sqrt()*x0+(1-a).sqrt()*eps
    conditioning=torch.where(torch.rand(128)<.15,torch.full_like(c,NULL),c)
    loss=F.mse_loss(model(xt,t,conditioning),eps)
    optimizer.zero_grad(set_to_none=True);loss.backward()
    nn.utils.clip_grad_norm_(model.parameters(),1.);optimizer.step();trace.append(loss.item())
assert not torch.equal(initial,model.net[-1].weight)
assert all(p.grad is None or torch.isfinite(p.grad).all() for p in model.parameters())

@torch.no_grad()
def sample(c,g,initial_noise):
    if not isinstance(g,(int,float)) or not torch.isfinite(torch.tensor(g)):
        raise ValueError("有限guidance")
    x=initial_noise.clone()
    for t in range(T,0,-1):
        times=torch.full((len(x),),t,dtype=torch.long)
        conditional=model(x,times,c)
        baseline=model(x,times,torch.full_like(c,NULL))
        epsilon=baseline+g*(conditional-baseline)
        mean=(x-beta[t]/(1-bar[t]).sqrt()*epsilon)/alpha[t].sqrt()
        variance=beta[t]*(1-bar[t-1])/(1-bar[t])
        x=mean+(variance.sqrt()*torch.randn_like(x) if t>1 else 0.)
    return x
model.eval();c=torch.tensor([0]*32+[1]*32);z=torch.randn(64,1)
ordinary=sample(c,1.,z)
assert ordinary.shape==(64,1) and torch.isfinite(ordinary).all()
print("实际小训练前/末50平均MSE",round(sum(trace[:50])/50,4),round(sum(trace[-50:])/50,4))
print("64步结果两类均值",round(ordinary[:32].mean().item(),3),round(ordinary[32:].mean().item(),3),"参数更新/有限采样通过")
```

输出中的loss/类均值是此次小实验观测，不承诺固定质量；参数更新与有限数值不是学会完整数据分布。评估需独立noise/t采样和目标数据、分布覆盖/条件命中/多seed，而不是仅把正负个数各半当两峰已恢复。time embedding的输入范围/维度与原训练匹配，sin/cos、FiLM、AdaLN都是选项，不把raw t永远禁用或cosine永远更好当理论。

## 4. LDM与scheduler：先核对接口，再选择步数

Latent diffusion先训练autoencoder（可能KL/perceptual/adversarial等目标），再把其latent视为扩散数据；重构好不保证latent prior或条件生成好。source的x×.5/z×2只是可逆尺度变换，维度没有减少，不是VAE压缩。历史512×512×3→64×64×4仅元素数减少48倍，空间网格64倍；不推出固定64倍FLOPs/显存/速度或相同质量。

必须记录posterior取sample/mode、scale/shift及decoder逆变换。一种明确合同为 $z_{model}=s(z_{raw}-b)$，解码前 $z_{raw}=z_{model}/s+b$；有的模型b=0，有的配置含非零shift。s=.18215不是所有VAE普适常数，新的channel数、patch packing、条件encoder也非按年份统一改变。

scheduler不是仅for循环步数。需要checkpoint对应的train timesteps、beta/sigma/logSNR、prediction_type、time embedding范围、`scale_model_input`、initial noise sigma、step的输入/输出以及真实最后时刻。重用不同solver需要这些合同兼容，不能把flow velocity交给DDPM epsilon step或只改T而不重新定义模型时间。多步solver还保存历史预测，换prompt/轨迹/重启时不得复用错cache。

### 4.1 完整latent scale/shift与DDIM跳步合同

本例codec只验证数值变换，没有训练autoencoder或压缩图像。模型是知道常数target的oracle，用于测试接口；source主章DDPM/真实小训练的目标定义仍有效。

```python
import numpy as np

class LatentContract:
    def __init__(self,scale,shift=0.):
        if not np.isfinite([scale,shift]).all() or scale<=0:raise ValueError("有限正scale")
        self.scale,self.shift=scale,shift
    def to_model(self,raw):return self.scale*(np.asarray(raw)-self.shift)
    def to_codec(self,model_latent):return np.asarray(model_latent)/self.scale+self.shift

class MiniDDIM:
    init_noise_sigma=1.
    def __init__(self,T=32,prediction_type="epsilon"):
        if T<2 or prediction_type not in ["epsilon","v_prediction","sample"]:raise ValueError("日程/预测类型")
        self.T,self.prediction_type=T,prediction_type
        self.beta=np.r_[0.,np.linspace(.003,.18,T)];self.bar=np.cumprod(1-self.beta)
        self.timesteps=None
    def set_timesteps(self,times):
        if any(type(t) is not int or not 0<=t<=self.T for t in times) or len(times)<2 or times[-1]!=0 or any(a<=b for a,b in zip(times,times[1:])):
            raise ValueError("严格递减合法时刻，包含真实clean0")
        self.timesteps=list(times)
    def add_noise(self,clean,noise,t):
        if type(t) is not int or not 0<=t<=self.T:raise ValueError("噪声时刻越界")
        return np.sqrt(self.bar[t])*clean+np.sqrt(1-self.bar[t])*noise
    def scale_model_input(self,x,t):return x  # 本scheduler明确identity；其他实现不必相同
    def step(self,output,t,s,x):
        if not 0<=s<t<=self.T:raise ValueError("必须向clean推进")
        a=np.sqrt(self.bar[t]);sigma=np.sqrt(1-self.bar[t])
        if self.prediction_type=="epsilon":eps=output;clean=(x-sigma*eps)/a
        elif self.prediction_type=="v_prediction":clean=a*x-sigma*output;eps=sigma*x+a*output
        else:clean=output;eps=(x-a*clean)/sigma
        return np.sqrt(self.bar[s])*clean+np.sqrt(1-self.bar[s])*eps  # eta0，不额外随机噪声

rng=np.random.default_rng(23)
raw=rng.normal(size=(2,4,4,4));codec=LatentContract(.18215,.1)
clean=codec.to_model(raw);assert np.allclose(codec.to_codec(clean),raw)
scheduler=MiniDDIM();scheduler.set_timesteps([32,20,8,1,0])
x=rng.normal(size=clean.shape)*scheduler.init_noise_sigma
for t,next_t in zip(scheduler.timesteps[:-1],scheduler.timesteps[1:]):
    model_input=scheduler.scale_model_input(x,t)
    epsilon=(model_input-np.sqrt(scheduler.bar[t])*clean)/np.sqrt(1-scheduler.bar[t])
    x=scheduler.step(epsilon,t,next_t,x)
assert np.allclose(x,clean,atol=1e-10) and np.allclose(codec.to_codec(x),raw)
assert not np.allclose(x,raw)  # 忘记inverse scale/shift不是解码成功
try:scheduler.set_timesteps([32,8,8,0])
except ValueError:print("重复时刻日程已拒绝")
print("latent双向合同与真正clean端点通过",x.shape)
```

`step`函数是训练日程上的DDIM eta0跳步。DDPM离散祖先链不能随意跳t而仍套相邻β；真实Diffusers `prev_sample`用于下一轮，`pred_original_sample`不是相同状态。clip predicted x0、动态threshold和sigma更改都可能影响目标/质量，不能用“换个最快scheduler”省略一致性检查。

文本条件可经cross-attention、pooled embedding/调制、joint attention等进入骨干，不是所有U-Net block都有同样cross-attn，也不是文本只有一个入口。SD3等可能要求多个encoder/长度/pooled输出，不存在通用 `use_t5=True` 开关；encoder/task/latent互换应检验形状和训练分布，不假定某版本库必定替用户发现全部错配。

## 5. CFG、negative prompt与结构条件

本章用 $f_g=f_b+g(f_c-f_b)$：g0是baseline/null，g1是普通conditional，g>1外推；source $(1+w)f_c-wf_u$ 的w等于g−1，所以source w0是普通条件，不能同时称无条件。CFG训练以明确概率替换condition为null，null不必是全0embedding；填negative prompt时baseline变成negative-condition预测，而不是数学无条件score。

CFG可以在线性参数化的epsilon/x0/diffusion-v/flow velocity中组合，但必须在同一时刻、样本尺度和预测类型下运算。某些guidance-distilled模型只接受guidance embedding或特定配置，不能强行补两分支；尺度g的质量/对齐/覆盖权衡由验证决定，没有10必坏/7最佳。把两分支拼batch能减少某些调度开销，却仍处理两份样本；batch统计/dropout也可能影响与分开计算的等价性。

### 5.1 两分支与negative-baseline的完整小例

```python
import torch
from torch import nn

torch.set_num_threads(1);torch.manual_seed(29)
class Conditional(nn.Module):
    def __init__(self):
        super().__init__();self.emb=nn.Embedding(3,4)
        self.net=nn.Sequential(nn.Linear(1+1+4,8),nn.SiLU(),nn.Linear(8,1))
    def forward(self,x,t,c):return self.net(torch.cat([x,t[:,None],self.emb(c)],-1))
model=Conditional().eval();x=torch.randn(4,1);t=torch.full((4,),.4)
positive=torch.ones(4,dtype=torch.long);null=torch.zeros_like(positive);negative=torch.full_like(positive,2)
with torch.no_grad():
    cond=model(x,t,positive);base=model(x,t,null);neg=model(x,t,negative)
    joint=model(torch.cat([x,x]),torch.cat([t,t]),torch.cat([null,positive]))
    a,b=joint.chunk(2);assert torch.allclose(a,base) and torch.allclose(b,cond)
    def guide(g,baseline):
        if not isinstance(g,(int,float)) or not torch.isfinite(torch.tensor(g)):raise ValueError("finite guidance")
        return baseline+g*(cond-baseline)
    assert torch.allclose(guide(0,base),base) and torch.allclose(guide(1,base),cond)
    assert not torch.allclose(guide(3,base),guide(3,neg))
print("CFG0/1与拼batch等价，negative不是null；随机模型只验合同")
```

结构条件（edge/pose/depth/segmentation）与输入图必须有一致坐标、resize、归一化和mask语义。相对深度不是米深度，pose置信度/遮挡不能被条件图抹掉。多个ControlNet的残差加权可以组合，不要求权重和固定1或1.5；存在矛盾条件时，要看条件服从与质量，不靠“叠越多越好”。IP-Adapter的图像tokens通常通过独立/解耦cross-attn路径提供外观语义，不能简化为一定与文字tokens直接拼接；Textual Inversion学embedding，DreamBooth是subject-driven微调范式，可与LoRA结合，并不定义为必然全量训练。

## 6. Zero-conv与LoRA的真实梯度路径

ControlNet类分支复制/借用部分预训练结构，condition经可训练网络生成多尺度残差，zero-initialized投影使**添加到基模型的残差**初始为0。零卷积自己不是identity，整个增强模型初始输出可等于base；后续训练可能改善也可能损害，source图“training can only improve”没有依据。

冻结base参数不等于把加入side残差后的decoder整体包 `no_grad`：那样会切掉通向side的loss梯度。首次反向时zero层获得梯度、上游side因zero权重可能grad0，是预期；两个相乘路径都初始化0又可能真使梯度消失。下面保留冻结decoder的可微运算，检验两轮梯度与基参数未变。

```python
import copy
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(31)
encoder=nn.Sequential(nn.Conv2d(1,4,3,padding=1),nn.SiLU())

```

这是小卷积分支，不是完整ControlNet/SDXL复现；多尺度复制、time/text条件、权重加载与训练目标还需具体模型。选择某条件图不保证输出“pose locked”或身份一致，不能把source预画人物动画当真实生成。

### 6.1 同一次forward的LoRA梯度、rank与融合

标准 $\Delta W=(\alpha_L/r)BA$，A为r×in、B为out×r，新增r(in+out)参数。另有runtime系数lambda，所以融合 $W_{merged}=W+\lambda(\alpha_L/r)BA$。alpha_L与runtime lambda不是一个不加说明的“strength”。两个adapter在单层权重上相加是线性的，但全网络激活/注意力的交互不线性；rank≥rank(target_delta)只是可表示性必要条件，不保证优化一定收敛。

```python
import torch
from torch import nn

torch.set_num_threads(1);torch.manual_seed(37)
din,dout,r=6,4,2
W=torch.randn(dout,din)
u=torch.linalg.qr(torch.randn(dout,2)).Q;v=torch.linalg.qr(torch.randn(din,2)).Q
true_delta=u@torch.diag(torch.tensor([1.1,.7]))@v.T
A=nn.Parameter(torch.randn(r,din)*.1);B=nn.Parameter(torch.zeros(dout,r))
alpha_L=2.;runtime=.8;scale=runtime*alpha_L/r
X=torch.eye(din);target=X@(W+true_delta).T
before=W.clone();opt=torch.optim.Adam([A,B],lr=.05)
for step in range(350):
    pred=X@W.T+scale*(X@A.T)@B.T
    loss=(pred-target).square().mean()
    opt.zero_grad();loss.backward()
    if step==0:
        assert B.grad.abs().sum()>0 and A.grad.abs().sum()==0
    opt.step()
assert torch.equal(W,before)
merged=W+scale*(B@A)
assert torch.allclose(X@merged.T,X@W.T+scale*(X@A.T)@B.T,atol=1e-6)
assert A.numel()+B.numel()==r*(din+dout)
print("本次rank2拟合MSE",round(((X@merged.T-target)**2).mean().item(),8),"LoRA参数",A.numel()+B.numel(),"未改变base")
# 关闭adapter回到原W；融合后需保留原权重/元数据，不从浮点减delta保证位级可逆。
```

source原LoRA训练先更新B、再用新B与旧error算A，不是同一次forward的标准联合梯度；这里autograd在step前统一取梯度。source声明随机target rank2/3，但实际u⊗v构造总rank1，练习不能据该程序验证rank2门槛。LoRA需核对base版本/模块shape/潜空间/目标和tokenizer，不能假定不同base必静默no-op或某库版必全面拒绝。

## 7. Inpainting、outpainting与编辑边界

本章mask=1/True表示**要重绘**，0表示保护。不同库可能相反，必须核验白黑/alpha、分辨率、原图resize与latent降采样对应。outpainting先扩大画布并保存原图位置，再把新增区域标为重绘；不等于对任意原mask取反就完整处理了画布几何，也没有固定30%原图锚点保证。

训练过的inpaint模型可读取额外mask与masked-image latent。历史SD的9ch为noisy latent4+mask1+**遮掉孔内内容的image latent4**，不是任意完整原图latent；很多实现先在像素空间遮孔再encode，latent乘mask一般不等于encode(masked pixels)。其他Flux/DiT家族有不同packing/channel合同，不能统称所有模型9ch。训练loss也不必只在孔内计算；模型输出与算力通常覆盖完整空间，9ch不自动提供局部稀疏推理。

无专门inpaint模型时可用known-region reinjection等方法：若从x_t推得proposal x_s，已知区域应按 **s的前向日程** 重新构造，而不是在x_s塞q_t或永远塞干净x0。以下固定known noise明确是一种边际一致coupling；RePaint还有前向跳步/重采样策略，不能把所有reinjection等同其完整算法。

### 7.1 完整time-matched reinjection与真实clean端点

为只检验下标/掩码，oracle知道完整希望得到的target；它不是学得补洞器。每轮在时刻t检查known区、一步后混合q_s，最后t0才精确恢复保护latent。

```python
import numpy as np
rng=np.random.default_rng(41)
T=24;beta=np.r_[0.,np.linspace(.01,.2,T)];alpha=1-beta;bar=np.cumprod(alpha)
source=np.linspace(-.7,.7,36).reshape(6,6)
mask=np.zeros((6,6),dtype=bool);mask[2:4,2:4]=True
target=source.copy();target[mask]=.9
known_noise=rng.normal(size=source.shape)

def add_noise(clean,t,noise):
    if type(t) is not int or not 0<=t<=T:raise ValueError("q時刻")
    return np.sqrt(bar[t])*clean+np.sqrt(1-bar[t])*noise

def edit(edit_mask):
    if edit_mask.dtype!=bool or edit_mask.shape!=source.shape:raise ValueError("bool edit mask必须对齐")
    x=rng.normal(size=source.shape)
    x=np.where(edit_mask,x,add_noise(source,T,known_noise))
    for t in range(T,0,-1):
        assert np.allclose(x[~edit_mask],add_noise(source,t,known_noise)[~edit_mask])
        eps=(x-np.sqrt(bar[t])*target)/np.sqrt(1-bar[t])  # explicit oracle
        clean_hat=(x-np.sqrt(1-bar[t])*eps)/np.sqrt(bar[t])
        proposal=np.sqrt(bar[t-1])*clean_hat+np.sqrt(1-bar[t-1])*eps
        known=add_noise(source,t-1,known_noise)
        x=np.where(edit_mask,proposal,known)
    return x
result=edit(mask);assert np.allclose(result[~mask],source[~mask])
assert np.allclose(result[mask],target[mask])
assert np.allclose(edit(np.zeros_like(mask)),source)
# 反例：在x_s继续放q_t，即使模型很好也违反时刻合同。
s=T-1
wrong=np.where(mask,result,add_noise(source,T,known_noise))
assert not np.allclose(wrong[~mask],add_noise(source,s,known_noise)[~mask])
# 合法前向jump: 从时刻s回到更噪t>s，不能仅加标准噪声而忘掉缩放。
x_s=add_noise(source,7,known_noise)
ratio=bar[12]/bar[7]
jumped=np.sqrt(ratio)*x_s+np.sqrt(1-ratio)*rng.normal(size=source.shape)
assert np.isfinite(jumped).all() and 0<ratio<1
print("known区时刻/clean端点/全保护mask通过；错时刻reinjection被识别")
```

RePaint的forward jump遵守q(x_t|x_s)比例bar_t/bar_s，何时跳/重复几次要记录算法，额外计算不自动改善每幅图。专用模型、邻域条件、mask形状与solver都会影响接缝，不能把source二维轮廓的“噪点淡为蓝块”当输出coherence证明。

### 7.2 latent保护不等于pixel保护，9ch与最终合成

下面的`masked_latent`是人为构造的通道形状fixture，没有编码真实masked pixels；真实流程应按模型在像素空间遮孔后编码，不能把这个ones数组当VAE输出。

```python
import numpy as np
from scipy.ndimage import convolve

source=np.linspace(-.7,.7,36).reshape(6,6)
mask=np.zeros((6,6),dtype=bool);mask[2:4,2:4]=True
changed=source.copy();changed[mask]+=1.
# 模拟有空间receptive field的decoder，不是VAE。
def decode(z):return convolve(z,np.ones((3,3))/9,mode="reflect")
original_pixel=decode(source);edited_pixel=decode(changed)
assert np.array_equal(changed[~mask],source[~mask])
assert np.any(np.abs(edited_pixel[~mask]-original_pixel[~mask])>1e-12)
composite=np.where(mask,edited_pixel,original_pixel)
assert np.array_equal(composite[~mask],original_pixel[~mask])
# 正确9ch参数含latent mask和masked-image latent，不表示自动只算masked位置。
noisy=np.zeros((2,4,6,6));latent_mask=np.broadcast_to(mask[None,None],(2,1,6,6)).astype(float)
masked_latent=np.ones_like(noisy)*(1-latent_mask)
packed=np.concatenate([noisy,latent_mask,masked_latent],axis=1)
assert packed.shape==(2,9,6,6)
print("latent未变但decoder邻域像素会变；最终硬合成保护pixel通过",packed.shape)
```

羽化是空间混合，不是自动质量修复；soft-mask过渡区本来就允许改变，须重新定义严格保护集合。JPEG/颜色转换/resize也可能改变全图，pixel-identical目标需保存/编码合同，不能仅比较latent。腐蚀/膨胀/blur半径依图像尺寸与对象尺度，不采用固定8～16像素跨任务。identity/pose/prompt服从与重绘质量分开评，不从“同一subject string”推断身份保持。

SDEdit在选定训练时间加噪再条件反向，strength影响starting time/steps与solver，固定.3/.6/.9不是线性保真刻度。图像条件仍可保结构，高strength不普遍等于完全忽略原图。InstructPix2Pix等可同时用图像与文字条件/不同guidance；Flux-Kontext接受图像/指令不代表只需一个forward，依然需其模型相应采样流程。`image_processor.preprocess`通常是像素预处理，不是VAE encode；pipeline `latents`可能指初始噪声/特定状态，复用上轮clean latent必须核查参数语义与重新加噪，而非直接省掉所有encode/调度。

## 8. Flow matching：直的训练配对不等于直的生成轨迹

沿本章与生成主章的数据→噪声约定：x_t=(1-t)x0+tε，配对velocity u=ε−x0；训练 $E\|v_\theta(x_t,t)-u\|^2$。最优边际场是 $E[u|x_t=x]$，同一点可能来自多个配对，所以积分ODE轨迹可以弯曲/非恒速。采样从t1噪声向t0，更新 $x\leftarrow x-\Delta t\,v(x,t)$；普通一阶Euler少步并不自动变成蒸馏模型或1-step高质量。

一般Gaussian conditional path x_t=a(t)x0+sigma(t)ε的速度为 **a' x0+sigma' ε**，两个导数都是实际符号，不是source写的任意minus。这里给定x0的epsilon须是独立标准高斯，才能使用该Gaussian conditional score关系；reflow改变端点耦合后不能未经核对继续套用。若a与sigma在内部正且够光滑，score s_t=-E[ε|x_t]/sigma，边际速度可写

$$
v_t(x)=\frac{a'}a x-\sigma\left(\sigma'-\frac{a'\sigma}{a}\right)s_t(x).
$$

a=1-t、sigma=t时得到 $v_t=-(x+t s_t)/(1-t)$（仅内部t，端点取适当极限/直接条件期望）。这与diffusion-v的旋转定义不同。对扩散系数仅依赖时间的Itô SDE $dX=f(x,t)dt+g(t)dW$，reverse-time SDE drift为f−g²score（倒时间积分），probability-flow ODE drift为f−.5g²score；在假设成立时共享边际，不共享所有随机路径/耦合。状态依赖扩散需另核广义公式及额外项，不能直接套本句。不能笼统说FM=“Stratonovich换写”或任何路径都代数完全等价。

### 8.1 完美边际场也可一Euler步塌到中间：解析混合实验

两个data mode均值±2、std .35，独立配对epsilon~N(0,1)。下面从Gaussian posterior算E[x0|xt]/E[ε|xt]的**解析场**，用相同初始noise比较Euler步数与细RK4轨迹参考，而非每组换seed混入Monte Carlo差异。

```python
import numpy as np
rng=np.random.default_rng(43)
mu=np.array([-2.,2.]);data_var=.35**2

def field(x,t):
    a=1-t;b=t;variance=a*a*data_var+b*b
    residual=x[...,None]-a*mu
    logw=-.5*residual**2/variance
    weights=np.exp(logw-logw.max(axis=-1,keepdims=True));weights/=weights.sum(axis=-1,keepdims=True)
    data_mean=mu+a*data_var/variance*residual
    noise_mean=b/variance*residual
    return np.sum(weights*(noise_mean-data_mean),axis=-1)

def integrate(initial,steps,method):
    if type(steps) is not int or steps<1 or method not in ["Euler","RK4"]:raise ValueError("合法solver")
    x=initial.copy();h=-1/steps
    for i in range(steps):
        t=1-i/steps
        if method=="Euler":x=x+h*field(x,t)
        else:
            k1=field(x,t);k2=field(x+h*k1/2,t+h/2)
            k3=field(x+h*k2/2,t+h/2);k4=field(x+h*k3,t+h)
            x=x+h*(k1+2*k2+2*k3+k4)/6
    return x

initial=rng.normal(size=1000)
reference=integrate(initial,600,"RK4")
one=integrate(initial,1,"Euler")
assert np.allclose(one,0) and np.std(reference)>1.5
errors=[]
for steps in [1,2,4,8,20]:
    output=integrate(initial,steps,"Euler")
    error=float(np.sqrt(np.mean((output-reference)**2)))
    errors.append(error);print("Euler steps/同轨迹RMS误差",steps,round(error,6))
assert errors[-1]<errors[0]
# score关系在内部时刻与条件期望速度核对。
t=.4;a=1-t;b=t;variance=a*a*data_var+b*b
x=np.array([-.7,.2,1.1]);r=x[:,None]-a*mu
w=np.exp(-.5*r*r/variance);w/=w.sum(-1,keepdims=True)
score=np.sum(w*(-r/variance),axis=-1)
assert np.allclose(field(x,t),-(x+t*score)/(1-t))
print("条件均值/score关系通过；完美场1Euler步仍塌中间，不是高质量生成")
```

这证明“各端点训练插值是直线”不足以承诺单步。stiffness、曲率、时间尺度、积分误差和学习误差是不同因素；Euler误差比较是在同一解析场/初始noise下，不是与真实DDPM图像质量的公平对照。

## 9. 实际小型FM训练与一轮reflow

Reflow先从已有场积分生成(noise endpoint, generated data endpoint)配对，再用这些端点直线插值训练新场。它改变耦合且有teacher采样成本；teacher错误也会被复制，不保证2轮就消除曲率/达到50步DDPM质量。Time sampling uniform/logit-normal改变训练时间权重；logit-normal是否集中中部依均值/标准差，不是给名字就自动改善。若要保持某一原目标期望，需要相应importance权重，而不是悄悄换采样后称同目标。

下面训练真正的两层MLP，数据仍是合成±2混合。一轮reflow由该teacher生成固定配对，再训练student；只检查数据配对、有限梯度/积分与参数更新，不断言student优于teacher。

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.set_num_threads(1);torch.manual_seed(47)
class Velocity(nn.Module):
    def __init__(self):
        super().__init__();self.net=nn.Sequential(nn.Linear(4,32),nn.SiLU(),nn.Linear(32,32),nn.SiLU(),nn.Linear(32,1))
    def forward(self,x,t):
        return self.net(torch.cat([x,t[:,None],(2*torch.pi*t).sin()[:,None],(2*torch.pi*t).cos()[:,None]],-1))

def train(model,steps,paired=None):
    optimizer=torch.optim.Adam(model.parameters(),lr=.002);trace=[]
    for _ in range(steps):
        if paired is None:
            labels=torch.randint(0,2,(128,));data=(labels.float()*4-2)[:,None]+.35*torch.randn(128,1)
            noise=torch.randn_like(data)
        else:
            indexes=torch.randint(0,len(paired[0]),(128,));noise=paired[0][indexes];data=paired[1][indexes]
        t=torch.rand(128);u=t[:,None]
        interpolated=(1-u)*data+u*noise;target=noise-data
        loss=F.mse_loss(model(interpolated,t),target)
        optimizer.zero_grad();loss.backward();nn.utils.clip_grad_norm_(model.parameters(),1.);optimizer.step()
        trace.append(loss.item())
    assert all(p.grad is None or torch.isfinite(p.grad).all() for p in model.parameters())
    return trace

@torch.no_grad()
def solve(model,noise,steps=40):
    x=noise.clone()
    for i in range(steps):
        t=torch.full((len(x),),1-i/steps)
        x-=model(x,t)/steps
    return x
teacher=Velocity();before=teacher.net[-1].weight.detach().clone()
loss1=train(teacher,400)
noise=torch.randn(512,1);teacher.eval();landing=solve(teacher,noise,40)
assert landing.shape==noise.shape and torch.isfinite(landing).all()
student=Velocity();loss2=train(student,400,paired=(noise,landing))
assert not torch.equal(before,teacher.net[-1].weight)
student.eval();student_out=solve(student,noise,4)
assert student_out.shape==noise.shape and torch.isfinite(student_out).all()
print("teacher末50MSE",round(sum(loss1[-50:])/50,4),"student末50MSE",round(sum(loss2[-50:])/50,4))
print("真实MLP训练/512配对/一轮reflow/4步有限结果通过；未证明质量提升")
```

“模拟免费”指构造训练pair不需沿ODE逐步采样，实际网络优化仍有成本；reflow生成配对又需要teacher积分。Consistency model学沿特定轨迹一致的映射，LCM是latent方案，adversarial diffusion distillation还有对抗/蒸馏目标；SDXL-Turbo/LCM/Schnell不能全部叫同一种“FM两轮reflow”。source13的normalizing-flow动态图实际画x=z+a tanh(z)与Jacobian密度，是[主章可逆Flow](10-深度生成模型.md#4-normalizing-flow可逆与密度)，不是训练上述velocity或执行reflow。

## 10. 实验比较、数值预算与学习验收

先分开网络骨干、data/latent分布、training loss、time sampling、condition、scheduler/solver和蒸馏。更换一个条件模块不意味着改变训练目标；把T从40降10而末端signal变强，会同时改终态分布与训练问题，不能当仅比较步数。少步学生与原模型比较还要计teacher数据生成/训练成本及独立质量。

保存base/model/codec/condition/adapter版本、processor、dtype、seed/RNG、训练与推理日程、prediction_type、guidance公式定义和实际条件/negative输入。同seed在同实现便于配对比较，不保证跨设备、库版本或solver有相同噪声调用/相同结果。source13各步数换初始noise，只能看带Monte Carlo波动的结果，积分误差更宜同initial/同场/细步参考；与数据分布比较用独立样本/分位/一维Wasserstein等，不能拿无配对真样本的逐点MSE当分布质量。

图像评价FID/KID/语义对齐/条件pose与identity/人工错误关注不同侧面，协议由[视觉生成第10节](../感知与多模态专题/09-视觉生成与视频时序.md#10-图像视频评价与物理检查)统一。训练loss下降或sampler输出有限不是质量标准，均值接近0不证明两个峰/覆盖都正确。Editing另外检查保护区域差异、边界缝、颜色、条件几何与绝对mask坐标，strict compositing的意义也要区别感知coherence。

总时间约为前处理/condition编码+真实步骤成本+codec decode+队列/通信，不普遍等于steps×单次恒定成本。batchsize/并发、ControlNet条数、guidance是否双分支、cache与offload改变step cost；吞吐只在明确稳定批处理/队列条件下由batch/time计算，不能用单图p50倒数或stage p95相加。12B参数四bit的原始权重仅理论约6GB（十进制），还需scales/zero、激活、text encoder、工作区/碎片，不能保证8GB装得下或质量“不可见下降”；CPU offload会转移显存压力但引入host内存/传输等待。量化、compile、adapter hot-swap和solver应先按实际支持与profile验证，不采纳固定1.5倍ControlNet cost、quad headroom或3～5%融合必快。

### 10.1 自查与参考答案

1. index0存第一步noisy，却将它当clean末端，会怎样？**答**：bar_alpha仍<1，DDIM还留下noise；必须匹配纸面t0/数组/模型时间。
2. 40步小β是否有pure Gaussian终态？**答**：此来源约bar_T=.667，仍含明显signal，不满足简单N(0,1)启动假设。
3. q(xprev|xt,x0)高斯能否证明未知x0逆过程精确高斯？**答**：不能，未知x0时是数据后验混合，模型另有近似假设。
4. v_D与flow velocity能直接送同scheduler吗？**答**：不能，前者日程旋转、后者路径导数；需prediction_type/time/scale合同。
5. source w0是否无条件？**答**：其(1+w)c−wu在w0是ordinary conditional，相当本章g1。
6. negative prompt填内容与null一样吗？**答**：不是，baseline改为negative-conditioned预测；不把“unconditional”变量名当数学结论。
7. zero-conv是否identity且只能改善？**答**：投影为零，添加残差使增强模型初始等base；后续质量可能好坏。
8. 第一次side上游grad0意味着模型dead吗？**答**：不一定，zero投影可能先学、随后side有梯度；双因子都零另需检查。
9. mask保护latent能保证pixel不变吗？**答**：decoder邻域/resize/编码可改变pixel，需要最后按保护目标合成与检查。
10. x_s该放q_t(source)吗？**答**：不该，reinjection要匹配s；RePaint forward jump另按bar_t/bar_s计算。
11. 固定配对直线为何完美field一Euler步仍塌中间？**答**：边际field是多个配对条件均值，采样ODE不是单条配对线；解析混合例已验证。
12. rank2能表示rank2Δ就保证训练解出吗？**答**：只有容量必要条件，数据/优化/regularization仍影响；本次拟合数值不能推广。
13. Normalizing-flow图是不是FM训练？**答**：不是，是可逆map与Jacobian密度展示，属于主生成Flow知识。
14. SDEdit strength=.6是否固定中等保真？**答**：不是，日程/solver/条件/对象与解码器共同影响，应扫参数与独立保真检查。

| Control/LoRA Hard | 条件坐标/预处理/branch版本一致，扫structural/prompt/quality预算；原固定.8/.6并非最佳，本批无SD/ControlNet/IP权重。 |
| Inpaint Easy | mask比例、known区时间与最终保护差异同时测，toy维度不是图像边缘metric，不预设某比例等于无条件。 |
| Inpaint Medium | 明确forward jump的from/to时刻、q缩放与resampling次数，再用同initial参考比较；追加noise不等RePaint。 |
| Inpaint Hard | pose/identity/保护区域/接缝分别定义人工与自动协议，检测器也有误差；不把同一prompt当身份gold。本批未下载face数据或模型。 |
| FM Easy | 统一data0/noise1/negative dt，同initial与同场细积分比较，分积分误差与真实分布差异。 |

| FM Hard | 第9节一轮teacher配对→student完整程序核对;报teacher成本、student误差与独立质量，不以4steps有限输出当高质量蒸馏。 |
