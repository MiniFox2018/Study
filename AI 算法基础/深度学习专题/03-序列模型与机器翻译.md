# 03｜序列模型与机器翻译

> 先修：条件概率、MLP、反向传播。先读 1、3～5 节并计算序列概率；门控和机器翻译放到第二轮。

## 1. 序列数据与状态

文本、语音、时间序列和行为日志都具有顺序依赖，不能简单假设样本内部元素独立。

序列预测常写成：

$$
p(x_t\mid x_1,\ldots,x_{t-1})
$$

模型的关键任务是压缩过去信息并用于当前预测。

## 2. 文本预处理

经典 NLP 流程包括：

```text
原始文本
→ tokenization
→ vocabulary
→ token id
→ sequence / mini-batch
```

需要额外处理：

- OOV/UNK；
- 序列截断与 padding；
- 句子边界；
- 子词单元；
- batch 内不同长度。

具体 tokenizer 已变化，但数据管线问题长期存在。

## 3. 语言模型

语言模型对序列联合概率进行分解：

$$
p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t})
$$

经典评估量包括 perplexity：

$$
\operatorname{PPL}=\exp\left(-\frac1T\sum_t\log p(x_t\mid x_{<t})\right)
$$

它是每个有效 token 的平均负对数似然取指数。只在同一测试语料、分词器和统计口径下比较；更换 token 粒度后，PPL 数字不能直接排名。padding 不计入有效 token。

## 4. RNN

基本递推：

$$
h_t=\phi(W_xx_t+W_hh_{t-1}+b)
$$

$$
y_t=W_oh_t+b_o
$$

隐藏状态 (h_t) 作为压缩后的历史记忆。

优势是结构自然；限制是时间步串行以及长距离梯度路径过长。

## 5. BPTT

反向传播穿越时间（BPTT）把 RNN 沿时间展开后应用链式法则。

常见问题：

- 梯度消失；
- 梯度爆炸；
- 长期依赖难学；
- 训练成本随序列长度增长。

梯度裁剪只能抑制爆炸，不能根治长期依赖。

## 6. GRU

GRU 使用更新门和重置门调节状态：

- reset gate 控制旧状态参与候选状态的程度；
- update gate 控制保留旧状态还是写入新状态。

它比 LSTM 结构更简洁，但同样旨在建立稳定的信息通路。

## 7. LSTM

LSTM 使用 cell state 与多个门：

- forget gate；
- input gate；
- output gate。

关键思想不是门的名称，而是：

> 通过近似线性的状态通路，让信息和梯度能够跨更长时间尺度传递。

## 8. 深层与双向 RNN

### Deep RNN

在同一时间步堆叠多个循环层，提升表示容量。

### Bidirectional RNN

同时利用过去和未来上下文，适用于整段输入已知的理解任务。

它不适合严格因果的在线生成，因为未来信息在推理时不可用。

## 9. Encoder–Decoder

面对输入输出长度不同的序列任务，可以抽象为：

```text
source
→ Encoder
→ context / representation
→ Decoder
→ target sequence
```

这一抽象后来继续存在于 Transformer encoder-decoder、语音识别和多模态系统中。

## 10. Seq2Seq

经典 RNN Seq2Seq 将 encoder 状态传入 decoder，自回归生成目标序列。

训练通常使用 teacher forcing，即解码时喂入真实上一 token；推理时只能使用模型自己生成的 token，因此会出现 exposure bias。

## 11. 机器翻译数据处理

机器翻译任务的重要工程点：

- source/target 分词；
- BOS/EOS；
- padding mask；
- 不同长度样本；
- loss 只在有效 token 上计算。

这些原则在现代生成模型训练中仍完全成立。

## 12. Beam Search

贪心解码每一步只选局部最优 token；Beam Search 同时保留多个候选序列。

需要理解：

- beam width；
- 累积 log probability；
- 长度偏置；
- 搜索更强不等于模型本身更强。

LLM 时代常结合 sampling、top-k、top-p 等生成策略，但序列搜索的基本权衡不变。

## 13. RNN 今天还有什么价值

Transformer 已取代大量 RNN 场景，但 RNN 仍有三类长期价值：

1. 理解状态空间和序列递归；
2. 低延迟 streaming / 小模型任务；
3. 作为现代 state-space、recurrent memory 方法的概念基础。

## 计算两步序列概率

真实序列有两个 token，模型给它们的条件概率分别为 0.5 和 0.25。联合概率为 $0.5\times0.25=0.125$，平均负对数似然为 $-(\log0.5+\log0.25)/2\approx1.0397$，PPL 为 $\sqrt8\approx2.8284$。

自查：为什么不能直接平均概率得到 0.375 后再取倒数作为 PPL？**答案：**PPL 由平均对数损失定义，对应概率的几何平均而不是算术平均。

训练检查：输入 `[开始符, 我, 爱]` 对应目标 `[我, 爱, 你]`，整体错位一位；padding 对应位置屏蔽损失。若输入和目标完全相同且可看当前位置，模型可能学会复制而没有学会下一 token 预测。
