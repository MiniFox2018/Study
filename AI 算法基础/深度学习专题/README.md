## 实现时效规则

D2L 中文仓库当前基线停留在 2023 年，因此：

- 数学、算法、模型结构、训练思想：保留；
- PyTorch / TensorFlow / MXNet / Paddle 的旧 API：不固化；
- GPU、分布式、云服务和安装命令：只保留原理，实际执行前查当前官方文档；
- 历史 benchmark：只用于理解方法演进，不作为 2026 年选型依据；
- `*_origin.md`、站点构建、CI、翻译和排版文件：不进入知识库。

## 学习方法

每个专题优先回答四个问题：

1. 这个方法解决什么问题？
2. 它依赖什么数学/统计假设？
3. 训练失败时最常见的原因是什么？
4. 今天哪些思想仍被现代模型继承？

这样可以从“会调用框架”升级到“理解模型、能诊断、能迁移”。
