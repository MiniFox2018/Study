## 实现时效规则

保留：

- 数学、概率、优化；
- 训练与泛化原理；
- 网络结构；
- 生成模型；
- 强化学习；
- 理论与 Responsible AI；
- 可复用实验方法。

不固化：

- 旧框架 API；
- 旧依赖/安装命令；
- 历史硬件 benchmark；
- 早期模型能力数字；
- 已有 issue 的 Notebook 运行错误。

## 学习方法

每个专题优先回答：

1. 这个方法解决什么问题？
2. 数学假设是什么？
3. 为什么这样训练？
4. 最常见失败模式是什么？
5. 与相邻方法的取舍是什么？
6. 今天哪些思想仍被现代系统继承？

目标是从“会调用模型”升级到“能推导、能诊断、能选择、能迁移”。
