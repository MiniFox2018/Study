## 没有做什么

### 没有镜像 304 篇教程

原因：大量教程绑定旧模型、旧依赖和旧硬件环境。机械复制会直接违反 Study 的“过时内容不进入主知识库”规则。

### 没有保存旧模型安装命令

例如早期：

- ChatGLM；
- Qwen 1.x；
- Baichuan；
- 旧 InternLM；

这些教程只用于归纳长期工程模式。

### 没有保存瞬时 benchmark

具体 GPU、特定版本下的 tokens/s 和显存数据具有强时效性。

### 没有复制图片和 Notebook

本轮目标是知识吸收，不是上游工程仓库备份。

如果后续要复现某个具体模型/实验，再按该模型当前版本单独吸收代码。

## 本轮吸收结论

`self-llm` 的最大价值不是“50+ 模型菜单”，而是重复出现并被多个模型验证的一套工程模式：

```text
获取模型
→ 环境隔离
→ 原生推理
→ 服务化
→ 高吞吐推理
→ 数据构造
→ PEFT / Full FT
→ DPO / GRPO
→ 评测 / 压测
→ 实验跟踪
→ 多硬件适配
→ 应用闭环
```

这些模式已写入本目录。
