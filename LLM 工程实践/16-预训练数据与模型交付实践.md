# 16｜预训练数据与模型交付实践

本章把输入语料、样本、训练、恢复与交付连接起来。Token算法和模型结构分别由[Tokenizer主入口](../LLM%20基础/02-文本-Tokenizer与Embedding.md)、[完整Transformer](../AI%20算法基础/深度学习专题/19-Transformer实现与训练实践.md)维护；SFT/偏好目标由[微调](04-微调与参数高效适配.md)/[偏好优化](05-偏好优化与强化学习.md)维护。本章保留独立CPU程序，因为只有一份manifest或目录并不能证明数据/梯度/恢复真正工作。

## 1. 先划清数据对象与学习目标

每条原始文档至少记录document ID、来源/取得日期、格式/语言或待核状态、原始内容SHA、清洗版本与派生内容SHA、文档族/group ID和split。原文、清洗文本、Token shard、训练batch、checkpoint、eval report是不同对象；改清洗或Tokenizer会改变下游输入，不应继续沿用旧Token文件。

网页、代码、书籍、论文、问答和合成文本提供不同分布。来源名不是质量标签；网页不必全垃圾，Wikipedia/书籍也不必每句正确。按任务检查内容、重复/时间/事实/格式、数据许可和可使用范围，保存抽样与剔除理由。源固定规模、语言比例和训练mix不能当各团队或所有年代的真配方；与架构、预算、可学参数及评测共同决定取舍。

划分通常先按用户/文档族/来源时间等实际独立单位分train/development/test，再生成窗口。不要先把同一文档切成重叠片段再随机分split。Tokenizer和频率/PPL参考模型仅从允许的训练数据fit；阈值可在development上调，锁定测试不能不断回流。去重族可跨split检查，同一族留在一侧；仅无精确hash相同不能证明无改写、答案或题目污染。

Chinchilla是在相应实验分布与固定训练compute下拟合模型/数据扩展关系，大致同时增加二者；不是“参数大十倍、数据多十倍便同loss”定理。服务成本目标可能偏好较小模型多训数据，重复epoch与新增独立数据也不等价。继续预训练、SFT或RAG按目标区别选择，不要求每个项目从Tokenizer→巨大预训练→RLHF→DPO→CAI全走一次。[训练compute研究](https://arxiv.org/html/2203.15556v1)

## 2. 清洗、语言与质量过滤：保留信息，再校准规则

HTML正文提取应区分标签、script/style与真实内容，保留段落边界、表格/代码所需结构和出处。正则删`<...>`不是完整页面提取器，还可能把两个段落串成一个词。自然文档可规范空白；代码中的缩进和运算符不能沿用同一规则。源`[^\x20-\x7E]`清洗会删除中文、emoji和其它Unicode，不是通用“去非文本”。

字符集统计只是语言提示，短文、代码和混合语言常不可靠；language model置信分数不必已校准成正确概率。长度、ALL CAPS、特殊字符比例、重复行和PPL是启发，每阶段同时抽查保留与删除样本，并按语言/领域切片报告误删。数学公式和有效代码可能标点多，数值答案可很短，不能硬套“50词/特殊字符<10%”定义有效知识。

PPL过滤衡量文本与参考LM分布接近程度，不是事实正确性：冷门术语、多语言或新领域也可能高PPL。使用相同Tokenizer/窗口/有效分母，训练参考模型只用train，明确定义“移除最高PPL的某个分位”或其它score方向。源把RefinedWeb归为Wikipedia小LM/PPL过滤的配方不能直接当原实现；其文档质量过滤/去重依具体研究流程，PPL是另一个可实验方法。完整n-gram/PPL程序在[文本预处理与稀疏表示](../AI%20算法基础/语言与文本专题/01-文本预处理与稀疏表示.md)，不在这里重复一套LM。

### 2.1 HTML提取、精确去重与MinHash/LSH的完整小例

MinHash先构造shingle集合S，再对每个独立hash取集合最小值。理想随机排列下两个签名位相同概率等于Jaccard：$J(S_1,S_2)=|S_1\cap S_2|/|S_1\cup S_2|$。b个band、每band r行时，近似候选概率为$1-(1-J^r)^b$；这是独立性假设下的概率，不保证所有近重复都召回。候选再算精确J，LSH只省候选，不把近似签名当最终真值。

本例使用salted SHA作为教学hash族，不复刻随机排列的精确理论；signature长度必须等于b×r，不丢余数。短文不足k时用整个非空短序列作一项，空文不进入MinHash。重复族按图连接分组用于split；删除时仅按固定代表的直接相似阈值，不将传递链当全员语义相同。

```python
import re
import json
import hashlib
import unicodedata
from html.parser import HTMLParser
from collections import defaultdict

class ArticleText(HTMLParser):
    def __init__(self):super().__init__(convert_charrefs=True);self.parts=[];self.blocked=0
    def handle_starttag(self,tag,attrs):
        if tag in ['script','style']:self.blocked+=1
        elif not self.blocked and tag in ['p','div','br','li','h1','h2']:self.parts.append('\n')
    def handle_endtag(self,tag):
        if tag in ['script','style']:self.blocked=max(0,self.blocked-1)
        elif not self.blocked and tag in ['p','div','li','h1','h2']:self.parts.append('\n')
    def handle_data(self,data):
        if not self.blocked:self.parts.append(data)

def clean_natural(text,is_html=False):
    if type(text) is not str:raise ValueError('文本类型')
    if is_html:
        p=ArticleText();p.feed(text);p.close();text=''.join(p.parts)
    # 只用于自然文本；代码等另选保缩进方案，原文应另外保存。
    return ' '.join(unicodedata.normalize('NFC',text).split())

def shingles(text,k=5):
    if type(k) is not int or k<1:raise ValueError('正shingle长度')
    words=text.casefold().split()  # 本例word口径；中文无空格需另设char/词切分。
    if not words:return set()
    if len(words)<k:return {tuple(words)}
    return {tuple(words[i:i+k]) for i in range(len(words)-k+1)}

def minhash(s,n=32):
    if type(n) is not int or n<1:raise ValueError('正签名长度')
    if not s:raise ValueError('空集合不作同一个重复族')
    return tuple(min(int(hashlib.sha256(json.dumps([i,list(x)],ensure_ascii=False).encode()).hexdigest(),16) for x in s) for i in range(n))

def candidates(signatures,bands=8):
    if type(bands) is not int or bands<1 or any(len(s)==0 or len(s)%bands for s in signatures):raise ValueError('完整band分组')
    buckets=defaultdict(list);pairs=set()
    for i,s in enumerate(signatures):
        r=len(s)//bands
        for b in range(bands):buckets[(b,s[b*r:(b+1)*r])].append(i)
    for ids in buckets.values():
        for n,i in enumerate(ids):
            for j in ids[n+1:]:pairs.add((min(i,j),max(i,j)))
    return sorted(pairs)

def dedup(records,threshold=.8):
    if not 0<=threshold<=1 or len({d['id'] for d in records})!=len(records):raise ValueError('阈值范围/唯一document ID')
    exact={};unique=[];removed=[]
    for record in sorted(records,key=lambda d:d['id']):
        clean=clean_natural(record['text'],record.get('html',False))
        if not clean:removed.append((record['id'],'empty'));continue
        digest=hashlib.sha256(clean.encode()).hexdigest()
        if digest in exact:removed.append((record['id'],'exact:'+exact[digest]));continue
        exact[digest]=record['id'];unique.append(dict(record,clean=clean,clean_sha=digest))
    sets=[shingles(d['clean']) for d in unique];sigs=[minhash(s) for s in sets]
    verified={};parent=list(range(len(unique)))
    def find(i):
        while parent[i]!=i:parent[i]=parent[parent[i]];i=parent[i]
        return i
    for i,j in candidates(sigs):
        sim=len(sets[i]&sets[j])/len(sets[i]|sets[j])
        if sim>=threshold:
            verified[i,j]=sim;ri,rj=find(i),find(j);parent[max(ri,rj)]=min(ri,rj)
    kept=[]
    for j,d in enumerate(unique):
        match=next((i for i in kept if (min(i,j),max(i,j)) in verified),None)
        if match is None:kept.append(j)
        else:removed.append((d['id'],'near:'+unique[match]['id']))
    families={d['id']:unique[find(i)]['id'] for i,d in enumerate(unique)}
    return [unique[i] for i in kept],removed,families

base='the small cat sits on the warm mat beside the red door'
records=[{'id':'a','text':base},{'id':'b','text':base},{'id':'c','text':base+' today'},
         {'id':'d','text':'<p>保留中文与段落。</p><script>删除脚本</script><p>第二段。</p>','html':True},
         {'id':'e','text':'独立短文'}]
kept,removed,families=dedup(records)
assert any(d['id']=='d' and '保留中文' in d['clean'] and '删除脚本' not in d['clean'] for d in kept)
assert ('b','exact:a') in removed
assert len(shingles('独立短文'))==1
assert ''.join(ArticleText().parts)==''
print('保留IDs',[d['id'] for d in kept],'删除原因',removed,'近重复family',families)
print('J=.5/.8，b8×r4候选概率',[1-(1-j**4)**8 for j in [.5,.8]])
```

SHA证明内容身份和损坏检查，不证明文本真实、来源可信或有训练权限。casefold/空白归一也可能改变代码或大小写含义，本程序合同仅自然文本。LSH漏召回、短文变体与跨语言相似仍需抽查；同bucket全部文档会产生最坏O(n²)候选，不能称任何数据上都近线性。相似但不同数值/否定的文档不一定该删除。源“去重少于20%必参数过保守”和“误候选应降Jaccard门槛”都不是可靠诊断，后者还可能增加误删。

## 3. 有界流、shuffle、shard与样本边界

真正streaming迭代读取文档或已tokenize shard，每次只保有限buffer/当前batch，不先将TB全拼进`all_tokens`列表。Shuffle buffer B先容纳B项，每读新项随机替换并yield一个，末尾随机排空；它保样本、内存有界，但不是整语料等概率全排列。多worker要分片而非每个worker重读同一流，并记录worker数、源shard顺序、epoch、buffer、seed和消费位置。

Token shard需明确整数dtype、最大ID、endian、文档offset/长度、Tokenizer hash与split；小词表可用uint16，大ID会溢出，不能凭模型名猜dtype。Memmap和预取可减少拷贝/等待，但吞吐要实际测读取/清洗/编码/packing/host-device耗时；不同硬件/语言没有固定10倍、100M token/s每核心的保证。

### 3.1 BOS/EOS、跨文档目标与attention的完整程序

本例为每文档加BOS/EOS，PAD0独立，普通byte ID有offset8（NUL为8）。程序返回x/y与document ID；label已右移，只计算真实下一token且属于同一文档。EOS被预测一次，但EOS→下一文档BOS不计loss。允许矩阵定义为True可见，框架若True代表blocked需反转。选择document-isolated attention或全流causal是两种训练目标；EOS只提供学习到的边界标记，不会自动隔离注意力。

```python
import random
from itertools import chain
import numpy as np

PAD,BOS,EOS,OFFSET=0,1,2,8

def buffered_shuffle(items,buffer_size,seed):
    if type(buffer_size) is not int or buffer_size<1:raise ValueError('正buffer')
    rng=random.Random(seed);buffer=[]
    for item in items:
        if len(buffer)<buffer_size:buffer.append(item)
        else:
            i=rng.randrange(len(buffer));yield buffer[i];buffer[i]=item
    rng.shuffle(buffer)
    yield from buffer

def packed_windows(documents,window=8):
    if type(window) is not int or window<1:raise ValueError('正窗口')
    # 不建全语料token list；pending最多window+1，另保当前文档的UTF-8 bytes。
    pending=[]
    for doc_id,text in enumerate(documents):
        if type(text) is not str:raise ValueError('文档应为str')
        for token in chain((BOS,), (OFFSET+b for b in text.encode('utf-8')), (EOS,)):
            pending.append((token,doc_id))
            if len(pending)==window+1:
                yield make_window(pending,window)
                pending=pending[-1:]  # 上一行末token成为下一行context，目标不重复计。
    if len(pending)>=2:yield make_window(pending,window)

def make_window(pairs,window):
    tokens=np.array([x for x,d in pairs]);docs=np.array([d for x,d in pairs])
    n=len(tokens)-1;x=np.full(window,PAD,dtype=int);y=np.full(window,-100,dtype=int);groups=np.full(window,-1,dtype=int)
    x[:n]=tokens[:-1];groups[:n]=docs[:-1]
    same=docs[:-1]==docs[1:];y[:n]=np.where(same,tokens[1:],-100)
    causal=np.arange(window)[:,None]>=np.arange(window)[None,:]
    isolated=causal&(groups[:,None]==groups[None,:])&(groups[None,:]>=0)
    # PAD query只允许看自己，使实现没有全blocked的softmax行；其输出不计loss。
    for i in range(n,window):isolated[i,i]=True
    assert isolated.any(1).all()
    return {'x':x,'y':y,'document_ids':groups,'allowed':isolated,'valid_input':np.arange(window)<n}

order=list(buffered_shuffle(range(17),4,3));assert sorted(order)==list(range(17))
assert order==list(buffered_shuffle(range(17),4,3))
windows=list(packed_windows(['ab','中\x00',''],window=8))
for row in windows:
    x,y,g,allowed=row['x'],row['y'],row['document_ids'],row['allowed']
    for i in range(len(x)):
        for j in range(len(x)):
            if g[i]>=0 and allowed[i,j]:assert j<=i and g[i]==g[j] and g[j]>=0
    assert np.all(y[~row['valid_input']]==-100)
    print('x/y/groups',x.tolist(),y.tolist(),g.tolist(),'有效targets',int((y!=-100).sum()))
assert sum((r['y']!=-100).sum() for r in windows)==sum(len(t.encode())+1 for t in ['ab','中\x00',''])
assert any(OFFSET in r['x'] for r in windows) and PAD!=OFFSET
print('有限shuffle保全部元素、targets不重复、文档隔离与NUL/PAD合同通过')
```

本实现接收完整单文档str，编码会暂存这一文档的UTF-8 bytes；内存界还取决于最大单文档，不声称所有输入下只占一个window。若需分块读取单个超大文件，应保UTF-8解码状态与文档offset。

空文在此有BOS→EOS一个目标；若任务不接收空文，应在上游过滤并记录，不让空文被当正常知识。切块可能截断前文，跨块长文训练需要明确保多少context/位置如何重置；本例上下文只保最后一个token，因此证明覆盖与边界，不提供长距离语言能力。packing高利用率不等高学习质量，也不等没有跨doc泄漏。

## 4. 真正训练、恢复与SFT的完整CPU小模型

下面固定字节词表，不从验证集fit任何merge/统计；人工文法是ABCD循环，文档ID不同、完整train/validation字符串不重叠。两层pre-LN decoder、可学位置、GELU、tied输出与AdamW都有真实autograd。模型的详细Attention/反向原理由已有主章维护，此处实现的目的在于串起**数据→有效loss→更新→checkpoint→精确续跑→SFT对照→完整生成评价**。

每次optimizer step聚合两micro-batch的loss总和/有效token总数，warmup/cosine按optimizer步数走。Checkpoint在完整更新边界保存，包含model/optimizer、下一步、数据采样generator与Torch RNG、结构、Tokenizer/数据SHA、调度配置；加载后先核元数据，再恢复状态。不是只保存weights后重新造optimizer继续算“同一轨迹”。本例无dropout且CPU固定版本，可核对下一步逐参数相同；这不承诺其它硬件/内核的bit-identical。

SFT任务仅“给A/B/C/D，答循环中的下一个字母”，模板中有独立role/EOT ID，监督回答内容+EOT；raw训练case0～47、raw验证48～63、SFT训练0～15，SFT验证64～71跨阶段留出。训练阶段可有意复用同域case，但锁定验证case不回流；SFT/eval各自有独立SHA，raw DATA_HASH保持原始对象定义。纯SFT与5% raw-example混合从同一base权重开始，另报实际raw目标比例。任务/验证的文档ID不同，但同属人工文法，成功不能叫自然语言通用泛化、真实知识学习或用户已经掌握。

```python
import math
import json
import copy
import hashlib
import tempfile
from pathlib import Path
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1);torch.manual_seed(21)
PAD,BOS,EOS,SYS,USR,ASST,EOT,OFFSET,V=0,1,2,3,4,5,6,8,264
CFG={'vocab':V,'dim':32,'heads':4,'layers':2,'context':64}
TOKENIZER={'scheme':'utf8-byte','offset':OFFSET,'special_ids':[PAD,BOS,EOS,SYS,USR,ASST,EOT],'normalization':'none'}
def digest_json(obj):return hashlib.sha256(json.dumps(obj,sort_keys=True,separators=(',',':')).encode()).hexdigest()
def bytes_ids(text):return [OFFSET+b for b in text.encode('utf-8')]
class TinyGPT(nn.Module):
    def __init__(self,cfg):
        super().__init__();self.cfg=cfg.copy();d=cfg['dim']
        if d%cfg['heads']:raise ValueError('head整除')
        self.embedding=nn.Embedding(cfg['vocab'],d,padding_idx=PAD)
        self.position=nn.Embedding(cfg['context'],d)
        self.blocks=nn.ModuleList([nn.TransformerEncoderLayer(d,cfg['heads'],4*d,dropout=0.,activation='gelu',batch_first=True,norm_first=True) for _ in range(cfg['layers'])])
        self.final_norm=nn.LayerNorm(d)
        def init(m):
            if isinstance(m,(nn.Linear,nn.Embedding)):
                nn.init.normal_(m.weight,std=.02)
                if isinstance(m,nn.Linear) and m.bias is not None:nn.init.zeros_(m.bias)
                if isinstance(m,nn.Embedding) and m.padding_idx is not None:
                    with torch.no_grad():m.weight[m.padding_idx].zero_()
        self.apply(init)
        for b in self.blocks:nn.init.normal_(b.self_attn.in_proj_weight,std=.02);nn.init.zeros_(b.self_attn.in_proj_bias)
    def forward(self,ids):
        if ids.dtype!=torch.long or ids.ndim!=2 or not ids.shape[1] or ids.shape[1]>self.cfg['context'] or (ids<0).any() or (ids>=self.cfg['vocab']).any() or (ids==7).any():raise ValueError('输入ID/长度合同')
        valid=ids!=PAD
        if not valid.any(1).all() or (valid[:,1:]&~valid[:,:-1]).any():raise ValueError('非空右padding序列')
        t=ids.shape[1];h=self.embedding(ids)+self.position(torch.arange(t))[None]
        blocked=torch.triu(torch.ones(t,t,dtype=torch.bool),diagonal=1)
        for block in self.blocks:h=block(h,src_mask=blocked,src_key_padding_mask=~valid)
        return F.linear(self.final_norm(h),self.embedding.weight)

def raw_example(text):
    tokens=[BOS]+bytes_ids(text)+[EOS]
    return {'x':tokens[:-1],'y':tokens[1:]}
def collate(examples):
    if not examples:raise ValueError('空batch')
    t=max(len(e['x']) for e in examples)
    if not 0<t<=CFG['context']:raise ValueError('batch长度超合同，不静默截断')
    x=torch.full((len(examples),t),PAD,dtype=torch.long);y=torch.full_like(x,-100)
    for i,e in enumerate(examples):
        n=len(e['x'])
        if n!=len(e['y']) or not n:raise ValueError('x/y对齐')
        x[i,:n]=torch.tensor(e['x']);y[i,:n]=torch.tensor(e['y'])
    if not (y!=-100).any():raise ValueError('无有效监督')
    return x,y

def ce_sum(model,x,y):return F.cross_entropy(model(x).reshape(-1,V),y.reshape(-1),ignore_index=-100,reduction='sum')
@torch.no_grad()
def evaluate(model,data):
    was_training=model.training;model.eval();nll=0.;count=correct=0
    for i in range(0,len(data),8):
        x,y=collate(data[i:i+8]);logits=model(x);mask=y!=-100
        nll+=float(F.cross_entropy(logits.reshape(-1,V),y.reshape(-1),ignore_index=-100,reduction='sum'))
        count+=int(mask.sum());correct+=int(((logits.argmax(-1)==y)&mask).sum())
    model.train(was_training)
    if count==0:raise ValueError('评测无targets')
    return {'nll':nll/count,'ppl':math.exp(nll/count),'teacher_accuracy':correct/count,'targets':count}

def lr_at(step,total,peak):
    warmup=5
    if step<warmup:return peak*(step+1)/warmup
    frac=(step-warmup)/max(1,total-warmup-1)
    return peak*(.1+.9*.5*(1+math.cos(math.pi*min(1,frac))))
```

## 5. Manifest、产物身份与交付决定

模型交付至少包含权重、结构/位置/mask配置、Tokenizer/模板、数据/训练recipe版本、输入输出合同、运行环境、候选模型SHA与绑定的eval报告；继续训练还需optimizer/scheduler、RNG和采样/流位置。Quantized权重须在量化**之后**重新评价该候选，不能拿量化前base报告替代；校准数据和方法版本一并记录。实际推理框架、量化和大模型加载由其它工程章维护，本例未跑真实服务。

Manifest描述这些关联及stage DAG，而不是只给12个来源课程名。数据依赖、训练recipe和模型结构配置应在训练前确定；SFT、DPO/RLHF、CAI等按目标选择，可作候选对照，不需要两种policy先强行合并再继续。一个DPO模型再SFT也可作为有意研究，类型字段不会自动让这种操作“编译失败”。

Content-addressed hash用于身份/完整性，不证明质量。每次get重算实际bytes hash、检查类型/schema与输入依赖；cache key应包含stage语义、recipe、代码版本、schema和**命名输入**的SHA。文件还存在不代表未损坏，名字`latest`可以作便利指针，但解析到已核对的不可变版本后再使用。

重放的bit-identical与指标等效是两个要求。若weights字节不同，output SHA也不同；记录各自实际SHA和同一协议下的误差/指标容忍，不能一边说hash全相同、一边说权重可不同。非确定性导致变化多少须实测，不保证只差1e−5或最终分数永不改变。

### 5.1 DAG、缓存失效、完整性与失败gate的可运行原型

本例处理**规格JSON与人工eval fixture**，不把JSON称实际checkpoint。真实训练可由上节返回权重/元数据后接同样合同。代码完整验证缺依赖/循环、命名输入类型、缓存key、get时rehash、实际预算、必需stage/本轮input/output记录一致及候选/数据逐次rehash绑定；失败保留原因。数据/模型规格缓存可复用，改变eval recipe只重做eval，改变模型recipe会使模型及其后代失效。

## 6. 质量、成本与观测记录的单位

交付gate先确定任务/切片/失败率、baseline差异与不确定性，绑定候选SHA、数据/评分器/模板和资源配置。形式上都是数字也不等规则合理：良性请求误拒与有害请求遵从分开，拒绝率低不自动表示安全；KL阈值须说明分布和单位，不能固定25便推正确性。人工复核、unknown和严重错误规则也可以成为明确可审查的条件，不强制“禁止任何主观评价”。本批micro SFT只有25%完整正确，应报告未达到示例任务阈值，不能因loss下降自动交付。

Dense Transformer的粗训练量级$C≈6ND$（参数N、训练token D）是忽略/近似部分开销的估算，长注意力、MoE活跃参数、序列/重算/优化器及并行通信可改变成本。若估算使用GPU峰值F、MFU m，GPU-hours≈C/(F m×3600)；峰值的dtype/稀疏口径、硬件和实际利用率要一致，不重复把MFU当额外GPU数量。训练、数据处理、失败重跑、研发与服务成本分开。

## 8. 可恢复语料下载：对象身份与已提交前缀

大文件下载解决的是“有限内存取得完整、同一版本的字节”，不是“HTTP请求正常结束便有完整训练集”。先保存取得入口/修订、强ETag等可靠对象版本、表示编码、压缩文件的总长度及可信完整SHA。读取响应体时使用固定上限的块，流式写盘；文档、解压后JSONL、去重后保留文档与Token shard分别产出并核验。传输层Content-Encoding和文件本身gzip/zstd格式也不同，Range偏移必须对应同一表示的字节，不能用解压后的文本位置续接压缩文件。

### 8.1 Range响应怎样决定恢复

恢复以checkpoint中的**已提交偏移**为准。先核本地前缀SHA，实际文件若多出尚未提交的尾部，将其截断；短于已提交长度或前缀不一致则拒绝恢复。以这个偏移发送Range，并用If-Range绑定同一强validator。弱ETag不适合此处的强版本比较。收到206也不能立即追加：解析Content-Range的起点、终点、总长，要求起点等于请求偏移、总长/版本与计划一致，并核实际响应体长度等于终点减起点加一。服务器可以返回一个较短的合法区间，继续请求直到完整总长；有限超时和重试不应把半段响应视为完整提交。

200通常表示返回完整表示，特别是If-Range失配时；把它追加到旧前缀会产生“旧半文件+新完整文件”。应保留诊断后从新临时文件重启。416表示请求范围无法满足；即使本地偏移恰等总长，也须重新核同一对象与完整SHA才能认定完成，不能只看状态码。结束时还要核完整长度、SHA和解压格式完整性；EOF只能证明连接已结束。协议依据为2026-10-11实际选读的[RFC 9110 If-Range、Range与Content-Range](https://www.rfc-editor.org/rfc/rfc9110.html)。

数据提交可设计为：写入块 → flush/fsync数据文件 → 写入新的checkpoint临时文件并fsync → 原子替换checkpoint → fsync所在目录。新checkpoint只记录已经持久化的前缀；若在数据落盘后、偏移发布前中断，下次截掉多余尾部再请求。另一选择是真正的write-ahead log，但日志必须有可重放的字节和事务规则；先把将来才写的内容标成“verified”不是WAL。多文件提交和不同文件系统的持久性另有条件，单次replace不替代它们。

### 8.2 无网络的响应与中断反例

下面是完整标准库合同程序：HTTP响应是本地字节fixture，没有发请求；data和checkpoint是内存中的“已持久化状态”模型，没有测文件系统fsync。输入为固定版本八字节对象、四字节已提交前缀，输出是成功续接和被拒绝的失配。它刻意使数据比旧checkpoint多两字节，以检验恢复截尾。它不实现HTTP客户端、压缩解码器或真实耐久存储。

```python
import re
import hashlib

sha = lambda value: hashlib.sha256(value).hexdigest()
expected = b"abcdefgh"
plan = {"etag": '"rev1"', "total": 8, "sha": sha(expected)}
checkpoint = {"offset": 4, "prefix_sha": sha(expected[:4])}

def valid_sha(value):
    return type(value) is str and re.fullmatch(r"[0-9a-f]{64}", value) is not None

def validate_pin(pin):
    if (type(pin) is not dict or set(pin) != {"etag", "total", "sha"}
        or type(pin["etag"]) is not str
        or re.fullmatch(r'"[^"\x00-\x20\x7f]+"', pin["etag"]) is None
        or type(pin["total"]) is not int or pin["total"] <= 0
        or not valid_sha(pin["sha"])):
        raise ValueError("固定可信pin的强ETag/长度/SHA")

def recover(data, cp, pin):
    validate_pin(pin)
    if (type(data) is not bytes or type(cp) is not dict
        or set(cp) != {"offset", "prefix_sha"} or not valid_sha(cp["prefix_sha"])):
        raise ValueError("本地字节/checkpoint字段")
    offset = cp["offset"]
    if type(offset) is not int or not 0 <= offset <= pin["total"] or len(data) < offset:
        raise ValueError("本地长度小于已提交偏移")
    if sha(data[:offset]) != cp["prefix_sha"]:
        raise ValueError("已提交前缀损坏")
    return data[:offset]  # 未提交尾部不能当已完成字节。

def append_response(data, status, etag, content_range, body, pin):
    validate_pin(pin)
    if (type(data) is not bytes or type(body) is not bytes
        or type(status) is not int or type(content_range) is not str
        or len(data) > pin["total"]):
        raise ValueError("响应类型/本地范围")
    if type(etag) is not str or etag != pin["etag"]:
        raise ValueError("对象版本变化")
    if status != 206:
        raise ValueError("仅合法206允许追加；200重启，416另核完成")
    match = re.fullmatch(r"bytes (\d+)-(\d+)/(\d+)", content_range)
    if not match:
        raise ValueError("Content-Range格式")
    start, end, total = map(int, match.groups())
    if not (start == len(data) and start <= end < total == pin["total"]):
        raise ValueError("区间起点/终点/总长")
    if len(body) != end - start + 1:
        raise ValueError("响应体长度")
    candidate = data + body
    if len(candidate) == total and sha(candidate) != pin["sha"]:
        raise ValueError("完整对象SHA")
    # 模型中先提交data，随后才发布新cp；真实实现另需文件/目录fsync。
    return candidate, {"offset": len(candidate), "prefix_sha": sha(candidate)}

prefix = recover(expected[:6], checkpoint, plan)

result, committed = append_response(prefix, 206, '"rev1"', "bytes 4-7/8", b"efgh", plan)
assert result == expected and committed["offset"] == 8
bad_cases = [
    ("200不能追加", 200, '"rev1"', "", expected),
    ("416不等完成", 416, '"rev1"', "bytes */8", b""),
    ("版本改变", 206, '"rev2"', "bytes 4-7/8", b"efgh"),
    ("错起点", 206, '"rev1"', "bytes 3-6/8", b"defg"),
    ("错总长", 206, '"rev1"', "bytes 4-7/9", b"efgh"),
    ("短响应", 206, '"rev1"', "bytes 4-7/8", b"ef"),
    ("同长损坏", 206, '"rev1"', "bytes 4-7/8", b"xxxx"),
]
for label, status, etag, header, body in bad_cases:
    try:
        append_response(prefix, status, etag, header, body, plan)
    except ValueError:
        pass
    else:
        raise AssertionError(label)
try:
    recover(b"abXd", checkpoint, plan)
except ValueError:
    pass
else:
    raise AssertionError("损坏前缀")
# 输入对象不被函数修改；无效状态即使data很长也不得越过pin总长。
invalid_pins = [
    dict(plan, etag=None), dict(plan, etag='W/"rev1"'),
    dict(plan, etag=""), dict(plan, etag='""'),
    dict(plan, total=True), dict(plan, total=0), dict(plan, sha="invalid"),
]
invalid_states = [
    {"offset": 9, "prefix_sha": sha(b"abcdefghi")},
    {"offset": True, "prefix_sha": sha(b"a")},
    {"offset": 4, "prefix_sha": "invalid"},
]

    saved = bad_pin.copy()
    try:
        recover(expected, checkpoint, bad_pin)
    except ValueError:
        pass
    else:
        raise AssertionError("无效pin")
    assert bad_pin == saved and checkpoint["offset"] == 4
for bad_cp in invalid_states:

        recover(b"abcdefghi", bad_cp, plan)
    except ValueError:
        pass
    else:
        raise AssertionError("无效checkpoint")
    assert bad_cp == saved
for etag, status, body in [(None, 206, b"efgh"), ('W/"rev1"', 206, b"efgh"),
                          ('"rev1"', True, b"efgh"), ('"rev1"', 206, "efgh")]:

    except ValueError:

    else:
```

### 8.3 去重索引与下载manifest接在什么位置

复用§2.1的MinHash/LSH与精确Jaccard程序。128签名、32个band、每band4行时，候选概率为 $P(s)=1-(1-s^4)^{32}$，s为shingle集合Jaccard。近似尺度 $32^{-1/4}\approx0.420448$，而50%候选点 $[1-2^{-1/32}]^{1/4}\approx0.382600114$；s=.8时候选概率约.999999952501。三个数字都不是删除阈值；删除仍需单独复核相似度和内容差异。按第一个band选单一分区会漏掉其余band的碰撞，分布式/持久索引必须路由全部band。

保存keeper、被删文档ID、文档族、split、规则版本、候选及最终剔除理由，使后续阈值变更可以追查。Tombstone只保存引用不等于能复原已丢弃原文；它自身和索引也占随文档数增长的内存。先去重常节约Tokenizer工作，但相似文档中的否定、数字变化或任务权重可能有价值，不能证明前置删除在所有目标下严格更好。

Manifest绑定每shard真实bytes的长度/SHA、格式与完成状态，并输出供下一阶段使用的**保留文档流**，不能只有duplicate_count而原压缩文件仍含重复内容。manifest.lock应来自独立可信修订或签名；能同时修改manifest与lock者可制造表面一致的伪记录。生产流程在入口读锁并失败关闭，写锁本身没有执行门禁。实现还需正整数chunk大小、有限超时/最大响应长度、唯一合法shard ID与输出根目录约束；checkpoint字段拒绝bool计数或宽松字符串转换，路径不能由未验证metadata任意指定。

**下载五项改动练习及判据。** ① 在标注的近重复/无关、代码/自然语言样本上比较shingle宽度3/5/9，报告召回、误删、候选数和复核成本后选默认，不预设哪个更好。② 按magic bytes区分gzip/zstd，保留嗅探时已读前缀，核多frame、结尾完整性和解压体积上限，不把HTTP编码当文件格式。③ resume-only必须要求有效checkpoint、同对象和已提交前缀，缺失/失配直接停并保原因，不能悄悄重拉大文件。④ 用SQLite等持久化所有band索引，测恢复一致性、内存、IO和候选复核吞吐；只迁移首band桶不满足召回合同。⑤ 启动时核可信manifest锁、每shard身份/大小/完成状态，并测试改manifest、改数据及改锁的不同威胁；同目录自洽hash不能认证来源。以上真实语料/压缩/数据库实验未运行。

**下载六题自查。** ① 为什么每shard有checkpoint？它使本地前缀和偏移可核，不保证远端版本、整个文件或恶意修改不会损坏。② LSH比exact hash多做什么？它概率召回词面近重复候选，仍需复核，不是语义改写检测器。③ 应先发布未来偏移再写data吗？不应；用持久data-first的已提交偏移或完整WAL，恢复截未提交尾部。④ hash锁提供什么？有可信pin时检查manifest身份，且必须真的在读取端执行。⑤ 为什么常先去重再tokenize？常能省重复编码成本，但保留策略还需任务/误删评价。⑥ tombstone有什么用途？保keeper关联、来源与规则，支撑审计；已销毁内容的恢复需独立保全。

## 9. HDF5 Token shard：逻辑范围与读取行为

HDF5适合预tokenize后的整数数组、可扩dataset、按chunk的批量写入与按窗口切片；热点训练路径可避免重复JSON解析。h5py通过hyperslab选择将数据读为NumPy数组，**不是NumPy memmap**，也不自动零拷贝。chunk压缩、缓存、OS page cache、随机窗口起点、跨chunk读取与worker数共同影响性能。JSONL、Parquet、连续mmap与HDF5各有合适负载，不能因为本课选HDF5就宣布其它格式失效。[h5py dataset选读](https://docs.h5py.org/en/stable/high/dataset.html)，核验2026-10-11。

先核JSONL每行确为对象且text字段为合法字符串，坏行保存原因/计数而非悄悄丢弃。下载课demo的纯文本行不能直接交给这个输入器。Tokenizer身份、词表范围、特殊ID、dtype和endian都进manifest：257个byte词表ID可用uint16，但真实Tokenizer超过65535时就需更宽dtype；bool、浮点、负值和溢出ID拒绝，不能先int转换抹平错误。

批量buffer后resize/写入通常减少小写与元数据开销。HDF5物理尾chunk未满并不意味着dataset.shape有逻辑零padding；源程序resize到实际Token总数，shape恰是实长。只有预分配或未完成逻辑区才需要count截断；无论哪种设计，index里的offset/count、dataset shape/dtype与属性必须互核，不能让它们各说一个范围。写入异常不得在退出处理时仍finalize半成品；完成标记与index最后发布，失败结果保诊断。完整验证以有界块读取重算hash，不将整shard读入内存后声称streaming。offset有缝、重叠、未知键或同名shard覆盖也须拒绝。

### 9.1 发布方式、worker与窗口边界

离线转换可以写完整不可变shard、flush/close、核验后发布index，训练不读半成品。若确需一个writer与多个live reader，SWMR是另一合同：先创建groups/datasets/attrs，writer再开启swmr_mode，写后flush；reader以SWMR打开并按需refresh。来源在启用后才新增结尾属性的写法不满足这个先建结构流程。每个worker独立打开自己的h5py handle，不将父进程句柄跨fork共享；实际文件系统并发语义也须验证。[h5py SWMR步骤](https://docs.h5py.org/en/stable/swmr.html)，选读2026-10-11。

读T+1个Token构成x/y右移，复用§3.1已运行的边界/有效target程序。EOS提示文档结束，却不自动屏蔽跨文档attention或loss。写入与读取两侧必须统一每文档separator政策；源buffer恰好填满后再插separator的分支可能漏边界，不能同每文档末尾始终加separator的另一函数混用。随机window还改变端点覆盖、长文权重与重复采样；同split跨shard可拼接也要保document offset和监督规则。固定seed只复现从头的随机序列，续跑还需RNG状态、消费位置和worker映射。byte Token的窗口还可能落在UTF-8多字节字符中间，单窗口decode失败后replace有损不能证明Token数据错误；应按连续字节与解码状态核对文本，先验证ID范围。

**HDF5五项练习及判据。** ① 比较无压缩/gzip，固定语料Token bytes、窗口负载和cache冷/热条件，同时测IO、解压CPU与端到端吞吐；压缩不必更快或更慢。② 同seed、shard顺序与采样/worker配置应得到同batch，并核中断后的下一batch，而不是仅把seed重置到开头。③ validate逐块重hash，并交叉核count/offset/shape/dtype/endian/Tokenizer/split/完成状态，注入index篡改和短文件失败。④ chunk取半窗口、一窗口、两窗口时，以T+1和随机起点测读取放大、缓存与拷贝；“倍数对齐”不保证每样本只读一chunk或吞吐必减半。⑤ max-document-tokens需定义截断、EOS、长文任务损失与审计记录；写时裁剪不可逆，读时裁剪便于后续改政策但保更多存储。均未运行真实HDF5/压缩/多worker实验。

**HDF5六题自查。** ① 为何预存整数dataset？省重复解析/编码并便于索引；不是直接mmap或普遍O(1)物理IO。② chunk怎样定？以实际随机窗口、压缩和cache负载测，T+1与偏移都计入。③ 尾chunk需要count吗？物理未满不等逻辑padding，源shape已是实长；count作为合同仍应与shape/index一致。④ buffer的作用？合并写入减少操作，不保证磁盘物理布局总连续。⑤ writer无需SWMR操作吗？错误；live writer先建结构再启用，reader还需refresh。⑥ boundary ID保证什么？明确文档提示，不代替attention mask、loss mask或split隔离。

## 10. 训练断点：恢复轨迹、发布与可信加载

§4已有完整CPU更新边界恢复实验；保存weights可恢复推理函数，恢复训练轨迹还要model/buffers、optimizer、scheduler、AMP scaler、成功/尝试更新计数、随机状态、数据sampler/stream/shuffle buffer/消费位置及输入/环境修订。来源“五个状态桶”是整理入口，不是所有程序的充分清单。loss历史有助观测但不是数学上必需的状态；随机Dropout或多worker数据才会实际检验相应RNG恢复。

优先在完整optimizer更新边界保存。若必须在累积窗口中断点保存，就增加micro位置、partial gradients、scale与该窗口Token分母，否则会重算/漏算部分梯度。特定合成generator可按epoch seed重建再跳过batch；已恢复消费后RNG状态的流不能再用同样方法快进一次，否则双重跳过。

### 10.1 单文件原子发布与多shard版本

同文件系统同目录唯一临时文件 → 冻结/复制当前状态后序列化 → flush/fsync文件 → replace目标 → fsync目录。冻结很重要：state_dict可引用正在改变的tensor存储，异步保存不能边训练边序列化它。replace提供旧/新文件名切换的原子可见性，不检查payload内容、schema或训练状态是否完整，也不单独保证掉电后持久化。

多shard先写一个新的不可变generation，核每文件长度/hash、tensor键/shape/dtype与完整覆盖，最后发布index或当前generation指针。先覆盖固定shard再更新index会破坏旧generation，单文件各自原子也不是整组事务。分片按键数round-robin可能极不均衡；按层/字节/恢复设备布局选择，并把optimizer与metadata也计入，不能假设它们总很小。失败保旧完整generation，清理不触碰当前引用或尚在写入的版本。

### 10.2 加载检查与安全版本边界

先用可信索引与预定资源上限验证全部文件，再在fresh model/optimizer/scheduler中加载严格schema、类型、计数、键与shape/dtype；全部成功才替换运行对象，避免model加载成功但optimizer/RNG失败后留下半恢复对象。未知schema拒绝或明确迁移，startswith“ckpt”不能认证所有未来版本；跨shard重复键、遗漏键、路径越界与损坏都单独检查。

**恢复五项练习及判据。** ① 比较按weight/bias、按layer与按字节布局，衡量最大shard、load峰值、并行IO和依赖，不只按键数均分。② last K结合保存频率、可容忍损失和磁盘容量，保best/被引用generation；不清current或in-flight，K无唯一答案。③ 墙钟间隔到期后在安全更新边界触发；一个长step不能即时保存则报告真实最大丢失窗口，不能丢partial grad却称完整。④ 启动扫描可信index，对损坏、缺失、键/shape失配分别报告，失败保诊断并尝试已验证旧generation。⑤ v1→v2迁移明确定义新字段默认值与计数时钟，严格接受已知两个版本，未来版本拒绝。上述分片/清理/真实中断迁移实验未运行。

**恢复六题自查。** ① 完整checkpoint包含什么？训练真正依赖的数值、随机、数据位置和配置状态，不只weights；loss历史辅助观测。② temp+rename有什么意义？旧/新命名原子可见，durability和内容正确性另核。③ shard hash能做什么？可信index下检测bytes变化，不解决双改索引、遗漏键或多文件版本混用。④ epoch/batch offset够吗？仅在定义好的可重放generator合同下；真实流/worker状态另存，避免双重快进。⑤ schema字段自动兼容吗？只是迁移入口，必须严格分派与验证。⑥ loss suffix最大差接近0证明什么？该fixture轨迹接近，仍需下一batch、逐参数/optimizer/scheduler与实际随机操作对照，不证明所有环境恢复。

## 11. 分片Checkpoint：发布一个完整版本，而不是覆盖一组文件

§10已经解释训练状态与不可变generation，本节把这个合同落实到源80/81的具体失败路径。源80先顺序写rank0.bin.tmp等文件和manifest.tmp，再逐个os.replace固定的rankN.bin，最后replace manifest。如果目标目录已有版本A，替换完rank0后中断，旧manifest仍指A的hash，却碰到B的rank0和A的其它rank。加载可能正确地报hash错，但**旧checkpoint已经无法恢复**；检测错误不等于保住旧版本。源动态图把所有shard同步变为final并标“flip at once”，不是实际多file事务。

改用新的generation目录：先冻结同一安全更新边界的所有状态，写不可变shard与manifest；核每个文件身份、所有权、布局和应用schema；全部成功后只原子替换一个CURRENT指针。A的文件始终不动，发布B前失败仍能读A，发布B后才能清理不被current/best/inflight/其它引用使用的旧版本。指针发布的原子可见性、文件/目录fsync的持久性、网络文件系统语义和整份数值状态正确性是不同要求，不能由一次os.replace全包。

源80的manifest包含world_size/schema_version/step/wall_clock_seconds以及各shard rank/path/hash/offset/numel，loader实际核world/schema、条目数、rank范围与去重、路径限制、文件存在和hash。它没有用offset/numel检查tensor键/shape/dtype或覆盖关系，也没有检查文件内部rank/world/step与manifest一致；并且逐文件校hash后马上反序列化，不是全套身份先核齐后再加载。源81复制了更简化的save/load，丢掉schema、条目数、重复/非法rank、路径等检查，save也没有目录fsync。整合多个已测模块时重新复制代码，可能丢失原有保护，集成测试应明确覆盖这些合同。

### 11.1 一个可运行的不可变版本发布合同

下面程序只有标准库与自生成JSON状态，模拟两个rank的**保存布局**。weight/momentum是用于核snapshot的两个数，next_step/data_cursor是状态字段；它没有模型、梯度计算或optimizer更新。目标是核三处发布前中断时旧CURRENT和旧generation保持可读、成功发布后能明确选择新旧版本，以及损坏current shard会被拒绝。

这个最小schema接受固定rank次序、完整字段、有限数值、非负整数计数，manifest绑定每文件bytes/hash；pointer/manifest必须为完整dict，world_size必须为正整数并拒绝bool。数值字段中的Python整数保持精确，不转float；float才检查有限性，避免10**400隐式转换溢出。保存器在创建目录前核所有rank的完整snapshot、共同next_step与合法失败点；加载先核所有文件，再解码到fresh对象，未知schema拒绝。真实tensor要在此基础上增加键/shape/dtype/布局/模型与数据修订、资源上限和跨rank一致snapshot协议，不能直接拿JSON例代替分布式存储实现。CURRENT与manifest是在可信本地任务里生成，hash不认证恶意同时修改指针与文件的人。

```python
# 标准库文件发布合同；没有模型、tensor、分布式collective或云存储。
import copy
import hashlib
import json
import math
import os
import re
import tempfile
from pathlib import Path

class SimulatedCrash(Exception):
    pass

def encoded(obj):
    return json.dumps(obj, sort_keys=True, separators=(',', ':'),
                      allow_nan=False).encode('utf-8')

def sha(payload):
    return hashlib.sha256(payload).hexdigest()

def synced_write(path, payload):
    with path.open('xb') as stream:
        stream.write(payload)
        stream.flush()
        os.fsync(stream.fileno())

def sync_directory(path):
    fd = os.open(path, os.O_RDONLY)
    try:
        os.fsync(fd)
    finally:
        os.close(fd)

def checked_state(state, rank, next_step):
    if type(state) is not dict or set(state) != {
        'rank', 'weight', 'momentum', 'next_step', 'data_cursor'
    }:
        raise ValueError('state schema')
    if type(state['rank']) is not int or state['rank'] != rank:
        raise ValueError('state rank')
    for key in ('next_step', 'data_cursor'):
        if type(state[key]) is not int or state[key] < 0:
            raise ValueError('state counter')
    if state['next_step'] != next_step:
        raise ValueError('state step')
    for key in ('weight', 'momentum'):
        value = state[key]
        # Python整数精确保留，不隐式转float；float才核有限性。
        if type(value) is int:
            continue
        if type(value) is not float or not math.isfinite(value):
            raise ValueError('state number')
    return state

def read_generation(root, pointer, expected_world_size):
    if type(expected_world_size) is not int or expected_world_size <= 0:
        raise ValueError('expected world size')
    if type(pointer) is not dict or set(pointer) != {'generation', 'manifest_sha256'}:
        raise ValueError('pointer schema')
    if type(pointer['manifest_sha256']) is not str or not re.fullmatch(r'[0-9a-f]{64}', pointer['manifest_sha256']):
        raise ValueError('pointer hash')
    generation = pointer['generation']
    if type(generation) is not str or not re.fullmatch(r'g[0-9]+', generation):
        raise ValueError('generation name')
    directory = root / 'generations' / generation
    if directory.resolve().parent != (root / 'generations').resolve():
        raise ValueError('generation path')
    raw_manifest = (directory / 'manifest.json').read_bytes()
    if sha(raw_manifest) != pointer['manifest_sha256']:
        raise ValueError('manifest hash')
    manifest = json.loads(raw_manifest)
    if type(manifest) is not dict or set(manifest) != {'schema', 'world_size', 'next_step', 'shards'}:
        raise ValueError('manifest schema')
    if type(manifest['schema']) is not int or manifest['schema'] != 1:
        raise ValueError('manifest version')
    if type(manifest['world_size']) is not int or manifest['world_size'] != expected_world_size:
        raise ValueError('world size')
    if type(manifest['next_step']) is not int or manifest['next_step'] < 0:
        raise ValueError('manifest step')
    entries = manifest['shards']
    if type(entries) is not list or len(entries) != expected_world_size:
        raise ValueError('shard count')
    payloads = []
    for rank, entry in enumerate(entries):
        if type(entry) is not dict or set(entry) != {'rank', 'path', 'bytes', 'sha256'}:
            raise ValueError('shard entry')
        if type(entry['rank']) is not int or entry['rank'] != rank:
            raise ValueError('shard ownership/order')
        if entry['path'] != f'rank{rank}.json':
            raise ValueError('shard path')
        path = directory / entry['path']
        if path.resolve().parent != directory.resolve() or not path.is_file():
            raise ValueError('shard path escape')
        payload = path.read_bytes()
        if type(entry['bytes']) is not int or len(payload) != entry['bytes']:
            raise ValueError('shard bytes')
        if sha(payload) != entry['sha256']:
            raise ValueError('shard hash')
        payloads.append(payload)
    # 所有文件身份先核齐，再解码并核应用状态；返回fresh对象，不修改运行状态。
    return [checked_state(json.loads(p), r, manifest['next_step'])
            for r, p in enumerate(payloads)]

def publish(root, generation, snapshot, fail_at=None):
    if type(generation) is not str or not re.fullmatch(r'g[0-9]+', generation):
        raise ValueError('generation')
    if type(snapshot) not in (list, tuple) or not snapshot:
        raise ValueError('snapshot')
    if fail_at is not None and (type(fail_at) is not str or fail_at not in {
        'after_shards', 'after_manifest', 'after_pointer_tmp'
    }):
        raise ValueError('failure point')
    first = snapshot[0]
    if type(first) is not dict or type(first.get('next_step')) is not int or first['next_step'] < 0:
        raise ValueError('snapshot step')
    next_step = first['next_step']
    for rank, state in enumerate(snapshot):
        checked_state(state, rank, next_step)
    frozen = json.loads(encoded(snapshot))
    directory = root / 'generations' / generation
    directory.mkdir()  # 全部入口/state先核齐；已有generation拒绝覆盖。
    shards = []
    for rank, state in enumerate(frozen):
        checked_state(state, rank, next_step)
        payload = encoded(state)
        filename = f'rank{rank}.json'
        synced_write(directory / filename, payload)
        shards.append({'rank': rank, 'path': filename,
                       'bytes': len(payload), 'sha256': sha(payload)})
    if fail_at == 'after_shards':
        raise SimulatedCrash(fail_at)
    manifest = encoded({'schema': 1, 'world_size': len(frozen),
                        'next_step': next_step, 'shards': shards})
    synced_write(directory / 'manifest.json', manifest)
    sync_directory(directory)
    sync_directory(directory.parent)
    if fail_at == 'after_manifest':
        raise SimulatedCrash(fail_at)
    pointer = {'generation': generation, 'manifest_sha256': sha(manifest)}
    assert read_generation(root, pointer, len(frozen)) == frozen
    temporary_pointer = root / f'CURRENT.{generation}.tmp'
    synced_write(temporary_pointer, encoded(pointer))
    if fail_at == 'after_pointer_tmp':
        raise SimulatedCrash(fail_at)
    os.replace(temporary_pointer, root / 'CURRENT.json')
    sync_directory(root)
    return pointer

with tempfile.TemporaryDirectory(prefix='study-generation-contract-') as temporary:
    root = Path(temporary)
```

### 11.2 Async、rotation与跨world恢复各自的条件

Async保存首先要freeze一致snapshot，state_dict引用训练中会变的存储时，仅开线程或等“下一次保存之前结束”还会得到混合步数。训练rank应在约定更新边界提供不可变状态，各writer结束后协调检查再发布；异常须反馈训练控制器。Local NVMe后上传远端，需要远端独立版本/manifest提交与验证，第二本地目录的fake S3仅是协议实验，不证明网络durability。

Rotation按真实提交状态、step与引用计划选候选，而不是看到step_目录就删。源80按目录mtime与名称排序，mtime可随复制/补写变化，目录也可能尚未完成；shutil.rmtree(ignore_errors=True)后仍记deleted，不证明实际释放空间。写新版本前先删唯一旧版本会扩大故障损失，K=3/5只是容量政策候选。至少保current/必要best/正在写入或上传的版本，并记录删除成功与失败。

同world_size只是布局检查的一项。D4→D8恢复需按canonical tensor键、shape/dtype、offset与原长度重建master/m/v等状态，再映射新owner和padding；不能仅重分权重而漏moments或成功step。2026-10-13选读[PyTorch Distributed Checkpoint说明](https://docs.pytorch.org/docs/stable/distributed.checkpoint.html)：DCP能按新并行布局reshard，加载是in-place，须先分配目标，Stateful的load_state_dict才把状态交回应用；model/optimizer的FQN映射也参与合同，跨PyTorch版本state_dict不保证后向兼容。本次未执行DCP、load权重或调用SDK，官方能力不等源80/81已经实现它。

## 12. Round-trip不等恢复后训练轨迹一致

源81在step10保存full-model state_dict和各rank的master/m/v/step_count。verify_resume只从文件取master_shard，与当时返回的快照torch.equal，没有创建新模型/optimizer并装载，没有比较m/v、模型、计数、RNG或数据位置，更没有继续到step20。源80的round-trip test也只比较param_shard。这些都可叫指定张量的保存读取一致，不能叫完整训练resume完成。

真正continuation的最小比较沿§4现有完整CPU程序：在同一更新边界建立不中断与重启两分支，检查下一batch/有效目标、恢复状态和下一次更新的loss、逐参数、optimizer/scheduler/随机状态，再检查后续轨迹。原程序和2026-10-06结果保持字节与日期，本次没有重跑旧训练。在有Dropout、AMP、多worker stream、不同world或设备时，需分别新增相应状态与容差/确定性合同；也不能将教学fixture逐位相同推广到所有内核。

源81的模型参数与梯度同步分析见[计算性能与并行训练](../AI%20算法基础/深度学习专题/06-计算性能与并行训练.md)§27–29。它只记录rank0局部loss与最终norm，master+m+v逻辑字节可以精确核ceil(P/D)×12，却不包含完整model/grad、all-gather bytes、activation和workspace。Checkpoint打包每rank的完整model replica，通过all-gather让所有rank取得全部payload，rank0再顺序存，所以不能把它当“per-rank并行写避开root瓶颈”的实证。

要定义失败恢复，先确定坏loss、非有限grad、状态损坏、rank异常各自的处理政策，并协调所有rank在安全边界停下。源81没有NaN guard或loss-spike rollback；LR乘数不保证必然NaN，单次loss2倍也未必是坏状态。回滚必须恢复旧generation绑定的模型/optimizer、数据/RNG与计数，否则“换旧weights继续”仍会沿另一轨迹。步骤<10没有checkpoint，不能继续调用step10验证并假定snapshot存在；固定20步与exit0是控制流合同，不是数值、存储和全部rank均正确的证明。

### 12.1 十项保存与集成练习的判据

下面保留原80/81各五项扩展；除§11.1本地发布程序外，async/reshard、真实恢复训练、设备通信/性能与回滚实验均未实施。

1. **Async write（80-1）。** freeze同一步完整snapshot，在新generation内写；下次save等待完成并传回失败，发布前核全套身份/布局。开线程不等保存一致。
2. **最近五版（80-2）。** 用容量、已提交step与current/best/inflight引用计划清理；新commit有效后再清旧，核真实删除结果，不盲按mtime删唯一恢复点。
3. **CRC fast path（80-3）。** CRC是便宜损坏检测，不认证来源；保可信index、hash和全schema/shape合同，不能为“快”直接跳过所有验证。
4. **D4→D8（80-4）。** 按原tensor映射重建并reshard参数/master/m/v与padding，保计数/配置，核继续轨迹；不是拼接权重分8片就结束。
5. **Fake S3（80-5）。** 第二目录明确标本地模拟，分别核local与remote版本/上传manifest提交和旧版保留；真实网络durability另测。
6. **Attention TP（81-1）。** 分head的QKV和输出projection贡献按合同归约，LN/embedding复制边界与bias只加一次；与single-rank核输出、loss、梯度和完整更新，不能只比较norm。
7. **四micro累积（81-2）。** 固定完整输入、初态与RNG，等大mean除4或sum/总有效Token；核全batch梯度/参数及optimizer计数，不因局部loss表相似就接受。
8. **真step10→20续跑（81-3）。** 新对象加载完整model、master/m/v/step并重建模型参数，恢复data/RNG/recipe，比较loss suffix、下一batch、逐参数与状态；源verify函数缺的正是这个分支。
9. **Metrics JSONL（81-4）。** 记录rank与全局有效目标加权loss、attempt/success、grad norm、阶段时间/配置；rank0局部loss不代替globalloss，按实际同步计时。
10. **受控回滚（81-5）。** 明确非有限/异常输入或spike注入的可观察效果，协调rank停下，恢复已核generation和data/RNG；核失败step不推进成功时钟，再继续时状态一致。

### 12.2 十二题自查与参考判断

**存储六题（80）。** ① Gather-then-write有什么瓶颈？全state汇到root会受单点内存/IO限制，但64rank不保证正好64倍快。② Manifest比散文件多什么？world/schema/所有权与文件身份/布局合同，仍需可信索引和shape/dtype校验。③ tmp+rename保证什么？单文件名原子可见；多个固定shard逐replace不能保旧集合，需新generation再发布指针。④ SHA检什么？可信索引下bytes变化，不能认证双改索引与文件，不能查出遗漏状态/错shape。⑤ 为何拒world mismatch？相同owner layout不可默用新world，应显式reshard；同world也还要核其它元数据。⑥ 为什么rotation？防容量耗尽，但保current/best/inflight并核成功newcommit后清理，不固定K或先删old。

**集成六题（81）。** ① 为什么还需capstone测试？组合/rendezvous/归约/存储合同独立于unit正确。② 原四不变量实际测到哪些？rank0 log有限性、finalnorm摘要、三个shardtensor逻辑字节和master round-trip；没有每步逐参数、完整峰值、crash或继续训练验证。③ GPT多了什么边界？embedding gradientshape、attentionmask与CE数值、LN可学习参数；LayerNorm无runningstatistics，原选项误述。④ Self-terminating说明什么？固定步数与终态，deadlock/异常/数值仍需独立deadline和断言，exit0不自动证明成功。⑤ DDP与ZeRO怎样组合？init broadcast，ZeRO接管grad reduce-scatter与param all-gather，不额外再做一套DDP allreduce；源81没有PP。⑥ 为何可用墙钟cadence？step成本变化时可控制丢失时间窗口，但同10分钟不等同FLOPs，按安全更新边界/存储耗时和恢复风险定政策，5–15分钟不是定律。
