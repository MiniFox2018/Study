# 16｜预训练数据与模型交付实践

本章把输入语料、样本、训练、恢复与交付连接起来。Token算法和模型结构分别由[Tokenizer主入口](../LLM%20基础/02-文本-Tokenizer与Embedding.md)、[完整Transformer](../AI%20算法基础/深度学习专题/19-Transformer实现与训练实践.md)维护；SFT/偏好目标由[微调](04-微调与参数高效适配.md)/[偏好优化](05-偏好优化与强化学习.md)维护。本章保留独立CPU程序，因为只有一份manifest或目录并不能证明数据/梯度/恢复真正工作。

## 1. 先划清数据对象与学习目标

每条原始文档至少记录document ID、来源/取得日期、格式/语言或待核状态、原始内容SHA、清洗版本与派生内容SHA、文档族/group ID和split。原文、清洗文本、Token shard、训练batch、checkpoint、eval report是不同对象；改清洗或Tokenizer会改变下游输入，不应继续沿用旧Token文件。

网页、代码、书籍、论文、问答和合成文本提供不同分布。来源名不是质量标签；网页不必全垃圾，Wikipedia/书籍也不必每句正确。按任务检查内容、重复/时间/事实/格式、数据许可和可使用范围，保存抽样与剔除理由。源固定规模、语言比例和训练mix不能当各团队或所有年代的真配方；与架构、预算、可学参数及评测共同决定取舍。

划分通常先按用户/文档族/来源时间等实际独立单位分train/development/test，再生成窗口。不要先把同一文档切成重叠片段再随机分split。Tokenizer和频率/PPL参考模型仅从允许的训练数据fit；阈值可在development上调，锁定测试不能不断回流。去重族可跨split检查，同一族留在一侧；仅无精确hash相同不能证明无改写、答案或题目污染。

Chinchilla是在相应实验分布与固定训练compute下拟合模型/数据扩展关系，大致同时增加二者；不是“参数大十倍、数据多十倍便同loss”定理。服务成本目标可能偏好较小模型多训数据，重复epoch与新增独立数据也不等价。继续预训练、SFT或RAG按目标区别选择，不要求每个项目从Tokenizer→巨大预训练→RLHF→DPO→CAI全走一次。[训练compute研究](https://arxiv.org/html/2203.15556v1)

## 2. 清洗、语言与质量过滤：保留信息，再校准规则

HTML正文提取应区分标签、script/style与真实内容，保留段落边界、表格/代码所需结构和出处。正则删`<...>`不是完整页面提取器，还可能把两个段落串成一个词。自然文档可规范空白；代码中的缩进和运算符不能沿用同一规则。源`[^\x20-\x7E]`清洗会删除中文、emoji和其它Unicode，不是通用“去非文本”。

字符集统计只是语言提示，短文、代码和混合语言常不可靠；language model置信分数不必已校准成正确概率。长度、ALL CAPS、特殊字符比例、重复行和PPL是启发，每阶段同时抽查保留与删除样本，并按语言/领域切片报告误删。数学公式和有效代码可能标点多，数值答案可很短，不能硬套“50词/特殊字符<10%”定义有效知识。

PPL过滤衡量文本与参考LM分布接近程度，不是事实正确性：冷门术语、多语言或新领域也可能高PPL。使用相同Tokenizer/窗口/有效分母，训练参考模型只用train，明确定义“移除最高PPL的某个分位”或其它score方向。源把RefinedWeb归为Wikipedia小LM/PPL过滤的配方不能直接当原实现；其文档质量过滤/去重依具体研究流程，PPL是另一个可实验方法。完整n-gram/PPL程序在[文本预处理与稀疏表示](../AI%20算法基础/语言与文本专题/01-文本预处理与稀疏表示.md)，不在这里重复一套LM。

### 2.1 HTML提取、精确去重与MinHash/LSH的完整小例

MinHash先构造shingle集合S，再对每个独立hash取集合最小值。理想随机排列下两个签名位相同概率等于Jaccard：$J(S_1,S_2)=|S_1\cap S_2|/|S_1\cup S_2|$。b个band、每band r行时，近似候选概率为$1-(1-J^r)^b$；这是独立性假设下的概率，不保证所有近重复都召回。候选再算精确J，LSH只省候选，不把近似签名当最终真值。

本例使用salted SHA作为教学hash族，不复刻随机排列的精确理论；signature长度必须等于b×r，不丢余数。短文不足k时用整个非空短序列作一项，空文不进入MinHash。重复族按图连接分组用于split；删除时仅按固定代表的直接相似阈值，不将传递链当全员语义相同。

```python
import re
import json
import hashlib
import unicodedata
from html.parser import HTMLParser
from collections import defaultdict

class ArticleText(HTMLParser):
    def __init__(self):super().__init__(convert_charrefs=True);self.parts=[];self.blocked=0
    def handle_starttag(self,tag,attrs):
        if tag in ['script','style']:self.blocked+=1
        elif not self.blocked and tag in ['p','div','br','li','h1','h2']:self.parts.append('\n')
    def handle_endtag(self,tag):
        if tag in ['script','style']:self.blocked=max(0,self.blocked-1)
        elif not self.blocked and tag in ['p','div','li','h1','h2']:self.parts.append('\n')
    def handle_data(self,data):
        if not self.blocked:self.parts.append(data)

def clean_natural(text,is_html=False):
    if type(text) is not str:raise ValueError('文本类型')
    if is_html:
        p=ArticleText();p.feed(text);p.close();text=''.join(p.parts)
    # 只用于自然文本；代码等另选保缩进方案，原文应另外保存。
    return ' '.join(unicodedata.normalize('NFC',text).split())

def shingles(text,k=5):
    if type(k) is not int or k<1:raise ValueError('正shingle长度')
    words=text.casefold().split()  # 本例word口径；中文无空格需另设char/词切分。
    if not words:return set()
    if len(words)<k:return {tuple(words)}
    return {tuple(words[i:i+k]) for i in range(len(words)-k+1)}

def minhash(s,n=32):
    if type(n) is not int or n<1:raise ValueError('正签名长度')
    if not s:raise ValueError('空集合不作同一个重复族')
    return tuple(min(int(hashlib.sha256(json.dumps([i,list(x)],ensure_ascii=False).encode()).hexdigest(),16) for x in s) for i in range(n))

def candidates(signatures,bands=8):
    if type(bands) is not int or bands<1 or any(len(s)==0 or len(s)%bands for s in signatures):raise ValueError('完整band分组')
    buckets=defaultdict(list);pairs=set()
    for i,s in enumerate(signatures):
        r=len(s)//bands
        for b in range(bands):buckets[(b,s[b*r:(b+1)*r])].append(i)
    for ids in buckets.values():
        for n,i in enumerate(ids):
            for j in ids[n+1:]:pairs.add((min(i,j),max(i,j)))
    return sorted(pairs)

def dedup(records,threshold=.8):
    if not 0<=threshold<=1 or len({d['id'] for d in records})!=len(records):raise ValueError('阈值范围/唯一document ID')
    exact={};unique=[];removed=[]
    for record in sorted(records,key=lambda d:d['id']):
        clean=clean_natural(record['text'],record.get('html',False))
        if not clean:removed.append((record['id'],'empty'));continue
        digest=hashlib.sha256(clean.encode()).hexdigest()
        if digest in exact:removed.append((record['id'],'exact:'+exact[digest]));continue
        exact[digest]=record['id'];unique.append(dict(record,clean=clean,clean_sha=digest))
    sets=[shingles(d['clean']) for d in unique];sigs=[minhash(s) for s in sets]
    verified={};parent=list(range(len(unique)))
    def find(i):
        while parent[i]!=i:parent[i]=parent[parent[i]];i=parent[i]
        return i
    for i,j in candidates(sigs):
        sim=len(sets[i]&sets[j])/len(sets[i]|sets[j])
        if sim>=threshold:
            verified[i,j]=sim;ri,rj=find(i),find(j);parent[max(ri,rj)]=min(ri,rj)
    kept=[]
    for j,d in enumerate(unique):
        match=next((i for i in kept if (min(i,j),max(i,j)) in verified),None)
        if match is None:kept.append(j)
        else:removed.append((d['id'],'near:'+unique[match]['id']))
    families={d['id']:unique[find(i)]['id'] for i,d in enumerate(unique)}
    return [unique[i] for i in kept],removed,families

base='the small cat sits on the warm mat beside the red door'
records=[{'id':'a','text':base},{'id':'b','text':base},{'id':'c','text':base+' today'},
         {'id':'d','text':'<p>保留中文与段落。</p><script>删除脚本</script><p>第二段。</p>','html':True},
         {'id':'e','text':'独立短文'}]
kept,removed,families=dedup(records)
assert any(d['id']=='d' and '保留中文' in d['clean'] and '删除脚本' not in d['clean'] for d in kept)
assert ('b','exact:a') in removed
assert len(shingles('独立短文'))==1
assert ''.join(ArticleText().parts)==''
print('保留IDs',[d['id'] for d in kept],'删除原因',removed,'近重复family',families)
print('J=.5/.8，b8×r4候选概率',[1-(1-j**4)**8 for j in [.5,.8]])
```

SHA证明内容身份和损坏检查，不证明文本真实、来源可信或有训练权限。casefold/空白归一也可能改变代码或大小写含义，本程序合同仅自然文本。LSH漏召回、短文变体与跨语言相似仍需抽查；同bucket全部文档会产生最坏O(n²)候选，不能称任何数据上都近线性。相似但不同数值/否定的文档不一定该删除。源“去重少于20%必参数过保守”和“误候选应降Jaccard门槛”都不是可靠诊断，后者还可能增加误删。

## 3. 有界流、shuffle、shard与样本边界

真正streaming迭代读取文档或已tokenize shard，每次只保有限buffer/当前batch，不先将TB全拼进`all_tokens`列表。Shuffle buffer B先容纳B项，每读新项随机替换并yield一个，末尾随机排空；它保样本、内存有界，但不是整语料等概率全排列。多worker要分片而非每个worker重读同一流，并记录worker数、源shard顺序、epoch、buffer、seed和消费位置。

Token shard需明确整数dtype、最大ID、endian、文档offset/长度、Tokenizer hash与split；小词表可用uint16，大ID会溢出，不能凭模型名猜dtype。Memmap和预取可减少拷贝/等待，但吞吐要实际测读取/清洗/编码/packing/host-device耗时；不同硬件/语言没有固定10倍、100M token/s每核心的保证。

### 3.1 BOS/EOS、跨文档目标与attention的完整程序

本例为每文档加BOS/EOS，PAD0独立，普通byte ID有offset8（NUL为8）。程序返回x/y与document ID；label已右移，只计算真实下一token且属于同一文档。EOS被预测一次，但EOS→下一文档BOS不计loss。允许矩阵定义为True可见，框架若True代表blocked需反转。选择document-isolated attention或全流causal是两种训练目标；EOS只提供学习到的边界标记，不会自动隔离注意力。

```python
import random
from itertools import chain
import numpy as np

PAD,BOS,EOS,OFFSET=0,1,2,8

def buffered_shuffle(items,buffer_size,seed):
    if type(buffer_size) is not int or buffer_size<1:raise ValueError('正buffer')
    rng=random.Random(seed);buffer=[]
    for item in items:
        if len(buffer)<buffer_size:buffer.append(item)
        else:
            i=rng.randrange(len(buffer));yield buffer[i];buffer[i]=item
    rng.shuffle(buffer)
    yield from buffer

def packed_windows(documents,window=8):
    if type(window) is not int or window<1:raise ValueError('正窗口')
    # 不建全语料token list；pending最多window+1，另保当前文档的UTF-8 bytes。
    pending=[]
    for doc_id,text in enumerate(documents):
        if type(text) is not str:raise ValueError('文档应为str')
        for token in chain((BOS,), (OFFSET+b for b in text.encode('utf-8')), (EOS,)):
            pending.append((token,doc_id))
            if len(pending)==window+1:
                yield make_window(pending,window)
                pending=pending[-1:]  # 上一行末token成为下一行context，目标不重复计。
    if len(pending)>=2:yield make_window(pending,window)

def make_window(pairs,window):
    tokens=np.array([x for x,d in pairs]);docs=np.array([d for x,d in pairs])
    n=len(tokens)-1;x=np.full(window,PAD,dtype=int);y=np.full(window,-100,dtype=int);groups=np.full(window,-1,dtype=int)
    x[:n]=tokens[:-1];groups[:n]=docs[:-1]
    same=docs[:-1]==docs[1:];y[:n]=np.where(same,tokens[1:],-100)
    causal=np.arange(window)[:,None]>=np.arange(window)[None,:]
    isolated=causal&(groups[:,None]==groups[None,:])&(groups[None,:]>=0)
    # PAD query只允许看自己，使实现没有全blocked的softmax行；其输出不计loss。
    for i in range(n,window):isolated[i,i]=True
    assert isolated.any(1).all()
    return {'x':x,'y':y,'document_ids':groups,'allowed':isolated,'valid_input':np.arange(window)<n}

order=list(buffered_shuffle(range(17),4,3));assert sorted(order)==list(range(17))
assert order==list(buffered_shuffle(range(17),4,3))
windows=list(packed_windows(['ab','中\x00',''],window=8))
for row in windows:
    x,y,g,allowed=row['x'],row['y'],row['document_ids'],row['allowed']
    for i in range(len(x)):
        for j in range(len(x)):
            if g[i]>=0 and allowed[i,j]:assert j<=i and g[i]==g[j] and g[j]>=0
    assert np.all(y[~row['valid_input']]==-100)
    print('x/y/groups',x.tolist(),y.tolist(),g.tolist(),'有效targets',int((y!=-100).sum()))
assert sum((r['y']!=-100).sum() for r in windows)==sum(len(t.encode())+1 for t in ['ab','中\x00',''])
assert any(OFFSET in r['x'] for r in windows) and PAD!=OFFSET
print('有限shuffle保全部元素、targets不重复、文档隔离与NUL/PAD合同通过')
```

本实现接收完整单文档str，编码会暂存这一文档的UTF-8 bytes；内存界还取决于最大单文档，不声称所有输入下只占一个window。若需分块读取单个超大文件，应保UTF-8解码状态与文档offset。

空文在此有BOS→EOS一个目标；若任务不接收空文，应在上游过滤并记录，不让空文被当正常知识。切块可能截断前文，跨块长文训练需要明确保多少context/位置如何重置；本例上下文只保最后一个token，因此证明覆盖与边界，不提供长距离语言能力。packing高利用率不等高学习质量，也不等没有跨doc泄漏。

## 4. 真正训练、恢复与SFT的完整CPU小模型

下面固定字节词表，不从验证集fit任何merge/统计；人工文法是ABCD循环，文档ID不同、完整train/validation字符串不重叠。两层pre-LN decoder、可学位置、GELU、tied输出与AdamW都有真实autograd。模型的详细Attention/反向原理由已有主章维护，此处实现的目的在于串起**数据→有效loss→更新→checkpoint→精确续跑→SFT对照→完整生成评价**。

每次optimizer step聚合两micro-batch的loss总和/有效token总数，warmup/cosine按optimizer步数走。Checkpoint在完整更新边界保存，包含model/optimizer、下一步、数据采样generator与Torch RNG、结构、Tokenizer/数据SHA、调度配置；加载后先核元数据，再恢复状态。不是只保存weights后重新造optimizer继续算“同一轨迹”。本例无dropout且CPU固定版本，可核对下一步逐参数相同；这不承诺其它硬件/内核的bit-identical。

SFT任务仅“给A/B/C/D，答循环中的下一个字母”，模板中有独立role/EOT ID，监督回答内容+EOT；raw训练case0～47、raw验证48～63、SFT训练0～15，SFT验证64～71跨阶段留出。训练阶段可有意复用同域case，但锁定验证case不回流；SFT/eval各自有独立SHA，raw DATA_HASH保持原始对象定义。纯SFT与5% raw-example混合从同一base权重开始，另报实际raw目标比例。任务/验证的文档ID不同，但同属人工文法，成功不能叫自然语言通用泛化、真实知识学习或用户已经掌握。

```python
import math
import json
import copy
import hashlib
import tempfile
from pathlib import Path
import torch
from torch import nn
import torch.nn.functional as F

torch.set_num_threads(1);torch.manual_seed(21)
PAD,BOS,EOS,SYS,USR,ASST,EOT,OFFSET,V=0,1,2,3,4,5,6,8,264
CFG={'vocab':V,'dim':32,'heads':4,'layers':2,'context':64}
TOKENIZER={'scheme':'utf8-byte','offset':OFFSET,'special_ids':[PAD,BOS,EOS,SYS,USR,ASST,EOT],'normalization':'none'}
def digest_json(obj):return hashlib.sha256(json.dumps(obj,sort_keys=True,separators=(',',':')).encode()).hexdigest()
def bytes_ids(text):return [OFFSET+b for b in text.encode('utf-8')]
class TinyGPT(nn.Module):
    def __init__(self,cfg):
        super().__init__();self.cfg=cfg.copy();d=cfg['dim']
        if d%cfg['heads']:raise ValueError('head整除')
        self.embedding=nn.Embedding(cfg['vocab'],d,padding_idx=PAD)
        self.position=nn.Embedding(cfg['context'],d)
        self.blocks=nn.ModuleList([nn.TransformerEncoderLayer(d,cfg['heads'],4*d,dropout=0.,activation='gelu',batch_first=True,norm_first=True) for _ in range(cfg['layers'])])
        self.final_norm=nn.LayerNorm(d)
        def init(m):
            if isinstance(m,(nn.Linear,nn.Embedding)):
                nn.init.normal_(m.weight,std=.02)
                if isinstance(m,nn.Linear) and m.bias is not None:nn.init.zeros_(m.bias)
                if isinstance(m,nn.Embedding) and m.padding_idx is not None:
                    with torch.no_grad():m.weight[m.padding_idx].zero_()
        self.apply(init)
        for b in self.blocks:nn.init.normal_(b.self_attn.in_proj_weight,std=.02);nn.init.zeros_(b.self_attn.in_proj_bias)
    def forward(self,ids):
        if ids.dtype!=torch.long or ids.ndim!=2 or not ids.shape[1] or ids.shape[1]>self.cfg['context'] or (ids<0).any() or (ids>=self.cfg['vocab']).any() or (ids==7).any():raise ValueError('输入ID/长度合同')
        valid=ids!=PAD
        if not valid.any(1).all() or (valid[:,1:]&~valid[:,:-1]).any():raise ValueError('非空右padding序列')
        t=ids.shape[1];h=self.embedding(ids)+self.position(torch.arange(t))[None]
        blocked=torch.triu(torch.ones(t,t,dtype=torch.bool),diagonal=1)
        for block in self.blocks:h=block(h,src_mask=blocked,src_key_padding_mask=~valid)
        return F.linear(self.final_norm(h),self.embedding.weight)

def raw_example(text):
    tokens=[BOS]+bytes_ids(text)+[EOS]
    return {'x':tokens[:-1],'y':tokens[1:]}
def collate(examples):
    if not examples:raise ValueError('空batch')
    t=max(len(e['x']) for e in examples)
    if not 0<t<=CFG['context']:raise ValueError('batch长度超合同，不静默截断')
    x=torch.full((len(examples),t),PAD,dtype=torch.long);y=torch.full_like(x,-100)
    for i,e in enumerate(examples):
        n=len(e['x'])
        if n!=len(e['y']) or not n:raise ValueError('x/y对齐')
        x[i,:n]=torch.tensor(e['x']);y[i,:n]=torch.tensor(e['y'])
    if not (y!=-100).any():raise ValueError('无有效监督')
    return x,y

def ce_sum(model,x,y):return F.cross_entropy(model(x).reshape(-1,V),y.reshape(-1),ignore_index=-100,reduction='sum')
@torch.no_grad()
def evaluate(model,data):
    was_training=model.training;model.eval();nll=0.;count=correct=0
    for i in range(0,len(data),8):
        x,y=collate(data[i:i+8]);logits=model(x);mask=y!=-100
        nll+=float(F.cross_entropy(logits.reshape(-1,V),y.reshape(-1),ignore_index=-100,reduction='sum'))
        count+=int(mask.sum());correct+=int(((logits.argmax(-1)==y)&mask).sum())
    model.train(was_training)
    if count==0:raise ValueError('评测无targets')
    return {'nll':nll/count,'ppl':math.exp(nll/count),'teacher_accuracy':correct/count,'targets':count}

def lr_at(step,total,peak):
    warmup=5
    if step<warmup:return peak*(step+1)/warmup
    frac=(step-warmup)/max(1,total-warmup-1)
    return peak*(.1+.9*.5*(1+math.cos(math.pi*min(1,frac))))

## 5. Manifest、产物身份与交付决定

模型交付至少包含权重、结构/位置/mask配置、Tokenizer/模板、数据/训练recipe版本、输入输出合同、运行环境、候选模型SHA与绑定的eval报告；继续训练还需optimizer/scheduler、RNG和采样/流位置。Quantized权重须在量化**之后**重新评价该候选，不能拿量化前base报告替代；校准数据和方法版本一并记录。实际推理框架、量化和大模型加载由其它工程章维护，本例未跑真实服务。

Manifest描述这些关联及stage DAG，而不是只给12个来源课程名。数据依赖、训练recipe和模型结构配置应在训练前确定；SFT、DPO/RLHF、CAI等按目标选择，可作候选对照，不需要两种policy先强行合并再继续。一个DPO模型再SFT也可作为有意研究，类型字段不会自动让这种操作“编译失败”。

Content-addressed hash用于身份/完整性，不证明质量。每次get重算实际bytes hash、检查类型/schema与输入依赖；cache key应包含stage语义、recipe、代码版本、schema和**命名输入**的SHA。文件还存在不代表未损坏，名字`latest`可以作便利指针，但解析到已核对的不可变版本后再使用。

重放的bit-identical与指标等效是两个要求。若weights字节不同，output SHA也不同；记录各自实际SHA和同一协议下的误差/指标容忍，不能一边说hash全相同、一边说权重可不同。非确定性导致变化多少须实测，不保证只差1e−5或最终分数永不改变。

### 5.1 DAG、缓存失效、完整性与失败gate的可运行原型

本例处理**规格JSON与人工eval fixture**，不把JSON称实际checkpoint。真实训练可由上节返回权重/元数据后接同样合同。代码完整验证缺依赖/循环、命名输入类型、缓存key、get时rehash、实际预算、必需stage/本轮input/output记录一致及候选/数据逐次rehash绑定；失败保留原因。数据/模型规格缓存可复用，改变eval recipe只重做eval，改变模型recipe会使模型及其后代失效。

else:raise AssertionError('损坏产物必须拒绝')
cyclic=[Stage('a',{'b':'x'},'x',{},'v1',0.,data_build),Stage('b',{'a':'x'},'x',{},'v1',0.,data_build)]
e2=Engine();passing=e2.run(make_stages(score=.9),1.);assert gate(e2,passing,1.,.8)[0]
try:e2.run(cyclic,1.)
except ValueError:pass
else:raise AssertionError('DAG循环须在执行前拒绝')
assert not gate(e2,passing,1.,.8)[0] and e2.records[0]['status']=='failed'
# 同字符串高分报告不够：候选文件不存在/损坏也必须HOLD。
e3=Engine();old_outputs=e3.run(make_stages(score=.9),1.);assert gate(e3,old_outputs,1.,.8)[0]
original_blob=e3.store.blobs.pop(old_outputs['model']);assert not gate(e3,old_outputs,1.,.8)[0]
e3.store.blobs[old_outputs['model']]=b'corrupt';assert not gate(e3,old_outputs,1.,.8)[0]

# 另一轮只执行data，或执行了不同模型，旧完整outputs均不能冒认本轮成功。
e3.run(make_stages(score=.9)[:1],1.);assert not gate(e3,old_outputs,1.,.8)[0]
e3.run(make_stages(dim=64,score=.9),1.);assert not gate(e3,old_outputs,1.,.8)[0]
wrong_schema=canonical({'schema':True,'kind':'model-spec','payload':{}});wrong_sha=sha(wrong_schema);e2.store.blobs[wrong_sha]=wrong_schema

```

原source main只产生12份JSON占位与固定成本/评分；`plan`未实际核DAG/估算预算，`run`没有cache/schema/rehash，`gate`也没有核全部stage完成或实际cost来源。三个CLI命令每次新建内存store，输出stdout JSON，不是读写文档所说的`manifest.out.yaml`。可以把它当协议骨架阅读，不能说真实Tokenizer/预训练/SFT/量化/服务全部打通。

上例cache在内存，仅展示正确失效逻辑；进程间恢复须持久化cache索引/产物与manifest，并逐次核hash。保守估算没有用cache减少预预算；真实预算可按已核输入/输出key进一步计算。重放选择从失败stage及所有后代重做，保留已验证祖先；不能为了跳过训练而复用输入/代码已变的checkpoint。

## 6. 质量、成本与观测记录的单位

交付gate先确定任务/切片/失败率、baseline差异与不确定性，绑定候选SHA、数据/评分器/模板和资源配置。形式上都是数字也不等规则合理：良性请求误拒与有害请求遵从分开，拒绝率低不自动表示安全；KL阈值须说明分布和单位，不能固定25便推正确性。人工复核、unknown和严重错误规则也可以成为明确可审查的条件，不强制“禁止任何主观评价”。本批micro SFT只有25%完整正确，应报告未达到示例任务阈值，不能因loss下降自动交付。

Dense Transformer的粗训练量级$C≈6ND$（参数N、训练token D）是忽略/近似部分开销的估算，长注意力、MoE活跃参数、序列/重算/优化器及并行通信可改变成本。若估算使用GPU峰值F、MFU m，GPU-hours≈C/(F m×3600)；峰值的dtype/稀疏口径、硬件和实际利用率要一致，不重复把MFU当额外GPU数量。训练、数据处理、失败重跑、研发与服务成本分开。

```python
import math

def estimate_cost(params,tokens,peak_flops,mfu,hourly_assumption):
    values=[params,tokens,peak_flops,mfu,hourly_assumption]
    if any(type(x) is bool or not math.isfinite(x) for x in values) or min(params,tokens,peak_flops)<=0 or not 0<mfu<=1 or hourly_assumption<0:raise ValueError('成本单位/范围')
    flops=6*params*tokens;hours=flops/(peak_flops*mfu*3600)
    return {'dense_flops_estimate':flops,'gpu_hours_estimate':hours,'scenario_cost':hours*hourly_assumption}
# 仅沿用source练习给定假设：7B×2T、989TFLOPs、MFU .4、$2.50/h；不是当前报价。
r=estimate_cost(7e9,2e12,989e12,.4,2.5)
assert math.isclose(r['dense_flops_estimate'],8.4e22)
print('历史题设场景',r,'；未租GPU/付费/运行大模型，不能直接横比论文总成本')
```

日志最少保run/trace ID、stage、输入输出hash、状态、实际开始/结束、样本/有效tokens、更新步数、loss/关键metric与失败原因；hosted tracker/S3/OTel collector是可选实现，不是每个小实验必须开新服务。变动时间/成本与数据/权重的内容身份分开，不能把一次实际成本估计写成所有后续重放固定金额。

## 7. 练习参考答案与继续学习的边界

1. 英语字符集提示：可以统计Latin字母比例作为教学启发，但混合语言、数字/代码/短文会误判；正式过滤报告保留/误删样本，不用ASCII删中文再宣称高质量。
2. Exact与near去重：第2.1节完整跑同一个小语料，hash抓完全一致、MinHash/LSH先找候选再精确J；短文/阈值/代表顺序有定义，不把词面相似当语义同一。
3. Wikipedia bigram PPL过滤：完整语言模型算法接语言专题01，fit仅train、标清unit/窗口/阈值方向，开发集校准与过滤前后同一真实任务测试。此处未下载Wikipedia、训练公开语料或给过滤后质量必涨的结论。
4. 数据管线和mini GPT：固定字节词表、真实全图梯度、归约、split、自然文法验证、SFT与恢复均实跑，源局部更新/随机扰动已明确不作成功证据。
5. 07/08并行与stage09“合并”：可并行比较候选，但不能把两个policy只按hash串联就认为权重已经正确融合。真正组合方法/独立candidate评测另定；本例未跑RLHF/DPO集群。
6. 污染gate：hash/13-gram或MinHash提供词面排查，不证明所有改写不存在；门槛.1%是原题示例，需要定义总题分母、匹配对象与严重样本规则。metadata只含eval dataset SHA不能直接计算与train文档重叠，必须访问对应内容/特征。
7. 7B×2T费用：第6节按历史题设计算FLOPs/hours/金额；公开论文可能使用不同硬件、tokens与成本边界，不从两个金额就推MoE或厂商效率比。
8. 部分rollback：第5.1节改eval recipe保data/model cache，改model recipe重建model/eval；实际源12stage部分失败/多worker持久重放本批未运行，具体依赖决定失效集合。
9. OpenTelemetry：可用本地structured stage日志作为最小观测，实际span/exporter/collector需要自己的服务和运行协议。本批没有启动collector或把stdout称远端链路追踪成功。
