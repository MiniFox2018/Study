## 工程主线

```text
需求
→ 模型选择
→ 模型/权重
→ 基线推理
→ 数据与微调
→ 评测
→ 量化/推理优化
→ 服务化
→ 系统扩展
→ 监控/实验/反馈
```

具体 CUDA/CANN/ROCm 版本、模型名、API 参数和云产品能力变化快，执行前重新核验；主库只保留稳定工程角色与决策原则。

## 从无需部署的小练习开始

建议先掌握 [LLM 基础](../LLM%20基础/README.md) 的数据流、损失和缓存。工程学习可以按任务走，不必按目录顺序立刻做 SFT/RL。

| 阶段 | 章节 | 交付物与自检 |
|---|---|---|
| 建立可比较基线 | 01、02、06 | 一个任务定义、正常/边界样本、期望答案、环境记录 |
| 理解服务与资源 | 03、09、11 | 手算延迟和权重/KV 容量；解释测量口径 |
| 针对失败选择方法 | 04、05、10 | 说明为何需要训练、选哪类数据、怎样防止指标投机 |
| 专项实践 | 07 或 08 | 只选检索或多模态之一，检查样本、标签与评价方式 |

运行练习从已有可用环境中的最小样本开始，先确认正确，再扩大。硬件未确定时不预设模型或开通云服务；可先完成本文的数值计算、数据设计与失败分析。每章附带例子和核对答案，实际模型训练、压测和部署需要另记运行环境与结果。

2026-10-02 修订明确了“文档能力核验”和“本机运行验证”的区别。当前正文的教学场景不是已经完成的模型实验，框架 main/latest 文档也不是安装版本锁定文件。
