> **已经有一个模型后，怎样把它真正运行、微调、评测、服务化，并扩展成稳定的生产系统？**

- [AI 算法基础](../AI%20%E7%AE%97%E6%B3%95%E5%9F%BA%E7%A1%80/README.md)：算法与模型通用底座；

## 工程主线

```text
需求
→ 模型选择
→ 模型/权重
→ 基线推理
→ 数据与微调
→ 评测
→ 量化/推理优化
→ 服务化
→ 系统扩展
→ 监控/实验/反馈
```

具体 CUDA/CANN/ROCm 版本、模型名、API 参数和云产品能力变化快，执行前重新核验；主库只保留稳定工程角色与决策原则。
