# 10｜案例方法论

`self-llm` 的几个案例比“照着命令部署模型”更有长期价值，因为它们展示了如何从真实需求反推数据和训练方案。

## 1. 角色风格模型

角色模仿类案例的核心不是 LoRA，而是：

> **怎样把角色特征转化为可学习数据。**

数据需要覆盖：

- 语言习惯；
- 语气；
- 场景；
- 人物关系；
- 拒绝边界；
- 多轮一致性。

### 风险

如果只抽取经典台词，模型容易：

- 复读；
- 模板化；
- 无法泛化到新场景。

需要把原始语料转换成“任务—回答”训练样本。

## 2. 领域问答

例如数学类领域模型。

需要区分：

- 领域知识；
- 解题过程；
- 最终答案；
- 格式。

如果知识需要经常更新，RAG 可能比参数微调更合适。

如果需要形成稳定推理格式，SFT / RL 才更有价值。

## 3. 个人数字分身

个人表达风格建模核心在数据。

需要特别关注：

- 隐私；
- 数据授权；
- 身份冒充；
- 敏感记忆；
- 删除机制。

工程上应把：

```text
稳定表达规则 → 先用 Prompt/示例；确有需要再训练
动态个人事实 → 经授权的 Memory / RAG
```

分开。

## 4. 综合应用系统

复杂案例通常会组合：

- Prompt；
- RAG；
- Agent；
- SFT；
- UI / API。

这说明真实系统不应强行用单一技术解决所有问题。

## 6. 最重要结论

学习项目可以以“理解 LoRA”为目标，产物是能解释、运行并修改小实验；应用项目则应从“系统在哪些可重复场景下失败”开始。两种目标应分别验收，教学实验成功不等于解决了真实业务问题。

然后选择最小、最可验证的改动。

## 7. 一个完整但很小的案例设计

**目标**：本地文档问答回答“请假申请需要哪些材料”，并标出证据段。**基线**：直接把现行制度全文放入上下文；如果全文足够短且表现可靠，暂不建向量库。**失败样例**：旧制度混入、同名条款、文档缺答案、用户无访问权限。

若输入过长才引入检索，记录每个问题应召回的证据 ID；若检索正确却回答错误，修改上下文组织或生成约束；若找不到答案，要求明确证据不足。评测时分别核对证据命中、答案正确、引用对应、权限遵守与成本，而不是只保存一段看起来不错的演示。

**自检**：基线已经能答对全部练习题，还要不要加入微调？

**核对**：应用目标下先停止增加复杂度；扩大有代表性的验证，确认实际需求是否满足。若目标是学习微调，可另做隔离实验，并明确它尚无业务增益证据。


## 8. 从需求走到可追责的请求流水线

生产案例先冻结任务、数据访问、输出schema与成功/unknown/失败分母，再决定组件。以制度问答为例：鉴权→请求与预算admission→选模板/实验版本→授权检索→同身份/数据版本cache→模型尝试→结果/引用/权限检查→记录usage/trace→候选门禁。任一关键权限/guardrail不可用应fail closed或返回明确定义的不可服务状态，不能为了“优雅降级”偷偷关闭。缓存代码见[推理与服务化第15节](03-推理与服务化.md)，预算/计费见[资源感知优化](../Agentic%20Design%20Patterns/01-核心章节/16-资源感知优化.md)。

错误分成输入/schema/身份权限、瞬态供应商错误、deadline/cancel、语义输出失败和未知副作用状态。重试需上限、deadline、backoff与Retry-After；参数/权限错误不原样重试。换供应商还要重新核数据出站许可、模板、工具、输出和质量合同，不能把已生成一半的旧文本与新模型片段拼成一次成功。写动作超时可能已执行，先查询receipt/幂等状态，不能直接再次写。

下面完整runner只消费预设尝试结果，时间为虚拟duration，不睡眠/联网。每次尝试都有独立账本记录，失败已知usage照计，unknown费用保持未结；输出拒绝不改原usage。deadline只验证事件模型，未实现真实网络取消。

```python
from dataclasses import dataclass
from decimal import Decimal as D

@dataclass(frozen=True)
class Attempt:
    status:str;duration:int;input_tokens:int;output_tokens:int;answer:str='';usage_known:bool=True

def run(attempts,deadline,max_attempts=3,output_ok=lambda x:x=='申请表',mutating=False):
    if type(deadline) is not int or deadline<=0 or type(max_attempts) is not int or max_attempts<1:raise ValueError('预算')
    elapsed=0;trace=[];spent=D(0);unknown=[];result='failed'
    for i,a in enumerate(attempts[:max_attempts],1):
        if any(type(x) is not int or x<0 for x in [a.duration,a.input_tokens,a.output_tokens]):raise ValueError('尝试记录')
        if elapsed+a.duration>deadline:
            result='deadline';break  # fixture假设未dispatch；真实inflight费用另核。
        elapsed+=a.duration
        cost=(D(a.input_tokens)+2*D(a.output_tokens))/1000 if a.usage_known else None
        if cost is None:unknown.append(i)
        else:spent+=cost
        row={'attempt':i,'status':a.status,'duration':a.duration,'input_tokens':a.input_tokens,'output_tokens':a.output_tokens,'known_cost':str(cost) if cost is not None else None}
        trace.append(row)
        if a.status=='ok':result='accepted' if output_ok(a.answer) else 'output_rejected';break
        if a.status=='ambiguous_write' or (mutating and a.status=='timeout'):
            result='reconcile_required';break
        if a.status not in {'transient','timeout','rate_limited'}:break
    return {'status':result,'virtual_elapsed':elapsed,'spent_units':spent,'unknown_usage_attempts':unknown,'trace':trace}
r=run([Attempt('transient',2,100,0),Attempt('ok',3,100,10,'申请表')],deadline=8)
assert r['status']=='accepted' and r['spent_units']==D('.22') and len(r['trace'])==2
blocked=run([Attempt('ok',1,100,40,'无证据猜测')],8)
assert blocked['status']=='output_rejected' and blocked['spent_units']==D('.18') and blocked['trace'][0]['output_tokens']==40
pending=run([Attempt('timeout',1,100,0,usage_known=False)],8,mutating=True)
assert pending['status']=='reconcile_required' and pending['unknown_usage_attempts']==[1]
assert run([Attempt('ok',9,0,0,'申请表')],8)['status']=='deadline'
print('重试已知总费',r['spent_units'],'输出拒绝保原usage',blocked['spent_units'],'未知写状态不重复',pending['status'])
```

Trace每个span保request/run ID、父子关系、阶段、status、版本/模型、实际单调clock时间、usage与错误类型，脱敏资料别直接放日志。多个并行span的时长之和不等端到端延迟；依赖health需probe和超时策略，不是返回固定healthy。原源20个async canned请求不是100真实用户或容量结论，缓存/账本/内存状态多worker间也不会自动共享。这里console记录不是OpenTelemetry exporter/collector集成。

## 9. 候选门禁、A/B和回滚要绑定版本

实验variant应在完整流水线前稳定分配，cache key包含variant/template/data/model；shadow仍消耗费用、处理数据且可能调用有副作用工具，须独立授权和禁写。评价同case ID、失败/unknown、切片、区间与严重错误，沿用[评测与实验管理](06-评测与实验管理.md)，不要把100题2×错误率当通用自动回滚定律。Prompt registry保不可变revision与alias，回滚alias后也使相关cache失效；模型/量化候选验收应绑定实际artifact SHA，见[模型交付](16-预训练数据与模型交付实践.md)。

## 10. 综合应用原练习怎样验收

第13课五题：①RAG先分离retrieval与生成失败、同case比较，20doc/top3只是题设，现有RAG主章维护完整算法，未跑真实模型质量；②function calling不是文本声称“用了工具”，登记调用ID/参数/身份/结果与tools_used，工具/结构化合同由相关主章维护，本批未调外部天气/搜索；③按用户日账期/总账原子预留与实际结算，.50/$100/2000token及某便宜型号是题设，不能直接作当前生产阈值；④版本diff和paired证据优先，100题2×错误率不保证显著性或业务损失；⑤每span duration与父子trace必须真实测量，没启动OTel不可称端到端追踪完成。

## 11. 综合案例先冻结输入、产物与证据

研究报告系统的输入应是“明确主题、已授权资料范围、输出字段/长度、允许的动作和预算”，而非只有“帮我调研”一句话。输出应是可核对报告、证据对应关系、来源/数据版本、任务状态和未完成边界。只有需要独立远端委托、异步状态或交互界面时，再加入相关协议。若直接读取少量材料已能达成目标，完整生态并不是必选。

举一个封闭的教学案例：Alice 获准使用 t1 的两段制度材料 `policy:7` 与 `policy:9`，要求列出申请材料，报告只生成在本地，不发送。Bob 只获准检索自己的资料。成功要求不是“出现HTML”，而是：Alice 的报告只含被授权证据，字段和出处对应；Bob 的生成动作拒绝且无报告效果；暂停/失败/取消有明确状态；重启以后能读回同一结果，不能重新写一份报告。

需要分别管理五种身份：认证主体 `(tenant,actor)`、业务操作 key、MCP task ID、A2A task/message ID、trace/span ID。操作 key 定位可能产生副作用的同一动作；task ID 定位工作状态；trace ID 定位可观测轨迹。它们都不替代授权，也不能互换。某任务在恢复后可以跨多个短 trace，通过受控任务关联字段链接；不能把前一天已结束的 request span 假装仍覆盖所有后续轮询。

### 调用边界与状态的唯一维护入口

MCP 发现、工具/资源/提示与每请求metadata，由[MCP主章](../Agentic%20Design%20Patterns/01-核心章节/10-模型上下文协议-MCP.md)维护。当前固定2026-07-28，client每次请求携带版本、clientInfo、clientCapabilities；连接没有旧session也不意味着业务无状态。异步工作依然要存 task/owner/输入摘要/TTL/结果。MCP Tasks 是独立扩展：初次工具返回 task handle，poll用 `tasks/get`，completed Task携带最终result；不要混用旧 `tasks/result` 或 A2A `GetTask` 的对象。

多个后端同名工具要用明确公开名，例如 `research::search` 和 `archive::search`，映射到唯一backend/tool identity；gateway发现过滤与直接调用都核当前政策，不能“列表里隐藏所以无法调用”。完整descriptor的pin/准入与OAuth、精确动作授权由[安全模式](../Agentic%20Design%20Patterns/01-核心章节/18-安全模式.md)维护。静态token或clientInfo声明只用于教学数据，不证明真人身份、issuer/audience/expiry检查。外层凭据与后端凭据分别持有，不能把用户token随A2A/MCP转发给任意peer。

写报告的远端委托用[A2A通信](../Agentic%20Design%20Patterns/01-核心章节/15-智能体间通信-A2A.md)的Card/media/interface、SendMessage与任务归属合同。只有边界span和artifact可见，也可以足够定位整体成功与失败；不能为了“完整trace”要求对方公开私人推理。模型候选与fallback用[路由](../Agentic%20Design%20Patterns/01-核心章节/02-路由.md)先筛许可范围，每hop消耗同一预算并重核政策。采样与usage不能取代任务质量验证。

交互界面关联一个不可变report identity/version，Host通过真实MCP Apps资源与bridge加载，App的 `app.callServerTool({name,arguments})` 请求仍经Host政策与服务端授权。加载状态、最近一次result、用户选中项等App state不是凭据，恢复界面时先核报告归属与当前权限。CSP约束资源/连接来源，iframe sandbox与权限限制执行能力，服务端限制能读取或修改什么；三者互补。把HTML字符串或 `ui://report/current` 写入Python字典，既没有浏览器执行，也没有bridge/CSP证据。课程自造 `ui_resource` block 不能直接当现行MCP content类型。

trace按[评估和监控](../Agentic%20Design%20Patterns/01-核心章节/19-评估和监控.md)注入/提取，在真实接收端核parentage、error、数量与export。业务鉴权、descriptor检查、委托和报告提交失败都应留下脱敏决策记录；不把secret、原资料全文或凭据放进日志。只打印相同traceId不证明传播，生成`ui://`不证明渲染。

### 断点选择决定恢复动作

| 观察到的断点 | 已知证据与状态 | 正确恢复 |
| --- | --- | --- |
| schema/授权检查未通过 | 未dispatch，没有业务effect | 修输入或授权；记录拒绝，不创建伪成功任务 |
| task已创建、委托尚未发出 | 持久owner、输入摘要、待办与TTL | 当前权限仍有效时继续；每次出站重新准入 |
| SendMessage发出、响应丢失 | 是否接收/执行未知 | 查已知task/message的去重/状态合同；无保证时保留unknown，不新建同效果任务 |
| writer要求输入或授权 | INPUT_REQUIRED / AUTH_REQUIRED与请求内容 | 按原task补充信息或完成外部授权，精确绑定动作；状态本身不授权 |
| 报告effect已提交、task completed未写回 | 同操作key的可验证receipt与产物摘要 | 核receipt/输入一致后补回状态与结果，不再生成报告 |
| App断线/重载 | 可能只有旧view state | 重新读权威任务与report version，再核权限；不重复按钮对应的写动作 |
| collector部分拒收/后端不可查 | 可观察证据不完整 | 修instrument/export，保业务结果与telemetry故障分开；不称全链路已验 |
| TTL已过、取消或权限撤销 | 当前不可继续 | 返回明确终态/不可访问；过期副作用另按receipt对账，不能重放旧许可 |

同一个数据库内业务effect与receipt可放在一个事务；跨第三方写入不能靠本地事务保证原子。若先写远端再保存本地receipt时崩溃，恢复需要远端业务幂等key/可查询receipt或人工对账；查不清就停在reconcile_required，不能承诺恰好一次。任务的终态还应与效果区分：已生成的报告不会因取消状态自动删除。

## 12. 可运行的报告提交与重启恢复实验

下面程序输入可信认证边界给出的身份、每请求meta和带evidence/version的报告参数；输出本地MCP任务形状的工作/完成状态、不可变report reference与receipt。它模拟“业务提交后，worker在写completed前退出”，再关闭/重开SQLite恢复；另检查同名工具必须qualified、缺Tasks能力、只读主体拒绝、归属、输入key冲突、TTL和界面读取时撤权。时间为虚拟值，任务轮询间隔为1；提前poll拒绝，TTL不随poll延长。

程序只实现该封闭案例需要的本地合同子集。外部身份、MCP envelope、A2A委托、App bridge和telemetry在正文有独立验收要求，代码没有运行它们；存储的trace link也只是恢复关联资料。本地report是固定教学文本，不称真实调研或模型摘要。

```python
import hashlib, json, sqlite3, tempfile
from pathlib import Path

VERSION='2026-07-28'; EXT='io.modelcontextprotocol/tasks'
def encode(x): return json.dumps(x,sort_keys=True,separators=(',',':'),allow_nan=False)
def digest(x): return hashlib.sha256(encode(x).encode()).hexdigest()
def meta():
    return {'io.modelcontextprotocol/protocolVersion':VERSION,
            'io.modelcontextprotocol/clientInfo':{'name':'fixture','version':'1'},
            'io.modelcontextprotocol/clientCapabilities':{'extensions':{EXT:{}}}}
grants={('t1','alice'):{'read','write'},('t1','bob'):{'read'}}
def authorize(actor,tenant,scope):
    if scope not in grants.get((tenant,actor),set()): raise PermissionError('当前scope不足')
def check_meta(m):
    if m.get('io.modelcontextprotocol/protocolVersion') != VERSION: raise ValueError('版本')
    if EXT not in m.get('io.modelcontextprotocol/clientCapabilities',{}).get('extensions',{}):
        raise ValueError('本次请求缺Tasks capability')
class Reports:
    def __init__(self,path,clock):
        self.db=sqlite3.connect(path);self.clock=clock
        self.db.executescript('''
          CREATE TABLE IF NOT EXISTS jobs (
            task TEXT PRIMARY KEY, actor TEXT, tenant TEXT, operation TEXT,
            input_sha TEXT, state TEXT, expires INTEGER, poll_due INTEGER,
            trace_link TEXT, result TEXT);
          CREATE TABLE IF NOT EXISTS receipts (
            operation TEXT PRIMARY KEY, input_sha TEXT, report TEXT);''')
    def getrow(self,actor,tenant,task):
        authorize(actor,tenant,'read')
        row=self.db.execute('SELECT * FROM jobs WHERE task=? AND actor=? AND tenant=?',
                            (task,actor,tenant)).fetchone()
        if row is None or self.clock() >= row[6]: raise LookupError('不可访问或过期')
        return row
    def submit(self,actor,tenant,operation,args,m):
        check_meta(m);authorize(actor,tenant,'write')
        if set(args)!= {'evidence','data_revision','format'} or args['format']!='text':
            raise ValueError('报告合同')
        if args['evidence']!=['policy:7']: raise ValueError('教学资料授权范围')
        key=encode([tenant,actor,'research::generate_report',operation]);sha=digest(args)
        task='task-'+digest(key)[:16]
        old=self.db.execute('SELECT input_sha FROM jobs WHERE task=? AND actor=? AND tenant=?',
                            (task,actor,tenant)).fetchone()
        if old:
            if old[0]!=sha: raise ValueError('同操作key不同输入')
            self.getrow(actor,tenant,task)
        else:
            with self.db:
                self.db.execute('INSERT INTO jobs VALUES (?,?,?,?,?,?,?,?,?,?)',
                  (task,actor,tenant,key,sha,'working',self.clock()+10,self.clock()+1,
                   encode({'traceId':'a'*32,'spanId':'b'*16}),None))
        return {'resultType':'task','taskId':task,'status':self.getrow(actor,tenant,task)[5],
                'pollIntervalMs':1000}
    def commit_report(self,actor,tenant,task,args,crash_after_effect=False):
```
