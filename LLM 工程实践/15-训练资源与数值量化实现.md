## 1. 训练内存：先声明状态，再算字节

N个参数不等于N个低精度数。至少逐项计入：参数、梯度、优化器moment、可选独立master权重、反向保存的激活、临时workspace、通信缓冲和allocator预留。内存单位统一：GB=10^9字节，GiB=2^30字节。

例如参数与梯度各2字节、Adam m/v各4字节：静态状态每参数12字节；另有独立FP32 master时为16字节。7B参数为84GB或112GB，不能先说Adam两份28GB再在表格按56GB计算。FP32参数4字节+梯度4+m/v8也是16字节，已有FP32参数作master时不能再次计一份。常见autocast只改变某些算子的计算dtype，并没有把登记参数都变成BF16。

Adam的状态dtype依实现/配置而定，不能称“永远FP32”。普通PyTorch Adam通常以参数dtype创建moment；混合精度训练库可能维护FP32主权重/状态。必须查看实际state。moment初始化还可能是lazy的，在第一个optimizer step前量内存会漏项。

设P/G/O分别为参数/梯度/优化器及master总字节，分片组大小D：不分片为P+G+O；ZeRO1为P+G+O/D；ZeRO2为P+(G+O)/D；ZeRO3的常驻状态下界为(P+G+O)/D。FSDP与ZeRO3都分片这些类别，但分组、挂钩、reshard、checkpoint保存和offload实现并不完全相同。ZeRO1/2的节省比例取决于P/G/O/D，不是固定4倍/8倍。

70B、每参数12字节、D8的常驻状态就有105GB。即使激活降到零，也无法放进80GB预算；activation checkpoint不能减少这一项。分片数增加只给静态下界，层计算还要临时all-gather完整参数，预取/并行组可能同时保多组，通信与reduce dtype也影响峰值。不能只将总字节除卡数就断言训练必能启动。[FSDP2官方状态说明](https://docs.pytorch.org/docs/stable/distributed.fsdp.fully_shard.html)

```python
import math,torch
torch.set_num_threads(1)
def state_bytes(N,D=1,stage=0,param_bytes=2,grad_bytes=2,moment_bytes=8,master_bytes=0):
    if type(N) is not int or N<1 or type(D) is not int or D<1 or stage not in [0,1,2,3]:raise ValueError('N/D正整数；stage0..3')
    p=N*param_bytes;g=N*grad_bytes;o=N*(moment_bytes+master_bytes)
    return {'parameters':p/(D if stage>=3 else 1),'gradients':g/(D if stage>=2 else 1),'optimizer+master':o/(D if stage>=1 else 1)}
for stage in range(4):
    z=state_bytes(7_000_000_000,D=8,stage=stage,master_bytes=4)
    print('stage',stage,'static state GB',sum(z.values())/1e9,z)
assert sum(state_bytes(7_000_000_000,master_bytes=4).values())==112e9
assert sum(state_bytes(70_000_000_000,D=8,stage=3).values())==105e9
# 105GB static state cannot be fixed by eliminating activations entirely.
assert 105e9>80e9
# Real CPU Adam state dtype follows this concrete parameter dtype/configuration.
for dtype in [torch.float32,torch.bfloat16]:
    p=torch.nn.Parameter(torch.tensor([.1,.2],dtype=dtype));opt=torch.optim.Adam([p],lr=.001)
    (p.float().square().sum()).backward();opt.step()
    tensors=[p,p.grad]+[v for v in opt.state[p].values() if isinstance(v,torch.Tensor)]
    total=sum(t.numel()*t.element_size() for t in tensors)
    print(str(dtype),'actual parameter/grad/state tensor bytes',total,'moment dtype',opt.state[p]['exp_avg'].dtype)
# Toy dense cost: declared positive rates/currency, not hardware/price recommendations.
N=1_000_000;tokens=1_000_000;measured_rate=1e10;ranks=4;price=2.
wall_seconds=6*N*tokens/(ranks*measured_rate)
gpu_hours=ranks*wall_seconds/3600
assert math.isclose(wall_seconds,150.)
print('declared toy wall_seconds/GPUhours/cost',wall_seconds,gpu_hours,gpu_hours*price)
```

程序比较四个分片级别的**算术估计**，并查看普通CPU Adam实际状态dtype/字节。成本算例的速率、价格均为显式教学输入，6ND只是dense主矩阵训练的粗近似，未包含长序列attention、稀疏架构、重计算、通信和checkpoint保存；不能以公开某次训练费用反推通用价格/利用率。

## 2. 浮点格式：范围、精度与舍入分开

FP32=1符号+8指数+23显式尾数，FP16=1+5+10，BF16=1+8+7。正常数含隐式leading1；非规格数、零、Inf/NaN使用特殊指数编码，不能都用`exponent-bias`公式解释。FP16最大有限65504，最小正常约6.10e-5，最小非规格约5.96e-8；BF16的指数范围接近FP32，但有效位更少。

FP8须写具体格式。E4M3FN是有限数/NaN约定，最大448；E5M2有更大范围与较少尾数位，最大有限57344。不同变体的bias/Inf/NaN/负零合同不同，不能仅靠“1+4+3”猜全部值。格式可存储也不代表当前设备有快速算子。

将FP32最高16位直接截下来只是BF16**截断模拟**，不等于一般round-to-nearest转换；FP8小数还要处理subnormal和进位。源代码把1e-6夹到最小正常区间，而真实E4M3FN cast可舍成0；FP32展示函数返回原Python浮点，也不是真正stored-value。下例使用库实际cast并与截断对照，不模拟TensorCore kernel。

```python
import torch,numpy as np
torch.set_num_threads(1)
x=torch.tensor([.1,.07342,1e-6,1e-20,448.],dtype=torch.float32)
for dtype in [torch.float32,torch.float16,torch.bfloat16,torch.float8_e4m3fn,torch.float8_e5m2]:
    y=x.to(dtype).float();print(str(dtype),y.tolist(),'max',torch.finfo(dtype).max)
# Truncating top16 bits is not round-to-nearest BF16.
a=np.float32(1.007);trunc=np.uint32(a.view(np.uint32)&np.uint32(0xffff0000)).view(np.float32)
round_bf=float(torch.tensor(float(a)).bfloat16().float())
assert trunc!=round_bf
assert float(torch.tensor(1e-6).to(torch.float8_e4m3fn).float())==0.
print('BF16 truncation vs actual cast',float(trunc),round_bf)
```

混合精度的数值训练见[张量框架与模型调试](../AI%20算法基础/深度学习专题/18-张量框架与模型调试.md)。FP16 loss scaling须在真实梯度裁剪前unscale，并保持一组累积微批scale一致；BF16范围大不代表不会NaN或无需质量检查。格式本身不保证所有前向/反向状态减半。

## 3. 均匀量化的完整合同

### 3.1 scale、zero-point、round与clamp

仿射量化定义 $q=\mathrm{clamp}(\mathrm{round}(x/s)+z,q_{min},q_{max})$，反量化 $\widehat x=s(q-z)$，s>0，z为整数。明确round规则：本例NumPy rint按最近偶数；Rust标准round在tie处常按远离零，与其结果可以不同。zero-point是在round之后相加的整数；tie处随意改成round(x/s+z)也可能改变编码。

对称量化z=0。本例采用有符号对称范围[-127,127]或[-7,7]，保留一个最负编码不用；也可采用[-128,127]/[-8,7]，但正负端点和scale约定必须配套。有符号整数通常是二进制补码，不是“1bit符号+剩下的绝对值”。INT4的16种编码不意味着对称方案用了16个等距非零幅度。

无clipping的值，最近舍入误差至多s/2；若校准范围小于真实输入或outlier被截掉，此界不成立。动态scale每请求变化与静态校准scale也是不同合同。输入必须有限且非空；全部零可约定s1/z0，不能除零。

不对称range要包含零：lo=min(0,min(x))、hi=max(0,max(x))，s=(hi-lo)/(qmax-qmin)，再选合法整数z。源程序仅使用[min,max]后把z夹到合法范围，正值[10,11]因此严重饱和；非零常量又直接返回全零，丢掉常量。本章两种情况都有回归检查。

### 3.2 per-channel/group的形状与打包

本章线性层W=[out,in]，每输出行单独scale；group是在每一输出行的输入维按连续group_size分组。若代码W=[in,out]，输出channel是列；“axis0即输出行”的标签不能跨布局通用。激活X=[token,in]可按token选scale，KV可能按head/channel/token/group选scale，需与kernel接受的布局一致。

group小通常能适配局部范围，但scale/zero-point更占存储，打包与kernel开销也变。假设每group g个4-bit权重，scale占4字节、zero-point占1字节，则有效位宽理想约`4+40/g`bit/weight，再加尾组padding/对齐/未量化层。source将所有量化code存int32，并没有实际4-bit内存节省；下例真正把两个有符号nibble打包为一个uint8，再验证反解。

```python
import numpy as np
import math

def check(x,bits):
    x=np.asarray(x,dtype=np.float64)
    if x.size==0 or not np.isfinite(x).all() or type(bits) is not int or not 2<=bits<=8:
        raise ValueError('非空有限输入；整型bits在2..8')
    return x

def symmetric(x,bits=8):
    x=check(x,bits);limit=2**(bits-1)-1  # symmetric [-limit,limit], reserve -128/-8
    scale=float(np.max(np.abs(x)))/limit or 1.
    code=np.clip(np.rint(x/scale),-limit,limit).astype(np.int8)
    return code,scale,code.astype(float)*scale

def affine(x,bits=8):
    x=check(x,bits);qmax=2**bits-1
    lo=min(0.,float(x.min()));hi=max(0.,float(x.max()))
    scale=(hi-lo)/qmax or 1.
    zp=int(np.clip(np.rint(-lo/scale),0,qmax))
    code=np.clip(np.rint(x/scale)+zp,0,qmax).astype(np.uint8)
    return code,scale,zp,(code.astype(float)-zp)*scale

def group_quant(W,group=4,bits=4):
    W=check(W,bits)
    if W.ndim!=2 or type(group) is not int or group<1:raise ValueError('W=[out,in]；正整型group')
    rows,cols=W.shape;G=(cols+group-1)//group
    codes=np.zeros(W.shape,dtype=np.int8);scales=np.zeros((rows,G));decoded=np.zeros_like(W)
    for row in range(rows):
        for g,start in enumerate(range(0,cols,group)):
            q,s,recon=symmetric(W[row,start:start+group],bits)
            codes[row,start:start+group]=q;scales[row,g]=s;decoded[row,start:start+group]=recon
    return codes,scales,decoded

def pack4(code):
    a=np.asarray(code)
    if not np.issubdtype(a.dtype,np.integer) or np.any(a<-8) or np.any(a>7):raise ValueError('合法有符号4bit code')
    n=a.size;raw=(a.astype(np.int64).ravel()&15).astype(np.uint8)
    if n%2:raw=np.append(raw,np.uint8(0))
    return raw[::2]|(raw[1::2]<<4),n

def unpack4(packed,n,shape):
    raw_payload=np.asarray(packed)
    if (raw_payload.ndim!=1 or not np.issubdtype(raw_payload.dtype,np.integer)
        or np.any(raw_payload<0) or np.any(raw_payload>255)):
        raise ValueError('1D integer payload bytes in 0..255; no silent float/overflow cast')
    if (type(n) is not int or n<0 or not isinstance(shape,(tuple,list))
        or any(type(d) is not int or d<0 for d in shape) or math.prod(shape)!=n):
        raise ValueError('nonnegative integer n/shape and product(shape)==n')
    if raw_payload.size!=(n+1)//2:raise ValueError('payload length must equal ceil(n/2)')
    p=raw_payload.astype(np.uint8)
    if n%2 and (int(p[-1])>>4)!=0:raise ValueError('odd tail padding nibble must be zero')
    raw=np.empty(2*p.size,dtype=np.int16)
    raw[::2]=p&15;raw[1::2]=p>>4;raw=raw[:n]
    return np.where(raw>=8,raw-16,raw).astype(np.int8).reshape(shape)

for x in [np.array([10.,11.]),np.full(3,5.),np.zeros(3),np.array([-5.,-4.])]:
    q,s,z,y=affine(x);assert np.max(np.abs(y-x))<=s/2+1e-12
    print('affine',x.tolist(),'scale',round(s,5),'zero',z,'maxerr',round(float(abs(y-x).max()),5))
W=np.array([[.01,.02,.03,1.,.1],[3.,-1.,.2,.5,0.]])
for g in [1,2,5]:
    q,sc,y=group_quant(W,g);packed,n=pack4(q)
    assert np.array_equal(q,unpack4(packed,n,q.shape))
    payload=packed.nbytes+sc.astype(np.float32).nbytes
    print('group',g,'weightMSE',round(float(((y-W)**2).mean()),7),'packed+fp32scale bytes',payload)
assert np.array_equal(np.rint([.5,1.5,2.5,-.5]),[0,2,2,0])
q,s,y=symmetric(np.array([0.,0.]));assert s==1 and not q.any()
for bad in [np.array([]),np.array([np.nan]),np.array([np.inf])]:
    try:symmetric(bad)
    except ValueError:pass
    else:raise AssertionError('invalid input accepted')

for payload,n,shape in [(np.array([1.5]),2,(2,)),(np.array([256]),2,(2,)),
                        (np.array([],dtype=np.uint8),2,(2,)),
                        (np.array([1],dtype=np.uint8),2,(3,))]:
    try:unpack4(payload,n,shape)
    except ValueError:pass
    else:raise AssertionError('malformed packed payload/metadata accepted')
print('packed float/overflow/short payload and shape mismatch rejected')
```

最后不整除的组照实际长度量化；最后奇数个nibble补零并记录原长度。小矩阵的metadata可能比权重还大，不能由“INT4”推四倍文件压缩。GGUF是存储格式，不是一个独立数值量化算法；文件包含元数据、tokenizer和张量类型，实际tensor可以混合位宽，不能将Q4_K_M等价为所有参数每个恰好4bit。[GGUF官方规格](https://github.com/ggml-org/ggml/blob/master/docs/gguf.md)

## 4. 从编码到矩阵乘法：W-only、W+A与异常通道

权重量化可在运算时按块反量化后做浮点乘法，也可使用专门低位宽kernel。W4A16描述权重4bit、激活16bit；W8A8量化两者，不是把同一个checkpoint文件改名。反量化成完整FP32矩阵再调用普通matmul，只验证数值误差，不证明减少访存或加速。

对称int8的X和W分别有token/output尺度，int32 accumulator $C=q_Xq_W^T$，输出 $s_X s_W^T\odot C$。若非零zero-point，则要用中心化整数，或展开修正`qX@qW.T - zX*sum(qW) - zW*sum(qX) + in*zX*zW`。整数乘加必须先扩dtype；源整数编码配浮点反量化的例子没有验证真实integer GEMM。

LLM.int8类方法将异常activation通道单独做高精度矩阵乘法，余下部分量化后再相加。哪些通道异常应依据代表性校准/实际激活和明确阈值；不是“超过均值六倍”总有效，也不必在所有层都用同一个阈值。本例只以校准张量绝对最大值>10作可核对fixture。

```python
import numpy as np
rng=np.random.default_rng(3)
X=rng.normal(size=(3,5));W=rng.normal(size=(4,5));X[:,2]=np.array([20.,-30.,25.])

def sym(x,axis):
    limit=127;s=np.max(np.abs(x),axis=axis,keepdims=True)/limit;s=np.where(s==0,1.,s)
    return np.clip(np.rint(x/s),-127,127).astype(np.int8),s
qX,sX=sym(X,1);qW,sW=sym(W,1)
acc=qX.astype(np.int32)@qW.astype(np.int32).T
Y=acc.astype(float)*sX*sW.T;reference=X@W.T
# int8 matmul accumulation can overflow; widen BEFORE multiplication.
wrong=np.array([[100,100]],dtype=np.int8)@np.array([[100],[100]],dtype=np.int8)
right=np.array([[100,100]],dtype=np.int32)@np.array([[100],[100]],dtype=np.int32)
assert right.item()==20000 and wrong.item()!=20000
# Calibration-frozen absolute threshold; not the source's 6x-mean universal rule.
keep=np.max(np.abs(X),axis=0)>10
assert np.flatnonzero(keep).tolist()==[2]
normal=~keep;qN,sN=sym(X[:,normal],1);qWN,sWN=sym(W[:,normal],1)
Ymix=(qN.astype(np.int32)@qWN.astype(np.int32).T)*sN*sWN.T+X[:,keep]@W[:,keep].T
# Simulate asymmetric zero-point correction in an integer GEMM.
A=np.array([[5,7]],dtype=np.int32);B=np.array([[8,6]],dtype=np.int32);zx=4;zw=3
correct=(A-zx)@(B-zw).T
expanded=A@B.T-zx*B.sum(1)[None,:]-zw*A.sum(1)[:,None]+A.shape[1]*zx*zw
assert np.array_equal(correct,expanded)
print('integer accumulation',wrong.item(),right.item(),'zero-point corrected',correct.item())
print('full/mixed output MSE',float(((Y-reference)**2).mean()),float(((Ymix-reference)**2).mean()),'kept',np.flatnonzero(keep).tolist())
```

程序展示int8累加溢出与zero-point修正，并比较保留一个异常通道的输出误差。不构成“保某比例一定更好”的结论；通道数量、额外高精度权重、合并kernel和最终任务指标都要记入成本。

## 5. 校准导向PTQ：GPTQ、AWQ与SmoothQuant

### 5.1 GPTQ的目标与逆Hessian误差反馈

给定校准输入X=[in,samples]和W=[out,in]，逐层目标是最小化`||(W-Q)X||²`，而非只最小化`||W-Q||²`。其二阶矩H约为`2XX.T+λI`，damping改善病态/相关通道的数值稳定性。逐输入列量化某权重后，用逆Hessian信息调整尚未量化的权重，补偿重要方向的输出误差。GPTQ用统一列顺序、分块批量更新和逆Hessian的Cholesky表示提高效率。[GPTQ原论文Algorithm1](https://arxiv.org/abs/2210.17323)

下面实现blocksize1、固定对称行grid的核心递推：U=chol(H^-1).T，`e=(W[:,j]-Q[:,j])/U[j,j]`，`W[:,j:] -= e[:,None]*U[j,j:]`。它省略真实大模型的分组搜索、activation ordering、逐block传播校准与kernel打包，但保留真正的二阶误差反馈。源`simulated_gptq`只读H对角并任意给其他输出列加0.1补偿，不是这个算法；1D校准输入还会把scalar outer-product广播到整个H。

### 5.2 AWQ的等价缩放与校准搜索

对输入通道对角D=diag(s)，精确实数函数满足`W X = (W D)(D^-1 X)`。AWQ根据激活统计选择输入通道尺度，在同一个输出channel/group内保护重要通道，并校准量化后输出误差。放大一个通道可能同时放大该组scale并伤害其他通道，因此要搜索而非固定“保护1%就无损”。[AWQ原论文](https://arxiv.org/abs/2306.00978)

若每输入行自己用absmax量化，随后除回同一输入行尺度，这个缩放可能与量化grid一起完全抵消；源AWQ例就存在此问题。下面用正确输出行布局，共用输入通道组，搜索激活统计的几个指数，先断言未量化函数不变，再独立报告校准和留出误差。它是AWQ机制小实现，不是完整模型转换器或AWQ品牌性能复现。

```python
import numpy as np
rng=np.random.default_rng(1)
# W=[out,in], X=[in,calibration samples], objective ||(W-Q)X||_F^2.
X=rng.normal(size=(6,40));X[1]=.95*X[0]+.05*X[1]
W=rng.normal(size=(3,6))*.3;limit=7
scales=np.maximum(np.max(abs(W),axis=1,keepdims=True)/limit,1e-12)
RTN=np.clip(np.rint(W/scales),-limit,limit)*scales
H=2*X@X.T;H+=np.eye(6)*(.01*np.diag(H).mean())
# GPTQ Algorithm1 at blocksize1: fixed grids, upper Cholesky inverse Hessian.
U=np.linalg.cholesky(np.linalg.inv(H)).T
work=W.copy();Q=np.zeros_like(W)
for j in range(W.shape[1]):
    Q[:,j]=np.clip(np.rint(work[:,j]/scales[:,0]),-limit,limit)*scales[:,0]
    error=(work[:,j]-Q[:,j])/U[j,j]
    work[:,j:]-=error[:,None]*U[j,j:][None,:]
assert np.isfinite(Q).all() and not np.array_equal(Q,RTN)
print('RTN/GPTQ calibration output MSE',float(np.mean(((RTN-W)@X)**2)),float(np.mean(((Q-W)@X)**2)))
# AWQ-style activation-guided input-channel scaling, shares output-row groups.
# This is a small search of the actual equivalent transformation, not full AWQ tooling.
X2=rng.normal(size=(6,40));X2[0]*=10;W2=rng.normal(size=(3,6))*.1
importance=np.maximum(np.mean(abs(X2),axis=1),1e-4);candidates=[]
for power in [0.,.25,.5,.75,1.]:
    s=importance**power;s/=np.sqrt(s.max()*s.min())
    scaled=W2*s[None,:]
    assert np.allclose((scaled@(X2/s[:,None])),W2@X2)
    grid=np.maximum(np.max(abs(scaled),axis=1,keepdims=True)/7,1e-12)
    deq=np.clip(np.rint(scaled/grid),-7,7)*grid
    reconstructed=deq/s[None,:]
    candidates.append((float(np.mean(((reconstructed-W2)@X2)**2)),power,reconstructed))
best=min(candidates,key=lambda z:z[0]);assert best[0]<=candidates[0][0]
# Independent held-out inputs, not claims of task quality or universal superiority.
Xt=rng.normal(size=(6,20));Xt[0]*=10
print('AWQ-style best power/calibration/heldout MSE',best[1],best[0],float(np.mean(((best[2]-W2)@Xt)**2)))
```

SmoothQuant也做输入通道等价缩放，将activation的量化困难部分移到权重上，以便W8A8；AWQ主要优化weight-only低位宽。两者“缩放”相似，但目标、激活是否量化、校准和kernel配置不同。scale不可随意添加到一层却忘记融合到前层归一化/相邻算子；融合后要检查原float函数和保存的权重修订。

## 6. QAT：fake quant、STE与真正的小训练

PTQ在已训练参数上做校准/量化，不做常规梯度重训；QAT在前向模拟round/clamp/反量化，并用代理梯度让参数学习适应误差，可以从头训练或短期微调，不是必然完整预训练。fake quant通常保留浮点主参数，并不立刻实现低位宽物理存储。

真实round几乎处处导数0；STE在未饱和区用近似导数1，clipping外通常用0。它是有偏代理，不是round的真实导数。scale/zero-point是固定、observer更新还是学习参数，需要说明；若scale随权重取absmax但detach，只验证该代理合同，不能称完整最优QAT。

```python
import copy,torch
from torch import nn
import torch.nn.functional as F
torch.set_num_threads(1);torch.manual_seed(3)
# Fixed quantizer demonstrates clipped STE: gradient1 inside,0 outside.
x=torch.tensor([-3.,-.7,.1,2.],requires_grad=True)
y=torch.fake_quantize_per_tensor_affine(x,.2,0,-7,7);y.sum().backward()
assert torch.equal(x.grad,torch.tensor([0.,1.,1.,0.]))
class Net(nn.Module):
    def __init__(self):super().__init__();self.a=nn.Linear(2,8);self.b=nn.Linear(8,1)
    def forward(self,x,fake=False):
        def W(w):
            if not fake:return w
            scale=max(float(w.detach().abs().max())/7,1e-6)
            return torch.fake_quantize_per_tensor_affine(w,scale,0,-7,7)
        h=F.relu(F.linear(x,W(self.a.weight),self.a.bias))
        return F.linear(h,W(self.b.weight),self.b.bias)
xx=torch.randn(64,2);yy=(xx[:,0:1]**2+.5*xx[:,1:2])
base=Net();ptq=copy.deepcopy(base);qat=copy.deepcopy(base)
for model,fake in [(ptq,False),(qat,True)]:
    opt=torch.optim.Adam(model.parameters(),lr=.02)
    for _ in range(120):
        loss=F.mse_loss(model(xx,fake),yy);opt.zero_grad();loss.backward();opt.step()
xt=torch.randn(32,2);yt=xt[:,0:1]**2+.5*xt[:,1:2]
with torch.no_grad():
    fp=F.mse_loss(ptq(xt),yt);post=F.mse_loss(ptq(xt,True),yt);aware=F.mse_loss(qat(xt,True),yt)
assert all(torch.isfinite(z) for z in (fp,post,aware))
print('STE gradient',x.grad.tolist(),'heldout FP/PTQ/QAT losses',[round(float(z),5) for z in (fp,post,aware)])
```

程序训练同初始化的两层回归网络，分别采用普通训练后PTQ、训练时fake-quant，留出输入报告FP/PTQ/QAT loss；不预定QAT必胜。本次FP/PTQ/QAT留出loss分别约.03584/.04760/.05476，QAT在这个训练预算与grid下比PTQ更差，应如实保留，而不是为了证明方法好再改实验。还验证饱和区STE为0。真正导出时需使用后端支持的量化算子/pack配置，fake-quant训练loss通过不等于引擎已兼容。

## 7. KV与activation量化：误差在哪里进入计算

KV的基础字节由batch×layers×seq×KV-heads×head-dim×2份K/V×dtype确定，见工程14公式。GQA不能用完整hidden_dim直接代KV头；源70B32K=40GB的例子漏掉GQA等条件，另一课40GiB对应128K，这不是同一上下文容量。scale/zero-point/未量化部分要另计。

量化K会改变attention scores及归一化权重，量化V会改变weighted sum。并非所有误差都“按长度平方累计”；某些模型/通道/长度更敏感，需要实际校准和长上下文任务评估。softmax对所有logits加同一常量完全不变，因而不能说任意0.01扰动都被放大。源sensitivity experiment把“logit加5%高斯噪声”与实际量化其他模块比较，不能推一般敏感性排序。

下面单query/GQA缓存fixture分别量化K/V，明确K按feature跨sequence、V按token跨feature定scale；它不规定任何生产KV方案。

```python
import numpy as np
rng=np.random.default_rng(5)
B,HQ,HK,S,D=1,4,2,6,4
q=rng.normal(size=(B,HQ,1,D));k=rng.normal(size=(B,HK,S,D));v=rng.normal(size=k.shape)
def quant(x,axis,bits=4):
    limit=2**(bits-1)-1;scale=np.max(abs(x),axis=axis,keepdims=True)/limit;scale=np.where(scale==0,1.,scale)
    code=np.clip(np.rint(x/scale),-limit,limit).astype(np.int8)
    return code.astype(float)*scale,code,scale

def attn(q,k,v,shift=0.):
    k=np.repeat(k,HQ//HK,axis=1);v=np.repeat(v,HQ//HK,axis=1)
    scores=q@k.swapaxes(-1,-2)/np.sqrt(D)+shift
    w=np.exp(scores-scores.max(-1,keepdims=True));w/=w.sum(-1,keepdims=True)
    return w@v,w
base,p=attn(q,k,v)
kq,kcode,kscale=quant(k,-2)  # per feature across sequence, explicit toy convention
vq,vcode,vscale=quant(v,-1)  # per token across feature
for name,kk,vv in [('K only',kq,v),('V only',k,vq),('K+V',kq,vq)]:
    out,prob=attn(q,kk,vv)
    print(name,'outputMSE',float(np.mean((out-base)**2)),'attentionL1',float(np.mean(abs(prob-p))))
assert np.allclose(attn(q,k,v,shift=.01)[0],base)
ideal_fp16=2*B*HK*S*D*2
packed4=(kcode.size+vcode.size+1)//2+(kscale.size+vscale.size)*4
print('small-cache FP16 bytes / packed4+fp32scale estimate',ideal_fp16,packed4)
print('common logit shift leaves softmax unchanged; no universal component sensitivity ordering')
```

本次两种单项输出MSE约.00036，K量化改变attention、V量化只改变weighted sum；一起量化约.00085，不能将误差简单相加。小cache 16bit载荷192byte，4bit打包+FP32scale估计128byte，未获理想四倍缩小。

评估分三个层次：权重重构MSE/max-error/cosine、校准和独立输入的层输出误差、真实模型任务指标与容量/时延。零向量cosine未定义，零signal的SNR也须特别处理；不要把人为返回0误读成不相似。PPL比较要保持tokenizer、切块、mask、语料与loss约定相同，领域任务看完整错误分布；原表的固定PPL/MMLU/速度没有本批可比实测，不保留为保证。

## 8. Activation checkpoint：重算哪些值，保持哪些状态

### 8.1 用计算换保存，不能减少所有状态

反向需要计算局部VJP的输入/中间量，不是只有调用`retain_grad()`才保存；autograd会按算子规则保留所需张量。checkpoint将区域的一部分中间量丢弃，反向需要时从保存的边界重新前向；segment内部重算仍按原前向顺序，反向遍历segment则逆序；它不等于训练断点存盘，也不减少optimizer/parameter常驻字节。

对uniform chain，边界数量约L/k，最大局部重算segment约k，粗存储模型`a*(L/k+k)`在k≈sqrt(L)附近最小。这是均匀成本、单链、特定保存策略的直觉，不是Transformer所有架构最优。每层内部保存可远大于边界输入，因此k1仍可能节省内存并重算该层；源cost函数却给k1额外算术0，与其实际每层重算不符。

若前向F、反向约2F，完整额外前向为F，总训练step由3F变4F，额外为**整个step约33%**，不是“前向只多33%”。按真实kernel/early-stop/FSDP再次all-gather、缓存/通信可能完全不同。activation的`12*B*S*d`是假定系数，不是实测峰值；FlashAttention已避免保存完整S²矩阵时，旧selective估计需重算。

### 8.2 非重入实现、RNG与副作用

显式`checkpoint(fn,x,use_reentrant=False)`。非重入会记录图、按所需中间量early-stop；重入通常整段重算，有输入输出requires_grad及嵌套结构等限制。官方推荐优先非重入，但实际版本行为应核对。[PyTorch checkpoint](https://docs.pytorch.org/docs/stable/checkpoint.html)

Dropout等随机操作重算必须与原前向同mask，否则梯度不再对应原loss。默认保存CPU及推断的另一种设备类型RNG；函数内部搬到未被预见的新设备或额外随机源，不自动保证正确。`preserve_rng_state=False`是明确改变一致性条件，不是免费优化。`determinism_check`主要检查保存张量的metadata，不能代替数值梯度等价。

BatchNorm运行均值、计数器、FP8 amax history、路由容量状态或I/O副作用，可能在重算再更新一次。设计纯函数区域，或明确保存/恢复相关状态；要检查参数梯度和**输入梯度**，同时核对buffer。没有报错不等于grad正确。

```python
import copy,torch
from torch import nn
from torch.utils.checkpoint import checkpoint
torch.set_num_threads(1);torch.manual_seed(5)
class Block(nn.Module):
    def __init__(self):
        super().__init__();self.a=nn.Linear(4,8);self.b=nn.Linear(8,4);self.drop=nn.Dropout(.35)
        self.calls=0
    def forward(self,x):
        self.calls+=1
        return self.b(self.drop(torch.tanh(self.a(x))))
base=nn.Sequential(*[Block() for _ in range(4)]).double().train()
input0=torch.randn(3,4,dtype=torch.float64)
def run(mode,preserve=True):
    model=copy.deepcopy(base);x=input0.clone().requires_grad_(True);torch.manual_seed(91)
    saved=[]
    def pack(t):saved.append((t.shape,t.numel()*t.element_size()));return t
    with torch.autograd.graph.saved_tensors_hooks(pack,lambda t:t):
        y=x
        for layer in model:
            if mode:y=checkpoint(layer,y,use_reentrant=False,preserve_rng_state=preserve)
            else:y=layer(y)
        loss=y.square().sum();loss.backward()
    return y.detach(),x.grad,[p.grad.clone() for p in model.parameters()],[b.calls for b in model],saved
normal=run(False);ck=run(True);no_rng=run(True,False)
assert torch.allclose(normal[0],ck[0],atol=1e-12)
assert torch.allclose(normal[1],ck[1],atol=1e-12)
assert all(torch.allclose(a,b,atol=1e-12) for a,b in zip(normal[2],ck[2]))
assert not torch.allclose(normal[1],no_rng[1],atol=1e-10)
assert normal[3]==[1]*4 and ck[3]==[2]*4
# Hooks count saved tensor references, not unique storage or CPU/GPU peak memory.
print('module entries normal/checkpoint',normal[3],ck[3])
print('saved-reference logical bytes',sum(z[1] for z in normal[4]),sum(z[1] for z in ck[4]))
print('with RNG: outputs+input+parameter gradients agree; without RNG input maxdiff',float((normal[1]-no_rng[1]).abs().max()))
# Side effect outside autograd is replayed; purity must include buffer state.
class Stateful(nn.Module):
    def __init__(self):super().__init__();self.register_buffer('count',torch.zeros(()))
    def forward(self,x):self.count.add_(1);return (x*float(self.count)).square()
a=Stateful();x=torch.tensor([2.],requires_grad=True);a(x).sum().backward()
b=Stateful();z=torch.tensor([2.],requires_grad=True)
checkpoint(b,z,use_reentrant=False).sum().backward()
assert a.count==1 and b.count==2 and not torch.equal(x.grad,z.grad)
print('stateful counts/gradient',float(a.count),float(b.count),x.grad.tolist(),z.grad.tolist())
```

这段程序真实运行checkpoint forward/backward，比较output、input和全部parameter gradients，计数模块进入次数；另主动关闭RNG保持，构造mutable buffer反例。saved-tensor hook统计的是保存引用的逻辑字节，包含重复引用/参数可能被引用，**不是GPU峰值或完整实际内存**。本次普通/重算模块进入次数分别为每层1/2，保存引用逻辑字节4832/480；关闭RNG保持的输入梯度最大差约.0445，状态计数器反例梯度4变8。CPU程序不能用此数字宣称显存减几倍。

### 8.3 Selective与offload的条件

Selective选择性保留成本较高的matmul结果、重算低成本但占保存空间的算子；策略要结合真实attention kernel、FFN、张量大小及compiler。checkpoint整块即使attention内部已重算，也可能节省FFN等其他激活，不能因FlashAttention存在就总禁用整层checkpoint。更多设备内并行可能增加重算通信，也需profile。

Activation offload把反向所需张量保存在CPU、使用时回传；与FSDP2 `CPUOffloadPolicy`的参数/梯度/optimizer状态offload不同。`to_empty()`分配未初始化存储，不是保留activation的offload API，不能拿它实现数据保存。真实实现可研究autograd saved-tensor hooks/`save_on_cpu`，并核对pin_memory、异步传输与生命周期。

粗比较是额外传出+传回的字节/有效带宽与重算时间，加分配/同步；二者可部分重叠，但竞争带宽后可能双慢。把CPU列表叫PCIe测量不成立。源要求真实CUDA峰值benchmark本批没有设备分支执行，保留实验判据：同模型/数据/RNG、预热、同步、峰值重置后测step、同时测梯度一致与目标设备峰值。

## 9. 验收题与来源纠错

- 70B、2byte参数/梯度、8byte moments、D8 ZeRO3：常驻105GB；去掉所有激活仍不能满足80GB。另有FP32master时则140GB/rank。所需rank下界与最终峰值必须分开。
- W=[out,in]时per-output scales的形状是[out,1]；若按输入列缩放，须反向缩放X，且量化group不同才可能产生保护作用。
- 4bit编码存int32每个占32bit，没有四倍载荷节省。打包奇数尾部需保存原长度，scale metadata另计。
- 全正常量5不能量化后变0；仿射范围含0时s=5/255、z0可表示5。clipping之外不能声称s/2误差界。
- 原quiz“95%Llama70B权重位于[-.1,.1]因为weight decay/LN”没有读取真实模型统计证据；正确定义是先测每层分布/outlier，训练方法不证明该比例，更不证明量化无损。
- 重算区域有Dropout时output相同但参数/input梯度不同比如RNG未恢复；buffer多更新一次也是正确性失败。只比较parameter grad不足。

来源的开放练习完整保留评价方法：group32/64/128/256对比同时报告pack+metadata和输出误差；首尾INT8/中间INT4与uniform位宽比较同输入；outlier3x/6x/10x阈值需校准留出；dashboard用直方图、每channel max-error/MSE与100输入层误差寻找敏感块。真实GPTQ/AWQ转换、Llama benchmark、本批CUDAoffload/FP8kernel/多卡训练均未执行，不能将这些开放练习写成已通过。

Checkpoint五题：完整/重算比较须同时含input/param/buffer；扫k应实测重算调用/保存引用和目标设备峰值而非只画假公式；selective32层S8192须按实际kernel获取FLOPs/存储；offload虚拟列表不能称PCIe测速；真实Transformer显存/step benchmark需GPU环境且同步。分布式五题的1F1B与微批累加数值程序在计算性能06维护；固定33%/30–50%offload成本和租卡报价没有被当已验证结果。
