# 来源保全

本目录不是主学习入口，用于保存重要来源的完整上下文、版本与可恢复标识。

原则：

- 主知识库回答“现在应该知道什么”；
- 来源保全回答“这些知识来自哪里、原始上下文是什么”；
- 不把站点构建脚本、缓存、运行日志等工程噪声当知识保存；
- 对未能直接迁移的资源，保存精确路径、版本和 Blob SHA。
